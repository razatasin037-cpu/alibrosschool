PHP Setup Kaise Karein?

PHP ek Server-Side Language hai, isliye ise apne computer par run karne ke liye ek Local Web Server Environment ki zaroorat hoti hai.

Is tutorial me hum sabse popular free aur open-source tool XAMPP ka use karenge, jisme Apache Web Server, PHP aur MySQL Database ek sath mil jate hain.

Setup Ke Liye Kya Software Chahiye?

1. Web Server

Apache Server jo PHP scripts ko read aur process karta hai.

2. PHP Engine

PHP 8+ execution engine jo aapka backend code run karta hai.

3. Text Editor

Code likhne ke liye VS Code, SubLime Text ya Notepad++.

XAMPP Install Karne Ke Steps

  • Step 1
    XAMPP Download Karein

    Official website Apache Friends (apachefriends.org) par jayein aur apne OS (Windows/Mac/Linux) ke hisaab se PHP 8+ version download karein.

  • Step 2
    Installer Run Karein

    Downloaded file ko open karein, default options select rehne dein aur Next-Next karke installation complete karein (by default yeh C:\xampp folder me install hoga).

  • Step 3
    XAMPP Control Panel Start Karein

    XAMPP Control Panel open karein aur Apache ke saamne bane Start button par click karein.

Pehli PHP File Kaise Run Karein?

Setup hone ke baad, apni pehli PHP script run karne ke liye niche diye gaye steps follow karein:

1. Htdocs Folder Me File Banayein:
Apne PC me C:\xampp\htdocs\ path par jayein aur વહા ek naya folder banayein (jaise mytutorial).

2. File Banayein:
Uss folder me index.php naam se file banayein aur usme niche diya gaya code likhein:

<?php
  // Server Output Check
  echo "Hello World! Localhost server setup successful.";
?>

3. Browser Me Test Karein:
Apna Browser (Chrome/Edge) open karein aur URL bar me type karein:
http://localhost/mytutorial/index.php

💡 Important Point to Remember

Apni PHP files ko hamesha C:\xampp\htdocs\ folder ke andar hi rakhein. Browser me file run karne se pehle ensure kar lein ki XAMPP Control Panel me Apache Server "Running" state me ho.
