Modify Strings Kya Hota Hai?

PHP me strings me badlav (modify) karne ke liye alag-alag built-in functions hote hain.

Aap string ko Uppercase/Lowercase me badal sakte hain, extra spaces hata sakte hain, characters ko replace kar sakte hain ya string ko slice kar sakte hain.

Upper and Lower Case

String letters ko UPPERCASE ya lowercase me convert karne ke liye strtoupper() aur strtolower() ka upyog hota hai: 

<?php
  $x = "Hello World!";

  // Convert to Uppercase
  echo strtoupper($x); // Output: HELLO WORLD!

  // Convert to Lowercase
  echo strtolower($x); // Output: hello world!
?>

Replace String (str_replace)

String ke kisi specific word ya character ko dusre word se badalne ke liye str_replace() ka use karte hain: 

<?php
  $x = "Hello World!";

  // Replace "World" with "Dolly"
  echo str_replace("World", "Dolly", $x); // Output: Hello Dolly!
?>

Reverse String (strrev)

Poori string ko ulta (reverse) karne ke liye strrev() function use kiya jata hai: 

<?php
  $x = "Hello World!";

  // Reverse the string
  echo strrev($x); // Output: !dlroW olleH
?>

Remove Whitespace (trim)

Whitespace string ke start aur end wale space ko kehte hain. trim() extra space ko hata deta hai: 

<?php
  $x = " Hello World! ";

  // Removes spaces from beginning and end
  echo trim($x); // Output: "Hello World!"
?>

Convert String into Array (explode)

explode() function string ko specific separator (jaise space ya comma) ke basis par tod kar **Array** me convert kar deta hai: 

<?php
  $x = "Hello World!";

  // Split string into array by space
  $y = explode(" ", $x);

  // Display Array
  print_r($y);
  /* Output:
  Array ( 
    [0] => Hello 
    [1] => World! 
  ) */
?>

Quick Reference Table

Function Kaya karta hai?
strtoupper() String ko Uppercase me convert karta hai.
strtolower() String ko Lowercase me convert karta hai.
str_replace() String me kisi text ko doosre text se badalta hai.
strrev() Poori string ko reverse (ulta) kar deta hai.
trim() Start aur End ke extra space ko remove karta hai.
explode() String ko array me divide kar deta hai.

💡 Important Note

PHP me string modify karne wale functions original variable ko change **nahi** karte. Woh bas ek modified new string return karte hain. Agar original variable ki value change karni ho, toh us variable me nayi value assign karni padegi (jaise: $x = strtoupper($x);).
