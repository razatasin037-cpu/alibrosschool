Strings Kya Hain?

String characters ka ek sequence hota hai (jaise "Hello World"). PHP me strings ko single quotes ('') ya double quotes ("") ke andar enclose kiya jata hai.

Double quotes me variables render ho jate hain ("$x"), jabki single quotes me string literal form me print hoti hai.

Built-in String Functions

PHP me strings ko manipulate karne ke liye bohot se handy built-in functions hote hain: 

<?php
  $str = "Hello World!";

  // 1. String Length
  echo strlen($str); // Output: 12

  // 2. Word Count
  echo str_word_count($str); // Output: 2

  // 3. Reverse String
  echo strrev($str); // Output: !dlroW olleH

  // 4. Search Text Position
  echo strpos($str, "World"); // Output: 6

  // 5. Replace Text
  echo str_replace("World", "PHP", $str); // Output: Hello PHP!
?>

String Concatenation (Jodna)

Do ya do se zyada strings ko combine karne ke liye dot operator (.) ya assignment operator (.=) ka use kiya jata hai. 

<?php
  $firstname = "John";
  $lastname = "Doe";

  // Using dot (.) operator
  $fullname = $firstname . " " . $lastname;
  echo $fullname; // Output: John Doe

  // Concatenation Assignment (.=)
  $txt = "Hello";
  $txt .= " World!";
  echo $txt; // Output: Hello World!
?>

Slicing & Case Modification

Strings ka specific part extract karne ya letters ko Upper/Lower case me badalne ke tarike: 

<?php
  $str = "PHP Programming";

  // Convert to Uppercase
  echo strtoupper($str); // Output: PHP PROGRAMMING

  // Convert to Lowercase
  echo strtolower($str); // Output: php programming

  // Slicing / Substring (Start index, Length)
  echo substr($str, 4, 7); // Output: Program
?>

Escape Characters

Jab string me special symbols (jaise double quotes ke andar double quotes) use karne hon, tab Backslash (\) ka upyog hota hai: 

<?php
  // Escaping Double Quotes
  $txt = "We are the \"Vikings\" from the north.";
  echo $txt;

  // Common Escape Sequences:
  // \"  Double Quote
  // \$  PHP Variable Sign
  // \\  Backslash
  // \n  New Line
?>

💡 Important Tip

Double Quotes ("") aur Single Quotes ('') me speed ka minor diff hota hai. Double quotes string parse karte hain jabki single quotes raw print karte hain. Isliye variables bina concatenation ke print karne ke liye double quotes best hain.
