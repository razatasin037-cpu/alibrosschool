String Functions Kya Hain?

PHP me text data ko modify, trim, search, ya format karne ke liye bohot se powerful built-in functions milte hain.

In functions ki madad se aap user input clean kar sakte hain, security parameters enforce kar sakte hain, aur dynamic content format kar sakte hain.

Trimming & Cleaning Functions

String ke starting ya ending whitespaces remove karne ke liye trim(), ltrim(), aur rtrim() ka use hota hai: 

<?php
  $str = "   Hello World!   ";

  // Both sides space remove
  echo trim($str); // Output: "Hello World!"

  // Left side space remove
  echo ltrim($str);

  // Right side space remove
  echo rtrim($str);
?>

Convert Between Array & String

String ko array me break karne ke liye explode() aur array elements ko string me join karne ke liye implode() ka use hota hai: 

<?php
  $text = "HTML,CSS,JavaScript,PHP";

  // String to Array
  $arr = explode(",", $text);
  print_r($arr); 

  // Array to String
  $languages = ["PHP", "Python", "Java"];
  $string = implode(" - ", $languages);
  echo $string; // Output: PHP - Python - Java
?>

Capitalization Functions

First letter ya har word ke pehle letter ko capital karne ke liye handy functions: 

<?php
  $title = "welcome to php web development";

  // Capitalize first letter of string
  echo ucfirst($title); // Output: Welcome to php web development

  // Capitalize first letter of EVERY word
  echo ucwords($title); // Output: Welcome To Php Web Development
?>

Top PHP String Functions Reference

Function Description
strlen($str) String ki total length return karta hai.
str_replace($old, $new, $str) Specific characters ko naye content se replace karta hai.
strpos($str, "search") Search word ka pehla index position batata hai.
substr($str, $start, $len) String ka portion extract karta hai.
htmlspecialchars($str) HTML tags ko safe entities me convert karta hai (Security for XSS).

💡 Security Tip

Form inputs se aane wale dynamic text data par hamesha trim() aur htmlspecialchars() functions apply karna chahiye taaki Cross-Site Scripting (XSS) attacks aur unnecessary trailing spaces se protection mil sake.
