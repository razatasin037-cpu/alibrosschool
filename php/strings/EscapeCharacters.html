Escape Characters Kya Hote Hain?

Jab aapko string ke andar aise special characters insert karne hote hain jo PHP syntax se clash karte hain (jaise double quotes ke andar double quotes), tab **Escape Characters** ka upyog kiya jata hai.

PHP me kisi character ko escape karne ke liye backslash (\) Symbol ka use hota hai.

Escaping Quotes

Agar aap double quotes string ke andar ek aur double quote likhenge bina escape kiye, toh PHP error de dega. Isko prevent karne ke liye \" use karein: 

<?php
  // Correct Syntax with Escape Backslash
  $x = "We are the \"Vikings\" from the north.";
  echo $x; // Output: We are the "Vikings" from the north.

  // Escaping Single Quote in Single-Quoted String
  $y = 'It\'s a beautiful day!';
  echo $y; // Output: It's a beautiful day!
?>

Control Characters (\n, \t, \$)

Double-quoted strings me escape sequences ka upyog Nayi Line (`\n`), Tab space (`\t`), ya Dollar symbol (`\$`) ko literals ki tarah dikhane ke liye hota hai: 

<?php
  // 1. Prevent Variable Parsing (\$)
  $price = 100;
  echo "The product cost is \$price."; // Output: The product cost is $price.

  // 2. New line (\n) & Tab (\t) - visible in source code / terminal
  $text = "Hello\tWorld!\nWelcome to PHP.";
  echo nl2br($text); // nl2br converts \n to HTML <br> tag
?>

Common Escape Sequences Reference

Escape Code Character Name Description
\' Single Quote Single quote ko print karta hai.
\" Double Quote Double quote ko print karta hai.
\$ PHP Dollar Sign Variable expansion ko rok kar dollar sign ($) print karta hai.
\\ Backslash Ek single backslash (\) character print karta hai.
\n New Line Output me nayi line insert karta hai.
\r Carriage Return Line break control ke liye use hota hai.
\t Tab Space Horizontal tab space add karta hai.

💡 Important Difference

Escape sequences jaise \n, \t, aur \$ sirf Double-Quoted Strings (`""`) ke andar kaam karte hain. Single-quoted strings (`''`) me `\n` ya `\t` ko plain text ki tarah maana jayega.
