Echo aur Print Kya Hain?

PHP me screen par data ya text display (output) karne ke do basic tarike hote hain: echo aur print.

Dono ka use output dikhane ke liye hota hai, lekin inke kaam karne me kuch chote differences hain.

Echo vs Print Difference

Feature echo print
Return Value Koi value return nahi karta (Void). Hamesha 1 return karta hai (Expression me use kar sakte hain).
Parameters Multiple parameters le sakta hai (comma se separate karke). Sirf ek hi argument/string le sakta hai.
Speed Thoda fast hota hai. echo ke muqable thoda slow hota hai.
Syntax echo ya echo() print ya print()

PHP echo Statement

echo statement ke sath parentheses () lagana optional hota hai. Aap HTML tags aur strings ko aasan tarike se print kar sakte hain: 

<?php
  echo "<h2>PHP is Fun!</h2>";
  echo "Hello World!<br>";
  echo "I'm learning PHP!<br>";
  
  // Passing multiple parameters (Only allowed in echo)
  echo "This ", "string ", "was ", "made ", "with multiple parameters.";
?>

Displaying Variables with echo

Variables aur text ko ek sath print karne ke liye concatenation operator (.) ya direct double quotes interpolate ka use kiya ja sakta hai: 

<?php
  $txt1 = "Learn PHP";
  $txt2 = "W3Schools";
  $x = 5;
  $y = 4;

  echo "<h2>" . $txt1 . "</h2>";
  echo "Study PHP at " . $txt2 . "<br>";
  echo $x + $y;
?>

PHP print Statement

print statement bhi text print karne ke kaam aata hai. Isme bhi parentheses optional hote hain, lekin yeh multiple parameters support nahi karta. 

<?php
  $txt1 = "PHP Scripting";
  $x = 10;

  print "<h2>" . $txt1 . "</h2>";
  print "Value of X is: $x";
?>

💡 Important Tip

Real-world Web Development me ziada tar developers echo ko prefer karte hain kyunki yeh speed me thoda fast hota hai aur syntax readable rehta hai.
