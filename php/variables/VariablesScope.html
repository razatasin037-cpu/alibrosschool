Variable Scope Kya Hota Hai?

PHP me variable ka Scope yeh decide karta hai ki wo script ke kis hisse me access ya use kiya ja sakta hai.

PHP me 3 mukhya scopes hote hain: Local, Global, aur Static.

1. Global vs Local Scope

Function ke bahar declare hua variable Global hota hai, aur function ke andar declare hua variable Local hota hai. 

<?php
  $x = 5; // Global Scope

  function myTest() {
    $y = 10; // Local Scope
    // echo $x;  // Error: Cannot access global $x directly inside function
    echo "Local y: " . $y;
  }

  myTest();
?>

2. The global Keyword

Function ke andar Global variable ko use karne ke liye global keyword ka use kiya jata hai: 

<?php
  $a = 10;
  $b = 20;

  function addValues() {
    global $a, $b;
    $b = $a + $b;
  }

  addValues();
  echo $b; // Outputs: 30
?>

3. The static Keyword

Normal function execute hone ke baad uske local variables delete ho jate hain. Agar aap variable ki purani value ko retain (yaad) rakhna chahte hain, toh static keyword ka use karein: 

<?php
  function counter() {
    static $count = 0;
    echo $count;
    $count++;
  }

  counter(); // Outputs: 0
  counter(); // Outputs: 1
  counter(); // Outputs: 2
?>

💡 Scope Quick Summary

  • Global: Function ke bahar access hota hai.
  • Local: Sirf usi function ke andar access hota hai.
  • Static: Function call ke baad bhi apni value lose nahi karta.
