Variables Kya Hain?

Variables data store karne ke liye containers ki tarah kaam karte hain (jaise text, numbers, arrays, etc.).

PHP me variable ka naam hamesha $ (Dollar) sign se shuru hota hai.

Creating (Declaring) PHP Variables

PHP me variable declare karne ke liye koi alag command nahi hoti. Jab aap variable ko value assign karte hain, tabhi woh create ho jata hai: 

<?php
  $txt = "Hello World!"; // String variable
  $x = 5;               // Integer variable
  $y = 10.5;            // Float (Decimal) variable

  echo $txt;
  echo "<br>";
  echo $x + $y;
?>

PHP Variable Naming Rules

Rule 1: Starts with $ Sign

Variable $ se start hona chahiye, jiske baad variable ka naam aata hai.

Rule 2: First Character

Naam ka pehla letter letter (A-z) ya underscore (_) hona chahiye. Number se start nahi ho sakta.

Rule 3: Allowed Characters

Naam me sirf alpha-numeric characters aur underscores (A-z, 0-9, aur _ ) allowed hain.

Rule 4: Case-Sensitive

$age aur $AGE do alag variables maane jayenge.

Outputting Variables (echo & Concatenation)

Variables ko screen par print karne ke liye echo statement ka use kiya jata hai. Variables ko text ke sath milane ke liye dot (.) operator use hota hai: 

<?php
  $txt = "PHP Tutorials";
  
  // Method 1: String Concatenation using Dot (.)
  echo "I love " . $txt . "!";

  // Method 2: Double quotes interpolation
  echo "<br>I love $txt!";
?>

PHP is a Loosely Typed Language

PHP me variable ka data type declare nahi karna padta (jaise C++ ya Java me karna padta hai). PHP automatically value ke hisaab se data type assign kar leta hai. 

<?php
  $x = "5";  // String
  $y = 10;   // Integer
  
  // PHP automatically converts string to number for addition
  echo $x + $y; // Outputs: 15
?>

Variable Ka Data Type Kaise Check Karein?

PHP me kisi bhi variable ka data type aur uski exact value janne ke liye var_dump() function ka use hota hai: 

<?php
  $name = "Amit";
  $age = 25;
  $price = 99.99;
  $is_active = true;

  var_dump($name);     // Output: string(4) "Amit"
  var_dump($age);      // Output: int(25)
  var_dump($price);    // Output: float(99.99)
  var_dump($is_active); // Output: bool(true)
?>

💡 Important Tip

Descriptive names use karein (e.g., $user_name ya $totalAmount) bajaye $u ya $t ke, taaki code readable rahe.
