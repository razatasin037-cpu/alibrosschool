Managing Client-Side Data with Cookies

Cookie ek chhoti file hoti hai jo server user ke computer par store karta hai. Jab bhi same computer dobara page request karta hai, browser cookie ko sath me bhejta hai.

Syntax Rule

setcookie() function hamesha <html> tag se PEHLE call hona chahiye, kyunki ye HTTP headers ke sath bheja jata hai.

1. Create and Read a Cookie

Cookie set karne ke liye setcookie() function use hota hai aur uski value access karne ke liye $_COOKIE superglobal ka use hota hai. 

<?php
// Cookie set karein (30 din ke liye valid)
$cookie_name = "user";
$cookie_value = "John Doe";
setcookie($cookie_name, $cookie_value, time() + (86400 * 30), "/"); // 86400 = 1 day
?>
<html>
<body>

<?php
if(!isset($_COOKIE[$cookie_name])) {
     echo "Cookie named '" . $cookie_name . "' is not set!";
} else {
     echo "Cookie '" . $cookie_name . "' is set!<br>";
     echo "Value is: " . $_COOKIE[$cookie_name];
}
?>

</body>
</html>

2. Modify and Delete a Cookie

Cookie ko modify karne ke liye dubara setcookie() call karein nayi value ke sath. Delete karne ke liye expiration date past ki set kar dein (e.g. time() - 3600): 

<?php
// Cookie delete karne ke liye date past me set karein
setcookie("user", "", time() - 3600, "/");

echo "Cookie 'user' is deleted.";
?>

3. Check if Cookies are Enabled

Aap test cookie set karke aur fir count($_COOKIE) check karke jaan sakte hain ki user ke browser me cookies enabled hain ya nahi: 

<?php
setcookie("test_cookie", "test", time() + 3600, "/");
?>
<html>
<body>

<?php
if(count($_COOKIE) > 0) {
  echo "Cookies are enabled.";
} else {
  echo "Cookies are disabled.";
}
?>

</body>
</html>
