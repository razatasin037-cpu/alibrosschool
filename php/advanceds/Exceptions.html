Handling Errors with Exceptions

Exception ek aisa object hota hai jo unexpected errors ko describe karta hai. Agar koi code execution me problem aati hai, to script fatal error hone ke bajaye Exception throw karti hai jise gracefully handle kiya ja sakta hai.

throw

Jab koi error detect hoti hai to throw statement ka use karke exception trigger ki jati hai.

try...catch

try block risky code execute karta hai aur catch block exception ko catch karta hai.

finally

finally block hamesha execute hota hai, chahe exception aaye ya na aaye.

1. Throwing an Exception

Aap throw new Exception("Error message") ka use karke manual exception generate kar sakte hain: 

<?php
function divide($dividend, $divisor) {
  if($divisor == 0) {
    throw new Exception("Division by zero is not allowed");
  }
  return $dividend / $divisor;
}

// Isse Uncaught Exception Fatal Error aayega agar handle na kiya jaye
// echo divide(5, 0);
?>

2. The Try...Catch Statement

Script ko crash hone se bachane ke liye code ko try...catch block me wrap karein: 

<?php
function divide($dividend, $divisor) {
  if($divisor == 0) {
    throw new Exception("Division by zero");
  }
  return $dividend / $divisor;
}

try {
  echo divide(5, 0);
} catch(Exception $e) {
  echo "Unable to divide. Message: " . $e->getMessage();
}
?>

3. The Try...Catch...Finally Statement

finally block cleanup tasks (jaise database connections close karna ya log files save karna) ke liye perfect hota hai: 

<?php
function divide($dividend, $divisor) {
  if($divisor == 0) {
    throw new Exception("Division by zero");
  }
  return $dividend / $divisor;
}

try {
  echo divide(5, 0);
} catch(Exception $e) {
  echo "Unable to divide. ";
} finally {
  echo " Process complete.";
}
?>

4. Exception Object Useful Methods

Catch ki gayi Exception object ($e) ke paas debugging ke liye kai useful built-in methods hote hain:

$e->getMessage()

Exception create karte waqt diya gaya error message laata hai.

$e->getCode()

Exception ka error code return karta hai.

$e->getFile()

Uss file ka full path jahan exception throw hui.

$e->getLine()

Line number batata hai jahan exception occur hui.
