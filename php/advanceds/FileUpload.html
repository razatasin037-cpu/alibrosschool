Uploading Files to Server

PHP ke saath aap server par files (Images, Documents, PDFs) upload kar sakte hain. Iske liye HTML form me enctype="multipart/form-data" aur PHP me $_FILES superglobal variable ka use hota hai.

Security Warning

File upload features me validation bohot zaroori hai! Hamesha file extensions, MIME types, aur size limits check karein taaki malicious script (.php, .exe) upload na ho sake.

1. HTML Form Requirements

File upload karne ke liye HTML Form me in teen cheezon ka hona zaroori hai:

  • Form ka method hamesha "POST" hona chahiye.
  • Form attribute me enctype="multipart/form-data" zaroor set karein.
  • Input field ka type type="file" hona chahiye.
<!-- upload.html -->
<form action="upload.php" method="post" enctype="multipart/form-data">
  Select image to upload:
  <input type="file" name="fileToUpload" id="fileToUpload">
  <input type="submit" value="Upload Image" name="submit">
</form>

2. Complete PHP Upload Script (upload.php)

Ye script file ko check karti hai, validation apply karti hai aur safe hone par move_uploaded_file() ka use karke file ko target directory me save karti hai: 

<?php
// Directory jahan files save hongi
$target_dir = "uploads/";
$target_file = $target_dir . basename($_FILES["fileToUpload"]["name"]);
$uploadOk = 1;
$imageFileType = strtolower(pathinfo($target_file, PATHINFO_EXTENSION));

// 1. Check if file already exists
if (file_exists($target_file)) {
    echo "Sorry, file already exists.<br>";
    $uploadOk = 0;
}

// 2. Check file size (Limit to 2MB)
if ($_FILES["fileToUpload"]["size"] > 2000000) {
    echo "Sorry, your file is too large.<br>";
    $uploadOk = 0;
}

// 3. Allow only specific file formats
if($imageFileType != "jpg" && $imageFileType != "png" && $imageFileType != "jpeg") {
    echo "Sorry, only JPG, JPEG, & PNG files are allowed.<br>";
    $uploadOk = 0;
}

// 4. Process Upload if all checks pass
if ($uploadOk == 0) {
    echo "Sorry, your file was not uploaded.";
} else {
    // Move file from temporary location to server directory
    if (move_uploaded_file($_FILES["fileToUpload"]["tmp_name"], $target_file)) {
        echo "The file ". htmlspecialchars(basename($_FILES["fileToUpload"]["name"])). " has been uploaded.";
    } else {
        echo "Sorry, there was an error uploading your file.";
    }
}
?>

3. Understanding the $_FILES Superglobal

Jab aap file upload karte hain, to PHP $_FILES array me file ki complete details store karta hai:

$_FILES['file']['name']

Uploaded file ka original name.

$_FILES['file']['type']

File ka MIME type (e.g. image/png).

$_FILES['file']['tmp_name']

Server par temporary location jahan file temporary store hoti hai.

$_FILES['file']['size']

Bytes me file ka exact size.
