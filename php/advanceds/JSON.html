JSON Kya Hai?

JSON ka matlab JavaScript Object Notation hota hai. Ye data ko store aur exchange (lene-dene) karne ka ek lightweight, text-based tareeka hai.

Kyunki JSON purely text format me hota hai, isse kisi bhi server par bhejna aur wahan se receive karna bahut aasan hota hai. PHP me JSON data ke sath kaam karne ke liye pehle se bane hue (built-in) functions milte hain.

json_encode()

PHP Array ya Value ko JSON text format me convert karne ke liye is function ka use kiya jata hai.

json_decode()

JSON text string ko read karke PHP Object ya Associative Array me badalne ke liye use hota hai.

1. PHP Array Ko JSON Me Convert Karna (json_encode)

json_encode() function ka use kisi bhi PHP value ya array ko JSON format me badalne ke liye hota hai:

Example 1: Associative Array ko JSON Object banana

<?php
// Associative Array (Key-Value pairs)
$age = array("Peter"=>35, "Ben"=>37, "Joe"=>43);

echo json_encode($age);
// Output: {"Peter":35,"Ben":37,"Joe":43}
?>

Example 2: Indexed Array ko JSON Array banana

<?php
// Simple Indexed Array
$cars = array("Volvo", "BMW", "Toyota");

echo json_encode($cars);
// Output: ["Volvo","BMW","Toyota"]
?>

2. JSON Data Ko PHP Me Convert Karna (json_decode)

json_decode() function JSON string ko parse karke PHP Object ya Associative Array me convert karta hai. By default ye PHP Object return karta hai, lekin agar aap second parameter me true likhenge to ye Associative Array dega:

Example 1: PHP Object me decode karna

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

// By default Object banega
var_dump(json_decode($jsonobj));
?>

Example 2: Associative Array me decode karna (true parameter ke sath)

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

// true likhne se Associative Array banega
var_dump(json_decode($jsonobj, true));
?>

3. Decoded Values Ko Access Karna

Jab aap JSON data decode karte hain, toh object aur array dono se values read karne ka tareeka alag hota hai:

PHP Object se values nikalna (-> arrow syntax)

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

$obj = json_decode($jsonobj);

// Arrow operator (->) ka use karein
echo $obj->Peter;
echo $obj->Ben;
echo $obj->Joe;
?>

PHP Associative Array se values nikalna (['key'] bracket syntax)

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

// Second parameter true hai matlab array milega
$arr = json_decode($jsonobj, true);

// Square brackets ['key'] ka use karein
echo $arr["Peter"];
echo $arr["Ben"];
echo $arr["Joe"];
?>

4. Values Par Loop Chalana (foreach Loop)

Aap foreach loop ka use karke decoded object ya array ke saare key-value pairs par bari-bari iterate kar sakte hain:

PHP Object par Loop chalana

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

$obj = json_decode($jsonobj);

foreach($obj as $key => $value) {
  echo $key . " => " . $value . "<br>";
}
?>

PHP Associative Array par Loop chalana

<?php
$jsonobj = '{"Peter":35,"Ben":37,"Joe":43}';

$arr = json_decode($jsonobj, true);

foreach($arr as $key => $value) {
  echo $key . " => " . $value . "<br>";
}
?>
