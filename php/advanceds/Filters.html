Validating & Sanitizing User Input

PHP Filters ka use user ke dwara bheje gaye data ko check (Validate) aur clean (Sanitize) karne ke liye hota hai. Ye features Web Application ki security ke liye zaroori hain.

Sanitization

Data se unwanted characters (jaise HTML tags, spaces, illegal symbols) ko permanently hata kar data ko clean karta hai.

Validation

Ye check karta hai ki input sahi format me hai ya nahi (e.g. valid Email, URL ya Integer). Ye output True/False deta hai.

1. Sanitize & Validate an Email

Pehle FILTER_SANITIZE_EMAIL se invalid characters hatate hain, phir FILTER_VALIDATE_EMAIL se email ka format test karte hain: 

<?php
$email = "john.doe(parenthesis)@example.com";

// Remove all illegal characters from email
$email = filter_var($email, FILTER_SANITIZE_EMAIL);

// Validate email
if (!filter_var($email, FILTER_VALIDATE_EMAIL) === false) {
    echo "$email is a valid email address";
} else {
    echo "$email is not a valid email address";
}
?>

2. Validate URL (Web Address)

FILTER_VALIDATE_URL ka use karke verify karein ki URL correct structure me hai: 

<?php
$url = "https://www.google.com";

// Remove all illegal characters from a url
$url = filter_var($url, FILTER_SANITIZE_URL);

// Validate URL
if (!filter_var($url, FILTER_VALIDATE_URL) === false) {
    echo "$url is a valid URL";
} else {
    echo "$url is not a valid URL";
}
?>

3. Validate Integer Within a Range

Options array ke saath min_range aur max_range set karke number ki limit check kar sakte hain: 

<?php
$int = 122;
$min = 1;
$max = 200;

// Check if integer is in range
if (filter_var($int, FILTER_VALIDATE_INT, array("options" => array("min_range"=>$min, "max_range"=>$max))) === false) {
    echo "Variable value is not within the allowed range";
} else {
    echo "Variable value is within the allowed range";
}
?>
