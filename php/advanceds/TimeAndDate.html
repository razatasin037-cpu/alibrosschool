PHP Date and Time Functions

PHP me dates aur times ko handle karne ke liye bohot se built-in functions hote hain. Niche main functions ki detail di gayi hai.

Core Date & Time Functions

  • date() - Formats a local date and/or time.
  • time() - Returns the current time as a Unix timestamp.
  • mktime() - Returns the Unix timestamp for a specific date.
  • strtotime() - Converts an English textual datetime string into a Unix timestamp.
  • date_default_timezone_set() - Sets the default timezone to be used.
  • date_default_timezone_get() - Gets the current default timezone.

1. The date() and time() Functions

time() current timestamp (seconds since Jan 1 1970) return karta hai, jabki date() us timestamp ko readable format me badalta hai. 

<?php
  // Formatting dates
  echo "Today is " . date("Y/m/d") . "<br>";
  echo "Day: " . date("l") . "<br>";

  // Current Unix timestamp
  echo "Current Timestamp: " . time();
?>

2. Managing Timezones

Aap date_default_timezone_get() se current timezone check kar sakte hain aur date_default_timezone_set() se nayi timezone set kar sakte hain. 

<?php
  // Get default timezone
  echo "Default Timezone: " . date_default_timezone_get() . "<br>";

  // Set timezone to Asia/Kolkata
  date_default_timezone_set("Asia/Kolkata");
  echo "Indian Time: " . date("h:i:s a");
?>

3. Create Date with mktime()

mktime(hour, minute, second, month, day, year) function specific date aur time ka Unix timestamp generate karta hai. 

<?php
  // mktime(hour, minute, second, month, day, year)
  $d = mktime(11, 14, 54, 8, 12, 2024);
  echo "Created date is " . date("Y-m-d h:i:sa", $d);
?>

4. Create Date from String with strtotime()

strtotime() human-readable English text (jaise "tomorrow", "next Sunday") ko timestamp me convert kar deta hai. 

<?php
  // Convert string to timestamp
  $d1 = strtotime("10:30pm April 15 2024");
  echo "Created date: " . date("Y-m-d h:i:sa", $d1) . "<br>";

  $d2 = strtotime("tomorrow");
  echo "Tomorrow: " . date("Y-m-d", $d2) . "<br>";

  $d3 = strtotime("+3 months");
  echo "3 Months Later: " . date("Y-m-d", $d3);
?>
