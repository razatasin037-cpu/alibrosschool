Managing Server-Side User State

Session ka use user information (jaise login state, user ID) ko multiple pages par store aur access karne ke liye hota hai. Cookies ke opposite, session data client computer ke bajaye server par secure tarike se store hota hai.

Important Rule

session_start() function hamesha aapke script ke sabse pehle tag <?php ke turant baad call hona chahiye, kisi bhi HTML print hone se pehle.

1. Start a PHP Session & Set Variables

Session start karne ke baad aap $_SESSION superglobal array me variables set kar sakte hain: 

<?php
// Always start the session first
session_start();
?>
<!DOCTYPE html>
<html>
<body>

<?php
// Set session variables
$_SESSION["favcolor"] = "green";
$_SESSION["favanimal"] = "cat";
echo "Session variables are set.";
?>

</body>
</html>

2. Get / Read PHP Session Variable Values

Kisi dusre page par (same domain me) session values ko read karne ke liye fir se session_start() call karna hoga: 

<?php
session_start();
?>
<!DOCTYPE html>
<html>
<body>

<?php
// Accessing variables set on another page
echo "Favorite color is " . $_SESSION["favcolor"] . ".<br>";
echo "Favorite animal is " . $_SESSION["favanimal"] . ".";
?>

</body>
</html>

3. Modify and Destroy a PHP Session

Session variables ki value change karne ke liye bas key ko overwrite kar dein. Complete session remove (logout) karne ke liye session_unset() aur session_destroy() ka use hota hai: 

<?php
session_start();
?>
<!DOCTYPE html>
<html>
<body>

<?php
// Remove all session variables
session_unset();

// Destroy the session completely
session_destroy();

echo "All session variables are removed, and the session is destroyed.";
?>

</body>
</html>
