Reusing Code with Include & Require

include aur require statements ka use ek PHP file ke content ko dusri PHP file me inject ya embed karne ke liye hota hai. Isse code reusable aur maintainable banta hai.

1. PHP include vs require Difference

Dono statements ka kaam same hai, lekin error handling alag hoti hai:

  • include: Agar file nahi milti to ek E_WARNING generate hoti hai aur script rest code ko execute karti rehti hai.
  • require: Agar file nahi milti to E_COMPILE_ERROR (Fatal Error) generate hoti hai aur script execution wahi ruk jati hai.
<?php
  // Layout components embed karna
  include 'footer.php';

  // Critical files (Jaise Database Connection) ke liye require use karein
  require 'db_config.php'; 
?>

2. PHP Include Example (Reusing Footer & Menu)

Maan lijiye aapke paas ek standard footer file footer.php hai: 

<!-- footer.php -->
<?php
  echo "<p>Copyright &copy; 2010-" . date("Y") . " AlibrosSchool.com</p>";
?>

Ab aap is footer file ko apne sabhi web pages me include kar sakte hain: 

<html>
<body>

<h1>Welcome to my home page!</h1>
<p>Some text.</p>

<?php include 'footer.php'; ?>

</body>
</html>

3. Including Variables from External File

Aap dusri file me defined variables ko bhi apne current script me import kar ke access kar sakte hain. 

// vars.php
<?php
  $color = 'red';
  $car = 'BMW';
?>
// index.php
<?php
  include 'vars.php';
  echo "I have a " . $color . " " . $car; // Outputs: I have a red BMW
?>

4. include_once and require_once

Agar aap galti se ek hi file ko multiple times include kar dete hain, to function redeclaration ya variable overwrite errors ho sakte hain. Isse bachne ke liye include_once ya require_once use hota hai. 

<?php
  // File only once include hogi, chahe kitni baar bhi call karein
  include_once 'functions.php';
  require_once 'config.php';
?>
