Advanced File Operations in PHP

fopen() function readfile() se zyada control aur flexibility deta hai. Isse aap file ko alag-alag modes me open, read, write aur close kar sakte hain.

1. PHP fopen() Modes Reference

File open karte waqt doosra parameter mode specify karta hai ki file ke sath kya operation karna hai:

Mode Description
r Read only. File pointer beginning se start hota hai.
w Write only. File contents ko erase (truncate) kar deta hai ya nayi file banata hai.
a Append (Write only). Existing content ke end me data add karta hai.
x Create & Write only. Nayi file banata hai; agar file pehle se exist karti hai to false return karta hai.
r+ / w+ / a+ Read aur Write dono permissions allow karta hai.

2. Open, Read, and Close a File

fread() function open ki hui file se content read karta hai. File read karne ke baad fclose() se file stream close karna zaruri hota hai. 

<?php
  // Open file in read mode or throw custom message
  $myfile = fopen("webdictionary.txt", "r") or die("Unable to open file!");

  // Read entire file contents
  echo fread($myfile, filesize("webdictionary.txt"));

  // Always close the file handle
  fclose($myfile);
?>

3. Read Single Line - fgets() with feof()

fgets() file se ek single line read karta hai. While loop aur feof() (End-of-File check) ka use karke puri file line-by-line read kar sakte hain: 

<?php
  $myfile = fopen("webdictionary.txt", "r") or die("Unable to open file!");

  // Output one line until end-of-file is reached
  while(!feof($myfile)) {
    echo fgets($myfile) . "<br>";
  }

  fclose($myfile);
?>

4. Read Single Character - fgetc()

fgetc() function file me se ek-ek character karke read karta hai. 

<?php
  $myfile = fopen("webdictionary.txt", "r") or die("Unable to open file!");

  // Output character by character until end-of-file
  while(!feof($myfile)) {
    echo fgetc($myfile);
  }

  fclose($myfile);
?>
