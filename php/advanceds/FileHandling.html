Managing Files in PHP

File handling kisi bhi web application ka zaroori hissa hai. PHP ke paas files ko create, read, upload, write aur delete karne ke liye kaafi saare built-in functions majood hain.

Important Warning

Files ko edit ya delete karte waqt savdhani bartein! Galat file modify karna, accidental deletion, ya server ki storage bhar jaana jaisi galtiya ho sakti hain.

1. Core File Handling Functions

PHP me files par alag-alag operations perform karne ke liye ye mukhya functions use hote hain:

readfile()

File ko read karta hai aur directly output buffer me write kar deta hai.

fopen()

File ko open karta hai (readfile se zyada advanced options deta hai).

fread()

Open ki hui file se content ko read karta hai.

fgets() / fgetc()

Single line (fgets) ya single character (fgetc) read karta hai.

feof()

Check karta hai ki file ke End-Of-File (EOF) tak pahunch gaye hain ya nahi.

fwrite() & fclose()

File me write/append karta hai aur file handle ko close karta hai.

unlink()

Server se kisi file ko permanently delete kar deta hai.

2. The PHP readfile() Function

Agar aapko bas kisi text file ko open karke uske content ko browser par output karna ho, toh readfile() sabse best aur quick function hai.

Maan lijiye server par webdictionary.txt name ki file hai:

AJAX = Asynchronous JavaScript and XML
CSS = Cascading Style Sheets
HTML = Hyper Text Markup Language
PHP = PHP Hypertext Preprocessor
SQL = Structured Query Language
SVG = Scalable Vector Graphics
XML = EXtensible Markup Language

Is file ko read aur output karne ke liye PHP Code:

<?php
  // Reads file, prints content, and returns total character count
  echo readfile("webdictionary.txt");
?>

Note: readfile() function content render karne ke saath-saath success hone par total read kiye gaye bytes (character count) bhi return karta hai.
