PHP Math Functions Kya Hain?

PHP me numbers par mathematical tasks perform karne ke liye built-in math functions ki ek wide range milti hai, jaise pi value nikalna, min/max dhoondna, square root ya rounding off karna.

In functions ka upyog karke aap complex mathematical calculations easily kar sakte hain.

1. pi(), min() aur max() Functions

pi() function PI ki value return karta hai. Jabki min() aur max() values ki list me se sabse choti aur sabse badi value find karne ke liye use hote hain: 

<?php
  // PI value
  echo pi(); // Output: 3.1415926535898

  // Min & Max Value
  echo min(0, 150, 30, -20, -200); // Output: -200
  echo max(0, 150, 30, -20, -200); // Output: 150
?>

2. abs() aur sqrt() Functions

abs() function kisi bhi negative number ki positive (absolute) value return karta hai, jabki sqrt() square root calculate karta hai: 

<?php
  // Absolute Value
  echo abs(-6.7); // Output: 6.7

  // Square Root
  echo sqrt(64); // Output: 8
?>

3. round() aur rand() Functions

round() floating point number ko nearest integer me round off kar deta hai. Aur rand() random number generate karne ke liye use hota hai: 

<?php
  // Rounding off
  echo round(0.60); // Output: 1
  echo round(0.49); // Output: 0

  // Random Numbers (between 10 and 100)
  echo rand(10, 100); // Generates random number between 10 and 100
?>

Popular PHP Math Functions Reference

Function Example Description
pi() pi() PI Value (3.14159...) return karta hai.
min(), max() min(2, 4, 8) Minimum ya Maximum value return karta hai.
abs() abs(-5) Positive (Absolute) value return karta hai.
sqrt() sqrt(16) Number ka Square Root return karta hai.
round() round(4.6) Number ko nearest integer tak round karta hai.
rand() rand(1, 100) Optional Range ke andar Random number generate karta hai.

💡 Pro-Tip: ceil() vs floor()

Agar aapko decimal value ko specific direction me round off karna ho:

  • ceil(0.60) : Hamesha nearest UPPER integer par round karta hai (Output: 1).
  • floor(0.60) : Hamesha nearest LOWER integer par round karta hai (Output: 0).
