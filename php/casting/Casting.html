Type Casting Kya Hota Hai?

Jab aap kisi variable ka data type forcefully ek type se doosre type me badalte hain (jaise String ko Integer me ya Float ko Integer me convert karna), toh us process ko **Type Casting** kehte hain.

PHP me casting karne ke liye variable ke aage parenthesis ( ) ke andar target data type ka naam likha jata hai.

1. Cast to Integer (int)

Float numbers ya numeric strings ko integer me badalne ke liye (int) ya (integer) ka use hota hai. Float se int me convert hone par decimal ke baad ki values discard ho jaati hain. 

<?php
  // Cast Float to Integer
  $a = 23465.768;
  $int_a = (int)$a; // Result: 23465

  // Cast String to Integer
  $b = "25 kilometers";
  $int_b = (int)$b; // Result: 25

  var_dump($int_a);
  var_dump($int_b);
?>

2. Cast to String (string)

Kisi integer, float ya boolean value ko string text format me convert karne ke liye (string) ka upyog hota hai: 

<?php
  $x = 500;
  $str_x = (string)$x;

  var_dump($str_x); // Output: string(3) "500"
?>

3. Cast to Boolean (bool)

0, empty string "", aur null boolean conversion par false bante hain. Baki saari non-zero values true me convert hoti hain. 

<?php
  $a = 0;
  $b = "Hello";

  var_dump((bool)$a); // Output: bool(false)
  var_dump((bool)$b); // Output: bool(true)
?>

PHP Casting Operators Reference

Cast Operator Target Type Description
(int), (integer) Integer Value ko Integer me cast karta hai.
(float), (double) Float Value ko Floating-point number me convert karta hai.
(string) String Value ko String text format me badalta hai.
(bool), (boolean) Boolean Value ko true ya false (Boolean) me convert karta hai.
(array) Array Variable ko Indexed Array me convert karta hai.
(object) Object Variable ko stdClass Object me badalta hai.

💡 Important Tip: Array & Object Casting

Jab aap kisi simple variable ko (array) cast karte hain, toh PHP us value ko array ke index 0 par place kar deta hai:

$a = "PHP";
$arr = (array)$a; // Result: array(0 => "PHP")
