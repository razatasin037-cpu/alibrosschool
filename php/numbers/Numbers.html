PHP Me Numbers Kya Hain?

PHP automatic data type conversion handle karta hai. Jab aap kisi variable me number assign karte hain, toh PHP uske value ke basis par type automatically check kar leta hai.

Mainly PHP me 3 major numeric data types hote hain: **Integers**, **Floats** (Floating Point Numbers), aur **Numeric Strings**.

1. PHP Integers

Integer ek aisa number hota hai jisme koi decimal point nahi hota (e.g. 25, -50, 4000). Yeh positive ya negative dono ho sakte hain. Isko check karne ke liye is_int() function ka use hota hai. 

<?php
  $x = 5985;
  var_dump(is_int($x)); // Output: bool(true)

  $y = 59.85;
  var_dump(is_int($y)); // Output: bool(false)
?>

2. PHP Floats

Float (Double) ek aisa number hota hai jisme decimal point ya exponential form hota hai (e.g. 10.5, 2.4e3). Float validation ke liye is_float() ka upyog karte hain: 

<?php
  $x = 10.365;
  var_dump(is_float($x)); // Output: bool(true)
?>

3. PHP Infinity & NaN

Aap is_finite() aur is_infinite() se check kar sakte hain ki number finite range ke andar hai ya nahi. Aise hi invalid mathematical operations ke liye NaN (Not a Number) return hota hai: 

<?php
  // Infinite Check
  $x = 1.9e411;
  var_dump($x); // Output: float(INF)

  // NaN (Not a Number)
  $y = acos(8);
  var_dump($y); // Output: float(NAN)
?>

PHP Number Checking Functions

Function Type Description
is_int() Integer Check karta hai ki value Integer hai ya nahi.
is_float() Float Check karta hai ki value Float/Decimal hai ya nahi.
is_numeric() Numeric Check karta hai ki string/value numeric hai ya nahi.
(int) / (float) Casting String ya Float ko Integer me convert karne ke liye.

💡 Important Pro-Tip: Casting Strings to Numbers

Aap (int) ya (float) cast operator ka upyog karke kisi bhi numeric string ko integer ya float me convert kar sakte hain:

$x = "23465.768";
$int_cast = (int)$x; // Value becomes 23465
