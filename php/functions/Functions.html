PHP Function Kya Hota Hai?

Function statements/code ka ek aisa block hota hai jisko aap ek naam dete hain aur us code ko poore program me kahin bhi reuse (baar-baar upayog) kar sakte hain.

Function tab tak execute nahi hota jab tak aap use call (invoke) nahi karte.

1. Basic Function Declaration & Calling

PHP me function banane ke liye function keyword ka upayog hota hai: 

<?php
  // Function Define kar rahe hain
  function greetUser() {
      echo "Welcome to PHP Tutorial! <br>";
  }

  // Function Call kar rahe hain
  greetUser();
  greetUser(); // Kitni bhi baar call kar sakte hain
?>

2. Function Arguments (Parameters)

Aap functions me dynamic data pass karne ke liye arguments de sakte hain. Aap Default argument values bhi set kar sakte hain: 

<?php
  // $name parameters hai, $role ki default value 'User' hai
  function userGreeting($name, $role = "User") {
      echo "Hello $name, your role is: $role <br>";
  }

  userGreeting("Amit", "Admin"); // Output: Hello Amit, your role is: Admin
  userGreeting("Priya");          // Output: Hello Priya, your role is: User
?>

3. Returning Values

echo ke bajaye function se kisi value ko wapas bhejne ke liye return keyword ka upayog karein: 

<?php
  function addNumbers($a, $b) {
      return $a + $b;
  }

  $result = addNumbers(10, 20);
  echo "Total: $result"; // Output: Total: 30
?>

4. Type Declaration & Strict Mode (PHP 7+)

PHP me aap parameters aur return value ka Data Type (e.g., int, string, bool) specify kar sakte hain: 

<?php
  // Strict Mode ON karte hain (file ke sabse upar hona chahiye)
  declare(strict_types=1);

  function multiply(int $a, int $b): int {
      return $a * $b;
  }

  echo multiply(5, 4); // Returns 20
?>

5. Pass by Reference (&)

Jab aap argument me & lagate hain, to function variable ki copy ke bajaye original variable ka value change kar deta hai: 

<?php
  function addFive(&$num) {
      $num += 5;
  }

  $value = 10;
  addFive($value);
  echo "Updated Value: " . $value; // Output: Updated Value: 15
?>

6. Variadic Functions (...Spread Operator)

Jab aapko fix nahi ho ki function me kitne arguments aayenge, tab ... ka upayog karke unlimited arguments accept kar sakte hain: 

<?php
  function sumAll(...$numbers) {
      $sum = 0;
      foreach ($numbers as $n) {
          $sum += $n;
      }
      return $sum;
  }

  echo sumAll(1, 2, 3, 4, 5); // Output: 15
?>

7. Anonymous & Arrow Functions (PHP 7.4+)

Bina kisi naam wale functions ko Anonymous Functions (Closures) kehte hain. PHP 7.4+ me short syntax ke liye Arrow Functions ka upayog hota hai: 

<?php
  // Anonymous Function
  $sayHello = function($name) {
      return "Hello " . $name;
  };
  echo $sayHello("Rahul") . "<br>";

  // Arrow Function (Short Syntax)
  $square = fn($n) => $n * $n;
  echo "Square of 4: " . $square(4); // Output: 16
?>

💡 Pro Tip: Function Naming Rules

  • Function ka naam letter ya underscore (_) se shuru hona chahiye, number se nahi.
  • PHP functions case-insensitive hote hain (e.g., myFunc() aur MYFUNC() same hain), lekin best practice hai ki aap hamesha camelCase ya snake_case standard maintain karein.
