Form Validation Kyun Zaroori Hai?

Form validation ka maqsad ye confirm karna hota hai ki user ne correct aur safe data enter kiya hai pehle isse ki wo database me save ho ya process kiya jaaye.

Proper validation aapki application ko Cross-Site Scripting (XSS) attacks aur malicious script injections se protect karti hai.

Essential Input Sanitization Functions

Function Purpose / Kaam
trim($data) Input ke start aur end se extra whitespaces, tabs, aur newlines remove karta hai.
stripslashes($data) Input string se backslashes (\) remove karta hai.
htmlspecialchars($data) Special HTML characters (jaise <, >) ko HTML entities me convert karke XSS block karta hai.

1. Custom Sanitization Helper Function

Ek reusable custom function banakar har input field ko clean aur sanitize karna best practice maana jata hai: 

<?php
  // Helper function to sanitize user inputs
  function test_input($data) {
      $data = trim($data);
      $data = stripslashes($data);
      $data = htmlspecialchars($data);
      return $data;
  }

  // Example variables
  $name = $email = $website = $comment = "";

  if ($_SERVER["REQUEST_METHOD"] == "POST") {
      $name    = test_input($_POST["name"] ?? "");
      $email   = test_input($_POST["email"] ?? "");
      $website = test_input($_POST["website"] ?? "");
      $comment = test_input($_POST["comment"] ?? "");
  }
?>

2. Complete HTML Form Setup

Form setup me secure action attribute (`htmlspecialchars($_SERVER["PHP_SELF"])`) ke sath sanitization integrate karna: 

<!-- Form submitting to self securely -->
<form method="post" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
  <label>Name:</label>
  <input type="text" name="name">
  
  <label>E-mail:</label>
  <input type="text" name="email">

  <button type="submit">Submit</button>
</form>

💡 Pro Tip: Server-Side vs Client-Side Validation

HTML5 attributes (jaise required ya type="email") browser-level user experience ko fast banate hain, lekin inhe browser developer tools se easily bypass kiya ja sakta hai. Isliye Server-Side PHP Validation hamesha compulsory hoti hai.
