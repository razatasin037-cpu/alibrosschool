Form Handling Kya Hota Hai?

PHP me Form Handling ka matlab HTML forms se user ka input (Jaise Name, Email, Password) capture karna aur use server-side process karna hai.

PHP do superglobals $_GET aur $_POST ka istemal karke form submit hone par data collect karti hai.

GET vs POST Method

Feature GET Method POST Method
Data Visibility URL me visible rehta hai HTTP body me hidden rehta hai
Security Less secure (Sensitive data ke liye nahi hai) More secure (Passwords/Cards ke liye best)
Data Limit Max ~2000 characters No limit (File uploads allowed)
Use Case Search forms, Bookmarks Login, Registration, Contact Forms

1. Basic POST Form Example

Niche ek standard HTML form aur PHP processing script hai jo same page par hi submit hoti hai: 

<!-- HTML Form -->
<form method="POST" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
  <label>Name:</label>
  <input type="text" name="username" required>
  
  <label>Email:</label>
  <input type="email" name="email" required>

  <button type="submit">Submit</button>
</form>

<?php
  // Processing form input on submit
  if ($_SERVER["REQUEST_METHOD"] === "POST") {
      $name = htmlspecialchars($_POST['username'] ?? '');
      $email = htmlspecialchars($_POST['email'] ?? '');

      echo "Welcome, " . $name . "<br>";
      echo "Your Email: " . $email;
  }
?>

🛡️ Security Rule: Always Sanitize Form Input

Users ke dwara submit kiye gaye data par kabhi trust na karein. Malicious users HTML script/JavaScript code inject kar sakte hain (Cross-Site Scripting - XSS).

Hamesha htmlspecialchars() function ka use karein taaki `<` aur `>` jaise characters safely HTML entities (&lt; aur &gt;) me convert ho sakein.
