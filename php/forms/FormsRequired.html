Required Fields Validation Kya Hai?

Form handling me kuch fields mandatory hote hain (jaise Name, Email, Gender). Server-side script se ye check karna zaroori hai ki user ne in fields ko empty na chhoda ho.

PHP me hum empty() function ka use karke required fields check karte hain aur field-specific error messages show karte hain.

Required Field Logic Mechanics

  • Error Variables: Har field ke liye alag error variable declare karein (e.g., $nameErr).
  • Empty Check: empty($_POST["field"]) se validation run karein.
  • Error Display: Form ke sath red color asterisks (*) aur dynamic messages highlight karein.

1. PHP Required Fields Script with Inline Errors

Ye complete code hai jo empty fields detect karta hai aur errors return karta hai: 

<?php
  // Define variables and set to empty values
  $nameErr = $emailErr = $genderErr = "";
  $name = $email = $gender = "";

  if ($_SERVER["REQUEST_METHOD"] == "POST") {
      // Validate Name
      if (empty($_POST["name"])) {
          $nameErr = "Name is required";
      } else {
          $name = test_input($_POST["name"]);
      }
      
      // Validate Email
      if (empty($_POST["email"])) {
          $emailErr = "Email is required";
      } else {
          $email = test_input($_POST["email"]);
      }

      // Validate Gender
      if (empty($_POST["gender"])) {
          $genderErr = "Gender selection is required";
      } else {
          $gender = test_input($_POST["gender"]);
      }
  }

  function test_input($data) {
      $data = trim($data);
      $data = stripslashes($data);
      $data = htmlspecialchars($data);
      return $data;
  }
?>

2. HTML Form UI Rendering Error Spans

Errors ko user interface par render karne ke liye `*` pattern: 

<form method="post" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
  <!-- Name Field -->
  Name: <input type="text" name="name" value="<?php echo $name; ?>">
  <span class="text-red-500">* <?php echo $nameErr; ?></span>
  <br><br>

  <!-- Email Field -->
  E-mail: <input type="text" name="email" value="<?php echo $email; ?>">
  <span class="text-red-500">* <?php echo $emailErr; ?></span>
  <br><br>

  <button type="submit">Submit</button>
</form>

📌 Pro Tip: Retaining User Values

User experience enhance karne ke liye validation error subtle dikhayein aur value="<?php echo $name; ?>" ka use karke user ka entered valid data dobara form fields me fill rehne dein (form re-population).
