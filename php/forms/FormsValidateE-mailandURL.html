Name, E-mail Aur URL Code Validation

Sirf empty check karna kafi nahi hota! PHP me hume Name, Email, aur Website URL ke format ko specific rules (syntax validation) ke mutabiq verify karna zaroori hai.

Iske liye PHP me preg_match() (Regex) aur built-in filter_var() functions ka istemal hota hai.

Built-in Validation Tools

Input Type Validation Function Rule / Description
Name preg_match("/^[a-zA-Z-' ]*$/", $name) Only letters, spaces, and hyphens allowed.
Email filter_var($email, FILTER_VALIDATE_EMAIL) Validates e-mail format (name@domain.com).
URL filter_var($url, FILTER_VALIDATE_URL) Validates absolute URL structure (http/https).

1. PHP Validation Logic Script

Complete script jo Name, Email, aur URL syntaxes ko strictly inspect karti hai: 

<?php
  $nameErr = $emailErr = $websiteErr = "";
  $name = $email = $website = "";

  if ($_SERVER["REQUEST_METHOD"] == "POST") {
      
      // 1. Validate Name Syntax
      if (empty($_POST["name"])) {
          $nameErr = "Name is required";
      } else {
          $name = test_input($_POST["name"]);
          if (!preg_match("/^[a-zA-Z-' ]*$/", $name)) {
              $nameErr = "Only letters and white space allowed";
          }
      }

      // 2. Validate E-mail Syntax
      if (empty($_POST["email"])) {
          $emailErr = "Email is required";
      } else {
          $email = test_input($_POST["email"]);
          if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
              $emailErr = "Invalid email format";
          }
      }

      // 3. Validate Website URL Syntax
      if (!empty($_POST["website"])) {
          $website = test_input($_POST["website"]);
          if (!filter_var($website, FILTER_VALIDATE_URL)) {
              $websiteErr = "Invalid URL format";
          }
      }
  }

  function test_input($data) {
      $data = trim($data);
      $data = stripslashes($data);
      $data = htmlspecialchars($data);
      return $data;
  }
?>

🚀 Key Takeaway: filter_var vs Regex

E-mail aur URL validation ke liye custom Regex likhne ke bajaye hamesha PHP ke internal filter_var() filters use karein, kyunki ye industry standards (RFC compliance) ko strictly follow karte hain.
