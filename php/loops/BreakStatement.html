Break Statement Kya Hota Hai?

break statement ka upayog kisi bhi loop (for, while, do-while, foreach) ya switch block ko turant terminate (band) karne ke liye kiya jata hai.

Jaise hi PHP script break statement tak pahunchti hai, loop wahi ruk jata hai aur execution loop ke thik baad wale code par chala jata hai.

1. Basic Loop Exit (For / While Loop)

Aap kisi specific condition par loop ko aage chalne se rokne ke liye break ka upayog kar sakte hain: 

<?php
  for ($i = 1; $i <= 10; $i++) {
      if ($i == 5) {
          break; // $i ki value 5 hote hi loop terminate ho jayega
      }
      echo "Number: $i <br>";
  }
  // Output: 1 2 3 4
?>

2. Practical Example: Array Search Optimization

Jab aapko array me required element mil jata hai, toh aage search karne ka koi fayda nahi hota. break statement se performance improve hoti hai: 

<?php
  $users = ["Amit", "Rahul", "Priya", "Vikas", "Neha"];
  $search = "Priya";

  foreach ($users as $user) {
      if ($user == $search) {
          echo "User '$search' mil gaya! <br>";
          break; // Target milne ke baad baki users check nahi honge
      }
      echo "Checking: $user <br>";
  }
?>

3. Breaking Out of Nested Loops (break $num)

PHP me aap break ke aage ek number pass karke multiple nested loops se ek sath bahar nikal sakte hain (e.g., break 2;): 

<?php
  // Outer Loop (Level 2)
  for ($i = 1; $i <= 3; $i++) {
      // Inner Loop (Level 1)
      for ($j = 1; $j <= 3; $j++) {
          if ($i == 2 && $j == 2) {
              break 2; // Inner aur Outer dono loops se bahar nikal jayega
          }
          echo "i=$i, j=$j <br>";
      }
  }
?>

⚠️ Important Note: Switch Statements

Remember, switch block bhi PHP me looping structure ki tarah dekha jata hai. Isliye agar aap switch statement ke andar loop chalakar break 1; likhte hain, toh woh sirf switch ko break karega, loop ko nahi!
