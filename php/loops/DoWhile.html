Do...While Loop Kya Hota Hai?

do...while loop ek Exit-Controlled Loop hai. Iska matlab hai ki condition sabse aakhri me check hoti hai, na ki shuruat me.

Kyunki condition aakhri me check hoti hai, isliye yeh loop kam se kam ek baar zarur execute hota hai, chahe condition shuruat me hi FALSE kyun na ho.

1. Basic Syntax & Execution

Iska syntax pehle code block execute karta hai (do) aur aakhir me condition check karta hai (while). Dhyan rakhein ki while condition ke aakhir me semicolon ; zaroori hai. 

<?php
  $i = 1; // Initialization

  do {
      echo "Number: $i <br>";
      $i++; // Increment
  } while ($i <= 5); // Condition check (Semicolon mandatory hai)
?>

2. Key Difference: Guaranteed 1st Execution

Yahan dekhein ki $i = 10 hai jo condition $i <= 5 ko pehli hi baar me FALSE bana deta hai. Phir bhi code ek baar execute hoga: 

<?php
  $i = 10; // Value condition se badi hai

  do {
      // Yeh line 1 baar print hogi kyunki condition end me check hoti hai
      echo "Yeh kam se kam ek baar chalega! Value: $i <br>";
      $i++;
  } while ($i <= 5);
?>

3. Differences: while vs do...while

Feature while Loop do...while Loop
Control Type Entry-Controlled (Pehle check) Exit-Controlled (Aakhir me check)
Minimum Iteration 0 (Aapka loop 0 baar bhi chal sakta hai) 1 (Kam se kam 1 baar zarur chalega)
Semicolon Syntax Condition ke baad `;` nahi lagta Condition ke aakhir me `;` compulsory hai

4. Practical Example: Dice Rolling Simulation

Real-world scenario jahan hume dice ko kam se kam 1 baar roll karna hi hota hai jab tak 6 na aa jaye: 

<?php
  $rollCount = 0;

  do {
      // Random number generate karein (1 se 6)
      $dice = rand(1, 6);
      $rollCount++;
      echo "Roll #$rollCount: Rolled a $dice <br>";
  } while ($dice != 6);

  echo "<strong>Success! Total Rolls: $rollCount</strong>";
?>

Syntax Tip & Common Errors

Common mistake: do...while me while($condition); ke aakhir wala semicolon bhool jana syntax error paida karta hai.

do {
  echo "Hello";
} while ($x <= 5) // ❌ Error: Semicolon missing at the end!
