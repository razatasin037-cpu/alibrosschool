Loops Kya Hote Hain?

Programming me jab aapko kisi code block ko baar-baar execute (repeat) karna hota hai jab tak ek specified condition TRUE rahe, tab hum Loops ka use karte hain.

PHP me mukhya roop se 4 prakar ke loops hote hain: while, do-while, for, aur foreach.

PHP Loops Types & Comparison

Loop Name Type Kab Use Karein?
while Entry Control Jab iterations ki sankhya fix na ho aur pehle condition check karni ho.
do...while Exit Control Jab code ko kam se kam EK BAAR zaroor run karna ho, chahe condition false hi kyu na ho.
for Entry Control Jab aapko pehle se pata ho ki loop kitni baar chalega (fixed iterations).
foreach Specialized Jab Arrays ya Objects ke saare elements par loop chalana ho.

1. While Loop

Pehle condition check karta hai, TRUE hone par hi code block run karta hai.

while ($i <= 5) {
  echo $i;
  $i++;
}
Details dekhein ➔

2. Do...While Loop

Pehle code run karta hai, fir aakhir me condition check karta hai.

do {
  echo $i;
  $i++;
} while ($i <= 5);
Details dekhein ➔

3. For Loop

Initialization, condition, aur increment ek hi line me hote hain.

for ($i = 1; $i <= 5; $i++) {
  echo $i;
}
Details dekhein ➔

4. Foreach Loop

Array ke har item ko sequence me iterate karne ke liye sabse best hai.

foreach ($colors as $color) {
  echo $color;
}
Details dekhein ➔

⚠️ Infinite Loops Se Kaise Bachein?

Kisi bhi loop me increment ($i++) ya condition modifier dena kabhi na bhoolein. Agar condition hamesha TRUE reh gayi, toh server hang ho sakta hai aur memory issue aayega.
