Foreach Loop Kya Hota Hai?

foreach loop khaas taur par Arrays aur Objects ke elements par iterate (loop) karne ke liye banaya gaya hai. Isme aapko koi manual counter ($i++) ya condition check nahi karni padti.

Yeh loop array ke har ek element par automatic traversal karta hai aur array khatam hote hi ruk jata hai.

1. Value-Only Iteration (Indexed Arrays)

Jab aapko sirf array ki values se matlab ho, tab foreach ($array as $value) syntax use karein: 

<?php
  $colors = ["Red", "Green", "Blue"];

  foreach ($colors as $color) {
      echo "Color: $color <br>";
  }
?>

2. Key-Value Iteration ($key => $value)

Associative Arrays me Keys aur Values dono ko access karne ke liye foreach ($array as $key => $value) syntax use hota hai: 

<?php
  $student = [
      "name" => "Rahul",
      "role" => "Developer",
      "age" => 22
  ];

  foreach ($student as $key => $val) {
      echo "ucfirst($key)" . ": $val <br>";
  }
?>

3. Array Direct Modification (&$value)

By default, foreach array ki copy ke saath kaam karta hai. Lekin agar aap asli array ke elements ko loop ke andar update karna chahte hain, toh variable ke aage Ampersand (&) lagayein: 

<?php
  $prices = [100, 200, 300];

  // Har price par 10% tax add karein (& reference se original array modify hoga)
  foreach ($prices as &$price) {
      $price = $price * 1.10;
  }
  unset($price); // Reference breaking (Safety Best Practice)

  print_r($prices);
?>

4. Alternative Syntax (foreach: ... endforeach;)

HTML UI components (jaise List Items ya Table Rows) render karte waqt endforeach; syntax sabse clean hota hai: 

<ul class="skills-list">
  <?php $skills = ["PHP", "MySQL", "Tailwind"]; ?>
  
  <?php foreach ($skills as $skill): ?>
      <li> Skill: <?php echo $skill; ?> </li>
  <?php endforeach; ?>
</ul>

🚨 Reference Loop Danger Trap

Jab aap &$value (reference) ke sath foreach chalate hain, toh loop ke baad bhi pointer aakhri element par rehta hai. Agar aap baad me same variable bina unset() kiye use karenge, toh data corrupt ho sakta hai.

foreach ($items as &$value) { /* modification */ }
unset($value); // 👈 Reference hamesha loop ke turant baad destroy karein!
