For Loop Kya Hota Hai?

for loop sabse zyaada istemaal hone wala Counting Loop hai. Jab aapko pehle se pata ho ki koi code block kitni baar execute karna hai, tab hum for loop ka use karte hain.

Yeh loop teen main parts ko ek hi line me combine karta hai: Initialization, Condition, aur Increment/Decrement.

1. Basic Syntax & Basic Example

for(init; condition; increment/decrement) format ka use hota hai. 

<?php
  // 1 se 5 tak print karein
  for ($i = 1; $i <= 5; $i++) {
      echo "Iteration Number: $i <br>";
  }
?>

2. Alternative Syntax (for: ... endfor;)

HTML/PHP templates likhte waqt Curly Braces { } ki jagah Colon : aur endfor; ka use zyaada readable hota hai: 

<?php for ($i = 1; $i <= 3; $i++): ?>
  <div class="card">Card #<?php echo $i; ?></div>
<?php endfor; ?>

3. Nested Loops (Loop inside Loop)

Jab ek loop ke andar dusra loop run hota hai, toh use Nested Loop kehte hain. Yeh 2D grids, tables ya star patterns banane ke liye helpful hota hai: 

<?php
  // Simple Star Pattern Example
  for ($row = 1; $row <= 3; $row++) {
      for ($col = 1; $col <= $row; $col++) {
          echo "* ";
      }
      echo "<br>";
  }
?>

4. Control Statements: break & continue 

<?php
  for ($i = 1; $i <= 10; $i++) {
      if ($i == 3) continue; // 3 ko skip kar dega
      if ($i == 6) break;    // Loop ko yahin stop kar dega

      echo "Value: $i <br>";
  }
?>

Infinite Loop Risk

Agar aap increment step bhool gaye ya condition galat likh di, toh server Infinite Loop me chala ja sakta hai aur memory crash ho sakti hai.

for ($i = 1; $i > 0; $i++) {
  // ❌ Never stops: $i hamesha 0 se bada rahega!
}
