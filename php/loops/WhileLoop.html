While Loop Kya Hota Hai?

while loop ek entry-controlled loop hai jo kisi code block ko tab tak baar-baar execute karta hai jab tak di gayi condition TRUE rehti hai.

Har iteration (chakar) se pehle condition check hoti hai. Agar pehli hi baar me condition FALSE ho jaye, toh loop ek baar bhi nahi chalega.

1. Standard Syntax ({ } Braces)

Yeh sabse zyada use hone wala standard format hai jisme loop body ko { } curly braces ke andar rakha jata hai. 

<?php
  // Example: 1 se 5 tak counter print karna
  $i = 1; // Step 1: Initialization

  while ($i <= 5) { // Step 2: Condition Check
      echo "Number: $i <br>";
      $i++; // Step 3: Increment
  }
?>

2. Alternative Syntax (: ... endwhile;)

PHP me curly braces ki jagah colon (:) aur ending keyword (endwhile;) ka istemal bhi kiya jata hai. Yeh format pure HTML / Template files ke sath mixing karte waqt sabse clean lagta hai. 

<?php
  // Syntax Structure:
  // while (condition):
  //     // code to execute
  // endwhile;

  $count = 3;
  while ($count > 0):
      echo "Countdown: $count <br>";
      $count--;
  endwhile;
?>

3. Practical Example: Embedding in HTML

Dekhiye kaise alternative syntax ka use karke HTML elements (`<ul>` / `<li>`) ke sath clean tareeqe se loop chalaya jata hai: 

<!-- HTML and PHP Mix Example -->
<?php $step = 1; ?>

<ul class="list-disc pl-5">
  <?php while ($step <= 4): ?>
      <li>Step Number: <?php echo $step; ?></li>
      <?php $step++; ?>
  <?php endwhile; ?>
</ul>

4. Practical Example: Array Print Karna

count() function ka upayog karke kisi array ke saare elements ko ek-ek karke fetch karne ka tareeqa: 

<?php
  $colors = ["Red", "Green", "Blue", "Yellow"];
  $index = 0;

  while ($index < count($colors)) {
      echo "Color: " . $colors[$index] . "<br>";
      $index++;
  }
?>

5. Loop Control (break & continue)

Break Statement:

Loop ko kisi condition par turant roknay ke liye:

<?php
  $num = 1;
  while ($num <= 10) {
      if ($num == 5) {
          break; // 5 par aate hi loop stop ho jayega
      }
      echo "$num ";
      $num++;
  }
  // Output: 1 2 3 4
?>

Continue Statement:

Kisi particular iteration ko skip karke aage badhne ke liye:

<?php
  $num = 0;
  while ($num < 5) {
      $num++;
      if ($num == 3) {
          continue; // 3 ko skip kar dega
      }
      echo "$num ";
  }
  // Output: 1 2 4 5
?>

Warning: Infinite Loop Risks

Agar aap loop ke andar variable ko increment ya decrement ($i++) karna bhool jate hain, toh condition hamesha TRUE rahegi.

$i = 1;
while ($i <= 5) {
  echo $i; // Increment missing! Server response time out ho jayega.
}

Nuksan: Isse PHP script ki execution time limit cross ho jayegi aur browser hang/crash ho sakta hai.
