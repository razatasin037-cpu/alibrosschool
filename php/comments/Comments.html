Single-line Comments Kya Hain?

PHP me Single-line Comment ka use ek hi line me note ya explanation likhne ke liye kiya jata hai. Browser ise ignore karta hai aur yeh code me execute nahi hota.

PHP me Single-line comment karne ke 2 tarike hain: // (Double Slash) aur # (Hash sign).

1. Double Slash Syntax ( // )

Yeh PHP me sabse zyada use hone wala comment style hai. Line ke shuru me // lagane par poori line comment ban jati hai. 

<?php
  // Yeh ek single-line comment hai
  echo "Hello World!";
?>

2. Hash Syntax ( # )

Aap single line comment banane ke liye # symbol ka bhi use kar sakte hain (Unix shell-style comment). 

<?php
  # Yeh bhi ek single-line comment hai
  $name = "Rahul";
  echo $name;
?>

Code Ke Baad Inline Commenting

Aap code statement ke aage usi same line me bhi comment jod sakte hain: 

<?php
  $x = 10; // Variable x me 10 assign kiya
  $y = 20; # Variable y me 20 assign kiya
  echo $x + $y;
?>

💡 Pro Tip

Single-line comments ka use chote notes ya specific variable ko describe karne ke liye best hota hai. VS Code me shortcut key Ctrl + / (Windows) ya Cmd + / (Mac) dabakar aap single-line comment easily toggle kar sakte hain.
