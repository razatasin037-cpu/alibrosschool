Multiline Comments Kya Hain?

Jab aapko ek se zyada lines ka explanation ya documentation likhna ho, tab Multiline Comment ka use hota hai.

Multiline comment hamesha /* se shuru hota hai aur */ par end hota hai. Iske beech ki sabhi lines server ignore kar deta hai.

Basic Multiline Syntax ( /* ... */ )

Niche diye gaye example me dekhein ki multiple lines ko ek sath kaise comment kiya jata hai: 

<?php
  /*
    Yeh ek Multiline comment hai.
    Aap isme kitne bhi paragraphs 
    aur lines likh sakte hain.
  */
  echo "Multiline comments complete!";
?>

Code Block Ko Temporarily Ignore Karna

Debugging ke dauran code ke bade parts ko run hone se rokne ke liye bhi multiline comments ka use hota hai: 

<?php
  $x = 5 + 5;

  /*
  $y = 10;
  $z = $x + $y;
  echo $z;
  */

  echo "Code block ignore kar diya gaya.";
?>

Code Expression Ke Beech Comment

Aap expression ke kisi specific part ko skip karne ke liye bhi statement ke beech me /* */ ka use kar sakte hain: 

<?php
  // Yahan + 15 comment hone ki wajah se total result 10 aayega
  $total = 5 /* + 15 */ + 5;
  echo "Total: " . $total;
?>

⚠️ Important Caution

PHP me Multiline comments ko nest (ek ke andar dusra multiline comment) nahi kiya ja sakta. Pehla */ milte hi sabhi comments band ho jate hain, jisse error aa sakti hai.
