PHP Syntax Kya Hai?

PHP script ko HTML documento ke andar kahin bhi rakha ja sakta hai. PHP script hamesha <?php se shuru hoti hai aur ?> par khatam hoti hai.

PHP me har statement ke aakhair me semicolon (;) lagana zaroori hota hai. Semicolon server ko batata hai ki instruction yahan khatam ho gayi hai.

Basic PHP Tags & Code Structure

Peechhe diye gaye code format ko dekhein. Standard PHP file me PHP tags ke andar code likha jata hai: 

<?php
  // PHP code yahan likhein
  echo "Welcome to PHP Syntax!";
?>

* Note: Agar kisi file me sirf PHP code hai (HTML nahi hai), toh aakhri closing tag ?> ko omit karna optional/recommended hota hai.

HTML ke Andar PHP Ka Use

PHP ki sabse badi taakat yeh hai ki aap ise HTML tags ke andar kahin bhi embed kar sakte hain: 

<!DOCTYPE html>
<html>
<body>

  <h1><?php echo "Dynamic Heading"; ?></h1>
  <p><?php echo "Yeh paragraph PHP se render hua hai."; ?></p>

</body>
</html>

PHP Case Sensitivity Rules

PHP me kuch cheezein case-sensitive hoti hain aur kuch nahi hoti. In rules ko samajhna bohot zaroori hai:

NOT Case-Sensitive (Keywords & Functions)

PHP ke built-in keywords (jaise if, else, echo, while) aur custom function names case-insensitive hote hain.

echo "Hello"; // Valid
ECHO "Hello"; // Valid
EcHo "Hello"; // Valid

CASE-SENSITIVE (Variables)

PHP me sabhi variable names case-sensitive hote hain. Small aur Capital letters alag-alag variables maane jate hain.

$color = "Red";
echo $color; // Outputs: Red
echo $COLOR; // Undefined Variable Error

💡 Syntax Rules Checklist

  • PHP code hamesha <?php se start aur ?> par end hota hai.
  • Har instruction ke end me semicolon (;) compulsory hai.
  • Variables ($name) case-sensitive hote hain.
  • Keywords (ECHO, IF) case-sensitive nahi hote.
