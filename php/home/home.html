PHP Programming Sikho

PHP (Hypertext Preprocessor) ek popular server-side scripting language hai jo dynamic aur interactive web pages banane ke liye use hoti hai.

PHP ka use web development, CMS (jaise WordPress), backend APIs aur databases (jaise MySQL) ko integrate karne ke liye kiya jata hai.

Examples Ke Sath PHP Sikho

PHP web backend development ke liye ek open-source aur beginner-friendly language hai. Yeh dynamic content handle karne, database connectivity, sessions aur user authentication ko handle karne me bahut efficient hai. Is tutorial me aap PHP ko fundamental concepts se lekar advanced backend functions tak practical examples aur coding practice ke sath seekhenge.

1. Basic Syntax & Output (Hello World)

PHP code <?php ... ?> tags ke andar likha jata hai. Output show karne ke liye echo statement ka use hota hai.

<?php
  // Basic PHP Script
  echo "Hello, World!";
?>

2. Variables aur Data Types

PHP me variables create karne ke liye $ sign ka use hota hai. Variables dynamically typed hote hain.

<?php
  $name = "Rahul"; // String
  $age = 22;       // Integer
  $price = 99.99;  // Float
  $isStudent = true; // Boolean

  echo "Name: " . $name . "<br>";
  echo "Age: " . $age;
?>

3. Form Handling ($_POST Superglobal)

HTML Form ka data backend PHP script me $_POST array ka use karke read kiya jata hai.

<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = htmlspecialchars($_POST['username']);
    echo "Welcome, " . $username;
}
?>

4. Database Connection (MySQLi)

PHP ko MySQL database se connect karne ke liye mysqli_connect() function ka use kiya jata hai.

<?php
  $servername = "localhost";
  $username = "root";
  $password = "";
  $dbname = "myDB";

  // Create Connection
  $conn = mysqli_connect($servername, $username, $password, $dbname);

  // Check Connection
  if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
  }
  echo "Connected successfully!";
?>
