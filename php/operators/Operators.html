Operators Kya Hote Hain?

Operators symbols hote hain jo variables aur values par mathematical, logical, ya comparison operations perform karne ke liye use kiye jaate hain.

PHP me operators ko principalmente **8 major categories** me divide kiya gaya hai.

1. Arithmetic Operators

Common mathematical operations jaise addition, subtraction, multiplication perform karne ke liye:

Operator Name Example Result
+ Addition $x + $y Sum of $x and $y
- Subtraction $x - $y Difference of $x and $y
* Multiplication $x * $y Product of $x and $y
/ Division $x / $y Quotient of $x and $y
% Modulus $x % $y Remainder of $x divided by $y
** Exponentiation $x ** $y Result of raising $x to the $y'th power

2. Assignment Operators

Variables me values assign aur modify karne ke liye:

Operator Same As Description
x = y x = y Left operand me right value store karta hai
x += y x = x + y Value add karke assign karta hai
x -= y x = x - y Value subtract karke assign karta hai
x *= y x = x * y Multiply karke assign karta hai
x /= y x = x / y Divide karke assign karta hai
x %= y x = x % y Remainder calculate karke assign karta hai

3. Comparison Operators

Do values ya variables ko compare karke Boolean result (true or false) dene ke liye:

Operator Name Example Returns True If
== Equal $x == $y $x and $y are equal
=== Identical $x === $y Equal AND have the same type
!= / <> Not equal $x != $y $x is not equal to $y
!== Not identical $x !== $y Not equal OR not of the same type
> Greater than $x > $y $x is greater than $y
< Less than $x < $y $x is less than $y
>= Greater than or equal to $x >= $y $x is greater than or equal to $y
<= Less than or equal to $x <= $y $x is less than or equal to $y
<=> Spaceship $x <=> $y Returns -1 ($x<$y), 0 ($x==$y), 1 ($x>$y)

4. Increment / Decrement Operators

Variables ki value 1 se increase ya decrease karne ke liye:

Operator Name Description
++$x Pre-increment $x ko 1 se increase karta hai, fir $x return karta hai
$x++ Post-increment Pehle $x return karta hai, fir 1 se increase karta hai
--$x Pre-decrement $x ko 1 se decrease karta hai, fir $x return karta hai
$x-- Post-decrement Pehle $x return karta hai, fir 1 se decrease karta hai

5. Logical Operators

Multiple conditions ko combine karne ke liye use hote hain:

Operator Name Example Returns True If
and / && And $x && $y Both $x and $y are true
or / || Or $x || $y Either $x or $y is true
xor Xor $x xor $y Either $x or $y is true, but NOT both
! Not !$x $x is not true (inverts result)

6. String Operators

PHP me strings ko combine karne ke do specific operators hote hain: 

<?php
  // Concatenation (.)
  $txt1 = "Hello ";
  $txt2 = "World!";
  echo $txt1 . $txt2; // Output: Hello World!

  // Concatenation Assignment (.=)
  $txt1 .= $txt2;
  echo $txt1; // Output: Hello World!
?>

7. Array Operators

Arrays ko combine aur compare karne ke liye:

Operator Name Example Description
+ Union $x + $y Union of $x and $y arrays
== Equality $x == $y True if same key/value pairs
=== Identity $x === $y True if same key/value pairs in same order & type

8. Conditional & Null Coalescing Operators

Ternary operator ?: aur Null Coalescing ?? short conditional expressions ke liye use hote hain: 

<?php
  // 1. Ternary Operator (condition ? expr1 : expr2)
  $status = (empty($user)) ? "anonymous" : "logged in";

  // 2. Null Coalescing Operator (expr1 ?? expr2)
  // Returns expr1 if it exists and is not NULL
  $user_name = $_GET['user'] ?? 'Guest';
  echo $user_name; // Outputs $_GET['user'] or 'Guest' if NULL
?>

💡 Pro-Tip: Spaceship Operator (<=>)

PHP 7 me introduce hua Spaceship Operator (<=>) sorting algorithms ke liye bohot useful hai. Yeh 3 results return karta hai:

  • 1 <=> 2 : Returns -1 (Left side small hai)
  • 1 <=> 1 : Returns 0 (Dono equal hain)
  • 2 <=> 1 : Returns 1 (Left side big hai)
