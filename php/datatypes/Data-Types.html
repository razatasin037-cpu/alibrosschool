Data Types Kya Hain?

Variables alag-alag tarah ka data store kar sakte hain. Data Types batate hain ki kisi variable me kis tarah ki value (text, number, boolean, etc.) store ki gayi hai.

PHP me data type manual declare nahi karna padta. Variable ka type aur value details dekhne ke liye hum var_dump() use karte hain.

Supported Data Types

String Text values
Integer Whole numbers
Float Decimals
Boolean true / false
Array Multiple values
Object Class instances
NULL Empty variable
Resource External references

String & Integer

String: Letters aur characters ka sequence hota hai jise single ('') ya double quotes ("") me likhte hain.
Integer: Bina decimal wala koi bhi poora number (positive ya negative) hota hai. 

<?php
  $x = "Hello PHP!"; // String
  $y = 5985;         // Integer

  var_dump($x); // Output: string(10) "Hello PHP!"
  echo "<br>";
  var_dump($y); // Output: int(5985)
?>

Float & Boolean

Float (Double): Fractional part ya decimal point wala number hota hai.
Boolean: Decisional conditions ke liye use hota hai: true (1) ya false (empty/0). 

<?php
  $num = 10.365;    // Float
  $is_valid = true; // Boolean

  var_dump($num);      // Output: float(10.365)
  echo "<br>";
  var_dump($is_valid); // Output: bool(true)
?>

PHP Array

Array ek hi single variable ke andar multiple items/values store karta hai: 

<?php
  $cars = array("Volvo", "BMW", "Toyota");

  // Check complete array structure & data types
  var_dump($cars);
?>

PHP Object (OOP)

Objects Data aur Functions dono ko combine karte hain. Objects banana ke liye pehle class define karni padti hai: 

<?php
  class Car {
    public $color;
    public function __construct($color) {
      $this->color = $color;
    }
  }

  // Creating object instance
  $myCar = new Car("Red");
  var_dump($myCar); // Output: object(Car)#1 (1) { ["color"]=> string(3) "Red" }
?>

Special Types: NULL & Resource

NULL: Iska matlab hota hai ki variable ke paas koi value nahi hai (Empty variable).
Resource: Special variable jo external sources (jaise Database connection ya Open file stream) ke references hold karta hai. 

<?php
  // NULL Example
  $x = "Hello";
  $x = null; // Variable clear kar diya
  var_dump($x); // NULL

  // Resource Example (File reference)
  $file = fopen("test.txt", "r");
  var_dump($file); // resource(stream)
?>

PHP Type Casting (Conversion)

Aap kisi variable ka data type forcefully change kar sakte hain (e.g., String ko Integer me convert karna): 

<?php
  $a = 5;       // Integer
  $b = 5.34;    // Float
  $c = "25 kilometers"; // String

  // Cast to integer
  $a = (int) $a;
  $b = (int) $b; // Outputs: 5
  $c = (int) $c; // Outputs: 25

  var_dump($b); // int(5)
?>

💡 Important Tip

Variable ka type check karne ke liye 2 main functions hote hain:
1. var_dump() - Returns Type + Value + Length.
2. gettype() - Sirf Type Name return karta hai (e.g., "integer").
