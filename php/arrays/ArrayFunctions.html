Built-in Array Functions

PHP me Arrays par operations perform karne ke liye 80+ built-in functions hote hain. Ye data add/remove karne, search karne, transform karne aur merge karne me madad karte hain.

Chaliye real-world Web Development me sabse zyada use hone wale essential array functions ko dekhte hain.

1. Array Modification (push, pop, shift, unshift)

Array ke start ya end me elements insert ya remove karne ke liye in functions ka use hota hai: 

<?php
  $stack = ["Orange", "Banana"];

  // End me add karein
  array_push($stack, "Apple", "Mango");

  // End se remove karein
  $last = array_pop($stack); // "Mango"

  // Start me add karein
  array_unshift($stack, "Pineapple");

  // Start se remove karein
  $first = array_shift($stack); // "Pineapple"
?>

2. Search & Checking (in_array, array_key_exists, array_search)

Array ke andar value ya key present hai ya nahi check karne ke liye: 

<?php
  $user = ["name" => "Rahul", "role" => "Admin"];

  // Check Value
  if (in_array("Admin", $user)) {
      echo "Access Granted!";
  }

  // Check Key
  if (array_key_exists("role", $user)) {
      echo "Role key exists!";
  }

  // Search value and get Key/Index
  $key = array_search("Rahul", $user); // Output: "name"
?>

3. Extracting Data (array_keys, array_values, count)

Arrays se pure Keys ya pure Values ki separate indexed array banane ke liye: 

<?php
  $person = ["a" => "Red", "b" => "Green", "c" => "Blue"];

  // Total Items Count
  echo count($person); // Output: 3

  // Saari Keys lein
  $all_keys = array_keys($person); // ['a', 'b', 'c']

  // Saari Values lein
  $all_values = array_values($person); // ['Red', 'Green', 'Blue']
?>

4. Utility Functions (array_merge, array_unique, array_map)

Arrays ko combine karne aur duplicate entries clean karne ke liye: 

<?php
  $arr1 = ["a", "b"];
  $arr2 = ["b", "c"];

  // Merging two arrays
  $merged = array_merge($arr1, $arr2); // ['a', 'b', 'b', 'c']

  // Remove duplicates
  $unique = array_unique($merged); // ['a', 'b', 'c']

  // Array Map (Transforming each element)
  $numbers = [1, 2, 3];
  $squared = array_map(fn($n) => $n * $n, $numbers); // [1, 4, 9]
?>

💡 Strict Type Search

in_array() aur array_search() functions me 3rd parameter optional hota hai: strict boolean (`true`). Strict checking enable karne par ye values ke sath types (integer vs string) ko bhi verify karte hain. Always use in_array($val, $arr, true) for security!
