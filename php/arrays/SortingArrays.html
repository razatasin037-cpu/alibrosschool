PHP Array Sorting Functions

PHP me arrays ke elements ko alphabetical ya numerical order me arrange karne ke liye built-in sorting functions available hain.

In functions ko basically teen categories me toda ja sakta hai: Indexed Array Sorting, Associative Value Sorting, aur Key-based Sorting.

Quick Reference Chart

Function Order Sort By Maintains Keys?
sort() Ascending (A-Z / 0-9) Value No (Re-indexes)
rsort() Descending (Z-A / 9-0) Value No (Re-indexes)
asort() Ascending Value Yes
arsort() Descending Value Yes
ksort() Ascending Key Yes
krsort() Descending Key Yes

1. Indexed Arrays: sort() & rsort()

sort() array ko ascending order me arrange karta hai, jabki rsort() descending order me karta hai: 

<?php
  $fruits = ["Lemon", "Orange", "Banana", "Apple"];

  // Ascending Order (A-Z)
  sort($fruits);
  print_r($fruits); // Apple, Banana, Lemon, Orange

  $numbers = [40, 10, 100, 25];

  // Descending Order (High to Low)
  rsort($numbers);
  print_r($numbers); // 100, 40, 25, 10
?>

2. Value Sort with Keys Preserved: asort() & arsort()

Associative arrays ke values ko sort karte waqt keys ki association maintains rakhne ke liye asort() (Ascending) aur arsort() (Descending) use hota hai: 

<?php
  $age = ["Peter" => 35, "Ben" => 37, "Joe" => 43];

  // Value ke acc. Ascending Order
  asort($age);
  print_r($age);

  // Value ke acc. Descending Order
  arsort($age);
  print_r($age);
?>

3. Key-based Sort: ksort() & krsort()

Jab aapko array ko values ki bajaye uski **Keys** ke according sort karna ho: 

<?php
  $age = ["Peter" => 35, "Ben" => 37, "Joe" => 43];

  // Keys ke acc. Ascending Order (Ben, Joe, Peter)
  ksort($age);
  print_r($age);

  // Keys ke acc. Descending Order (Peter, Joe, Ben)
  krsort($age);
  print_r($age);
?>

💡 Important Difference

Hamesha yaad rakhein ki sort() aur rsort() associative array ki keys ko remove karke numeric index (0, 1, 2) me convert kar dete hain. Associative arrays ke sath hamesha asort(), arsort(), ksort(), ya krsort() ka hi use karein!
