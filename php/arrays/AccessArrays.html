Array Elements Ko Access Kaise Karein?

PHP me array ke elements ko access karne ke liye unke Index Number ya Named Key ka use kiya jata hai.

Aap Square Brackets [ ] syntax, functions ya loops ka istemaal karke single aur multidimensional array values ko extract kar sakte hain.

1. Accessing Indexed Array Elements

Indexed array ke elements 0-based index number se access hote hain: 

<?php
  $cars = ["Volvo", "BMW", "Toyota"];

  // Index 0 (Pehla item)
  echo $cars[0]; // Output: Volvo

  // Index 2 (Teesra item)
  echo $cars[2]; // Output: Toyota
?>

2. Accessing Associative Array Elements

Associative array me values unki Key ke naam se access ki jati hain: 

<?php
  $user = [
      "username" => "john_doe",
      "email" => "john@example.com",
      "age" => 25
  ];

  // Key ka naam brackets me likhein
  echo $user["username"]; // Output: john_doe
  echo $user["email"];    // Output: john@example.com
?>

3. Accessing Nested / Multidimensional Arrays

Multidimensional array me sub-arrays ko access karne ke liye multiple brackets [ ][ ] ka use hota hai: 

<?php
  $employees = [
      ["name" => "Amit", "role" => "Developer"],
      ["name" => "Priya", "role" => "Designer"]
  ];

  // Pehle employee ka name
  echo $employees[0]["name"]; // Output: Amit

  // Dusre employee ka role
  echo $employees[1]["role"]; // Output: Designer
?>

4. Safe Accessing (isset() & Null Coalescing)

Error se bachne ke liye access karne se pehle check karein ki key exist karti hai ya nahi: 

<?php
  $data = ["status" => "active"];

  // Method 1: Using isset()
  if (isset($data["status"])) {
      echo $data["status"];
  }

  // Method 2: Null Coalescing Operator (PHP 7+)
  $role = $data["role"] ?? "Guest"; // Role nahi mila toh "Guest" return karega
  echo $role; // Output: Guest
?>

⚠️ Warning: Undefined Array Key

Jab aap kisi non-existing key ya index ko access karte hain, toh PHP Warning throw karta hai. Hamesha Null Coalescing Operator ?? ka use karke fallback value set karein.

$age = $user["age"] ?? 0; // 👈 Safe access method
