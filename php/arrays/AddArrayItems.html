Array Me Naye Items Kaise Add Karein?

PHP me kisi array ke andar naye elements add karne ke kai tarike hain. Aap array ke start, end ya specific key par values insert kar sakte hain.

Aap Square Bracket syntax [], built-in functions jaise array_push(), array_unshift(), ya Spread Operator ka use kar sakte hain.

1. Add to End (Square Bracket Syntax)

Array ke aakhir (end) me ek item add karne ka sabse simple aur fast tarika: 

<?php
  $fruits = ["Apple", "Banana"];

  // End me item add karein
  $fruits[] = "Mango";

  print_r($fruits);
  // Output: Array ( [0] => Apple [1] => Banana [2] => Mango )
?>

2. Add Multiple Items to End (array_push)

Agar aapko ek saath multiple items array ke aakhir me add karne hain: 

<?php
  $colors = ["Red", "Green"];

  // Ek sath multiple items add karein
  array_push($colors, "Blue", "Yellow");

  print_r($colors);
  // Output: Array ( [0] => Red [1] => Green [2] => Blue [3] => Yellow )
?>

3. Add to Beginning (array_unshift)

Array ke shuruat (start) me items insert karne ke liye array_unshift() ka use karein: 

<?php
  $cars = ["BMW", "Toyota"];

  // Start me add karein
  array_unshift($cars, "Volvo");

  print_r($cars);
  // Output: Array ( [0] => Volvo [1] => BMW [2] => Toyota )
?>

4. Add Items to Associative Array

Associative array me nayi key ke sath element add karne ke liye key name specify karein: 

<?php
  $user = [
      "name" => "Aman",
      "age" => 22
  ];

  // Nayi key-value pair add karein
  $user["email"] = "aman@example.com";

  print_r($user);
?>

💡 Performance Tip

Agar aapko sirf ek item array ke end me add karna hai, toh $array[] = $val; ka use karein. Yeh array_push() se fast hota hai kyunki isme koi function call overhead nahi hota.
