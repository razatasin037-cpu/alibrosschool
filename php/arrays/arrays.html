PHP Array Kya Hota Hai?

Ek Array ek aisa special variable hota hai jo ek hi samay par ek se adhik values ko store kar sakta hai.

Agar aapke paas items ki ek list hai (jaise car ke naam ya products), toh unhe alag-alag variables me rakhne ke bajaye aap un sabhi ko ek single array me organize kar sakte hain.

1. Array Create Kaise Karein?

PHP me array do tarike se banaya ja sakta hai: array() function se ya modern short syntax [] ka upayog karke. 

<?php
  // Method 1: Short Syntax (Recommended)
  $cars = ["BMW", "Audi", "Tesla"];

  // Method 2: Traditional array() function
  $fruits = array("Apple", "Banana", "Mango");
?>

2. PHP me Arrays ke Prakar (Types of Arrays)

Indexed Array

Numeric index wale arrays (0 se shuru hone wale position numbers).

Associative Array

Named keys wale arrays jahan har element ka ek specific name/key hota hai.

Multidimensional Array

Aise arrays jinke andar ek ya ek se adhik dusre arrays hote hain.

3. Array Length & Debugging

Array me kitne elements hain yeh janne ke liye count() ka use karein, aur poora array dekhne ke liye print_r() ya var_dump() use karein: 

<?php
  $bikes = ["Yamaha", "Honda", "Kawasaki"];

  // Array ki length find karein
  echo "Total Bikes: " . count($bikes); // Output: 3

  // Debugging ke liye array print karein
  print_r($bikes);
?>

💡 Pro Tip: Array vs Echo

Aap echo ka use karke poore array ko seedhe print nahi kar sakte (jaise: echo $cars;). Aisa karne par PHP "Array to string conversion" warning/error dega. Single element print karne ke liye index batayein (e.g., echo $cars[0];) ya debugging ke liye print_r() ka use karein.
