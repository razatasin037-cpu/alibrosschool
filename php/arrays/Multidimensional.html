Multidimensional Array Kya Hota Hai?

Multidimensional Array ek aisa array hota hai jiske andar ek ya ek se zyada sub-arrays contain hote hain. PHP 2, 3, 4, ya isse bhi zyada levels deep arrays ko support karta hai.

Iska use tabular data (rows & columns), matrix representation, ya complex API JSON responses ko store karne ke liye sabse zyada kiya jata hai.

1. Two-Dimensional (2D) Array

Ek 2D array Basically tables (Rows aur Columns) ki tarah hota hai: 

<?php
  // Creating 2D Array (Car Name, Stock, Sold)
  $cars = [
      ["Volvo", 22, 18],
      ["BMW", 15, 13],
      ["Saab", 5, 2]
  ];

  // Accessing elements: $array[row][column]
  echo $cars[0][0] . ": Stock: " . $cars[0][1]; 
  // Output: Volvo: Stock: 22

  echo $cars[1][0] . ": Sold: " . $cars[1][2]; 
  // Output: BMW: Sold: 13
?>

2. Multidimensional Associative Array

Real-world web applications me numbers se zyada Named Keys (Associative Sub-Arrays) ka use hota hai: 

<?php
  $users = [
      "user1" => [
          "name" => "Rahul",
          "email" => "rahul@gmail.com",
          "roles" => ["Admin", "Editor"]
      ],
      "user2" => [
          "name" => "Priya",
          "email" => "priya@gmail.com",
          "roles" => ["Subscriber"]
      ]
  ];

  // Accessing Nested Values
  echo $users["user1"]["name"]; // Output: Rahul
  echo $users["user1"]["roles"][0]; // Output: Admin
?>

3. Looping Through Multidimensional Arrays

Nested arrays ke sare elements display karne ke liye aap **Nested Foreach Loops** ka use karte hain: 

<?php
  $students = [
      ["name" => "Aman", "score" => 85],
      ["name" => "Neha", "score" => 92]
  ];

  foreach ($students as $student) {
      echo "Student: " . $student["name"] . " | Score: " . $student["score"] . "<br>";
  }
?>

💡 Depth Best Practice

Array depth ko zyadatar 2 ya 3 levels tak hi simit rakhna chahiye. Excessive nesting (4+ levels) se code padhna, manage karna, aur memory analyze karna kaafi mushkil ho jata hai.
