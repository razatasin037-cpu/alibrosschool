Array Items Ko Update Kaise Karein?

PHP me kisi existing array element ki value badalne ke liye aap uske Index Number ya Key par nai value assign karte hain.

Aap direct assignment, loops (Reference &), ya array functions (array_splice) ka use karke values ko update kar sakte hain.

1. Updating Indexed Array Items

Indexed array me specific index reference par nayi value assign karein: 

<?php
  $cars = ["Volvo", "BMW", "Toyota"];

  // Index 1 ("BMW") ko "Ford" se update karein
  $cars[1] = "Ford";

  print_r($cars);
  // Output: Array ( [0] => Volvo [1] => Ford [2] => Toyota )
?>

2. Updating Associative Array Items

Associative array me desired key naam specify karke value overwrite karein: 

<?php
  $user = [
      "name" => "Rahul",
      "role" => "Student",
      "status" => "pending"
  ];

  // Status aur Role update karein
  $user["status"] = "active";
  $user["role"] = "Developer";

  print_r($user);
?>

3. Updating All Items in a Loop (&$item)

foreach loop ke andar array ke original items ko direct update karne ke liye reference & symbol ka istemaal karein: 

<?php
  $prices = [100, 200, 300];

  // Subhi prices me 10% discount update karein
  foreach ($prices as &$price) {
      $price = $price * 0.90;
  }
  unset($price); // Reference break karein

  print_r($prices);
?>

4. Replacing Range of Items (array_splice)

Ek sath multiple elements ko replace karne ke liye array_splice() function best hota hai: 

<?php
  $fruits = ["Apple", "Banana", "Cherry", "Date"];

  // Index 1 se 2 items ko "Kiwi" aur "Mango" se replace karein
  array_splice($fruits, 1, 2, ["Kiwi", "Mango"]);

  print_r($fruits);
  // Output: Array ( [0] => Apple [1] => Kiwi [2] => Mango [3] => Date )
?>

🚨 Important Safety Tip: Unset References

Jab aap &$value reference ka use karke array items ko loop me update karte hain, toh loop khatam hone ke turant baad unset($value); karna zaroori hai. Aisa na karne par same variable aage array ki last value corrupt kar sakta hai.

foreach ($list as &$item) { $item = $item * 2; }
unset($item); // 👈 Hamesha reference break karein!
