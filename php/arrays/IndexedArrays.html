Indexed Array Kya Hota Hai?

Indexed Array PHP me sabse aam array type hai, jisme har element ka ek numeric index hota hai. Index hamesha 0 se shuru hota hai.

Aap isme strings, numbers, floats ya mix data types ko ek hi variable ke andar order list ki tarah store kar sakte hain.

1. Creating an Indexed Array

PHP me array banane ke do tarike hain: Short bracket syntax [] ya fir array() function: 

<?php
  // Method 1: Short Syntax (Recommended)
  $cars = ["BMW", "Audi", "Mercedes"];

  // Method 2: Traditional array() function
  $fruits = array("Apple", "Banana", "Mango");
?>

2. Accessing & Modifying Elements

Elements ko unke Index Number se access ya update kiya jata hai: 

<?php
  $bikes = ["Yamaha", "Honda", "Suzuki"];

  // Accessing values
  echo $bikes[0]; // Output: Yamaha
  echo $bikes[2]; // Output: Suzuki

  // Modifying a value
  $bikes[1] = "Royal Enfield"; // Honda replace ho jayega

  // Adding a new element at the end
  $bikes[] = "KTM"; // Index 3 par add hoga
?>

3. Looping Through an Indexed Array

Array ke sabhi items par iterate karne ke liye aap foreach loop ya count() ke sath for loop use kar sakte hain: 

<?php
  $languages = ["PHP", "JavaScript", "Python", "C++"];

  // Method 1: Using Foreach Loop
  foreach ($languages as $lang) {
      echo "Language: $lang <br>";
  }

  // Method 2: Using For Loop and count()
  $arrLength = count($languages);
  for ($i = 0; $i < $arrLength; $i++) {
      echo "Index $i : " . $languages[$i] . "<br>";
  }
?>

⚠️ Common Pitfall: Undefined Array Key

Yadi aap kisi aise index ko access karne ki koshish karte hain jo exist nahi karta (jaise 3 elements wale array me Index 5), toh PHP ek Warning: Undefined array key error show karega.

$items = ["A", "B"];
echo $items[5]; // ❌ Error: Index 5 does not exist!
