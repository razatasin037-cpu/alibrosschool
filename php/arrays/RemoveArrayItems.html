Array Se Items Remove Kaise Karein?

PHP me array ke elements ko delete karne ke liye alag-alag requirements ke hisab se alag functions ka istemaal hota hai.

Aap unset(), array_pop(), array_shift(), ya array_splice() ka use karke array me se single ya multiple items remove kar sakte hain.

1. Specific Item Delete Karna (unset)

Aap unset() function ka use karke kisi specific index ya key ko delete kar sakte hain: 

<?php
  $cars = ["Volvo", "BMW", "Toyota"];

  // Index 1 ("BMW") ko remove karein
  unset($cars[1]);

  print_r($cars);
  // Note: Unset index numbers ko re-index nahi karta!
?>

2. Last Element Remove Karna (array_pop)

Array ke bilkul aakhri (last) element ko remove karne ke liye: 

<?php
  $fruits = ["Apple", "Banana", "Cherry"];

  // Last item ("Cherry") delete hoga
  array_pop($fruits);

  print_r($fruits);
  // Output: Array ( [0] => Apple [1] => Banana )
?>

3. First Element Remove Karna (array_shift)

Array ke pehle (first) element ko remove karne ke liye. Yeh baaki items ko automatically re-index kar deta hai: 

<?php
  $colors = ["Red", "Green", "Blue"];

  // First item ("Red") delete hoga
  array_shift($colors);

  print_r($colors);
  // Output: Array ( [0] => Green [1] => Blue )
?>

4. Multiple Items Range Remove Karna (array_splice)

Agar kisi specific position se continuous items delete karne hon aur array ko auto re-index bhi rakhna ho: 

<?php
  $numbers = [10, 20, 30, 40, 50];

  // Index 1 se start karke 2 items delete karein
  array_splice($numbers, 1, 2);

  print_r($numbers);
  // Output: Array ( [0] => 10 [1] => 40 [2] => 50 )
?>

⚠️ Important Note: unset() vs array_splice()

unset() use karne par index gaps rah jate hain (e.g., [0, 2] bina index 1 ke). Agar aapko array ko clean karke continuous indexes [0, 1, 2] chahiye, toh array_splice() use karein ya unset ke baad array_values() run karein.

unset($arr[1]);
$arr = array_values($arr); // 👈 Re-indexes array back to 0, 1, 2...
