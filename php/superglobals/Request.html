$_REQUEST Superglobal Kya Hota Hai?

$_REQUEST ek PHP superglobal array variable hai jo default taur par $_GET, $_POST, aur $_COOKIE ke contents ko combine karke hold karta hai.

Jab aapko farak nahi padta ki user ne data URL parameter (GET) se bheja hai ya Form submission (POST) se, tab aap single array `$_REQUEST` se use access kar sakte hain.

Key Concepts & Order Priority

  • Combined Array: Ye GET query string, POST body data, aur Cookies teeno ka mix hota hai.
  • Precedence/Order (GPC): By default PHP config (`php.ini`) me order GET > POST > COOKIE hota hai. Agar same key teenon me ho, toh last wali value (COOKIE ya POST) previous value ko overwrite kar deti hai.

1. Receiving Form & URL Data

Chahe request GET method se aaye ya POST se, $_REQUEST dono scenarios me work karega: 

<?php
  // Example: URL is index.php?fname=Rahul or Form sent fname via POST
  if ($_SERVER["REQUEST_METHOD"] == "POST" || isset($_GET['fname'])) {
      
      // Safely collect input using $_REQUEST
      $name = htmlspecialchars($_REQUEST['fname'] ?? '');
      
      if (empty($name)) {
          echo "Name is empty!";
      } else {
          echo "Hello, " . $name;
      }
  }
?>

2. HTML Form Setup for $_REQUEST

HTML form jisme PHP same file me submission receive karti hai: 

<!-- HTML Form -->
<form method="post" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']);?>">
  <label class="text-white">Name:</label>
  <input type="text" name="fname">
  <button type="submit">Submit</button>
</form>

⚠️ Developer Tip: When NOT to use $_REQUEST

Industry standards me $_REQUEST ke bajaye explicit variables ($_GET ya $_POST) ka use recommend kiya jata hai.

Kyun? Kyunki agar user bilkul same key URL parameter me pass kar de aur Form POST data me bhi bhej de, toh values overwrite ho sakti hain jisse application unexpected behavior generate kar sakti hai (CSRF / Parameter Tampering vulnerability).
