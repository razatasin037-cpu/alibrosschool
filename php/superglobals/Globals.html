$GLOBALS Kya Hota Hai?

$GLOBALS ek built-in PHP superglobal array variable hai jo script ke sabhi Global Scope Variables ko store karta hai.

Iska sabse bada fayda ye hai ki aap kisi bhi local function ya method ke andar se global variables ko bina `global` keyword declare kiye directly access aur modify kar sakte hain.

Key Features

  • Associative Array: Variable ka naam key banta hai (jaise `$x` ke liye `['x']`) aur uski value associative value hoti hai.
  • Everywhere Accessible: Script me kisi bhi jagah (Functions, Classes, Loops) se directly call ho sakta hai.
  • Direct Mutation: Agar aap `$GLOBALS['x']` ki value badalte hain, toh original `$x` variable ki value bhi change ho jaati hai.

1. Basic Access Inside Function

Dekhiye kaise local function ke andar global scope variables ko calculate kiya gaya: 

<?php
  $num1 = 50;
  $num2 = 25;

  function calculateSum() {
      // $GLOBALS array se access karke new global variable 'result' banaya
      $GLOBALS['result'] = $GLOBALS['num1'] + $GLOBALS['num2'];
  }

  calculateSum();

  // Direct global scope me access
  echo $result; // Output: 75
?>

2. Modifying Global Variables

Function ke andar se existing variable ki value update karna: 

<?php
  $site_title = "My Blog";

  function updateTitle() {
      // Original variable value change kar rahe hain
      $GLOBALS['site_title'] = "My Awesome PHP Blog";
  }

  updateTitle();

  echo $site_title; // Output: My Awesome PHP Blog
?>

3. $GLOBALS vs global Keyword

Dono tareeqon me antar samjhein: 

<?php
  $a = 10;

  // Method 1: Using 'global' keyword
  function methodOne() {
      global $a;
      echo $a;
  }

  // Method 2: Using $GLOBALS array
  function methodTwo() {
      echo $GLOBALS['a'];
  }
?>

⚠️ Caution: Overusing Global State

Excessive global variables ka use karne se code ka logic complex ho jata hai (Spaghetti Code). Professional PHP architectures me data pass karne ke liye Function Arguments aur Return Values ka use better practice maana jata hai.
