$_POST Superglobal Kya Hota Hai?

$_POST ek PHP superglobal associative array variable hai jiska use HTTP POST method se bheje gaye HTML Form data ko receive karne ke liye kiya jata hai.

POST method data ko URL ke andar show nahi karta (wo HTTP request body ke andar hidden bheja jata hai), isiliye sensitive data jaise Passwords, Passcodes, aur Credit Card details bhejne ke liye ye sabse secure tareeqa hai.

Key Features & Advantages

  • Secure Transfer: Data URL query string me visible nahi hota (browser history me save nahi hota).
  • No Size Limits: GET method ki tarah URL length limit (2000 chars) nahi hoti, aap large files aur large texts bhi bhej sakte hain.
  • File Upload Support: Multipart data (images, PDFs) upload karne ke liye mandatory method hai.

1. HTML Form Handling with $_POST

Niche dekhiye kaise HTML form `method="POST"` ka use karke sensitive credentials PHP backend par bhejta hai: 

<!-- Login Form Example -->
<form method="POST" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
  <label>Email:</label>
  <input type="email" name="user_email" required>
  
  <label>Password:</label>
  <input type="password" name="user_pass" required>

  <button type="submit">Login</button>
</form>

<?php
  // PHP Script to Process $_POST Data
  if ($_SERVER["REQUEST_METHOD"] === "POST") {
      
      // Safely receive values using input name attributes as key
      $email = htmlspecialchars($_POST['user_email'] ?? '');
      $password = htmlspecialchars($_POST['user_pass'] ?? '');

      echo "Logged in as: " . $email;
  }
?>

2. Checking Fields with isset() & empty()

Undefined Array Key warnings se bachne ke liye data access karne se pehle checking zaroori hoti hai: 

<?php
  if (isset($_POST['username']) && !empty($_POST['username'])) {
      $username = $_POST['username'];
      echo "Hello, " . htmlspecialchars($username);
  } else {
      echo "Please provide a valid username.";
  }
?>

💡 Best Practice: Sanitation & Security

Chahe data HTTP Body (POST) me hi kyu na aa raha ho, direct client inputs par blind trust mat karein!

1. Output screen par print karte waqt hamesha htmlspecialchars() ka use karein (XSS Protection).
2. Database queries me $POST variables directly inject karne ki jagah hamesha PDO / Prepared Statements ka hi use karein (SQL Injection Protection).
