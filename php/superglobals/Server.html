$_SERVER Superglobal Kya Hota Hai?

$_SERVER ek built-in array hai jo Web Server headers, file paths, script locations, aur client HTTP requests ki details hold karta hai.

Ye variables Web Server (jaise Apache ya Nginx) ke dwara auto-generate hote hain aur inka sabse zyada use routing, client IP tracking, aur form submission handling me hota hai.

Commonly Used $_SERVER Elements

Element / Key Description
$_SERVER['PHP_SELF'] Currently executing script ka filename relative path ke sath return karta hai.
$_SERVER['SERVER_NAME'] Host server ka name return karta hai (e.g. www.example.com ya localhost).
$_SERVER['HTTP_HOST'] Current request ki Host header value deta hai.
$_SERVER['REQUEST_METHOD'] Page access karne ka HTTP request method batata hai (e.g. GET, POST).
$_SERVER['REMOTE_ADDR'] Current page view karne wale client user ki IP address return karta hai.
$_SERVER['HTTP_USER_AGENT'] User ke browser aur Operating System ki Agent string details deta hai.

1. Reading Basic Server Environment

Is example me dekhiye kaise server headers aur client device details fetch ki jati hain: 

<?php
  // Fetch Host Name
  echo "Server Host: " . $_SERVER['SERVER_NAME'] . "<br>";

  // Fetch Client IP Address
  echo "Your IP Address: " . $_SERVER['REMOTE_ADDR'] . "<br>";

  // Fetch User Browser Agent
  echo "User Agent: " . $_SERVER['HTTP_USER_AGENT'];
?>

2. Form Submission Check using REQUEST_METHOD

Form submit hua hai ya nahi check karne ke liye sabse secure approach REQUEST_METHOD verify karna hota hai: 

<?php
  // Check if request type is POST
  if ($_SERVER["REQUEST_METHOD"] === "POST") {
      // Process form data safely
      $username = $_POST['username'] ?? '';
      echo "Welcome, " . htmlspecialchars($username);
  }
?>

🛡️ Security Alert: XSS with $_SERVER['PHP_SELF']

Jab aap HTML Forms ke `action` attribute me $_SERVER['PHP_SELF'] ka use karte hain, toh attackers URL ke aage malicious JavaScript code append karke Cross-Site Scripting (XSS) attack kar sakte hain.

Isse bachne ke liye hamesha htmlspecialchars($_SERVER["PHP_SELF"]) ka hi use karein!
