Superglobal Variables Kya Hote Hain?

PHP me Superglobals wo built-in variables hote hain jo hamesha Global Scope me accessible hote hain.

Inhe access karne ke liye aapko kisi function ya class ke andar `global $variable;` declare karne ki zaroorat nahi padti.

All Superglobal Variables

Variable Purpose / Use Case
$_SERVER Headers, paths, and script locations ki information ke liye.
$_GET URL parameters se bheje gaye data ko collect karne ke liye.
$_POST HTTP POST method se bheje gaye Form data ko receive karne ke liye.
$_FILES Uploaded files (Image, PDF, Document) ki details lene ke liye.
$_SESSION Multiple pages par user data persist/store karne ke liye.
$_COOKIE Client browser par saved cookie values access karne ke liye.
$_REQUEST Combine data of $_GET, $_POST, and $_COOKIE.
$GLOBALS Global scope ke saare variables ko reference karne ke liye.

Security Best Practice

Kabhi bhi $_GET ya $_POST se aane wale raw data par seedhe andha-dhund trust na karein! XSS aur SQL Injection attacks se bachne ke liye hamesha input sanitize karein (Jaise: htmlspecialchars() ya filter_input() ka use karke).
