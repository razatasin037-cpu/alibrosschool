$_GET Superglobal Kya Hota Hai?

$_GET ek PHP superglobal associative array variable hai jiska use URL query string ke zariye bheje gaye data ko collect karne ke liye kiya jata hai.

Jab bhi aap kisi URL me key-value pairs (`?name=Rahul&age=25`) dekhte hain ya HTML Form ko `method="GET"` ke sath submit karte hain, toh PHP un values ko auto-populate karke $_GET array me store kar leta hai.

Key Features & Limitations

  • URL Visibility: Data browser address bar me sabko dikhta hai, isiliye ise bookmark kiya ja sakta hai.
  • Size Limit: URL length restriction hone ki wajah se aap max ~2000 characters (2KB) tak ka data hi bhej sakte hain.
  • Non-Sensitive Data Only: Search queries, pagination, aur filter tags ke liye ideal hai; sensitive data (Passwords, Cards) ke liye strictly avoid karein.

1. Reading URL Query Parameters

Maan lijiye user is URL par visit karta hai: profile.php?user=John&role=admin 

<?php
  // Safely check and retrieve URL parameters
  $username = htmlspecialchars($_GET['user'] ?? 'Guest');
  $role     = htmlspecialchars($_GET['role'] ?? 'Subscriber');

  echo "Welcome, " . $username . "! Your role is: " . $role;
?>

2. HTML Search Form using method="GET"

Search forms ke liye standard industry practice GET method use karna hota hai: 

<!-- Search Form Example -->
<form method="GET" action="search.php">
  <input type="text" name="query" placeholder="Search products...">
  <button type="submit">Search</button>
</form>

<!-- Inside search.php -->
<?php
  if (isset($_GET['query'])) {
      $search_term = htmlspecialchars($_GET['query']);
      echo "Search Results for: " . $search_term;
  }
?>

⚠️ Security Warning: Never Trust $_GET Data Directly

Kyunki URL ko koi bhi user manually edit kar sakta hai, $_GET parameters Cross-Site Scripting (XSS) aur SQL Injection ke liye highly vulnerable hote hain.

- Screen par print karte waqt htmlspecialchars() ka istemal karein.
- Numeric IDs (e.g. `product.php?id=5`) ke liye filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT) se integer validation zaroor karein.
