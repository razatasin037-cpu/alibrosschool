Shorthand If Kya Hota Hai?

Jab aapko chote condition statements likhne hote hain, toh poora if...else block likhne ki jagah aap Shorthand If ka upyog karke code ko 1 single line me likh sakte hain.

PHP me ise hum mukhya roop se Ternary Operator (? :) aur Null Coalescing Operator (??) ke zariye use karte hain.

1. Ternary Operator (? :)

Ternary operator if...else ka ek shortcut syntax hai: 

// Syntax: condition ? exprIfTrue : exprIfFalse;
<?php
  $age = 20;

  // Shorthand syntax
  $result = ($age >= 18) ? "Adult" : "Minor";

  echo $result; // Output: Adult
?>

2. Short Ternary Operator (?:)

Aap middle part ko omit (chhod) sakte hain agar aapko condition ki value ko hi assign karna ho jab woh TRUE ho: 

<?php
  $username = "Rahul";

  // Agar $username present hai toh wahi assign hoga, nahi toh "Guest"
  $user = $username ?: "Guest";

  echo $user; // Output: Rahul
?>

3. Null Coalescing Operator (??)

Yeh check karta hai ki variable **set hai ya nahi** aur kya woh NULL nahi hai. Yeh Undefined Variable notice aane se bachata hai: 

<?php
  // Agar $_GET['user'] set nahi hai, toh "Anonymous" assign hoga
  $user = $_GET['user'] ?? 'Anonymous';

  echo $user;
?>

💡 Pro Tip: Best Practice

Shorthand conditions sirf chote assignment tasks ke liye best hote hain. Complex ya nested conditions ke liye hamesha standard if...else block ka use karein taaki aapka code readable rahe.
