Nested If Kya Hota Hai?

Jab aap ek if statement ke andar doosra if statement likhte hain, toh usko Nested If bolte hain.

Andar wala if block tabhi execute hota hai jab bahar wale if ki condition TRUE ho.

1. Basic Nested if Example

Ise step-by-step validations ke liye use kiya jata hai: 

<?php
  $country = "India";
  $age = 20;

  // Outer IF Condition
  if ($country == "India") {
      
      // Inner IF Condition (Tabhi check hoga agar country India ho)
      if ($age >= 18) {
          echo "Aap India me vote dene ke liye eligible hain!";
      } else {
          echo "Aapki age 18 se kam hai.";
      }

  } else {
      echo "Yeh sirf Indian citizens ke liye hai.";
  }
?>

2. Logical Operators Alternative (&&)

Agar aapko alag-alag error messages nahi dikhane hain, toh aap Logical AND (&&) operator se code ko clean aur short bana sakte hain: 

<?php
  $country = "India";
  $age = 20;

  // Dono conditions ko single line me merge kar diya
  if ($country == "India" && $age >= 18) {
      echo "Aap India me vote dene ke liye eligible hain!";
  }
?>

3. Clean Code Pattern: Guard Clauses

Bahut zyada deep nesting (Arrow Anti-pattern) se bachne ke liye Guard Clause Pattern ka use karke pehle invalid cases ko handle karke return ya break kar diya jata hai: 

<?php
  // Deep Nesting se bachne ka tarika (Inside Functions)
  function checkEligibility($country, $age) {
      // Guard Clause 1: Country Check
      if ($country !== "India") {
          return "Sirf Indian citizens ke liye.";
      }

      // Guard Clause 2: Age Check
      if ($age < 18) {
          return "Aapki umar 18 se kam hai.";
      }

      // Main Logic (Clean & Un-nested)
      return "Aap vote de sakte hain!";
  }

  echo checkEligibility("India", 20);
?>

💡 When to use Nested If vs Logical Operators?

  • Nested If: Tab use karein jab alag-alag condition fail hone par unique/different messages show karne hon.
  • Logical Operators (&&): Tab use karein jab target output tabhi show karna ho jab SAARI conditions ek sath true hon.
