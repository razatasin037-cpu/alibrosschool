If...Else Statement Kya Hota Hai?

if...else statement ka upyog tab kiya jata hai jab aapko do vikalp (options) dene hon: ek code block tab chale jab condition TRUE ho, aur doosra block tab chale jab condition FALSE ho.

Aap elseif ka use karke 2 se zyada conditions ko bhi ek sath sequential Order me test kar sakte hain.

1. Basic if...else Syntax

Agar condition TRUE hogi toh if block execute hoga, warna automatically else block wala code chalega: 

<?php
  $age = 16;

  // Condition check
  if ($age >= 18) {
      echo "Aap adult hain aur vote de sakte hain!";
  } else {
      // Target code tab chalega jab condition FALSE ho
      echo "Aap abhi minor hain.";
  }
?>

2. if...elseif...else Statement

Multiple conditions ko sequentially check karne ke liye: 

<?php
  $marks = 75;

  if ($marks >= 90) {
      echo "Grade: Excellent (A+)";
  } elseif ($marks >= 70) {
      // Pehli condition false hone par ye check hoga
      echo "Grade: Very Good (B)";
  } elseif ($marks >= 50) {
      echo "Grade: Good (C)";
  } else {
      // Jab koi bhi condition TRUE na ho
      echo "Result: Fail";
  }
?>

💡 Syntax Note: elseif vs else if

PHP me aap elseif (single word) aur else if (do words) dono ka upyog kar sakte hain. Curly brackets {} ke sath dono bilkul same kaam karte hain.
