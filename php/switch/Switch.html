Switch Statement Kya Hota Hai?

switch statement ka upyog tab kiya jata hai jab aapko ek single variable ki value ko multiple alag-alag values (cases) ke sath compare karna ho.

Yeh bahut saare if...elseif...else blocks likhne ka ek cleaner aur structured vikalp hai.

Switch Keywords Breakdown

Keyword Description
switch($expr) Us variable ya expression ko define karta hai jise evaluate karna hai.
case label: Expected value jisse variable match kiya jayega. Match hone par code block run hoga.
break; Execution ko terminate karta hai taaki aage ke baaki cases automatically run na hon (Fallthrough prevention).
default: Fallback block jo tab execute hota hai jab koi bhi case match na ho (Optional).

1. Basic switch Syntax & Example

Niche diye gaye example me hum din ke hisab se message display kar rahe hain: 

<?php
  $favColor = "red";

  switch ($favColor) {
      case "red":
          echo "Aapka favorite color Red hai!";
          break;

      case "blue":
          echo "Aapka favorite color Blue hai!";
          break;

      case "green":
          echo "Aapka favorite color Green hai!";
          break;

      default:
          // Jab koi bhi case match na ho
          echo "Aapka favorite color Red, Blue, ya Green nahi hai.";
  }
?>

2. Multiple Cases Ko Group Karna (Fall-through)

Aap multiple cases ke liye ek hi code block execute karwane ke liye break ko beech me se hata sakte hain: 

<?php
  $day = "Saturday";

  switch ($day) {
      // Both Monday & Tuesday execute same code
      case "Monday":
      case "Tuesday":
      case "Wednesday":
      case "Thursday":
      case "Friday":
          echo "Aaj Working Day hai!";
          break;

      case "Saturday":
      case "Sunday":
          echo "Aaj Weekend hai!";
          break;

      default:
          echo "Invalid Day Name.";
  }
?>

💡 Modern PHP Feature: match Expression (PHP 8+)

PHP 8 me switch ka aadhunik replacement match aaya hai. Yeh strict comparison (===) karta hai, value return karta hai, aur isme break likhne ki zaroorat nahi hoti:

$result = match($status) {
  200, 201 => 'Success',
  404 => 'Not Found',
  default => 'Unknown Error',
};
