PHP Kya Hai?

PHP ka full form Hypertext Preprocessor hai (pehle ise Personal Home Page kaha jata tha). Yeh ek widely-used, open-source server-side scripting language hai jo dynamic aur interactive web applications banane ke liye design ki gayi hai.

Rasmus Lerdorf ne 1994 me PHP ka pehla version banaya tha. Aaj yeh modern web ka backbone hai aur worldwide millions of websites par use ho rahi hai.

PHP Kaise Kaam Karta Hai?

Client-side languages (HTML, CSS, JS) browser me process hoti hain, lekin PHP code bilkul alag tarike se execute hota hai:

1. Request

User browser me URL enter karke page request karta hai.

2. Processing

Web Server PHP code ko read aur process karta hai.

3. DB Interaction

Zaroorat padne par Database se data fetch/save karta hai.

4. Response

Final output plain HTML me convert ho kar browser ko milta hai.

PHP Ki Main Features

  • Server-Side Execution: Browser ko sirf final output dikhta hai, source PHP code secure rehta hai.
  • Open Source & Free: PHP 100% free hai, aap iske kisi bhi version ko bina license cost ke use kar sakte hain.
  • Cross-Platform Support: Windows, Linux, Unix, macOS sabhi OS par bina kisi badlaav ke chalti hai.
  • Database Compatibility: MySQL, PostgreSQL, Oracle, Sybase, aur SQLite jaise sabhi major databases ko support karti hai.
  • High Speed & Performance: PHP 8+ me JIT (Just-In-Time) compiler ki wajah se script execution speed kafi fast hai.
  • Huge Ecosystem & Community: WordPress, Laravel, Symfony aur Magento jaise powerful frameworks PHP par hi bane hain.

PHP Se Aap Kya Kar Sakte Hain?

1. Dynamic Page Content

Real-time user input ke according webpages ka content live updates karna.

2. Form Data Handling

HTML forms se data receive karna, check karna aur email ya DB me bhejna.

3. File Operations

Server par files create, open, write, update aur delete karna.

4. Cookies & Sessions

Login status, shopping cart details aur user preferences track karna.

5. Database CRUD

Database me naye records Add, Read, Update aur Delete karna.

6. Security & Encryption

Data hashing, password encryption aur user authorization implement karna.

Kyun PHP Use Karein? (Why PHP?)

Duniya ki 77%+ websites aaj bhi backend ke liye PHP ka use karti hain. Internet ke sabse bade platforms jaise WordPress, Wikipedia, aur early-stage Facebook sabhi PHP par bane hain.

Basic PHP File Structure (index.php)

<!DOCTYPE html>
<html>
<head>
  <title>PHP Introduction</title>
</head>
<body>

  <h1>Mera Pehla PHP Page</h1>

  <?php
    // Simple echo statement
    echo "Hello World! PHP sikhna bahut aasan hai.";
  ?>

</body>
</html>

* Note: PHP file ko hamesha .php extension ke sath save kiya jata hai.

💡 Requirement Notice

PHP scripts direct browser me execute nahi ho sakti. Iske liye aapke PC me local web server (jaise XAMPP, WAMP ya LAMP) install hona zaroori hai. Agle chapter me hum step-by-step installation dekhenge.
