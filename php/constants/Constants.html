Constants Kya Hote Hain?

Constants aise identifiers (identifiers/names) hote hain jin ki value ek baar define hone ke baad poor script execution ke dauran change nahi ki ja sakti.

Variables ki tarah constants ke aage Dollar sign ($) lagane ki zaroorat nahi hoti. By default, Constants automatically Global hote hain.

1. Constant Define Karna - define()

PHP me constant banane ke liye define() function ka use sabse common hai. Syntax: define(name, value) 

<?php
  // Case-sensitive constant name
  define("GREETING", "Welcome to PHP Tutorial!");
  
  echo GREETING; // Output: Welcome to PHP Tutorial!
?>

2. const Keyword Ka Upyog

Aap const keyword ka bhi use karke constant define kar sakte hain. Constant names ko hamesha UPPERCASE me likhna best practice mana jata hai: 

<?php
  const SITE_NAME = "MyWebTutorials";

  echo SITE_NAME; // Output: MyWebTutorials
?>

3. Constant Arrays

PHP 7+ se aap define() ka upyog karke **Array** ko bhi constant bana sakte hain: 

<?php
  define("CARS", [
    "Alpha Romeo",
    "BMW",
    "Toyota"
  ]);

  echo CARS[1]; // Output: BMW
?>

define() vs const Difference

Feature define() const
Execution Time Run-time par define hota hai. Compile-time par define hota hai.
Usage Context Conditional statements (`if-else`) me use ho sakta hai. Classes aur global scope ke top-level par hi valid hota hai.
Syntax define('NAME', 'value') const NAME = 'value'

💡 Constants Scope Rule

Constants automatically **Global Scope** carry karte hain. Iska matlab hai ki aap script ke kisi bhi function ya block ke andar bina kisi global keyword ke constant ko direct access kar sakte hain:

define("WELCOME", "Hello Friends!");

function myTest() {
  echo WELCOME; // Function ke andar kaam karega
}
myTest();
