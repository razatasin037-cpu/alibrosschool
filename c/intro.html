C Introduction

C ek general-purpose programming language hai jo Dennis Ritchie ne 1972 me Bell Labs me develop ki thi.

C ka use Operating Systems, Database Systems, Embedded Systems, Drivers aur Software banane ke liye hota hai.

Agar aap programming ki strong foundation banana chahte hain to C best language hai.

Features of C

  • Simple Language
  • Fast Execution
  • Portable
  • Structured Programming
  • Rich Library Functions
  • Memory Management
  • Easy to Learn

Har example ko khud type karke compile aur run karein. Practice hi programming seekhne ka sabse achha tareeka hai.
