Decimal Data Types Kya Hain?

C language me point (floating-point) wali values store karne ke liye **Decimal Data Types** ka use hota hai, jaise 9.99, 3.14159, ya -0.005.

Inko hum Floating-Point Numbers bhi kehte hain. C me teen main floating-point types hote hain: float, double, aur long double.

Decimal Types Comparison

Data Type Memory Size Format Specifier Precision (Point ke baad)
float 4 Bytes %f 6 - 7 Decimal Digits
double 8 Bytes %lf 15 - 17 Decimal Digits
long double 10, 12, or 16 Bytes %Lf 19+ Decimal Digits

Float vs Double Precision

float (Single Precision)

float choti values aur kam accuracy ke liye exact hota hai. Yeh point ke baad 6 se 7 digits tak sahi accurate output deta hai.

double (Double Precision)

double jyada accuracy deta hai (point ke baad 15 digits tak). Mathematical and Scientific calculations me hamesha double recommend kiya jata hai.

💡 Decimal Precision Set Karna:

Point ke baad exact digits control karne ke liye format specifier ke sath %.2f (2 decimal places ke liye) ya %.4f use karein.

Scientific Numbers (Exponent 'e')

Bohat zyada badi ya choti float/double values ko represent karne ke liye scientific notation 'e' ya 'E' ka istemal kiya jata hai (10 ki power): 

#include <stdio.h>

int main() {
    float f1 = 35e3f;   // 35 * 10^3 = 35000
    double d1 = 12E4;   // 12 * 10^4 = 120000

    printf("%f\n", f1);
    printf("%lf\n", d1);

    return 0;
}

Decimal Data Types Code Example

Neeche diye gaye program me dekhiye kaise float aur double ki accuracy me farq hota hai aur decimal precision kaise format karte hain: 

#include <stdio.h>

int main() {
    float myFloatNum = 5.75f;
    double myDoubleNum = 19.99;

    // Default output (6 decimal digits)
    printf("Float default: %f\n", myFloatNum);
    printf("Double default: %lf\n", myDoubleNum);

    // Precision set karke (2 decimal places)
    printf("Float formatted: %.2f\n", myFloatNum);
    printf("Double formatted: %.2lf\n", myDoubleNum);

    return 0;
}

Output:

Float default: 5.750000

Double default: 19.990000

Float formatted: 5.75

Double formatted: 19.99

Summary

Jab bhi decimal numbers store karne ho toh default choice double hoti hai kyunki yeh zyada precision aur safety deta hai. Memory bachani ho toh float use karein.
