Data Types Ka Practical Use

Data types seekhne ke baad unka sahi jagah par istemal karna zaroori hai. Sahi data type chunte waqt teen baaton ka dhyan rakha jata hai:

  • Value decimal wali hai ya integer (float/double vs int).
  • Memory size aur accuracy kitni chahiye.
  • Data text, single character, ya number hai.

Example 1: Marks & Percentage System

Student ke total marks aur percentage calculate karne ke liye int, float, aur typecasting ka use: 

#include <stdio.h>

int main() {
    int maxScore = 500;
    int userScore = 423;

    // Percentage float me aayegi isliye Explicit Type Conversion
    float percentage = ((float) userScore / maxScore) * 100.0;

    printf("User's Percentage is: %.2f%%\n", percentage);

    return 0;
}

Output:

User's Percentage is: 84.60%

Example 2: Shopping Cart & Tax Invoice

Online shopping billing system me int, float, aur char sabhi types milkar kaam karte hain: 

#include <stdio.h>

int main() {
    int itemsCount = 4;
    float pricePerItem = 25.50f;
    float taxRate = 0.05f; // 5% Tax
    char currency = '$';

    float subTotal = itemsCount * pricePerItem;
    float totalTax = subTotal * taxRate;
    float finalBill = subTotal + totalTax;

    printf("Items Purchased: %d\n", itemsCount);
    printf("Subtotal: %c%.2f\n", currency, subTotal);
    printf("Tax Added: %c%.2f\n", currency, totalTax);
    printf("Grand Total: %c%.2f\n", currency, finalBill);

    return 0;
}

Output:

Items Purchased: 4

Subtotal: $102.00

Tax Added: $5.10

Grand Total: $107.10

Summary

Real-world problems solve karte waqt correct data types lene se calculations accurate rehti hain aur memory uselessly waste nahi hoti.
