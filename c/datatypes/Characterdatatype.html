Character Data Type Kya Hai?

C language me single letter, number, ya special symbol (jaise 'A', 'z', '5', '@') store karne ke liye char data type ka use hota hai.

Character value ko hamesha **Single Quotes** (' ') ke andar likha jata hai. Agar aap double quotes (" ") use karenge toh compiler error dega kyunki woh string ban jata hai.

char Data Type Overview

Data Type Memory Size Format Specifier Value Range
char / signed char 1 Byte (8 bits) %c -128 to 127
unsigned char 1 Byte (8 bits) %c / %u 0 to 255

ASCII Values Ka Magic

C language characters ko asal me memory me **ASCII (American Standard Code for Information Interchange)** integer numbers ke format me store karti hai.

'A' - 'Z'

ASCII Code: 65 to 90

'a' - 'z'

ASCII Code: 97 to 122

'0' - '9'

ASCII Code: 48 to 57

💡 Pro Tip:

Agar aap kisi char variable ko %c se print karenge toh character dikhega, aur %d se print karenge toh uski ASCII integer value dikhegi!

Character Code Examples

Example 1: Basic char & ASCII Conversion

#include <stdio.h>

int main() {
    char myGrade = 'A';
    char myAscii = 66; // ASCII for 'B'

    printf("Grade as Character: %c\n", myGrade);
    printf("Grade as ASCII Code: %d\n", myGrade);
    printf("ASCII 66 as Character: %c\n", myAscii);

    return 0;
}

Output:

Grade as Character: A

Grade as ASCII Code: 65

ASCII 66 as Character: B

Example 2: Multiple Characters (String Preview)

Multiple characters yani word/text store karne ke liye character array (String) ka use hota hai: 

#include <stdio.h>

int main() {
    char myText[] = "Hello World!";
    
    printf("%s\n", myText);

    return 0;
}

Common Escape Sequences

Characters ke roop me kuch special actions perform karne ke liye backslash (\) wale escape characters use hote hain:

  • \n - New Line (Nayi line me jane ke liye)
  • \t - Horizontal Tab (Tab space dene ke liye)
  • \\ - Backslash character print karne ke liye
  • \" - Double quote print karne ke liye

Summary

char 1 byte memory leta hai aur single character store karta hai. Internally yeh ASCII value ki tarah behave karta hai, jisse hum ispar arithmetic operations bhi perform kar sakte hain.
