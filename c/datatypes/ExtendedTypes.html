Extended Data Types Kya Hain?

C me basic data types (`int`, `char`, `float`) ki range ya memory size ko modify karne ke liye **Type Modifiers** ka use kiya jata hai.

In modifiers ki madad se hum memory allocation optimize kar sakte hain, negative numbers ko ignore karke positive range double kar sakte hain, ya phir extra large numbers store kar sakte hain.

Type Modifiers Overview

Size Modifiers

  • short: Memory requirement kam karta hai (2 Bytes).
  • long: Higher range deta hai (4 ya 8 Bytes).
  • long long: Extremely large values ke liye (8 Bytes).

Sign Modifiers

  • signed: Positive aur Negative dono values support karta hai (Default).
  • unsigned: Sirf Positive values (Only Zero & Positive), range double ho jati hai.

Extended Integer Types Table

Data Type Bytes Format Specifier Approximate Range
short int 2 %hd -32,768 to 32,767
unsigned short int 2 %hu 0 to 65,535
unsigned int 4 %u 0 to 4,294,967,295
long int 4 / 8 %ld -2 × 10⁹ to 2 × 10⁹
long long int 8 %lld -9 × 10¹⁸ to 9 × 10¹⁸
unsigned long long int 8 %llu 0 to 18 × 10¹⁸

Code Example: Using Extended Types

#include <stdio.h>

int main() {
    // Large population/distance values ke liye long long
    long long int worldPopulation = 8000000000LL;

    // Positives only - Unsigned int
    unsigned int accountBalance = 50000U;

    // Small memory range - Short int
    short int age = 25;

    printf("World Population: %lld\n", worldPopulation);
    printf("Account Balance: %u\n", accountBalance);
    printf("Age: %hd\n", age);

    return 0;
}

Output:

World Population: 8000000000

Account Balance: 50000

Age: 25

Modern Fixed-Width Integers (<stdint.h>)

C99 standard me exact bit size guarantees ke liye <stdint.h> header file introduce kiya gaya tha. Isse Har System/OS par size hamesha fixed rehta hai:

int8_t / uint8_t

Exact 8-bits (1 Byte)

int16_t / uint16_t

Exact 16-bits (2 Bytes)

int32_t / uint32_t

Exact 32-bits (4 Bytes)

int64_t / uint64_t

Exact 64-bits (8 Bytes)

Summary

Jab exact size aur memory constraints matter karti ho (jaise Embedded systems ya cross-platform game development), tab modifiers aur <stdint.h> types ka code safety ke liye use kiya jata hai.
