Numeric Data Types Kya Hain?

C language me bina decimal point (bina point wali) values jaise 10, -500, ya 0 ko store karne ke liye Numeric Data Types ka use kiya jata hai. Unme sabse basic aur common data type int hota hai.

Jab hume alag-alag range ya size ke numbers store karne hote hain, toh hum Type Modifiers (jaise short, long, unsigned) ka istemal karte hain.

Integer Types Breakdown Table

Type Memory Size Format Specifier Value Range
short int 2 Bytes %hd -32,768 to 32,767
unsigned short int 2 Bytes %hu 0 to 65,535
int 2 or 4 Bytes %d -2,147,483,648 to 2,147,483,647
unsigned int 4 Bytes %u 0 to 4,294,967,295
long int 4 or 8 Bytes %ld -2,147,483,648 to 2,147,483,647
long long int 8 Bytes %lld -9,223,372,036,854,775,808 to 9.22e18

Signed vs Unsigned Integers

Signed Integers (Default)

Isme positive (+) aur negative (-) dono tarah ke numbers store ho sakte hain. Normal int by default signed hi hota hai.

Unsigned Integers

Isme sirf positive numbers (0 aur usse badhe) store hote hain. Iska fayda yeh hai ki positive numbers store karne ki range double ho jaati hai!

Numeric Data Types Code Example

Yeh program alag-alag numeric integer types ke declaration aur correct format specifiers ka use batata hai: 

#include <stdio.h>

int main() {
    short smallVal = 32000;
    int normalVal = 150000;
    unsigned int positiveOnly = 4000000000U;
    long long hugeVal = 9000000000000000000LL;

    printf("Short Value: %hd\n", smallVal);
    printf("Normal Int Value: %d\n", normalVal);
    printf("Unsigned Int Value: %u\n", positiveOnly);
    printf("Long Long Value: %lld\n", hugeVal);

    return 0;
}

Output:

Short Value: 32000

Normal Int Value: 150000

Unsigned Int Value: 4000000000

Long Long Value: 9000000000000000000

Summary

Non-decimal numbers ke liye int primary choice hoti hai. Chote data ke liye memory bachane short aur bohot bade values ke liye long long ka use karein.
