sizeof Operator Kya Hai?

sizeof ek compile-time unary operator hai jo kisi data type, variable, ya object ka memory size (in **bytes**) calculate karke return karta hai.

Alag-alag computer architecture (32-bit vs 64-bit systems) par data types ka memory size alag ho sakta hai, isliye programmatically memory exact check karne ke liye sizeof ka use hota hai.

sizeof Operator Ka Syntax

// Data Type ke sath:
sizeof(dataType);

// Variable ke sath:
sizeof(variableName);

💡 Format Specifier Note:

sizeof operator ek size_t (unsigned integer type) value return karta hai. Isko print karne ke liye standard format specifier %lu (long unsigned) ya %zu ka istemal kiya jata hai.

Basic Types Size Example

Neeche diye gaye code se aap sabhi basic data types ke actual memory size check kar sakte hain: 

#include <stdio.h>

int main() {
    int myInt;
    float myFloat;
    double myDouble;
    char myChar;

    printf("Size of int: %lu bytes\n", sizeof(myInt));
    printf("Size of float: %lu bytes\n", sizeof(myFloat));
    printf("Size of double: %lu bytes\n", sizeof(myDouble));
    printf("Size of char: %lu bytes\n", sizeof(myChar));

    return 0;
}

Output (64-bit Architecture):

Size of int: 4 bytes

Size of float: 4 bytes

Size of double: 8 bytes

Size of char: 1 byte

Array Count Calculate Karna

sizeof ka sabse bada real-world advantage hai kisi **Array ke elements ka total length** calculate karna: 

#include <stdio.h>

int main() {
    int myNumbers[] = {10, 25, 50, 75, 100};

    // Array Size Formula: Total Bytes / Byte size of one element
    int length = sizeof(myNumbers) / sizeof(myNumbers[0]);

    printf("Total Bytes of Array: %lu\n", sizeof(myNumbers));
    printf("Number of Elements: %d\n", length);

    return 0;
}

Output:

Total Bytes of Array: 20

Number of Elements: 5

Summary

sizeof operator memory management, dynamic memory allocation (malloc), aur cross-platform coding me sabse critical role play karta hai.
