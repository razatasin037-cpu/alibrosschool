Data Types Kya Hain?

C language me jab bhi hum koi Variable banate hain, toh hume compiler ko batana padta hai ki us variable me kis tarah ka data (number, text, decimal) store hoga. Isi ko Data Type kehte hain.

Data type yeh decide karta hai ki memory me kitni space allocate hogi aur us par kon se operations perform kiye ja sakte hain.

Basic C Data Types Overview

Data Type Memory Size Format Specifier Description
int 2 or 4 bytes %d Whole numbers store karne ke liye (e.g. 100, -50)
float 4 bytes %f Single-precision fractional / decimal numbers (e.g. 3.14)
double 8 bytes %lf Double-precision decimal numbers (larger decimals)
char 1 byte %c Single character or ASCII values (e.g. 'A', 'z')

Basic Code Example

#include <stdio.h>

int main() {
    int myNum = 5;               // Integer
    float myFloatNum = 5.99;     // Floating point number
    double myDoubleNum = 9.98;   // Double precision number
    char myLetter = 'D';         // Character

    printf("%d\n", myNum);
    printf("%f\n", myFloatNum);
    printf("%lf\n", myDoubleNum);
    printf("%c\n", myLetter);

    return 0;
}
