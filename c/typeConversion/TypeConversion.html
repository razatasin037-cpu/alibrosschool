C Type Conversion (Type Casting)

Type Conversion Kya Hai?

Jab ek variable ke data type ko doosre data type me convert kiya jata hai, toh us process ko **Type Conversion** ya **Type Casting** kehte hain.

C language me Type Conversion do tareeqon se hota hai:

  • Implicit Conversion (Automatic): Compiler ise khud kar deta hai.
  • Explicit Conversion (Manual): Programmer ise forcibly code likh kar karta hai.

Implicit vs Explicit Conversion

Feature Implicit Conversion Explicit Conversion
Execution Automatic (by Compiler) Manual (by Programmer)
Data Loss Risk No (Promotes to larger type) Yes (Possible data truncation)
Syntax Required None (dataType) expression

1. Implicit Type Conversion (Automatic)

Jab chote data type ko bade data type me assign kiya jata hai, toh C compiler bina kisi data loss ke automatic type upgrade kar deta hai. Isko **Type Promotion** bhi kehte hain:

bool ➔ char ➔ short int ➔ int ➔ unsigned int ➔ long ➔ float ➔ double

Implicit Example:

#include <stdio.h>

int main() {
    int myInt = 9;
    double myDouble = myInt; // Automatic conversion: int to double

    printf("Integer: %d\n", myInt);
    printf("Double: %lf\n", myDouble);

    return 0;
}

Output:

Integer: 9

Double: 9.000000

2. Explicit Type Conversion (Type Casting)

Jab kisi value ko forcibly doosre data type me convert karna ho, toh value ke aage brackets me type specify karte hain: (type) value.

⚠️ Warning (Data Loss):

Jab aap floating-point value ko int me convert karte hain, toh decimal ke baad ke sare digits ignore (truncate) ho jate hain.

Example 1: Truncation (Decimal Loss)

#include <stdio.h>

int main() {
    float pi = 3.99f;
    int intPi = (int) pi; // Manual casting: float to int

    printf("Float Value: %.2f\n", pi);
    printf("Cast to Int: %d\n", intPi);

    return 0;
}

Output:

Float Value: 3.99

Cast to Int: 3

Example 2: Division Accuracy Fix

Do integers ko divide karne par integer division hota hai. Exact result ke liye type casting zaroori hai: 

#include <stdio.h>

int main() {
    int num1 = 5;
    int num2 = 2;

    // Without Casting: 5 / 2 = 2 (Incorrect)
    float wrongResult = num1 / num2;

    // With Explicit Casting: 5 / 2 = 2.50 (Correct)
    float correctResult = (float) num1 / num2;

    printf("Without Casting: %.2f\n", wrongResult);
    printf("With Casting: %.2f\n", correctResult);

    return 0;
}

Output:

Without Casting: 2.00

With Casting: 2.50

Summary

Calculations me accuracy preserve karne ke liye Explicit Casting ka use karein, especially jab do integers ko divide karke decimal result lana ho.
