Print Text in C

C Programming me text print karne ke liye printf() function ka use kiya jata hai.

Output 


Hello World!

Explanation

  • printf() screen par text print karta hai.
  • Text hamesha double quotes (" ") ke andar likha jata hai.
  • Har statement ke end me semicolon (;) lagana zaruri hota hai.
  • return 0; program successfully end karta hai.

Practice

Ek program likhiye jo ye output print kare: 


My Name is Parwez

📝 Note

printf() C language ka sabse important output function hai. Iska use text aur values print karne ke liye kiya jata hai.

Summary

  • Output print karne ke liye printf() use hota hai.
  • Text double quotes ke andar likha jata hai.
  • Har statement semicolon se end hoti hai.
  • Program return 0; se end hota hai.
