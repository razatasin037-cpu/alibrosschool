string.h Header File Kya Hai?

C language mein strings par alag-alag operations karne ke liye pehle se bane hue builtin functions hote hain. In functions ka upyog karne ke liye hume program ke top par <string.h> header file include karni padti hai.

Popular String Functions:

  • strlen() - String ki length nikalne ke liye
  • strcat() - Do strings ko aapas mein jodne ke liye (Concatenate)
  • strcpy() - Ek string ko doosri string mein copy karne ke liye
  • strcmp() - Do strings ko compare karne ke liye

1. String Length (strlen)

strlen() function string ke andar ke characters ki count return karta hai.

Code Example: strlen

#include <stdio.h>
#include <string.h>

int main() {
    char alphabet[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

    printf("Length of string: %zu\n", strlen(alphabet));

    return 0;
}

Output:

Length of string: 26

2. Concatenate & Copy (strcat & strcpy)

strcat() do strings ko combine karta hai, jabki strcpy() ek string ki value ko doosri mein copy kar deta hai.

Code Example: strcat and strcpy

#include <stdio.h>
#include <string.h>

int main() {
    char str1[20] = "Hello ";
    char str2[] = "World!";
    char str3[20];

    // Concatenate str2 to str1
    strcat(str1, str2);
    printf("Combined String: %s\n", str1);

    // Copy str1 to str3
    strcpy(str3, str1);
    printf("Copied String: %s\n", str3);

    return 0;
}

Output:

Combined String: Hello World!

Copied String: Hello World!

3. Compare Strings (strcmp)

strcmp() function do strings ko compare karta hai. Agar dono strings equal hoti hain toh yeh 0 return karta hai. 

#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello";
    char str2[] = "Hello";
    char str3[] = "Hi";

    // Comparing str1 and str2
    printf("%d\n", strcmp(str1, str2)); // Returns 0 (Equal)

    // Comparing str1 and str3
    printf("%d\n", strcmp(str1, str3)); // Returns non-zero (Not Equal)

    return 0;
}

Output:

0

-4
