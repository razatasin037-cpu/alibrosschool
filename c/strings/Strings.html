String Kya Hota Hai?

C programming mein text ya words ko store karne ke liye koi dedicated string data type nahi hota. Iske bajaye, hum characters ke array (char array) ka use karke strings banate hain.

Key Points:

  • String ko double quotes (" ") ke andar likha jata hai.
  • C language har string ke aakhir mein automatically ek Null Terminator (\0) add kar deti hai.
  • String print karne ke liye %s format specifier ka use hota hai.

String Declare aur Access Kaise Karein?

String declare karne ke liye char data type ke saath variable ke aage square brackets [] ka upyog karte hain.

Code Example: Basic String Operation

#include <stdio.h>

int main() {
    // Creating a String
    char greetings[] = "Hello World!";

    // Printing String
    printf("%s\n", greetings);

    // Accessing individual character using Index
    printf("First character: %c\n", greetings[0]); // Outputs H

    return 0;
}

Output:

Hello World!

First character: H

Modify String Characters (Value Badalna)

String ke kisi specific character ko badalne ke liye uske index number ko refer karte hue single quotes (' ') mein naya character assign kiya jata hai.

Code Example: Modifying Characters

#include <stdio.h>

int main() {
    char greetings[] = "Hello World!";

    // Changing the first character 'H' to 'J'
    greetings[0] = 'J';

    // Printing Updated String
    printf("%s", greetings); // Outputs Jello World!

    return 0;
}

Output:

Jello World!

Loop Through a String

String ke saare characters ko ek-ek karke print ya process karne ke liye for loop ka upyog kiya ja sakta hai. 

#include <stdio.h>

int main() {
    char carName[] = "Volvo";
    int i;

    for (i = 0; carName[i] != '\0'; i++) {
        printf("%c\n", carName[i]);
    }

    return 0;
}

Output:

V

o

l

v

o
