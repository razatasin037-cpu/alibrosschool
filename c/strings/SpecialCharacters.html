Special Characters Aur Escape Sequences

C programming mein kyunki strings ko double quotes (" ") ke andar likha jata hai, isliye agar hum string ke andar hi double quotes ya backslash write karna chahein, toh syntax error aata hai.

Is problem ko solve karne ke liye hum escape character Backslash (\) ka upyog karte hain.

Common Escape Sequences:

  • \" - Double quote print karne ke liye
  • \' - Single quote print karne ke liye
  • \\ - Backslash print karne ke liye
  • \n - New Line ke liye
  • \t - Tab space ke liye

Quotes Aur Backslash Ka Use

Niche diye gaye example mein dekhein ki kaise backslash ka use karke text ke andar quotes print kiye jaate hain.

Code Example

#include <stdio.h>

int main() {
    // Inserting double quotes inside a string
    char txt1[] = "We are the so-called \"Vikings\" from the north.";

    // Inserting single quote inside a string
    char txt2[] = "It\'s alright.";

    // Inserting a single backslash
    char txt3[] = "The character \\ is called backslash.";

    printf("%s\n", txt1);
    printf("%s\n", txt2);
    printf("%s\n", txt3);

    return 0;
}

Output:

We are the so-called "Vikings" from the north.

It's alright.

The character \ is called backslash.

Newline Aur Tab Control

Text ko align karne aur new lines par move karne ke liye \n aur \t ka upyog sabse zyada kiya jata hai.

Code Example: Newline and Tab

#include <stdio.h>

int main() {
    // \n creates a new line
    char text1[] = "Hello\nWorld!";

    // \t creates a horizontal tab space
    char text2[] = "Hello\tWorld!";

    printf("--- New Line Example ---\n%s\n\n", text1);
    printf("--- Tab Space Example ---\n%s\n", text2);

    return 0;
}

Output:

--- New Line Example ---

Hello

World!


--- Tab Space Example ---

Hello World!
