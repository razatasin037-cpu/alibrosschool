Variable Identifiers Kya Hain?

C Language me sabhi variables ko pehchan'ne ke liye ek unique naam dena zaroori hota hai. In unique names ko **Identifiers** kaha jata hai.

Variable ka naam chhota (jaise x aur y) ho sakta hai, par zyaada descriptive names (jaise age, totalSum, studentName) use karna best practice mani jati hai.

Variable Naming Rules (Niyam)

  • Variable names me **letters** (A-Z, a-z), **digits** (0-9), aur **underscores** (_) ho sakte hain.
  • Name hamesha ek **letter** ya **underscore** (_) se shuru hona chahiye (Number se shuru nahi ho sakta).
  • Names **Case-sensitive** hote hain (yani myVar aur myvar alag-alag variables hain).
  • Variable name me **spaces** ya **special characters** (jaise !, #, %, @, $) allowed nahi hain.
  • Reserved words ya **Keywords** (jaise int, float, return) ko variable name ke taur par use nahi kar sakte.

Valid & Invalid Examples

// ✅ Sahi (Valid) Variable Names:
int mySpeed = 80;
int _total_marks = 95;
int student1 = 100;

// ❌ Galat (Invalid) Variable Names:
int 1student = 100;   // Galat: Digits se start nahi ho sakta
int my Speed = 80;    // Galat: Spaces allowed nahi hain
int int = 10;         // Galat: 'int' ek keyword hai
int total$ = 50;      // Galat: '$' special character allowed nahi hai

Camel Case Best Practice

Jab variable name me ek se zyaada words hon, to **camelCase** naming convention follow karna standard practice mana jata hai. Isme pehla word lowercase me hota hai aur baaki saare aane wale words ka pehla letter capital hota hai: 

int studentAge = 20;
float totalAccountBalance = 1500.50;
char userFirstLetter = 'A';

Summary

Variable names hamesha meaningful hone chahiye, digits se shuru nahi hone chahiye, case-sensitive hote hain, aur inme kisi bhi reserved keyword ka istemal nahi hona chahiye.
