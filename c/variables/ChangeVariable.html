Variable Value Ko Badlana (Overwrite)

C Language me Variable ka matlab hi hota hai "jo change ho sake". Jab aap pehle se bane kisi variable ko nayi value assign karte hain, to purani value delete (overwrite) ho jati hai aur usme nayi value store ho jati hai.

Subse zaroori baat: Value change karte waqt dobara Data Type (jaise int, float) nahi likha jata.

1. Direct Value Overwrite Karna

Is method me hum variable ke naam me naya data assign kar dete hain. 

#include <stdio.h>

int main() {
    // Variable declare & initialize
    int myNum = 15; 

    // Value overwrite kar rahe hain (Dobara int mat likho)
    myNum = 20; 

    printf("%d", myNum); // Output: 20

    return 0;
}

2. Ek Variable Ki Value Doosre Me Copy Karna

Aap ek variable ki value ko kisi doosre variable me assign (copy) bhi kar sakte hain. 

#include <stdio.h>

int main() {
    int myNum = 15;
    int myOtherNum = 23;

    // myOtherNum (23) ki value myNum me copy ho jayegi
    myNum = myOtherNum;

    printf("%d", myNum); // Output: 23

    return 0;
}

3. Calculation Karke Value Change Karna

Aap math operators (+, -, *, /) use karke bhi variable ki current value me changes kar sakte hain. 

#include <stdio.h>

int main() {
    int score = 50;

    // 50 + 10 = 60 ab score me store ho jayega
    score = score + 10; 

    printf("New Score: %d", score); // Output: 60

    return 0;
}

❌ Common Mistake (Khas Dhyan Rakhein)

Jab variable pehle se bana ho to uski value update karte waqt Data Type dobara likhne se Compile Error aata hai: 

int age = 18;
int age = 20; // ❌ WRONG: "redefinition of 'age'" error aayega!

age = 20;     // ✅ CORRECT: Direct variable name use karein.

Summary

Variable ki value ko badalna bohot aasan hai. Sirf Variable Name likhein, `=` sign lagayein aur nayi value assign kar dein. Purani value apne aap replace ho jayegi.
