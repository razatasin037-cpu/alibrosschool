Format Specifiers Kya Hain?

C language me Format Specifiers ka use Compiler ko yeh batane ke liye kiya jata hai ki variable me kis type ka data store hai aur usko screen par kaise print ya input karna hai.

Format specifiers hamesha percentage symbol % se start hote hain aur inka use printf() aur scanf() functions ke sath hota hai.

Common Format Specifiers List

Format Specifier Data Type Description
%d / %i int Signed Integer numbers (jaise 10, -50)
%f float Decimal values (jaise 12.34)
%lf double Double precision floating-point numbers
%c char Single Character (jaise 'A', 'b')
%s char[] / String Sequence of characters / Text

Example Program

#include <stdio.h>

int main() {
    // 1. Integer Data Type (Whole Numbers)
    int myNum = 15;

    // 2. Float Data Type (Decimal Numbers)
    float myFloatNum = 5.99;

    // 3. Character Data Type (Single Letter)
    char myLetter = 'D';

    // Printing using Format Specifiers (%d, %f, %c)
    printf("Integer: %d\n", myNum);     // %d -> int ke liye
    printf("Float: %f\n", myFloatNum);   // %f -> float ke liye
    printf("Character: %c\n", myLetter);  // %c -> char ke liye

    return 0;
}

Output

Integer: 15
Float: 5.990000
Character: D

Set Precision (Decimal Format)

By default, Float Value print karte waqt point ke baad 6 digits dikhta hai. Isko control karne ke liye hum %.1f, %.2f jaisa format style use karte hain. 

float myFloat = 9.5742;

printf("%.1f\n", myFloat); // Output: 9.6
printf("%.2f\n", myFloat); // Output: 9.57

Summary

Format Specifiers variables ki values output screen par sahi format me dikhane aur user input receive karne ke liye essential tools hain.
