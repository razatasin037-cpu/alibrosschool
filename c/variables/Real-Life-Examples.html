Real-World Me Variables Ka Use

Real-world applications me variables ka istemal dynamic data store karne ke liye hota hai. Jaise kisi student ka report card banana, e-commerce bill calculate karna, ya kisi account ki details track karna.

In examples se aapko samajh aayega ki alag-alag data types (int, float, char) ek saath real-life scenarios me kaise kaam karte hain.

Example 1: Student Profile System

Ek student ka data store karne ke liye hum roll number (int), percentage (float), aur grade (char) jaisse variables use kar sakte hain: 

#include <stdio.h>

int main() {
    // Student details
    int studentID = 101;
    int studentAge = 20;
    float studentFee = 7500.50;
    char studentGrade = 'A';

    printf("Student ID: %d\n", studentID);
    printf("Age: %d\n", studentAge);
    printf("Fee: %.2f\n", studentFee);
    printf("Grade: %c\n", studentGrade);

    return 0;
}

Output:

Student ID: 101

Age: 20

Fee: 7500.50

Grade: A

Example 2: Rectangle Ka Area Calculate Karna

Variables ki madad se hum Mathematical operations ko aasan bana sakte hain. 

#include <stdio.h>

int main() {
    int length = 12;
    int width = 8;
    int area;

    // Area = length * width
    area = length * width;

    printf("Length: %d\n", length);
    printf("Width: %d\n", width);
    printf("Area of Rectangle: %d\n", area);

    return 0;
}

Output:

Length: 12

Width: 8

Area of Rectangle: 96

Example 3: E-Commerce Bill & Total Cost

Jab hum online items khareedte hain, tab total price, quantity, aur currency format ki calculation iss tarah hoti hai: 

#include <stdio.h>

int main() {
    int items = 5;
    float costPerItem = 99.99;
    float totalCost = items * costPerItem;
    char currency = '$';

    printf("Number of items: %d\n", items);
    printf("Cost per item: %c%.2f\n", currency, costPerItem);
    printf("Total Cost: %c%.2f\n", currency, totalCost);

    return 0;
}

Output:

Number of items: 5

Cost per item: $99.99

Total Cost: $499.95

Summary

Real-world problems ko solve karne ke liye variables, right data types, aur clear naming conventions ka use sabse zaroori step hota hai.
