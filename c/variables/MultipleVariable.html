Multiple Variables Kya Hain?

C Language me agar aapko ek hi Data Type ke bahut saare variables banane hain, toh unhe alag-alag lines me declare karne ki jagah aap comma ( , ) ka use karke ek hi line me declare kar sakte hain.

Isse aapka code chhota, clean aur readable banta hai.

1. Ek Hi Line Me Multiple Variables Declare Karna

Ek hi data type ke multiple variables ko comma se separate karke likhein: 

#include <stdio.h>

int main() {
    // Teeno variables ek hi line me declare aur initialize hue hain
    int x = 5, y = 6, z = 50;

    printf("%d", x + y + z); // Output: 61

    return 0;
}

2. Multiple Variables Ko Same Value Assign Karna

Agar aapko multiple variables me ek hi (same) value assign karni hai, toh aap chaining (=) ka use kar sakte hain: 

#include <stdio.h>

int main() {
    int x, y, z;

    // Teeno variables ko ek hi value (50) mil gayi
    x = y = z = 50;

    printf("%d", x + y + z); // Output: 150

    return 0;
}

Difference (Koun Sa Behtar Hai?)

Misaal ke taur par, alag-alag lines me likhna vs ek line me likhna: 

// ❌ Long Way (Lamba Tarika):
int x = 5;
int y = 6;
int z = 50;

// ✅ Short & Clean Way (Aasan Tarika):
int x = 5, y = 6, z = 50;

Summary

Ek hi data type ke multiple variables ko comma (,) se separate karke ek sath declare kiya ja sakta hai. Isse code kam likhna padta hai aur readable banta hai.
