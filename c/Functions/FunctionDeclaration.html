Declaration Aur Definition Me Kya Antar Hai?

C program me function do parts me divide hota hai: Declaration (jise Function Prototype bhi kehte hain) aur Definition.

1. Function Declaration

Compiler ko function ke naam, return type aur parameters ki jankari deta hai. Isme semicolon (;) lagana jaruri hota hai.

2. Function Definition

Ye function ka actual body code hota hai jo execute hota hai. Isme braces { } ke andar code likha jata hai.

Declaration Ki Zaroorat Kyun Padti Hai?

C compiler code ko upar se niche (top-to-bottom) read karta hai. Agar aap apne user-defined function ko main() function ke niche likhte hain bina declaration ke, toh compiler error ya warning deta hai.

❌ Problem: Bina Declaration Ke Error/Warning

#include <stdio.h>

int main() {
    myFunction(); // Compiler ko abhi tak myFunction ke bare me nahi pata!
    return 0;
}

void myFunction() {
    printf("Hello World!\n");
}

Correct Code Solution

Is samasya ko door karne ke liye hum program ke top par function ko **Declare** kar dete hain: 

#include <stdio.h>

// 1. Function Declaration (Prototype)
void myFunction();

int main() {
    // Function Call
    myFunction();
    return 0;
}

// 2. Function Definition
void myFunction() {
    printf("Sahi tarika! Declaration top par hai.\n");
}

Output:

Sahi tarika! Declaration top par hai.

Parameters Ke Saath Declaration Syntax

Declaration ke samay aap parameters ke variable names ko skip kar sakte hain, bas unka data type likhna mandatory hota hai: 

#include <stdio.h>

// Declaration (Variable names optional hain)
int multiply(int, int);

int main() {
    int ans = multiply(5, 4);
    printf("Multiplication = %d\n", ans);
    return 0;
}

// Definition
int multiply(int a, int b) {
    return a * b;
}

Output:

Multiplication = 20
