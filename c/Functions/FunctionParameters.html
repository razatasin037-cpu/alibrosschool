Parameters Aur Arguments Kya Hain?

Function me data paas karne ke liye hum Parameters ka upyog karte hain. Parameters variables ki tarah act karte hain jo function ke andar local variable ki tarah kaam karte hain.

Parameter

Jab function ki definition me variables declare kiye jaate hain, unhe Parameters kehte hain.

Argument

Jab function call karte vakt actual values pass karte hain, unhe Arguments kehte hain.

Single Parameter Ka Example

Niche diye gaye example me humne ek name parameter (char name[]) pass kiya hai: 

#include <stdio.h>

// 'name' parameter hai
void greetUser(char name[]) {
    printf("Hello %s, welcome to C programming!\n", name);
}

int main() {
    // Actual names pass kar rahe hain (Arguments)
    greetUser("Rahul");
    greetUser("Amit");

    return 0;
}

Output:

Hello Rahul, welcome to C programming!

Hello Amit, welcome to C programming!

Multiple Parameters

Aap function me ek se zyada parameters comma (,) se separate karke pass kar sakte hain. 

#include <stdio.h>

// Multple parameters (String aur Int)
void printInfo(char name[], int age) {
    printf("%s ki age %d saal hai.\n", name, age);
}

int main() {
    printInfo("Rohan", 21);
    printInfo("Priya", 19);

    return 0;
}

Output:

Rohan ki age 21 saal hai.

Priya ki age 19 saal hai.

Return Values (Function Se Value Return Karna)

Jab hume function se output me koi calculation ka result wapas chahiye hota hai, toh hum void ki jagah data type (jaise int, float) likhte hain aur return keyword ka upyog karte hain. 

#include <stdio.h>

// Int return type wala function
int addNumbers(int a, int b) {
    return a + b;
}

int main() {
    int result = addNumbers(10, 20);
    printf("Sum = %d\n", result);

    return 0;
}

Output:

Sum = 30

Pass By Value Vs Pass By Reference

1. Pass by Value

Function ko original value ki copy milti hai. Function ke andar change karne par main variable change nahi hota.

2. Pass by Reference

Pointers ki madad se memory address pass kiya jata hai. Function ke andar change karne se original value me bhi badlaav hota hai.
