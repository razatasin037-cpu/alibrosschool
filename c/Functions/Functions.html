Functions Kya Hote Hain?

Function code ka ek block hota hai jo tabhi run hota hai jab usse call kiya jata hai. Iska upyog code ko clean, reusable, aur modular banane ke liye kiya jata hai.

Why Use Functions?

  • Code Reusability: Ek baar likho, baar-baar use karo.
  • Code Organization: Complex programs ko chhote aur readable blocks mein baante hain.
  • DRY Principle: Don't Repeat Yourself (Baar-baar same code likhne se bachata hai).

Types of Functions

C Language mein 2 tarah ke functions hote hain:

1. Standard Library Functions

Ye C compiler ke dwara pehle se bane hue hote hain. Examples: printf(), scanf(), main().

2. User-Defined Functions

Ye functions programmer dwara specific task perform karne ke liye banaye jate hain.

Function Ka Syntax SAMJHEIN

Function banane ke liye nishchit structure ko follow karna hota hai: 

return_type function_name(parameters) {
    // Function body (Code to be executed)
}

return_type

Batata hai ki function kya value return karega (`int`, `float`, `char`). Agar koi value return nahi karni ho toh void likhte hain.

function_name

Function ka unique naam hota hai jisse usse baad mein call kiya jata hai (e.g., myFunction).

parameters

Function ko paas ki jaane wali values/variables (optional hote hain).

Function Create Aur Call Karna

Function ko use karne ke liye pehle usse define karna padta hai aur phir main() function ke andar call kiya jata hai.

Code Example: Basic Function Call

#include <stdio.h>

// Creating a user-defined function
void myFunction() {
    printf("Hello! Welcome to Functions in C.\n");
}

int main() {
    // Calling the function
    myFunction();
    myFunction(); // Can be called multiple times

    return 0;
}

Output:

Hello! Welcome to Functions in C.

Hello! Welcome to Functions in C.

Function Work Kaise Karta Hai? (Execution Flow)

Program hamesha main() function se chalna shuru hota hai. Execution ke charan step-by-step niche dekhein:

  1. Step 1: Compiler main() function mein enter karta hai.
  2. Step 2: Jab compiler line myFunction(); par pahunchta hai, toh control seedha myFunction() ke body par jump kar jata hai.
  3. Step 3: myFunction() ka pura code execute hota hai.
  4. Step 4: Code khatam hone ke baad control vapas main() function par usi jagah laut aata hai jahan se function call hua tha.

Khaas Baatein (Important Rules)

Function ko kitni bhi baar call kiya ja sakta hai (1 baar ya 100 baar).

C language mein function ka name uniquely identifiable hona chahiye.

Agar aap function definition ko main() ke niche likhna chahte hain, toh uske liye Function Declaration (Prototype) banana compulsory hota hai.
