Recursion Kya Hota Hai?

Recursion ek aisi technique hai jisme koi function khud ko hi call karta hai. Aise function ko Recursive Function kehte hain. Complex problems ko chhote sub-problems me divide karke solve karne me iska upyog hota hai.

Recursion Ke Do Main Parts:

  • Base Condition: Yeh woh condition hai jo recursion ko rokti hai (Infinite loop se bachati hai).
  • Recursive Step: Yeh woh jagah hai jahan function khud ko dubara call karta hai.

Code Example: Factorial Calculate Karna

Factorial (jaise 5! = 5 * 4 * 3 * 2 * 1 = 120) calculate karne ke liye Recursion sabse accha udaharan hai: 

#include <stdio.h>

// Recursive function for Factorial
int factorial(int n) {
    // Base Condition
    if (n <= 1) {
        return 1;
    }
    // Recursive Step
    return n * factorial(n - 1);
}

int main() {
    int num = 5;
    printf("Factorial of %d = %d\n", num, factorial(num));
    return 0;
}

Output:

Factorial of 5 = 120

Factorial Code Kaise Run Hota Hai?

Jab factorial(5) call hota hai, toh memory me stack is tarah banta hai:

factorial(5) -> 5 * factorial(4)

factorial(4) -> 4 * factorial(3)

factorial(3) -> 3 * factorial(2)

factorial(2) -> 2 * factorial(1)

factorial(1) -> 1 (Base condition hit hui! Target achieve!)

Wapas Return value calculate hoti hai: 5 * 4 * 3 * 2 * 1 = 120

Dusra Example: Sum of Numbers

1 se lekar `n` tak ki sankhyaon ka jod (Sum) recursion se nikalne ka tareeka: 

#include <stdio.h>

int sum(int k) {
    if (k > 0) {
        return k + sum(k - 1);
    } else {
        return 0;
    }
}

int main() {
    int result = sum(10);
    printf("Sum of first 10 numbers = %d\n", result);
    return 0;
}

Output:

Sum of first 10 numbers = 55

⚠️ Stack Overflow Se Bachne Ke Rules

Hamesha **Base Condition** lagana zaroori hai, nahi toh program crash ho jayega (Stack Overflow Error).

Recursion memory zyada consume karta hai simple loops ki tulna me, isliye iska upyog zaroorat padne par hi karein.
