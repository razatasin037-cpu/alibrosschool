if Statement Kya Hai?

if statement C language ka sabse basic Decision Making Statement hai. Yeh check karta hai ki koi condition True hai ya False.

Key Points:

  • Agar condition True (1) hoti hai, toh if block ke andar ka code execute hota hai.
  • Agar condition False (0) hoti hai, toh C compiler us code block ko skip kar deta hai.

Syntax

if (condition) {
    // Executed only if condition is true
    code_to_be_executed;
}

Code Example: Age Verification

#include <stdio.h>

int main() {
    int age = 20;

    // Checking condition using if
    if (age >= 18) {
        printf("You are eligible to vote!\n");
    }

    printf("Program finished successfully.");

    return 0;
}

Output:

You are eligible to vote!

Program finished successfully.

Important Rules to Remember

1. Non-Zero is True

C me koi bhi non-zero value (jaise 1, 5, -10) True mani jati hai, aur 0 ko False mana jata hai.

2. Single Statement Bracket

Agar if ke andar sirf ek hi line ka code hai, toh {} brackets optional hote hain.

Summary

if statement program execution ke flow ko control karta hai. Condition sahi hone par block run hota hai, aur galat hone par skip ho jata hai.
