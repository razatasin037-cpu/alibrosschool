else-if Ladder Kya Hai?

Jab hamare paas 2 se zyada conditions check karni hoti hain, tab hum else-if ladder ka use karte hain. Yeh top se bottom conditions check karta hai aur jahan pehli condition True milti hai, sirf wahi block execute hota hai.

Key Points:

  • Multiple conditions ko sequentially test karne ke liye kaam aata hai.
  • Jaise hi koi condition True hoti hai, baaki ki saari conditions skip ho jaati hain.
  • Agar koi bhi condition True nahi hoti, toh last wala else block run hota hai (agar diya gaya ho).

Syntax

if (condition1) {
    // Executed if condition1 is true
    code_block_1;
} else if (condition2) {
    // Executed if condition1 is false and condition2 is true
    code_block_2;
} else {
    // Executed if all conditions are false
    code_block_default;
}

Code Example: Grade Calculator

#include <stdio.h>

int main() {
    int marks = 85;

    if (marks >= 90) {
        printf("Grade: A+\n");
    } else if (marks >= 80) {
        printf("Grade: A\n");
    } else if (marks >= 70) {
        printf("Grade: B\n");
    } else {
        printf("Grade: Fail\n");
    }

    return 0;
}

Output:

Grade: A

Important Rules to Remember

1. Sequence Matters

Conditions upar se neeche check hoti hain. Isliye specific conditions ko pehle aur general conditions ko baad me rakhna chahiye.

2. Optional Final Else

Aakhiri me else lagana optional hota hai, lekin yeh tab kaam aata hai jab baaki saari conditions false ho jayein.

Summary

else-if ladder multiple choices me se sahi decision lene me madad karta hai. Program execution pehli true condition milte hi complete ho jata hai.
