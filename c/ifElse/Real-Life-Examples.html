Real-Life Control Flow Applications

Programming seekhte waqt theoretical concepts ko practical use-cases me apply karna zaroori hai. Yahan hum dekhenge ki real-world scenarios me if, else, aur conditional statements ka kaise upayog kiya jata hai.

Key Concepts Covered:

  • Door Lock System (Passcode Verification)
  • ATM Cash Withdrawal Logic
  • Temperature Alert System

Example 1: Door Lock Passcode Check

Yeh system check karta hai ki user ka enter kiya gaya passcode correct hai ya nahi.

#include <stdio.h>

int main() {
    int doorCode = 1337;
    int userEnteredCode = 1337;

    if (userEnteredCode == doorCode) {
        printf("Correct code. Door unlocked!\n");
    } else {
        printf("Wrong code. Access denied!\n");
    }

    return 0;
}

Output:

Correct code. Door unlocked!

Example 2: ATM Balance Check

Nested logic jisse account balance aur withdrawal amount ko compare kiya jata hai.

#include <stdio.h>

int main() {
    int accountBalance = 5000;
    int withdrawAmount = 2000;

    if (withdrawAmount <= accountBalance) {
        accountBalance -= withdrawAmount;
        printf("Transaction Successful!\n");
        printf("Remaining Balance: %d\n", accountBalance);
    } else {
        printf("Insufficient Balance!\n");
    }

    return 0;
}

Output:

Transaction Successful!

Remaining Balance: 3000

Summary

Real-world software development me conditionals sabse foundational building blocks hote hain. Security systems se lekar financial applications tak, har jagah if-else ka upayog hota hai.
