Nested if Kya Hai?

Nested if ka matlab hota hai ek if statement ke andar dusra if statement hona. Jab hame kisi condition ke sahi hone par hi uske andar ki doosri condition check karni ho, tab hum iska use karte hain.

Key Points:

  • Andar wala if tabhi check hoga jab bahar wala if True hoga.
  • Aap kitni bhi levels tak nesting kar sakte hain (lekin zyada nesting se code readable nahi rehta).
  • Yeh multiple dependent conditions ko check karne ke liye kaam aata hai.

Syntax

if (outer_condition) {
    // Executed if outer_condition is true
    
    if (inner_condition) {
        // Executed if both outer and inner conditions are true
        code_to_be_executed;
    }
}

Code Example: Voting Eligibility with License Check

#include <stdio.h>

int main() {
    int age = 20;
    int hasID = 1; // 1 means True, 0 means False

    if (age >= 18) {
        printf("You are an adult.\n");

        // Nested if check
        if (hasID == 1) {
            printf("You have ID. You can enter.\n");
        } else {
            printf("ID required to enter.\n");
        }
    } else {
        printf("You are underage.\n");
    }

    return 0;
}

Output:

You are an adult.

You have ID. You can enter.

Important Rules to Remember

1. Proper Indentation

Nested code ko hamesha sahi indent (spaces) karke likhein taaki pata chal sake kaun sa block kiska part hai.

2. Avoid Deep Nesting

3-4 level se zyada nesting se bachein. Zyada conditions ke liye Logical Operators (&&, ||) use karein.

Summary

Nested if ek condition ke andar doosri sub-condition test karne ka tarika hai, jo decision-making ko zyada precise banata hai.
