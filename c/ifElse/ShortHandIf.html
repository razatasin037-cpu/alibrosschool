Short Hand If Kya Hai?

Short Hand If ko C language me Ternary Operator (`? :`) bhi kaha jata hai. Yeh standard if-else statement ko ek single line me likhne ka short tarika hai.

Key Points:

  • Code readable aur compact banta hai jab chote decision-making logic ho.
  • Isme 3 operands hote hain: Condition, Expression 1 (True), aur Expression 2 (False).
  • Aap ise kisi variable me value direct store karne ke liye use kar sakte hain.

Syntax

variable = (condition) ? expression_if_true : expression_if_false;

Code Example: Standard vs Short Hand

#include <stdio.h>

int main() {
    int time = 20;

    // Using Short Hand If (Ternary Operator)
    (time < 18) ? printf("Good day.\n") : printf("Good evening.\n");

    return 0;
}

Output:

Good evening.

Important Rules to Remember

1. When to Use

Iska use sirf simple, single-line conditions ke liye karein. Complex conditions me regular if-else hi behtar hota hai.

2. Direct Assignment

Aap is se directly value return karke variable me assign kar sakte hain: int max = (a > b) ? a : b;

Summary

Ternary operator (`? :`) ek quick aur clean rasta hai conditional logic ko ek hi line me perform karne ka.
