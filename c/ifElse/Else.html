if-else Statement Kya Hai?

if-else statement ka use tab hota hai jab hamare paas do paths hote hain. Agar condition True hoti hai toh if block chalta hai, aur agar condition False hoti hai toh else block chalta hai.

Key Points:

  • Condition True hone par if wala code execute hota hai.
  • Condition False hone par fallback ki tarah else wala code run hota hai.
  • else block ko akele nahi likha ja sakta, yeh hamesha if ke sath hi aata hai.

Syntax

if (condition) {
    // Runs if condition is true
    code_block_1;
} else {
    // Runs if condition is false
    code_block_2;
}

Code Example: Even or Odd Number

#include <stdio.h>

int main() {
    int num = 7;

    if (num % 2 == 0) {
        printf("The number is Even.\n");
    } else {
        printf("The number is Odd.\n");
    }

    return 0;
}

Output:

The number is Odd.

Important Rules to Remember

1. No Condition with Else

else ke aage koi condition (jaise else (x > 5)) nahi likhi jati. Yeh sirf if ki condition false hone par chalta hai.

2. Single Block Execution

Dono me se sirf ek hi block execute hoga, kabhi bhi dono blocks ek sath execute nahi ho sakte.

Summary

if-else statement program ko two-way decision making capability deta hai: True hone par ek action aur False hone par dusra action take kiya jata hai.
