C Get Started

Is tutorial mein hum seekhenge ki C Programming Language ko apne computer par kaise install karein aur apna pehla C program kaise likhein.

Step 1: Install a C Compiler

C program ko run karne ke liye ek compiler ki zarurat hoti hai.

  • Windows - MinGW ya Code::Blocks install karein.
  • Linux - GCC Compiler pehle se available hota hai.
  • Mac - Xcode Command Line Tools install karein.

Step 2: Choose an IDE

IDE (Integrated Development Environment) ek software hota hai jisme aap code likhte hain, save karte hain aur run karte hain.

  • Visual Studio Code
  • Code::Blocks
  • Dev-C
  • Visual Studio

Step 3: Write Your First C Program

Is program ko hello.c naam se save karein aur compiler ki madad se compile aur run karein.

Output 


Hello, World!

Summary

  • C program chalane ke liye Compiler install karein.
  • Code likhne ke liye IDE ka use karein.
  • Program ko .c extension ke saath save karein.
  • Compiler se compile karke program run karein.
  • Sabse pehla program Hello, World! hota hai.
