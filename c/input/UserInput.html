User Input Kya Hota Hai?

Ab tak humne jitne bhi C programs banaye hain, unme variables ki values pehle se hi code ke andar fix (hardcode) hoti thi. Jaise int age = 20;. Isme har baar program run karne par age hamesha 20 hi print hoti thi.

Lekin real-world software aur applications me aisa nahi hota! Applications me user keyboard se khud apni value type karta hai (jaise apna naam, password, ya age) aur program us input ko accept karke process karta hai.

💡 User Input ka matlab:

Jab program chalne ke baad (runtime par) user keyboard ke zariye computer ko data deta hai, aur program us data ko apne kisi variable me store kar leta hai, toh ise User Input kehte hain.

C Language me user se keyboard input lene ke liye scanf() function ka use kiya jata hai. Yeh function standard input (yani keyboard) se value read karke variable ko de deta hai.

scanf() Ka Syntax

scanf("%format_specifier", &variableName);
  • %format_specifier - Yeh batata hai ki kis type ka data input lena hai (Jaise: %d for int, %f for float, %c for char).
  • & (Address-of Operator) - Yeh variable ka memory address batata hai jaha user ka enter kiya data store hoga.

Single Value Input Example

Neeche diye gaye program me user se ek integer number liya gaya hai aur usko print kiya gaya hai: 

#include <stdio.h>

int main() {
    int myNum;

    // User ko message dikhana
    printf("Type a number: \n");

    // User se input lena (& operator zaroori hai)
    scanf("%d", &myNum);

    // User ka enter kiya number print karna
    printf("Your number is: %d", myNum);

    return 0;
}

Output:

Type a number:

42

Your number is: 42

Multiple Inputs Lena

Aap ek hi scanf() me multiple values bhi user se input karwa sakte hain: 

#include <stdio.h>

int main() {
    int myNum;
    char myChar;

    printf("Type a number AND a character, then press enter: \n");

    // Ek saath do inputs lena
    scanf("%d %c", &myNum, &myChar);

    printf("Your number is: %d\n", myNum);
    printf("Your character is: %c\n", myChar);

    return 0;
}

⚠️ Common Mistakes (Sabhse Zyada Hone Wali Galati)

  • & Symbol Bhool Jana: scanf() me variable name ke aage & nahi lagane par program crash ho sakta hai.
    scanf("%d", myNum); // ❌ Galat
    scanf("%d", &myNum); // ✅ Sahi
  • Wrong Format Specifier: int ke liye %f ya %c use kar dena.

String (Text) Input (fgets)

scanf("%s", name) space milte hi ruk jata hai. Isliye poora naam ya line input lene ke liye fgets() ka istemal kiya jata hai: 

#include <stdio.h>

int main() {
    char fullName[30];

    printf("Enter your full name: \n");

    // Full text input lene ke liye fgets
    fgets(fullName, sizeof(fullName), stdin);

    printf("Hello %s", fullName);

    return 0;
}

Summary

User se value lene ke liye scanf() ka use hota hai. Scanner me hamesha right format specifier aur & (address-of) operator ka dhyan rakhna zaroori hai. Full string/text line ke liye fgets() best practice hai.
