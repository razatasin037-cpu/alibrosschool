Switch Statement Kya Hai?

switch statement ka use multiple alternatives me se kisi ek code block ko execute karne ke liye kiya jata hai. Yeh multiple else-if statements ka ek cleaner aur faster substitute hai.

Key Points:

  • Expression ki value ko alag-alag case values se compare kiya jata hai.
  • Match hone par us case ka code block execute hota hai.
  • break statement switch block se bahar nikalne ke liye zaroori hota hai.
  • default keyword tab chalta hai jab koi bhi case match nahi hota.

Syntax

switch (expression) {
    case value1:
        // Code to be executed if expression == value1
        break;
    case value2:
        // Code to be executed if expression == value2
        break;
    default:
        // Code to be executed if no case matches
}

Code Example: Day of the Week

#include <stdio.h>

int main() {
    int day = 3;

    switch (day) {
        case 1:
            printf("Monday\n");
            break;
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        default:
            printf("Invalid Day\n");
    }

    return 0;
}

Output:

Wednesday

Important Keywords to Remember

1. The break Keyword

Jab C break keyword par pahunchta hai, toh yeh switch block se bahar nikal jata hai. Agar break na ho, toh agla case bhi automatically execute ho jayega (jise Fall-through bolte hain).

2. The default Keyword

default keyword tab execute hota hai jab koi bhi case value match nahi hoti. Yeh optional hota hai lekin fallback ke liye recommended hai.

Summary

switch statement fixed discrete values (integers ya characters) ko compare karne ke liye best hai aur complex else-if ladders ke muqable code ko zyada readable banata hai.
