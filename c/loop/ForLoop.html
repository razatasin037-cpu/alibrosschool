For Loop Kya Hai?

Jab aapko pehle se pata ho ki aapko code kitni baar repeat chalana hai, tab for loop sabse best choice hoti hai. Yeh initialization, condition, aur counter update ko ek hi line me combine kar deta hai.

For Loop Ke 3 Parts:

  • Initialization: Loop counter variable create aur set karta hai (ek baar chalta hai).
  • Condition: Check hota hai ki loop chalu rahega ya nahi.
  • Update (Increment/Decrement): Har step ke baad variable ki value change hoti hai.

Syntax

for (initialization; condition; increment/decrement) {
    // Code to be executed repeatedly
}

Code Example: Printing Numbers 1 to 5

#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        printf("%d\n", i);
    }

    return 0;
}

Output:

1

2

3

4

5

Nested For Loop

Jab ek for loop ke andar doosra for loop use hota hai, toh use Nested For Loop kehte hain. Iska istemal patterns, matrices, aur 2D arrays me hota hai. 

#include <stdio.h>

int main() {
    int i, j;

    for (i = 1; i <= 2; i++) {
        for (j = 1; j <= 3; j++) {
            printf("i=%d, j=%d\n", i, j);
        }
    }

    return 0;
}

Summary

for loop sabse concise aur popular loop structures me se ek hai, jo fixed-count iterations ke liye ideal mana jata hai.
