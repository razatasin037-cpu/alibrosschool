Do-While Loop Kya Hai?

do-while loop while loop ka hi ek variant hai, lekin isme condition baad me check hoti hai. Is wajah se ise Exit-Controlled Loop kehte hain.

Sabse Bada Difference:

Condition chaotic (false) bhi ho, phir bhi kam se kam ek baar loop body zaroor run hogi, kyunki condition baad me test hoti hai.

Syntax

do {
    // Code to be executed repeatedly
    
    increment_or_decrement;
} while (condition);

* Note: while statement ke baad semicolon (;) lagana mat bhoolna.

Code Example: Printing Numbers 1 to 5

#include <stdio.h>

int main() {
    int i = 1;

    do {
        printf("%d\n", i);
        i++;
    } while (i <= 5);

    return 0;
}

Output:

1

2

3

4

5

While vs Do-While Loop

While Loop

  • Condition pehle check hoti hai.
  • Agar condition False hui toh 0 baar execute hoga.
  • Entry-Controlled Loop kehte hain.

Do-While Loop

  • Condition baad me check hoti hai.
  • Kam se kam 1 baar execute hoga hi.
  • Exit-Controlled Loop kehte hain.

Summary

do-while loop aise scenarios me best hota hai jahan hume user se menu options lene hote hain ya code ko kam se kam ek baar har haal me execute karwana hota hai.
