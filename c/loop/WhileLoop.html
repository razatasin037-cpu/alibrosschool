Loop Kya Hota Hai?

Programming me Loop ka use kisi code block ko baar-baar repeat (execute) karne ke liye kiya jata hai, jab tak ki koi particular condition True rahe.

Loop Kyun Use Karte Hain?

  • Time Save Hota Hai: Ek hi code ko baar-baar repeat likhne ki zaroorat nahi padti.
  • Code Efficiency: Code chota, clean aur readable rehta hai.
  • Automation: 100 ya 1000 baar print karna ho toh bas loop ka counter change karna hota hai.

While Loop Kya Hai?

while loop condition ko code execute hone se pehle check karta hai (isliye ise Entry-Controlled Loop bhi kehte hain). Agar condition True hai, tabhi andar ka code run hoga.

Syntax

while (condition) {
    // Code to be executed repeatedly
    
    increment_or_decrement;
}

Code Example: Printing Numbers 1 to 5

#include <stdio.h>

int main() {
    int i = 1;

    while (i <= 5) {
        printf("%d\n", i);
        i++; // Incrementing variable
    }

    return 0;
}

Output:

1

2

3

4

5

Important Rules to Remember

1. Infinite Loop Warning

Agar aap loop variable ko increment/decrement (i++) nahi karenge, toh condition hamesha True rahegi aur loop kabhi nahi rukega (Infinite Loop).

2. Initial Variable

Loop start hone se pehle counter variable (jaise int i = 1) ko initialize karna zaroori hota hai.

Summary

while loop kisi task ko repeated execution deta hai. Jab tak condition sahi rehti hai, code repeat hota rehta hai.
