Arrays Ke Saath Loops Ka Use

Array ke elements ko ek-ek karke access karne ke liye hum for loop ka use karte hain. Loop counter ko **index 0** se start kiya jata hai.

Code Example: Printing Array with For Loop

#include <stdio.h>

int main() {
    int myNumbers[] = {25, 50, 75, 100};
    int i;

    // Calculate dynamic length of the array
    int length = sizeof(myNumbers) / sizeof(myNumbers[0]);

    for (i = 0; i < length; i++) {
        printf("%d\n", myNumbers[i]);
    }

    return 0;
}

Output:

25

50

75

100
