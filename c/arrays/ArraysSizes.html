Array Size Kaise Calculate Karein?

C language mein sizeof operator ka use array ki memory size (bytes mein) nikalne ke liye hota hai. Array mein kitne elements hain, yeh janne ke liye hum poore array ke size ko uske **pehle element ke size** se divide karte hain.

length = sizeof(array) / sizeof(array[0]);

Code Example: Finding Array Length

#include <stdio.h>

int main() {
    int myNumbers[] = {10, 20, 30, 40, 50};

    // Memory size in Bytes
    printf("Total Size in Bytes: %lu\n", sizeof(myNumbers)); 

    // Calculating Length (Number of elements)
    int length = sizeof(myNumbers) / sizeof(myNumbers[0]);
    printf("Total Elements: %d\n", length);

    return 0;
}

Output:

Total Size in Bytes: 20

Total Elements: 5
