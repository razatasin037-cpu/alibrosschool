Array Kya Hota Hai?

Array ek aisa data structure hai jiska use **multiple values ko ek single variable** mein store karne ke liye kiya jata hai. Alag-alag variables create karne ke bajaye hum ek hi array mein continuous memory allocate karke elements ko store karte hain.

Key Points:

  • Array mein saare elements **same data type** ke hone chahiye.
  • Elements ka Index Always **0 se start** hota hai (0-indexed).

Array Declare aur Access Kaise Karein?

Array declare karte waqt variable ke aage [] (square brackets) lagaye jaate hain aur unke andar elements ki count di jati hai. Access karne ke liye index number ka use kiya jata hai.

Code Example: Creating & Accessing Array

#include <stdio.h>

int main() {
    // Array declaration with initialization
    int myNumbers[] = {25, 50, 75, 100};

    // Accessing elements using index
    printf("First Element: %d\n", myNumbers[0]); // Outputs 25
    printf("Third Element: %d\n", myNumbers[2]); // Outputs 75

    return 0;
}

Output:

First Element: 25

Third Element: 75

Change an Array Element (Modify Values)

Array ke kisi specific element ki value ko change karne ke liye, hum uske **index number** ko refrence karke nayi value assign (= operator) karte hain.

Kaise Kaam Karta Hai?

1. Sabse pehle specify karein ki kis array position ki value badalni hai (e.g., myNumbers[0]).
2. Ab assignment operator (=) ka use karke nayi value set karein (e.g., myNumbers[0] = 99;).
3. Purani value overwrite ho jayegi aur new value RAM ke us location par store ho jayegi.

Code Example: Changing Elements

#include <stdio.h>

int main() {
    int myNumbers[] = {25, 50, 75, 100};

    // Printing Original Value at Index 0
    printf("Original First Element: %d\n", myNumbers[0]);

    // Changing the value of the first element (Index 0)
    myNumbers[0] = 33;

    // Changing the value of the third element (Index 2)
    myNumbers[2] = 99;

    // Printing Modified Values
    printf("Updated First Element: %d\n", myNumbers[0]);
    printf("Updated Third Element: %d\n", myNumbers[2]);

    return 0;
}

Output:

Original First Element: 25

Updated First Element: 33

Updated Third Element: 99
