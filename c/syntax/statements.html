C Statements

Statements C program ke instructions hote hain jo compiler execute karta hai. Har statement generally semicolon (;) se end hoti hai.

Example

Upar diye gaye program me har line ek statement hai jo compiler execute karta hai.

Types of Statements

  • Declaration Statement
  • Assignment Statement
  • Function Call Statement
  • Conditional Statement
  • Loop Statement
  • Return Statement

Explanation

Declaration: Variable banane ke liye use hota hai.

Assignment: Variable me value store karta hai.

Function Call: Kisi function ko execute karta hai.

Conditional: if, else, switch jaise statements decision lene ke liye use hote hain.

Loop: for, while, do-while statements repeat karne ke liye use hote hain.

Return: Function se value return karta hai.

📝 Note

C me almost har statement semicolon (;) se end hoti hai. Agar semicolon miss ho jaye to compiler error dega.

Summary

  • Statement compiler ko instruction deta hai.
  • Har statement usually semicolon se end hoti hai.
  • C me different types ke statements hote hain.
  • Statements milkar ek complete program banate hain.
