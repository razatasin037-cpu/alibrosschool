Real-World Projects Me Structure Ka Use

Real-world software development me structures ka upayog multi-data entity (jaise Student, Bank Account, Car, E-commerce Product) ke data ko manageable tarike se program me handle karne ke liye hota hai. Niche practical examples diye gaye hain.

Example 1: Bank Account System

Bank me customer ka Account Number, Name aur Balance ek sath manage karne ke liye struct ka upayog kaise karte hain: 

#include <stdio.h>
#include <string.h>

struct BankAccount {
    int accountNumber;
    char holderName[50];
    float balance;
};

int main() {
    // Creating account details
    struct BankAccount acc1;
    
    acc1.accountNumber = 987654321;
    strcpy(acc1.holderName, "Vikram Singh");
    acc1.balance = 12500.75;

    printf("--- Bank Statement ---\n");
    printf("Acc No: %d\n", acc1.accountNumber);
    printf("Holder: %s\n", acc1.holderName);
    printf("Balance: ₹%.2f\n", acc1.balance);

    return 0;
}

Output:

--- Bank Statement ---

Acc No: 987654321

Holder: Vikram Singh

Balance: ₹12500.75

Example 2: Array of Structures (Multiple Students Record)

Jab ek se zyada records store karne hote hain, toh hum Array of Structures ka upayog karte hain: 

#include <stdio.h>

struct Student {
    int rollNo;
    char name[30];
    float percentage;
};

int main() {
    // Array of 3 Students
    struct Student class1[3] = {
        {1, "Aarav", 92.4},
        {2, "Neha", 88.5},
        {3, "Karan", 79.0}
    };

    printf("--- Student Report Card ---\n");
    for(int i = 0; i < 3; i++) {
        printf("Roll No: %d | Name: %s | Marks: %.1f%%\n", 
               class1[i].rollNo, class1[i].name, class1[i].percentage);
    }

    return 0;
}

Output:

--- Student Report Card ---

Roll No: 1 | Name: Aarav | Marks: 92.4%

Roll No: 2 | Name: Neha | Marks: 88.5%

Roll No: 3 | Name: Karan | Marks: 79.0%
