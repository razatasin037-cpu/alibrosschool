C Structure Kya Hai?

Structure (jise struct keyword se banaya jata hai) ek User-Defined Data Type hai. Array me hum sirf ek hi type ka data rakh sakte hain, lekin Structure me hum alag-alag data types (jaise int, float, char) ke data ko ek single name ke andar group kar sakte hain.

❌ Array Ki Limitation

Array me aap sirf same type ki values rakh sakte hain (jaise sare integers ya sare characters).

✅ Structure Ka Fayda

Ek Student ka Data (Roll No, Name, Marks) ek jagah combine karke store kar sakte hain.

Structure Kaise Banayein? (Syntax)

Structure banane ke liye struct keyword ka use hota hai. Uske andar alag-alag variables hote hain jinhe Members bolte hain: 

// Structure Definition
struct Student {
    int rollNo;
    char name[50];
    float marks;
}; // Semicolon mandatory hai

Complete Code Example

Structure Variable banane ke baad uske members ko access karne ke liye Dot Operator (.) ka use hota hai: 

#include <stdio.h>
#include <string.h>

// Structure declaring
struct Student {
    int rollNo;
    char name[30];
    float marks;
};

int main() {
    // Structure Variable declaration
    struct Student s1;

    // Values Assigning
    s1.rollNo = 101;
    strcpy(s1.name, "Rahul Sharma");
    s1.marks = 89.5;

    // Printing Structure Values
    printf("Roll No: %d\n", s1.rollNo);
    printf("Name: %s\n", s1.name);
    printf("Marks: %.1f\n", s1.marks);

    return 0;
}

Output:

Roll No: 101

Name: Rahul Sharma

Marks: 89.5

Direct Initialization Ka Tarika

Aap structure variable ko declare karte waqt hi directly values assign kar sakte hain: 

#include <stdio.h>

struct Car {
    char brand[20];
    int year;
    int price;
};

int main() {
    // Single-line Direct Initialization
    struct Car c1 = {"BMW", 2024, 7500000};

    printf("%s (%d) - Price: ₹%d\n", c1.brand, c1.year, c1.price);
    return 0;
}

Output:

BMW (2024) - Price: ₹7500000
