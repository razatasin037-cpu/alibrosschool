Nested Structure Kya Hota Hai?

Jab ek Structure ke andar dusra Structure element/member ke roop me declare kiya jata hai, toh use Nested Structure kehte hain.

Real-Life Example:

Maan lijiye aapko ek Employee ka data store karna hai. Employee ke pass id, name aur uska address hai. Address me multiple fields hoti hain jaise city, state, aur pinCode. Toh hum Address ka alag se structure banakar use Employee structure me nest kar sakte hain.

Code Example (Separate Structures)

Nested Structure ke members ko access karne ke liye Double Dot (.) operator ka upyog kiya jata hai (jaise: emp1.addr.city): 

#include <stdio.h>
#include <string.h>

// 1. Outer Structure (Address)
struct Address {
    char city[20];
    int pinCode;
};

// 2. Main Structure (Employee)
struct Employee {
    int id;
    char name[30];
    struct Address addr; // Nested Structure Member
};

int main() {
    struct Employee emp1;

    emp1.id = 101;
    strcpy(emp1.name, "Aman");
    strcpy(emp1.addr.city, "Delhi");
    emp1.addr.pinCode = 110001;

    printf("ID: %d\n", emp1.id);
    printf("Name: %s\n", emp1.name);
    printf("City: %s\n", emp1.addr.city);
    printf("Pin Code: %d\n", emp1.addr.pinCode);

    return 0;
}

Output:

ID: 101

Name: Aman

City: Delhi

Pin Code: 110001

Embedded Structure (Inline)

Aap chahein toh ek Structure ke andar hi dusre structure ko directly define kar sakte hain: 

struct Student {
    int rollNo;
    char name[30];

    // Inner Structure
    struct DOB {
        int day;
        int month;
        int year;
    } date; // Inner Variable
};
