Structure Me Strings Ka Upayog

Structure me Jab aap char array (String) declare karte hain, toh aap direct assignment operator (=) se string value assign nahi kar sakte. Iske liye C library ke strcpy() function ka upayog karna padta hai.

❌ Incorrect Method

Directly equal to (=) lagane par compiler error deta hai:

s1.name = "Rahul"; // Compilation Error!

✅ Correct Method

strcpy() function ka use karke value copy karein:

strcpy(s1.name, "Rahul"); // Works Perfectly!

Code Example: strcpy() Ke Saath

strcpy() ko use karne ke liye header file <string.h> ko include karna zaroori hai: 

#include <stdio.h>
#include <string.h> // Mandatory for strcpy

struct Book {
    int bookId;
    char title[50];
    char author[30];
};

int main() {
    struct Book b1;

    b1.bookId = 101;

    // String Copying using strcpy
    strcpy(b1.title, "C Programming Mastery");
    strcpy(b1.author, "Dennis Ritchie");

    printf("Book ID: %d\n", b1.bookId);
    printf("Title: %s\n", b1.title);
    printf("Author: %s\n", b1.author);

    return 0;
}

Output:

Book ID: 101

Title: C Programming Mastery

Author: Dennis Ritchie

Bina strcpy() Ke String Assign Karna

Agar aap Structure variable ko Declaration ke time par hi initialize kar dete hain, toh aapko strcpy() ki zaroorat nahi padti: 

#include <stdio.h>

struct User {
    char username[20];
    char email[40];
};

int main() {
    // Direct Initialization (No strcpy needed!)
    struct User u1 = {"tech_ninja", "ninja@example.com"};

    printf("Username: %s\n", u1.username);
    printf("Email: %s\n", u1.email);

    return 0;
}

Output:

Username: tech_ninja

Email: ninja@example.com
