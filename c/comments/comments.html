C Comments

Comments ka use C program me code ko explain karne ke liye kiya jata hai. Ye sirf programmer ke liye hote hain aur compiler inhe ignore kar deta hai. Isliye comments program ke output ko affect nahi karte.

Jab project bada ho ya team me kaam karna ho, tab comments code ko samajhna aur maintain karna bahut aasan bana dete hain.

Comments Ka Use Kyu Karte Hai?

Sochiye aapne aaj ek bada project banaya aur 6 mahine baad us project ko dubara open kiya. Agar aapne comments nahi likhe honge to code ko samajhne me kaafi time lagega. Lekin agar important jagah comments likhe honge to turant samajh aa jayega ki code kis kaam ke liye likha gaya tha.

Team me kaam karte waqt comments aur bhi important ho jate hain. Har programmer ka coding style alag hota hai. Comments dusre developers ko code samajhne me help karte hain aur project ko maintain karna bahut easy bana dete hain.

Isi liye har professional developer important logic ke upar comments zarur likhta hai. Lekin unnecessary comments likhne se bachna chahiye.

Single Line Comment

Agar hume sirf ek line ke liye comment likhna ho to hum // ka use karte hain. Compiler // ke baad us line me likhe hue pure text ko ignore kar deta hai.

Single Line Comments ka use chhoti information dene ke liye kiya jata hai. Jaise kisi variable ka purpose batana, kisi function ko explain karna ya kisi important line ke baare me short note likhna.

Ye beginners ke liye bhi bahut useful hote hain kyunki jab aap programming seekh rahe hote hain tab comments likhne se concepts ko yaad rakhna aasaan ho jata hai.

Is example me // Print Hello World ek Single Line Comment hai. Compiler is line ko ignore karega aur sirf printf() statement execute karega. Isliye output sirf Hello World! hi print hoga.

Multi Line Comment

Kabhi-kabhi hume ek line se zyada explanation likhne ki zarurat hoti hai. Aise situation me hum Multi Line Comment ka use karte hain. Multi Line Comment /* se start hota hai aur */ par khatam hota hai. In dono symbols ke beech me jitna bhi text likha hota hai, compiler usse ignore kar deta hai.

Multi Line Comments ka use tab kiya jata hai jab hume kisi function, algorithm ya code ke kisi bade part ke baare me detail me information deni ho. Professional projects me developers documentation likhne ke liye bhi Multi Line Comments ka use karte hain.

Agar aap kisi code ko temporary disable karna chahte hain to us code ko bhi Multi Line Comment ke andar rakh sakte hain. 


#include <stdio.h>

int main()
{

   /*
      This is
      a Multi Line
      Comment
   */

   printf("Hello World!");

   return 0;

}

Is program me compiler /* */ ke andar likhe hue text ko ignore karega aur sirf printf() function execute karega.

Single Line aur Multi Line Comment me Difference

Single Line Comment sirf ek line ke liye use hota hai aur iske liye // ka use kiya jata hai. Ye chhoti information ya kisi ek statement ko explain karne ke liye best hota hai.

Multi Line Comment ek se zyada lines ke liye use hota hai aur iske liye /* */ ka use kiya jata hai. Jab explanation lambi ho ya kisi function ke baare me detail likhni ho tab Multi Line Comment use karna better hota hai.

Best Practices

Comments hamesha simple aur meaningful hone chahiye. Aisa comment likho jise padhkar turant samajh aa jaye ki code kya kar raha hai.

Har line ke liye comment likhna achhi practice nahi hai. Sirf wahi jagah comment likho jahan explanation ki zarurat ho.

Agar code change ho jaye to comments ko bhi update karna chahiye. Purane aur galat comments dusre programmers ko confuse kar sakte hain.

Code jitna clean aur readable hoga, utne hi kam comments ki zarurat padegi.

Common Mistakes

Bahut se beginners har line ke baad comment likh dete hain. Isse code bada aur confusing lagne lagta hai.

Kuch programmers code update kar dete hain lekin comments update nahi karte. Is wajah se comments aur code alag-alag information dene lagte hain.

Hamesha sirf useful comments likho aur unnecessary comments se bachne ki koshish karo.

Real Life Example

Sochiye aapne ek School Management System banaya hai jisme 10,000 se bhi zyada lines ka code hai. Agar comments nahi honge to kuch mahino baad apna hi code samajhna mushkil ho jayega.

Isi liye professional developers important functions, login system, database queries aur complex logic ke upar comments zarur likhte hain.

📝 Note

Comments program ko readable banate hain, lekin bahut zyada comments likhne se code aur bhi confusing ho sakta hai. Hamesha sirf wahi comments likho jo dusre programmer ya future me khud tumhare liye useful hon.

Summary

C Programming me Comments ka use code ko explain karne ke liye kiya jata hai. Compiler comments ko execute nahi karta aur unhe completely ignore kar deta hai.

Single Line Comment ke liye // aur Multi Line Comment ke liye /* */ ka use hota hai. Dono ka purpose code ko readable aur easy to understand banana hai.

Hamesha meaningful comments likho aur unnecessary comments se bacho. Clean code aur achhe comments milkar kisi bhi project ko professional banate hain.
