New Lines in C

C Programming me \n ko New Line Escape Sequence kaha jata hai.

Jab bhi \n use karte hain to cursor next line me chala jata hai.

Example 


#include <stdio.h>

int main()
{
    printf("Hello\n");
    printf("Welcome");
    return 0;
}

Output 


Hello
Welcome

Explanation

  • \n ek Escape Sequence hai.
  • Ye cursor ko next line me le jata hai.
  • Readable output ke liye iska use kiya jata hai.
  • Ek hi printf() me multiple \n use kar sakte hain.

Multiple New Lines Example 


#include <stdio.h>

int main()
{
    printf("HTML\n");
    printf("CSS\n");
    printf("JavaScript\n");
    printf("C Programming");

    return 0;
}

Output 


HTML
CSS
JavaScript
C Programming

💡 Tips

  • Long output ko readable banane ke liye \n use karein.
  • \n sirf strings ke andar hi kaam karta hai.
  • Programming me Escape Sequences bahut useful hote hain.

Escape Sequences

Sequence Description
\n New Line
\t Horizontal Tab
\" Double Quote
\\ Backslash

Important Points

  • printf() output print karne ke liye use hota hai.
  • Text hamesha double quotes ke andar likha jata hai.
  • Har statement semicolon (;) se end hoti hai.
  • \n new line ke liye use hota hai.
  • \t tab space dene ke liye use hota hai.

Practice

Ek program likhiye jo niche diya gaya output print kare: 


Apple
Mango
Orange
Banana

📝 Note

\n C Programming ka sabse common Escape Sequence hai. Iska use output ko multiple lines me print karne ke liye kiya jata hai.

Summary

  • \n ek New Line Escape Sequence hai.
  • Ye cursor ko next line me le jata hai.
  • Output ko readable banata hai.
  • Iska use printf() ke andar kiya jata hai.
