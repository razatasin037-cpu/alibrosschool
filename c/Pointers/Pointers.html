Memory Address Kya Hota Hai?

Jab bhi hum C language mein koi variable create karte hain, toh RAM (Computer Memory) mein us variable ke liye ek space allocate hoti hai. Us memory location ka ek unique address hota hai.

Kisi variable ka memory address lene ke liye hum Reference Operator (&) ka upyog karte hain, aur use print karne ke liye %p format specifier ka use hota hai.

Code Example: Getting Memory Address

#include <stdio.h>

int main() {
    int myAge = 43;
    printf("Memory Address: %p\n", &myAge);
    return 0;
}

Output (Hexadecimal Format):

Memory Address: 0x7ffe5367e044

Pointer Kya Hai?

Pointer ek aisa variable hota hai jo kisi doosre variable ka memory address store karta hai.

Key Highlights:

  • Pointer declare karne ke liye data type ke baad asterisk symbol (*) lagaya jata hai.
  • Pointer ka data type wahi hona chahiye jo us variable ka hai jiska address aap store kar rahe hain.

Code Example: Pointer Declaration & Usage

#include <stdio.h>

int main() {
    int myAge = 43;     // Normal variable
    int* ptr = &myAge;   // Pointer variable storing the address of myAge

    // Output the value of myAge
    printf("Value of myAge: %d\n", myAge);

    // Output the memory address of myAge
    printf("Memory address of myAge: %p\n", &myAge);

    // Output the memory address stored in ptr
    printf("Value stored in ptr: %p\n", ptr);

    return 0;
}

Output:

Value of myAge: 43

Memory address of myAge: 0x7ffe5367e044

Value stored in ptr: 0x7ffe5367e044

Dereferencing (Pointer Se Value Access Karna)

Jab aapke paas pointer mein kisi variable ka address hota hai, toh aap Dereference Operator (*) ka use karke us address par rakhi actual value ko access ya modify kar sakte hain.

Code Example: Dereferencing

#include <stdio.h>

int main() {
    int myAge = 43;
    int* ptr = &myAge;

    // Reference: Outputting address stored in ptr
    printf("Address: %p\n", ptr);

    // Dereference: Outputting the value of the variable pointed by ptr
    printf("Value: %d\n", *ptr);

    return 0;
}

Output:

Address: 0x7ffe5367e044

Value: 43
