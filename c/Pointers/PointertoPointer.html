Pointer to Pointer (Double Pointer) Kya Hai?

C language mein, Pointer to Pointer (jise Double Pointer bhi kaha jata hai) ek aisa variable hota hai jo kisi **doosre pointer ka memory address** hold karke rakhta hai.

Jaise normal pointer kisi variable ka address rakhta hai, waise hi double pointer kisi pointer ka address rakhta hai. Isse declare karne ke liye double asterisk symbol (**) ka use hota hai.

Key Points:

  • Normal Variable: Data Value Store karta hai.
  • Single Pointer (*ptr): Variable ka Address store karta hai.
  • Double Pointer (**pptr): Single Pointer ka Address store karta hai.

Double Pointer Declaration & Dereferencing

Niche diye gaye example mein dekhein ki kaise hum double asterisk ka upyog karke value aur address access karte hain.

Code Example

#include <stdio.h>

int main() {
    int var = 3000;
    int *ptr;
    int **pptr;

    // Storing address of var in ptr
    ptr = &var;

    // Storing address of ptr in pptr using &
    pptr = &ptr;

    // Accessing value of var
    printf("Value of var = %d\n", var);
    printf("Value using single pointer (*ptr) = %d\n", *ptr);
    printf("Value using double pointer (**pptr) = %d\n\n", **pptr);

    // Accessing Memory Addresses
    printf("Address of var = %p\n", &var);
    printf("Address stored in ptr = %p\n", ptr);
    printf("Address of ptr = %p\n", &ptr);
    printf("Address stored in pptr = %p\n", pptr);

    return 0;
}

Output:

Value of var = 3000

Value using single pointer (*ptr) = 3000

Value using double pointer (**pptr) = 3000


Address of var = 0x7ffe5367e044

Address stored in ptr = 0x7ffe5367e044

Address of ptr = 0x7ffe5367e048

Address stored in pptr = 0x7ffe5367e048

Double Pointer Se Value Modify Karna

Jaise single pointer se hum actual variable ki value change kar sakte hain, waise hi double pointer **pptr ke through bhi hum direct original variable ki value update kar sakte hain.

Code Example: Modifying Value

#include <stdio.h>

int main() {
    int num = 10;
    int *p = &num;
    int **pp = &p;

    // Changing value using double pointer
    **pp = 50;

    printf("New value of num: %d\n", num);

    return 0;
}

Output:

New value of num: 50
