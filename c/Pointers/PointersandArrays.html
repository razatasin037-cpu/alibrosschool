Pointers Aur Arrays Ka Relation

C language mein Arrays aur Pointers aapas mein bahut gahre tarike se jude hue hain. Jab aap kisi array ka naam use karte hain, toh wo actual mein array ke sabse pehle element (index 0) ke memory address ko point kar raha hota hai.

Key Points:

  • Array ka naam ek constant pointer ki tarah kaam karta hai jo first element ka location hold karta hai.
  • Array ke elements contiguous (ek ke baad ek continuous) memory locations par store hote hain.
  • myNumbers aur &myNumbers[0] dono exact same memory address represent karte hain.

Array Elements Ka Memory Address

Niche diye gaye example mein dekhein ki kaise har next element ka memory address 4 bytes (standard integer size) aage badhta hai.

Code Example: Printing Memory Addresses

#include <stdio.h>

int main() {
    int myNumbers[4] = {25, 50, 75, 100};
    int i;

    for (i = 0; i < 4; i++) {
        printf("Element %d Address: %p\n", i, &myNumbers[i]);
    }

    return 0;
}

Output (4 Bytes Offset):

Element 0 Address: 0x7ffe5367e040

Element 1 Address: 0x7ffe5367e044

Element 2 Address: 0x7ffe5367e048

Element 3 Address: 0x7ffe5367e04c

Pointer Arithmetic (Accessing via Pointer)

Aap brackets [ ] ka use kiye bina bhi dereference operator * aur pointer arithmetic ka upyog karke array ke kisi bhi element ko access kar sakte hain.

Pointer Expressions:

1. *myNumbers array ke pehle element ki value deta hai.
2. *(myNumbers + 1) array ke doosre element ki value deta hai.
3. *(myNumbers + 2) array ke teesre element ki value deta hai.

Code Example: Dereferencing Array Pointers

#include <stdio.h>

int main() {
    int myNumbers[4] = {25, 50, 75, 100};

    // Get the value of the first element
    printf("First Element: %d\n", *myNumbers);

    // Get the value of the second element
    printf("Second Element: %d\n", *(myNumbers + 1));

    // Get the value of the third element
    printf("Third Element: %d\n", *(myNumbers + 2));

    return 0;
}

Output:

First Element: 25

Second Element: 50

Third Element: 75

Pointer Ke Sath Loop Chalana

Pointer arithmetic ka use karke hum pooray array par efficiently loop chala sakte hain. 

#include <stdio.h>

int main() {
    int myNumbers[4] = {10, 20, 30, 40};
    int *ptr = myNumbers;
    int i;

    for (i = 0; i < 4; i++) {
        printf("Value at index %d = %d\n", i, *(ptr + i));
    }

    return 0;
}

Output:

Value at index 0 = 10

Value at index 1 = 20

Value at index 2 = 30

Value at index 3 = 40
