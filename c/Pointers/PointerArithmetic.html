Pointer Arithmetic Kya Hai?

Pointer arithmetic C language ka ek powerful feature hai jo hume memory address ke saath mathematical operations karne ki anumati deta hai.

Jab aap kisi pointer mein 1 add ya subtract karte hain, toh wo actual memory mein 1 byte aage ya peeche nahi badhta, balki us data type ke size (jaise int ke liye 4 bytes) ke anusar jump karta hai.

Allowed Operations in Pointer Arithmetic:

  • Increment Operator (ptr++) - Agle memory location par jane ke liye
  • Decrement Operator (ptr--) - Pichhle memory location par aane ke liye
  • Integer Addition (ptr + n) - Multiple steps aage badhne ke liye
  • Integer Subtraction (ptr - n) - Multiple steps pichhe aane ke liye
  • Pointer Comparison (ptr1 == ptr2) - Do addresses ko compare karne ke liye

1. Incrementing & Decrementing Pointers

ptr++ ka upyog karke hum pointer ko agle element ki memory location par shift karte hain.

Code Example: Incrementing Pointer

#include <stdio.h>

int main() {
    int arr[3] = {100, 200, 300};
    int *ptr = arr; // Points to arr[0]

    printf("Value at ptr: %d\n", *ptr);
    printf("Address at ptr: %p\n\n", ptr);

    ptr++; // Moves to arr[1] (jumps 4 bytes ahead)

    printf("Value after ptr++: %d\n", *ptr);
    printf("Address after ptr++: %p\n", ptr);

    return 0;
}

Output:

Value at ptr: 100

Address at ptr: 0x7ffe5367e040


Value after ptr++: 200

Address after ptr++: 0x7ffe5367e044

2. Pointer Addition & Subtraction

Aap kisi pointer mein integer n ko add ya subtract kar ke directly target index location tak pahunch sakte hain.

Code Example: Addition and Subtraction

#include <stdio.h>

int main() {
    int numbers[] = {10, 20, 30, 40, 50};
    int *ptr = numbers;

    // Move 3 elements ahead (Index 3)
    ptr = ptr + 3;
    printf("Value at (ptr + 3): %d\n", *ptr);

    // Move 1 element back (Index 2)
    ptr = ptr - 1;
    printf("Value at (ptr - 1): %d\n", *ptr);

    return 0;
}

Output:

Value at (ptr + 3): 40

Value at (ptr - 1): 30

3. Pointer Comparison

Hum Relational Operators (jaise <, >, ==) ka use karke do pointers ke memory addresses ko compare kar sakte hain. Iska sabse aam upyog array traversal ki boundaries set karne mein hota hai. 

#include <stdio.h>

int main() {
    int arr[4] = {5, 10, 15, 20};
    int *start = arr;
    int *end = &arr[3];

    while (start <= end) {
        printf("Value: %d | Address: %p\n", *start, start);
        start++;
    }

    return 0;
}

Output:

Value: 5 | Address: 0x7ffe5367e040

Value: 10 | Address: 0x7ffe5367e044

Value: 15 | Address: 0x7ffe5367e048

Value: 20 | Address: 0x7ffe5367e04c
