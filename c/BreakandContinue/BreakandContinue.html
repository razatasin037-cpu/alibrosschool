Break aur Continue Kya Hain?

Loops (for, while, do-while) ke normal flow ko control karne ke liye break aur continue statements ka use kiya jata hai.

Break Statement

Loop ko turant poori tarah terminate (stop) kar deta hai, chahe condition abhi bhi true hi kyun na ho.

Continue Statement

Current iteration ko skip karke directly agli iteration par jump kar deta hai.

1. C Break Statement

Pehle humne dekha tha ki break ka use switch statement se bahar nikalne ke liye hota tha. Jab ise kisi loop ke andar condition ke sath lagaya jata hai, toh yeh loop ko wahi rok deta hai.

Code Example: Loop stops when i is 3

#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        if (i == 3) {
            break; // Stop loop completely when i reaches 3
        }
        printf("%d\n", i);
    }

    return 0;
}

Output:

1

2

2. C Continue Statement

continue statement ek specific value ya condition ko skip kar deta hai aur baki bache hue numbers ke liye loop regular chalata hai.

Code Example: Skipping Number 3

#include <stdio.h>

int main() {
    int i;

    for (i = 1; i <= 5; i++) {
        if (i == 3) {
            continue; // Skips printing 3 and moves to next step
        }
        printf("%d\n", i);
    }

    return 0;
}

Output:

1

2

4

5

Break vs Continue Comparison

Feature break continue
Action Loop ko turant end kar deta hai. Sirf current step ko skip karta hai.
Execution Flow Loop ke bahar jump kar deta hai. Loop ke agle iteration par chala jata hai.
Use Case Jab desired item mil jaye ya error ho. Jab kisi unwanted value ko filter/ignore karna ho.

Summary

break keyword poori loop execution rokne ke liye design kiya gaya hai, jabki continue loop ko chalte hue sirf ek part ko bypass karne ke liye use hota hai.
