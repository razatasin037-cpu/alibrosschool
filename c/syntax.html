C Syntax

Syntax ka matlab hota hai kisi programming language ke rules aur structure.

Agar syntax sahi hoga tabhi program compile aur execute hoga.

Basic C Program

Program Explanation

  • #include <stdio.h> - Standard Input Output header file include karta hai.
  • int main() - Program yahin se start hota hai.
  • printf() - Screen par output print karta hai.
  • return 0; - Program successfully complete hone ko batata hai.
  • { } - Curly braces function ka starting aur ending block batate hain.
  • ; - Har statement ke end me semicolon lagana zaruri hota hai.

Important Syntax Rules

  • Har statement ke end me semicolon (;)lagta hai.
  • Main function har C program ka starting point hota hai.
  • Code ko curly braces { } ke andar likha jata hai.
  • Keywords ka spelling change nahi kar sakte.
  • CLanguage case-sensitive hai.
