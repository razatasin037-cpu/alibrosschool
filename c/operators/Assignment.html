Assignment Operators Kya Hain?

**Assignment Operators** ka use kisi variable me value assign (store) karne ke liye kiya jata hai. Right-hand side (RHS) ki value ya expression calculate hokar Left-hand side (LHS) ke variable me store ho jati hai.

variable = expression / value;

Assignment Operators List

Operator Name Equivalent Expression Example (Initial x = 10)
= Simple Assignment x = 5 x becomes 5
+= Add AND Assign x = x + 5 x becomes 15
-= Subtract AND Assign x = x - 3 x becomes 7
* = Multiply AND Assign x = x * 2 x becomes 20
/= Divide AND Assign x = x / 2 x becomes 5
%= Modulus AND Assign x = x % 3 x becomes 1

Compound (Shorthand) Assignment

Jab hum kisi variable me usi ki calculation perform karke dubara value store karte hain, tab **Compound Operators** (+=, -=, etc.) ka use code ko concise aur fast banane ke liye kiya jata hai.

Long Syntax (Standard)

total = total + bonus;

Shorthand Syntax (Recommended)

total += bonus;

Code Example: Assignment Operators

#include <stdio.h>

int main() {
    int num = 10;

    printf("Initial Value: %d\n", num);

    num += 5;  // Equivalent to num = num + 5
    printf("After += 5: %d\n", num);

    num *= 2;  // Equivalent to num = num * 2
    printf("After *= 2: %d\n", num);

    num %= 4;  // Equivalent to num = num % 4
    printf("After %%= 4: %d\n", num);

    return 0;
}

Output:

Initial Value: 10

After += 5: 15

After *= 2: 30

After %= 4: 2

Summary

Assignment operator (=) aur Relational Equality operator (==) ke beech confuse na hon. Single equal value assign karta hai, jabki double equal values compare karta hai.
