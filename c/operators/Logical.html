Logical Operators Kya Hain?

**Logical Operators** ka use multiple conditions ya expressions ko combine karne ke liye kiya jata hai.

Inka result hamesha boolean hota hai: 1 (True) ya 0 (False).

List of Logical Operators

Operator Name Description Example (a = 1, b = 0)
&& Logical AND Result 1 hota hai agar **dono** conditions True hon a && b ➔ 0
|| Logical OR Result 1 hota hai agar **kam se kam ek** condition True ho a || b ➔ 1
! Logical NOT Condition ko reverse (invert) karta hai (True ➔ False, False ➔ True) !a ➔ 0

Short-Circuit Evaluation ⚡

C language me logical operators **Left to Right** evaluate hote hain aur agar pehli condition se result pehle hi confirm ho jaye toh agli condition execute nahi hoti:

AND (&&) Short-Circuit

Agar pehli condition False (0) hai, toh doosri check nahi hoti kyunki result overall False hi hoga.

OR (||) Short-Circuit

Agar pehli condition True (1) hai, toh doosri check nahi hoti kyunki result overall True hi hona hai.

Code Example: Logical Operators

#include <stdio.h>

int main() {
    int age = 22;
    int hasLicense = 1; // 1 = True

    // Logical AND
    if (age >= 18 && hasLicense) {
        printf("Drive kar sakte hain!\n");
    }

    // Logical OR
    int isWeekend = 0;
    int isHoliday = 1;
    if (isWeekend || isHoliday) {
        printf("Aaj chutti hai!\n");
    }

    // Logical NOT
    int isLoggedIn = 0;
    if (!isLoggedIn) {
        printf("Please pehle login karein.\n");
    }

    return 0;
}

Output:

Drive kar sakte hain!

Aaj chutti hai!

Please pehle login karein.

Summary

Logical operators ka mostly use Complex conditions (jaise validation checks) likhne me `if-else` block ke andar hota hai.
