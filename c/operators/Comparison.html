Comparison Operators Kya Hain?

**Comparison (ya Relational) Operators** ka use do values ya variables ko compare karne ke liye kiya jata hai.

C language me Boolean (true/false) built-in data type nahi hota (jab tak <stdbool.h> na use karein). Isliye comparison result integers me aata hai:

  • 1 (True): Agar condition sahi (satisfy) hai.
  • 0 (False): Agar condition galat hai.

List of Comparison Operators

Operator Name Description Example (a = 10, b = 20) Result
== Equal to Check karta hai ki kya dono values barabar hain a == b 0 (False)
!= Not Equal to Check karta hai ki kya dono values barabar nahi hain a != b 1 (True)
> Greater than Check karta hai ki kya pehli value doosri se badi hai a > b 0 (False)
< Less than Check karta hai ki kya pehli value doosri se choti hai a < b 1 (True)
>= Greater than or Equal to Check karta hai ki kya pehli value badi ya barabar hai a >= 10 1 (True)
<= Less than or Equal to Check karta hai ki kya pehli value choti ya barabar hai b <= 15 0 (False)

Common Beginners Mistake ⚠️

❌ Incorrect: Assignment Operator

Single equal (=) value assign karne ke liye hota hai.

if (x = 5) // Always True! Modifies x

✅ Correct: Comparison Operator

Double equal (==) values compare karne ke liye hota hai.

if (x == 5) // Compares x with 5

Code Example: Comparison Operators

#include <stdio.h>

int main() {
    int age = 18;
    int passingScore = 50;
    int userScore = 75;

    // Returns 1 (True) or 0 (False)
    printf("Is eligible to vote? (age >= 18): %d\n", age >= 18);
    printf("Is score equal to passing? (userScore == passingScore): %d\n", userScore == passingScore);
    printf("Has passed test? (userScore >= passingScore): %d\n", userScore >= passingScore);
    printf("Is score not equal to 100?: %d\n", userScore != 100);

    return 0;
}

Output:

Is eligible to vote? (age >= 18): 1

Is score equal to passing? (userScore == passingScore): 0

Has passed test? (userScore >= passingScore): 1

Is score not equal to 100?: 1

Summary

Comparison operators ka mostly use if-else conditions aur loops me control flow structure tay karne ke liye kiya jata hai.
