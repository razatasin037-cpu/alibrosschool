Precedence Aur Associativity Kya Hai?

Jab ek expression me ek se zyada operators (jaise +, *, ==) hote hain, tab C compiler tay karta hai ki pehle kaun sa part solve hoga.

1. Operator Precedence (Priority)

Yeh batata hai ki kis operator ki Priority high hai. Higher priority wala operator pehle solve hota hai (Jaise maths me BODMAS rule me Multiplication * pehle aur Addition + baad me).

2. Operator Associativity (Direction)

Jab do operators ki Priority Same ho (jaise * aur /), tab Associativity batati hai ki expression Left-to-Right (L->R) solve hoga ya Right-to-Left (R->L).

Operator Precedence Table (Highest to Lowest)

Rank Operators Description Associativity
1 (Highest) () [] . -> Parentheses, Array Subscript, Structure Member Left-to-Right
2 ++ -- + - ! ~ (type) sizeof & * Unary operators, Logical NOT, Bitwise NOT, Cast, Address-of, Pointer Dereference Right-to-Left
3 * / % Multiplicative (Multiply, Divide, Modulus) Left-to-Right
4 + - Additive (Addition, Subtraction) Left-to-Right
5 << >> Bitwise Shift Left and Right Left-to-Right
6 < <= > >= Relational Comparison Operators Left-to-Right
7 == != Equality Operators (Equal / Not Equal) Left-to-Right
8 & Bitwise AND Left-to-Right
9 ^ Bitwise XOR Left-to-Right
10 | Bitwise OR Left-to-Right
11 && Logical AND Left-to-Right
12 || Logical OR Left-to-Right
13 ?: Ternary Conditional Operator Right-to-Left
14 = += -= *= /= %= <<= >>= &= ^= |= Assignment Operators Right-to-Left
15 (Lowest) , Comma Operator Left-to-Right

Golden Rule: Parentheses () ka Use Karein!

Aapko poori table yaad rakhne ki zarurat nahi hai! Agar aapko order control karna ho ya code ko clean banana ho, toh **Parentheses ()** ka use karein kyunki inki precedence sabse highest hoti hai.

❌ Confusing & Bug Prone

int result = x + y * z >> 2 & mask;

Samajhna mushkil hai ki pehle kya evaluate hoga.

✅ Clean & Explicit

int result = ((x + (y * z)) >> 2) & mask;

Clearly dikhta hai ki execution flow kya hai.

Code Example: Evaluation Step-by-Step

#include <stdio.h>

int main() {
    int a = 10, b = 20, c = 30, d = 40;
    int res1, res2;

    // Example 1: * has higher precedence than +
    // Evaluates as: 10 + (20 * 30) = 10 + 600 = 610
    res1 = a + b * c;

    // Example 2: () forces + to execute first
    // Evaluates as: (10 + 20) * 30 = 30 * 30 = 900
    res2 = (a + b) * c;

    printf("a + b * c = %d\n", res1);
    printf("(a + b) * c = %d\n", res2);

    // Example 3: Associativity for / and * (Left-to-Right)
    // Evaluates as: (100 / 10) * 2 = 10 * 2 = 20
    int res3 = 100 / 10 * 2;
    printf("100 / 10 * 2 = %d\n", res3);

    return 0;
}

Output:

a + b * c = 610

(a + b) * c = 900

100 / 10 * 2 = 20

Summary

Precedence decides kaun sa operator pehle chalega, aur Associativity decides kis direction se evaluation hoga agar precedence same ho. Unnecessary bugs se bachne ke liye hamesha parentheses () ka use karein.
