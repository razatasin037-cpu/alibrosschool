Arithmetic Operators Kya Hain?

**Arithmetic Operators** ka use numerical values (numbers aur variables) ke beech basic mathematical operations jaise addition, subtraction, multiplication, aur division perform karne ke liye kiya jata hai.

List of Arithmetic Operators

Operator Name Description Example (a = 10, b = 3)
+ Addition Do values ko add karta hai a + b ➔ 13
- Subtraction Pehli value se doosri subtract karta hai a - b ➔ 7
* Multiplication Do values ko multiply karta hai a * b ➔ 30
/ Division Numerator ko denominator se divide karta hai a / b ➔ 3 (Integer Div)
% Modulo (Remainder) Division ke baad ka remainder return karta hai a % b ➔ 1

Important Rules to Remember ⚠️

1. Integer Division Rule

Jab do integers ko divide kiya jata hai (int / int), toh result hamesha int hi aata hai. Decimal part discard (truncate) ho jata hai (e.g., 5 / 2 = 2, not 2.5). Exact value ke liye kam se kam ek operand float ya double hona chahiye.

2. Modulo Operator (%) Restriction

Modulo operator (%) sirf integers ke sath kaam karta hai. Iska use floating-point numbers (float / double) ke sath nahi kar sakte.

Code Example: Basic Arithmetic Operations

#include <stdio.h>

int main() {
    int a = 15;
    int b = 4;

    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d (Integer Division)\n", a / b);
    printf("a %% b = %d (Remainder)\n", a % b);

    // Precise floating division
    printf("Precise Division = %.2f\n", (float)a / b);

    return 0;
}

Output:

a + b = 19

a - b = 11

a * b = 60

a / b = 3 (Integer Division)

a % b = 3 (Remainder)

Precise Division = 3.75

Increment (++) & Decrement (--) Operators

Yeh special unary arithmetic operators hain jo value ko 1 se increase ya decrease karte hain:

Pre-increment / Decrement

++x ya --x

Pehle value modify hoti hai, phir expression me use hoti hai.

Post-increment / Decrement

x++ ya x--

Pehle current value use hoti hai, phir value modify hoti hai.

Summary

Calculations me remander check karne ke liye % use karein (e.g., Even/Odd check), aur division me exact decimal loss rokne ke liye type casting ((float)a / b) zaroor lagayein.
