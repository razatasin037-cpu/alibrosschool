Operators Kya Hain?

**Operator** ek aisa symbol hota hai jo compiler ko specific mathematical, logical ya relational manipulation perform karne ka instruction deta hai.

Jin values par operator kaam karta hai unhe **Operands** kehte hain.
Example: a + b (yahan + operator hai, aur a, b operands hain).

Types of Operators in C

Arithmetic

Basic maths calculations ke liye.

+ - * / %

Relational

Values compare karne ke liye.

== != > < >= <=

Logical

Multiple conditions combine karne ke liye.

&& || !

Assignment

Value variable me assign karne ke liye.

= += -= *= /= %=

Bitwise

Binary level (bits) par kaam karne ke liye.

& | ^ ~ << >>

Special / Misc

Size, pointers, aur conditional logic.

sizeof, ?, &, *

Basic Operators Example

#include <stdio.h>

int main() {
    int a = 10, b = 3;

    // Arithmetic Operator
    printf("Addition: %d\n", a + b);

    // Relational Operator
    printf("Is 'a' greater than 'b'?: %d\n", a > b); // Returns 1 (True)

    return 0;
}

Output:

Addition: 13

Is 'a' greater than 'b'?: 1
