C Language Me Booleans Kya Hain?

Programming me **Boolean** data type ka use conditional values ko store karne ke liye hota hai, jiske paas sirf do possible values hoti hain: true ya false.

C99 standard se pehle C language me built-in boolean type nahi tha. C internal working me boolean ko integers se represent karti hai:

  • 1 (True): Kisi bhi non-zero value ko C true maanti hai.
  • 0 (False): Zero value ko false maana jata hai.

<stdbool.h> Header File

C99 standard me <stdbool.h> header introduce kiya gaya. Is header ko include karne ke baad aap bool keyword aur true / false keywords ka direct istemaal kar sakte hain.

Syntax:

#include <stdbool.h>

bool isProgrammingFun = true;
bool isFishTasty = false;

Booleans Ko Print Kaise Karein?

C me boolean value ko print karne ke liye %d format specifier ka use hota hai kyunki output integer (1 ya 0) ke roop me hi show hota hai. 

#include <stdio.h>
#include <stdbool.h>

int main() {
    bool isCodingAwesome = true;
    bool isSkyGreen = false;

    printf("%d\n", isCodingAwesome); // Returns 1
    printf("%d\n", isSkyGreen);       // Returns 0

    return 0;
}

Output:

1

0

Real-World Code Example

Boolean variables ka mostly use decision making (if-else statements) aur age verification jaise real-world tasks me hota hai: 

#include <stdio.h>
#include <stdbool.h>

int main() {
    int myAge = 20;
    int votingAge = 18;

    // Comparison evaluates to boolean true (1) or false (0)
    bool isOldEnough = myAge >= votingAge;

    if (isOldEnough) {
        printf("Aap Vote dene ke liye eligible hain! 🗳️\n");
    } else {
        printf("Aap abhi Vote nahi de sakte.\n");
    }

    return 0;
}

Output:

Aap Vote dene ke liye eligible hain! 🗳️

Summary

  • C me booleans ke liye <stdbool.h> Include karein.
  • bool keyword declaration ke liye aur true/false values store karne ke liye use hota hai.
  • Print karte time %d format specifier ka use karein (true = 1, false = 0).
