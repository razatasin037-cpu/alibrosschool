Constants Kya Hain?

**Constants** un values ko kehte hain jo program ke execution ke dauran change (modify) nahi ho sakti. Inkis fixed values hoti hain.

Agar aap kisi constant variable ki value change karne ki koshish karenge, toh compiler **Compilation Error** throw karega.

C me Constants Banane Ke 2 Tareeqe

1. const Keyword

Variable declaration ke aage const keyword lagaya jata hai. Isse variable **read-only** ban jata hai.

const data_type var_name = value;

2. #define Preprocessor

Code ke top par `#define` directive use karke symbolic constants create kiye jate hain. Isme memory assign nahi hoti.

#define CONST_NAME value

const vs #define Comparison

Feature const Keyword #define Macro
Data Type Has a specific type (e.g., int, float) No type safety (Text replacement)
Memory Allocation Takes memory (RAM) Does NOT take memory
Scope Obeys block scope ({ }) Global scope (after definition)
Semicolon Required Yes (;) No

Code Example: Using Constants in C

#include <stdio.h>

// 1. Using #define directive
#define PI 3.14159
#define MAX_USERS 100

int main() {
    // 2. Using const keyword
    const int BIRTH_YEAR = 2002;
    const float GRAVITY = 9.8f;

    // BIRTH_YEAR = 2005; // ❌ ERROR: Cannot modify a const variable!

    printf("PI Value: %.5f\n", PI);
    printf("Max Users: %d\n", MAX_USERS);
    printf("Birth Year: %d\n", BIRTH_YEAR);
    printf("Gravity: %.1f m/s^2\n", GRAVITY);

    return 0;
}

Output:

PI Value: 3.14159

Max Users: 100

Birth Year: 2002

Gravity: 9.8 m/s^2

Summary & Best Practice

Best practice ke mutabiq, modern C programs me const keyword ko favor kiya jata hai kyunki yeh **Type Safety** provide karta hai aur debugging easy banata hai. Constant names ko hamesha **UPPERCASE** me likhne ki convention follow karein (e.g., MAX_LIMIT).
