C Variables

Variable ek container hota hai jisme hum data ko store karte hain. Har Variable ka ek Name aur Data Type hota hai jo batata hai ki Variable kis type ka data store karega.

  • int - Whole numbers store karta hai, jaise 123 ya -123.
  • float - Decimal numbers store karta hai, jaise 19.99 ya -19.99.
  • char - Sirf ek single character store karta hai, jaise 'A' ya 'b'. Character hamesha single quotes (' ') ke andar likha jata hai.

Variables Ka Use Kyu Karte Hai?

Agar Variables na hote to har value ko direct code me likhna padta. Isse program ko update karna bahut difficult ho jata. Variables ki madad se hum values ko easily store aur modify kar sakte hain.

Professional software me hazaro Variables use hote hain jisse user information, marks, salary, price aur bahut saara data store kiya jata hai.

Syntax

C Language me Variable banane ke liye pehle Data Type, phir Variable Name aur uske baad value likhi jati hai. 


type variableName = value;
  • type - Variable ka Data Type hota hai, jaise int, float ya char.
  • variableName - Variable ka naam hota hai.
  • value - Variable me store ki jane wali value hoti hai.
  • ; - Har statement ke end me semicolon lagana zaruri hota hai.

Variable Declaration

Variable declare karne ke liye sabse pehle Data Type likha jata hai aur uske baad Variable ka Name likhte hain. 


int age;

float salary;

char grade;

Yaha age Integer Variable hai, salary Float Variable hai aur grade Character Variable hai.

Variable Initialization

Variable ko declare karte hi usme value store karna Initialization kehlata hai. 


int age = 20;

float salary = 25000.50;

char grade = 'A';

Initialization se Variable ke andar starting value store ho jati hai aur baad me zarurat ke hisab se value change bhi ki ja sakti hai.

Example Program 


#include <stdio.h>

int main()
{
    int age = 20;

    printf("Age = %d", age);

    return 0;
}

Output 


Age = 20

Is program me age variable ki value 20 hai. Jab printf() function execute hota hai tab screen par wahi value print hoti hai.

Variable Naming Rules

  • Variable ka naam letter ya underscore (_) se start hona chahiye.
  • Number se variable start nahi ho sakta.
  • Special characters jaise @ # $ % allowed nahi hote.
  • Keywords (int, float, if, while) ko Variable Name nahi bana sakte.
  • Meaningful naam use karna best practice hai, jaise studentAge ya totalMarks.

Best Practices

Hamesha Variable ka naam aisa rakho jisse uska purpose samajh aaye. Chhote aur meaningful names code ko readable banate hain.

Jab bhi possible ho Variable ko declare karte hi initialize karo. Isse garbage values ki problem kam ho jati hai.

Ek hi Variable me alag-alag purpose ka data store karne se bachna chahiye.

Common Mistakes

  • Variable declare karna bhool jana.
  • Wrong Data Type use karna.
  • Keyword ko Variable Name bana dena.
  • Variable initialize na karna.
  • Ek hi naam ke multiple Variables banana.

Real Life Example

Sochiye aap School Management System bana rahe hain. Har Student ka Name, Age, Roll Number aur Marks alag-alag Variables me store kiya jata hai. Jab user data update karta hai tab sirf Variable ki value change hoti hai.

Isi tarah Banking, Hospital, Shopping aur Social Media Applications me bhi lakho Variables use hote hain.

📝 Note

Variable kisi bhi C Program ka important part hai. Agar Variable ka Data Type ya Name galat hoga to program compile hone me error aa sakta hai.

Summary

Variable ek container hota hai jo data ko store karta hai. Har Variable ka Name aur Data Type hota hai.

Variable ko pehle declare kiya jata hai aur uske baad usme value store ki jati hai. Meaningful Variable Names code ko samajhna aur maintain karna easy bana dete hain.

Har programmer ko Variable Declaration, Initialization aur Naming Rules achhi tarah samajhne chahiye kyunki ye C Programming ki basic foundation hai.
