Continue Statement Kya Hai?

JavaScript me continue statement ka use loop ki current iteration ko skip karne ke liye kiya jata hai.

Jab continue execute hota hai, current iteration ka remaining code skip ho jata hai aur loop directly next iteration par chala jata hai.

Continue Syntax 

for (...) {

  if (condition) {
    continue;
  }

  // remaining code
}

Jaise hi continue execute hota hai, current iteration skip ho jati hai aur loop next iteration se continue hota hai.

Continue Example

Is example me hum 1 se 5 tak numbers print karenge, lekin 3 ko skip karenge. 

for (let i = 1; i <= 5; i++) {

  if (i === 3) {
    continue;
  }

  console.log(i);
}

Output: 

1
2
4
5

Example Kaise Kaam Kar Raha Hai?

let i = 1 → Loop 1 se start hota hai.

i <= 5 → Loop 5 tak chalega.

if (i === 3) → Har iteration me check hota hai ki i ki value 3 hai ya nahi.

Jab i = 3 hota hai, condition true ho jati hai.

continue; → Current iteration skip ho jati hai.

Isliye 3 console me print nahi hota aur loop next value 4 par chala jata hai.

Continue Flow

i Value i === 3 Result
1 false Print 1
2 false Print 2
3 true Skip
4 false Print 4
5 false Print 5

Break vs Continue

Break Continue
Loop ko completely stop karta hai. Sirf current iteration skip karta hai.
Next iteration execute nahi hoti. Next iteration normal execute hoti hai.
break; continue;

Important Points

1. continue current iteration ko skip karta hai.

2. Continue loop ko completely stop nahi karta.

3. Continue execute hone ke baad loop next iteration par chala jata hai.

4. continue ko for aur while jaise loops me use kiya ja sakta hai.

5. break aur continue ka kaam alag hai — break stop karta hai, continue skip karta hai.
