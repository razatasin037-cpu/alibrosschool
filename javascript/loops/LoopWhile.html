While Loop Kya Hai?

JavaScript me while loop ka use kisi code ko tab tak repeat karne ke liye kiya jata hai jab tak given condition true hoti hai.

While Loop me sabse pehle condition check hoti hai. Agar condition true hai to loop ka code execute hota hai, aur condition false hote hi loop stop ho jata hai.

While Loop Syntax 

while (condition) {
  // code to execute

  // update value
}

condition → Decide karti hai loop kab tak chalega.

Jab condition true hoti hai, loop execute hota hai.

Jab condition false ho jati hai, loop stop ho jata hai.

While Loop Example

Is example me hum 1 se 5 tak numbers print karenge. 

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

Output: 

1
2
3
4
5

Example Kaise Kaam Kar Raha Hai?

let i = 1 → Sabse pehle i ki starting value 1 set hoti hai.

i <= 5 → JavaScript check karta hai ki i ki value 5 se chhoti ya equal hai ya nahi.

console.log(i) → Current value console me print hoti hai.

i++ → Har iteration ke baad i ki value 1 increase hoti hai.

Jab i ki value 6 ho jati hai, condition 6 <= 5 false ho jati hai aur loop stop ho jata hai.

While Loop Flow

i Value Condition Output
1 1 <= 5 → true 1
2 2 <= 5 → true 2
3 3 <= 5 → true 3
4 4 <= 5 → true 4
5 5 <= 5 → true 5
6 6 <= 5 → false Loop Stop

For Loop vs While Loop

For Loop While Loop
Jab repetitions ka number pata ho. Jab loop condition par depend karta ho.
Initialization, condition aur update ek hi line me hote hain. Initialization aur update alag likhe ja sakte hain.
for (let i = 1; i <= 5; i++) while (i <= 5)

Important Points

1. while loop condition true rehne tak execute hota hai.

2. While Loop me condition code execute hone se pehle check hoti hai.

3. Loop ke andar variable ko update karna important hai.

4. Agar i++ jaise update ko nahi likhenge, to infinite loop ho sakta hai.

5. Condition false hote hi While Loop stop ho jata hai.
