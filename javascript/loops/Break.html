Break Statement Kya Hai?

JavaScript me break statement ka use loop ko turant stop karne ke liye kiya jata hai.

Jab loop ke andar koi specific condition true ho jaye aur hume loop ko aage nahi chalana ho, tab break ka use karte hain.

Break Syntax 

for (...) {

  if (condition) {
    break;
  }

}

Jaise hi break execute hota hai, current loop completely stop ho jata hai.

Break Example

Is example me loop 1 se 10 tak chal sakta hai, lekin jab i ki value 5 hogi tab loop stop ho jayega. 

for (let i = 1; i <= 10; i++) {

  if (i === 5) {
    break;
  }

  console.log(i);
}

Output: 

1
2
3
4

Example Kaise Kaam Kar Raha Hai?

let i = 1 → Loop 1 se start hota hai.

i <= 10 → Loop maximum 10 tak chal sakta hai.

if (i === 5) → Har iteration me check hota hai ki i ki value 5 hai ya nahi.

Jab i = 5 hota hai, condition true ho jati hai.

break; → Loop wahi par completely stop ho jata hai.

Isliye 5 console me print nahi hota, kyunki break pehle execute ho gaya.

Break Flow

i Value i === 5 Result
1 false Print 1
2 false Print 2
3 false Print 3
4 false Print 4
5 true Loop Stop

Important Points

1. break loop ko completely stop karta hai.

2. Break mostly if condition ke saath use hota hai.

3. Break execute hone ke baad loop ki next iteration nahi chalti.

4. break ko for, while aur switch me use kiya ja sakta hai.
