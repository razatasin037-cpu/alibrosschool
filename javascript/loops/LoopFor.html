For Loop Kya Hai?

JavaScript me for loop ka use kisi code ko fixed number of times repeat karne ke liye kiya jata hai. Jab hume pehle se pata ho ki loop kitni baar chalana hai, tab for loop bahut useful hota hai.

Example ke liye, agar hume 1 se 5 tak numbers print karne hain, to baar-baar console.log() likhne ki jagah ek for loop ka use kar sakte hain.

For Loop Syntax 

for (initialization; condition; update) {
  // code to execute
}

initialization → Loop ki starting value set karta hai.

condition → Decide karta hai loop kab tak chalega.

update → Har iteration ke baad variable ki value change karta hai.

For Loop Example

Is example me hum 1 se 5 tak numbers print karenge. 

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Output: 

1
2
3
4
5

Example Kaise Kaam Kar Raha Hai?

let i = 1 → Sabse pehle i ki value 1 set hoti hai.

i <= 5 → JavaScript check karta hai ki i ki value 5 se chhoti ya equal hai ya nahi.

console.log(i) → Current value console me print hoti hai.

i++ → Har round ke baad i ki value 1 increase hoti hai.

Jab i ki value 6 ho jati hai, condition 6 <= 5 false ho jati hai aur loop stop ho jata hai.

For Loop Flow

i Value Condition Output
1 1 <= 5 → true 1
2 2 <= 5 → true 2
3 3 <= 5 → true 3
4 4 <= 5 → true 4
5 5 <= 5 → true 5
6 6 <= 5 → false Loop Stop

Important Points

1. For Loop repeated code ko execute karne ke liye use hota hai.

2. For Loop me initialization, condition aur update important parts hain.

3. i++ variable ki value ko 1 se increase karta hai.

4. Condition false hote hi loop stop ho jata hai.
