Loop Kya Hai?

JavaScript me Loop ka use same code ko baar-baar execute karne ke liye kiya jata hai. Loop ki help se hum repeated tasks ko easily perform kar sakte hain aur same code ko baar-baar likhne ki zarurat nahi hoti.

Example ke liye, agar hume 1 se 10 tak numbers print karne hain, to 10 baar console.log() likhne ki jagah ek Loop ka use karke easily numbers print kar sakte hain.

Types of Loops

Loop Use
for Jab pata ho loop kitni baar chalana hai.
while Condition true rehne tak code chalata hai.
do...while Code kam se kam ek baar execute hota hai.

1. For Loop

For Loop tab use hota hai jab hume pata ho ki loop kitni baar chalana hai.

Syntax 

for (initialization; condition; update) {
  // code
}

Example 

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Output:

1
2
3
4
5

2. While Loop

While Loop tab tak execute hota hai jab tak given condition true hoti hai.

Syntax 

while (condition) {
  // code
}

Example 

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

Output:

1
2
3
4
5

3. Do While Loop

Do While Loop me code pehle execute hota hai aur condition baad me check hoti hai.

Syntax 

do {
  // code
} while (condition);

Example 

let i = 1;

do {
  console.log(i);
  i++;
} while (i <= 5);

Output:

1
2
3
4
5

Important Points

1. Loop same code ko baar-baar execute karta hai.

2. for fixed repetitions ke liye useful hai.

3. while condition true rehne tak chalta hai.

4. do...while minimum ek baar execute hota hai.
