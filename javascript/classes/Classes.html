JavaScript Class Kya Hai?

JavaScript me class ek blueprint hota hai jiske through hum multiple objects create kar sakte hain.

Class ke andar properties aur methods define kiye ja sakte hain.

Classes Kyu Use Karte Hain?

1. Same structure ke multiple objects create karne ke liye.

2. Code ko organized rakhne ke liye.

3. Properties aur methods ko ek jagah group karne ke liye.

4. Object-Oriented Programming me reusable code banane ke liye.

5. Inheritance ke through existing class ko reuse karne ke liye.

Class Syntax 

class ClassName {

  constructor() {

    // properties

  }

  methodName() {

    // method code

  }

}

Simple Class Example 

class User {

  constructor() {

    this.name =
      "Ali";

  }

}

const user1 =
  new User();

console.log(
  user1.name
);
Ali

Class Method

Class ke andar functions ko methods kehte hain. 

class User {

  constructor(name) {

    this.name =
      name;

  }

  greet() {

    console.log(
      "Hello "
      + this.name
    );

  }

}

const user =
  new User(
    "Ali"
  );

user.greet();
Hello Ali

Real Project Product Class 

class Product {

  constructor(
    name,
    price,
    stock
  ) {

    this.name =
      name;

    this.price =
      price;

    this.stock =
      stock;

  }

  getTotalValue() {

    return
      this.price *
      this.stock;

  }

}

const laptop =
  new Product(
    "Laptop",
    50000,
    5
  );

console.log(
  laptop.getTotalValue()
);
250000

Important Class Keywords

Keyword Use
class Class create karta hai.
new Class ka object create karta hai.
constructor Object initialize karta hai.
this Current object ko refer karta hai.
extends Inheritance ke liye use hota hai.
super Parent class ke constructor/method ko access karta hai.
static Method ko class se directly call karne deta hai.

Important Points

1. Class ek blueprint hota hai.

2. class keyword se class create hoti hai.

3. new keyword se class ka object create hota hai.

4. constructor() object create hote hi automatically run hota hai.

5. this current object ko refer karta hai.

6. Ek class se multiple objects create kiye ja sakte hain.

7. Class ke andar methods define kiye ja sakte hain.

8. Classes reusable aur organized code likhne me help karti hain.

9. Class declaration ko use karne se pehle define karna chahiye.
