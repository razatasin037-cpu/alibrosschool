Class Method Kya Hai?

JavaScript class ke andar jo functions define kiye jaate hain, unhe methods kehte hain.

Methods ka use object ke data ke saath koi action perform karne ke liye hota hai.

Class Method Syntax 

class User {

  methodName() {

    // method code

  }

}

Basic Method Example 

class User {

  greet() {

    console.log(
      "Hello User"
    );

  }

}

const user =
  new User();

user.greet();
Hello User

Method Me this Ka Use

Class method ke andar this current object ki properties ko access karta hai. 

class User {

  constructor(name) {

    this.name =
      name;

  }

  greet() {

    console.log(
      "Hello " +
      this.name
    );

  }

}

const user =
  new User(
    "Ali"
  );

user.greet();
Hello Ali

Stock Remove Method 

class Product {

  constructor(stock) {

    this.stock =
      stock;

  }

  removeStock(quantity) {

    if (
      quantity >
      this.stock
    ) {

      return
        
          "Not enough stock"
        ;

    }

    this.stock -=
      quantity;

    return
      
        "Stock updated"
      ;

  }

}

const product =
  new Product(
    10
  );

console.log(
  product.removeStock(
    3
  )
);

console.log(
  product.stock
);
Stock updated
7

Getter Method

get keyword se getter method create hota hai. Getter ko property ki tarah access kiya jata hai. 

class User {

  constructor(
    firstName,
    lastName
  ) {

    this.firstName =
      firstName;

    this.lastName =
      lastName;

  }

  get fullName() {

    return
      this.firstName +
      " " +
      this.lastName;

  }

}

const user =
  new User(
    "Ali",
    "Khan"
  );

console.log(
  user.fullName
);
Ali Khan

Setter Method

set keyword se setter method create hota hai. Iska use property ki value update karne me kiya ja sakta hai. 

class User {

  constructor(name) {

    this._name =
      name;

  }

  set name(value) {

    this._name =
      value;

  }

  get name() {

    return
      this._name;

  }

}

const user =
  new User(
    "Ali"
  );

user.name =
  "Ahmed";

console.log(
  user.name
);
Ahmed

Real Project Cart Example 

class Cart {

  constructor() {

    this.items = [];

  }

  addItem(product) {

    this.items.push(
      product
    );

  }

  getTotal() {

    return
      this.items.reduce(
        (total, item) =>
          total + item.price,
        0
      );

  }

}

const cart =
  new Cart();

cart.addItem({
  name:
    "Mouse",

  price:
    500
});

cart.addItem({
  name:
    "Keyboard",

  price:
    1000
});

console.log(
  cart.getTotal()
);
1500

User Login Method Example 

class User {

  constructor(
    email,
    password
  ) {

    this.email =
      email;

    this.password =
      password;

  }

  login(
    email,
    password
  ) {

    if (

        this.email
      &&
      password ===

      return

        ;

        "Invalid Credentials"
      ;

  }

}

      "123456"
    
  );

    ,
    
      "123456"
    
  )
);
Login Successful

Method vs Normal Function

Method Function
Class ya object ke andar hota hai. Independent bhi ho sakta hai.
user.greet() greet()
Object ke data ko easily access kar sakta hai. Data parameters ke through mil sakta hai.

Important Points

1. Class ke andar define kiya gaya function method kehlata hai.

2. Method ko object ke through call kiya ja sakta hai.

3. Methods parameters accept kar sakte hain.

4. Methods values return kar sakte hain.

5. this se current object ki properties access hoti hain.

6. Ek class me multiple methods ho sakte hain.

7. Ek method se dusra method this.method() ke through call kiya ja sakta hai.

8. get se getter method banaya ja sakta hai.

9. set se setter method banaya ja sakta hai.
