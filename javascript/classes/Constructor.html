Constructor Kya Hai?

JavaScript class me constructor() ek special method hota hai.

Jab bhi new keyword se class ka object create hota hai, constructor automatically execute hota hai.

Constructor Syntax 

class User {

  constructor() {

    // initialization code

  }

}

Basic Constructor Example 

class User {

  constructor() {

    console.log(
      "Constructor called"
    );

  }

}

const user1 =
  new User();
Constructor called

Constructor Me Property Banana 

class User {

  constructor() {

    this.name =
      "Ali";

    this.age =
      20;

  }

}

const user =
  new User();

console.log(
  user.name
);

console.log(
  user.age
);
Ali
20

Constructor Me this Ka Use

Constructor + Method Example 

class Product {

  constructor(
    price,
    quantity
  ) {

    this.price =
      price;

    this.quantity =
      quantity;

  }

  total() {

    return
      this.price *
      this.quantity;

  }

}

const product =
  new Product(
    500,
    4
  );

console.log(
  product.total()
);
2000

Ek Class Me Kitne Constructor?

Ek JavaScript class me sirf ek constructor() method ho sakta hai. Agar ek hi class me do constructors define karoge to syntax error milega.

Wrong Example 

class User {

  constructor() {

  }

  constructor(name) {

    this.name =
      name;

  }

}
SyntaxError:
A class may only have one constructor

Constructor Me Validation 

class Product {

  constructor(
    name,
    price
  ) {

    if (price < 0) {

      throw new Error(
        
          "Price cannot be negative"
        
      );

    }

    this.name =
      name;

    this.price =
      price;

  }

}

Constructor vs Normal Method

Constructor Normal Method
Object create hote hi automatically run hota hai. Manually call karna padta hai.
constructor() showUser()
Initial properties set karta hai. Specific work perform karta hai.
Class me ek hi constructor hota hai. Multiple methods ho sakte hain.

Important Points

1. constructor() class ka special method hai.

2. Constructor object create hote hi automatically execute hota hai.

3. new keyword constructor ko trigger karta hai.

4. this current object ko refer karta hai.

5. Constructor parameters se different objects ko different values di ja sakti hain.

6. Constructor parameters me default values di ja sakti hain.

7. Ek class me sirf ek constructor method ho sakta hai.

8. Constructor me basic validation bhi ki ja sakti hai.

9. Bahut saare parameters ke liye object destructuring useful ho sakti hai.
