Static Method Kya Hai?

JavaScript class me static keyword ka use aise method banane ke liye hota hai jo object ke bajaye directly class se call hota hai.

Static method use karne ke liye object banana zaroori nahi hota.

Static Method Syntax 

class ClassName {

  static methodName() {

    // code

  }

}

Basic Static Method Example 

class User {

  static greet() {

    console.log(
      "Hello User"
    );

  }

}

User.greet();
Hello User

Object Banana Zaroori Nahi

Static method ko directly class ke naam se call kiya jata hai. 

class Calculator {

  static add(
    a,
    b
  ) {

    return
      a + b;

  }

}

console.log(
  Calculator.add(
    10,
    20
  )
);
30

Static Method Object Se Call Nahi Hota 

class User {

  static greet() {

    console.log(
      "Hello"
    );

  }

}

const user =
  new User();

user.greet();
TypeError:
user.greet is not a function

Correct Way

Wrong 

const user =
  new User();

user.greet();

Correct 

User.greet();

Normal Method vs Static Method

Normal Method 

class User {

  greet() {

    return
      "Hello";

  }

}

const user =
  new User();

user.greet();

Static Method 

class User {

  static greet() {

    return
      "Hello";

  }

}

User.greet();

Normal vs Static Method

Normal Method Static Method
Object se call hota hai. Class se directly call hota hai.
user.show() User.show()
Instance data ke saath kaam karta hai. Class-level utility work ke liye useful hai.
Object banana padta hai. Object banana zaroori nahi hai.

Static Property Ko Static Method Me Use Karna 

class User {

  static role =
    "Admin";

  static showRole() {

    return
      this.role;

  }

}

console.log(
  User.showRole()
);
Admin

Static Method Me this

Static method ke andar this normal instance object ko refer nahi karta. Static method class ke context me call hone par this class ko refer karta hai. 

class App {

  static name =
    "Stockify";

  static getName() {

    return
      this.name;

  }

}

console.log(
  App.getName()
);

Static Method With Inheritance

Child class parent class ke static methods ko bhi access kar sakti hai. 

class User {

  static info() {

    return
      
        "User Class"
      ;

  }

}

class Admin
  extends User {

}

console.log(
  Admin.info()
);
User Class

Static Method Instance Property Directly Access Nahi Karta

Static method kisi particular object se attached nahi hota, isliye normal instance property ko this.name se directly access karna expected instance value nahi deta. 

class User {

  constructor(name) {

    this.name =
      name;

  }

  static showName() {

    console.log(
      this.name
    );

  }

}

Agar object ka data chahiye to object ko static method me parameter ke roop me pass kar sakte hain.

Object Ko Static Method Me Pass Karna 

class User {

  constructor(name) {

    this.name =
      name;

  }

  static showName(
    user
  ) {

    return
      user.name;

  }

}

const user =
  new User(
    "Ali"
  );

console.log(
  User.showName(user)
);
Ali

Static Method Kab Use Karein?

1. Jab method ko kisi specific object ke data ki zarurat na ho.

2. Utility/helper functions banane ke liye.

3. Validation methods ke liye.

4. Calculation helpers ke liye.

5. Object create karne wale factory methods ke liye.

6. Class-level common data ya behavior ke liye.

Important Points

1. static keyword class-level method create karta hai.

2. Static method ko class name se directly call kiya jata hai.

3. Static method call karne ke liye object banana zaroori nahi hai.

4. Normal object se static method directly call nahi hota.

5. Static methods parameters receive aur value return kar sakte hain.

6. Static properties bhi define ki ja sakti hain.

7. Static method ke andar this class ko refer kar sakta hai.

8. Ek static method dusre static method ko call kar sakta hai.

9. Child class inherited static methods ko access kar sakti hai.

10. Utility, validation aur calculation functions ke liye static methods useful hote hain.
