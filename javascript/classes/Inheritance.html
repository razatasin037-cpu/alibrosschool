Inheritance Kya Hai?

JavaScript me inheritance ka matlab hai ek class dusri class ki properties aur methods ko reuse kar sakti hai.

Iske liye extends keyword use hota hai.

Inheritance Kyu Use Karte Hain?

1. Existing code ko reuse karne ke liye.

2. Same code baar-baar likhne se bachne ke liye.

3. Parent aur child classes ke beech relationship banane ke liye.

4. Code ko organized aur maintainable rakhne ke liye.

5. Child class me extra features add karne ke liye.

super() Kya Hai?

Child class ke constructor me parent class ka constructor call karne ke liye super() use hota hai.

super() Constructor Example 

class User {

  constructor(name) {

    this.name =
      name;

  }

}

class Admin
  extends User {

  constructor(
    name,
    role
  ) {

    super(name);

    this.role =
      role;

  }

}

const admin =
  new Admin(
    "Ali",
    "Admin"
  );

console.log(
  admin.name
);

console.log(
  admin.role
);
Ali
Admin

super() Important Kyu Hai?

Derived class ke constructor me this use karne se pehle super() call karna zaroori hota hai. 

class Admin
  extends User {

  constructor(
    name,
    role
  ) {

    super(name);

    this.role =
      role;

  }

}

Wrong super() Example 

class User {

  constructor(name) {

    this.name =
      name;

  }

}

class Admin
  extends User {

  constructor(
    name,
    role
  ) {

    // Wrong

    this.role =
      role;

    super(name);

  }

}

Derived constructor me this ko super() se pehle use nahi karna chahiye.

class User {

      email;

  extends User {

Product → DigitalProduct Example 

class Product {

  constructor(
    name,
    price
  ) {

    this.name =
      name;

    this.price =
      price;

  }

  getInfo() {

    return
      this.name +
      " - ₹" +
      this.price;

  }

}

class DigitalProduct
  extends Product {

  constructor(
    name,
    price,
    fileSize
  ) {

    super(
      name,
      price
    );

    this.fileSize =
      fileSize;

  }

  download() {

    return
      
        "Downloading "
       +
      this.name;

  }

}

const course =
  new DigitalProduct(
    
      "JavaScript Course"
    ,
    999,
    "2GB"
  );

console.log(
  course.getInfo()
);

console.log(
  course.download()
);
JavaScript Course - ₹999
Downloading JavaScript Course

extends vs super

Keyword Use
extends Child class ko parent class se inherit karata hai.
super() Parent constructor ko call karta hai.
super.method() Parent class ka method call karta hai.

Important Points

1. Inheritance existing class ke code ko reuse karne deta hai.

2. extends se child class parent class inherit karti hai.

3. Child object parent class ke methods use kar sakta hai.

4. Child class apne extra properties aur methods bhi rakh sakti hai.

5. super() parent constructor ko call karta hai.

6. Derived constructor me this use karne se pehle super() call karna hota hai.

7. super.method() parent method ko call kar sakta hai.

8. Child class parent method ko override kar sakti hai.

9. JavaScript me multilevel inheritance possible hai.
