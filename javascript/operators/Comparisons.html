Comparison Operators Kya Hain?

JavaScript me Comparison Operators ka use do values ko compare karne ke liye kiya jata hai.

Comparison ka result hamesha Boolean value hota hai: true ya false.

List of Comparison Operators

Operator Name Example Result
== Equal To 10 == "10" true
=== Strict Equal To 10 === "10" false
!= Not Equal To 10 != 5 true
!== Strict Not Equal 10 !== "10" true
> Greater Than 20 > 10 true
< Less Than 5 < 10 true
>= Greater Than or Equal 10 >= 10 true
<= Less Than or Equal 8 <= 10 true

Basic Comparison Example

Comparison operator condition check karta hai aur true ya false return karta hai. 

let a = 10;
let b = 20;

console.log(a == b);
console.log(a < b);
console.log(a > b);

Output:

false
true
false

== aur === me Difference

== sirf value ko compare karta hai, jabki === value ke saath data type bhi compare karta hai. 

let x = 10;

console.log(x == "10");
console.log(x === "10");

Output:

true
false

10 == "10" → true, kyunki value same hai.

10 === "10" → false, kyunki ek number hai aur doosra string.

!= aur !== Example 

let num = 10;

console.log(num != 5);
console.log(num != "10");
console.log(num !== "10");

Output:

true
false
true

Greater Than aur Less Than 

let age = 18;

console.log(age > 15);
console.log(age < 20);
console.log(age >= 18);
console.log(age <= 17);

Output:

true
true
true
false

Comparison Operator With If Else

Comparison operators ka sabse common use if else conditions me hota hai. 

let age = 18;

if (age >= 18) {
  console.log("You are eligible");
} else {
  console.log("You are not eligible");
}

Output:

You are eligible

Student Marks Example 

let marks = 75;

if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

Output:

Pass

Important Note

JavaScript me comparison karte waqt generally === aur !== use karna better hota hai, kyunki ye value ke saath data type bhi check karte hain. 

let a = 5;

console.log(a === 5);     // true

console.log(a === "5");   // false
