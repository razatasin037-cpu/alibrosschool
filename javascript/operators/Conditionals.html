Conditionals Kya Hain?

JavaScript me Conditionals ka use kisi condition ke basis par decision lene ke liye kiya jata hai.

Agar condition true hoti hai to ek block execute hota hai, aur agar false hoti hai to doosra block execute ho sakta hai.

JavaScript Conditional Statements

Statement Use
if Condition true hone par code execute karta hai.
if...else True aur false dono conditions handle karta hai.
else if Multiple conditions check karne ke liye use hota hai.
nested if Ek if statement ke andar doosra if statement.
? : Short form me if else likhne ke liye.

1. If Statement

if statement tab execute hota hai jab condition true ho. 

let age = 20;

if (age >= 18) {
  console.log("You are eligible");
}

Output:

You are eligible

2. If Else Statement

Agar condition true hai to if block chalega, warna else block chalega. 

let age = 15;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Output:

Minor

3. Else If Statement

Jab multiple conditions check karni ho tab else if use kiya jata hai. 

let marks = 75;

if (marks >= 80) {
  console.log("Grade A");
} else if (marks >= 60) {
  console.log("Grade B");
} else if (marks >= 40) {
  console.log("Grade C");
} else {
  console.log("Fail");
}

Output:

Grade B

4. Even or Odd Example 

let number = 10;

if (number % 2 === 0) {
  console.log("Even Number");
} else {
  console.log("Odd Number");
}

Output:

Even Number

number % 2 === 0 check karta hai ki number ko 2 se divide karne par remainder 0 aata hai ya nahi.

5. Positive, Negative or Zero 

let number = -5;

if (number > 0) {
  console.log("Positive Number");
} else if (number < 0) {
  console.log("Negative Number");
} else {
  console.log("Zero");
}

Output:

Negative Number

6. Nested If

Jab ek if statement ke andar doosra if likha jata hai, use Nested If kehte hain. 

let age = 20;
let hasId = true;

if (age >= 18) {

  if (hasId === true) {
    console.log("Entry Allowed");
  } else {
    console.log("ID Required");
  }

} else {
  console.log("Age is below 18");
}

Output:

Entry Allowed

7. Multiple Conditions

Logical operator && ka use karke ek saath multiple conditions check kar sakte hain. 

let username = "admin";
let password = "1234";

if (username === "admin" && password === "1234") {
  console.log("Login Successful");
} else {
  console.log("Invalid Username or Password");
}

Output:

Login Successful

8. Ternary Operator

Ternary operator simple if else ka short form hota hai. 

let age = 20;

let result = age >= 18
  ? "Adult"
  : "Minor";

console.log(result);

Output:

Adult

Syntax: 

condition ? true value : false value;

9. Student Result Example 

let marks = 55;

if (marks >= 80) {
  console.log("Excellent");
} else if (marks >= 60) {
  console.log("Good");
} else if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

Output:

Pass

Important Points

1. Condition ka result true ya false hota hai.

2. if ke andar wahi code execute hota hai jab condition true ho.

3. Multiple conditions ke liye else if use kar sakte hain.

4. Comparison ke liye preferably === use karo.

5. Simple if else ko short me likhne ke liye ternary operator use kar sakte ho.
