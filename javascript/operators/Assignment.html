Assignment Operators Kya Hain?

JavaScript me Assignment Operators ka use kisi variable me value assign karne ke liye kiya jata hai.

Sabse basic assignment operator = hai. Iske alawa +=, -=, *=, /= jaise operators bhi hote hain.

List of Assignment Operators

Operator Example Same As Description
= x = 10 x = 10 Variable me value assign karta hai
+= x += 5 x = x + 5 Existing value me new value add karta hai
-= x -= 5 x = x - 5 Existing value se value subtract karta hai
*= x *= 5 x = x * 5 Existing value ko multiply karta hai
/= x /= 5 x = x / 5 Existing value ko divide karta hai
%= x %= 5 x = x % 5 Division ka remainder assign karta hai
**= x **= 2 x = x ** 2 Variable ki power calculate karta hai

Basic Assignment Operator

Equal sign = ka use variable ke andar value store karne ke liye hota hai. 

let age = 20;

let name = "Prawez";

let course = "JavaScript";

console.log(age);
console.log(name);
console.log(course);

Output:

20
Prawez
JavaScript

Addition Assignment (+=)

+= operator existing value me dusri value add karta hai. 

let x = 10;

x += 5;

console.log(x);

Output:

15

Iska same meaning hai: x = x + 5

Subtraction Assignment (-=) 

let x = 20;

x -= 5;

console.log(x);

Output:

15

Assignment Operators Example

Ek hi variable par alag-alag assignment operators ka use: 

let num = 10;

num += 5;   
console.log(num); // 15

num -= 3;
console.log(num); // 12

num *= 2;
console.log(num); // 24

num /= 4;
console.log(num); // 6

num %= 4;
console.log(num); // 2

num **= 3;
console.log(num); // 8

Real Life Example

Maan lo ek student ke paas initially 100 marks hain aur usko 20 bonus marks milte hain. 

let marks = 100;

marks += 20;

console.log(marks);

Output:

120

Important Note

Assignment operator = aur comparison operator == ya === alag-alag hote hain. 

// Assignment
let x = 10;

// Comparison
x == 10;

// Strict Comparison
x === 10;
