JavaScript Operators Kya Hote Hain?

JavaScript Operators vishesh symbols (jaise +, -, *, =) hote hain jinaka upayog variables aur values par computation, logic, ya data modification karne ke liye kiya jata hai.

Misaal ke taur par: Expression x = 10 + 5 me + aur = operators hain, jabki 10, 5, aur x ko Operands kaha jata hai.

Anatomy of an Operation:

x Operand = Operator 10 Operand + Operator 5 Operand

Types of JavaScript Operators

Arithmetic Operators

Math calculations ke liye: Addition, Subtraction, Multiplication, Division, etc.

+ , - , * , / , % , **

Assignment Operators

Variables me values assign aur update karne ke liye use kiye jaate hain.

= , += , -= , *= , /=

Comparison Operators

Do values ya expressions ko compare karke Boolean (`true`/`false`) result dete hain.

== , === , != , > , <

Logical Operators

Multiple conditions ko combine karke decision making ke liye.

&& (AND) , || (OR) , ! (NOT)

String Concatenation

Text strings ko aapas me jodne ke liye `+` operator ka use hota hai.

"Hello " + "World"

Conditional (Ternary)

`if-else` ka inline shortcut operator (`condition ? true : false`).

(age >= 18) ? "Adult" : "Minor"

Operators Code Examples

Dekhiye ki alag-alag operators real code me kaise kaam karte hain: 

// 1. Arithmetic Operators
let a = 10;
let b = 3;
let sum = a + b;       // 13
let remainder = a % b; // 1

// 2. Assignment Operator
let x = 5;
x += 2;               // x ab 7 ban jayega (x = x + 2)

// 3. String Operator (Concatenation)
let text1 = "John";
let text2 = "Doe";
let fullName = text1 + " " + text2; // "John Doe"

// 4. Comparison Operator
let isGreater = (a > b); // true
