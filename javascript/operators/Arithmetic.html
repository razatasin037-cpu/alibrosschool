Arithmetic Operators Kya Hain?

Arithmetic Operators ka upayog numbers (literals ya variables) par ganitiya (mathematical) calculations karne ke liye kiya jata hai.

Inme basic addition, subtraction se lekar exponentiation (power) aur modulus (remainder) jaise advanced operations shamil hain.

List of Arithmetic Operators

Operator Name Description Example
+ Addition Do numbers ko jodta hai 10 + 5 = 15
- Subtraction Ek number se doosra ghatata hai 10 - 5 = 5
* Multiplication Numbers ko guna karta hai 10 * 5 = 50
** Exponentiation Power calculate karta hai (ES6) 10 ** 2 = 100
/ Division Numbers ko bhaag deta hai 10 / 5 = 2
% Modulus Division ka remainder (shesh) deta hai 10 % 3 = 1
++ Increment Value me 1 jodta hai x++ (x = x + 1)
-- Decrement Value se 1 ghatata hai x-- (x = x - 1)

Arithmetic Code Example

Niche diye gaye example me dekhiye ki JavaScript me arithmetic operations kaise execute hote hain: 

let a = 100;
let b = 50;

let add = a + b;        // Output: 150
let sub = a - b;        // Output: 50
let mult = a * b;       // Output: 5000
let div = a / b;        // Output: 2
let mod = a % 30;       // Output: 10

let x = 5;
x++;                    // x ab 6 ho gaya
let z = x ** 2;         // Output: 36 (6 * 6)

Operator Precedence (Niyam)

Jab ek se zyada operators ek sath hote hain, to **BODMAS** rule ke mutabiq Multiplication (*) aur Division (/) ko Addition (+) aur Subtraction (-) se pehle calculate kiya jata hai. 

let res1 = 100 + 50 * 3;     // Output: 250 (Pehle 50 * 3 = 150, fir + 100)
let res2 = (100 + 50) * 3;   // Output: 450 (Pehle Parentheses calculation)
