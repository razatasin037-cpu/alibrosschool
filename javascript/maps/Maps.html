Map Kya Hai?

JavaScript me Map ek collection hai jo data ko key → value pairs me store karta hai.

Object ki tarah Map bhi key-value data store karta hai, lekin Map me key String ke alawa Number, Object ya kisi aur value type ki bhi ho sakti hai.

Map Syntax 

const myMap =
  new Map();

Simple Map Example 

const student =
  new Map();

student.set(
  "name",
  "Ali"
);

student.set(
  "age",
  20
);

console.log(student);

Example Output:

Map(2) {
  "name" => "Ali",
  "age" => 20
}

Map With Initial Values

Map create karte waqt Array of key-value pairs pass kar sakte hain. 

const student =
  new Map([
    [
      "name",
      "Ali"
    ],
    [
      "age",
      20
    ],
    [
      "course",
      "JavaScript"
    ]
  ]);

console.log(student);

set()

set() Map me new key-value pair add karta hai. 

const user =
  new Map();

user.set(
  "name",
  "Rahul"
);

console.log(user);

get()

get() key ke through Map ki value return karta hai. 

const student =
  new Map();

student.set(
  "name",
  "Ali"
);

console.log(
  student.get(
    "name"
  )
);

Output:

Ali

Existing Value Update Karna

Same key par dobara set() karne par existing value update ho jati hai. 

const student =
  new Map();

student.set(
  "age",
  20
);

student.set(
  "age",
  21
);

console.log(
  student.get(
    "age"
  )
);

Output:

21

has()

has() check karta hai ki given key Map me exist karti hai ya nahi. 

const student =
  new Map([
    [
      "name",
      "Ali"
    ]
  ]);

console.log(
  student.has(
    "name"
  )
);

console.log(
  student.has(
    "age"
  )
);

Output:

true
false

size Property

size Map ke total entries ki count return karta hai. 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20],
    ["city", "Ranchi"]
  ]);

console.log(student.size);

Output:

3

console.log(

Object As Map Key

Map ki key ek Object bhi ho sakti hai. 

const user = {
  id: 1
};

const data =
  new Map();

data.set(
  user,
  "Admin"
);

console.log(
  data.get(user)
);

Output:

Admin

delete() 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

student.delete(
  "age"
);

console.log(student);

Result:

Map(1) {"name" => "Ali"}

clear()

clear() Map ki saari entries remove karta hai. 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

student.clear();

console.log(student.size);

Output:

0

Loop Through Map 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20],
    ["city", "Ranchi"]
  ]);

for (
  const [key, value]
  of
  student
) {
  console.log(key, value);
}

Output:

name Ali
age 20
city Ranchi

Map forEach() 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

student.forEach(
  (value, key) => {
    console.log(key, value);
  }
);
name Ali
age 20

Object vs Map

Object Map
Keys mainly String ya Symbol hoti hain. Keys kisi bhi value type ki ho sakti hain.
user.name map.get("name")
Property add assignment se. Entry add set() se.
Property count ke liye extra method chahiye. size directly available hai.

Set vs Map

Set Map
Unique values store karta hai. Key-value pairs store karta hai.
set.add(value) map.set(key, value)
set.has(value) map.has(key)

Important Points

1. new Map() se Map create hota hai.

2. Map data ko key → value pairs me store karta hai.

3. set() entry add ya update karta hai.

4. get() key ki value return karta hai.

5. has() key available hai ya nahi check karta hai.

6. delete() specific entry remove karta hai.

7. clear() complete Map empty karta hai.

8. size Map ki total entries ki count deta hai.

9. Map me Object, Number aur String sab keys ban sakte hain.
