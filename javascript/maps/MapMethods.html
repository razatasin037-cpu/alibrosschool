Map Methods Kya Hain?

JavaScript Map Methods ka use Map ke andar data add, read, update, delete aur iterate karne ke liye hota hai.

Important methods hain set(), get(), has(), delete(), clear(), keys(), values() aur entries().

Map Methods List

Method / Property Use
set() Key-value pair add ya update karta hai.
get() Key ki value return karta hai.
has() Key exist karti hai ya nahi check karta hai.
delete() Specific entry remove karta hai.
clear() Map ki saari entries remove karta hai.
keys() Map keys ka iterator return karta hai.
values() Map values ka iterator return karta hai.
entries() Key-value pairs ka iterator return karta hai.
forEach() Har Map entry par callback run karta hai.
size Total entries ki count deta hai.

set()

set() Map me new key-value pair add karta hai. 

const student =
  new Map();

student.set(
  "name",
  "Ali"
);

student.set(
  "age",
  20
);

console.log(student);

set() Chaining

set() Map ko return karta hai, isliye chaining possible hai. 

const user =
  new Map();

user
  .set("name", "Ali")
  .set("age", 20)
  .set("city", "Ranchi");

console.log(user);

get() 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

console.log(
  student.get(
    "name"
  )
);

Output:

Ali

Key Na Mile To

Agar key Map me exist nahi karti to get() undefined return karta hai. 

const student =
  new Map();

console.log(
  student.get(
    "email"
  )
);
undefined

Existing Value Update Karna 

const user =
  new Map();

user.set(
  "age",
  20
);

user.set(
  "age",
  21
);

console.log(
  user.get(
    "age"
  )
);
21

has() 

const user =
  new Map([
    ["name", "Ali"]
  ]);

console.log(
  user.has(
    "name"
  )
);

console.log(
  user.has(
    "age"
  )
);

Output:

true
false

delete()

delete() given key ki entry remove karta hai aur success par boolean return karta hai. 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

const result =
  user.delete(
    "age"
  );

console.log(result);
console.log(user);

Output:

true
Map(1) {"name" => "Ali"}

clear() 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

user.clear();

console.log(user.size);
0

size Property

size method nahi, property hai. 

const student =
  new Map([
    ["name", "Ali"],
    ["age", 20],
    ["city", "Ranchi"]
  ]);

console.log(student.size);
3

keys()

keys() Map ki keys ka iterator return karta hai. 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20],
    ["city", "Ranchi"]
  ]);

for (
  const key
  of
  user.keys()
) {
  console.log(key);
}
name
age
city

values() 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

for (
  const value
  of
  user.values()
) {
  console.log(value);
}
Ali
20

entries() 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

for (
  const entry
  of
  user.entries()
) {
  console.log(entry);
}
["name", "Ali"]
["age", 20]

entries() With Destructuring 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

for (
  const [key, value]
  of
  user
) {
  console.log(key, value);
}
name Ali
age 20

forEach()

Map forEach() callback me pehle value aur phir key deta hai. 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

user.forEach(
  (value, key) => {
    console.log(key, value);
  }
);
name Ali
age 20

Map Ko Array Me Convert Karna 

const user =
  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

const array = [
  ...user
];

console.log(array);
[
  ["name", "Ali"],
  ["age", 20]
]

Map Methods Quick Reference

Code Result
map.set("name", "Ali") Add / Update
map.get("name") Value read
map.has("name") true / false
map.delete("name") Entry delete
map.clear() All entries delete
map.size Entry count

Important Points

1. set() Map me entry add ya update karta hai.

2. get() key ki value deta hai.

3. has() key exist karti hai ya nahi check karta hai.

4. delete() ek entry remove karta hai.

5. clear() Map ko empty karta hai.

6. keys(), values() aur entries() iteration ke liye useful hain.

7. size property total entries ki count deti hai.

8. Map forEach() me callback parameters ka order (value, key) hota hai.
