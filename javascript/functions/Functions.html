Function Kya Hai?

JavaScript me Function ek reusable block of code hota hai jo kisi specific task ko perform karta hai.

Ek baar function bana kar usse zarurat ke hisaab se baar-baar call kar sakte hain. Isse same code ko repeat karne ki zarurat nahi padti.

Function Syntax 

function functionName() {
  // code
}

Function banane ke liye function keyword use kiya jata hai. Uske baad function ka naam aur () likhte hain.

Simple Function Example

Neeche ek simple function banaya gaya hai jo console me message print karta hai. 

function greet() {
  console.log("Hello JavaScript");
}

greet();

Output:

Hello JavaScript

Function Kaise Kaam Karta Hai?

function → Function declare karne ka keyword hai.

greet → Function ka naam hai.

() → Function ke parameters yahan likhe jate hain.

{ } → Function ka code block hota hai.

greet(); → Function ko execute ya call karta hai.

Function Declare Aur Call

Sirf function banane se uska code execute nahi hota. Function ko execute karne ke liye usse call karna padta hai. 

// Function Declaration

function message() {
  console.log("Welcome");
}


// Function Call

message();

Output:

Welcome

Function Ko Baar-Baar Call Karna

Function reusable hota hai. Ek function ko multiple times call kar sakte hain. 

function hello() {
  console.log("Hello");
}

hello();
hello();
hello();

Output:

Hello
Hello
Hello

Function With Calculation

Function ke andar calculations bhi kar sakte hain. 

function add() {

  let a = 10;
  let b = 20;

  console.log(a + b);
}

add();

Output:

30

Function With Parameters

Function ko dynamic banane ke liye parameters use kar sakte hain. Parameters ke baare me next lesson me detail se padhenge. 

function greet(name) {
  console.log("Hello " + name);
}

greet("Ali");
greet("Ahmed");

Output:

Hello Ali
Hello Ahmed

Function With Return

return keyword function se value wapas bhejne ke liye use hota hai. 

function add(a, b) {
  return a + b;
}

let result = add(10, 20);

console.log(result);

Output:

30

Functions Kyu Use Karte Hain?

1. Same code ko baar-baar likhne ki zarurat nahi padti.

2. Code reusable ho jata hai.

3. Large program ko small tasks me divide kar sakte hain.

4. Code ko samajhna aur maintain karna easy hota hai.

5. Parameters ki help se function ko dynamic bana sakte hain.

Important Points

1. function keyword se normal function declare kiya ja sakta hai.

2. Function ka naam meaningful rakhna chahiye.

3. Function ke andar ka code tab execute hota hai jab function call hota hai.

4. Function ko multiple times call kiya ja sakta hai.

5. Function parameters ke through values receive kar sakta hai.

6. return se function result wapas de sakta hai.
