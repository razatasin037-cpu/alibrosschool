Function Parameter Kya Hai?

JavaScript me Function Parameters wo variables hote hain jo function banate waqt parentheses () ke andar define kiye jate hain.

Parameters ki help se function bahar se values receive kar sakta hai aur un values par kaam kar sakta hai.

Parameter Syntax 

function functionName(parameter) {
  // code
}

Parameter function declaration ke () ke andar likha jata hai.

Simple Parameter Example 

function greet(name) {
  console.log("Hello " + name);
}

greet("Ali");

Output:

Hello Ali

Example Kaise Kaam Kar Raha Hai?

greet → Function ka naam hai.

name → Function ka parameter hai.

"Ali" → Function call ke time pass ki gayi argument hai.

Function ke andar name ki value "Ali" ho jati hai.

Multiple Parameters

Ek function me multiple parameters bhi define kar sakte hain. Parameters ko comma , se separate kiya jata hai. 

function add(a, b) {
  console.log(a + b);
}

add(10, 20);

Output:

30

Different Values Pass Karna

Same function ko alag-alag values ke saath call kar sakte hain. 

function add(a, b) {
  console.log(a + b);
}

add(10, 20);
add(50, 30);
add(5, 2);

Output:

30
80
7

String And Number Parameters 

function student(name, age) {
  console.log(name + " is " + age + " years old");
}

student("Ali", 20);

Output:

Ali is 20 years old

Default Parameters

Default parameter ki help se parameter ko pehle se ek default value de sakte hain. 

function greet(name = "Guest") {
  console.log("Hello " + name);
}

greet();
greet("Ali");

Output:

Hello Guest
Hello Ali

Argument Pass Na Karne Par

Agar parameter define hai lekin function call karte waqt argument nahi diya gaya, to parameter ki value undefined ho sakti hai. 

function showName(name) {
  console.log(name);
}

showName();

Output:

undefined

Parameter vs Argument

Parameter Argument
Function banate waqt define hota hai. Function call karte waqt value pass hoti hai.
function greet(name) greet("Ali")
name parameter hai. "Ali" argument hai.

Practical Example

Product ka total price calculate karne ke liye parameters use kar sakte hain. 

function totalPrice(price, quantity) {

  let total = price * quantity;

  console.log(total);
}

totalPrice(500, 3);

Output:

1500

Important Points

1. Parameters function declaration ke () ke andar likhe jate hain.

2. Multiple parameters ko comma se separate karte hain.

3. Parameter function ke andar variable ki tarah use hota hai.

4. Function call ke time pass ki gayi actual value ko argument kehte hain.

5. Default parameter se pehle se default value set kar sakte hain.

6. Parameters function ko reusable aur dynamic banate hain.
