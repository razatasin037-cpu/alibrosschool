Arrow Function Kya Hai?

JavaScript me Arrow Function function likhne ka ek short aur modern syntax hai.

Arrow Function me normal function keyword ki jagah => arrow symbol use hota hai.

Arrow Function Syntax 

const functionName = () => {
  // code
};

Simple Arrow Function Example 

const greet = () => {
  console.log("Hello JavaScript");
};

greet();

Output:

Hello JavaScript

Example Kaise Kaam Kar Raha Hai?

const greet → Function ko greet variable me store kiya gaya hai.

() → Parameters yahan likhe jate hain.

=> → Ye Arrow Function ka main symbol hai.

greet() → Arrow Function ko call karta hai.

Normal Function vs Arrow Function

Normal Function: 

function add(a, b) {
  return a + b;
}

Arrow Function: 

const add = (a, b) => {
  return a + b;
};

Arrow Function With Parameters 

const add = (a, b) => {
  console.log(a + b);
};

add(10, 20);

Output:

30

Single Parameter

Sirf ek parameter ho to parentheses optional hote hain. 

const greet = name => {
  console.log("Hello " + name);
};

greet("Ali");

Output:

Hello Ali

Short Arrow Function Return

Agar Arrow Function me sirf ek expression return karna ho, to curly braces aur return keyword hata sakte hain. 

const add = (a, b) => a + b;

console.log(add(10, 20));

Output:

30

Multiple Statements

Agar function me multiple statements hain, to curly braces { } use karte hain. 

const calculate = (a, b) => {

  let total = a + b;

  return total;
};

console.log(calculate(5, 7));

Output:

12

Arrow Function With Array

Arrow Functions arrays ke methods ke saath bahut commonly use hote hain. 

let numbers = [1, 2, 3];

numbers.forEach((number) => {
  console.log(number);
});

Output:

1
2
3

Arrow Function Aur this

Arrow Function ka apna this binding nahi hota. Ye surrounding scope se this leta hai.

Isliye object methods ya constructor jaise cases me normal function aur arrow function ka behavior different ho sakta hai.

Arrow Function Aur arguments

Arrow Function ka apna arguments object nahi hota. Multiple unknown arguments handle karne ke liye rest parameters ...args use karna better hota hai.

Arrow Function With Rest Parameters 

const show = (...args) => {
  console.log(args);
};

show(
  10,
  20,
  30
);

Output:

[10, 20, 30]

Normal Function vs Arrow Function

Normal Function Arrow Function
function keyword use hota hai. => syntax use hota hai.
Syntax comparatively longer hota hai. Syntax short aur concise hota hai.
Apna arguments object hota hai. Apna arguments object nahi hota.
this behavior call ke context par depend kar sakta hai. Lexical this use karta hai.

Important Points

1. Arrow Function function likhne ka short syntax hai.

2. => Arrow Function ka main symbol hai.

3. Single parameter me parentheses optional ho sakte hain.

4. Single expression ko directly return kiya ja sakta hai.

5. Multiple statements ke liye { } use karte hain.

6. Arrow Function ka apna arguments object nahi hota.

7. Arrow Function ka this normal function se different behave karta hai.
