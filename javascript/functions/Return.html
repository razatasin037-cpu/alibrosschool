Return Kya Hai?

JavaScript me return keyword ka use function se koi value wapas bhejne ke liye kiya jata hai.

Jab function me calculation ya processing hoti hai, tab return us result ko function ke bahar bhej sakta hai.

Return Syntax 

function functionName() {
  return value;
}

Simple Return Example 

function message() {
  return "Hello JavaScript";
}

let result = message();

console.log(result);

Output:

Hello JavaScript

Example Kaise Kaam Kar Raha Hai?

message() → Function call hota hai.

return "Hello JavaScript" → Function String value wapas bhejta hai.

Returned value result variable me store ho jati hai.

console.log(result) → Returned value ko console me print karta hai.

Return With Parameters 

function add(a, b) {
  return a + b;
}

let result = add(10, 20);

console.log(result);

Output:

30

Returned Value Ko Direct Use Karna

Returned value ko variable me store karna compulsory nahi hai. Directly bhi use kar sakte hain. 

function multiply(a, b) {
  return a * b;
}

console.log(multiply(5, 4));

Output:

20

Return Function Ko Stop Bhi Karta Hai

Jaise hi return execute hota hai, function wahi stop ho jata hai. 

function test() {

  console.log("Start");

  return "Done";

  console.log("End");
}

console.log(test());

Output:

Start
Done

"End" print nahi hoga kyunki usse pehle return execute ho chuka hai.

Return With If Condition 

function checkAge(age) {

  if (age >= 18) {
    return "Adult";
  }

  return "Minor";
}

console.log(checkAge(20));

Output:

Adult

Return Na Ho To Kya Hota Hai?

Agar function explicitly koi value return nahi karta, to uska return value undefined hota hai. 

function hello() {
  console.log("Hello");
}

let result = hello();

console.log(result);

Output:

Hello
undefined

console.log() vs return

console.log() return
Value ko console me show karta hai. Value function ke bahar bhejta hai.
Value ko automatically reusable result nahi banata. Returned result ko variable, calculation ya kisi aur function me use kar sakte hain.
console.log(a + b) return a + b

Practical Example

Product ka total price function se return kar sakte hain. 

function totalPrice(price, quantity) {

  let total = price * quantity;

  return total;
}

let finalPrice = totalPrice(
  500,
  3
);

console.log(finalPrice);

Output:

1500

Important Points

1. return function se value wapas bhejta hai.

2. Returned value ko variable me store kar sakte hain.

3. Returned value ko directly calculation ya console.log() me bhi use kar sakte hain.

4. Return execute hote hi current function stop ho jata hai.

5. Function agar koi explicit value return nahi karta, to undefined return hota hai.

6. console.log() aur return same kaam nahi karte.
