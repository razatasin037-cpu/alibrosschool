Function Expression Kya Hai?

JavaScript me Function Expression ek aisa function hota hai jise kisi variable ke andar store kiya jata hai.

Function Expression me function ko pehle create karke const, let ya kabhi-kabhi var variable me assign kiya jata hai.

Function Expression Syntax 

const functionName = function() {
  // code
};

Simple Function Expression Example 

const greet = function() {
  console.log("Hello JavaScript");
};

greet();

Output:

Hello JavaScript

Example Kaise Kaam Kar Raha Hai?

const greet → Ek variable create kiya gaya hai.

function() → Anonymous function create karta hai.

Function ko greet variable ke andar store kiya gaya hai.

greet() → Stored function ko call karta hai.

Anonymous Function

Function Expression me function ka apna naam na ho to use Anonymous Function kehte hain. 

const message = function() {
  console.log("Welcome");
};

message();

Output:

Welcome

Function Expression With Parameters 

const add = function(a, b) {
  console.log(a + b);
};

add(10, 20);

Output:

30

Function Expression With Return 

const multiply = function(a, b) {
  return a * b;
};

let result = multiply(
  5,
  4
);

console.log(result);

Output:

20

Function Declaration vs Function Expression

Function Declaration Function Expression
Direct function declare hota hai. Function variable me assign hota hai.
function add() {} const add = function() {};
Function declaration hoisting support karta hai. Variable declaration rules par depend karta hai.

Function Expression Aur Hoisting

const ya let me stored Function Expression ko declaration se pehle call nahi karna chahiye. 

// Wrong order

greet();

const greet = function() {
  console.log("Hello");
};

Result:

ReferenceError

Correct Way 

const greet = function() {
  console.log("Hello");
};

greet();

Output:

Hello

Function Ko Value Ki Tarah Store Karna

JavaScript me functions values ki tarah variables me store kiye ja sakte hain. 

const add = function(a, b) {
  return a + b;
};

const myFunction = add;

console.log(
  myFunction(
    10,
    20
  )
);

Output:

30

Named Function Expression

Function Expression ke andar function ko naam bhi diya ja sakta hai. 

const greet = function showMessage() {
  console.log("Hello JavaScript");
};

greet();

Output:

Hello JavaScript

Function Expression vs Arrow Function

Function Expression: 

const add = function(a, b) {
  return a + b;
};

Arrow Function: 

const add = (a, b) => {
  return a + b;
};

Important Points

1. Function Expression me function ko variable me store kiya jata hai.

2. Anonymous Function ka apna function name nahi hota.

3. Function Expression parameters aur return dono use kar sakta hai.

4. const me stored Function Expression ko assignment se pehle call nahi kar sakte.

5. JavaScript me function ko value ki tarah variable me store kiya ja sakta hai.

6. Arrow Function bhi commonly variable me store kiya jata hai, lekin uska syntax aur kuch behavior different hota hai.
