JavaScript Function Arguments

Arguments Kya Hain?

JavaScript me Arguments wo actual values hoti hain jo function ko call karte waqt parentheses () ke andar pass ki jati hain.

Function ke parameters in arguments ki values ko receive karte hain aur function ke andar use karte hain.

Argument Syntax 

function functionName(parameter) {
  // code
}

functionName(argument);

Simple Argument Example 

function greet(name) {
  console.log("Hello " + name);
}

greet("Ali");

Output:

Hello Ali

Example Kaise Kaam Kar Raha Hai?

name → Function ka parameter hai.

"Ali" → Function call ke time pass ki gayi argument hai.

Function execute hote waqt name ke andar "Ali" value aa jati hai.

Multiple Arguments

Function ko ek se zyada arguments bhi pass kar sakte hain. 

function add(a, b) {
  console.log(a + b);
}

add(10, 20);

Output:

30

Argument Order Important Hai

Arguments ka order parameters ke order ke according hona chahiye. 

function student(name, age) {
  console.log(name);
  console.log(age);
}

student("Ali", 20);

Output:

Ali
20

Different Arguments Pass Karna 

function greet(name) {
  console.log("Hello " + name);
}

greet("Ali");
greet("Rahul");
greet("Aman");

Output:

Hello Ali
Hello Rahul
Hello Aman

Argument Missing Ho To

Agar function me parameter hai lekin corresponding argument pass nahi kiya gaya, to us parameter ki value undefined ho sakti hai. 

function show(name, age) {
  console.log(name);
  console.log(age);
}

show("Ali");

Output:

Ali
undefined

Extra Arguments

JavaScript me function call ke time defined parameters se zyada arguments bhi pass kiye ja sakte hain. 

function show(name) {
  console.log(name);
}

show(
  "Ali",
  20,
  "Delhi"
);

Output:

Ali

arguments Object

Normal functions ke andar JavaScript ek special arguments object provide karta hai. Isme function ko pass ki gayi arguments access ki ja sakti hain. 

function show() {

  console.log(arguments[0]);
  console.log(arguments[1]);

}

show(
  "Ali",
  20
);

Output:

Ali
20

arguments.length

Function ko kitni arguments pass hui hain ye arguments.length se check kar sakte hain. 

function count() {
  console.log(arguments.length);
}

count(
  10,
  20,
  30
);

Output:

3

Parameters vs Arguments

Parameters Arguments
Function declare karte waqt define hote hain. Function call karte waqt values pass hoti hain.
function add(a, b) add(10, 20)
a aur b parameters hain. 10 aur 20 arguments hain.

Practical Example 

function total(price, quantity) {

  return price * quantity;

}

console.log(
  total(
    500,
    3
  )
);

Output:

1500

Important Points

1. Arguments function call ke time pass ki gayi actual values hoti hain.

2. Parameters function declaration ke time define hote hain.

3. Multiple arguments ko comma , se separate karte hain.

4. Arguments ka order parameters ke order ke according important hota hai.

5. Missing argument ki wajah se corresponding parameter undefined ho sakta hai.

6. Normal functions me arguments object available hota hai.

7. Arrow functions ka apna arguments object nahi hota.
