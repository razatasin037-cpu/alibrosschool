JavaScript Error Kya Hai?

JavaScript me jab code sahi tarah execute nahi ho pata hai, tab JavaScript ek error show karta hai.

Error hume batata hai ki code me kis jagah ya kis type ki problem hui hai.

Simple Error Example

Agar hum aise variable ko access karein jo define nahi hai, JavaScript error dega. 

console.log(userName);

Error: 

ReferenceError:
userName is not defined

JavaScript Me Error Kyu Aata Hai?

1. Variable define nahi kiya ho.

2. Syntax galat ho.

3. Galat data type par method use ki ho.

4. Function available na ho.

5. Object ki missing property access ki ho.

6. API ya server response me problem ho.

Common JavaScript Errors

JavaScript me different situations ke according different types ke errors milte hain.

1. SyntaxError

Jab JavaScript code ka syntax galat hota hai tab SyntaxError aata hai. 

const name =
  "Ali"

console.log(name;
SyntaxError

2. ReferenceError

Jab hum kisi aise variable ko use karte hain jo define nahi hua hai tab ReferenceError aata hai. 

console.log(age);
ReferenceError:
age is not defined

3. TypeError

Jab kisi value ke saath aisa operation kiya jaye jo uske data type ke liye valid nahi hai tab TypeError mil sakta hai. 

const number =
  10;

number.toUpperCase();
TypeError:
number.toUpperCase is not a function

4. RangeError

Jab koi value JavaScript ki allowed range ke bahar hoti hai tab RangeError aa sakta hai. 

const number =
  10;

console.log(
  number.toFixed(101)
);
RangeError

5. URIError

Invalid URI ko encode ya decode karte waqt URIError aa sakta hai. 

decodeURIComponent(
  "%E0%A4%A"
);
URIError:
URI malformed

JavaScript Error Object

JavaScript me Error object ka use custom error information create karne ke liye bhi kiya ja sakta hai. 

const error =
  new Error(
    "Something went wrong"
  );

console.log(error.name);

console.log(error.message);

Output: 

Error
Something went wrong

error.name

name property error ka type batati hai. 

try {

  console.log(user);

} catch (error) {

  console.log(error.name);

}
ReferenceError

error.message

message property error ke baare me message provide karti hai. 

try {

  console.log(student);

} catch (error) {

  console.log(error.message);

}
student is not defined

Runtime Error

Runtime error wo error hai jo JavaScript program execute hote waqt aata hai. 

const user = null;

console.log(
  user.name
);
TypeError

Logical Error

Logical error me JavaScript koi error message nahi deta, lekin program ka output galat aa jata hai. 

const price =
  100;

const quantity =
  5;

// Wrong logic

const total =
  price + quantity;

console.log(total);

Wrong Output: 

105

Yahan correct calculation price * quantity honi chahiye thi.

Logical Error Fix 

const price =
  100;

const quantity =
  5;

const total =
  price * quantity;

console.log(total);
500

Common Error Types

Error Meaning
SyntaxError JavaScript syntax galat hai.
ReferenceError Variable ya reference available nahi hai.
TypeError Value ke type ke saath invalid operation hua hai.
RangeError Value valid range ke bahar hai.
URIError URI encode/decode karte waqt problem hui hai.

Real Project Example

API se data fetch karte waqt bhi error aa sakta hai. 

async function getUsers() {

  try {

    const response =
      await fetch(
        
          "https://example.com/users"
        
      );

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

getUsers();

Important Points

1. JavaScript error code me problem ko show karta hai.

2. SyntaxError syntax mistake ki wajah se aata hai.

3. ReferenceError undefined variable access karne par aa sakta hai.

4. TypeError invalid data type operation par aa sakta hai.

5. RangeError invalid range ki wajah se aa sakta hai.

6. error.name error ka type batata hai.

7. error.message error ka message batata hai.

8. Logical error me program run ho sakta hai lekin output galat aa sakta hai.

9. try...catch se runtime errors ko handle kiya ja sakta hai.
