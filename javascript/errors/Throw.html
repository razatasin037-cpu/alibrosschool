Throw Kya Hai?

JavaScript me throw statement ka use manually custom error generate karne ke liye hota hai.

Jab hamari koi condition invalid ho, tab hum khud error throw kar sakte hain.

Throw Syntax 

throw value;

Recommended way: 

throw new Error(
  "Custom error message"
);

Basic Throw Example 

throw new Error(
  "Something went wrong"
);
Error:
Something went wrong

Condition Ke Saath Throw 

const age =
  15;

if (age < 18) {

  throw new Error(
    
      "Age must be 18 or above"
    
  );

}

console.log(
  "Access Allowed"
);
Error:
Age must be 18 or above

Throw With Try Catch

Usually throw ko try...catch ke saath use kiya jata hai. 

try {

  const age =
    15;

  if (age < 18) {

    throw new Error(
      
        "You are under 18"
      
    );

  }

  console.log(
    "Access Allowed"
  );

} catch (error) {

  console.log(
    error.message
  );

}
You are under 18

Recommended Way

Sirf string throw karne ke bajaye new Error() use karna better hota hai, kyunki isme name, message aur stack information mil sakti hai.

Avoid 

throw
  "Invalid user";

Better 

throw new Error(
  "Invalid user"
);

API Example

API response successful nahi ho to custom error throw kar sakte hain. 

async function getUsers() {

  try {

    const response =
      await fetch(
        
          "https://example.com/users"
        
      );

    if (!response.ok) {

      throw new Error(
        
          "Failed to fetch users"
        
      );

    }

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

Real Project Product Example 

function buyProduct(
  product
) {

  if (!product) {

    throw new Error(
      
        "Product not found"
      
    );

  }

  if (
    product.stock <= 0
  ) {

    throw new Error(
      
        "Product is out of stock"
      
    );

  }

  return
    
      "Product purchased"
    ;

}

const product = {
  name:
    "Laptop",

  stock:
    0
};

try {

  console.log(
    buyProduct(product)
  );

} catch (error) {

  console.log(
    error.message
  );

}
Product is out of stock

Throw Kaise Kaam Karta Hai?

1. JavaScript code normally execute hota hai.

2. Jab throw execute hota hai, current code execution wahi stop ho jata hai.

3. Agar throw try ke andar hai to control catch me chala jata hai.

4. catch error ko receive aur handle karta hai.

Important Points

1. throw manually error generate karta hai.

2. Custom validation me throw bahut useful hota hai.

3. throw new Error() recommended way hai.

4. Throw execute hote hi current code ka remaining part skip ho jata hai.

5. try...catch ke saath throw ko easily handle kiya ja sakta hai.

6. error.message custom message ko access karta hai.

7. Form validation me custom errors throw kiye ja sakte hain.

8. API response fail hone par bhi custom error throw kar sakte hain.

9. Business rules jaise out of stock ko bhi throw ke through handle kiya ja sakta hai.

10. Next topic me finally samjhenge, jo error aaye ya na aaye dono cases me execute hota hai.
