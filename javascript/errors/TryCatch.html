Try Catch Kya Hai?

JavaScript me try...catch ka use errors ko handle karne ke liye hota hai.

Agar try block ke andar error aata hai, to program completely stop hone ke bajaye catch block execute hota hai.

Try Catch Syntax 

try {

  // Code

} catch (error) {

  // Error handling

}

Without Try Catch

Agar error ko handle nahi karenge to JavaScript execution wahi ruk sakta hai. 

console.log(user);

console.log(
  "Program Running"
);
ReferenceError:
user is not defined

Basic Try Catch Example 

try {

  console.log(user);

} catch (error) {

  console.log(
    "Error aa gaya"
  );

}

console.log(
  "Program Running"
);

Output: 

Error aa gaya
Program Running

Try Catch Kaise Kaam Karta Hai?

1. JavaScript pehle try block run karta hai.

2. Agar koi error nahi hai to catch block skip ho jata hai.

3. Agar try ke andar error aata hai to remaining try code skip ho jata hai.

4. Uske baad catch block execute hota hai.

5. Catch ke baad program ka next code continue ho sakta hai.

Jab Error Nahi Aata 

try {

  const name =
    "Ali";

  console.log(name);

} catch (error) {

  console.log(
    "Error"
  );

}
Ali

Catch Error Object

Catch ke andar milne wala error object error ki complete information rakhta hai. 

try {

  console.log(student);

} catch (error) {

  console.log(error);

}

error.name

error.name error ka type batata hai. 

try {

  console.log(student);

} catch (error) {

  console.log(
    error.name
  );

}
ReferenceError

error.message

error.message actual error message provide karta hai. 

try {

  console.log(student);

} catch (error) {

  console.log(
    error.message
  );

}
student is not defined

Error Name Aur Message 

try {

  console.log(user);

} catch (error) {

  console.log(
    "Name:",
    error.name
  );

  console.log(
    "Message:",
    error.message
  );

}
Name: ReferenceError
Message: user is not defined

Try Catch With Async Await

Async/await ke saath API errors handle karne ke liye try catch bahut commonly use hota hai. 

async function getUsers() {

  try {

    const response =
      await fetch(
        
          "https://example.com/users"
        
      );

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

getUsers();

Fetch Response Check

Fetch me 404 ya 500 response automatically catch me nahi jata. Isliye response.ok check karna useful hota hai. 

async function getProduct() {

  try {

    const response =
      await fetch(
        
          "https://example.com/product/1"
        
      );

    if (!response.ok) {

      throw new Error(
        
          "Product not found"
        
      );

    }

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

Try Catch Summary

Part Work
try Risky code execute karta hai.
catch Error ko handle karta hai.
error Error ki information rakhta hai.
error.name Error type batata hai.
error.message Error ka message batata hai.

Important Points

1. try ke andar wo code likhte hain jahan error aa sakta hai.

2. catch error ko handle karta hai.

3. Error nahi aaya to catch execute nahi hota.

4. Error aane ke baad try block ka remaining code skip ho jata hai.

5. error.name error ka type deta hai.

6. error.message error ka message deta hai.

7. JSON parsing me try catch useful hai.

8. Async/await aur API calls ke saath try catch bahut important hai.

9. React aur Axios projects me API errors handle karne ke liye try catch commonly use hota hai.

10. Custom errors banane ke liye throw use kiya jata hai.
