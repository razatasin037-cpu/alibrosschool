Finally Kya Hai?

JavaScript me finally block ka use aisa code run karne ke liye hota hai jo error aaye ya na aaye, dono condition me execute hona chahiye.

Ye usually try...catch ke saath use hota hai.

Finally Syntax 

try {

  // Code

} catch (error) {

  // Error handle

} finally {

  // Always execute

}

Basic Finally Example 

try {

  console.log(
    "Try block"
  );

} catch (error) {

  console.log(
    "Catch block"
  );

} finally {

  console.log(
    "Finally block"
  );

}

Output: 

Try block
Finally block

Try Catch Finally Ka Flow

1. Sabse pehle try block execute hota hai.

2. Error nahi aaya to catch skip ho jata hai.

3. Error aaya to catch execute hota hai.

4. Dono cases ke baad finally execute hota hai.

Simple Flow 

try
 ↓
Error?

No  ──────────────┐
                  ↓
Yes → catch → finally
                  ↑
No Error ─────────┘

Try With Finally

finally ko catch ke bina bhi use kiya ja sakta hai. 

try {

  console.log(
    "Working..."
  );

} finally {

  console.log(
    "Finished"
  );

}
Working...
Finished

Finally With Return

Function ke try block me return hone par bhi finally pehle execute hota hai. 

function test() {

  try {

    return
      "Hello";

  } finally {

    console.log(
      "Finally executed"
    );

  }

}

console.log(
  test()
);
Finally executed
Hello

Finally Me Return Se Bachna Chahiye

Agar finally ke andar bhi return likh diya jaye, to wo try ya catch ke return ko override kar sakta hai. Isliye generally finally me return avoid karna better hai. 

function test() {

  try {

    return
      "Try";

  } finally {

    return
      "Finally";

  }

}

console.log(
  test()
);
Finally

API Example 

async function getProducts() {

  try {

    console.log(
      "Loading started"
    );

    const response =
      await fetch(
        
          "https://example.com/products"
        
      );

    if (!response.ok) {

      throw new Error(
        
          "Failed to fetch products"
        
      );

    }

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  } finally {

    console.log(
      "Loading stopped"
    );

  }

}

getProducts();

React Me Finally

React me API call ke baad loading state reset karne ke liye finally useful hota hai. 

const getProducts =
  async () => {

  setLoading(
    true
  );

  try {

    const response =
      await axios.get(
        
          "/api/products"
        
      );

    setProducts(
      response.data
    );

  } catch (error) {

    console.log(
      error.message
    );

  } finally {

    setLoading(
      false
    );

  }

};

Finally Kab Use Karein?

1. Loading state reset karne ke liye.

2. API request complete hone ke baad cleanup karne ke liye.

3. File ya connection close karne jaise cleanup work ke liye.

4. Temporary state ko reset karne ke liye.

5. Aisa code chalane ke liye jo success aur error dono me run hona chahiye.

Try vs Catch vs Finally

Block Work Kab Run Hota Hai?
try Main risky code Sabse pehle
catch Error handle karta hai Jab error aaye
finally Cleanup/final work Error aaye ya na aaye

Complete Try Catch Finally Example 

function divide(
  a,
  b
) {

  try {

    if (b === 0) {

      throw new Error(
        
          "Cannot divide by zero"
        
      );

    }

    console.log(
      a / b
    );

  } catch (error) {

    console.log(
      error.message
    );

  } finally {

    console.log(
      
        "Calculation completed"
      
    );

  }

}

divide(
  10,
  0
);
Cannot divide by zero
Calculation completed

Important Points

1. finally success aur error dono cases me execute hota hai.

2. Finally ko commonly try...catch ke saath use kiya jata hai.

3. Error nahi aaye tab bhi finally execute hota hai.

4. Error aaye aur catch execute ho tab bhi finally execute hota hai.

5. try...finally catch ke bina bhi valid hai.

6. Finally loading state reset karne me bahut useful hai.

7. Cleanup code ke liye finally ek common choice hai.

8. Finally ke andar unnecessary return avoid karna chahiye.

9. API aur React projects me loading ko false karne ke liye finally commonly use hota hai.
