JavaScript Module Kya Hai?

JavaScript Modules ka use code ko alag-alag files me divide karne ke liye hota hai.

Ek file se function, variable ya class ko export karke dusri file me import kar sakte hain.

Modules Kyu Use Karte Hain?

1. Code ko clean aur organized rakhne ke liye.

2. Large project ko multiple files me divide karne ke liye.

3. Same function ko different files me reuse karne ke liye.

4. Duplicate code kam karne ke liye.

5. Project ko maintain karna easy banane ke liye.

Basic Module Structure 

project/

├── index.html
├── app.js
└── math.js

Yahan math.js se code export hoga aur app.js me import hoga.

type="module" Important Hai

Browser me JavaScript Modules use karne ke liye script tag me type="module" likhna hota hai. 

<script
  type="module"
  src="app.js"
></script>

Simple Export Example

File: math.js 

export const add =
  (a, b) => {

    return a + b;

  };

Simple Import Example

File: app.js 

import {
  add
} from "./math.js";

console.log(
  add(
    10,
    20
  )
);
30

Named Export

Ek file se multiple variables, functions ya classes export karne ke liye Named Export use hota hai.

math.js 

export const add =
  (a, b) => a + b;

export const subtract =
  (a, b) => a - b;

Named Import 

import {
  add,
  subtract
} from "./math.js";

console.log(
  add(10, 5)
);

console.log(
  subtract(10, 5)
);
15
5

Export At Bottom

Pehle functions create karke baad me bhi export kar sakte hain. 

const add =
  (a, b) => a + b;

const multiply =
  (a, b) => a * b;

export {
  add,
  multiply
};

Default Export

Ek module me ek default export ho sakta hai.

user.js 

export default function greet() {

  return
    "Hello User";

}

Default Import 

import greet
from "./user.js";

console.log(
  greet()
);
Hello User

Named Export vs Default Export

Named Export Default Export
Multiple exports possible. Ek default export per module.
export const add export default greet
Import me { } lagte hain. Import me braces nahi lagte.
import { add } import greet

Named Import Rename Karna

as keyword se imported item ka local name change kar sakte hain. 

import {
  add as sum
} from "./math.js";

console.log(
  sum(10, 20)
);
30

Import Everything

Module ke saare named exports ko ek object jaisa import kar sakte hain. 

import * as MathUtils
from "./math.js";

console.log(
  MathUtils.add(
    5,
    5
  )
);

Variable Export 

export const appName =
  "My Website";

export const version =
  "1.0.0";

Class Export 

export class User {

  constructor(name) {

    this.name =
      name;

  }

}

Dusri file me: 

import {
  User
} from "./User.js";

const user =
  new User(
    "Ali"
  );

console.log(
  user.name
);

Module Scope

Module ke andar declared variables automatically global scope me add nahi hote. Har module ka apna scope hota hai.

Agar kisi value ko dusri file me use karna hai to usko explicitly export karna hota hai.

Browser Me Module Run Karna

Modules ko browser me test karte waqt project ko local server se run karna better hota hai. VS Code Live Server ya Vite jaise development server use kar sakte ho.

        ↓

  return a + b;

        ↓

export { add };

        ↓

Import In app.js

import { add } from "./math.js";

        ↓

30

Important Points

1. Modules code ko multiple files me divide karte hain.

2. export se value ko dusri files ke liye available banate hain.

3. import se exported value ko dusri file me use karte hain.

4. Named exports ko { } ke andar import kiya jata hai.

5. Default import me curly braces nahi lagte.

6. Ek module me multiple named exports ho sakte hain.

7. Ek module me ek default export ho sakta hai.

8. Browser modules ke liye type="module" important hai.

9. Modules code reuse aur project organization ke liye bahut useful hain.
