Export Kya Hai?

JavaScript me export keyword ka use variable, function ya class ko dusri JavaScript file me use karne ke liye available banane ke liye hota hai.

Export ke mainly do types hote hain: Named Export aur Default Export.

Export Syntax 

export value;

Named Export

Named Export se ek file se multiple values export kar sakte hain. 

export const name =
  "Ali";

export const age =
  20;

Function Export 

export function add(a, b) {

  return a + b;

}

Arrow Function Export 

export const multiply =
  (a, b) => {

    return a * b;

  };

Class Export 

export class User {

  constructor(name) {

    this.name = name;

  }

}

Export At Bottom

Pehle variables ya functions create karke baad me bhi export kar sakte hain. 

const add =
  (a, b) => a + b;

const subtract =
  (a, b) => a - b;

export {
  add,
  subtract
};

Multiple Named Exports 

const add =
  (a, b) => a + b;

const subtract =
  (a, b) => a - b;

const multiply =
  (a, b) => a * b;

const divide =
  (a, b) => a / b;

export {
  add,
  subtract,
  multiply,
  divide
};

Export Rename With as

as keyword se export ka naam change kar sakte hain. 

const add =
  (a, b) => a + b;

export {
  add as sum
};

Ab dusri file me sum naam se import hoga.

Default Export

Ek module me ek default export hota hai. 

export default function greet() {

  return
    "Hello User";

}

Variable As Default Export 

const appName =
  "My App";

export default appName;

Class As Default Export 

export default class Product {

  constructor(name, price) {

    this.name =
      name;

    this.price =
      price;

  }

}

Named Aur Default Export Together

Ek file me default export ke saath multiple named exports bhi rakh sakte hain. 

const appName =
  "Shop App";

export const version =
  "1.0.0";

export const author =
  "Ali";

export default appName;

Named Export vs Default Export

Named Export Default Export
Multiple ho sakte hain. Ek module me ek default export hota hai.
export const add export default greet
Import me braces lagte hain. Import me braces nahi lagte.
import { add } import greet

Configuration Export Example

File: config.js 

export const API_URL =
  "https://api.example.com";

export const APP_NAME =
  "Inventory App";

export const VERSION =
  "1.0.0";

Object Export 

const config = {

  appName:
    "Inventory",

  version:
    "1.0"

};

export default config;

Common Mistake

Ek module me multiple default exports nahi rakh sakte.

Wrong 

export default add;

export default subtract;

Correct 

export {
  add,
  subtract
};

Export Ka Simple Flow 

Create File

math.js

       ↓

Create Function

const add = (a, b) => a + b;

       ↓

Export

export { add };

       ↓

Now add Can Be Imported

       ↓

import { add } from "./math.js";

Important Points

1. export module ke code ko dusri files ke liye available banata hai.

2. Variables, functions aur classes export ki ja sakti hain.

3. Named exports multiple ho sakte hain.

4. Ek module me ek default export hota hai.

5. Named export ko direct declaration ke saath bhi likh sakte hain.

6. Values ko end me export { } ke through bhi export kar sakte hain.

7. as keyword se named export ka naam change kiya ja sakta hai.

8. Named export aur default export same file me saath use kiye ja sakte hain.
