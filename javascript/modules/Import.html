Import Kya Hai?

JavaScript me import keyword ka use kisi dusri module file se exported variable, function ya class ko current file me use karne ke liye hota hai.

Import tabhi kaam karega jab dusri file me value export ki gayi ho.

Import Syntax 

import {
  item
} from "./file.js";

Named Import

Named export ko import karne ke liye curly braces { } use hote hain. 

import {
  add
} from "./math.js";

Multiple Named Imports 

import {
  add,
  subtract,
  multiply
} from "./math.js";

Imported Function Use Karna

math.js 

export const add =
  (a, b) => a + b;

app.js 

import {
  add
} from "./math.js";

console.log(
  add(
    10,
    20
  )
);
30

Default Import

Default export ko import karte waqt curly braces nahi lagte.

user.js 

export default function greet() {

  return
    "Hello User";

}

app.js 

import greet
from "./user.js";

console.log(
  greet()
);
Hello User

Default Import Ka Naam Change Karna

Default import ko apni file me kisi bhi valid variable name se import kar sakte ho. 

import showMessage
from "./user.js";

console.log(
  showMessage()
);

Named Import Rename With as 

import {
  add as sum
} from "./math.js";

console.log(
  sum(
    10,
    5
  )
);
15

Import All Named Exports

Saare named exports ko ek namespace object me import karne ke liye * as use hota hai. 

import * as MathUtils
from "./math.js";

console.log(
  MathUtils.add(
    10,
    5
  )
);

console.log(
  MathUtils.subtract(
    10,
    5
  )
);

Default + Named Import Together

Agar ek module default aur named exports dono deta hai: 

import appName, {
  version,
  author
} from "./config.js";

console.log(appName);
console.log(version);
console.log(author);

Class Import

User.js 

export class User {

  constructor(name) {

    this.name =
      name;

  }

}

app.js 

import {
  User
} from "./User.js";

const user =
  new User(
    "Ali"
  );

console.log(
  user.name
);
Ali

Import File Paths

Path Meaning
./math.js Current folder
../math.js Parent folder
./utils/math.js Current folder ke andar utils folder

Folder Structure Example 

project/

├── index.html
├── app.js

└── modules/
    └── calculator.js

Agar app.js root folder me hai: 

import {
  add
} from
  "./modules/calculator.js";

HTML Me Import Use Karna

Browser me ES Modules ke liye type="module" zaroor use karo. 

<script
  type="module"
  src="./app.js"
></script>

Complete Import Example

calculator.js 

export const add =
  (a, b) => a + b;

export const subtract =
  (a, b) => a - b;

  (a, b) => a * b;

Import vs Export

Export Import
Value ko module se bahar available karta hai. Exported value ko current module me lata hai.
export { add } import { add } from "./math.js"
Source file me hota hai. Jahan value use karni ho wahan hota hai.

Common Mistake

Named export ko default import ki tarah import nahi karna chahiye.

Wrong 

// math.js

export const add =
  (a, b) => a + b;

// app.js

import add
from "./math.js";

Correct 

import {
  add
} from "./math.js";

Import Ka Simple Flow 

math.js

export const add = (a, b) => a + b;

          ↓

Export Available

          ↓

app.js

import { add } from "./math.js";

          ↓

Use Imported Function

add(10, 20)

          ↓

30

Important Points

1. import dusri module file ki exported value ko current file me lata hai.

2. Named imports me { } use hote hain.

3. Default import me curly braces nahi lagte.

4. as se named import rename kar sakte hain.

5. import * as Name se saare named exports ek namespace object me milte hain.

6. Relative paths me ./ current folder aur ../ parent folder ko represent karta hai.

7. Browser me ES Modules ke liye type="module" use karna hota hai.

8. Export aur import se code reusable aur organized banta hai.
