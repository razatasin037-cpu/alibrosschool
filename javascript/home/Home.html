JavaScript Kya Hai?

JavaScript duniya ki sabse popular Programming Language hai. Ye web pages ko interactive aur dynamic banane ke liye use hoti hai.

HTML structure banata hai, CSS design karta hai, aur JavaScript page me interactivity & logic daalta hai.

Client-Side Interactivity

Buttons click actions, form validation, animations, aur interactive content sab JavaScript se handle hota hai.

Full-Stack Capability

Node.js ke aane ke baad JavaScript ab backend servers aur database operations ke liye bhi use hoti hai.

1. Simple JavaScript Code Example

JavaScript code ko HTML me <script> tag ke andar likha jata hai: 

<!DOCTYPE html>
<html>
<body>

  <h2>My First JavaScript</h2>

  <button onclick="displayDate()">Click Me</button>

  <p id="demo"></p>

  <script>
    function displayDate() {
      document.getElementById('demo').innerHTML = Date();
    }
  </script>

</body>
</html>

2. JavaScript Se Aap Kya Kar Sakte Hain?

  • HTML content ko change kar sakte hain (DOM Manipulation).
  • HTML CSS styles ko dynamic badal sakte hain.
  • User inputs (Forms) ko validate kar sakte hain.
  • APIs se data fetch karke web page par bina refresh kiye dikha sakte hain (AJAX/Fetch API).
