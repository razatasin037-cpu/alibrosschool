Object Method Kya Hai?

JavaScript Object ke andar agar kisi property ki value ek function ho, to use Object Method kaha jata hai.

Object Methods ka use object ke data par kaam karne ke liye hota hai. Jaise name display karna, calculation karna, full information return karna, ya object ki properties ko process karna.

Object Method Syntax 

const objectName = {

  methodName: function() {
    // code
  }

};

Simple Object Method Example 

const student = {

  name: "Ali",

  greet: function() {
    console.log("Hello");
  }

};

student.greet();

Output:

Hello

Example Kaise Kaam Kar Raha Hai?

student → Object ka naam hai.

greet → Object ki method hai.

function() → Method ke andar function define kiya gaya hai.

student.greet() → Object ki method ko call karta hai.

Short Method Syntax

Modern JavaScript me function keyword ke bina bhi object method likh sakte hain. 

const student = {

  name: "Ali",

  greet() {
    console.log("Hello");
  }

};

student.greet();

Output:

Hello

this Keyword in Object Method

Object method ke andar this current object ko refer karta hai. Iski help se object ki dusri properties access kar sakte hain. 

const student = {

  name: "Ali",

  greet() {
    console.log("Hello " + this.name);
  }

};

student.greet();

Output:

Hello Ali

Method With Multiple Properties 

const student = {

  firstName: "Ali",
  lastName: "Khan",

  fullName() {
    return this.firstName + " " + this.lastName;
  }

};

console.log(student.fullName());

Output:

Ali Khan

Object Method With Parameters

Normal functions ki tarah Object Methods bhi parameters receive kar sakti hain. 

const calculator = {

  add(a, b) {
    return a + b;
  }

};

console.log(
  calculator.add(
    10,
    20
  )
);

Output:

30

Object Me Method Add Karna

Object create hone ke baad bhi new method add ki ja sakti hai. 

const user = {
  name: "Rahul"
};

user.greet = function() {
  console.log("Welcome " + this.name);
};

user.greet();

Output:

Welcome Rahul

Common Built-in Object Methods

Method Use
Object.keys() Object ki keys ka Array return karta hai.
Object.values() Object ki values ka Array return karta hai.
Object.entries() Key-value pairs ka Array return karta hai.
Object.assign() Properties ko ek object se dusre object me copy karta hai.
Object.hasOwn() Check karta hai object ki apni property exist karti hai ya nahi.

Object.keys() 

const student = {
  name: "Ali",
  age: 20
};

console.log(Object.keys(student));

Output:

["name", "age"]

Object.values() 

const student = {
  name: "Ali",
  age: 20
};

console.log(Object.values(student));

Output:

["Ali", 20]

Object.entries() 

const student = {
  name: "Ali",
  age: 20
};

console.log(Object.entries(student));

Output:

[
  ["name", "Ali"],
  ["age", 20]
]

Object.assign() 

const user = {
  name: "Ali"
};

const details = {
  age: 20
};

Object.assign(user, details);

console.log(user);

Output:

{ name: "Ali", age: 20 }

Object.hasOwn() 

const student = {
  name: "Ali"
};

console.log(
  Object.hasOwn(
    student,
    "name"
  )
);

Output:

true

Object Property vs Object Method

Property Method
Object ka data/value hota hai. Object ke andar function hota hai.
student.name student.greet()
Parentheses nahi lagte. Method call me parentheses lagte hain.

Important Points

1. Object ke andar function ko Object Method kaha jata hai.

2. Method ko object.method() syntax se call karte hain.

3. Modern JavaScript me short method syntax methodName() { } use kar sakte hain.

4. this se current object ki properties access ki ja sakti hain.

5. Methods parameters receive aur values return kar sakti hain.

6. Object.keys(), Object.values() aur Object.entries() object data process karne ke important built-in methods hain.
