Object Ko Display Kaise Karte Hain?

JavaScript Object ko direct page par display karne ke liye object ki properties ko access karna, loop use karna, ya JSON.stringify() ka use karna padta hai.

Agar hum object ko direct String ke saath display karne ki koshish karein, to aksar [object Object] result milta hai.

Example Object 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

Display Object in Console

Object ko inspect karne ka sabse simple tarika console.log() hai. 

const student = {
  name: "Ali",
  age: 20
};

console.log(student);

Output:

{ name: "Ali", age: 20 }

Display Object Property

Object ki individual properties ko dot notation se display kar sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

console.log(student.name);
console.log(student.age);

Output:

Ali
20

Display Object Data in HTML

Object ki properties ko DOM ke through webpage par show kar sakte hain. 

<p id="demo"></p>

<script>

const student = {
  name: "Ali",
  age: 20
};

document.getElementById("demo").innerHTML =
  student.name + " - " + student.age;

</script>

Output:

Ali - 20

Display With Template Literal

Template Literals se object properties ko readable tarike se display kar sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

let text =
  `Name: ${student.name}, Age: ${student.age}`;

console.log(text);

Output:

Name: Ali, Age: 20

Display Object With for...in

for...in loop object ki enumerable properties ko iterate karne ke liye use kiya ja sakta hai. 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

for (let key in student) {
  console.log(key + ": " + student[key]);
}

Output:

name: Ali
age: 20
course: JavaScript

Display With Object.values()

Object.values() object ki own enumerable property values ka Array return karta hai. 

const student = {
  name: "Ali",
  age: 20
};

let values = Object.values(student);

console.log(values);

Output:

["Ali", 20]

Display With Object.entries()

Object.entries() object ke key-value pairs return karta hai. 

const student = {
  name: "Ali",
  age: 20
};

console.log(Object.entries(student));

Output:

[
  ["name", "Ali"],
  ["age", 20]
]

Display With JSON.stringify()

JSON.stringify() JavaScript value ko JSON String representation me convert karta hai. Plain data objects ko text ke form me display karne ke liye ye useful hai. 

const student = {
  name: "Ali",
  age: 20
};

let text = JSON.stringify(student);

console.log(text);

Output:

{"name":"Ali","age":20}

Pretty JSON Display

JSON ko readable format me print karne ke liye third argument me spaces de sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

console.log(
  JSON.stringify(student, null, 2)
);

Output:

{
  "name": "Ali",
  "age": 20
}

Direct Object Display Problem

Object ko normal String ke saath concatenate karne par useful object data nahi milta. 

const student = {
  name: "Ali"
};

console.log("Student: " + student);

Output:

Student: [object Object]

Isliye specific properties access karo ya JSON.stringify() use karo.

Object Display Methods

Method Use
console.log(object) Development/debugging me object inspect karne ke liye.
object.property Specific property display karne ke liye.
for...in Properties ko iterate karne ke liye.
Object.values() Object values ka Array lene ke liye.
Object.entries() Key-value pairs lene ke liye.
JSON.stringify() Object data ko JSON String me convert karne ke liye.

Important Points

1. Object inspect karne ke liye console.log() useful hai.

2. Specific data ke liye object properties ko directly access karna best hai.

3. for...in se properties par loop chala sakte hain.

4. Object.values() sirf values return karta hai.

5. Object.entries() key-value pairs return karta hai.

6. JSON.stringify() plain object data ko JSON String me convert karta hai.

7. Object ko String ke saath direct concatenate karne par [object Object] mil sakta hai.
