Object Property Kya Hai?

JavaScript Object ke andar jo values store hoti hain unhe properties kaha jata hai.

Har property ek key : value pair hoti hai. Jaise name: "Ali" me name property name hai aur "Ali" uski value hai.

Object Property Syntax 

const objectName = {
  propertyName: value
};

Object Property Example 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

console.log(student.name);

Output:

Ali

Dot Notation

Dot notation object property access karne ka simple tarika hai. 

const user = {
  name: "Rahul",
  age: 21
};

console.log(user.name);
console.log(user.age);

Output:

Rahul
21

Bracket Notation

Bracket notation me property name String ke form me diya jata hai. 

const user = {
  name: "Rahul"
};

console.log(user["name"]);

Output:

Rahul

Dynamic Property Access

Agar property ka naam variable ke andar store ho, to bracket notation use karna useful hota hai. 

const student = {
  name: "Ali",
  age: 20
};

let key = "age";

console.log(student[key]);

Output:

20

Property Value Change Karna 

const student = {
  name: "Ali",
  age: 20
};

student.age = 21;

console.log(student.age);

Output:

21

New Property Add Karna 

const student = {
  name: "Ali"
};

student.city = "Ranchi";

console.log(student.city);

Output:

Ranchi

Property Delete Karna

delete operator se object ki property remove kar sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

delete student.age;

console.log(student);

Output:

{ name: "Ali" }

Property Exist Karti Hai Ya Nahi?

in operator se check kar sakte hain ki property object me available hai ya nahi. 

const student = {
  name: "Ali",
  age: 20
};

console.log("name" in student);

Output:

true

Object.keys()

Object.keys() object ke own enumerable property names ko Array me return karta hai. 

const student = {
  name: "Ali",
  age: 20,
  city: "Ranchi"
};

console.log(Object.keys(student));

Output:

["name", "age", "city"]

Loop Through Object Properties

for...in loop se object properties ko access kar sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

for (let key in student) {
  console.log(key, student[key]);
}

Output:

name Ali
age 20

Dot vs Bracket Notation

Dot Notation Bracket Notation
student.name student["name"]
Simple property names ke liye easy hai. Dynamic property name ke liye useful hai.
Variable se property name directly nahi le sakta. Variable ke through property access kar sakta hai.

Important Points

1. Object property ek key aur value pair hoti hai.

2. Dot notation: object.property

3. Bracket notation: object["property"]

4. Dynamic property names ke liye bracket notation useful hai.

5. Object properties add, update aur delete ki ja sakti hain.

6. Object.keys() se property names ki Array milti hai.

7. for...in se object properties par loop chala sakte hain.
