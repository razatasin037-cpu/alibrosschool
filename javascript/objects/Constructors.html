Object Constructor Kya Hai?

JavaScript me Object Constructor ek function hota hai jiska use same structure wale multiple objects create karne ke liye kiya jata hai.

Constructor Function ko generally capital letter se start kiya jata hai aur object create karne ke liye new keyword use hota hai.

Constructor Function Syntax 

function ObjectName(value1, value2) {

  this.property1 = value1;
  this.property2 = value2;

}

const obj =
  new ObjectName(value1, value2);

Simple Constructor Example 

function Student(name, age) {

  this.name = name;
  this.age = age;

}

const student1 =
  new Student(
    "Ali",
    20
  );

console.log(student1);

Output:

Student { name: "Ali", age: 20 }

Example Kaise Kaam Kar Raha Hai?

Student → Constructor Function ka naam hai.

name aur age → Constructor ke parameters hain.

this.name → New object ki name property banata hai.

this.age → New object ki age property banata hai.

new Student() → Constructor se naya object create karta hai.

Multiple Objects Create Karna

Constructor ka sabse bada fayda ye hai ki ek hi structure se multiple objects create kar sakte hain. 

function Student(name, age) {

  this.name = name;
  this.age = age;

}

const student1 =
  new Student(
    "Ali",
    20
  );

const student2 =
  new Student(
    "Rahul",
    22
  );

console.log(student1.name);
console.log(student2.name);

Output:

Ali
Rahul

Constructor With Method

Constructor Function ke andar method bhi create ki ja sakti hai. 

function Student(name, age) {

  this.name = name;
  this.age = age;

  this.greet = function() {
    return "Hello " + this.name;
  };

}

const student1 =
  new Student(
    "Ali",
    20
  );

console.log(student1.greet());

Output:

Hello Ali

Property Baad Me Add Karna 

function Student(name, age) {

  this.name = name;
  this.age = age;

}

const student1 =
  new Student(
    "Ali",
    20
  );

student1.city = "Ranchi";

console.log(student1.city);

Output:

Ranchi

Constructor Prototype

Agar same method sab objects ke liye share karni ho, to prototype use kiya ja sakta hai. 

function Student(name) {
  this.name = name;
}

Student.prototype.greet = function() {
  return "Hello " + this.name;
};

const student1 =
  new Student(
    "Ali"
  );

console.log(student1.greet());

Output:

Hello Ali

instanceof Operator

instanceof check karta hai ki object kisi particular constructor se related hai ya nahi. 

function Student(name) {
  this.name = name;
}

const student1 =
  new Student(
    "Ali"
  );

console.log(student1 instanceof Student);

Output:

true

Object Literal vs Constructor

Object Literal Constructor Function
Single ya few objects ke liye simple hai. Same structure ke multiple objects ke liye useful hai.
const user = { name: "Ali" }; new Student("Ali")
Direct object create hota hai. Template jaisa reusable structure milta hai.

Important Points

1. Constructor Function same structure ke multiple objects create karne ke liye useful hai.

2. Constructor ka naam commonly capital letter se start kiya jata hai.

3. new keyword se constructor se object create kiya jata hai.

4. this newly created object ko refer karta hai jab constructor new ke saath call hota hai.

5. prototype se shared methods add ki ja sakti hain.

6. instanceof constructor relationship check karne ke liye use hota hai.
