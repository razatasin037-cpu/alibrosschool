Object Kya Hai?

JavaScript me Object ek data structure hai jo multiple related values ko ek hi variable ke andar store karta hai.

Object ke andar data key : value pairs me store hota hai. Object me name, age, email, mobile jaise multiple properties ek saath rakhi ja sakti hain.

Object Syntax 

const objectName = {
  property1: value1,
  property2: value2
};

Object ko curly braces { } ke andar likha jata hai. Har property me key aur value hoti hai.

Object Example

Is example me ek student ki information Object ke andar store karenge. 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

console.log(student);

Output:

{ name: "Ali", age: 20, course: "JavaScript" }

Example Kaise Kaam Kar Raha Hai?

student → Object ka variable name hai.

name, age aur course → Object ki properties hain.

"Ali", 20 aur "JavaScript" → Properties ki values hain.

Object Property Access - Dot Notation

Object ki property ko dot . notation se access kar sakte hain. 

const student = {
  name: "Ali",
  age: 20
};

console.log(student.name);

Output:

Ali

Object Property Access - Bracket Notation 

const student = {
  name: "Ali",
  age: 20
};

console.log(student["age"]);

Output:

20

Object Property Change Karna 

const student = {
  name: "Ali",
  age: 20
};

student.age = 21;

console.log(student.age);

Output:

21

New Property Add Karna 

const student = {
  name: "Ali"
};

student.city = "Delhi";

console.log(student.city);

Output:

Delhi

Object Property Delete Karna 

const student = {
  name: "Ali",
  age: 20
};

delete student.age;

console.log(student);

Output:

{ name: "Ali" }

Object Method

Object ke andar function ko property ke roop me store kiya jaye to use Object Method kaha jata hai. 

const student = {

  name: "Ali",

  greet: function() {
    console.log("Hello");
  }

};

student.greet();

Output:

Hello

this Keyword in Object

Object method ke andar this ka use current object ki properties access karne ke liye kiya ja sakta hai. 

const student = {

  name: "Ali",

  greet: function() {
    console.log("Hello " + this.name);
  }

};

student.greet();

Output:

Hello Ali

Primitive Value vs Object

Primitive Object
Single value store karta hai. Multiple related values store kar sakta hai.
let name = "Ali"; const student = { name: "Ali", age: 20 };

Object Data Type Check 

const student = {
  name: "Ali"
};

console.log(typeof student);

Output:

object

Important Points

1. Object multiple related values ko ek variable me store karta hai.

2. Object data key : value pairs me store karta hai.

3. Object properties ko dot notation ya bracket notation se access kar sakte hain.

4. Existing property ki value change ki ja sakti hai.

5. Object me new properties add aur existing properties delete ki ja sakti hain.

6. Object ke andar function ko Object Method kehte hain.

7. typeof object ka result "object" hota hai.
