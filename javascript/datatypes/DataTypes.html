Data Type Kya Hai?

JavaScript me Data Type batata hai ki kisi variable ke andar kis type ka data store kiya gaya hai.

Jaise text ke liye String, numbers ke liye Number aur true/false ke liye Boolean use hota hai.

Simple Example 

let name = "Ali";

let age = 20;

let isStudent = true;

"Ali" → String

20 → Number

true → Boolean

1. String

String ka use text store karne ke liye hota hai. String ko single quotes, double quotes ya template literals me likh sakte hain. 

let name = "Prawez";

let city = 'Ranchi';

let message = `Hello JavaScript`;

console.log(name);
Prawez

2. Number

JavaScript me integers aur decimal numbers dono Number type hote hain. 

let age = 20;

let price = 499.99;

console.log(age);
console.log(price);
20
499.99

3. BigInt

Bahut bade integer numbers ko represent karne ke liye BigInt use hota hai. Number ke end me n lagaya jata hai. 

let bigNumber =
  12345678901234567890n;

console.log(bigNumber);
12345678901234567890n

4. Boolean

Boolean ke sirf do values hoti hain: true aur false. 

let isLogin =
  true;

let isAdmin =
  false;

console.log(isLogin);
console.log(isAdmin);
true
false

5. Undefined

Jab variable declare kiya gaya ho lekin usko value assign nahi ki gayi ho, uski value undefined hoti hai. 

let username;

console.log(username);
undefined

6. Null

null ka use intentionally empty value represent karne ke liye kiya jata hai. 

let selectedUser =
  null;

console.log(selectedUser);
null

7. Symbol

Symbol unique values create karne ke liye use hota hai. 

const id1 =
  Symbol("id");

const id2 =
  Symbol("id");

console.log(
  id1 === id2
);
false

8. Object

Object multiple related values ko key: value pairs me store karta hai. 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

console.log(
  student.name
);
Ali

9. Array

Array ka use ek variable me multiple values store karne ke liye hota hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(
  fruits[1]
);
Mango

10. Function

Function reusable code ka block hota hai. JavaScript me functions bhi objects ki tarah values hain. 

function greet() {
  return "Hello";
}

console.log(
  greet()
);
Hello

Data Type Check Karna

Kisi value ka type check karne ke liye typeof operator use hota hai. 

console.log(
  typeof "Hello"
);

console.log(
  typeof 100
);

console.log(
  typeof true
);
string
number
boolean

JavaScript Is Dynamically Typed

JavaScript me ek variable ki value ka type runtime par change ho sakta hai. 

let value =
  100;

console.log(
  typeof value
);

value =
  "Hello";

console.log(
  typeof value
);
number
string

Important: typeof null

JavaScript me typeof null ka result "object" aata hai. Ye JavaScript ka ek purana historical behavior hai. 

console.log(
  typeof null
);
object

Important Points

1. Data Type batata hai variable me kis type ki value stored hai.

2. JavaScript ke primitive types me String, Number, BigInt, Boolean, Undefined, Null aur Symbol aate hain.

3. Objects ke examples me Object, Array, Function, Date, Map aur Set aate hain.

4. typeof se value ka type check kar sakte hain.

5. typeof [] ka result "object" hota hai.

6. typeof null bhi "object" return karta hai.

7. JavaScript dynamically typed language hai, isliye variable ki value ka type change ho sakta hai.
