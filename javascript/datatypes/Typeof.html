typeof Kya Hai?

JavaScript me typeof ek operator hai jo kisi value ya variable ka type check karne ke liye use hota hai.

Jaise variable String hai, Number hai, Boolean hai ya Object hai, ye hum typeof se check kar sakte hain.

typeof Syntax 

typeof value;

// OR

typeof(value);

Dono syntax valid hain.

Simple Example 

let name = "Ali";

console.log(
  typeof name
);

Output:

string

typeof String 

let username =
  "Prawez";

console.log(
  typeof username
);
string

typeof Number 

let age =
  20;

let price =
  499.99;

console.log(
  typeof age
);

console.log(
  typeof price
);
number
number

typeof NaN

Interesting baat ye hai ki NaN ka typeof bhi "number" hota hai. 

console.log(
  typeof NaN
);
number

typeof Boolean 

let isLogin =
  true;

console.log(
  typeof isLogin
);
boolean

typeof Undefined 

let data;

console.log(
  typeof data
);
undefined

typeof BigInt 

let bigNumber =
  12345678901234567890n;

console.log(
  typeof bigNumber
);
bigint

typeof Symbol 

const id =
  Symbol("id");

console.log(
  typeof id
);
symbol

typeof Object 

const user = {
  name: "Ali",
  age: 20
};

console.log(
  typeof user
);
object

typeof Array

Array ka typeof result "object" hota hai. 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  typeof fruits
);
object

Array Ko Sahi Tarike Se Check Karna

Array check karne ke liye Array.isArray() use karna better hai. 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  Array.isArray(fruits)
);
true

typeof Function 

function greet() {
  return "Hello";
}

console.log(
  typeof greet
);
function

typeof null

JavaScript me typeof null ka result "object" aata hai. Ye JavaScript ka historical behavior hai. 

console.log(
  typeof null
);
object

typeof Date 

const today =
  new Date();

console.log(
  typeof today
);
object

Real Example

Condition ke saath bhi typeof use kar sakte hain. 

let age = 20;

if (
  typeof age === "number"
) {

  console.log(
    "Age is a number"
  );

} else {

  console.log(
    "Age is not a number"
  );

}
Age is a number

Important Points

1. typeof kisi value ka type check karta hai.

2. typeof "Hello" ka result "string" hota hai.

3. typeof 100 ka result "number" hota hai.

4. typeof NaN bhi "number" hota hai.

5. typeof [] ka result "object" hota hai.

6. Array check karne ke liye Array.isArray() use karna chahiye.

7. typeof null ka result bhi "object" hota hai.

8. Function ka typeof "function" return karta hai.
