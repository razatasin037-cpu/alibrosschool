Type Conversion Kya Hai?

JavaScript me Type Conversion ka matlab hai ek data type ko dusre data type me convert karna.

Jaise String ko Number me, Number ko String me ya kisi value ko Boolean me convert karna.

Type Conversion Ke 2 Types

Explicit Conversion

Jab hum khud String(), Number() ya Boolean() use karke type convert karte hain.

Implicit Conversion

Jab JavaScript automatically ek type ko dusre type me convert karta hai.

Convert To String

String() kisi value ko String me convert karta hai. 

let age = 20;

let result =
  String(age);

console.log(result);

console.log(
  typeof result
);
20
string

Number.toString() 

let number =
  100;

let text =
  number.toString();

console.log(text);

console.log(
  typeof text
);
100
string

Convert String To Number

Number() numeric String ko Number me convert kar sakta hai. 

let age =
  "20";

let result =
  Number(age);

console.log(result);

console.log(
  typeof result
);
20
number

Invalid String To Number

Agar String valid numeric value nahi hai to Number() ka result NaN aa sakta hai. 

let value =
  "Hello";

console.log(
  Number(value)
);
NaN

parseInt()

parseInt() String ke starting numeric part ko integer me convert karta hai. 

let price =
  "150px";

let result =
  parseInt(price);

console.log(result);
150

parseFloat()

parseFloat() decimal numeric String ko Number me convert karta hai. 

let price =
  "99.50";

let result =
  parseFloat(price);

console.log(result);
99.5

Convert To Boolean

Boolean() kisi value ko true ya false me convert karta hai. 

console.log(
  Boolean(1)
);

console.log(
  Boolean(0)
);

console.log(
  Boolean("Hello")
);

console.log(
  Boolean("")
);
true
false
true
false

Ye values Boolean conversion me generally false hoti hain: 

Boolean(false);

Boolean(-0);
Boolean(0n);
Boolean("");

Boolean(undefined);
Boolean(NaN);

console.log(
  Number(true)
);

console.log(
  Number(false)

1
0

null Aur undefined To Number 

console.log(
  Number(null)
);

console.log(
  Number(undefined)
);

NaN

Implicit Conversion With +

Agar + operator ke saath String ho, JavaScript dusri value ko String me convert kar sakta hai. 

let result =
  "10" + 5;

console.log(result);

console.log(
  typeof result
);
105
string

Implicit Conversion With - 

let result =
  "10" - 5;

console.log(result);

console.log(
  typeof result
);
5
number

Implicit Conversion With * 

console.log(
  "10" * 2
);

console.log(
  "5" / 2
);
20
2.5

HTML Input Value Ko Number Banana

HTML input ki value normally String hoti hai. Calculation se pehle Number me convert karna useful hota hai. 

<input
  type="number"
  id="age"
>

<script>

const value =
  document.getElementById(
    "age"
  ).value;

const age =
  Number(value);

</script>

Quick Conversion Reference

Code Result Type
String(100) "100" String
Number("100") 100 Number
parseInt("20px") 20 Number
parseFloat("10.5") 10.5 Number
Boolean(1) true Boolean
Boolean(0) false Boolean

Important Points

1. String() value ko String me convert karta hai.

2. Number() compatible value ko Number me convert karta hai.

3. parseInt() integer parse karta hai.

4. parseFloat() decimal number parse karta hai.

5. Boolean() value ko true ya false me convert karta hai.

6. "10" + 5 ka result String "105" hota hai.

7. "10" - 5 ka result Number 5 hota hai.

8. Form input values ke saath type conversion bahut important hota hai.
