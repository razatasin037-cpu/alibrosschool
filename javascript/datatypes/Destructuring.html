Destructuring Kya Hai?

JavaScript me Destructuring ka use Array ya Object ke andar se values ko easily alag-alag variables me nikalne ke liye hota hai.

Isse code chhota, clean aur readable ho jata hai.

Normal Way vs Destructuring

Normal Way 

const user = {
  name: "Ali",
  age: 20
};

const name =
  user.name;

const age =
  user.age;

Destructuring 

const user = {
  name: "Ali",
  age: 20
};

const {
  name,
  age
} = user;

Array Destructuring Syntax 

const [
  first,
  second
] = array;

Array Destructuring Example 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

const [
  first,
  second,
  third
] = fruits;

console.log(first);
console.log(second);
console.log(third);

Output:

Apple
Mango
Banana

Array Value Skip Karna 

const colors = [
  "Red",
  "Blue",
  "Green"
];

const [
  first,
  ,
  third
] = colors;

console.log(first);
console.log(third);
Red
Green

Array Default Value 

const numbers = [
  10
];

const [
  a,
  b = 20
] = numbers;

console.log(a);
console.log(b);
10
20

Array Destructuring With Rest

Rest operator ... remaining values ko ek Array me collect karta hai. 

const numbers = [
  10,
  20,
  30,
  40
];

const [
  first,
  ...rest
] = numbers;

console.log(first);
console.log(rest);
10
[20, 30, 40]

Variables Swap Karna 

let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a);
console.log(b);
20
10

Object Destructuring Syntax 

const {
  property1,
  property2
} = object;

Object Destructuring Example 

const student = {
  name: "Ali",
  age: 20,
  course: "JavaScript"
};

const {
  name,
  age,
  course
} = student;

console.log(name);
console.log(age);
console.log(course);
Ali
20
JavaScript

Property Ko New Variable Name Dena 

const user = {
  name: "Ali",
  age: 20
};

const {
  name: username,
  age: userAge
} = user;

console.log(username);
console.log(userAge);
Ali
20

Object Default Value 

const user = {
  name: "Ali"
};

const {
  name,
  role = "User"
} = user;

console.log(name);
console.log(role);
Ali
User

Object Destructuring With Rest 

const user = {
  id: 1,
  name: "Ali",
  age: 20,
  city: "Ranchi"
};

const {
  id,
  ...details
} = user;

console.log(id);
console.log(details);
1

{
  name: "Ali",
  age: 20,
  city: "Ranchi"
}

Nested Object Destructuring 

const user = {
  name: "Ali",

  address: {
    city: "Ranchi",
    state: "Jharkhand"
  }
};

const {
  name,
  address: {
    city,
    state
  }
} = user;

console.log(name);
console.log(city);
console.log(state);
Ali
Ranchi
Jharkhand

Function Parameter Destructuring 

const user = {
  name: "Ali",
  age: 20
};

function showUser({
  name,
  age
}) {

  console.log(name);
  console.log(age);

}

showUser(user);
Ali
20

Array Destructuring In Function 

function showColors([
  first,
  second
]) {

  console.log(first);
  console.log(second);

}

showColors([
  "Red",
  "Blue"
]);
Red
Blue

Real Project Example

API response se required data easily destructure kar sakte ho. 

const response = {
  data: {
    id: 1,
    name: "Laptop",
    price: 50000
  }
};

const {
  data: {
    id,
    name,
    price
  }
} = response;

console.log(name);
console.log(price);
Laptop
50000

React Me Destructuring

React me props aur hooks ke saath destructuring bahut commonly use hoti hai. 

// Props Destructuring

function User({
  name,
  age
}) {

  return (
    <h1>
      {name} - {age}
    </h1>
  );

}

useState Destructuring 

const [
  count,
  setCount
] = useState(0);

Yahan useState() se milne wale Array ko destructure karke count aur setCount nikale ja rahe hain.

Array vs Object Destructuring

Array Object
Square brackets [] use hote hain. Curly braces {} use hote hain.
Position important hoti hai. Property name important hota hai.
const [a, b] = arr const {name, age} = user

Important Points

1. Destructuring Array aur Object se values easily nikalne ke liye use hoti hai.

2. Array destructuring me [] use hota hai.

3. Object destructuring me {} use hota hai.

4. Array destructuring me position important hoti hai.

5. Object destructuring me property name important hota hai.

6. Default values bhi assign kar sakte hain.

7. Rest operator ... remaining values collect karta hai.

8. Nested Objects ko bhi destructure kiya ja sakta hai.

9. React me Props aur useState() ke saath destructuring bahut important hai.
