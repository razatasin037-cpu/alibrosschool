Date Formats Kya Hain?

JavaScript me Date ko different formats me create aur display kiya ja sakta hai.

Sabse common aur reliable format ISO format hota hai, jaise YYYY-MM-DD.

Common Date Formats

Format Example Use
YYYY-MM-DD 2026-09-10 ISO date format
YYYY-MM-DDTHH:mm:ssZ 2026-09-10T10:30:00Z ISO date and time
Month DD, YYYY September 10, 2026 Readable date string

ISO Date Format

ISO format date likhne ka standard format hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date);

Format:

YYYY-MM-DD

ISO Date With Time 

const date =
  new Date(
    "2026-09-10T10:30:00Z"
  );

console.log(date.toISOString());

Output:

2026-09-10T10:30:00.000Z

T Aur Z Ka Meaning

T date aur time ko separate karta hai.

Z UTC timezone ko represent karta hai. 

2026-09-10T10:30:00Z

Date Only Format 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date.toDateString());

Example Output:

Thu Sep 10 2026

Readable Date String 

const date =
  new Date(
    "September 10, 2026"
  );

console.log(date.toDateString());

Example Output:

Thu Sep 10 2026

Numeric Date Format

Date ko numbers ke through bhi create kar sakte hain. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(date.toDateString());

Output:

Thu Sep 10 2026

Yahan 8 ka matlab September hai, kyunki numeric constructor me month zero-based hota hai.

toString()

toString() Date object ko readable date-time String me convert karta hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(date.toString());

toDateString()

Sirf readable date portion return karta hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(date.toDateString());
Thu Sep 10 2026

toTimeString()

Date object ke time portion ko String me return karta hai. 

const date =
  new Date();

console.log(date.toTimeString());

toLocaleDateString()

Date ko locale-friendly format me display karta hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(
  date.toLocaleDateString(
    "en-IN"
  )
);

Output:

10/9/2026

Custom Date Format

toLocaleDateString() ke options se custom readable format bana sakte hain. 

const date =
  new Date(
    2026,
    8,
    10
  );

const options = {
  day: "numeric",
  month: "long",
  year: "numeric"
};

console.log(
  date.toLocaleDateString(
    "en-IN",
    options
  )
);

Output:

10 September 2026

toLocaleTimeString()

Time ko locale ke according readable form me show karta hai. 

const date =
  new Date();

console.log(
  date.toLocaleTimeString(
    "en-IN"
  )
);

Date Formatting Quick Reference

Method Result
toString() Date + time readable String
toDateString() Date portion
toTimeString() Time portion
toISOString() ISO UTC format
toLocaleDateString() Locale date
toLocaleTimeString() Locale time

Important Points

1. ISO format: YYYY-MM-DD.

2. ISO date-time me T date aur time ko separate karta hai.

3. Z UTC ko represent karta hai.

4. Numeric Date constructor me months 0 - 11 hote hain.

5. toISOString() standard UTC format return karta hai.

6. toLocaleDateString() user-friendly date formatting ke liye useful hai.

7. Non-standard date Strings browser ke hisaab se differently parse ho sakti hain, isliye predictable input ke liye ISO format prefer karo.
