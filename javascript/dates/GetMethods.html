Date Get Methods Kya Hain?

JavaScript Date Get Methods ka use Date object se year, month, date, day, hours, minutes, seconds aur milliseconds jaise parts ko read karne ke liye hota hai.

Jaise getFullYear(), getMonth(), getDate() aur getDay().

Date Get Methods List

Method Use
getFullYear() Year return karta hai.
getMonth() Month return karta hai, 0 se 11 tak.
getDate() Month ka date/day number return karta hai.
getDay() Week day return karta hai, 0 se 6 tak.
getHours() Hours return karta hai.
getMinutes() Minutes return karta hai.
getSeconds() Seconds return karta hai.
getMilliseconds() Milliseconds return karta hai.
getTime() Unix epoch se milliseconds return karta hai.

getFullYear()

getFullYear() Date object se complete year return karta hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date.getFullYear());

Output:

2026

getMonth()

getMonth() month ka number return karta hai. January = 0 aur December = 11. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(date.getMonth());

Output:

8

8 ka matlab September hai.

Normal Month Number Kaise Nikale? 

const date =
  new Date(
    2026,
    8,
    10
  );

let month = date.getMonth() + 1;

console.log(month);

Output:

9

getTime()

Date ko Unix epoch se milliseconds me return karta hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date.getTime());

Complete Date Get Example 

const date =
  new Date(
    2026,
    8,
    10,
    14,
    30,
    45
  );

console.log("Year:", date.getFullYear());
console.log("Month:", date.getMonth() + 1);
console.log("Date:", date.getDate());
console.log("Day:", date.getDay());
console.log("Hours:", date.getHours());
console.log("Minutes:", date.getMinutes());
console.log("Seconds:", date.getSeconds());

Output:

Year: 2026
Month: 9
Date: 10
Day: 4
Hours: 14
Minutes: 30
Seconds: 45

getDate() vs getDay()

getDate() getDay()
Month ka date return karta hai. Week ka day return karta hai.
Range: 1 - 31 Range: 0 - 6
10 4 = Thursday

UTC Get Methods

Normal get... methods local timezone ke according values return karte hain. UTC values ke liye UTC methods available hain.

getUTCFullYear() UTC year
getUTCMonth() UTC month
getUTCDate() UTC date
getUTCDay() UTC weekday
getUTCHours() UTC hours

Important Points

1. getFullYear() complete year deta hai.

2. getMonth() ka range 0 - 11 hota hai.

3. getDate() month ka date 1 - 31 return karta hai.

4. getDay() week day 0 - 6 return karta hai.

5. getHours() ka range 0 se 23 hota hai.

6. getTime() milliseconds timestamp return karta hai.

7. UTC ke liye getUTC... methods use kar sakte hain.
