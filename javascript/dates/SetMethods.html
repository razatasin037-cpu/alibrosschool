JavaScript Date Set Methods

Date Set Methods Kya Hain?

JavaScript Date Set Methods ka use existing Date object ke year, month, date, hours, minutes, seconds aur milliseconds ko change karne ke liye kiya jata hai.

Jaise setFullYear(), setMonth(), setDate() aur setHours().

Date Set Methods List

Method Use
setFullYear() Year change karta hai.
setMonth() Month change karta hai.
setDate() Month ka date change karta hai.
setHours() Hours change karta hai.
setMinutes() Minutes change karta hai.
setSeconds() Seconds change karta hai.
setMilliseconds() Milliseconds change karta hai.
setTime() Unix epoch se milliseconds ke through complete date/time set karta hai.

setFullYear()

setFullYear() Date object ka year change karta hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

date.setFullYear(2030);

console.log(date.getFullYear());

Output:

2030

setMonth()

setMonth() Date object ka month change karta hai. Month number 0 - 11 hota hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

date.setMonth(11);

console.log(date.getMonth());

Output:

11

11 ka matlab December hai.

setDate()

setDate() month ke andar date number change karta hai. 

const date =
  new Date(
    2026,
    8,
    10
  );

date.setDate(20);

console.log(date.getDate());

Output:

20

Date Me Days Add Karna

getDate() aur setDate() ko combine karke date me days add kar sakte hain. 

const date =
  new Date(
    2026,
    8,
    10
  );

date.setDate(
  date.getDate() + 5
);

console.log(date.toDateString());

Output:

Tue Sep 15 2026

setHours()

Hours ko 0 se 23 ke range me set kiya ja sakta hai. 

const date =
  new Date();

date.setHours(18);

console.log(date.getHours());

Output:

18

setMinutes() 

const date =
  new Date();

date.setMinutes(45);

console.log(date.getMinutes());

Output:

45

setSeconds() 

const date =
  new Date();

date.setSeconds(30);

console.log(date.getSeconds());

Output:

30

setMilliseconds() 

const date =
  new Date();

date.setMilliseconds(500);

console.log(date.getMilliseconds());

Output:

500

setTime()

setTime() milliseconds timestamp se complete Date object ka time change karta hai. 

const date =
  new Date();

date.setTime(0);

console.log(date.toISOString());

Output:

1970-01-01T00:00:00.000Z

setFullYear() With Month and Date

setFullYear() me year ke saath month aur date bhi pass kiye ja sakte hain. 

const date =
  new Date();

date.setFullYear(
  2030,
  11,
  25
);

console.log(date.toDateString());

Example Output:

Wed Dec 25 2030

Date Automatically Adjust Hoti Hai

Agar date ya month normal range se bahar chala jaye, JavaScript Date automatically next ya previous month/year me adjust kar sakta hai. 

const date =
  new Date(
    2026,
    8,
    30
  );

date.setDate(35);

console.log(date.toDateString());

September ke day 35 ko JavaScript October ki corresponding date me adjust kar dega.

UTC Set Methods

UTC timezone ke according date modify karne ke liye UTC set methods use kiye ja sakte hain.

setUTCFullYear() UTC year set karta hai.
setUTCMonth() UTC month set karta hai.
setUTCDate() UTC date set karta hai.
setUTCHours() UTC hours set karta hai.
setUTCMinutes() UTC minutes set karta hai.
setUTCSeconds() UTC seconds set karta hai.

Get Methods vs Set Methods

Get Method Set Method
getFullYear() setFullYear()
Value read karta hai. Value change karta hai.
date.getMonth() date.setMonth(11)

Important Points

1. setFullYear() year change karta hai.

2. setMonth() me month 0 se 11 tak hota hai.

3. setDate() month ka date change karta hai.

4. setHours(), setMinutes() aur setSeconds() time change karte hain.

5. setTime() timestamp milliseconds se complete date/time set karta hai.

6. Range se bahar value dene par Date object automatic adjustment kar sakta hai.

7. UTC date change karne ke liye setUTC... methods available hain.
