JavaScript Date Kya Hai?

JavaScript me Date object ka use date aur time ke saath kaam karne ke liye kiya jata hai.

Iski help se hum current date, current time, year, month, day, hours, minutes aur seconds ko get ya change kar sakte hain.

Date Syntax 

const date = new Date();

new Date() ek naya JavaScript Date object create karta hai.

Current Date and Time

Bina argument ke new Date() current date aur time ka Date object banata hai. 

const date = new Date();

console.log(date);

Example Output:

Thu Sep 10 2026 13:18:00 GMT+0530

Note: Exact output device ke current date, time aur timezone par depend karega.

Specific Date Create Karna

Hum year, month aur day dekar specific Date object create kar sakte hain. 

const date =
  new Date(
    2026,
    8,
    10
  );

console.log(date);

Date:

September 10, 2026

Important: JavaScript Months

Numeric Date constructor me JavaScript months 0 se start hote hain.

Month Number
January 0
February 1
March 2
... ...
September 8
December 11

Date With Time

Date constructor me year, month, day ke saath hours, minutes, seconds aur milliseconds bhi diye ja sakte hain. 

const date =
  new Date(
    2026,
    8,
    10,
    10,
    30,
    0
  );

console.log(date);

Meaning:

10 September 2026, 10:30:00

Date Constructor Parameters 

new Date(
  year,
  month,
  day,
  hours,
  minutes,
  seconds,
  milliseconds
);
Parameter Meaning
year Year
month Month (0 - 11)
day Day of month
hours Hours
minutes Minutes
seconds Seconds
milliseconds Milliseconds

Create Date From String

Date String se bhi Date object create kiya ja sakta hai. Standard ISO-style format use karna better hota hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date);

Date From Milliseconds

JavaScript Date ko milliseconds value se bhi create kiya ja sakta hai. Ye milliseconds 1 January 1970, 00:00:00 UTC se count kiye jate hain. 

const date =
  new Date(
    0
  );

console.log(date);

0 Unix epoch ko represent karta hai. Console ka displayed time timezone ke according differ kar sakta hai.

Date.now()

Date.now() current time ko Unix epoch se milliseconds ke form me return karta hai. 

const time = Date.now();

console.log(time);

Example Output:

1789026480000

Number har time change hota rahega.

getTime()

getTime() Date object ka timestamp milliseconds me return karta hai. 

const date = new Date();

console.log(date.getTime());

toDateString()

toDateString() Date object ke date portion ko readable string me convert karta hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date.toDateString());

Example Output:

Thu Sep 10 2026

toISOString()

toISOString() date ko standard ISO format me UTC time ke saath return karta hai. 

const date =
  new Date(
    "2026-09-10"
  );

console.log(date.toISOString());

Output:

2026-09-10T00:00:00.000Z

Date Is An Object 

const date = new Date();

console.log(typeof date);

Output:

object

Common Ways To Create Dates

Code Use
new Date() Current date and time
new Date("2026-09-10") Date string se Date object
new Date(2026, 8, 10) Year, month aur day se date
new Date(0) Milliseconds from Unix epoch

Important Points

1. new Date() Date object create karta hai.

2. Bina arguments ke new Date() current date aur time leta hai.

3. Numeric constructor me January 0 aur December 11 hota hai.

4. Date object me date ke saath time bhi store hota hai.

5. Date.now() current timestamp milliseconds me deta hai.

6. getTime() Date object ka timestamp return karta hai.

7. toISOString() standard UTC ISO date-time string deta hai.

8. typeof new Date() ka result "object" hota hai.
