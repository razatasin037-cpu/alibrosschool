JSON.parse() Kya Hai?

JavaScript me JSON.parse() ka use valid JSON string ko JavaScript value me convert karne ke liye hota hai.

Usually JSON string ko object ya array me convert karke uske data ko access karne ke liye iska use kiya jata hai.

JSON.parse() Syntax 

JSON.parse(jsonString);

Basic Example 

const json =
  
    '{"name":"Ali","age":20}'
  ;

const user =
  JSON.parse(json);

console.log(user);
{
  name: "Ali",
  age: 20
}

Parsed Object Ki Property Access Karna 

const json =
  
    '{"name":"Ali","age":20}'
  ;

const user =
  JSON.parse(json);

console.log(
  user.name
);

console.log(
  user.age
);
Ali
20

Invalid JSON Parse

Invalid JSON ko parse karne par SyntaxError aata hai. 

const json =
  
    '{"name":"Ali",}'
  ;

const user =
  JSON.parse(json);
SyntaxError

JSON.parse() With Try Catch

Unknown JSON data parse karte waqt try...catch use karna helpful hota hai. 

const json =
  
    '{"name":"Ali",}'
  ;

try {

  const user =
    JSON.parse(json);

  console.log(user);

} catch (error) {

  console.log(
    
      "Invalid JSON"
    
  );

}
Invalid JSON

Parse Error Message Check Karna 

try {

  JSON.parse(
    
      '{"name":"Ali",}'
    
  );

} catch (error) {

  console.log(
    error.name
  );

  console.log(
    error.message
  );

}

Error message browser ke according thoda different ho sakta hai, lekin error type generally SyntaxError hota hai.

localStorage Se JSON Parse Karna

localStorage se object retrieve karne ke baad us string ko JSON.parse() karna padta hai. 

localStorage.setItem(
  "user",
  
    '{"name":"Ali","age":20}'
  
);

const storedUser =
  localStorage.getItem(
    "user"
  );

const user =
  JSON.parse(storedUser);

console.log(
  user.name
);
Ali

localStorage Data Check Karna

Data use karne se pehle check karna useful hai ki value actually available hai ya nahi. 

const storedUser =
  localStorage.getItem(
    "user"
  );

if (storedUser) {

  const user =
    JSON.parse(storedUser);

  console.log(
    user
  );

} else {

  console.log(
    
      "User not found"
    
  );

}

API Response Aur JSON Parsing

APIs commonly JSON response bhejti hain. Fetch API me response.json() response body ko read karke parsed JavaScript value return karta hai. 

async function getUsers() {

  const response =
    await fetch(
      
        "/api/users"
      
    );

  const data =
    await response.json();

  console.log(data);

}

response.json() vs JSON.parse()

Method Use
JSON.parse() Existing JSON string ko JavaScript value me convert karta hai.
response.json() Fetch response body ko read aur JSON ke roop me parse karta hai.

JSON.parse() Reviver

JSON.parse() ka optional second parameter reviver parsed values ko transform karne ke liye use kiya ja sakta hai. 

const json =
  
    '{"price":500}'
  ;

const product =
  JSON.parse(
    json,
    (key, value) => {

      if (
        key ===
        "price"
      ) {

        return
          value * 2;

      }

      return value;

    }
  );

console.log(
  product.price
);
1000

Common Mistakes

1. Invalid JSON string ko parse karna.

2. JSON object keys me double quotes use nahi karna.

3. Trailing comma rakhna.

4. Already JavaScript object par unnecessary JSON.parse() lagana.

5. External JSON parse karte waqt error handling nahi karna.

Wrong vs Correct

Wrong 

JSON.parse(
  '{name:"Ali"}'
);

Correct 

JSON.parse(
  
    '{"name":"Ali"}'
  
);

Important Points

1. JSON.parse() valid JSON string ko JavaScript value me convert karta hai.

2. JSON object string parse hone ke baad JavaScript object ban jata hai.

3. JSON array string parse hone ke baad JavaScript array ban jata hai.

4. Invalid JSON parse karne par SyntaxError aata hai.

5. Unknown JSON parse karte waqt try...catch useful hota hai.

6. Parsed object ki properties dot notation se access kar sakte hain.

7. JSON.parse() localStorage data ke saath commonly use hota hai.

8. response.json() aur JSON.parse() related hain, lekin same method nahi hain.

9. reviver se parsing ke time values transform ki ja sakti hain.

10. Object ko JSON string me convert karne ke liye JSON.stringify() use hota hai.
