JSON Kya Hai?

JSON ka full form JavaScript Object Notation hai.

JSON ek lightweight text format hai jo data ko store aur transfer karne ke liye use hota hai.

APIs me server aur frontend ke beech data exchange karne ke liye JSON bahut commonly use hota hai.

Simple JSON Example 

{
  "name": "Ali",
  "age": 20,
  "city": "Ranchi"
}

JSON Syntax Rules

1. JSON data key : value pair me hota hai.

2. Keys double quotes " " ke andar honi chahiye.

3. String values bhi double quotes me hoti hain.

4. Multiple properties ko comma se separate kiya jata hai.

5. JSON object curly braces { } me hota hai.

6. JSON array square brackets [ ] me hota hai.

JSON Object

JSON object curly braces ke andar key-value pairs store karta hai. 

{
  "product": "Laptop",
  "price": 50000,
  "stock": 10
}

JSON Array

JSON array multiple values ko square brackets me store karta hai. 

[
  "HTML",
  "CSS",
  "JavaScript"
]

JSON Array Of Objects 

[
  {
    "id": 1,
    "name": "Ali"
  },
  {
    "id": 2,
    "name": "Ahmed"
  }
]

Nested JSON

JSON ke andar object ke andar dusra object bhi ho sakta hai. 

{
  "name": "Ali",

  "address": {
    "city": "Ranchi",
    "state": "Jharkhand"
  }
}

JSON vs JavaScript Object

JavaScript Object 

const user = {
  name: "Ali",
  age: 20
};

JSON 

{
  "name": "Ali",
  "age": 20
}

JSON Aur JavaScript Object Me Difference

JSON JavaScript Object
Text format hai. JavaScript data structure hai.
Keys double quotes me hoti hain. Keys quotes ke bina bhi ho sakti hain.
Functions allowed nahi hain. Functions/methods ho sakte hain.
Data transfer me commonly use hota hai. JavaScript code ke andar use hota hai.

Invalid JSON Example

JSON keys ko double quotes me likhna zaroori hai.

Invalid 

{
  name: "Ali",
  age: 20
}

Valid 

{
  "name": "Ali",
  "age": 20
}

Trailing Comma Allowed Nahi Hai

Invalid 

{
  "name": "Ali",
  "age": 20,
}

Valid

  "name": "Ali",

Fetch API Me JSON 

async function getProducts() {

  const response =
    await fetch(
      "/api/products"
    );

  const data =
    await response.json();

  console.log(data);

}

getProducts();

response.json() response body ko read karke JavaScript value me convert karta hai.

JSON.parse()

JSON string ko JavaScript object me convert karne ke liye JSON.parse() use hota hai. 

const json =
  
    '{"name":"Ali","age":20}'
  ;

const user =
  JSON.parse(json);

console.log(user.name);
Ali

JSON.stringify()

JavaScript object ko JSON string me convert karne ke liye JSON.stringify() use hota hai. 

const user = {
  name: "Ali",
  age: 20
};

const json =
  JSON.stringify(user);

console.log(json);
{"name":"Ali","age":20}

JSON With localStorage

localStorage strings store karta hai, isliye objects save karne ke liye JSON useful hota hai. 

const user = {
  name: "Ali",
  age: 20
};

localStorage.setItem(
  "user",
  JSON.stringify(user)
);

const savedUser =
  JSON.parse(
    localStorage.getItem(
      "user"
    )
  );

console.log(
  savedUser.name
);
Ali

JSON Kahan Use Hota Hai?

1. REST APIs me data send aur receive karne me.

2. Frontend aur backend communication me.

3. Configuration files me.

4. localStorage me object data store karne me.

5. Different programming languages ke beech data exchange me.

6. React, Laravel, Node.js aur mobile applications me.

Important Points

1. JSON ka full form JavaScript Object Notation hai.

2. JSON ek text-based data format hai.

3. JSON data key-value pairs me hota hai.

4. JSON object me keys double quotes me honi chahiye.

5. JSON arrays aur nested objects support karta hai.

6. JSON functions ko directly support nahi karta.

7. JSON.parse() JSON string ko JavaScript value me convert karta hai.

8. JSON.stringify() JavaScript value ko JSON string me convert karta hai.

9. APIs me JSON sabse commonly used data formats me se ek hai.

10. JSON aur JavaScript object similar dikhte hain, lekin dono exactly same nahi hain.
