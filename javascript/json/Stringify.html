JSON.stringify() Kya Hai?

JavaScript me JSON.stringify() ka use JavaScript value ko JSON string me convert karne ke liye hota hai.

Ye mainly object ya array ko API, localStorage ya kisi aur system me string format me bhejne ya save karne ke kaam aata hai.

JSON.stringify() Syntax 

JSON.stringify(value);

Basic Example 

const user = {
  name: "Ali",
  age: 20
};

const json =
  JSON.stringify(user);

console.log(json);
{"name":"Ali","age":20}

Stringify Se Pehle Aur Baad Me typeof 

const user = {
  name: "Ali"
};

console.log(
  typeof user
);

const json =
  JSON.stringify(user);

console.log(
  typeof json
);
object
string

Array Ko JSON String Me Convert Karna 

const skills = [
  "HTML",
  "CSS",
  "JavaScript"
];

const json =
  JSON.stringify(skills);

console.log(json);
["HTML","CSS","JavaScript"]

Pretty JSON

Third parameter use karke JSON output ko readable format me show kar sakte hain. 

const user = {
  name: "Ali",
  age: 20
};

const json =
  JSON.stringify(
    user,
    null,
    2
  );

console.log(json);
{
  "name": "Ali",
  "age": 20
}

JSON.stringify() Parameters 

JSON.stringify(
  value,
  replacer,
  space
);
Parameter Meaning
value Jo value JSON string me convert karni hai.
replacer Properties filter ya transform kar sakta hai.
space Pretty formatting ke liye indentation deta hai.

Replacer Array

Sirf selected properties ko JSON me include karne ke liye replacer array use kar sakte hain. 

const user = {
  name: "Ali",
  age: 20,
  city: "Ranchi"
};

const json =
  JSON.stringify(
    user,
    ["name", "city"]
  );

console.log(json);
{"name":"Ali","city":"Ranchi"}

Replacer Function 

const product = {
  name: "Laptop",
  price: 50000
};

const json =
  JSON.stringify(
    product,
    (key, value) => {

      if (
        key ===
        "price"
      ) {

        return
          value + 1000;

      }

      return value;

    }
  );

console.log(json);
{"name":"Laptop","price":51000}

undefined Property

Object ke andar undefined property JSON string me omit ho jati hai. 

const user = {
  name: "Ali",
  age: undefined
};

console.log(
  JSON.stringify(user)
);
{"name":"Ali"}

Function Property

Object ki function property bhi normal JSON output me include nahi hoti.

    console.log(
      "Hello"

  }
};

console.log(
  JSON.stringify(user)
);
{"name":"Ali"}

localStorage Me Object Save Karna

localStorage me object directly save nahi karna chahiye. Pehle use JSON string me convert karte hain. 

const user = {
  id: 1,
  name: "Ali",
  email:
    
      "ali@gmail.com"
    
};

localStorage.setItem(
  "user",
  JSON.stringify(user)
);

localStorage Complete Flow 

const user = {
  name: "Ali",
  age: 20
};

// Object to JSON string

localStorage.setItem(
  "user",
  JSON.stringify(user)
);


// Get JSON string

const stored =
  localStorage.getItem(
    "user"
  );


// JSON string to object

const savedUser =
  JSON.parse(stored);

console.log(
  savedUser.name
);
Ali

Fetch POST Request Me JSON.stringify()

Fetch API se JSON data POST karte waqt JSON.stringify() commonly use hota hai. 

const user = {
  name: "Ali",
  email:
    
      "ali@gmail.com"
    
};

fetch(
  "/api/users",
  {

    method:
      "POST",

    headers: {
      
        "Content-Type"
      :
      
        "application/json"
      
    },

    body:
      JSON.stringify(user)

  }
);

Complete API POST Example 

async function createUser() {

  const user = {
    name: "Ali",
    email:
      
        "ali@gmail.com"
      
  };

  try {

    const response =
      await fetch(
        
          "/api/users"
        ,
        {

          method:
            
              "POST"
            ,

          headers: {
            
              "Content-Type"
            :
            
              "application/json"
            
          },

          body:
            JSON.stringify(user)

        }
      );

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

createUser();

JSON.parse() vs JSON.stringify()

Method Conversion
JSON.parse() JSON String → JavaScript Value
JSON.stringify() JavaScript Value → JSON String

JSON.stringify() Flow

       ↓

 JSON.stringify()

       ↓

API / localStorage

Common Mistakes

1. Object ko localStorage me directly store karna.

2. Fetch POST request me object ko directly body me dena jab JSON body expected ho.

3. Stringify ke baad object properties directly access karna.

4. Functions aur undefined properties ko JSON me preserve hone ki expectation rakhna.

5. Circular object ko directly stringify karna.

Circular Reference Error

Agar object khud ko reference kare, normal JSON.stringify() error de sakta hai. 

const user = {
  name: "Ali"
};

user.self = user;

JSON.stringify(user);
TypeError:
Converting circular structure to JSON

Important Points

1. JSON.stringify() JavaScript value ko JSON string me convert karta hai.

2. Object stringify hone ke baad uska type string hota hai.

3. Arrays ko bhi JSON string me convert kiya ja sakta hai.

4. Pretty JSON ke liye third parameter me indentation de sakte hain.

5. Replacer se selected properties include ya values transform ki ja sakti hain.

6. Object ki undefined aur function properties generally JSON output me omit ho jati hain.

7. localStorage me objects save karne se pehle stringify karna useful hai.

8. Fetch API me JSON body send karte waqt JSON.stringify() commonly use hota hai.

9. Axios normal object data ko automatically JSON me serialize kar sakta hai.

10. JSON.parse() stringify ka opposite conversion karta hai.
