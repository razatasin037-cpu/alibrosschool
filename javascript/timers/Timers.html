JavaScript Timers Kya Hain?

JavaScript Timers ka use kisi code ko kuch time baad execute karne ya fixed time interval par baar-baar execute karne ke liye hota hai.

JavaScript me mainly setTimeout() aur setInterval() timer functions use hote hain.

JavaScript Timer Functions

Function Use
setTimeout() Code ko ek baar delay ke baad execute karta hai.
clearTimeout() setTimeout() ko cancel karta hai.
setInterval() Code ko fixed interval par baar-baar execute karta hai.
clearInterval() setInterval() ko stop karta hai.

setTimeout()

setTimeout() kisi function ya code ko given delay ke baad ek baar execute karta hai.

Syntax 

setTimeout(function, delay);

Delay milliseconds me diya jata hai. 1000 milliseconds = 1 second.

Example 

setTimeout(() => {
  console.log("Hello JavaScript");
}, 2000);

Output:

2 seconds ke baad:
Hello JavaScript

clearTimeout()

clearTimeout() scheduled timeout ko execute hone se pehle cancel karta hai. 

let timer = setTimeout(() => {
  console.log("Hello");
}, 3000);

clearTimeout(timer);

Result:

Timer cancel ho jayega.
"Hello" print nahi hoga.

setInterval()

setInterval() code ko fixed time interval ke baad repeatedly execute karta hai.

Syntax 

setInterval(function, interval);

Example 

setInterval(() => {
  console.log("Hello");
}, 1000);

Output:

Hello
Hello
Hello
...

Yahan Hello approximately har 1 second ke interval par print hota rahega, jab tak interval stop nahi kiya jata.

clearInterval()

clearInterval() running interval ko stop karta hai. 

let timer = setInterval(() => {
  console.log("Running...");
}, 1000);

setTimeout(() => {
  clearInterval(timer);
}, 5000);

Is code me interval start hota hai aur baad me clearInterval(timer) usse stop kar deta hai.

Countdown Example 

let count = 5;

let timer = setInterval(() => {

  console.log(count);

  count--;

  if (count === 0) {
    clearInterval(timer);
  }

}, 1000);

Output:

5
4
3
2
1

Timer ID Kya Hai?

setTimeout() aur setInterval() ek timer identifier return karte hain. Us identifier ko store karke timer ko baad me cancel kiya ja sakta hai. 

let timer = setTimeout(() => {
  console.log("Done");
}, 2000);

clearTimeout(timer);

setTimeout vs setInterval

setTimeout() setInterval()
Code ek baar execute karta hai. Code repeatedly execute karta hai.
Given delay ke baad run hota hai. Given interval ke according repeat hota hai.
clearTimeout() clearInterval()

Practical DOM Timer Example

Timer ki help se webpage ka content kuch seconds baad change kar sakte hain. 

<h2 id="message">Loading...</h2>

<script>

setTimeout(() => {

  document.getElementById("message").innerText =
    "Welcome User";

}, 2000);

</script>

2 seconds ke baad Loading... change hokar Welcome User ho jayega.

Important Points

1. setTimeout() code ko delay ke baad ek baar run karta hai.

2. setInterval() code ko repeatedly run karta hai.

3. Timer delay milliseconds me diya jata hai.

4. 1000ms = 1 second.

5. clearTimeout() timeout ko cancel karta hai.

6. clearInterval() interval ko stop karta hai.

7. Timer delay exact guaranteed execution time nahi hota; event loop busy ho to callback thoda baad run ho sakta hai.
