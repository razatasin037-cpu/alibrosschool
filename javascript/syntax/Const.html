`const` Keyword Kya Hai?

const keyword ko ES6 (2015) me introduce kiya gaya tha.

const se bane variables ko **reassign nahi kiya ja sakta** aur na hi **re-declare** kiya ja sakta hai. Ye variables bhi **Block Scope** hote hain.

Cannot Reassign

Ek baar value assign karne ke baad uski binding ko change (reassign) nahi kar sakte.

Must Assign Value

`const` variable declare karte waqt hi uski value dena zaroori (mandatory) hai.

Block Scope

`let` ki tarah `const` variables bhi `{ ... }` block scope rules ko follow karte hain.

1. Must be Assigned when Declared

JavaScript const variables me declaration ke waqt hi value assign honi chahiye:

Correct Syntax: 
const PI = 3.14159265359;
Incorrect Syntax: 
const PI;
PI = 3.14159265359; 
// SyntaxError: Missing initializer in const declaration

2. Constant Objects and Arrays

const keyword thoda confusing ho sakta hai! Ye kisi value ko constant nahi banata, balki Variable Binding ko constant banata hai.

Constant Arrays

Aap `const` array ke elements ko change/add kar sakte hain, lekin Poore Array ko reassign nahi kar sakte: 

const cars = ["Saab", "Volvo", "BMW"];

// You can change an element:
cars[0] = "Toyota";

// You can add an element:
cars.push("Audi");

// BUT You CANNOT reassign the array:
cars = ["Toyota", "Volvo"]; // TypeError: Assignment to constant variable.

Constant Objects

Aap `const` object ki properties ko change/add kar sakte hain: 

const car = {type: "Fiat", model: "500", color: "white"};

// You can change a property:
car.color = "red";

// You can add a property:
car.owner = "Johnson";

// BUT You CANNOT reassign the object:
car = {type: "Volvo", model: "EX60"}; // TypeError!

3. Block Scope Example

Block `{ ... }` ke andar declare kiya gaya const variable bahar access nahi kiya ja sakta: 

const x = 10;

{
  const x = 2;
  // Yahan block ke andar x = 2 hai
}

// Yahan block ke bahar x = 10 hai
