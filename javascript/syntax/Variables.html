JavaScript Variables Kya Hain?

Variables Data Values ko store (hifazat) karne ke liye **Containers** hote hain.

Jab bhi aapko apne program me koi number, text, ya calculation save karke rakhna ho, tab variables ka upayog hota hai.

let

Modern JS me block-scoped variables declare karne ke liye sabse common tarika.

const

Aisi values jinhe aage change nahi karna ho (Constant/Fixed values).

var

Purana tarika (1995-2015). Iska use ab generally recommend nahi kiya jata.

Automatic

Bina keyword declare kiye direct value assign karna (Undeclared).

1. Variables Declare Kaise Karein?

JavaScript me variables ko create karne ke liye var, let, ya const keyword ka upayog kiya jata hai: 

let x = 5;
let y = 6;
let z = x + y;

console.log(z); // Result: 11

2. Best Practices (Kise Kab Use Karein?)

  • Hamesha const ka use karein agar variable ki value baad me badalni nahi hai.
  • Hamesha let ka use karein agar value aage chal kar badal sakti hai (jaise loop counters).
  • var ka use na karein jab tak aap older browsers (1995-2015) support na kar rahe hon. 
// Real-life Good Example:
const price1 = 5;
const price2 = 6;
let total = price1 + price2; // total baad me change ho sakta hai

3. Numbers and Strings

JavaScript variables alag-alag types ke data store kar sakte hain, jaise Numbers aur Text (Strings): 

const pi = 3.14;                  // Number
let person = "John Doe";           // String (Quotes me likha jata hai)
let answer = 'Yes I am!';          // Single ya Double Quotes dono valid hain

4. Variable Naming Rules (Identifiers)

JavaScript variables ke unique names ko **Identifiers** kaha jata hai. Unke naam rakhne ke rules:

✓ Allowed:
  • Letters (`a-z`, `A-Z`)
  • Digits (`0-9`)
  • Dollar signs (`$`)
  • Underscores (`_`)
✗ Not Allowed:
  • Naam letter se hi shuru hona chahiye (Digit se shuru nahi ho sakta).
  • Reserved Keywords (jaise `let`, `function`) use nahi ho sakte.
  • Case-sensitive (e.g., `myVar` aur `myvar` alag hain).
