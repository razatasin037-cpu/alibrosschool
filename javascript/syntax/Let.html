`let` Keyword Kya Hai?

let keyword ko ES6 (2015) me JavaScript me introduce kiya gaya tha.

`let` se declare kiye gaye variables **Block Scope** hote hain, inhe same scope me **re-declare nahi** kiya ja sakta, lekin inki value ko **re-assign** kiya ja sakta hai.

Block Scope

Curly braces `{ ... }` ke andar declare hone wale variables bahar access nahi ho sakte.

Cannot Redeclare

Same block/scope ke andar ek hi naam ka variable do baar `let` se nahi bana sakte.

Re-assignable

`let` variable me baad me nayi value assign (update) kar sakte hain.

1. Block Scope Example

ES6 se pehle JavaScript me sirf Global Scope aur Function Scope hota tha. let ke aane se **Block Scope** introduce hua: 

{
  let x = 2;
  // Yahan x ki value 2 hai
}
// Yahan x access NAHI ho sakta (Uncaught ReferenceError)

2. Redeclaring Variables

Aap same scope me let se ek variable ko dubara declare nahi kar sakte: 

let x = 10;
let x = 20; // SyntaxError: Identifier 'x' has already been declared

Lekin alag block/scope ke andar re-declare kar sakte hain: 

let x = 10; // Yahan x = 10

{
  let x = 2;  // Block ke andar x = 2
}

// Block ke bahar x wapas 10 hi rahega

3. Let Hoisting

let se bane variables bhi top par hoist hote hain, lekin initialize nahi hote. Unhe declare karne se pehle use karne par error milta hai (**Temporal Dead Zone**): 

carName = "Saab";
let carName; // ReferenceError: Cannot access 'carName' before initialization
