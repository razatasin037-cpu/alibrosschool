JavaScript Syntax Rules

JavaScript syntax un rules ka set hota hai jo batate hain ki JavaScript programs ko kaise likha aur structure kiya jana chahiye.

Isme variables create karna, values assign karna, computation karna aur functions structure karna shamil hai.

Fixed Values (Literals)

Numbers (`10.50`), Strings (`"John"`), Booleans (`true`).

Variable Values

Data store karne ke liye `let`, `const`, aur `var` ka upayog.

Operators

Values ko compute karne ke liye (`+`, `-`, `*`, `/`, `=`).

1. JavaScript Values

JavaScript Syntax do tarah ki values define karta hai:

Fixed Values (Literals)

Ye values fix rehti hain, jaise numbers aur text strings:

10.50
"John Doe"
'Hello World'

Variable Values

Variables data values ko store karne ke liye use hote hain:

let x;
x = 6;

2. Operators & Expressions

JavaScript **Assignment Operator** (=) ka upayog variables ko values assign karne ke liye karta hai, jabki **Arithmetic Operators** (+, -, *, /) ka use calculations ke liye hota hai: 

let x, y;
x = 5;          // Assign 5 to x
y = 6;          // Assign 6 to y

let z = x + y;  // Compute value 11 and assign to z

3. JavaScript Keywords

JavaScript **Keywords** ka upayog browser ko batane ke liye kiya jata hai ki kaun sa action perform karna hai: 

let x = 5;
const price = 100;
var total = x * price;

Yahan let, const, aur var keywords browser ko batate hain ki naye variables banaye ja rahe hain.

4. Case Sensitivity & Lower Camel Case

JavaScript **Case-Sensitive** hoti hai. Iska matlab hai ki lastName aur lastname do alag-alag variables hain: 

let lastname = "Doe";
let lastName = "Peterson"; 
// Ye dono alag variables hain!

Camel Case Rule:

JavaScript me multiple words wale variable names likhne ke liye **Lower Camel Case** sabse popular hai (Pehla word lowercase me, aur uske baad ke sabhi words uppercase letter se start hote hain):

firstName, lastName, masterCard, interCity
