JavaScript Comments Kya Hain?

JavaScript comments ka upayog code ko samjhane (explain) aur readable banane ke liye kiya jata hai.

Comments ko JavaScript engine execute nahi karta. Inka use testing ke dauran kisi code execution ko rokne ke liye bhi hota hai.

Single Line Comments ( // )

Ek hi line ke comment ke liye `//` ka upayog kiya jata hai.

Multi-line Comments ( /* ... */ )

Ek se zyada lines ke comments ke liye `/*` se shuru aur `*/` par khatam kiya jata hai.

1. Single Line Comments

Single-line comments // se start hote hain. // aur line ke aakhir tak ke beech ke kisi bhi text ko JavaScript ignore kar deti hai.

Code se pehle Comment:

// Change heading:
document.getElementById("myH").innerHTML = "My First Page";

// Change paragraph:
document.getElementById("myP").innerHTML = "My first paragraph.";

Code ke aage Inline Comment:

let x = 5;      // Declare x, give it the value of 5
let y = x + 2;  // Declare y, give it the value of x + 2

2. Multi-line Comments

Multi-line comments /* se start hote hain aur */ par end hote hain. Iske beech ki har line ignore kar di jaati hai: 

/*
The code below will change
the heading and the paragraph
in my web page:
*/
document.getElementById("myH").innerHTML = "My First Page";
document.getElementById("myP").innerHTML = "My first paragraph.";

3. Using Comments to Prevent Execution

Code testing ke waqt kisi line ko temporary stop/disable karne ke liye bhi comments ka use hota hai: 

// document.getElementById("myH").innerHTML = "My First Page";
document.getElementById("myP").innerHTML = "My first paragraph.";
