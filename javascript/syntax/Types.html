Data Types Kya Hote Hain?

Programming languages me variables alag-alag tarah ke data (jaise numbers, text, true/false values) ko hold kar sakte hain.

JavaScript ek **Dynamic / Weakly Typed** language hai. Iska matlab hai ki aapko variable ka type pehle se define nahi karna padta—value ke hisab se type apne aap decide hota hai.

Primitive Data Types (8)

Single simple values hoti hain jinme koi extra properties ya methods nahi hote (Immutable).

Non-Primitive / Reference

Complex collections hoti hain jaise Objects, Arrays, aur Functions.

1. Dynamic Types Example

JavaScript variables me aap kisi bhi waqt doosre type ki value reassign kar sakte hain: 

let x;         // Now x is undefined
x = 5;         // Now x is a Number
x = "John";    // Now x is a String

2. Primitive Data Types

JavaScript me mukhya Primitive Types niche diye gaye hain:

String

Textual data ko single ya double quotes me likha jata hai.

let carName = "Volvo XC60";

Number

Integers aur Decimals (floating-point numbers) dono ko represent karta hai.

let x1 = 34.00; // With decimals
let x2 = 34;    // Without decimals

BigInt

Bohot bade integer values ko store karne ke liye aakhir me `n` lagaya jata hai.

let bigNumber = 123456789012345678901234567890n;

Boolean

Sirf do values hold karta hai: true ya false.

let x = true;
let y = false;

Undefined & Null

Undefined: Ek aisa variable jisme abhi tak value assign nahi ki gayi hai.
Null: Ek intentional empty value (kuchh nahi/khaali) represent karta hai. 

let car;         // Value is undefined
let person = null; // Value is null

3. Non-Primitive (Object) Data Types

JavaScript me Arrays, Dates, Sets, etc. sabhi fundamentally **Objects** hi hoti hain:

Objects (Key-Value Pairs)

const person = {
  firstName: "John",
  lastName: "Doe",
  age: 50,
  eyeColor: "blue"
};

Arrays

const cars = ["Saab", "Volvo", "BMW"];

4. `typeof` Operator

Aap typeof operator ka use karke kisi bhi variable ka data type check kar sakte hain: 

typeof ""             // Returns "string"
typeof "John"         // Returns "string"
typeof 0              // Returns "number"
typeof true           // Returns "boolean"
typeof {name: 'John'} // Returns "object"
typeof [1,2,3]        // Returns "object"
