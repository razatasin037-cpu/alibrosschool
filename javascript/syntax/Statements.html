JavaScript Statements Kya Hain?

Aapke dwara likhe gaye computer instructions ko **Statements** kaha jata hai.

JavaScript programs me kai statements hoti hain, jo ek ke baad ek sequential order me execute hoti hain.

Semicolons ( ; )

Har statement ke aakhir me semicolon lagana best practice maana jata hai.

Code Blocks

Multiple statements ko `{ ... }` ke andar group karke saath execute kar sakte hain.

Keywords

Statements aksar reserved keywords (jaise `let`, `if`, `function`) se start hoti hain.

1. Example of a JavaScript Statement

Ye statement browser ko batati hai ki ek variable `x` banao, usme `5` assign karo aur element me result write karo: 

let x, y, z;  // Statement 1: Variables declare karna
x = 5;         // Statement 2: Value 5 assign karna
y = 6;         // Statement 3: Value 6 assign karna
z = x + y;     // Statement 4: Addition compute karna

document.getElementById("demo").innerHTML = z; // Statement 5

2. Semicolons ( ; )

JavaScript statements ko alag karne ke liye **Semicolons** ka upayog kiya jata hai. Agar aap semicolon lagate hain, toh ek hi line me multiple statements bhi likh sakte hain: 

let a, b, c;
a = 1; b = 2; c = a + b; // Multiple statements on one line

3. White Space & Line Length

JavaScript multiple spaces ko ignore kar deti hai. Aap apne code ko clean aur readable banane ke liye white space add kar sakte hain. 

// Ye dono statements bilkul same kaam karti hain:
let person = "John";
let person =   "John"  ;

Agar koi statement bahut lambi ho, toh best practice ye hai ki use operator ke baad break karein: 

document.getElementById("demo").innerHTML =
  "Hello World!";

4. JavaScript Code Blocks

Statements ko Curly Brackets { ... } ke andar group kiya jata hai taaki block ke andar ki saari statements ek saath execute ho sakein (jaise JavaScript Functions me): 

function myFunction() {
  document.getElementById("demo1").innerHTML = "Hello World!";
  document.getElementById("demo2").innerHTML = "How are you?";
}

5. Common JavaScript Keywords

Aap aage ke chapters me in mukhya keywords ko seekhenge:

Keyword Description
var / let Naya variable declare karta hai.
const Constant (non-changeable) variable declare karta hai.
if ... else Conditions ke base par code execute karta hai.
for / while Block of code ko loop me bar-bar execute karta hai.
function Reusable function declare karta hai.
return Function se exit hota hai aur value return karta hai.
