DOM Navigation Kya Hai?

DOM Navigation ka matlab hai ek HTML element se uske parent, children aur sibling elements tak move karna.

Iske liye properties jaise parentElement, children, firstElementChild, nextElementSibling etc. use hote hain.

DOM Family Structure 

Parent

  ├── Child 1
  ├── Child 2
  └── Child 3

Ek element ka parent ho sakta hai, uske child elements ho sakte hain aur same parent wale elements siblings hote hain.

Example HTML 

<div id="parent">

  <h2>Heading</h2>

  <p id="text">
    Paragraph
  </p>

  <button>
    Click
  </button>

</div>

parentElement

Current element ka parent HTML element access karta hai. 

const text =
  document.getElementById(
    "text"
  );

console.log(
  text.parentElement
);

parentNode

parentNode current node ka parent node return karta hai.

Element navigation ke liye commonly parentElement use karna easy hota hai.

children

Element ke child HTML elements ka collection return karta hai. 

const parent =
  document.getElementById(
    "parent"
  );

console.log(
  parent.children
);

childNodes

childNodes sab child nodes return karta hai, including text nodes aur comments. 

console.log(
  parent.childNodes
);

children vs childNodes

children childNodes
Sirf element nodes. Elements + text + comments.
HTMLCollection return karta hai. NodeList return karta hai.

firstElementChild 

const parent =
  document.getElementById(
    "parent"
  );

console.log(
  parent.firstElementChild
);

Parent ka first child element return karta hai.

lastElementChild 

console.log(
  parent.lastElementChild
);

Last child element return karta hai.

firstChild 

console.log(
  parent.firstChild
);

First node return karta hai. HTML formatting ki wajah se ye text node bhi ho sakta hai.

lastChild 

console.log(
  parent.lastChild
);

nextElementSibling

Current element ke next sibling element ko access karta hai. 

const text =

  );

previousElementSibling 

console.log(

nextSibling / previousSibling

Ye properties element ke bajay any node return kar sakti hain, including text nodes. 

console.log(
  text.nextSibling
);

console.log(
  text.previousSibling
);

const parent =

);

console.log(
  parent.children[1]
);

childElementCount

Element ke kitne child elements hain: 

console.log(
  parent.childElementCount
);

closest()

Current element se upward search karke nearest matching ancestor element find karta hai. 

<div class="card">

  <div>

    <button id="btn">
      Delete
    </button>

  </div>

</div>

<script>

const button =
  document.getElementById(
    "btn"
  );

const card =
  button.closest(
    ".card"
  );

console.log(card);

</script>

matches()

Check karta hai ki element given CSS selector se match karta hai ya nahi. 

const button =
  document.querySelector(
    ".btn"
  );

console.log(
  button.matches(
    ".btn"
  )
);
true

contains()

Check karta hai ki ek node dusre node ke andar hai ya nahi. 

const parent =
  document.getElementById(
    "parent"
  );

const text =
  document.getElementById(
    "text"
  );

console.log(
  parent.contains(text)
);
true

Children Par Loop 

const parent =
  document.getElementById(
    "parent"
  );

for (
  const child
  of parent.children
) {

  console.log(
    child
  );

}

Practical Example: Delete Card 

<div class="card">

  <h2>
    Product
  </h2>

  <p>
    Laptop
  </p>

  <button class="delete">
    Delete
  </button>

</div>

<script>

const button =
  document.querySelector(
    ".delete"
  );

button.addEventListener(
  "click",
  () => {

    const card =
      button.closest(
        ".card"
      );

    card.remove();

  }
);

</script>

          Parent
             ↑
             |
      parentElement

             |
             ↓

Previous ← Element → Next
Sibling             Sibling

             |
             ↓

          Children

     ┌───────┼───────┐
     ↓       ↓       ↓

  Child 1  Child 2  Child 3

DOM Navigation Quick Reference

Property / Method Use
parentElement Parent element
children Child elements
childNodes All child nodes
firstElementChild First child element
lastElementChild Last child element
nextElementSibling Next sibling element
previousElementSibling Previous sibling element
closest() Nearest matching ancestor
matches() Selector match check
contains() Descendant check

Important Points

1. parentElement parent HTML element ko access karta hai.

2. children sirf child elements deta hai.

3. childNodes text aur comment nodes ko bhi include kar sakta hai.

4. firstElementChild aur lastElementChild first/last child element dete hain.

5. nextElementSibling aur previousElementSibling sibling elements access karte hain.

6. closest() nearest matching ancestor find karta hai.

7. matches() selector match check karta hai.

8. contains() check karta hai ki element ke andar koi node maujood hai ya nahi.
