DOM Elements Kya Hain?

HTML page ke elements jaise <h1>, <p>, <button> aur <input> ko JavaScript DOM ke through access aur modify kiya ja sakta hai.

Element access karne ke liye JavaScript me multiple DOM methods available hain.

DOM Element Selection Methods

Method Use
getElementById() ID se ek element select karta hai.
getElementsByClassName() Class name se elements select karta hai.
getElementsByTagName() Tag name se elements select karta hai.
querySelector() Pehla matching CSS selector element deta hai.
querySelectorAll() Sab matching CSS selector elements deta hai.

getElementById()

Kisi element ko uske id se select karne ke liye use hota hai. 

<h1 id="title">
  Hello
</h1>

<script>

const title =
  document.getElementById(
    "title"
  );

console.log(title);

</script>

Selected Element Change Karna 

const title =
  document.getElementById(
    "title"
  );

title.textContent =
  "JavaScript DOM";

getElementsByClassName()

Same class wale multiple elements ko select karne ke liye use hota hai. 

<p class="item">Apple</p>
<p class="item">Mango</p>
<p class="item">Banana</p>

<script>

const items =
  document.getElementsByClassName(
    "item"
  );

console.log(items);

</script>

HTMLCollection

getElementsByClassName() aur getElementsByTagName() normally HTMLCollection return karte hain. 

const items =
  document.getElementsByClassName(
    "item"
  );

console.log(
  items[0]
);

console.log(
  items.length
);

HTMLCollection Par Loop 

const items =
  document.getElementsByClassName(
    "item"
  );

for (
  let i = 0;
  i < items.length;
  i++
) {

  console.log(
    items[i].textContent
  );

}

getElementsByTagName()

HTML tag name ke according elements select karta hai. 

const paragraphs =
  document.getElementsByTagName(
    "p"
  );

console.log(
  paragraphs
);

querySelector()

CSS selector use karke first matching element select karta hai. 

const heading =
  document.querySelector(
    ".heading"
  );

console.log(heading);

querySelector() With ID 

const title =
  document.querySelector(
    "#title"
  );

ID selector ke liye # use hota hai.

CSS Selectors Use Karna 

// Class
document.querySelector(
  ".box"
);

// ID
document.querySelector(
  "#title"
);

// Tag
document.querySelector(
  "p"
);

// Nested selector
document.querySelector(
  ".card h2"
);

// Attribute selector
document.querySelector(
  'input[type="email"]'
);

querySelectorAll()

Sab matching elements select karta hai aur normally NodeList return karta hai. 

const items =
  document.querySelectorAll(
    ".item"
  );

console.log(items);

NodeList Par forEach() 

const items =
  document.querySelectorAll(
    ".item"
  );

items.forEach((item) => {

  console.log(
    item.textContent
  );

});

querySelector() Sirf First Match Deta Hai 

<p class="text">First</p>
<p class="text">Second</p>

<script>

const item =
  document.querySelector(
    ".text"
  );

console.log(
  item.textContent
);

</script>
First

Parent Ke Andar Element Select Karna 

<div id="card">

  <h2>Product</h2>

  <p>Laptop</p>

</div>

const card =
  document.getElementById(
    "card"
  );

const heading =

</script>

Multiple Elements Change Karna 

const items =
  document.querySelectorAll(
    ".item"
  );

items.forEach((item) => {

  item.style.color =
    "blue";

});

Element Na Mile To Kya Hota Hai?

Agar getElementById() ya querySelector() ko matching element nahi milta, result null hota hai. 

const element =
  document.getElementById(
    "unknown"
  );

console.log(element);
null

Element Milne Ke Baad Check Karna 

const title =
  document.getElementById(
    "title"
  );

if (title) {

  title.textContent =
    "Hello DOM";

}

DOM Selection Methods Comparison

Method Returns Selector
getElementById() Single element / null ID
getElementsByClassName() HTMLCollection Class name
getElementsByTagName() HTMLCollection Tag name
querySelector() First matching element / null CSS selector
querySelectorAll() NodeList CSS selector

Practical Example 

<h2 id="heading">
  Original Heading
</h2>

<p class="text">
  Paragraph 1
</p>

<p class="text">
  Paragraph 2
</p>

<script>

const heading =
  document.getElementById(
    "heading"
  );

heading.textContent =
  "New Heading";

const paragraphs =
  document.querySelectorAll(
    ".text"
  );

paragraphs.forEach((paragraph) => {

  paragraph.style.fontSize =
    "20px";

});

</script>

Important Points

1. getElementById() ID se single element select karta hai.

2. getElementsByClassName() class name ke according elements select karta hai.

3. getElementsByTagName() tag name ke according elements select karta hai.

4. querySelector() first matching CSS selector element deta hai.

5. querySelectorAll() sab matching elements ka NodeList deta hai.

6. querySelectorAll() ke result par forEach() commonly use kar sakte hain.

7. Element na mile to getElementById() aur querySelector() null return kar sakte hain.

8. CSS selectors ki flexibility ke wajah se querySelector() aur querySelectorAll() bahut useful hain.
