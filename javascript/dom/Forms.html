DOM Forms Kya Hai?

JavaScript DOM Forms ka use form input values read karne, validation karne aur form submit event handle karne ke liye hota hai.

Hum input, email, password, radio, checkbox, select aur textarea jaise fields ko JavaScript se access kar sakte hain.

Basic HTML Form 

<form id="userForm">

  <input
    type="text"
    id="name"
    placeholder="Enter name"
  >

  <button type="submit">
    Submit
  </button>

</form>

Form Select Karna 

const form =
  document.getElementById(
    "userForm"
  );

console.log(form);

Input Value Read Karna 

const input =
  document.getElementById(
    "name"
  );

console.log(
  input.value
);

Form Submit Event 

const form =
  document.getElementById(
    "userForm"
  );

form.addEventListener(
  "submit",
  (event) => {

    event.preventDefault();

    console.log(
      "Form Submitted"
    );

  }
);

preventDefault()

Form submit hone par browser normally page ko reload ya navigate kar sakta hai.

JavaScript se form handle karte waqt event.preventDefault() default submit behavior ko rokta hai.

FormData

Form ke fields ko easily collect karne ke liye FormData use kar sakte hain. 

<form id="userForm">

  <input
    name="name"
    value="Ali"
  >

  <input
    name="email"
    value="ali@gmail.com"
  >

</form>

<script>

const form =
  document.getElementById(
    "userForm"
  );

const formData =
  new FormData(
    form
  );

console.log(
  formData.get(
    "name"
  )
);

</script>

FormData Entries 

const formData =
  new FormData(
    form
  );

for (
  const [key, value]
  of formData.entries()
) {

  console.log(
    key,
    value
  );

}

FormData To Object 

const formData =
  new FormData(
    form
  );

const data =
  Object.fromEntries(
    formData.entries()
  );

console.log(data);

Complete Form Validation Example 

<form id="registerForm">

  <input
    type="text"
    id="name"
    placeholder="Name"
  >

  <input
    type="email"
    id="email"
    placeholder="Email"
  >

  <input
    type="password"
    id="password"
    placeholder="Password"
  >

  <button type="submit">
    Register
  </button>

</form>

<p id="message"></p>

<script>

const form =
  document.getElementById(
    "registerForm"
  );

const message =
  document.getElementById(
    "message"
  );

form.addEventListener(
  "submit",
  (event) => {

    event.preventDefault();

    const name =
      document.getElementById(
        "name"
      ).value.trim();

    const email =
      document.getElementById(
        "email"
      ).value.trim();

    const password =
      document.getElementById(
        "password"
      ).value;

    if (name === "") {

      message.textContent =
        "Name is required";

      return;
    }

    if (!email.includes(
      "@"
    )) {

      message.textContent =
        "Enter valid email";

      return;
    }

    if (
      password.length < 6
    ) {

      message.textContent =
        "Password must be at least 6 characters";

      return;
    }

    message.textContent =
      "Form Submitted Successfully";

    form.reset();

  }
);

</script>

Form Data API Ko Send Karna 

form.addEventListener(
  "submit",
  async (event) => {

    event.preventDefault();

    const formData =
      new FormData(
        form
      );

    const data =
      Object.fromEntries(
        formData.entries()
      );

    const response =
      await fetch(
        "/api/users",
        {

          method:
            "POST",

          headers: {

            "Content-Type":
              "application/json"

          },

          body:
            JSON.stringify(data)

        }
      );

    const result =
      await response.json();

    console.log(result);

  }
);

DOM Forms Quick Reference

Property / Method Use
value Input value read/change
checked Checkbox/radio status
submit Form submit event
preventDefault() Default form submit stop
FormData Form fields collect
reset() Form reset
checkValidity() HTML validity check

Important Points

1. Form fields ki value value property se milti hai.

2. submit event form submit hone par fire hota hai.

3. preventDefault() default submit behavior rokta hai.

4. Checkbox aur radio ke liye checked useful hai.

5. FormData form values collect karna easy banata hai.

6. form.reset() fields ko reset karta hai.

7. Client-side validation user experience improve karti hai, lekin important data ko server side par bhi validate karna chahiye.

8. Form data ko Fetch API ke through backend API ko bhej sakte hain.
