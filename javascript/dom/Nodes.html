DOM Node Kya Hai?

DOM me HTML document ke different parts ko nodes ke roop me represent kiya jata hai.

HTML element, text, comments aur document khud bhi nodes ho sakte hain.

DOM Node Tree 

Document

   ↓

HTML Element

 ├── HEAD Element
 │
 └── BODY Element

      ├── H1 Element
      │    └── Text Node
      │
      ├── P Element
      │    └── Text Node
      │
      └── Comment Node

Simple HTML Example 

<h1>
  Hello JavaScript
</h1>

Is example me <h1> ek Element Node hai aur Hello JavaScript uska Text Node hai.

Common Node Types

Node Type Meaning
Document Node Complete HTML document.
Element Node HTML tags jaise div, p, h1.
Text Node Element ke andar ka text.
Comment Node HTML comments.

nodeType

Kisi node ka type check karne ke liye nodeType property use hoti hai. 

const title =
  document.getElementById(
    "title"
  );

console.log(
  title.nodeType
);
1

Element Node ka nodeType value 1 hota hai.

Important nodeType Values

Value Node
1 Element Node
3 Text Node
8 Comment Node
9 Document Node

nodeName

Node ka naam check karne ke liye nodeName use kar sakte hain. 

const title =
  document.getElementById(
    "title"
  );

console.log(
  title.nodeName
);
H1

nodeValue

Text Node ya Comment Node ki value read/change karne ke liye nodeValue use ho sakta hai. 

<h1 id="title">
  Hello
</h1>

<script>

const title =
  document.getElementById(
    "title"
  );

const textNode =
  title.firstChild;

console.log(
  textNode.nodeValue
);

</script>

createElement()

New Element Node create karne ke liye document.createElement() use hota hai. 

const paragraph =
  document.createElement(
    "p"
  );

paragraph.textContent =
  "Hello DOM";

createTextNode()

Text Node explicitly create karne ke liye createTextNode() use hota hai. 

const paragraph =
  document.createElement(
    "p"
  );

const text =
  document.createTextNode(
    "Hello JavaScript"
  );

paragraph.appendChild(
  text
);

appendChild()

Existing node ke end me new child node add karta hai. 

const list =
  document.getElementById(
    "list"
  );

const item =
  document.createElement(
    "li"
  );

item.textContent =
  "Mango";

list.appendChild(
  item
);

append()

Nodes ke saath direct text bhi append kar sakta hai. 

const box =
  document.getElementById(
    "box"
  );

box.append(
  "Hello ",
  paragraph
);

prepend()

Content ko element ke start me add karta hai. 

const list =
  document.getElementById(
    "list"
  );

const item =
  document.createElement(
    "li"
  );

item.textContent =
  "First Item";

list.prepend(
  item
);

before() Aur after() 

const box =
  document.getElementById(
    "box"
  );

const heading =
  document.createElement(
    "h2"
  );

heading.textContent =
  "Heading";

box.before(
  heading
);

box.after(
  "After Box"
);

remove()

Element ko DOM se remove karta hai. 

const message =
  document.getElementById(
    "message"
  );

message.remove();

removeChild() 

const parent =
  document.getElementById(
    "parent"
  );

const child =
  document.getElementById(
    "child"
  );

parent.removeChild(
  child
);

replaceChild()

Old child node ko new node se replace karta hai. 

const parent =
  document.getElementById(
    "parent"
  );

const oldItem =
  document.getElementById(
    "old"
  );

const newItem =
  document.createElement(
    "p"
  );

newItem.textContent =
  "New Item";

parent.replaceChild(
  newItem,
  oldItem
);

replaceWith() 

const oldItem =
  document.getElementById(
    "old"
  );

const newItem =
  document.createElement(
    "h2"
  );

newItem.textContent =
  "New Heading";

oldItem.replaceWith(
  newItem
);

cloneNode()

Existing node ki copy create karne ke liye cloneNode() use hota hai. 

const card =
  document.querySelector(
    ".card"
  );

const copy =
  card.cloneNode(
    true
  );

document.body.append(
  copy
);

true dene par child nodes bhi clone hote hain.

hasChildNodes() 

const box =
  document.getElementById(
    "box"
  );

console.log(
  box.hasChildNodes()
);

isSameNode()

Check karta hai ki dono references exactly same node ko point karte hain ya nahi. 

const a =
  document.getElementById(
    "box"
  );

const b =
  document.querySelector(
    "#box"
  );

console.log(
  a.isSameNode(b)
);
true

const items =

  );

items.forEach((item) => {

Practical Example: Dynamic List 

<input
  type="text"
  id="itemInput"
>

<button id="addBtn">
  Add Item
</button>

<ul id="list"></ul>

<script>

const input =
  document.getElementById(
    "itemInput"
  );

const button =
  document.getElementById(
    "addBtn"
  );

const list =
  document.getElementById(
    "list"
  );

button.addEventListener(
  "click",
  () => {

    if (
      input.value.trim() ===
      ""
    ) {
      return;
    }

    const item =
      document.createElement(
        "li"
      );

    item.textContent =
      input.value;

    list.appendChild(
      item
    );

    input.value =
      "";

  }
);

</script>

Create Aur Delete Node 

const item =
  document.createElement(
    "li"
  );

const text =
  document.createTextNode(
    "JavaScript"
  );

const button =
  document.createElement(
    "button"
  );

button.textContent =
  "Delete";

item.append(
  text,
  button
);

list.append(
  item
);

button.addEventListener(
  "click",
  () => {

    item.remove();

  }
);

Node vs Element

Node Element
DOM ka generic building block. Specific HTML tag node.
Element, text aur comment node ho sakta hai. HTML elements jaise div, h1, p.
Har Node Element nahi hota. Har Element ek Node hota hai.

DOM Nodes Quick Reference

Method / Property Use
nodeType Node type check
nodeName Node name
nodeValue Node value
createElement() Element Node create
createTextNode() Text Node create
appendChild() Child node append
append() Nodes/text append
prepend() Start me add
remove() Node remove
replaceWith() Node replace
cloneNode() Node clone
hasChildNodes() Child node check

Important Points

1. DOM ke almost har part ko node ke form me represent kiya jata hai.

2. Element, Text, Comment aur Document common node types hain.

3. nodeType node ka type batata hai.

4. nodeName node ka naam deta hai.

5. createElement() new HTML element create karta hai.

6. createTextNode() text node create karta hai.

7. appendChild() aur append() nodes add karte hain.

8. remove() node ko DOM se hata deta hai.

9. replaceWith() aur replaceChild() nodes replace karne ke liye use hote hain.

10. cloneNode() existing node ki copy create karta hai.
