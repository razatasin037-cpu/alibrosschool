DOM Kya Hai?

DOM ka full form Document Object Model hai.

Browser HTML page ko objects ke tree ke form me represent karta hai. JavaScript DOM ki help se HTML elements ko select, change, create, delete aur events handle kar sakta hai.

Simple Meaning

HTML page browser me load hone ke baad JavaScript ke liye ek object structure ban jata hai. Isi object structure ko DOM kehte hain.

DOM Tree 

Document

   ↓

HTML

 ├── HEAD
 │    └── TITLE
 │
 └── BODY
      ├── H1
      ├── P
      └── BUTTON

HTML ke har element ko DOM me ek node ke roop me represent kiya jata hai.

HTML Example 

<h1 id="title">
  Hello JavaScript
</h1>

<p>
  Welcome to DOM
</p>

document Object

JavaScript me current HTML document ko access karne ke liye document object use hota hai. 

console.log(
  document
);

Element Select Karna

ID ke through element select karne ke liye getElementById() use kar sakte hain. 

const title =
  document.getElementById(
    "title"
  );

console.log(title);

HTML Content Change Karna 

document.getElementById(
  "title"
).innerHTML =
  "Hello DOM";

Isse selected element ka HTML content change ho jayega.

textContent

Sirf text change karne ke liye textContent use kar sakte hain. 

const title =
  document.getElementById(
    "title"
  );

title.textContent =
  "New Heading";

CSS Change Karna 

const title =
  document.getElementById(
    "title"
  );

title.style.color =
  "blue";

title.style.fontSize =
  "40px";

Attribute Change Karna 

const image =
  document.getElementById(
    "photo"
  );

image.src =
  "image2.jpg";

querySelector()

CSS selector ke through pehla matching element select karne ke liye querySelector() use hota hai. 

const heading =
  document.querySelector(
    ".heading"
  );

console.log(heading);

querySelectorAll()

Sab matching elements select karne ke liye querySelectorAll() use hota hai. 

const items =
  document.querySelectorAll(
    ".item"
  );

items.forEach((item) => {

  console.log(item);

});

DOM Events

User click, input, submit ya keyboard action kare to JavaScript event handle kar sakta hai. 

const button =
  document.getElementById(
    "btn"
  );

button.addEventListener(
  "click",
  () => {

    console.log(
      "Button Clicked"
    );

  }
);

New Element Create Karna 

const paragraph =
  document.createElement(
    "p"
  );

paragraph.textContent =
  "New Paragraph";

document.body.appendChild(
  paragraph
);

Element Remove Karna 

const element =
  document.getElementById(
    "message"
  );

element.remove();

classList

CSS classes ko add, remove ya toggle karne ke liye classList use hota hai. 

const box =
  document.getElementById(
    "box"
  );

box.classList.add(
  "active"
);

box.classList.remove(
  "hidden"
);

box.classList.toggle(
  "dark"
);

Complete DOM Example 

<h1 id="title">
  Hello
</h1>

<button id="btn">
  Change Text
</button>

<script>

const title =
  document.getElementById(
    "title"
  );

const button =
  document.getElementById(
    "btn"
  );

button.addEventListener(
  "click",
  () => {

    title.textContent =
      "Hello JavaScript DOM";

  }
);

</script>

Common DOM Methods

Method / Property Use
getElementById() ID se element select karta hai.
querySelector() Pehla matching CSS selector element select karta hai.
querySelectorAll() Sab matching elements select karta hai.
innerHTML HTML content read/change karta hai.
textContent Text content read/change karta hai.
createElement() New element create karta hai.
appendChild() Child element add karta hai.
addEventListener() Event listener attach karta hai.

    ↓

    ↓

Handle Events

    ↓

Update Page

Important Points

1. DOM ka full form Document Object Model hai.

2. Browser HTML document ko DOM tree me convert karta hai.

3. document current HTML document ko represent karta hai.

4. getElementById() ID se element select karta hai.

5. querySelector() CSS selector ke through element select karta hai.

6. innerHTML aur textContent content change karne ke liye use hote hain.

7. style aur classList se element ki styling change kar sakte hain.

8. addEventListener() user events handle karta hai.

9. createElement() se dynamically new HTML element create kar sakte hain.
