DOM HTML Kya Hai?

JavaScript DOM ki help se HTML elements ka content, attributes aur structure dynamically change kiya ja sakta hai.

Iske liye commonly innerHTML, textContent, innerText, setAttribute() aur dusre DOM methods use hote hain.

innerHTML

innerHTML element ke andar ka HTML read ya change karta hai. 

<div id="box">
  Hello
</div>

<script>

document.getElementById(
  "box"
).innerHTML =
  "<h2>Hello JavaScript</h2>";

</script>

innerHTML Se Content Read Karna 

const box =
  document.getElementById(
    "box"
  );

console.log(
  box.innerHTML
);

textContent

Sirf text content read ya change karne ke liye textContent useful hai. 

const title =
  document.getElementById(
    "title"
  );

title.textContent =
  "Hello DOM";

innerText

innerText element ka rendered/visible text return karta hai. 

const message =
  document.getElementById(
    "message"
  );

console.log(
  message.innerText
);

innerHTML vs textContent vs innerText

Property Use
innerHTML HTML markup ke saath content read/change karta hai.
textContent Text content read/change karta hai.
innerText Rendered visible text ko represent karta hai.

HTML Attribute Change Karna 

<img
  id="photo"
  src="image1.jpg"
>

<script>

const image =
  document.getElementById(
    "photo"
  );

image.src =
  "image2.jpg";

Link href Change Karna 

const link =
  document.getElementById(
    "website"
  );

link.href =
  "https://example.com";

setAttribute()

Attribute add ya update karne ke liye setAttribute() use hota hai. 

const input =
  document.getElementById(
    "email"
  );

input.setAttribute(
  "placeholder",
  "Enter email"
);

getAttribute() 

const input =
  document.getElementById(
    "email"
  );

const type =
  input.getAttribute(
    "type"
  );

console.log(type);

removeAttribute() 

const button =
  document.getElementById(
    "btn"
  );

button.removeAttribute(
  "disabled"
);

hasAttribute() 

const button =
  document.getElementById(
    "btn"
  );

console.log(
  button.hasAttribute(
    "disabled"
  )
);

Dynamic HTML Create Karna 

const box =
  document.getElementById(
    "box"
  );

box.innerHTML = `
  <h2>Product</h2>
  <p>Laptop</p>
  <button>Buy Now</button>
`;

Dynamic Data With Template Literals 

const product = {
  name: "Laptop",
  price: 50000
};

const box =
  document.getElementById(
    "box"
  );

box.innerHTML = `
  <h2>${product.name}</h2>
  <p>₹${product.price}</p>
`;

Array Data HTML Me Show Karna 

const products = [
  {
    name: "Laptop",
    price: 50000
  },
  {
    name: "Mouse",
    price: 500
  }
];

let html =
  "";

products.forEach(
  (product) => {

    html += `
      <div>
        <h3>${product.name}</h3>
        <p>₹${product.price}</p>
      </div>
    `;

  }
);

document.getElementById(
  "products"
).innerHTML = html;

createElement()

New HTML element programmatically create karne ke liye createElement() use hota hai. 

const heading =
  document.createElement(
    "h2"
  );

heading.textContent =
  "New Heading";

document.body.appendChild(
  heading
);

append() 

const box =
  document.getElementById(
    "box"
  );

const paragraph =
  document.createElement(
    "p"
  );

paragraph.textContent =
  "Hello DOM";

box.append(
  paragraph
);

insertAdjacentHTML()

Existing element ke relative position par HTML insert karne ke liye use hota hai. 

const box =
  document.getElementById(
    "box"
  );

box.insertAdjacentHTML(
  "beforeend",
  "<p>New Item</p>"
);

Complete DOM HTML Example 

<h1 id="title">
  Old Title
</h1>

<div id="content"></div>

<button id="btn">
  Change HTML
</button>

<script>

const title =
  document.getElementById(
    "title"
  );

const content =
  document.getElementById(
    "content"
  );

const button =
  document.getElementById(
    "btn"
  );

button.addEventListener(
  "click",
  () => {

    title.textContent =
      "New Title";

    content.innerHTML =
      `
        <p>Hello JavaScript DOM</p>
        <button>Learn More</button>
      `;

  }
);

</script>

innerHTML Important Note

Unknown ya user-provided text ko directly innerHTML me insert karna risky ho sakta hai.

Sirf plain text show karna ho to textContent usually safer choice hai.

DOM HTML Quick Reference

Property / Method Use
innerHTML HTML content read/change
textContent Text read/change
value Form input value read/change
setAttribute() Attribute add/update
getAttribute() Attribute value read
removeAttribute() Attribute remove
createElement() New element create
append() Content/node append

Important Points

1. innerHTML HTML markup ke saath content change karta hai.

2. textContent text content ke liye useful hai.

3. innerText rendered text ko represent karta hai.

4. Element properties jaise src, href aur value directly change ki ja sakti hain.

5. setAttribute() attribute set karta hai.

6. getAttribute() attribute ki value read karta hai.

7. createElement() dynamically element create karta hai.

8. Dynamic lists aur cards banane ke liye Array ke saath DOM HTML commonly use hota hai.
