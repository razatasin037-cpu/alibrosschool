DOM Event Kya Hai?

JavaScript DOM Events ka use user ke actions ko detect aur handle karne ke liye hota hai.

Jaise button click karna, input me type karna, form submit karna, mouse move karna ya keyboard key press karna.

Common DOM Events

Event Use
click Element click hone par.
dblclick Double click hone par.
input Input value change hote waqt.
change Input/select value commit hone par.
submit Form submit hone par.
mouseover Mouse element ke upar aane par.
mouseout Mouse element se bahar jane par.
keydown Keyboard key press hone par.
keyup Key release hone par.

addEventListener()

Event handler attach karne ka common aur recommended way addEventListener() hai. 

element.addEventListener(
  "event",
  callback

event.target usually us element ko represent karta hai jahan se event originate hua.

preventDefault()

event.preventDefault() browser ke default behavior ko prevent karta hai.

Form submit ke case me ye page reload/normal submit behavior ko rokne ke liye commonly use hota hai.

target vs currentTarget 

button.addEventListener(
  "click",
  (event) => {

    console.log(
      event.target
    );

    console.log(
      event.currentTarget
    );

  }
);

target actual originating element hota hai, jabki currentTarget wo element hota hai jiske listener ka callback currently run ho raha hai.

stopPropagation()

Event ko aage propagate hone se rokne ke liye stopPropagation() use kar sakte hain. 

child.addEventListener(
  "click",
  (event) => {

    event.stopPropagation();

    console.log(
      "Child Only"
    );

  }
);

Event Delegation

Multiple child elements ko alag-alag listeners dene ki jagah parent par ek listener lagakar bubbling ka use kar sakte hain. 

<ul id="list">

  <li>Apple</li>
  <li>Mango</li>
  <li>Banana</li>

</ul>

<script>

const list =
  document.getElementById(
    "list"
  );

list.addEventListener(
  "click",
  (event) => {

    if (
      event.target.tagName ===
      "LI"
    ) {

      console.log(
        event.target.textContent
      );

    }

  }
);

</script>

removeEventListener() 

function handleClick() {

  console.log(
    "Clicked"
  );

}

button.addEventListener(
  "click",
  handleClick
);

button.removeEventListener(
  "click",
  handleClick
);

Listener remove karne ke liye same function reference dena hota hai.

onclick Property 

button.onclick = () => {

  console.log(
    "Clicked"
  );

};

Ye bhi valid hai, lekin multiple independent listeners attach karne ke liye addEventListener() zyada flexible hai.

Practical Counter Example 

<h2 id="count">
  0
</h2>

<button id="increase">
  Increase
</button>

<button id="decrease">
  Decrease
</button>

<script>

let count =
  0;

const output =
  document.getElementById(
    "count"
  );

document.getElementById(
  "increase"
).addEventListener(
  "click",
  () => {

    count++;

    output.textContent =
      count;

  }
);

document.getElementById(
  "decrease"
).addEventListener(
  "click",
  () => {

    count--;

    output.textContent =
      count;

  }
);

</script>

DOM Events Quick Reference

Code Use
addEventListener() Event listener add karta hai.
removeEventListener() Event listener remove karta hai.
event.target Originating element deta hai.
event.currentTarget Current listener element deta hai.
preventDefault() Default browser action rokta hai.
stopPropagation() Event propagation rokta hai.

Important Points

1. DOM events user ya browser actions ko represent karte hain.

2. addEventListener() event handler attach karta hai.

3. click, input, change, submit aur keyboard events commonly use hote hain.

4. event.target actual event target ko access karta hai.

5. preventDefault() default browser behavior ko rokta hai.

6. Event bubbling me event target se ancestors ki taraf propagate kar sakta hai.

7. stopPropagation() propagation ko rok sakta hai.

8. Event delegation dynamic lists aur repeated elements ke saath useful technique hai.
