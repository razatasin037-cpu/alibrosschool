DOM CSS Kya Hai?

JavaScript DOM ki help se HTML elements ki CSS styling dynamically change ki ja sakti hai.

Iske liye style, className aur classList commonly use hote hain.

style Property

Element ki inline CSS ko JavaScript se change karne ke liye style property use hoti hai. 

const title =
  document.getElementById(
    "title"
  );

title.style.color =
  "blue";

Font Size Change Karna 

const title =
  document.getElementById(
    "title"
  );

title.style.fontSize =
  "40px";

Background Change Karna 

const box =
  document.getElementById(
    "box"
  );

box.style.backgroundColor =
  "black";

CSS Property Naming

JavaScript me hyphen wali CSS properties ko normally camelCase me likhte hain.

CSS JavaScript
background-color backgroundColor
font-size fontSize
border-radius borderRadius
margin-top marginTop

Multiple CSS Properties 

const box =
  document.getElementById(
    "box"
  );

box.style.width =
  "200px";

box.style.height =
  "100px";

box.style.backgroundColor =
  "blue";

box.style.color =
  "white";

box.style.padding =
  "20px";

style.cssText

Multiple inline CSS properties ek saath set karne ke liye cssText use kar sakte hain. 

const box =
  document.getElementById(
    "box"
  );

box.style.cssText = `
  background: blue;
  color: white;
  padding: 20px;
  border-radius: 10px;
`;

className

Element ka poora class attribute set ya replace karne ke liye className use kar sakte hain. 

const box =
  document.getElementById(
    "box"
  );

box.className =
  "active card";

classList.add()

Existing classes ko replace kiye bina new class add karta hai. 

const box =
  document.getElementById(
    "box"
  );

box.classList.add(
  "active"
);

Multiple Classes Add Karna 

box.classList.add(
  "active",
  "shadow",
  "rounded"
);

classList.remove() 

box.classList.remove(
  "hidden"
);

classList.toggle()

Class present ho to remove karta hai, present na ho to add karta hai. 

box.classList.toggle(
  "active"
);

classList.contains()

Check karta hai ki element ke paas given class hai ya nahi. 

const result =
  box.classList.contains(
    "active"
  );

console.log(result);
true
or
false

classList.replace() 

box.classList.replace(
  "old",
  "new"
);

getComputedStyle()

Browser me element par actually applied computed CSS read karne ke liye getComputedStyle() use hota hai. 

const box =
  document.getElementById(
    "box"
  );

const styles =
  getComputedStyle(box);

console.log(
  styles.color
);

console.log(
  styles.fontSize
);

style vs classList

style classList
Inline CSS set karta hai. CSS class manage karta hai.
element.style.color element.classList.add()
Chhoti dynamic changes ke liye useful. Multiple reusable styles ke liye better.

Better Practice

Agar bahut saari styles change karni hain to har property ko JavaScript me manually set karne ke bajay CSS class banana aur classList se add/remove karna generally cleaner hota hai.

Less Clean 

box.style.color =
  "white";

box.style.background =
  "blue";

box.style.padding =
  "20px";

Cleaner 

// CSS

.active {
  color: white;
  background: blue;
  padding: 20px;
}

// JS

box.classList.add(
  "active"
);

DOM CSS Quick Reference

Code Use
element.style.color Inline color change
element.className Full class string set/replace
classList.add() Class add
classList.remove() Class remove
classList.toggle() Class toggle
classList.contains() Class check
getComputedStyle() Applied style read

Important Points

1. style se inline CSS change kar sakte hain.

2. JavaScript me CSS property names mostly camelCase me likhe jate hain.

3. className poora class attribute set ya replace karta hai.

4. classList.add() new class add karta hai.

5. classList.remove() class remove karta hai.

6. classList.toggle() class ko add/remove toggle karta hai.

7. classList.contains() class present hai ya nahi check karta hai.

8. getComputedStyle() applied/computed CSS read karne ke liye use hota hai.

9. Large styling changes ke liye classList use karna generally cleaner approach hai.
