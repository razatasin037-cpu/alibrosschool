async / await Kya Hai?

JavaScript me async aur await Promise based asynchronous code ko simple aur readable banane ke liye use hote hain.

async function Promise return karta hai aur await Promise ke result ka wait karta hai.

async Function Syntax 

async function functionName() {

  // code

}

Basic async Example 

async function greet() {

  return
    "Hello";

}

greet().then((result) => {

  console.log(result);

});
Hello

async Function Promise Return Karta Hai 

async function getNumber() {

  return 100;

}

console.log(
  getNumber()
);

Direct 100 nahi, Promise object milta hai.

await Syntax 

const result =
  await promise;

Commonly await ko async function ke andar use kiya jata hai.

Simple await Example

  return Promise.resolve(
    "Data Loaded"
  );

}

async function showData() {

  const result =
    await getData();

  console.log(result);

}

showData();
Data Loaded

async / await With setTimeout 

function loadData() {

  return new Promise(

async function showData() {

  console.log(
    "Loading..."
  );

    await loadData();

}

showData();

try...catch With async / await

Rejected Promise ya thrown error ko handle karne ke liye try...catch use karte hain. 

async function getData() {

  try {

    const result =
      await Promise.resolve(
        "Success"
      );

    console.log(result);

  } catch (error) {

    console.log(error);

  }

}

getData();

Rejected Promise Handle Karna 

function login() {

  return Promise.reject(
    "Invalid Login"
  );

}

async function handleLogin() {

  try {

    const result =
      await login();

    console.log(result);

  } catch (error) {

    console.log(error);

  }

}

handleLogin();
Invalid Login

try...catch...finally 

async function loadData() {

  try {

    console.log(
      "Loading"
    );

  } catch (error) {

    console.log(error);

  } finally {

    console.log(
      "Finished"
    );

  }

}

Fetch Error Check 

async function getUsers() {

  try {

    const response =
      await fetch(
        "https://jsonplaceholder.typicode.com/users"
      );

    if (!response.ok) {

      throw new Error(
        "Request failed"
      );

    }

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

getUsers();

Parallel Tasks With Promise.all()

Independent Promises ko parallel start karke ek saath wait karne ke liye Promise.all() useful hai.

  const [
    users,

    getUsers(),
    getProducts()
  ]);

  console.log(users);
  console.log(products);

}

Promise vs async / await

Promise async / await
then() aur catch() use karta hai. await aur try...catch use karta hai.
Chaining style. Synchronous-looking style.
Promise directly handle karta hai. Promise ke upar hi built hota hai.

Important Points

1. async function hamesha Promise return karta hai.

2. await Promise ke settle hone ka result wait karta hai.

3. await commonly async function ke andar use hota hai.

4. Error handling ke liye try...catch use karte hain.

5. finally success aur error dono ke baad run ho sakta hai.

6. API requests ke saath async/await bahut commonly use hota hai.

7. Independent async tasks ko parallel handle karne ke liye Promise.all() useful hai.

8. Async/await Promises ka replacement nahi hai; ye Promise-based code ko likhne ka cleaner syntax hai.
