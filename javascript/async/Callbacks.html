Callback Function Kya Hai?

JavaScript me callback ek function hota hai jo kisi dusre function ko argument ke roop me pass kiya jata hai.

Jab main function apna kaam complete karta hai, tab callback function ko execute kiya ja sakta hai.

Callback Syntax 

function mainFunction(callback) {

  // main code

  callback();

}

Basic Callback Example 

function greet(name, callback) {

  console.log(
    "Hello " + name
  );

  callback();

}

function done() {

  console.log(
    "Task Complete"
  );

}

greet(
  "Ali",
  done
);

Output:

Hello Ali
Task Complete

Important: Function Ko Call Nahi, Pass Karna Hai

Correct 

greet(
  "Ali",
  done
);

Different Meaning 

greet(
  "Ali",
  done()
);

done function reference pass karta hai, jabki done() function ko turant execute karta hai aur uska return value pass karta hai.

Callback With Parameters 

function calculate(
  a,
  b,
  callback
) {

  const result =
    a + b;

  callback(result);

}

function showResult(result) {

  console.log(result);

}

calculate(
  10,
  20,
  showResult
);

Asynchronous Callback

Callback ka use asynchronous operations ke saath bhi hota hai. 

function loadData(callback) {

  setTimeout(() => {

    const data = {
      id: 1,
      name: "Ali"
    };

    callback(data);

  }, 2000);

}

loadData((data) => {

  console.log(data);

});

Success Callback 

function login(
  email,
  callback
) {

  console.log(
    "Checking user..."
  );

  callback({
    email: email,
    status:
      "success"
  });

}

login(
  "ali@gmail.com",
  (user) => {

    console.log(user);

  }
);

Error-First Callback Pattern

Node.js style callbacks me commonly pehla parameter error aur second parameter result hota hai. 

function divide(
  a,
  b,
  callback
) {

  if (b === 0) {

    callback(
      "Cannot divide by zero",
      null
    );

    return;

  }

  callback(
    null,
    a / b
  );

}

divide(
  10,
  2,
  (error, result) => {

    if (error) {
      console.log(error);
      return;
    }

    console.log(result);

  }
);

Callback Hell

Jab multiple asynchronous callbacks ek dusre ke andar deeply nested ho jate hain, code difficult to read ho sakta hai. Is situation ko commonly callback hell kaha jata hai. 

getUser((user) => {

  getOrders(
    user.id,
    (orders) => {

      getPayment(
        orders[0].id,
        (payment) => {

          console.log(payment);

        }
      );

    }
  );

});

Callback Hell Flow 

Get User

    ↓

Callback

    ↓

Get Orders

    ↓

Callback

    ↓

Get Payment

    ↓

Callback

    ↓

Result

Isi problem ko improve karne ke liye Promises aur baad me async/await use kiye jate hain.

Normal Function vs Callback Function

Normal Function Callback Function
Directly call kiya ja sakta hai. Dusre function ko argument me pass hota hai.
greet() process(greet)
Normal execution ke liye. Custom behavior aur async flow me useful.

Real Project Example

JavaScript me event listeners bhi callback functions use karte hain. 

const button =
  document.getElementById(
    "btn"
  );

button.addEventListener(
  "click",
  () => {

    console.log(
      "Button Clicked"
    );

  }
);

Yahan arrow function addEventListener() ka callback hai.

Important Points

1. Callback ek function hota hai jo dusre function ko argument ke roop me pass hota hai.

2. Callback function ko named, anonymous ya arrow function ke form me likh sakte hain.

3. Callback ko parameters bhi pass kiye ja sakte hain.

4. forEach(), map() aur filter() callbacks use karte hain.

5. setTimeout() me bhi callback diya jata hai.

6. Event listeners me callback functions bahut common hain.

7. Deeply nested callbacks se callback hell ho sakta hai.

8. Complex asynchronous code ke liye Promises aur async/await zyada readable approach dete hain.
