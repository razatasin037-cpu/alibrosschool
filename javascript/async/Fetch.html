Fetch API Kya Hai?

JavaScript me fetch() ka use server ya API se data lene aur bhejne ke liye hota hai.

Fetch API Promise return karta hai, isliye ise then() ya async / await ke saath use kar sakte hain.

Fetch Syntax 

fetch(url)
  .then((response) => {

    // response handle

  });

GET Request

Server se data lene ke liye GET request use hoti hai. 

fetch(
  "https://jsonplaceholder.typicode.com/users"
)
  .then((response) => {
    return response.json();
  })
  .then((data) => {
    console.log(data);
  });

response.json()

Fetch se milne wala Response object directly JSON object nahi hota.

JSON body ko read aur parse karne ke liye response.json() use karte hain. Ye bhi Promise return karta hai.

Fetch With async / await 

async function getUsers() {

  const response =
    await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

  const data =
    await response.json();

  console.log(data);

}

getUsers();

Error Handling

Fetch network failure par reject ho sakta hai. HTTP error status, jaise 404 ya 500, ko manually response.ok se check karna useful hai. 

async function getUsers() {

  try {

    const response =
      await fetch(
        "https://jsonplaceholder.typicode.com/users"
      );

    if (!response.ok) {

      throw new Error(
        "Request Failed"
      );

    }

    const data =
      await response.json();

    console.log(data);

  } catch (error) {

    console.log(
      error.message
    );

  }

}

getUsers();

Response Status 

const response =
  await fetch(url);

console.log(
  response.status
);

console.log(
  response.ok
);

Example: 200 status normally successful response ko indicate karta hai.

POST Request

Server ko new data bhejne ke liye POST request use ki ja sakti hai. 

const user = {

  name:
    "Ali",

  email:
    "ali@gmail.com"

};

fetch(
  "https://jsonplaceholder.typicode.com/users",
  {

    method:
      "POST",

    headers: {

      "Content-Type":
        "application/json"

    },

    body:
      JSON.stringify(user)

  }
)
  .then(
    response =>
      response.json()
  )
  .then((data) => {

    console.log(data);

  });

JSON.stringify()

JavaScript object ko JSON text me convert karne ke liye JSON.stringify() use hota hai. 

const user = {
  name: "Ali"
};

const json =
  JSON.stringify(user);

console.log(json);
{"name":"Ali"}

PUT Request

Existing resource ko replace/update karne ke liye PUT request use ki ja sakti hai. 

fetch(
  "https://jsonplaceholder.typicode.com/users/1",
  {

    method:
      "PUT",

    headers: {

      "Content-Type":
        "application/json"

    },

    body:
      JSON.stringify({

        name:
          "Updated User",

        email:
          "updated@gmail.com"

      })

  }
);

HTTP Methods

Method Use
GET Data lena
POST New data bhejna/create karna
PUT Resource replace/update karna
PATCH Partial update
DELETE Resource delete karna

Headers

Request ke saath extra information bhejne ke liye headers use hote hain. 

headers: {

  "Content-Type":
    "application/json",

  "Accept":
    "application/json"

}

Authorization Header

Protected API request me Bearer token bhejne ka common format: 

const token =
  localStorage.getItem(
    "token"
  );

fetch(
  "https://example.com/api/user",
  {

    headers: {

      "Accept":
        "application/json",

      "Authorization":
        `Bearer ${token}`

    }

  }
);

API Data HTML Me Show Karna 

<div id="users"></div>

<script>

async function getUsers() {

  const response =
    await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

  const users =
    await response.json();

  let html = "";

  users.forEach((user) => {

    html +=
      `<p>${user.name}</p>`;

  });

  document.getElementById(
    "users"
  ).innerHTML = html;

}

getUsers();

</script>

Fetch vs Axios

Fetch Axios
Browser me built-in available hai. External library hai.
Install karna zaroori nahi. Normally package install karna hota hai.
JSON ke liye response.json() call karte hain. Parsed response commonly response.data me milta hai.
HTTP error status manually check karna pad sakta hai. Non-2xx responses normally rejected Promise ban jate hain.

Important Points

1. fetch() HTTP request bhejne ke liye use hota hai.

2. fetch() Promise return karta hai.

3. response.json() JSON response body ko JavaScript value me parse karta hai.

4. GET request data lene ke liye use hoti hai.

5. POST new data send/create karne ke liye commonly use hota hai.

6. PUT aur PATCH data update karne ke liye use kiye ja sakte hain.

7. DELETE resource remove karne ke liye use hota hai.

8. JSON.stringify() JavaScript data ko JSON text me convert karta hai.

9. HTTP error status ke liye response.ok check karna useful hai.

10. Fetch ko async / await aur try...catch ke saath use karna clean approach hai.
