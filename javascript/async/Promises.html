Promise Kya Hai?

JavaScript me Promise ek object hota hai jo future me complete hone wale asynchronous operation ka result represent karta hai.

Promise successful ho sakta hai ya fail ho sakta hai. Iske result ko then(), catch() aur finally() se handle karte hain.

Promise Syntax 

const promise =
  new Promise(
    (resolve, reject) => {

      // async code

    }
  );

Promise States

State Meaning
Pending Promise abhi complete nahi hua.
Fulfilled Promise successfully complete ho gaya.
Rejected Promise fail ho gaya.

Basic Promise Example 

const promise =
  new Promise(
    (resolve, reject) => {

      const success =
        true;

      if (success) {

        resolve(
          "Task completed"
        );

      } else {

        reject(
          "Task failed"
        );

      }

    }
  );

then()

Promise successfully resolve hone par then() run hota hai. 

promise.then((result) => {

  console.log(result);

});
Task completed

catch()

Promise reject hone par catch() error handle karta hai. 

promise.catch((error) => {

  console.log(error);

});

finally()

Promise resolve ho ya reject, finally() dono cases me run hota hai. 

promise.finally(() => {

  console.log(
    "Promise finished"
  );

});

then() + catch() + finally() 

promise
  .then((result) => {

    console.log(result);

  })
  .catch((error) => {

    console.log(error);

  })
  .finally(() => {

    console.log(
      "Finished"
    );

  });

Promise With setTimeout() 

const promise =
  new Promise(
    (resolve) => {

      setTimeout(() => {

        resolve(
          "Data Loaded"
        );

      }, 2000);

    }
  );

promise.then((result) => {
  console.log(result);
});
Data Loaded

Function Se Promise Return Karna 

function getData() {

  return new Promise(
    (resolve, reject) => {

      const dataFound =
        true;

      if (dataFound) {

        resolve({
          id: 1,
          name: "Ali"
        });

      } else {

        reject(
          "Data not found"
        );

      }

    }
  );

}

getData()
  .then((data) => {
    console.log(data);
  })
  .catch((error) => {
    console.log(error);
  });

Promise Chaining

Ek then() se value return karke next then() me use kar sakte hain. 

Promise.resolve(10)
  .then((number) => {

    return number * 2;

  })
  .then((number) => {

    return number + 5;

  })
  .then((result) => {

    console.log(result);

  });
25

Promise.resolve()

Already fulfilled Promise create karne ke liye Promise.resolve() use kar sakte hain. 

Promise.resolve(
  "Success"
)
  .then((result) => {

    console.log(result);

  });

Promise.reject() 

Promise.reject(
  "Something went wrong"
)
  .catch((error) => {

    console.log(error);

  });

Promise.all()

Multiple Promises ko ek saath wait karne ke liye Promise.all() use hota hai. 

const p1 =
  Promise.resolve("User");

const p2 =
  Promise.resolve("Products");

const p3 =
  Promise.resolve("Orders");

Promise.all([
  p1,
  p2,
  p3
])
  .then((results) => {

    console.log(results);

  });
["User", "Products", "Orders"]

Promise.all() Important

Agar Promise.all() me koi ek Promise reject ho jaye, returned Promise reject ho jata hai aur us rejection ko catch() se handle kar sakte hain.

Promise.allSettled()

Sab Promises ke settle hone ka wait karta hai, chahe wo fulfilled hon ya rejected. 

const p1 =
  Promise.resolve("Success");

const p2 =
  Promise.reject("Error");

Promise.allSettled([
  p1,
  p2
])
  .then((results) => {

    console.log(results);

  });

Promise.race()

Jo Promise sabse pehle settle hota hai, Promise.race() uska result leta hai. 

const fast =
  new Promise(
    (resolve) => {

      setTimeout(
        () => resolve(
          "Fast"
        ),
        1000
      );

    }
  );

const slow =
  new Promise(
    (resolve) => {

      setTimeout(
        () => resolve(
          "Slow"
        ),
        3000
      );

    }
  );

Promise.race([
  fast,
  slow
])
  .then((result) => {

    console.log(result);

  });
Fast

Callback vs Promise

Callback Promise
Function argument me pass hota hai. Async result represent karta hai.
Deep nesting ho sakti hai. Chaining se code readable ho sakta hai.
Error handling manually manage karna pad sakta hai. catch() se errors handle hote hain.

Real Project Example

Login jaise asynchronous operation ko Promise ke through represent kar sakte ho. 

function login(
  email,
  password
) {

  return new Promise(
    (resolve, reject) => {

      if (
        email ===
          "admin@gmail.com"
        &&
        password ===
          "1234"
      ) {

        resolve(
          "Login Successful"
        );

      } else {

        reject(
          "Invalid Login"
        );

      }

    }
  );

}

login(
  "admin@gmail.com",
  "1234"
)
  .then((message) => {
    console.log(message);
  })
  .catch((error) => {
    console.log(error);
  });

Important Points

1. Promise asynchronous task ka future result represent karta hai.

2. Promise ke three main states hain: Pending, Fulfilled aur Rejected.

3. resolve() successful result deta hai.

4. reject() failure result deta hai.

5. then() fulfilled Promise ko handle karta hai.

6. catch() rejection aur chain me throw hui errors handle karta hai.

7. finally() Promise settle hone ke baad run hota hai.

8. Promise chaining se multiple async steps ko organize kiya ja sakta hai.

9. Promise.all() multiple Promises ko saath handle karne ke liye useful hai.
