Async JavaScript Kya Hai?

JavaScript me asynchronous programming ka use aise tasks ke liye hota hai jo complete hone me time lete hain, jaise API request, timer ya server se data fetch karna.

Async code ki wajah se JavaScript baaki code ko wait karaye bina continue kar sakta hai.

Synchronous JavaScript

Synchronous code ek-ek line order me execute hota hai. 

console.log("One");

console.log("Two");

console.log("Three");
One
Two
Three

Asynchronous JavaScript 

console.log("Start");

setTimeout(() => {
  console.log("Hello");
}, 2000);

console.log("End");

Output:

Start
End
Hello

setTimeout()

setTimeout() kisi function ko specified delay ke baad run karta hai. 

setTimeout(() => {

  console.log(
    "2 seconds later"
  );

}, 2000);

Callback Function

Callback ek function hota hai jo kisi dusre function ko argument ke roop me diya jata hai. 

function greet(name, callback) {

  console.log(
    "Hello " + name
  );

  callback();

}

function done() {

  console.log(
    "Done"
  );

}

greet(
  "Ali",
  done
);

Promise

Promise future me complete hone wale asynchronous task ka result represent karta hai. 

const promise =
  new Promise(
    (resolve, reject) => {

      const success =
        true;

      if (success) {
        resolve(
          "Success"
        );
      } else {
        reject(
          "Error"
        );
      }

    }
  );

Promise States

State Meaning
Pending Task abhi complete nahi hua.
Fulfilled Task successfully complete ho gaya.
Rejected Task fail ho gaya.

then() Aur catch() 

promise
  .then((result) => {

    console.log(result);

  })
  .catch((error) => {

    console.log(error);

  });

async / await

async aur await Promise based code ko readable aur simple banate hain. 

async function getData() {

  const response =
    await fetch(
      "https://example.com/data"
    );

  console.log(response);

}

async Function

async function hamesha Promise return karta hai. 

async function hello() {

  return
    "Hello";

}

hello().then((result) => {
  console.log(result);
});
Hello

Fetch API

Fetch API ka use server ya API se data lene ke liye kiya jata hai. 

fetch(
  "https://jsonplaceholder.typicode.com/users"
)
  .then(
    response => response.json()
  )
  .then((data) => {
    console.log(data);
  })
  .catch((error) => {
    console.log(error);
  });

Fetch With async / await 

async function getUsers() {

  const response =
    await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

  const data =
    await response.json();

  console.log(data);

}

getUsers();

Async Error Handling

Async/await ke saath errors handle karne ke liye try...catch use karte hain. 

async function getData() {

  try {

    const response =
      await fetch(
        "https://example.com/data"
      );

    console.log(response);

  } catch (error) {

    console.log(error);

  }

}

Async Concepts Difference

Concept Use

Promise Future async result handle karna.
async/await Promise code ko readable syntax me likhna.
fetch() HTTP request / API data ke liye.

Real Project Example

React + Laravel project me jab frontend se backend API call karte ho, wo asynchronous operation hota hai.

Jaise products load karna, login request bhejna, users fetch karna ya form data save karna.

Important Points

1. Synchronous code line-by-line execute hota hai.

2. Asynchronous code slow tasks ke wait me baaki code ko block nahi karta.

3. setTimeout() delayed task run karta hai.

4. Callback function dusre function ko argument ke roop me diya jata hai.

5. Promise ke states Pending, Fulfilled aur Rejected hote hain.

6. async function Promise return karta hai.

7. await Promise ke settle hone ka result wait karta hai.

8. fetch() API requests ke liye commonly use hota hai.

9. try...catch async errors handle karne ke liye useful hai.
