JavaScript Introduction & Core Concepts

JavaScript ek lightweight, interpreted programming language hai jo modern web development ka sabse mukhya hissa hai.

Iska upayog client-side (browser par) Web pages ko interactive banane aur server-side (Node.js par) backend applications banane ke liye kiya jata hai.

Easy to Learn

JavaScript ka syntax beginner-friendly hai aur aap browser ke console me hi code test kar sakte hain.

Fast Execution

Client-side par run hone ki wajah se ye fast executing aur responsive web pages create karta hai.

Universal Support

Duniya ke lagbhag sabhi web browsers (Chrome, Edge, Firefox, Safari) me default support hota hai.

1. JS HTML Content Ko Change Kar Sakta Hai

JavaScript me getElementById() method sabse zyada use hone waala HTML DOM method hai: 

document.getElementById("demo").innerHTML = "Hello JavaScript!";

Ye method element jiska ID "demo" hai, uska text dynamic badal deta hai.

2. JS Image Source (`src`) Ko Change Kar Sakta Hai

JavaScript HTML attributes ki values ko change kar sakta hai. Yahan dekhiye kaise button click karne par src attribute change hota hai: 

<!-- Light On Button -->
<button onclick="document.getElementById('myImage').src='pic_bulbon.gif'">Turn On</button>

<!-- Light Off Button -->
<button onclick="document.getElementById('myImage').src='pic_bulboff.gif'">Turn Off</button>

3. HTML Styles (CSS) Change Karna

JavaScript se aap kisi bhi HTML element ka CSS style directly update kar sakte hain: 

const element = document.getElementById("demo");
element.style.fontSize = "25px";
element.style.color = "#3158ff";
element.style.display = "block";

4. JavaScript Code Kahan Likhein?

JavaScript code ko HTML document me <script> tag ke andar placement ke hisab se do tarike se likha ja sakta hai:

  • Internal JavaScript: Code ko HTML file ke <head> ya <body> section me <script> tag ke andar likha jata hai.
  • External JavaScript: Code ko alag .js file me likhkar HTML file me include kiya jata hai:
    <script src="script.js"></script>
