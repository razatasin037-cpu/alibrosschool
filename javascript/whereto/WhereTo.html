JavaScript Code Kahan Place Karein?

HTML me JavaScript code ko <script> tag ke andar likha jata hai.

Aap apne script tag ko HTML ke <head> section me, <body> section me, ya fir kisi external .js file me rakh sakte hain.

In <head>

Page load hone se pehle scripts initialize karne ya libraries include karne ke liye.

In <body> (Recommended)

Bottom par rkhne se page ka display speed fast ho jata hai.

External File

Code ko clean, reusable aur maintainable rakhne ke liye alag .js file me.

1. The <script> Tag

HTML document me JavaScript code daalne ke liye <script> aur </script> tags ka use hota hai: 

<script>
  document.getElementById("demo").innerHTML = "My First JavaScript";
</script>

2. JavaScript in <head> or <body>

Aap kisi bhi HTML document me kitne bhi scripts rakh sakte hain.

Example: JavaScript in <head>

<!DOCTYPE html>
<html>
<head>
  <script>
    function myFunction() {
      document.getElementById("demo").innerHTML = "Paragraph changed.";
    }
  </script>
</head>
<body>
  <h2>Demo JavaScript in Head</h2>
  <p id="demo">A Paragraph</p>
  <button onclick="myFunction()">Try it</button>
</body>
</html>

Example: JavaScript in <body> (Best Practice)

Scripts ko <body> ke bilkul bottom me rakhna display speed badhata hai kyunki HTML parse hona pehle complete hota hai. 

<!DOCTYPE html>
<html>
<body>

  <h2>Demo JavaScript in Body</h2>
  <p id="demo">A Paragraph</p>
  <button onclick="myFunction()">Try it</button>

  <script>
    function myFunction() {
      document.getElementById("demo").innerHTML = "Paragraph changed.";
    }
  </script>

</body>
</html>

3. External JavaScript (.js file)

Jab wahi script multiple web pages par use honi ho, toh **External JavaScript** sabse best option hota hai.

File: myScript.js 
function myFunction() {
  document.getElementById("demo").innerHTML = "Paragraph changed.";
}
File: index.html 
<script src="myScript.js"></script>

External JavaScript Ke Fayde:

  • HTML aur Code (Logic) alag-alag rehte hain.
  • HTML aur JavaScript files ko read aur maintain karna aasan ho jata hai.
  • Cached JavaScript files se page load speed fast hoti hai.
