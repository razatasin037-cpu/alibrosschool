forEach() Kya Hai?

JavaScript me forEach() Array ke har element par ek callback function execute karta hai.

Iska use tab hota hai jab hume Array ke har item par koi action perform karna ho, jaise console me print karna ya DOM me data show karna.

forEach() Syntax 

array.forEach((value, index, array) => {
  // code
});

Simple forEach() Example 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.forEach((fruit) => {
  console.log(fruit);
});

Output:

Apple
Mango
Banana

Current Value

Callback ka first parameter current Array element hota hai. 

const numbers = [
  10,
  20,
  30
];

numbers.forEach((number) => {
  console.log(number);
});

Output:

10
20
30

Value Aur Index

Callback ka second parameter current element ka index hota hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.forEach((fruit, index) => {
  console.log(index, fruit);
});

Output:

0 Apple
1 Mango
2 Banana

Third Parameter: Array

Callback ka third parameter original Array ko represent karta hai. 

const numbers = [
  10,
  20
];

numbers.forEach(
  (value, index, array) => {

    console.log(value);
    console.log(index);
    console.log(array);

  }
);

forEach() With Normal Function 

const numbers = [
  1,
  2,
  3
];

numbers.forEach(
  function(number) {
    console.log(number);
  }
);
1
2
3

forEach() With Named Function 

const numbers = [
  10,
  20,
  30
];

function showNumber(number) {
  console.log(number);
}

numbers.forEach(showNumber);
10
20
30

Calculation With forEach() 

const numbers = [
  10,
  20,
  30
];

let total = 0;

numbers.forEach((number) => {
  total = total + number;
});

console.log(total);

Output:

60

forEach() With Array of Objects 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

students.forEach((student) => {
  console.log(student.name);
});

Output:

Ali
Rahul

forEach() Se HTML Display 

<ul id="list"></ul>

<script>

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

let html = "";

fruits.forEach((fruit) => {
  html += `<li>${fruit}</li>`;
});

document.getElementById(
  "list"
).innerHTML = html;

</script>

forEach() Kya Return Karta Hai?

forEach() ka return value undefined hota hai. Ye new Array create nahi karta. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.forEach((number) => {
    return number * 2;
  });

console.log(result);

Output:

undefined

forEach() vs map()

forEach() map()
Har item par action perform karta hai. Har item ko transform karta hai.
New Array return nahi karta. New Array return karta hai.
undefined [...]

Important Points

1. forEach() Array ke har element par callback run karta hai.

2. Callback ka first parameter current value hota hai.

3. Second parameter current index hota hai.

4. Third parameter original array hota hai.

5. forEach() new Array return nahi karta.

6. Iska return value undefined hota hai.

7. Data ko transform karke new Array chahiye to map() better hai.
