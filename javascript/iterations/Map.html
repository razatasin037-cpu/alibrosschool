map() Kya Hai?

JavaScript me map() Array ke har element par callback function run karta hai aur uske result se ek new Array banata hai.

Jab hume existing Array ke har item ko transform karke new Array banana ho, tab map() bahut useful hota hai.

map() Syntax 

const newArray =
  array.map((value, index, array) => {

    return newValue;

  });

Simple map() Example 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map((number) => {

    return number * 2;

  });

console.log(result);

Output:

[2, 4, 6]

map() Short Syntax

Arrow function me ek hi expression ho to return aur curly braces hata sakte hain. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map(
    number => number * 2
  );

console.log(result);
[2, 4, 6]

map() New Array Return Karta Hai

Normal use me map() original Array ko replace nahi karta. Result ek new Array me milta hai. 

const numbers = [
  1,
  2,
  3
];

const doubled =
  numbers.map(
    number => number * 2
  );

console.log(numbers);
console.log(doubled);

Output:

[1, 2, 3]
[2, 4, 6]

map() With Index

Callback ka second parameter current element ka index hota hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

const result =
  fruits.map((fruit, index) => {

    return
      index + " - " + fruit;

  });

console.log(result);

Output:

[
  "0 - Apple",
  "1 - Mango",
  "2 - Banana"
]

Strings Ko Transform Karna 

const names = [
  "ali",
  "rahul",
  "aman"
];

const result =
  names.map(
    name => name.toUpperCase()
  );

console.log(result);

Output:

["ALI", "RAHUL", "AMAN"]

map() With Array of Objects

Array of Objects se sirf required property nikalne ke liye map() bahut useful hai. 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

const names =
  students.map(
    student => student.name
  );

console.log(names);

Output:

["Ali", "Rahul"]

New Objects Create Karna 

const products = [
  {
    name: "Mouse",
    price: 500
  },
  {
    name: "Keyboard",
    price: 1000
  }
];

const result =
  products.map((product) => {

    return {
      name: product.name,
      price: product.price,
      gstPrice: product.price * 1.18
    };

  });

console.log(result);

Object Return Short Syntax

Arrow function se directly Object return karte waqt Object ko parentheses ( ) ke andar likhna hota hai. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map(
    number => ({
      value: number
    })
  );

console.log(result);
[
  { value: 1 },
  { value: 2 },
  { value: 3 }
]

map() Callback Parameters 

array.map(
  (value, index, array) => {

    console.log(value);
    console.log(index);
    console.log(array);

  }
);
Parameter Meaning
value Current element
index Current element ka index
array Original Array

map() React Me Kyu Important Hai?

React me Array data se multiple elements render karne ke liye map() bahut commonly use hota hai. 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

students.map((student) => {
  return student.name;
});

map() vs forEach()

map() forEach()
New Array return karta hai. New Array return nahi karta.
Data transformation ke liye useful. Har item par action perform karne ke liye useful.
const result = arr.map(...) arr.forEach(...)

Important Points

1. map() Array ke har element par callback run karta hai.

2. map() ek new Array return karta hai.

3. New Array ki length normally source Array ki length ke corresponding hoti hai.

4. Callback se jo value return hoti hai wahi new Array ka element banti hai.

5. Array of Objects se specific properties nikalne ke liye map() useful hai.

6. map() aur forEach() ka main difference return value hai.

7. React me list rendering ke liye map() bahut important hai.
