Iteration Kya Hai?

JavaScript me Iteration ka matlab hai kisi collection, jaise Array, ke elements par ek-ek karke kaam karna.

Iske liye hum normal loops ke saath forEach(), map(), filter(), reduce() aur for...of use kar sakte hain.

Iteration Ka Use Kyu Karte Hain?

1. Array ke har element ko access karne ke liye.

2. Data ko transform karne ke liye.

3. Condition ke according values filter karne ke liye.

4. Array ke values ka total ya single result nikalne ke liye.

5. Repeated code ko easy aur readable banane ke liye.

Normal For Loop Iteration 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

for (
  let i = 0;
  i < fruits.length;
  i++
) {
  console.log(fruits[i]);
}

Output:

Apple
Mango
Banana

forEach()

forEach() Array ke har element par callback function run karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.forEach((fruit) => {
  console.log(fruit);
});

Output:

Apple
Mango
Banana

map()

map() har element ko process karke ek new Array return karta hai. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map(
    number => number * 2
  );

console.log(result);

Output:

[2, 4, 6]

filter()

filter() condition true hone wale elements ka new Array return karta hai. 

const numbers = [
  5,
  10,
  15,
  20
];

const result =
  numbers.filter(
    number => number > 10
  );

console.log(result);

Output:

[15, 20]

reduce()

reduce() Array ke multiple values ko process karke ek single result return karta hai. 

const numbers = [
  10,
  20,
  30
];

const total =
  numbers.reduce(
    (sum, number) => sum + number,
    0
  );

console.log(total);

Output:

60

for...of

for...of iterable values ko directly access karta hai. 

const colors = [
  "Red",
  "Blue",
  "Green"
];

for (
  const color
  of
  colors
) {
  console.log(color);
}

Output:

Red
Blue
Green

Callback Function Kya Hai?

Array iteration methods me jo function argument ke roop me pass hota hai use callback function kehte hain. 

const numbers = [
  10,
  20
];

numbers.forEach(
  (number) => {
    console.log(number);
  }
);

Yahan (number) => { } callback function hai.

Value, Index Aur Array

Kai Array iteration callbacks ko current value, index aur original Array mil sakta hai. 

const fruits = [
  "Apple",
  "Mango"
];

fruits.forEach(
  (value, index, array) => {

    console.log(value);
    console.log(index);
    console.log(array);

  }
);

Iteration With Array of Objects 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

students.forEach((student) => {
  console.log(student.name);
});

Output:

Ali
Rahul

Iteration Methods Difference

Method Main Use Returns
forEach() Har item par action undefined
map() Data transform New Array
filter() Matching items select New Array
reduce() Single result banana Any accumulated value
for...of Values par loop Loop statement

Kaunsa Method Kab Use Kare?

Sirf har item par kaam karna hai → forEach()

Har item ko change karke new Array banana hai → map()

Condition ke according items select karne hain → filter()

Total ya single result chahiye → reduce()

Simple values par loop chahiye → for...of

Important Points

1. Iteration ka matlab values ko ek-ek karke process karna hai.

2. forEach() har Array item par callback run karta hai.

3. map() new transformed Array return karta hai.

4. filter() condition match karne wale elements return karta hai.

5. reduce() Array ko ek accumulated result me convert kar sakta hai.

6. for...of iterable ke values ko directly access karta hai.

7. React me map() list rendering ke liye bahut important hai.
