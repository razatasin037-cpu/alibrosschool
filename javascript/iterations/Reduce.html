reduce() Kya Hai?

JavaScript me reduce() Array ke elements ko ek-ek karke process karta hai aur end me ek single result return karta hai.

Iska use total, sum, count, object grouping aur complex calculations ke liye kiya jata hai.

reduce() Syntax 

const result =
  array.reduce(
    (accumulator, currentValue) => {

      return accumulator + currentValue;

    },
    initialValue
  );

Simple Sum Example 

const numbers = [
  10,
  20,
  30
];

const total =
  numbers.reduce(
    (sum, number) => {
      return sum + number;
    },
    0
  );

console.log(total);

Output:

60

reduce() Short Syntax 

const numbers = [
  10,
  20,
  30
];

const total =
  numbers.reduce(
    (sum, number) => sum + number,
    0
  );

console.log(total);
60

reduce() Parameters

Parameter Meaning
accumulator Previous calculation ka result.
currentValue Current Array element.
currentIndex Current element ka index.
array Original Array.
initialValue Accumulator ki starting value.

Array of Objects Ka Total

Shopping cart ya inventory project me total price calculate karne ke liye reduce() useful hota hai. 

const products = [
  {
    name: "Mouse",
    price: 500
  },
  {
    name: "Keyboard",
    price: 1000
  },
  {
    name: "Monitor",
    price: 8000
  }
];

const totalPrice =
  products.reduce(
    (total, product) =>
      total + product.price,
    0
  );

console.log(totalPrice);

Output:

9500

Price × Quantity Total 

const cart = [
  {
    price: 500,
    qty: 2
  },

    qty: 3
  }
];

const total =
  cart.reduce(

    0
  );

console.log(total);

Output:

4000

Largest Number Find Karna 

const numbers = [
  10,
  50,
  20,
  80
];

const largest =
  numbers.reduce(
    (max, number) =>
      number > max ? number : max
  );

console.log(largest);
80

Values Ki Count Banana 

const fruits = [
  "Apple",
  "Mango",
  "Apple",
  "Banana",
  "Apple"
];

const count =
  fruits.reduce(
    (result, fruit) => {

      result[fruit] =
        (result[fruit] || 0) + 1;

      return result;

    },
    {}
  );

console.log(count);
{
  Apple: 3,
  Mango: 1,
  Banana: 1
}

Arrays Ko Combine Karna 

const arrays = [

initialValue Kyu Important Hai?

Initial value dene se accumulator ki starting value clear hoti hai. Sum ke liye usually 0 aur multiplication ke liye 1 use kiya jata hai. 

const numbers = [
  10,
  20
];

const total =
  numbers.reduce(
    (sum, number) =>
      sum + number,
    100
  );

console.log(total);
130

reduce() vs map() vs filter()

Method Use Returns
map() Elements transform karna New Array
filter() Elements select karna New Array
reduce() Values combine / accumulate karna Single accumulated result

Important Points

1. reduce() Array ke elements ko accumulated result me convert karta hai.

2. accumulator previous calculation ka result store karta hai.

3. currentValue current Array element hota hai.

4. initialValue accumulator ki starting value hoti hai.

5. Sum, cart total aur inventory value calculate karne me reduce() useful hai.

6. reduce() sirf Number nahi, Object ya Array bhi return kar sakta hai.

7. Complex data grouping aur counting me bhi reduce() ka use hota hai.
