for...of Kya Hai?

JavaScript me for...of loop ka use iterable values par loop chalane ke liye hota hai.

Ye Array, String, Set, Map aur dusre iterable objects ke values ko directly access karta hai.

for...of Syntax 

for (
  const value
  of iterable
) {
  // code
}

for...of With Array 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

for (
  const fruit
  of fruits
) {
  console.log(fruit);
}

Output:

Apple
Mango
Banana

for...of With Numbers Array 

const numbers = [
  10,
  20,
  30

  of numbers

Total Calculate Karna 

const numbers = [
  10,
  20,
  30
];

let total = 0;

for (
  const number
  of numbers
) {
  total += number;
}

console.log(total);

60

  new Map([
    ["name", "Ali"],
    ["age", 20]
  ]);

for (
  const [key, value]
  of user
) {
  console.log(key, value);
}
name Ali
age 20

Array Value Aur Index Dono Lena

Agar for...of ke saath Array ka index bhi chahiye to entries() use kar sakte hain. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

for (
  const [index, fruit]
  of
  fruits.entries()
) {
  console.log(index, fruit);
}
0 Apple
1 Mango
2 Banana

for...of With break

break se loop ko beech me stop kar sakte hain. 

const numbers = [
  10,
  20,
  30,
  40
];

for (
  const number
  of numbers
) {

  if (
    number === 30
  ) {
    break;
  }

  console.log(number);
}
10
20

for...of With continue 

const numbers = [
  1,
  2,
  3,
  4
];

for (
  const number
  of numbers
) {

  if (
    number === 3
  ) {
    continue;
  }

  console.log(number);
}
1
2
4

for...of vs for...in

for...of for...in
Iterable ki values deta hai. Enumerable property keys deta hai.
Arrays, Strings, Sets, Maps ke liye useful. Object properties ke liye commonly use hota hai.
for (const value of array) for (const key in object)

for...of vs forEach()

for...of forEach()
Loop statement hai. Array method hai.
break aur continue use kar sakte hain. Normal break se callback iteration ko stop nahi kar sakte.
Multiple iterable types ke saath kaam karta hai. Arrays ke liye commonly use hota hai.

Important Points

1. for...of iterable ki values ko directly access karta hai.

2. Ye Arrays, Strings, Sets aur Maps ke saath use hota hai.

3. Array ka index chahiye to array.entries() use kar sakte hain.

4. break se loop stop kiya ja sakta hai.

5. continue current iteration skip karta hai.

6. for...of values deta hai, jabki for...in property keys deta hai.

7. Simple readable iteration ke liye for...of bahut useful hai.
