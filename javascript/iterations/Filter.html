filter() Kya Hai?

JavaScript me filter() Array ke elements ko condition ke according check karta hai.

Jo elements condition ko true karte hain, unka ek new Array return hota hai.

filter() Syntax 

const newArray =
  array.filter((value, index, array) => {

    return condition;

  });

Simple filter() Example

10 se bade numbers ko filter karte hain. 

const numbers = [
  5,
  12,
  18,
  7
];

const result =
  numbers.filter((number) => {

    return number > 10;

  });

console.log(result);

Output:

[12, 18]

filter() Short Syntax 

const numbers = [
  5,
  12,
  18,
  7
];

const result =
  numbers.filter(
    number => number > 10
  );

console.log(result);

Output:

[12, 18]

Even Numbers Filter Karna 

const numbers = [
  1,
  2,
  3,
  4,
  5,
  6
];

const evenNumbers =
  numbers.filter(
    number => number % 2 === 0
  );

console.log(evenNumbers);

Output:

[2, 4, 6]

Odd Numbers Filter Karna 

const numbers = [
  1,
  2,
  3,
  4,
  5
];

const oddNumbers =
  numbers.filter(
    number => number % 2 !== 0
  );

console.log(oddNumbers);

Output:

[1, 3, 5]

Strings Ko Filter Karna

5 ya usse zyada characters wale names select karte hain. 

const names = [
  "Ali",
  "Rahul",
  "Aman",
  "Parwez"
];

const result =
  names.filter(
    name => name.length >= 5
  );

console.log(result);

Output:

["Rahul", "Parwez"]

filter() With Array of Objects

Real projects me filter() Array of Objects ke saath bahut useful hota hai. 

const products = [
  {
    name: "Mouse",
    price: 500
  },
  {
    name: "Keyboard",
    price: 1200
  },
  {
    name: "Monitor",
    price: 8000
  }
];

const result =
  products.filter(
    product => product.price > 1000
  );

console.log(result);

Filtered Products:

[
  { name: "Keyboard", price: 1200 },
  { name: "Monitor", price: 8000 }
]

Active Users Filter Karna 

const users = [
  {
    name: "Ali",
    active: true
  },
  {
    name: "Rahul",
    active: false
  },
  {
    name: "Aman",
    active: true
  }
];

const activeUsers =
  users.filter(
    user => user.active === true
  );

console.log(activeUsers);

Search Feature With filter()

Search bar jaise features me filter() bahut commonly use hota hai. 

const products = [
  "Laptop",
  "Mouse",
  "Keyboard",
  "Monitor"
];

const search =
  "mo";

const result =
  products.filter((product) =>

    product
      .toLowerCase()
      .includes(
        search.toLowerCase()
      )

  );

console.log(result);

Output:

["Mouse", "Monitor"]

filter() Original Array Ko Replace Nahi Karta 

const numbers = [
  5,
  15,
  25
];

const result =
  numbers.filter(
    number => number > 10
  );

console.log(numbers);
console.log(result);

Output:

[5, 15, 25]
[15, 25]

Koi Element Match Na Kare To

Agar koi element condition match nahi karta to filter() empty Array return karta hai. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.filter(
    number => number > 100
  );

console.log(result);

Output:

[]

filter() With Index 

const names = [
  "Ali",
  "Rahul",
  "Aman",
  "Parwez"
];

const result =
  names.filter(
    (name, index) => index < 2
  );

console.log(result);

Output:

["Ali", "Rahul"]

filter() Callback Parameters 

array.filter(
  (value, index, array) => {

    return condition;

  }
);
Parameter Meaning
value Current Array element
index Current element ka index
array Original Array

filter() vs map()

filter() map()
Condition ke according items select karta hai. Har item ko transform karta hai.
Result ki length chhoti, same, ya zero ho sakti hai. Normal Array usage me result corresponding elements ka transformed Array hota hai.
number => number > 10 number => number * 2

Real Project Example

Inventory ya e-commerce project me active products filter kar sakte ho. 

const products = [
  {
    name: "Laptop",
    status: "active"
  },
  {
    name: "Mouse",
    status: "inactive"
  },
  {
    name: "Keyboard",
    status: "active"
  }
];

const activeProducts =
  products.filter(
    product =>
      product.status === "active"
  );

console.log(activeProducts);

Important Points

1. filter() condition ke according Array elements select karta hai.

2. Callback true return kare to element new Array me include hota hai.

3. Callback false return kare to element new Array me include nahi hota.

4. filter() new Array return karta hai.

5. Koi element match na kare to empty Array [] milta hai.

6. Search, category filtering, active records aur price filtering me ye bahut useful hai.

7. Array of Objects ke saath filter() real projects me bahut commonly use hota hai.
