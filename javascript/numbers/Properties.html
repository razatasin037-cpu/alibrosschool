Number Properties Kya Hain?

JavaScript me Number Properties predefined values hoti hain jo JavaScript ke Number system ke limits aur special numeric values ko represent karti hain.

In properties ko directly Number.propertyName ke through access kiya jata hai.

Number Properties List

Property Use
Number.EPSILON 1 aur next representable floating-point number ke beech ka difference.
Number.MAX_VALUE Sabse bada finite Number value.
Number.MIN_VALUE Zero se bada sabse chhota positive Number value.
Number.MAX_SAFE_INTEGER Sabse bada safely representable integer.
Number.MIN_SAFE_INTEGER Sabse chhota safely representable integer.
Number.POSITIVE_INFINITY Positive Infinity ko represent karta hai.
Number.NEGATIVE_INFINITY Negative Infinity ko represent karta hai.
Number.NaN Not a Number value ko represent karta hai.

Number Property Syntax 

Number.propertyName

Number properties ko function ki tarah call nahi karte, isliye inke saath () nahi lagta.

Number.EPSILON

Floating-point calculations me bahut small difference ko represent karta hai. 

console.log(Number.EPSILON);

Output:

2.220446049250313e-16

Number.MAX_VALUE

JavaScript Number type ka largest finite value return karta hai. 

console.log(Number.MAX_VALUE);

Output:

1.7976931348623157e+308

Number.MIN_VALUE

Zero se greater sabse small positive Number value return karta hai. 

console.log(Number.MIN_VALUE);

Output:

5e-324

Number.MAX_SAFE_INTEGER

JavaScript me safely represent kiya jane wala largest integer hai. 

console.log(Number.MAX_SAFE_INTEGER);

Output:

9007199254740991

Number.MIN_SAFE_INTEGER

JavaScript me safely represent kiya jane wala smallest integer hai. 

console.log(Number.MIN_SAFE_INTEGER);

Output:

-9007199254740991

Number.POSITIVE_INFINITY 

console.log(Number.POSITIVE_INFINITY);

Output:

Infinity

Number.NEGATIVE_INFINITY 

console.log(Number.NEGATIVE_INFINITY);

Output:

-Infinity

Number.NaN

Invalid numeric result ko represent karta hai. 

console.log(Number.NaN);

Output:

NaN

Important Points

1. Number properties ko Number.property syntax se access karte hain.

2. MAX_SAFE_INTEGER aur MIN_SAFE_INTEGER safe integer limits batate hain.

3. MIN_VALUE sabse negative number nahi hai; ye zero ke closest positive representable number ko show karta hai.

4. NaN invalid numeric result ko represent karta hai.

5. Safe integer range se bahut bade exact integers ke liye BigInt useful hota hai.
