Number Methods Kya Hain?

JavaScript me Number Methods ka use numbers ko format, convert aur check karne ke liye kiya jata hai.

In methods ki help se hum number ko String me convert kar sakte hain, decimal places fix kar sakte hain, integer check kar sakte hain aur invalid numeric values ko bhi detect kar sakte hain.

Common Number Methods

Method Use
toString() Number ko String me convert karta hai.
toFixed() Decimal places fix karta hai.
toPrecision() Total significant digits set karta hai.
valueOf() Primitive number value return karta hai.
Number() Value ko Number me convert karta hai.
parseInt() String se integer number nikalta hai.
parseFloat() String se decimal number nikalta hai.
Number.isInteger() Check karta hai value integer hai ya nahi.
Number.isNaN() Check karta hai value NaN hai ya nahi.

Number Method Syntax 

number.methodName();

toString()

toString() Number ko String me convert karta hai. 

let num = 100;

let result = num.toString();

console.log(result);
console.log(typeof result);

Output:

100
string

toFixed()

toFixed() decimal ke baad kitne digits chahiye, wo set karta hai. 

let price = 99.456;

console.log(price.toFixed(2));

Output:

99.46

toPrecision()

toPrecision() total significant digits ki length set karta hai. 

let num = 123.456;

console.log(num.toPrecision(4));

Output:

123.5

valueOf()

valueOf() Number object ki primitive numeric value return karta hai. 

let num = 100;

console.log(num.valueOf());

Output:

100

Number()

Number() kisi value ko Number me convert karta hai. 

let value = "250";

let result = Number(value);

console.log(result);
console.log(typeof result);

Output:

250
number

parseInt()

parseInt() String se integer value parse karta hai. 

let value = "150px";

console.log(parseInt(value));

Output:

150

parseFloat()

parseFloat() String se decimal number parse karta hai. 

let value = "99.50kg";

console.log(parseFloat(value));

Output:

99.5

Number.isInteger()

Check karta hai ki given value integer hai ya nahi. 

console.log(Number.isInteger(100));

console.log(Number.isInteger(10.5));

Output:

true
false

Number.isNaN()

Check karta hai ki given value actual NaN hai ya nahi. 

let result = Number("Hello");

console.log(Number.isNaN(result));

Output:

true

Important Points

1. toString() Number ko String me convert karta hai.

2. toFixed() fixed decimal places return karta hai.

3. Number() full value ko Number me convert karne ki koshish karta hai.

4. parseInt() integer aur parseFloat() decimal value parse karne ke liye useful hain.

5. Number.isInteger() Boolean result return karta hai.

6. Number.isNaN() NaN ko check karta hai.
