Number Kya Hai?

JavaScript me Number ek data type hai jiska use numeric values ko store karne ke liye kiya jata hai.

JavaScript Numbers me integer, decimal, positive aur negative values store ki ja sakti hain. JavaScript me normal numbers ke liye alag integer aur float data types nahi hote; dono number type me aate hain.

Number Syntax 

let variableName = 100;

Number ko quotes ke andar nahi likhte. Agar number ko quotes me likh diya jaye to wo String ban jata hai.

Number Example

Is example me ek number variable me store karke console me print karenge. 

let age = 20;

console.log(age);

Output: 

20

Example Kaise Kaam Kar Raha Hai?

let → Variable create karta hai.

age → Variable ka naam hai.

20 → Number value hai.

console.log(age) → Number ko console me print karta hai.

Types of Number Values

Type Example
Integer 100
Decimal 10.50
Negative -25
Positive 50

Integer and Decimal Numbers 

let x = 100;

let y = 25.50;

console.log(x);
console.log(y);

Output:

100
25.5

Numbers With Arithmetic

Numbers ke saath arithmetic operators use karke calculations kar sakte hain. 

let a = 20;
let b = 10;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Output:

30
10
200
2

Check Number Data Type

typeof operator se Number ka data type check kar sakte hain. 

let price = 500;

console.log(typeof price);

Output:

number

Number vs String Number 

let a = 100;

let b = "100";

console.log(typeof a);

console.log(typeof b);

Output:

number
string

100 Number hai, lekin "100" quotes ke andar hone ki wajah se String hai.

Convert String To Number

Number() function se numeric String ko Number me convert kar sakte hain. 

let value = "100";

let result = Number(value);

console.log(result);

console.log(typeof result);

Output:

100
number

NaN - Not a Number

NaN ka full form Not a Number hai. Jab koi invalid numeric calculation ya conversion hoti hai, JavaScript NaN return kar sakta hai. 

let result = Number("Hello");

console.log(result);

Output:

NaN

Infinity

JavaScript me Infinity ek special numeric value hai jo infinite value ko represent karti hai. 

let number = 1 / 0;

console.log(number);

Output:

Infinity

Exponential Notation

Bahut bade ya chhote numbers ko exponential notation me bhi likh sakte hain. 

let x = 123e5;

let y = 123e-5;

console.log(x);
console.log(y);

Output:

12300000
0.00123

Important Points

1. JavaScript Number numeric values store karta hai.

2. Integer aur decimal dono ka typeof result number hota hai.

3. Quotes ke andar number likhne par wo String ban jata hai.

4. Number() ka use values ko Number me convert karne ke liye hota hai.

5. NaN ka matlab Not a Number hai.

6. Infinity ek special numeric value hai.

7. Bahut bade exact integers ke liye BigInt use kiya ja sakta hai.
