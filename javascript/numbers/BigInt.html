BigInt Kya Hai?

JavaScript me BigInt ka use bahut bade integer numbers ko store karne ke liye kiya jata hai.

Normal JavaScript Number ki safe integer limit hoti hai. Agar hume us limit se bhi bada exact integer store karna ho, to BigInt use kar sakte hain.

BigInt Syntax

BigInt banane ke liye number ke end me n lagaya jata hai. 

let number = 12345678901234567890n;

BigInt Example 

let bigNumber = 9007199254740995n;

console.log(bigNumber);

Output:

9007199254740995n

BigInt Data Type

typeof operator se BigInt ka data type check kar sakte hain. 

let number = 100n;

console.log(typeof number);

Output:

bigint

BigInt() Function

BigInt() function se integer String ya suitable integer value ko BigInt me convert kar sakte hain. 

let number = BigInt("12345678901234567890");

console.log(number);

Output:

12345678901234567890n

BigInt Arithmetic

BigInt ke saath addition, subtraction, multiplication aur division jaise operators use kiye ja sakte hain. 

let a = 20n;
let b = 10n;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Output:

30n
10n
200n
2n

BigInt Division

BigInt integer type hai, isliye division ka decimal part remove ho jata hai. 

let result = 10n / 3n;

console.log(result);

Output:

3n

Result 3.333... nahi hoga. BigInt division me fractional part discard ho jata hai.

Number vs BigInt

Number BigInt
Normal numeric calculations ke liye. Bahut bade exact integers ke liye.
100 100n
Decimal values support karta hai. Decimal values directly support nahi karta.
typeof → number typeof → bigint

Number Aur BigInt Ko Direct Mix Nahi Kar Sakte

Arithmetic operation me Number aur BigInt ko directly mix karne par error aata hai. 

let a = 10n;
let b = 5;

console.log(a + b);

Result:

TypeError

Dono values ko same type me convert karna hoga.

Correct Conversion 

let a = 10n;
let b = 5;

let result = a + BigInt(b);

console.log(result);

Output:

15n

BigInt Comparison 

console.log(10n > 5n);

console.log(10n === 10n);

console.log(10n === 10);

Output:

true
true
false

10n ka type BigInt hai aur 10 ka type Number hai, isliye strict comparison false hai.

BigInt Kab Use Kare?

Jab exact integer Number.MAX_SAFE_INTEGER ki safe range se bahar ho, tab BigInt useful hota hai. 

console.log(Number.MAX_SAFE_INTEGER);

let bigNumber =
  90071992547409911234567890n;

console.log(bigNumber);

Output:

9007199254740991
90071992547409911234567890n

Important Points

1. BigInt bahut bade exact integer values ke liye use hota hai.

2. BigInt literal ke end me n lagta hai.

3. typeof 100n ka result bigint hota hai.

4. Number aur BigInt ko arithmetic operation me directly mix nahi kar sakte.

5. BigInt decimal/fractional numbers ke liye nahi hai.

6. BigInt division ka fractional part discard ho jata hai.

7. Normal small numeric calculations ke liye Number hi use karna simple hota hai.
