Number Reference Kya Hai?

JavaScript Number Reference ek quick guide hai jisme important Number methods aur properties ko ek hi jagah par dekha ja sakta hai.

Is reference ki help se aap jaldi check kar sakte ho ki kisi Number method ya property ka use kya hai aur uska syntax kaise likha jata hai.

Number Basic Syntax 

let number = 100;

console.log(number);

Output:

100

Number Methods Reference

Method Use Example
toString() Number ko String me convert karta hai. num.toString()
toFixed() Decimal places fix karta hai. num.toFixed(2)
toPrecision() Total significant digits set karta hai. num.toPrecision(4)
toExponential() Number ko exponential notation me convert karta hai. num.toExponential(2)
valueOf() Primitive Number value return karta hai. num.valueOf()

Number Static Methods

Method Use Example
Number() Value ko Number me convert karta hai. Number("100")
Number.parseInt() String ko integer me parse karta hai. Number.parseInt("100px")
Number.parseFloat() String ko decimal Number me parse karta hai. Number.parseFloat("10.5kg")
Number.isInteger() Integer hai ya nahi check karta hai. Number.isInteger(10)
Number.isNaN() Value NaN hai ya nahi check karta hai. Number.isNaN(NaN)
Number.isFinite() Finite Number check karta hai. Number.isFinite(100)
Number.isSafeInteger() Safe integer range check karta hai. Number.isSafeInteger(100)

Number Properties Reference

Property Use
Number.EPSILON 1 aur next representable floating-point value ke difference ko show karta hai.
Number.MAX_VALUE Largest finite Number value.
Number.MIN_VALUE Zero se greater smallest positive Number value.
Number.MAX_SAFE_INTEGER Largest safely representable integer.
Number.MIN_SAFE_INTEGER Smallest safely representable integer.
Number.POSITIVE_INFINITY Positive Infinity.
Number.NEGATIVE_INFINITY Negative Infinity.
Number.NaN Not a Number value.

Quick Number Example 

let num = 123.456;

console.log(num.toFixed(2));

console.log(num.toString());

console.log(Number.isInteger(num));

console.log(Number.MAX_SAFE_INTEGER);

Output:

123.46
123.456
false
9007199254740991

Number Conversion Difference

Function Input Result
Number() "100" 100
Number() "100px" NaN
parseInt() "100px" 100
parseFloat() "10.5kg" 10.5

Important Points

1. Number instance methods ko number.method() se use karte hain.

2. Static methods ko Number.method() se use karte hain.

3. Number properties ke saath () nahi lagta.

4. Number() complete value ko Number me convert karta hai.

5. parseInt() aur parseFloat() String ke starting numeric part ko parse kar sakte hain.

6. Safe integer limit se bade exact integer ke liye BigInt use karna useful hota hai.
