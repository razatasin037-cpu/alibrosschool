String Methods Kya Hain?

JavaScript me String Methods ka use String data ko modify, check, search aur transform karne ke liye kiya jata hai.

String Methods ki help se hum text ko uppercase ya lowercase kar sakte hain, extra spaces remove kar sakte hain, text ka part nikal sakte hain aur String ko replace bhi kar sakte hain.

JavaScript String Methods List

Niche modern JavaScript ke standard String instance methods diye gaye hain. length ek property hai, method nahi.

isWellFormed() Check karta hai String valid UTF-16 well-formed hai ya nahi.

String Method Syntax

string.methodName();

Pehle String ya String variable, phir dot ., aur uske baad method ka naam likha jata hai.

1. at()

Index se character return karta hai; negative index bhi support karta hai.

let text = "JavaScript";
console.log(text.at(-1));

Output:

t

2. charAt()

Given index ka character return karta hai.

let text = "JavaScript";
console.log(text.charAt(4));

Output:

S

3. charCodeAt()

Given index ke UTF-16 code unit ka number return karta hai.

let text = "ABC";
console.log(text.charCodeAt(0));

Output:

65

4. codePointAt()

Given index ka Unicode code point return karta hai.

let text = "A";
console.log(text.codePointAt(0));

Output:

65

5. concat()

Do ya zyada strings ko join karta hai.

let a = "Hello";
let b = "JavaScript";
console.log(a.concat(" ", b));

Output:

Hello JavaScript

6. endsWith()

Check karta hai String given text par end hoti hai ya nahi.

let text = "Hello JavaScript";
console.log(text.endsWith("JavaScript"));

Output:

true

7. includes()

Check karta hai given text String ke andar present hai ya nahi.

let text = "Hello JavaScript";
console.log(text.includes("Java"));

Output:

true

8. indexOf()

Text ki first position/index return karta hai; na mile to -1.

let text = "Hello JavaScript";
console.log(text.indexOf("Java"));

Output:

6

9. isWellFormed()

Check karta hai String valid UTF-16 well-formed hai ya nahi.

let text = "Hello";
console.log(text.isWellFormed());

Output:

true

10. lastIndexOf()

Given text ki last occurrence ka index return karta hai.

let text = "Hello Hello";
console.log(text.lastIndexOf("Hello"));

Output:

6

11. localeCompare()

Do strings ko locale-aware tarike se compare karta hai.

console.log("apple".localeCompare("banana"));

Output:

Negative number

12. match()

Regular expression ke match ka result return karta hai.

let text = "cat bat rat";
console.log(text.match(/bat/)[0]);

Output:

bat

13. matchAll()

Regular expression ke sab matches ka iterator return karta hai.

let text = "a1 a2 a3";
let result = [...text.matchAll(/a\d/g)];
console.log(result.map(x => x[0]));

Output:

["a1", "a2", "a3"]

14. normalize()

Unicode text ko selected normalization form me normalize karta hai.

let text = "\u00F1";
console.log(text.normalize("NFC"));

Output:

ñ

15. padEnd()

String ke end me characters add karke required length banata hai.

let text = "5";
console.log(text.padEnd(3, "0"));

Output:

500

16. padStart()

String ke start me characters add karke required length banata hai.

let text = "5";
console.log(text.padStart(3, "0"));

Output:

005

17. repeat()

String ko given number of times repeat karta hai.

let text = "Hi ";
console.log(text.repeat(3));

Output:

Hi Hi Hi

18. replace()

First matching text ko replace karta hai.

let text = "Hello JavaScript";
console.log(text.replace("JavaScript", "React"));

Output:

Hello React

19. replaceAll()

Sab matching occurrences ko replace karta hai.

let text = "Hi Hi Hi";
console.log(text.replaceAll("Hi", "Hello"));

Output:

Hello Hello Hello

20. search()

Regex ya pattern ka first matching index return karta hai.

let text = "Hello JavaScript";
console.log(text.search(/Java/));

Output:

6

21. slice()

Start aur end index ke beech ka String part return karta hai.

let text = "JavaScript";
console.log(text.slice(0, 4));

Output:

Java

22. split()

String ko separator ke basis par Array me todta hai.

let text = "HTML,CSS,JS";
console.log(text.split(","));

Output:

["HTML", "CSS", "JS"]

23. startsWith()

Check karta hai String given text se start hoti hai ya nahi.

let text = "Hello JavaScript";
console.log(text.startsWith("Hello"));

Output:

true

24. substring()

Do indexes ke beech ka String part return karta hai.

let text = "JavaScript";
console.log(text.substring(4, 10));

Output:

Script

25. toLocaleLowerCase()

Locale rules ke according lowercase me convert karta hai.

let text = "HELLO";
console.log(text.toLocaleLowerCase());

Output:

hello

26. toLocaleUpperCase()

Locale rules ke according uppercase me convert karta hai.

let text = "hello";
console.log(text.toLocaleUpperCase());

Output:

HELLO

27. toLowerCase()

String ko lowercase me convert karta hai.

let text = "JavaScript";
console.log(text.toLowerCase());

Output:

javascript

28. toString()

String value/object ko String representation me return karta hai.

let text = new String("Hello");
console.log(text.toString());

Output:

Hello

29. toUpperCase()

String ko uppercase me convert karta hai.

let text = "JavaScript";
console.log(text.toUpperCase());

Output:

JAVASCRIPT

30. toWellFormed()

Invalid lone UTF-16 surrogates ko replacement character se replace karta hai.

let text = "Hello";
console.log(text.toWellFormed());

Output:

Hello

31. trim()

Start aur end ke whitespace ko remove karta hai.

let text = "   Hello   ";
console.log(text.trim());

Output:

Hello

32. trimEnd()

String ke end ka whitespace remove karta hai.

let text = "Hello   ";
console.log(text.trimEnd());

Output:

Hello

33. trimStart()

String ke start ka whitespace remove karta hai.

let text = "   Hello";
console.log(text.trimStart());

Output:

Hello

34. valueOf()

String object ki primitive String value return karta hai.

let text = new String("Hello");
console.log(text.valueOf());

Output:

Hello

Static String Methods

Ye methods kisi String variable par nahi, directly String object par call hote hain.

String.fromCharCode()

UTF-16 code units se String banata hai.

console.log(String.fromCharCode(72, 105));

Output:

Hi

String.fromCodePoint()

Unicode code points se String banata hai.

console.log(String.fromCodePoint(9731));

Output:

☃

String.raw()

Template literal ke raw characters return karta hai.

console.log(String.raw`Hello\nJS`);

Output:

Hello\nJS

Important Points

1. JavaScript Strings immutable hoti hain; methods normally new String/value return karte hain.

2. length property hai, method nahi.

3. Search/check ke important methods: includes(), indexOf(), lastIndexOf(), startsWith(), endsWith(), search(), match(), matchAll().

4. Text change ke methods: replace(), replaceAll(), trim(), padStart(), padEnd(), repeat().

5. Purane deprecated HTML wrapper String methods ko new projects me avoid karna chahiye.
