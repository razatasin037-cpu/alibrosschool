String Kya Hai?

JavaScript me String ka use text ko store karne ke liye kiya jata hai. String ke andar letters, words, sentences, numbers aur special characters bhi ho sakte hain.

String value ko hum single quotes ' ', double quotes " " ya backticks ` ` ke andar likh sakte hain.

String Syntax 

let variableName = "String Value";

String value ko quotes ke andar likha jata hai. Quotes ke andar likha hua data JavaScript me text maana jata hai.

String Example

Is example me hum ek student ka name String ke andar store karke console me print karenge. 

let name = "Rahul";

console.log(name);

Output: 

Rahul

Example Kaise Kaam Kar Raha Hai?

let → JavaScript me variable create karne ke liye use kiya gaya hai.

name → Ye variable ka naam hai.

"Rahul" → Ye String value hai kyunki ye quotes ke andar likhi gayi hai.

console.log(name) → Variable ke andar stored String ko console me print karta hai.

String Quotes

JavaScript me String banane ke liye three types ke quotes use kar sakte hain.

Type Example
Double Quotes "Hello JavaScript"
Single Quotes 'Hello JavaScript'
Backticks `Hello JavaScript`

String Length

String me kitne characters hain, ye check karne ke liye length property ka use hota hai. 

let text = "Hello";

console.log(text.length);

Output: 

5

"Hello" me 5 characters hain: H, e, l, l, o. Isliye output 5 aata hai.

String Index

String ke har character ka ek index number hota hai. JavaScript me index 0 se start hota hai.

Character H e l l o
Index 0 1 2 3 4 
let text = "Hello";

console.log(text[0]);

Output: 

H

Check String Data Type

typeof operator ka use variable ka data type check karne ke liye kiya jata hai. 

let name = "Rahul";

console.log(typeof name);

Output: 

string

Important Points

1. String ka use text data ko store karne ke liye hota hai.

2. String ko single quotes, double quotes ya backticks me likh sakte hain.

3. length se String ke total characters pata kar sakte hain.

4. String ka index 0 se start hota hai.

5. typeof se String ka data type check kar sakte hain.
