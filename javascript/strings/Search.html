String Search Kya Hai?

JavaScript me String Search Methods ka use kisi String ke andar text, word ya pattern ko find karne ke liye kiya jata hai.

In methods ki help se hum check kar sakte hain ki koi word String me present hai ya nahi, uska index kya hai, String kis text se start ya end ho rahi hai, aur regular expression se pattern bhi search kar sakte hain.

String Search Methods

Method Use
indexOf() First matching text ka index return karta hai.
lastIndexOf() Last matching text ka index return karta hai.
includes() Text present hai ya nahi check karta hai.
startsWith() String given text se start hoti hai ya nahi.
endsWith() String given text par end hoti hai ya nahi.
search() Pattern ka first matching index return karta hai.
match() Pattern ke matching result return karta hai.
matchAll() Pattern ke sab matches return karta hai.

indexOf()

indexOf() kisi text ki first position return karta hai. Text na mile to -1 return karta hai.

Syntax 

string.indexOf(searchValue);

Example 

let text = "Hello JavaScript";

console.log(text.indexOf("Java"));

Output:

6

lastIndexOf()

lastIndexOf() matching text ki last occurrence ka index return karta hai. 

let text = "Hello JS, Hello JS";

console.log(text.lastIndexOf("JS"));

Output:

16

includes()

includes() check karta hai ki given text String ke andar present hai ya nahi. Ye true ya false return karta hai. 

let text = "Hello JavaScript";

console.log(text.includes("JavaScript"));

Output:

true

startsWith()

startsWith() check karta hai ki String given text se start hoti hai ya nahi. 

let text = "Hello JavaScript";

console.log(text.startsWith("Hello"));

Output:

true

endsWith()

endsWith() check karta hai ki String given text par end hoti hai ya nahi. 

let text = "Hello JavaScript";

console.log(text.endsWith("JavaScript"));

Output:

true

search()

search() String me pattern ko search karta hai aur first match ka index return karta hai. 

let text = "Hello JavaScript";

console.log(text.search(/Java/));

Output:

6

match()

match() regular expression ke according matching result return karta hai. 

let text = "HTML CSS JavaScript";

let result = text.match(/JavaScript/);

console.log(result[0]);

Output:

JavaScript

matchAll()

matchAll() global regular expression ke sab matches return karta hai. 

let text = "JS1 JS2 JS3";

let result = [...text.matchAll(/JS\d/g)];

console.log(result.map(item => item[0]));

Output:

["JS1", "JS2", "JS3"]

Search Methods Difference

Method Return
indexOf() Index number ya -1
lastIndexOf() Last matching index ya -1
includes() true / false
startsWith() true / false
endsWith() true / false
search() First match ka index ya -1
match() Matching result / array / null
matchAll() All matches ka iterator

Important Points

1. indexOf() first matching position return karta hai.

2. lastIndexOf() last matching position return karta hai.

3. includes(), startsWith() aur endsWith() Boolean result return karte hain.

4. search() Regular Expression ke saath pattern search kar sakta hai.

5. match() matching data return karta hai.

6. matchAll() multiple matches ke liye useful hai.

7. String search generally case-sensitive hoti hai.
