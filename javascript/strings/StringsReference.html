String Reference Kya Hai?

JavaScript String Reference ek quick guide hai jisme important String properties aur methods ko ek jagah par dekha ja sakta hai.

Is reference ki help se aap quickly check kar sakte ho ki kisi String method ka naam kya hai, uska use kya hai aur uska basic syntax kaise likha jata hai.

String Basic Syntax 

let text = "Hello JavaScript";

console.log(text);

Output:

Hello JavaScript

String Property

Property Use Example
length String ke total characters return karta hai. text.length

Character Methods

Method Use Syntax
at() Index ka character return karta hai. text.at(0)
charAt() Given index ka character return karta hai. text.charAt(0)
charCodeAt() Character ka UTF-16 code return karta hai. text.charCodeAt(0)
codePointAt() Character ka Unicode code point deta hai. text.codePointAt(0)

Extract String Methods

Method Use Syntax
slice() String ka selected part return karta hai. text.slice(0, 5)
substring() Do indexes ke beech ka text return karta hai. text.substring(0, 5)

Uppercase & Lowercase Methods

Method Use Syntax
toUpperCase() String ko uppercase me convert karta hai. text.toUpperCase()
toLowerCase() String ko lowercase me convert karta hai. text.toLowerCase()
toLocaleUpperCase() Locale rules ke according uppercase karta hai. text.toLocaleUpperCase()
toLocaleLowerCase() Locale rules ke according lowercase karta hai. text.toLocaleLowerCase()

String Search Methods

Method Use Syntax
indexOf() First matching text ka index deta hai. text.indexOf("JS")
lastIndexOf() Last matching text ka index deta hai. text.lastIndexOf("JS")
includes() Text present hai ya nahi check karta hai. text.includes("Java")
startsWith() Starting text check karta hai. text.startsWith("Hello")
endsWith() Ending text check karta hai. text.endsWith("Script")
search() Pattern ka matching index find karta hai. text.search(/Java/)
match() Pattern ke matches find karta hai. text.match(/Java/)
matchAll() Pattern ke sabhi matches return karta hai. text.matchAll(/JS/g)

Modify & Format Methods

Method Use Syntax
replace() Matching text ko replace karta hai. text.replace("JS", "React")
replaceAll() Sab matching text replace karta hai. text.replaceAll("JS", "React")
trim() Start aur end ke spaces remove karta hai. text.trim()
trimStart() Starting spaces remove karta hai. text.trimStart()
trimEnd() Ending spaces remove karta hai. text.trimEnd()
padStart() Start me characters add karta hai. text.padStart(5, "0")
padEnd() End me characters add karta hai. text.padEnd(5, "0")
repeat() String ko multiple times repeat karta hai. text.repeat(3)

Join & Split Methods

Method Use Syntax
concat() Multiple Strings ko join karta hai. text.concat(text2)
split() String ko Array me convert karta hai. text.split(",")

Other String Methods

Method Use
localeCompare() Do Strings ko compare karta hai.
normalize() Unicode String normalize karta hai.
toString() String representation return karta hai.
valueOf() Primitive String value return karta hai.
isWellFormed() Valid UTF-16 String check karta hai.
toWellFormed() String ko well-formed UTF-16 banata hai.

Static String Methods

Method Use Example
String.fromCharCode() UTF-16 codes se String banata hai. String.fromCharCode(65)
String.fromCodePoint() Unicode code point se String banata hai. String.fromCodePoint(9731)
String.raw() Raw template String return karta hai. String.raw`Hello\nJS`

Quick Reference Example 

let text = "Hello JavaScript";

console.log(text.length);
console.log(text.toUpperCase());
console.log(text.includes("Java"));
console.log(text.slice(0, 5));

Output: 

16
HELLO JAVASCRIPT
true
Hello

Important Points

1. length ek property hai, method nahi.

2. String methods ko generally string.method() syntax se use karte hain.

3. JavaScript Strings immutable hoti hain, yani String methods normally original String ko change nahi karte.

4. includes(), startsWith() aur endsWith() boolean value true/false return karte hain.

5. indexOf() aur lastIndexOf() text na milne par -1 return karte hain.
