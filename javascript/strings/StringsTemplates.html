String Template Kya Hai?

JavaScript me String Template ko Template Literal bhi kaha jata hai. Iska use strings ko easy aur readable tarike se likhne ke liye hota hai.

String Template me normal single ya double quotes ki jagah backticks ` ` ka use hota hai. Iske andar variables aur expressions ko directly add karne ke liye ${ } syntax use hota hai.

Template Literal Syntax 

let text = `Your text here`;

Template Literal ko backticks ke andar likha jata hai.

Template Literal Example

Is example me variable ko String ke andar directly use karenge. 

let name = "Rahul";

let message = `Hello ${name}`;

console.log(message);

Output: 

Hello Rahul

Example Kaise Kaam Kar Raha Hai?

let name = "Rahul" → Name variable ke andar Rahul store kiya gaya hai.

`Hello ${name}` → Backticks ke andar String likhi gayi hai.

${name} → Variable ki value String ke andar insert karta hai.

Isliye final result Hello Rahul milta hai.

Normal String vs Template Literal

Normal String Template Literal
Single ya double quotes use hote hain. Backticks use hote hain.
"Hello " + name `Hello ${name}`
Variables add karne ke liye + use karna padta hai. Variable directly ${ } ke andar use hota hai.

Expression in Template Literal

Template Literal me sirf variable hi nahi, calculation bhi directly kar sakte hain. 

let a = 10;
let b = 20;

let result = `Total = ${a + b}`;

console.log(result);

Output: 

Total = 30

Multiline String

Backticks ka use karke String ko multiple lines me bhi easily likh sakte hain. 

let text = `Hello
Welcome to
JavaScript`;

console.log(text);

Output: 

Hello
Welcome to
JavaScript

Important Points

1. Template Literal me backticks ` ` use hote hain.

2. Variable ko String me insert karne ke liye ${variable} use hota hai.

3. ${ } ke andar calculations aur expressions bhi use kar sakte hain.

4. Template Literals multiline strings ko easy banate hain.

5. Template Literals normal String concatenation se zyada readable hote hain.
