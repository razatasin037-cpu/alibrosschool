Math Methods Kya Hain?

JavaScript Math object me bahut saare built-in methods hote hain jo mathematical calculations ko easy banate hain.

Jaise rounding, power, square root, minimum, maximum aur random numbers.

Important Math Methods

Method Use
Math.round() Nearest integer deta hai.
Math.floor() Neeche wale integer ki taraf round karta hai.
Math.ceil() Upar wale integer ki taraf round karta hai.
Math.trunc() Decimal part hata deta hai.
Math.abs() Absolute value deta hai.
Math.sign() Number ka sign batata hai.
Math.pow() Power calculate karta hai.
Math.sqrt() Square root deta hai.
Math.cbrt() Cube root deta hai.
Math.min() Smallest value deta hai.
Math.max() Largest value deta hai.
Math.random() Random decimal number deta hai.

Math.round()

Number ko nearest integer par round karta hai. 

console.log(Math.round(4.7));
console.log(Math.round(4.3));
5
4

Math.floor() 

console.log(
  Math.floor(5.9)
);
5

Math.ceil() 

console.log(
  Math.ceil(5.1)
);
6

Math.trunc() 

console.log(
  Math.trunc(7.98)
);
7

Math.abs()

Negative ya positive number ki non-negative absolute value return karta hai. 

console.log(
  Math.abs(-50)
);
50

Math.sign() 

console.log(Math.sign(20));
console.log(Math.sign(-20));
console.log(Math.sign(0));
1
-1
0

Math.sqrt() 

console.log(
  Math.sqrt(81)
);
9

Math.cbrt()

Number ka cube root return karta hai. 

console.log(
  Math.cbrt(27)
);
3

Math.pow() 

console.log(
  Math.pow(
    5,
    2
  )
);

Output:

25

Math.min() 

console.log(
  Math.min(
    20,
    5,
    50,
    2
  )

Math.max() 

console.log(
  Math.max(
    20,
    5,

  )

Math.min() / max() With Array 

const numbers = [
  10,
  40,
  5,
  80
];

console.log(
  Math.min(...numbers)
);

console.log(
  Math.max(...numbers)
);
5
80

Math.random()

Math.random() 0 inclusive aur 1 exclusive ke beech pseudo-random decimal number deta hai. 

console.log(
  Math.random()
);

Example:

0.728471...

Random Integer 1 Se 10 

const randomNumber =
  Math.floor(
    Math.random() * 10
  ) + 1;

console.log(randomNumber);
Possible result: 1 to 10

Math.hypot()

Given numbers ke squares ke sum ka square root return karta hai. 

console.log(
  Math.hypot(
    3,
    4
  )
);
5

Math.log()

Number ka natural logarithm return karta hai. 

console.log(
  Math.log(1)
);
0

Math.log10() 

console.log(
  Math.log10(100)
);
2

Rounding Methods Difference

Method Example Output
round() 4.6 5
floor() 4.9 4
ceil() 4.1 5
trunc() 4.9 4

Important Points

1. Math.round() nearest integer deta hai.

2. Math.floor() neeche ki taraf round karta hai.

3. Math.ceil() upar ki taraf round karta hai.

4. Math.trunc() decimal part remove karta hai.

5. Math.sqrt() square root aur Math.cbrt() cube root deta hai.

6. Math.min() aur Math.max() minimum aur maximum value dete hain.

7. Math.random() random decimal value generate karta hai.

8. Array ke min/max ke liye spread operator ... use kar sakte hain.
