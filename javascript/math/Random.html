Math.random() Kya Hai?

JavaScript me Math.random() ka use random number generate karne ke liye hota hai.

Ye 0 inclusive se 1 exclusive ke beech decimal number return karta hai.

Syntax 

Math.random();

Simple Random Number 

console.log(
  Math.random()
);

Example Output:

0.64372891

Random Integer 0 Se 9 

const number =
  Math.floor(
    Math.random() * 10
  );

console.log(number);

Possible Output:

0 se 9

Random Integer 1 Se 10 

const number =
  Math.floor(
    Math.random() * 10
  ) + 1;

console.log(number);

Possible Output:

1 se 10

Random Integer 1 Se 100 

const number =
  Math.floor(
    Math.random() * 100
  ) + 1;

console.log(number);

Random Number Between Min And Max

Kisi specific range ke andar random integer generate karne ke liye ye formula useful hai. 

Math.floor(
  Math.random() * (max - min + 1)
) + min;

Random Number 50 Se 100 

const min = 50;
const max = 100;

const number =
  Math.floor(
    Math.random() *
    (max - min + 1)
  ) + min;

console.log(number);

Random Number Function 

function randomNumber(min, max) {

  return Math.floor(
    Math.random() *
    (max - min + 1)
  ) + min;

}

console.log(
  randomNumber(1, 100)
);

Random Array Item

Array ke andar se random element select kar sakte hain. 

const fruits = [
  "Apple",
  "Mango",
  "Banana",
  "Orange"
];

const index =
  Math.floor(
    Math.random() * fruits.length
  );

console.log(
  fruits[index]
);

Possible Output:

Mango

Dice Example

Dice ke liye 1 se 6 ke beech random number chahiye. 

const dice =
  Math.floor(
    Math.random() * 6
  ) + 1;

console.log(dice);
1 se 6

Random True / False 

const result =
  Math.random() < 0.5;

console.log(result);

Possible Output:

true
or
false

6 Digit Random Number 

const randomCode =
  Math.floor(
    100000 +
    Math.random() * 900000
  );

console.log(randomCode);

Example Output:

538214

Important Note About Math.random()

Math.random() normal UI effects, games, testing aur random selections ke liye useful hai. Security-sensitive values ke liye secure random APIs use karna better hota hai.

Important Points

1. Math.random() 0 inclusive se 1 exclusive tak decimal deta hai.

2. Math.floor() ke saath random integers generate kar sakte hain.

3. 1 se 10 ke liye Math.floor(Math.random() * 10) + 1 use karte hain.

4. Custom range ke liye min aur max formula use kar sakte hain.

5. Array se random item select karne ke liye random index generate karte hain.

6. Dice, random colors, games aur demo data me Math.random() useful hai.
