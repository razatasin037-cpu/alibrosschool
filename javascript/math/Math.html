JavaScript Math Kya Hai?

JavaScript me Math ek built-in object hai jiska use mathematical calculations ke liye kiya jata hai.

Iski help se rounding, square root, power, minimum, maximum aur random numbers jaise operations kar sakte hain.

Math Object Kaise Use Hota Hai?

Math ko use karne ke liye new Math() nahi likhte. 

// Correct
Math.round(4.6);

// Wrong
new Math();

Common Math Methods

Method Use
Math.round() Nearest integer return karta hai.
Math.floor() Neeche wale integer par round karta hai.
Math.ceil() Upar wale integer par round karta hai.
Math.trunc() Decimal part remove karta hai.
Math.sqrt() Square root return karta hai.
Math.pow() Power calculate karta hai.
Math.min() Smallest value deta hai.
Math.max() Largest value deta hai.
Math.random() Random number generate karta hai.

Math.round()

Decimal number ko nearest integer me round karta hai. 

console.log(
  Math.round(4.6)
);

console.log(
  Math.round(4.4)
);
5
4

Math.floor()

Number ko nearest lower integer ki taraf round karta hai. 

console.log(
  Math.floor(4.9)
);
4

Math.ceil()

Number ko nearest upper integer ki taraf round karta hai. 

console.log(
  Math.ceil(4.1)
);
5

Math.trunc()

Decimal portion ko remove karke integer part return karta hai. 

console.log(
  Math.trunc(8.75)
);
8

Math.sqrt()

Number ka square root return karta hai. 

console.log(
  Math.sqrt(64)
);
8

Math.pow()

Number ki power calculate karta hai. 

console.log(
  Math.pow(
    2,
    3
  )
);

Meaning:

2 × 2 × 2 = 8

Math.min() 

console.log(
  Math.min(
    10,
    5,
    30,
    2
  )
);
2

Math.max() 

console.log(
  Math.max(
    10,
    5,
    30,
    2
  )
);
30

Array Se Min Aur Max

Array ke numbers ke saath spread operator ... use kar sakte hain. 

const numbers = [
  10,
  50,
  20,
  80
];

console.log(
  Math.min(...numbers)
);

console.log(
  Math.max(...numbers)
);
10
80

Math.random()

Math.random() 0 inclusive se 1 exclusive ke beech random decimal number return karta hai. 

console.log(
  Math.random()
);

Example Output:

0.5837291

Random Integer 0 Se 9 

const number =
  Math.floor(
    Math.random() * 10
  );

console.log(number);

Possible Output:

0 to 9

Random Integer 1 Se 10 

const number =
  Math.floor(
    Math.random() * 10
  ) + 1;

console.log(number);

Possible Output:

1 to 10

Math.abs()

Negative number ka positive absolute value return karta hai. 

console.log(
  Math.abs(-25)
);
25

Math.sign()

Number positive, negative ya zero hai ye identify karne me help karta hai. 

console.log(Math.sign(10));
console.log(Math.sign(-10));
console.log(Math.sign(0));
1
-1
0

Math Properties

Math object me kuch useful constant properties bhi available hain. 

console.log(Math.PI);
console.log(Math.E);
3.141592653589793
2.718281828459045

round() vs floor() vs ceil() vs trunc()

Method Math Value Result
round() 4.6 5
floor() 4.9 4
ceil() 4.1 5
trunc() 4.9 4

Important Points

1. Math JavaScript ka built-in object hai.

2. new Math() use nahi karte.

3. Math.round() nearest integer deta hai.

4. Math.floor() lower integer aur Math.ceil() upper integer deta hai.

5. Math.sqrt() square root calculate karta hai.

6. Math.min() aur Math.max() minimum aur maximum values dete hain.

7. Math.random() random decimal value deta hai.

8. Math.PI aur Math.E Math properties hain.
