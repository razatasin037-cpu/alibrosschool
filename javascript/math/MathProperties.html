Math Properties Kya Hain?

JavaScript Math object me kuch built-in mathematical constants available hote hain.

Inhe Math Properties kehte hain, jaise Math.PI, Math.E aur Math.SQRT2.

Important Math Properties

Property Value Meaning
Math.PI 3.141592653589793 Pi value
Math.E 2.718281828459045 Euler's number
Math.SQRT2 1.4142135623730951 Square root of 2
Math.SQRT1_2 0.7071067811865476 Square root of 1/2
Math.LN2 0.6931471805599453 Natural log of 2
Math.LN10 2.302585092994046 Natural log of 10
Math.LOG2E 1.4426950408889634 Base-2 logarithm of E
Math.LOG10E 0.4342944819032518 Base-10 logarithm of E

Math.PI

Math.PI Pi ki value return karta hai. 

console.log(
  Math.PI
);

Output:

3.141592653589793

Circle Area With Math.PI

Circle area formula: π × r² 

const radius =
  5;

const area =
  Math.PI * radius * radius;

console.log(area);

Output:

78.53981633974483

Math Property vs Math Method

Property Method
Fixed mathematical value hoti hai. Calculation perform karta hai.
Math.PI Math.round(4.5)
Parentheses nahi lagte. Parentheses () lagte hain.

Common Mistake

Math Property ko method ki tarah call mat karo. 

// Correct
console.log(Math.PI);

// Wrong
console.log(Math.PI());

Important Points

1. Math.PI Pi ki value deta hai.

2. Math.E Euler's number deta hai.

3. Math.SQRT2 square root of 2 deta hai.

4. Math.SQRT1_2 square root of 1/2 deta hai.

5. Math.LN2 aur Math.LN10 natural logarithm constants hain.

6. Math.LOG2E aur Math.LOG10E logarithm constants hain.

7. Math properties fixed values hoti hain, isliye unke saath () nahi lagaya jata.
