Set Methods Kya Hain?

JavaScript Set Methods ka use Set ke andar values ko add, check, remove, clear aur iterate karne ke liye hota hai.

Important methods hain add(), has(), delete(), clear(), values() aur forEach().

Set Methods List

Method / Property Use
add() Set me new value add karta hai.
has() Value available hai ya nahi check karta hai.
delete() Specific value remove karta hai.
clear() Set ki sabhi values remove karta hai.
values() Set values ka iterator return karta hai.
keys() Set values ka iterator return karta hai.
entries() [value, value] pairs return karta hai.
forEach() Har Set value par callback run karta hai.
size Total values ki count deta hai.

add()

add() Set me new value add karta hai. 

const fruits = new Set();

fruits.add("Apple");
fruits.add("Mango");

console.log(fruits);

Output:

Set(2) {"Apple", "Mango"}

add() Method Chaining

add() Set object ko return karta hai, isliye chaining bhi kar sakte hain. 

const fruits = new Set();

fruits
  .add("Apple")
  .add("Mango")
  .add("Banana");

console.log(fruits);
Set(3) {"Apple", "Mango", "Banana"}

has()

has() Set me value exist karti hai ya nahi check karta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango"
  ]);

console.log(
  fruits.has("Apple")
);

console.log(
  fruits.has("Banana")
);

Output:

true
false

delete()

delete() Set se given value remove karta hai aur boolean return karta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango"
  ]);

const result =
  fruits.delete(
    "Mango"
  );

console.log(result);
console.log(fruits);

Output:

true
Set(1) {"Apple"}

clear()

clear() Set ki saari values remove kar deta hai. 

const numbers =
  new Set([
    10,
    20,
    30
  ]);

numbers.clear();

console.log(numbers);
console.log(numbers.size);

Output:

Set(0) {}
0

size Property

size method nahi, property hai. Ye Set ke total unique values ki count deta hai. 

const numbers =
  new Set([
    10,
    20,
    30
  ]);

console.log(numbers.size);

Output:

3

values()

values() Set ki values ka iterator return karta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango",
    "Banana"
  ]);

for (
  const fruit
  of
  fruits.values()
) {
  console.log(fruit);
}

Output:

Apple
Mango
Banana

keys()

Set me separate keys nahi hoti. Isliye keys() bhi values ka iterator return karta hai. 

const numbers =
  new Set([
    10,
    20
  ]);

for (
  const value
  of
  numbers.keys()
) {
  console.log(value);
}
10
20

entries()

entries() har value ko [value, value] pair ke form me return karta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango"
  ]);

for (
  const item
  of
  fruits.entries()
) {
  console.log(item);
}

Output:

["Apple", "Apple"]
["Mango", "Mango"]

forEach()

forEach() Set ke har value ke liye callback function execute karta hai. 

const numbers =
  new Set([
    10,
    20,
    30
  ]);

numbers.forEach((value) => {
  console.log(value);
});

Output:

10
20
30

Set Ko Array Me Convert Karna 

const numbers =
  new Set([
    10,
    20,
    30
  ]);

const array = [
  ...numbers
];

console.log(array);
[10, 20, 30]

Important Points

1. add() Set me value add karta hai.

2. has() true ya false return karta hai.

3. delete() specific value remove karta hai.

4. clear() poora Set empty kar deta hai.

5. size property total unique values ki count deti hai.

6. values() aur keys() Set values iterate karne ke liye use kiye ja sakte hain.

7. entries() [value, value] pairs deta hai.

8. forEach() har Set value par callback run karta hai.
