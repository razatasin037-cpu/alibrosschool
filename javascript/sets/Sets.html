Set Kya Hai?

JavaScript me Set ek collection hai jo sirf unique values store karta hai.

Agar same value ko multiple baar add karoge, Set duplicate value ko store nahi karega.

Set Syntax 

const mySet =
  new Set();

Simple Set Example 

const fruits =
  new Set([
    "Apple",
    "Mango",
    "Banana"
  ]);

console.log(fruits);

Example Output:

Set(3) {"Apple", "Mango", "Banana"}

Set Duplicate Values Remove Karta Hai 

const numbers =
  new Set([
    10,
    20,
    10,
    30,
    20
  ]);

console.log(numbers);

Output:

Set(3) {10, 20, 30}

add()

add() Set me new value add karta hai. 

const fruits =
  new Set();

fruits.add("Apple");
fruits.add("Mango");
fruits.add("Banana");

console.log(fruits);

Output:

Set(3) {"Apple", "Mango", "Banana"}

Duplicate Value Add Karna 

const fruits =
  new Set();

fruits.add("Apple");
fruits.add("Apple");
fruits.add("Mango");

console.log(fruits);

Output:

Set(2) {"Apple", "Mango"}

size Property

size Set ke total unique elements ki count deta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango",
    "Banana"
  ]);

console.log(fruits.size);

Output:

3

has()

has() check karta hai ki given value Set me exist karti hai ya nahi. 

const fruits =
  new Set([
    "Apple",
    "Mango"
  ]);

console.log(
  fruits.has("Apple")
);

console.log(
  fruits.has("Banana")
);

Output:

true
false

delete() 

const fruits =
  new Set([
    "Apple",
    "Mango",
    "Banana"
  ]);

fruits.delete(
  "Mango"
);

console.log(fruits);

Output:

Set(2) {"Apple", "Banana"}

clear()

clear() Set ke sabhi elements remove karta hai. 

const fruits =
  new Set([
    "Apple",
    "Mango"
  ]);

fruits.clear();

console.log(fruits.size);

Output:

0

Array Se Set Banana 

const numbers = [
  1,
  2,
  2,
  3,
  3
];

const uniqueNumbers =
  new Set(numbers);

console.log(uniqueNumbers);

Output:

Set(3) {1, 2, 3}

Array Se Duplicate Values Remove Karna

Set ko spread operator ke saath use karke duplicate-free Array bana sakte hain. 

const numbers = [
  1,
  2,
  2,
  3,
  3
];

const unique = [
  ...new Set(numbers)
];

console.log(unique);

Output:

[1, 2, 3]

Loop Through Set

for...of loop se Set ke values par loop chala sakte hain. 

const fruits =
  new Set([
    "Apple",
    "Mango",
    "Banana"
  ]);

for (const fruit of fruits) {
  console.log(fruit);
}

Output:

Apple
Mango
Banana

Set forEach() 

const numbers =
  new Set([
    10,
    20,
    30
  ]);

numbers.forEach((number) => {
  console.log(number);
});

Output:

10
20
30

Array vs Set

Array Set
Duplicate values allowed hain. Duplicate values store nahi hoti.
Index se access kar sakte hain. Normal numeric index access available nahi hota.
array.length set.size
push() add()

Important Points

1. new Set() se Set create hota hai.

2. Set sirf unique values store karta hai.

3. add() new value add karta hai.

4. has() value exist karti hai ya nahi check karta hai.

5. delete() ek particular value remove karta hai.

6. clear() sabhi values remove karta hai.

7. size total unique values ki count deta hai.

8. Arrays se duplicate values remove karne ke liye Set bahut useful hai.
