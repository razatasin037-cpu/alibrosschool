Screen Object Kya Hai?

JavaScript me screen object user ke display screen ke baare me information provide karta hai.

Isse screen width, height, available size, color depth aur pixel depth jaise values mil sakti hain.

screen Object Access Karna 

console.log(
  screen
);

screen.width

User ki screen ki total width pixels me deta hai. 

console.log(
  screen.width
);

screen.height

Screen ki total height pixels me return karta hai. 

console.log(
  screen.height
);

Screen Size Check Karna 

const width =
  screen.width;

const height =
  screen.height;

console.log(
  "Width:",
  width
);

console.log(
  "Height:",
  height
);

screen.availWidth

Screen ki available width deta hai. Operating system ke reserved UI areas ki wajah se ye total width se different ho sakti hai. 

console.log(
  screen.availWidth
);

screen.availHeight 

console.log(
  screen.availHeight
);

Total Size vs Available Size

Property Meaning
screen.width Total screen width
screen.height Total screen height
screen.availWidth Available screen width
screen.availHeight Available screen height

screen.colorDepth

Color depth ki information bits per pixel me provide karta hai. 

console.log(
  screen.colorDepth
);

screen.pixelDepth

Screen ki pixel color depth ki information deta hai. 

console.log(
  screen.pixelDepth
);

screen.orientation

Supported browsers me screen orientation information access ki ja sakti hai. 

console.log(
  screen.orientation
);

Orientation Type 

if (
  screen.orientation
) {

  console.log(
    screen.orientation.type
  );

}

Possible values browser/device ke according portrait ya landscape orientation indicate kar sakti hain.

Orientation Angle 

if (
  screen.orientation
) {

  console.log(
    screen.orientation.angle
  );

}

screen.width vs window.innerWidth

Dono alag information dete hain.

screen.width window.innerWidth
Physical/logical display screen width. Browser viewport width.
Browser resize karne par normally same reh sakta hai. Browser viewport resize hone par change hota hai.

Screen Aur Window Compare Karna 

console.log(
  "Screen Width:",
  screen.width
);

console.log(
  "Viewport Width:",
  window.innerWidth
);

Screen Width Ke According Condition 

if (
  screen.width <=
  768
) {

  console.log(
    "Small Screen"
  );

} else {

  console.log(
    "Large Screen"
  );

}

Responsive layout ke liye CSS media queries usually better choice hote hain. JavaScript check tab useful hai jab behavior change karna ho.

Better Responsive Check: matchMedia() 

const mobile =
  window.matchMedia(
    "(max-width: 768px)"
  );

if (mobile.matches) {

  console.log(
    "Mobile Layout"
  );

}

Media Query Change Detect Karna 

const media =
  window.matchMedia(
    "(max-width: 768px)"
  );

media.addEventListener(
  "change",
  (event) => {

    if (
      event.matches
    ) {

      console.log(
        "Now Small Screen"
      );

    } else {

      console.log(
        "Now Large Screen"
      );

    }

  }
);

Screen Quick Reference

Property Use
screen.width Total screen width
screen.height Total screen height
screen.availWidth Available width
screen.availHeight Available height
screen.colorDepth Color depth
screen.pixelDepth Pixel depth
screen.orientation Screen orientation info

Important Points

1. screen display information provide karta hai.

2. screen.width aur screen.height total screen dimensions dete hain.

3. availWidth aur availHeight available screen area ki information dete hain.

4. colorDepth aur pixelDepth display color information dete hain.

5. screen.width aur window.innerWidth same cheez nahi hain.

6. Responsive CSS ke liye media queries use karna better hai.

7. JavaScript responsive behavior ke liye matchMedia() useful hai.
