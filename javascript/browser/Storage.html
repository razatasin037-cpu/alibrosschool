Browser Storage Kya Hai?

JavaScript me browser ke andar small amounts of data store karne ke liye Web Storage API use ki ja sakti hai.

Iske do main types hain: localStorage aur sessionStorage.

Browser Storage Types

Storage Meaning
localStorage Data browser me tab/session close hone ke baad bhi normally save rehta hai.
sessionStorage Data current tab session ke liye store hota hai.

localStorage

localStorage key-value format me data store karta hai. Stored values strings ke form me hoti hain.

localStorage.setItem()

Data save karne ke liye: 

localStorage.setItem(
  "name",
  "Ali"
);

localStorage.getItem()

Stored value read karne ke liye: 

const name =
  localStorage.getItem(
    "name"
  );

console.log(name);
Ali

localStorage.removeItem()

Specific key remove karne ke liye: 

localStorage.removeItem(
  "name"
);

localStorage.clear()

Current origin ka localStorage data clear karne ke liye: 

localStorage.clear();

localStorage.key()

Given index par key name access kar sakte hain. 

const keyName =
  localStorage.key(
    0
  );

console.log(
  keyName
);

localStorage.length 

console.log(
  localStorage.length
);

Stored keys ki count return karta hai.

Storage Values Strings Hoti Hain 

localStorage.setItem(
  "age",
  20
);

const age =
  localStorage.getItem(
    "age"
  );

console.log(
  typeof age
);
string

Object Directly Store Nahi Karna 

const user = {
  name:
    "Ali",
  age:
    20
};

localStorage.setItem(
  "user",
  user
);

Object aur array ko properly store karne ke liye JSON conversion use karna chahiye.

Object Store Karna — JSON.stringify() 

const user = {

  name:
    "Ali",

  email:
    "ali@gmail.com"

};

localStorage.setItem(
  "user",
  JSON.stringify(user)
);

Object Read Karna — JSON.parse() 

const savedUser =
  localStorage.getItem(
    "user"
  );

const user =
  JSON.parse(
    savedUser
  );

console.log(
  user.name
);
Ali

Stored Data Check Karna 

const savedUser =
  localStorage.getItem(
    "user"
  );

if (savedUser) {

  const user =
    JSON.parse(
      savedUser
    );

  console.log(user);

}

Array Store Karna 

const products = [

Array Wapas Read Karna

sessionStorage

sessionStorage bhi localStorage jaisi API use karta hai, lekin data current tab ki session se tied hota hai.

sessionStorage.setItem() 

sessionStorage.setItem(
  "page",
  "dashboard"
);

sessionStorage.getItem() 

const page =
  sessionStorage.getItem(
    "page"
  );

console.log(page);

sessionStorage.removeItem() 

sessionStorage.removeItem(
  "page"
);

localStorage vs sessionStorage

localStorage sessionStorage
Data persist kar sakta hai. Current tab session ke liye hota hai.
Browser/tab close ke baad bhi reh sakta hai. Tab close hone par session data remove ho jata hai.
Same origin ke pages use kar sakte hain. Same origin ke saath tab-specific session hota hai.

Practical Example: Theme Save Karna 

<button id="themeBtn">
  Change Theme
</button>

<script>

const button =
  document.getElementById(
    "themeBtn"
  );

const savedTheme =
  localStorage.getItem(
    "theme"
  );

if (
  savedTheme ===
  "dark"
) {

  document.body.classList.add(
    "dark"
  );

}

button.addEventListener(
  "click",
  () => {

    document.body.classList.toggle(
      "dark"
    );

    const theme =
      document.body.classList.contains(
        "dark"
      )
        ? "dark"
        : "light";

    localStorage.setItem(
      "theme",
      theme
    );

  }
);

</script>

localStorage.setItem(

General non-sensitive app preferences/profile display data ko store karna useful ho sakta hai. Sensitive information jaise passwords browser storage me store nahi karni chahiye.

Practical Example: Todo List Save Karna 

let todos =
  JSON.parse(
    localStorage.getItem(
      "todos"
    )
  ) || [];

function addTodo(
  text
) {

  todos.push({
    id:
      Date.now(),

    text:
      text
  });

  localStorage.setItem(
    "todos",
    JSON.stringify(
      todos
    )
  );

}

addTodo(
  "Learn JavaScript"
);

console.log(
  todos
);

Stored Array Se Item Delete Karna 

function deleteTodo(
  id
) {

  todos =
    todos.filter(
      (todo) =>
        todo.id !== id
    );

  localStorage.setItem(
    "todos",
    JSON.stringify(
      todos
    )
  );

}

storage Event

Same origin ke kisi dusre browsing context me localStorage change hone par storage event useful ho sakta hai. 

window.addEventListener(
  "storage",
  (event) => {

    console.log(
      event.key
    );

    console.log(
      event.oldValue
    );

    console.log(
      event.newValue
    );

  }
);

localStorage Ke Sab Keys Read Karna 

for (
  let i = 0;
  i < localStorage.length;
  i++
) {

  const key =
    localStorage.key(i);

  const value =
    localStorage.getItem(
      key
    );

  console.log(
    key,
    value
  );

}

Storage Security

Browser storage me password, OTP ya highly sensitive personal information save nahi karna chahiye.

JavaScript running on the same origin can potentially access Web Storage, isliye XSS security important hai.

Storage data ko trusted database ka replacement nahi samajhna chahiye.

Storage Quick Reference

Method / Property Use
setItem() Data store/update
getItem() Data read
removeItem() One key delete
clear() Storage clear
key() Index se key read
length Key count
JSON.stringify() Object/array ko string banana
JSON.parse() JSON string ko JS value banana

Important Points

1. localStorage persistent browser storage provide karta hai.

2. sessionStorage current tab session ke liye data store karta hai.

3. setItem() data save karta hai.

4. getItem() stored data read karta hai.

5. removeItem() specific key remove karta hai.

6. clear() storage ke sab entries remove karta hai.

7. Objects aur arrays ke liye JSON.stringify() aur JSON.parse() use karte hain.

8. Password aur sensitive secrets ko browser storage me save nahi karna chahiye.
