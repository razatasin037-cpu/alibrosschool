Navigator Object Kya Hai?

JavaScript me navigator object browser aur device environment ke baare me information provide karta hai.

Isse browser language, online status, user agent aur kuch device capabilities check ki ja sakti hain.

navigator Object Access Karna 

console.log(
  navigator
);

navigator.language

Browser ki preferred language return karta hai. 

console.log(
  navigator.language
);
en-US

navigator.languages

User ki preferred languages ki list deta hai. 

console.log(
  navigator.languages
);

navigator.onLine

Browser network connection available lag rahi hai ya nahi, uska boolean status deta hai. 

console.log(
  navigator.onLine
);
true
or
false

navigator.userAgent

Browser ka user-agent string return karta hai. 

console.log(
  navigator.userAgent
);

Browser detection ke liye sirf user-agent par depend karna reliable nahi hota. Feature detection usually better approach hai.

navigator.platform

Platform related string de sakta hai, lekin modern code me exact device detection ke liye is property par heavily depend nahi karna chahiye. 

console.log(
  navigator.platform
);

navigator.cookieEnabled

Cookies generally enabled hain ya nahi check karta hai. 

console.log(
  navigator.cookieEnabled
);

navigator.hardwareConcurrency

Browser ko available logical processor count ka approximate value provide karta hai. 

console.log(
  navigator.hardwareConcurrency
);

navigator.deviceMemory

Supported browsers me approximate device memory information mil sakti hai. Ye har browser me available nahi hoti. 

if (
  "deviceMemory"
  in navigator
) {

  console.log(
    navigator.deviceMemory
  );

}

navigator.clipboard

Supported secure contexts me Clipboard API ke through text copy/read operations ki ja sakti hain. 

async function copyText() {

  await
    navigator.clipboard.writeText(
      "Hello JavaScript"
    );

  console.log(
    "Copied"
  );

}

copyText();

navigator.permissions

Supported browsers me kuch web permissions ka status check karne ke liye Permissions API available ho sakti hai. 

async function checkPermission() {

  const permission =
    await
      navigator.permissions.query({
        name:
          "geolocation"
      });

  console.log(
    permission.state
  );

}

  document.getElementById(
    "status"
  );

  status.textContent =

      ? "Online"

  "online",

Navigator Quick Reference

Property / API Use
navigator.language Preferred language
navigator.languages Preferred language list
navigator.onLine Network status hint
navigator.userAgent User-agent string
navigator.cookieEnabled Cookie availability
hardwareConcurrency Logical processor count
clipboard Clipboard API
geolocation Location API
permissions Permission status API

Important Points

1. navigator browser/environment related APIs provide karta hai.

2. navigator.language preferred browser language deta hai.

3. navigator.onLine browser ka online/offline status hint deta hai.

4. online aur offline events connection changes handle karne me useful hain.

5. userAgent browser information deta hai, lekin browser detection ke liye perfect reliable method nahi hai.

6. navigator.clipboard Clipboard API expose kar sakta hai.

7. navigator.geolocation location permission-based API provide karta hai.

8. Modern JavaScript me browser detection se zyada feature detection use karna better hai.
