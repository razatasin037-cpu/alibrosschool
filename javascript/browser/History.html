History Object Kya Hai?

JavaScript me history object current browser tab ki session history ke saath interact karne ke liye use hota hai.

Isse hum previous page, next page ya history me kisi relative position par navigate kar sakte hain.

history Object Access Karna 

console.log(
  window.history
);

Short form me history directly bhi use kar sakte hain.

history.length

Current tab ki session history me kitni entries hain, ye batata hai. 

console.log(
  history.length
);

history.back()

Browser ke Back button jaisa behavior karta hai. 

history.back();

Back Button Example 

<button id="backBtn">
  Go Back
</button>

<script>

const button =
  document.getElementById(
    "backBtn"
  );

button.addEventListener(
  "click",
  () => {

    history.back();

  }
);

</script>

history.forward()

Browser ke Forward button jaisa behavior karta hai. 

history.forward();

Forward Button Example 

<button id="forwardBtn">
  Go Forward
</button>

<script>

document.getElementById(
  "forwardBtn"
).addEventListener(
  "click",
  () => {

    history.forward();

  }
);

</script>

history.go()

Session history me relative position par move karne ke liye history.go() use hota hai. 

// One page back
history.go(
  -1
);

// One page forward
history.go(
  1
);

history.go() Examples

Code Meaning
history.go(-1) One page back
history.go(-2) Two entries back
history.go(1) One page forward
history.go(2) Two entries forward

back() Aur go(-1)

Ye dono generally one step backward navigate karte hain. 

history.back();
history.go(
  -1
);

forward() Aur go(1) 

history.forward();
history.go(
  1
);

history.state

Current history entry se associated state object ko read karta hai. 

console.log(
  history.state
);

history.pushState()

Browser history me new entry add karta hai bina traditional full page reload ke. 

history.pushState(
  {
    page:
      "products"
  },
  "",
  "/products"
);

pushState() Parameters

Parameter Use
state History entry ke saath data object.
unused Usually empty string diya jata hai.
url New history entry ka URL.

pushState() State Read Karna 

history.pushState(
  {
    id: 10,
    name:
      "Laptop"
  },
  "",
  "?id=10"
);

console.log(
  history.state
);

history.replaceState()

Current history entry ko update/replace karta hai; new history entry add nahi karta. 

history.replaceState(
  {
    page:
      "dashboard"
  },
  "",
  "/dashboard"
);

pushState() vs replaceState()

pushState() replaceState()
New history entry add karta hai. Current history entry replace/update karta hai.
Back button se previous entry par ja sakte hain. Extra entry create nahi hoti.

popstate Event

User session history me navigate karta hai, jaise Back/Forward, tab popstate event useful hota hai. 

window.addEventListener(
  "popstate",
  (event) => {

    console.log(
      "History Changed"
    );

    console.log(
      event.state
    );

  }
);

Practical SPA-Style Example 

<button
  class="nav-btn"
  data-page="home"
>
  Home
</button>

<button
  class="nav-btn"
  data-page="products"
>
  Products
</button>

<h2 id="content">
  Home
</h2>

<script>

const content =
  document.getElementById(
    "content"
  );

document.querySelectorAll(
  ".nav-btn"
).forEach((button) => {

  button.addEventListener(
    "click",
    () => {

      const page =
        button.dataset.page;

      history.pushState(
        {
          page: page
        },
        "",
        `/${page}`
      );

      content.textContent =
        page;

    }
  );

});

window.addEventListener(
  "popstate",
  (event) => {

    content.textContent =
      event.state?.page ||
      "Home";

  }
);

</script>

History Ki Limitation

JavaScript browser history ki complete list ya user ke previously visited websites ke URLs directly read nahi kar sakta.

Ye privacy aur security ke liye restricted hai.

History Quick Reference

Property / Method Use
history.length History entry count
history.back() Previous page
history.forward() Next page
history.go() Relative history navigation
history.state Current state object
pushState() New history entry
replaceState() Current history entry replace
popstate History navigation event

Important Points

1. history current browser tab ki session history represent karta hai.

2. history.back() previous entry par navigate karta hai.

3. history.forward() next entry par navigate karta hai.

4. history.go() relative history position par navigate karta hai.

5. pushState() new history entry create karta hai bina traditional full reload ke.

6. replaceState() current history entry ko update karta hai.

7. popstate Back/Forward navigation handle karne me useful hai.

8. History API client-side routing aur SPA navigation me useful hoti hai.
