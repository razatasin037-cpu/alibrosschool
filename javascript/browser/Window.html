Window Object Kya Hai?

Browser JavaScript me window top-level global object hota hai.

Browser ki window, document, timers, URL, storage aur bahut se browser features window object ke through available hote hain.

window Object Access Karna 

console.log(
  window
);

window Global Object Hai

Browser me kai global APIs ko window. likhe bina bhi use kar sakte hain.

With window 

window.alert(
  "Hello"
);

Without window 

alert(
  "Hello"
);

window.document

Current HTML document window.document se access hota hai. 

console.log(
  window.document
);

Normally hum short form me sirf document likhte hain.

console.log(

innerHeight 

console.log(

console.log(

console.log(

window.open()

New browsing context open karne ke liye use hota hai.

  window.open(
    "https://example.com",

Browser popup blocking rules apply ho sakte hain.

window.close()

Browsers security rules ki wajah se scripts generally arbitrary tabs ko close nahi kar sakti; script-opened windows ke saath ye useful hota hai.

Window load Event

Page aur dependent resources load hone ke baad load event fire hota hai. 

window.addEventListener(
  "load",
  () => {

    console.log(
      "Page Loaded"
    );

  }
);

DOMContentLoaded

Initial HTML parse hone aur DOM ready hone par DOMContentLoaded event fire hota hai; images jaise resources ka wait zaroori nahi. 

document.addEventListener(
  "DOMContentLoaded",
  () => {

    console.log(
      "DOM Ready"
    );

  }
);

load vs DOMContentLoaded

DOMContentLoaded load
DOM parse hone ke baad. Page resources load hone ke baad.
Usually earlier fire hota hai. Usually later fire hota hai.

Practical Example: Back To Top 

<button id="topBtn">
  Back To Top
</button>

<script>

const button =
  document.getElementById(
    "topBtn"
  );

button.addEventListener(
  "click",
  () => {

    window.scrollTo({

      top:
        0,

      behavior:
        "smooth"

    });

  }
);

</script>

Window Quick Reference

Property / Method Use
innerWidth Viewport width
innerHeight Viewport height
scrollX Horizontal scroll
scrollY Vertical scroll
scrollTo() Specific position scroll
open() New window/tab request
print() Print dialog
setTimeout() Delayed execution
setInterval() Repeated execution

Important Points

1. window browser JavaScript ka global object hai.

2. innerWidth aur innerHeight viewport dimensions dete hain.

3. scrollX aur scrollY current scroll position dete hain.

4. scrollTo() page ko given position tak scroll karta hai.

5. alert(), confirm() aur prompt() browser dialogs provide karte hain.

6. setTimeout() delayed execution aur setInterval() repeated execution ke liye use hota hai.

7. window.location, window.history aur window.navigator browser functionality expose karte hain.

8. resize, scroll aur load important window events hain.
