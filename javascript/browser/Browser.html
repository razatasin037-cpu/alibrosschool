Browser Object Model Kya Hai?

JavaScript browser ke different features ko access karne ke liye Browser Object Model, yani BOM use karta hai.

Isme window, screen, location, history, navigator aur browser storage jaise objects aate hain.

BOM Ka Simple Meaning

DOM HTML document ko control karta hai, jabki BOM browser window aur browser-related features ke saath kaam karne deta hai.

Browser Object Model Structure 

window

├── document
├── screen
├── location
├── history
├── navigator
├── localStorage
├── sessionStorage
├── alert()
├── confirm()
├── prompt()
├── setTimeout()
└── setInterval()

window Object

Browser me window global object hota hai. 

console.log(
  window
);

  window.innerWidth

console.log(
  window.innerHeight

DOM vs BOM

DOM BOM
HTML document ke saath kaam karta hai. Browser environment ke saath kaam karta hai.
document window
Elements create/change/remove. URL, history, storage, screen etc.

Browser Objects Quick Reference

Object Use
window Browser global object
screen Display information
location Current URL / navigation
history Session history
navigator Browser/environment info
localStorage Persistent browser storage
sessionStorage Session-based storage

Important Points

1. BOM ka matlab Browser Object Model hai.

2. window browser JavaScript ka global object hai.

3. screen display information provide karta hai.

4. location current URL aur navigation ke liye use hota hai.

5. history session navigation history ke saath interact karta hai.

6. navigator browser/environment related information provide karta hai.

7. localStorage aur sessionStorage browser me key-value data store karte hain.

8. setTimeout() aur setInterval() timing operations ke liye use hote hain.
