Location Object Kya Hai?

JavaScript me location object current page ke URL ke baare me information deta hai.

Iska use URL read karne, page redirect karne, reload karne aur URL ke different parts jaise hostname, pathname aur protocol access karne ke liye hota hai.

location Object Access Karna 

console.log(
  window.location
);

Short form me simply location bhi use kar sakte hain.

location.href

Current page ka complete URL return karta hai. 

console.log(
  location.href
);

Example URL 

https://example.com:8080/products/list.html?id=10#details

Ab isi URL ke different parts ko location object se samjhenge.

location.protocol 

console.log(
  location.protocol
);
https:

location.hostname

Domain / hostname return karta hai. 

console.log(
  location.hostname
);
example.com

location.port 

console.log(
  location.port
);
8080

Agar URL default port use kar raha ho to value empty string ho sakti hai.

location.host

Hostname ke saath port ko return karta hai. 

console.log(
  location.host
);
example.com:8080

location.pathname

URL ka path return karta hai. 

console.log(
  location.pathname
);
/products/list.html

location.search

URL ka query string return karta hai. 

console.log(
  location.search
);
?id=10

location.hash

URL ka hash/fragment part return karta hai. 

console.log(
  location.hash
);
#details

location.origin

Protocol + hostname + port ka combination return karta hai. 

console.log(
  location.origin
);
https://example.com:8080

location.href Se Redirect 

location.href =
  "https://example.com";

Ye current page ko new URL par navigate kar deta hai.

location.assign() 

location.assign(
  "https://example.com"
);

New page load karta hai aur browser history me current page generally available rehta hai.

location.replace()

Current page ko new URL se replace karta hai. 

location.replace(
  "https://example.com"
);

Iska main difference ye hai ki replaced page browser history me normal back navigation ke liye preserve nahi hota.

assign() vs replace()

assign() replace()
New URL load karta hai. Current history entry replace karta hai.
Back navigation possible ho sakti hai. Replaced entry par normal Back se wapas nahi aate.

location.reload()

Current page reload karta hai. 

location.reload();

URL Query Parameter Read Karna

Example URL: 

https://example.com/product.html?id=10&name=Laptop

JavaScript: 

const params =
  new URLSearchParams(
    location.search
  );

const id =
  params.get(
    "id"
  );

const name =
  params.get(
    "name"
  );

console.log(id);
console.log(name);
10
Laptop

Query Parameter Check Karna 

const params =
  new URLSearchParams(
    location.search
  );

if (
  params.has(
    "id"
  )
) {

  console.log(
    "ID Exists"
  );

}

Hash Change Karna 

location.hash =
  "#contact";

hashchange Event 

window.addEventListener(
  "hashchange",
  () => {

    console.log(
      location.hash
    );

  }
);

Practical Example: Product ID From URL

Agar page URL ho: 

product.html?id=15
const params =
  new URLSearchParams(
    location.search
  );

const productId =
  params.get(
    "id"
  );

console.log(
  "Product ID:",
  productId
);

Ye dynamic product detail pages me kaafi useful hota hai.

Location Quick Reference

Property / Method Use
href Complete URL
origin Protocol + host
protocol http: / https:
hostname Domain name
port Port number
pathname URL path
search Query string
hash URL fragment
assign() Navigate to URL
replace() Replace history entry
reload() Reload current page

Important Points

1. location current page URL ko represent karta hai.

2. location.href complete URL deta hai aur navigation ke liye bhi set kiya ja sakta hai.

3. hostname, pathname, search aur hash URL ke different parts dete hain.

4. assign() new URL par navigate karta hai.

5. replace() current history entry ko replace karta hai.

6. reload() current page reload karta hai.

7. URLSearchParams query parameters read aur manage karne ke liye useful hai.

8. Dynamic detail pages me URL parameters commonly use hote hain.
