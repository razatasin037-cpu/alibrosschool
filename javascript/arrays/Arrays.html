Array Kya Hai?

JavaScript me Array ek special data structure hai jo multiple values ko ek hi variable ke andar store karta hai.

Array ke elements index ke through access hote hain aur index 0 se start hota hai.

Array Syntax 

const arrayName = [
  value1,
  value2,
  value3
];

Simple Array Example 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

Array Index

Array ka first element index 0 par hota hai.

Index Value
0 Apple
1 Mango
2 Banana

Array Element Access Karna 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(fruits[0]);
console.log(fruits[1]);

Output:

Apple
Mango

Array Element Change Karna 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits[1] =
  "Orange";

console.log(fruits);

Output:

["Apple", "Orange", "Banana"]

Array length

length property array ke total elements ki count return karti hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(fruits.length);

Output:

3

Last Array Element 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(
  fruits[fruits.length - 1]
);

Output:

Banana

Array Me Different Data Types

JavaScript Array me different data types ki values ek saath store ki ja sakti hain. 

const data = [
  "Ali",
  20,
  true,
  null
];

console.log(data);

Output:

["Ali", 20, true, null]

Array of Objects 

const students = [

  {
    name: "Ali",
    age: 20
  },

  {
    name: "Rahul",
    age: 21
  }

];

console.log(students[0].name);

Output:

Ali

Nested Array

Array ke andar dusra Array bhi store kiya ja sakta hai. 

const numbers = [
  [1, 2],
  [3, 4]
];

console.log(
  numbers[1][0]
);

Output:

3

Array.isArray()

Array.isArray() check karta hai ki given value Array hai ya nahi. 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  Array.isArray(fruits)
);

Output:

true

typeof Array 

const fruits = [
  "Apple"
];

console.log(
  typeof fruits
);

Output:

object

JavaScript me Array technically object type ka hota hai. Isliye Array check karne ke liye Array.isArray() better hai.

Loop Through Array 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

for (
  let i = 0;
  i < fruits.length;
  i++
) {
  console.log(fruits[i]);
}

Output:

Apple
Mango
Banana

Important Points

1. Array ek variable me multiple values store karta hai.

2. Array index 0 se start hota hai.

3. array[index] se element access karte hain.

4. length total elements ki count deta hai.

5. Array me Strings, Numbers, Objects aur dusre Arrays bhi store kiye ja sakte hain.

6. Array.isArray() value Array hai ya nahi check karta hai.

7. typeof array ka result "object" hota hai.
