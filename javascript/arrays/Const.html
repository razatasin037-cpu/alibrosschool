const Array Kya Hai?

JavaScript me Array ko const se declare karna bahut common hai.

const ka matlab ye nahi hai ki Array ke elements change nahi ho sakte. Iska matlab hai ki Array variable ko ek completely new Array se reassign nahi kar sakte.

const Array Syntax 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

Basic const Array Example 

const fruits = [
  "Apple",
  "Mango"
];

console.log(fruits);

Output:

["Apple", "Mango"]

const Array Ka Element Change Karna

const Array ke elements change kiye ja sakte hain. 

const fruits = [
  "Apple",
  "Mango"
];

fruits[0] =
  "Orange";

console.log(fruits);

Output:

["Orange", "Mango"]

const Array Me Element Add Karna 

const fruits = [
  "Apple",
  "Mango"
];

fruits.push(
  "Banana"
);

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

const Array Se Element Remove Karna 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.pop();

console.log(fruits);

Output:

["Apple", "Mango"]

const Array Ko Reassign Nahi Kar Sakte

Same const variable ko completely new Array assign nahi kar sakte. 

const fruits = [
  "Apple",
  "Mango"
];

fruits = [
  "Orange",
  "Banana"
];

Result:

TypeError: Assignment to constant variable.

Sabse Important Concept

const Array ke contents ko permanently lock nahi karta.

Ye variable ki Array reference ko reassign hone se rokta hai. 

const numbers = [1, 2, 3];

// Allowed
numbers[0] = 100;
numbers.push(4);

// Not Allowed
numbers = [5, 6];

const Array vs let Array

const let
Array variable reassign nahi kar sakte. Array variable reassign kar sakte hain.
Elements change kar sakte hain. Elements change kar sakte hain.
push/pop allowed hai. push/pop allowed hai.

let Array Reassignment 

let fruits = [
  "Apple"
];

fruits = [
  "Mango",
  "Banana"
];

console.log(fruits);

Output:

["Mango", "Banana"]

const Array Is Block Scoped

const block scoped hota hai. 

{
  const fruits = [
    "Apple",
    "Mango"
  ];

  console.log(fruits);
}

Output:

["Apple", "Mango"]

Block Ke Bahar Access 

{
  const fruits = [
    "Apple"
  ];
}

console.log(fruits);

Result:

ReferenceError

Same Array Name in Different Blocks 

{
  const fruits = [
    "Apple"
  ];

  console.log(fruits);
}

{
  const fruits = [
    "Mango"
  ];

  console.log(fruits);
}

Output:

["Apple"]
["Mango"]

const Array of Objects

Array ke andar objects ho to unki properties bhi change ki ja sakti hain. 

const students = [
  {
    name: "Ali",
    age: 20
  }
];

students[0].age =
  21;

console.log(
  students[0]
);

Output:

{ name: "Ali", age: 21 }

Array Ko Freeze Karna

Agar Array ki top-level structure ko modify hone se rokna ho to Object.freeze() use kar sakte hain. 

const fruits =
  Object.freeze([
    "Apple",
    "Mango"
  ]);

console.log(fruits);

Note: Object.freeze() shallow hota hai. Agar Array ke andar objects hain to nested objects automatically deep freeze nahi hote.

Important Points

1. Arrays ko commonly const se declare kiya jata hai.

2. const Array ke elements change kiye ja sakte hain.

3. push(), pop(), splice() jaise mutating methods use ho sakte hain.

4. const Array variable ko completely new Array se reassign nahi kar sakte.

5. const block scoped hota hai.

6. Agar reassignment zaroori ho to let use kar sakte hain.

7. Object.freeze() top-level mutations ko restrict karne ke liye use kiya ja sakta hai.
