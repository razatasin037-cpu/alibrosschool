Array Methods Kya Hain?

JavaScript Array Methods built-in functions hote hain jo Array ke elements ko add, remove, combine, copy ya convert karne me help karte hain.

Jaise push(), pop(), slice(), splice() aur concat().

Important Array Methods

Method Use
push() End me element add karta hai.
pop() Last element remove karta hai.
unshift() Start me element add karta hai.
shift() First element remove karta hai.
concat() Arrays ko combine karta hai.
slice() Array ka selected part copy karta hai.
splice() Elements add/remove karta hai.
join() Array ko String me join karta hai.

push()

push() Array ke end me ek ya multiple elements add karta hai. 

const fruits = [
  "Apple",
  "Mango"
];

fruits.push("Banana");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

pop()

pop() Array ka last element remove karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.pop();

console.log(fruits);

Output:

["Apple", "Mango"]

unshift()

unshift() Array ke beginning me element add karta hai. 

const fruits = [
  "Mango",
  "Banana"
];

fruits.unshift("Apple");

console.log(fruits);

Output:

["Apple", "Mango", "Banana"]

shift()

shift() Array ka first element remove karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.shift();

console.log(fruits);

Output:

["Mango", "Banana"]

concat()

concat() do ya zyada Arrays ko combine karke new Array return karta hai. 

const first = [
  "Apple",
  "Mango"
];

const second = [
  "Banana",
  "Orange"
];

const fruits =
  first.concat(second);

console.log(fruits);

Output:

["Apple", "Mango", "Banana", "Orange"]

slice()

slice() Array ka selected portion new Array me return karta hai aur original Array ko change nahi karta. 

const fruits = [
  "Apple",
  "Mango",
  "Banana",
  "Orange"
];

const result =
  fruits.slice(1, 3);

console.log(result);

Output:

["Mango", "Banana"]

splice()

splice() Array ke elements remove, replace ya add kar sakta hai. Ye original Array ko modify karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.splice(
  1,
  1,
  "Orange"
);

console.log(fruits);

Output:

["Apple", "Orange", "Banana"]

join()

join() Array ke elements ko String me combine karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(
  fruits.join(" - ")
);

Output:

Apple - Mango - Banana

toString() 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  fruits.toString()
);

Output:

Apple,Mango

at()

at() index ke through Array element return karta hai. Negative index se end se element access kar sakte hain. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(fruits.at(-1));

Output:

Banana

includes() 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  fruits.includes(
    "Mango"
  )
);

Output:

true

indexOf() 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(
  fruits.indexOf(
    "Mango"
  )
);

Output:

1

Important Points

1. push() end me item add karta hai.

2. pop() last item remove karta hai.

3. shift() first item remove karta hai.

4. unshift() beginning me item add karta hai.

5. slice() original Array ko modify nahi karta.

6. splice() original Array ko modify karta hai.

7. concat() new combined Array return karta hai.

8. join() Array elements ko String me combine karta hai.
