Array Search Methods Kya Hain?

JavaScript Array Search Methods ka use Array ke andar kisi value, element ya condition ko search karne ke liye hota hai.

Important methods hain indexOf(), lastIndexOf(), includes(), find() aur findIndex().

Array Search Methods List

Method Use
indexOf() First matching element ka index return karta hai.
lastIndexOf() Last matching element ka index return karta hai.
includes() Value available hai ya nahi check karta hai.
find() Condition match karne wala first element return karta hai.
findIndex() Condition match karne wale first element ka index return karta hai.
findLast() Last matching element return karta hai.
findLastIndex() Last matching element ka index return karta hai.

indexOf()

indexOf() Array me value ko search karke uska first index return karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

console.log(
  fruits.indexOf(
    "Mango"
  )
);

Output:

1

Value Na Mile To

Agar value Array me nahi milti, to indexOf() -1 return karta hai. 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  fruits.indexOf(
    "Orange"
  )
);

Output:

-1

lastIndexOf()

lastIndexOf() duplicate value ka last matching index return karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Apple"
];

console.log(
  fruits.lastIndexOf(
    "Apple"
  )
);

Output:

2

includes()

includes() check karta hai ki value Array me exist karti hai ya nahi. 

const fruits = [
  "Apple",
  "Mango"
];

console.log(
  fruits.includes(
    "Apple"
  )
);

Output:

true

find()

find() condition satisfy karne wala first element return karta hai. 

const numbers = [
  5,
  12,
  18,
  25
];

const result =
  numbers.find((number) => {
    return number > 10;
  });

console.log(result);

Output:

12

find() Short Syntax 

const numbers = [
  5,
  12,
  18
];

const result =
  numbers.find(
    number => number > 10
  );

console.log(result);

Output:

12

findIndex()

findIndex() condition match karne wale first element ka index return karta hai. 

const numbers = [
  5,
  12,
  18
];

const index =
  numbers.findIndex(
    number => number > 10
  );

console.log(index);

Output:

1

Search Object Inside Array

find() Array of Objects me bahut useful hota hai. 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

const student =
  students.find(
    item => item.id === 2
  );

console.log(student.name);

Output:

Rahul

findLast()

findLast() Array ke end ki taraf se condition match karne wala last element return karta hai. 

const numbers = [
  5,
  12,
  18,
  25
];

const result =
  numbers.findLast(
    number => number > 10
  );

console.log(result);

Output:

25

findLastIndex() 

const numbers = [
  5,
  12,
  18,
  25
];

const index =
  numbers.findLastIndex(
    number => number > 10
  );

console.log(index);

Output:

3

Search Methods Difference

Method Returns
indexOf() Index ya -1
includes() true / false
find() Element ya undefined
findIndex() Index ya -1
findLast() Last matching element ya undefined

Important Points

1. indexOf() first matching value ka index deta hai.

2. lastIndexOf() last matching value ka index deta hai.

3. includes() true ya false return karta hai.

4. find() callback condition match karne wala first element deta hai.

5. findIndex() first matching element ka index deta hai.

6. Matching value na mile to find() undefined return karta hai.

7. find() Array of Objects me commonly use hota hai.
