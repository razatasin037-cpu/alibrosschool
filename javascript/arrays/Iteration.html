Array Iteration Kya Hai?

JavaScript me Array Iteration ka matlab hai Array ke elements par ek-ek karke kaam karna.

Iske liye forEach(), map(), filter(), reduce(), some() aur every() jaise methods use hote hain.

Important Iteration Methods

Method Use
forEach() Har element par function run karta hai.
map() Har element ko transform karke new Array deta hai.
filter() Condition match karne wale elements ka new Array deta hai.
reduce() Array ko ek single value me reduce karta hai.
some() Check karta hai koi ek element condition match karta hai ya nahi.
every() Check karta hai sab elements condition match karte hain ya nahi.

forEach()

forEach() Array ke har element ke liye callback function run karta hai. 

const fruits = [
  "Apple",
  "Mango",
  "Banana"
];

fruits.forEach((fruit) => {
  console.log(fruit);
});

Output:

Apple
Mango
Banana

map()

map() har element ko process karke ek new Array return karta hai. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map((number) => {
    return number * 2;
  });

console.log(result);

Output:

[2, 4, 6]

map() Short Syntax 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.map(
    number => number * 2
  );

console.log(result);

Output:

[2, 4, 6]

filter()

filter() condition true karne wale elements ka new Array return karta hai. 

const numbers = [
  5,
  12,
  18,
  3
];

const result =
  numbers.filter(
    number => number > 10
  );

console.log(result);

Output:

[12, 18]

reduce()

reduce() Array ke elements ko process karke ek single value return karta hai. 

const numbers = [
  10,
  20,
  30
];

const total =
  numbers.reduce(
    (sum, number) => sum + number,
    0
  );

console.log(total);

Output:

60

reduce() Kaise Kaam Karta Hai? 

numbers.reduce(
  (sum, number) => sum + number,
  0
);

sum accumulator hai.

number current Array element hai.

Last 0 initial value hai.

some()

some() agar kam se kam ek element condition match karta hai to true return karta hai. 

const ages = [
  12,
  15,
  20
];

const result =
  ages.some(
    age => age >= 18
  );

console.log(result);

Output:

true

every()

every() tabhi true return karta hai jab sabhi elements condition match karein. 

const ages = [
  20,
  25,
  30
];

const result =
  ages.every(
    age => age >= 18
  );

console.log(result);

Output:

true

Array of Objects With map() 

const students = [
  {
    id: 1,
    name: "Ali"
  },
  {
    id: 2,
    name: "Rahul"
  }
];

const names =
  students.map(
    student => student.name
  );

console.log(names);

Output:

["Ali", "Rahul"]

Array of Objects With filter() 

const products = [
  {
    name: "Keyboard",
    price: 500
  },
  {
    name: "Mouse",
    price: 300
  },
  {
    name: "Monitor",
    price: 8000
  }
];

const result =
  products.filter(
    product => product.price > 400
  );

console.log(result);

forEach vs map vs filter

Method Main Use New Array?
forEach() Har item par action No
map() Transform elements Yes
filter() Matching elements select karna Yes

Important Points

1. forEach() har element par callback run karta hai.

2. map() same length ka new transformed Array generally return karta hai.

3. filter() matching elements ka new Array return karta hai.

4. reduce() multiple values ko ek result me combine kar sakta hai.

5. some() kisi ek match par true ho sakta hai.

6. every() sab elements match hone par true deta hai.

7. React me map() list render karne ke liye bahut commonly use hota hai.
