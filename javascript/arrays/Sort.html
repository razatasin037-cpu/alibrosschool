Array Sorting Kya Hai?

JavaScript me Array Sorting ka use Array ke elements ko kisi order me arrange karne ke liye kiya jata hai.

Strings ko alphabetical order me aur numbers ko ascending ya descending order me arrange kiya ja sakta hai.

Array Sort Methods

Method Use
sort() Array elements ko sort karta hai.
reverse() Array ka current order reverse karta hai.
toSorted() Sorted new Array return karta hai.
toReversed() Reversed new Array return karta hai.

sort()

sort() Array ke elements ko default string comparison ke according sort karta hai. 

const fruits = [
  "Mango",
  "Apple",
  "Banana"
];

fruits.sort();

console.log(fruits);

Output:

["Apple", "Banana", "Mango"]

reverse()

reverse() Array ke existing order ko reverse karta hai. 

const fruits = [
  "Apple",
  "Banana",
  "Mango"
];

fruits.reverse();

console.log(fruits);

Output:

["Mango", "Banana", "Apple"]

Alphabetical Descending Sort 

const fruits = [
  "Mango",
  "Apple",
  "Banana"
];

fruits.sort();
fruits.reverse();

console.log(fruits);

Output:

["Mango", "Banana", "Apple"]

Number Sorting Problem

Normal sort() numbers ko numeric value ki jagah strings ki tarah compare karta hai. Isliye direct numeric sorting galat result de sakti hai. 

const numbers = [
  40,
  100,
  1,
  5,
  25
];

numbers.sort();

console.log(numbers);

Output:

[1, 100, 25, 40, 5]

Numeric Ascending Sort

Numbers ko smallest se largest sort karne ke liye compare function use karte hain. 

const numbers = [
  40,
  100,
  1,
  5,
  25
];

numbers.sort((a, b) => a - b);

console.log(numbers);

Output:

[1, 5, 25, 40, 100]

Numeric Descending Sort

Largest se smallest sort karne ke liye b - a use karte hain. 

const numbers = [
  40,
  100,
  1,
  5,
  25
];

numbers.sort((a, b) => b - a);

console.log(numbers);

Output:

[100, 40, 25, 5, 1]

Compare Function Kaise Kaam Karta Hai? 

numbers.sort((a, b) => a - b);

Agar result negative hai → a pehle aata hai.

Agar result positive hai → b pehle aata hai.

Agar result 0 hai → relative order change karna zaroori nahi.

Smallest Aur Largest Number 

const numbers = [
  40,
  100,
  1,
  5
];

numbers.sort((a, b) => a - b);

console.log(numbers[0]);

console.log(
  numbers[numbers.length - 1]
);

Output:

1
100

Math.min() Aur Math.max()

Sirf minimum ya maximum value chahiye to poora Array sort karna zaroori nahi hai. 

const numbers = [
  40,
  100,
  1,
  5
];

console.log(
  Math.min(...numbers)
);

console.log(
  Math.max(...numbers)
);

Output:

1
100

Sort Array of Objects

Objects ko kisi property ke according sort kiya ja sakta hai. 

const students = [
  {
    name: "Ali",
    age: 22
  },
  {
    name: "Rahul",
    age: 18
  },
  {
    name: "Aman",
    age: 20
  }
];

students.sort((a, b) => a.age - b.age);

console.log(students);

Order:

Rahul - 18
Aman - 20
Ali - 22

Sort Objects By Name 

const students = [
  { name: "Rahul" },
  { name: "Ali" },
  { name: "Aman" }
];

students.sort((a, b) =>
  a.name.localeCompare(b.name)
);

console.log(students);

Order:

Ali
Aman
Rahul

toSorted()

toSorted() sorted new Array return karta hai aur original Array ko change nahi karta. 

const numbers = [
  30,
  10,
  20
];

const sorted =
  numbers.toSorted((a, b) => a - b);

console.log(sorted);
console.log(numbers);

Output:

[10, 20, 30]
[30, 10, 20]

toReversed()

toReversed() reverse order me new Array return karta hai aur original Array ko modify nahi karta. 

const numbers = [
  1,
  2,
  3
];

const result =
  numbers.toReversed();

console.log(result);
console.log(numbers);

Output:

[3, 2, 1]
[1, 2, 3]

sort() vs toSorted()

sort() toSorted()
Original Array modify karta hai. Original Array modify nahi karta.
Same Array ko sorted order me change karta hai. New sorted Array return karta hai.

Important Points

1. sort() default me values ko strings ki tarah compare karta hai.

2. Number ascending sort ke liye (a, b) => a - b use karo.

3. Number descending sort ke liye (a, b) => b - a use karo.

4. reverse() current Array ka order reverse karta hai.

5. sort() aur reverse() original Array ko modify karte hain.

6. toSorted() aur toReversed() new Array return karte hain.

7. Array of Objects ko property ke according custom compare function se sort kar sakte hain.
