Logical Operators Kya Hain?

JavaScript me Logical Operators ka use ek ya multiple conditions ko combine aur check karne ke liye hota hai.

JavaScript ke main logical operators hain: &&, || aur !.

List of Logical Operators

Operator Name Meaning
&& Logical AND Dono conditions true honi chahiye.
|| Logical OR Koi ek condition true ho to result true hota hai.
! Logical NOT Boolean result ko reverse karta hai.

1. Logical AND (&&)

&& operator tab true return karta hai jab dono conditions true hon. 

let age = 20;
let hasId = true;

if (age >= 18 && hasId === true) {
  console.log("Entry Allowed");
} else {
  console.log("Entry Not Allowed");
}

Output:

Entry Allowed

AND Truth Table

Condition 1 Condition 2 Result
true true true
true false false
false true false
false false false

2. Logical OR (||)

|| operator me agar koi ek condition bhi true ho, to result true hota hai. 

let isAdmin = false;
let isManager = true;

if (isAdmin || isManager) {
  console.log("Access Allowed");
} else {
  console.log("Access Denied");
}

Output:

Access Allowed

OR Truth Table

Condition 1 Condition 2 Result
true true true
true false true
false true true
false false false

3. Logical NOT (!)

! operator Boolean value ko reverse kar deta hai. 

let isLoggedIn = true;

console.log(!isLoggedIn);

Output:

false

NOT Truth Table

Value !Value
true false
false true

Login Example With && 

let email = "admin@gmail.com";
let password = "12345";

if (
  email === "admin@gmail.com" &&
  password === "12345"
) {
  console.log("Login Successful");
} else {
  console.log("Invalid Login");
}

Output:

Login Successful

Marks Range Example

&& ka use range check karne me bhi hota hai. 

let marks = 75;

if (marks >= 60 && marks <= 79) {
  console.log("Grade B");
}

Output:

Grade B

Multiple Roles With || 

let role = "manager";

if (role === "admin" || role === "manager") {
  console.log("Dashboard Access");
} else {
  console.log("Access Denied");
}

Output:

Dashboard Access

NOT With If Statement 

let isBlocked = false;

if (!isBlocked) {
  console.log("User Can Login");
}

Output:

User Can Login

Yahan isBlocked false hai. Isliye !isBlocked true ban jata hai.

&& aur || Ek Saath 

let age = 20;
let hasId = true;
let specialPermission = false;

if (
  (age >= 18 && hasId) ||
  specialPermission
) {
  console.log("Entry Allowed");
} else {
  console.log("Entry Denied");
}

Output:

Entry Allowed

Direct Logical Results 

console.log(true && true);
console.log(true && false);

console.log(true || false);
console.log(false || false);

console.log(!true);
console.log(!false);

Output:

true
false
true
false
false
true

Easy Way To Remember

&& = AND = dono true chahiye.

|| = OR = koi ek true chalega.

! = NOT = result ulta kar do.

Important Points

1. && me sabhi conditions true honi chahiye.

2. || me kam se kam ek condition true honi chahiye.

3. ! true ko false aur false ko true karta hai.

4. Logical operators ka use mostly if, if...else aur ternary conditions me hota hai.

5. Complex conditions me brackets ( ) use karna code ko clear banata hai.
