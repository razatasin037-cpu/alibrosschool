If Statement Kya Hai?

JavaScript me if statement ka use condition check karne ke liye hota hai.

Agar condition true hoti hai, tab if ke andar wala code execute hota hai.

If Statement Syntax

JavaScript me basic if syntax: 

if (condition) {
  // condition true hone par code chalega
}

If Statement Kaise Kaam Karta Hai?

1. Sabse pehle if ke andar condition check hoti hai.

2. Agar condition true hai, to curly brackets { } ke andar ka code execute hota hai.

3. Agar condition false hai, to if block skip ho jata hai.

Basic If Example 

let age = 20;

if (age >= 18) {
  console.log("You are an adult");
}

Output:

You are an adult

Agar Condition False Ho 

let age = 15;

if (age >= 18) {
  console.log("You are an adult");
}

Output:

No Output

Kyunki 15 >= 18 false hai, isliye if block execute nahi hoga.

Student Marks Example

Student ke marks 40 ya usse zyada hain to Pass print karenge. 

let marks = 65;

if (marks >= 40) {
  console.log("Pass");
}

Output:

Pass

Positive Number Example 

let number = 25;

if (number > 0) {
  console.log("Positive Number");
}

Output:

Positive Number

Even Number Example

Modulus % operator ka use karke check kar sakte hain ki number even hai ya nahi. 

let number = 10;

if (number % 2 === 0) {
  console.log("Even Number");
}

Output:

Even Number

Yahan 10 % 2 ka remainder 0 hai, isliye condition true hai.

If With Multiple Conditions

Logical && operator se ek saath do conditions check kar sakte hain. 

let age = 22;
let country = "India";

if (age >= 18 && country === "India") {
  console.log("Condition Passed");
}

Output:

Condition Passed

Compare Two Variables 

let a = 50;
let b = 20;

if (a > b) {
  console.log("a is greater than b");
}

Output:

a is greater than b

Important Points

1. if condition ke andar comparison likha jata hai.

2. Condition ka result true hone par hi code execute hota hai.

3. Comparison ke liye === use karna better hota hai.

4. if ke saath >, <, >=, <=, === jaise comparison operators use hote hain.

5. Agar condition false hone par bhi code chalana hai, tab if...else use hota hai.
