Ternary Operator Kya Hai?

JavaScript me Ternary Operator simple if...else statement ka short form hota hai.

Isme ? aur : symbols ka use hota hai.

Ternary Operator Syntax

Ternary operator ka basic syntax: 

condition ? trueValue : falseValue;

Ternary Operator Kaise Kaam Karta Hai?

1. Sabse pehle condition check hoti hai.

2. Agar condition true hai, to ? ke baad wali value return hoti hai.

3. Agar condition false hai, to : ke baad wali value return hoti hai.

Basic Ternary Example 

let age = 20;

let result = age >= 18
  ? "Adult"
  : "Minor";

console.log(result);

Output:

Adult

If Else vs Ternary

Pehle same condition ko if...else se dekho: 

let age = 20;
let result;

if (age >= 18) {
  result = "Adult";
} else {
  result = "Minor";
}

console.log(result);

Isi code ko Ternary Operator se short me: 

let age = 20;

let result = age >= 18
  ? "Adult"
  : "Minor";

console.log(result);

Output:

Adult

Student Pass or Fail 

let marks = 55;

let result = marks >= 40
  ? "Pass"
  : "Fail";

console.log(result);

Output:

Pass

Even or Odd Example 

let number = 7;

let result = number % 2 === 0
  ? "Even Number"
  : "Odd Number";

console.log(result);

Output:

Odd Number

Positive or Negative 

let number = -5;

let result = number >= 0
  ? "Positive Number"
  : "Negative Number";

console.log(result);

Output:

Negative Number

Login Example 

let isLoggedIn = true;

let message = isLoggedIn
  ? "Welcome User"
  : "Please Login";

console.log(message);

Output:

Welcome User

Direct Ternary in console.log()

Ternary ka result variable me store karna compulsory nahi hai. Direct console.log() ke andar bhi use kar sakte hain. 

let age = 16;

console.log(
  age >= 18
    ? "Eligible"
    : "Not Eligible"
);

Output:

Not Eligible

Nested Ternary Operator

Ek Ternary Operator ke andar doosra Ternary Operator bhi likh sakte hain. Isse multiple conditions check hoti hain. 

let marks = 75;

let grade =
  marks >= 80
    ? "Grade A"
    : marks >= 60
      ? "Grade B"
      : marks >= 40
        ? "Grade C"
        : "Fail";

console.log(grade);

Output:

Grade B

Nested ternary technically valid hai, lekin bahut zyada conditions hone par if...else if zyada readable hota hai.

If Else vs Ternary Operator

If Else Ternary
Multiple lines me likha jata hai. Short form me likha ja sakta hai.
Complex conditions ke liye better hai. Simple conditions ke liye useful hai.
if (...) { } else { } condition ? value1 : value2

Important Points

1. Ternary Operator if...else ka short form hai.

2. ? ke baad true condition ka result likhte hain.

3. : ke baad false condition ka result likhte hain.

4. Simple conditions ke liye ternary operator useful hota hai.

5. Bahut complex conditions me if...else if zyada readable hota hai.
