Boolean Kya Hai?

JavaScript me Boolean ek data type hai jisme sirf do values hoti hain: true aur false.

Boolean values ka use mostly conditions, comparisons aur decision making me hota hai.

Boolean Values

Boolean me sirf do possible values hoti hain. 

let isLoggedIn = true;

let isAdmin = false;

console.log(isLoggedIn);
console.log(isAdmin);

Output:

true
false

Boolean Data Type

typeof operator se Boolean ka data type check kar sakte hain. 

let status = true;

console.log(typeof status);

Output:

boolean

Comparison Se Boolean Result

Comparison operators ka result hamesha true ya false hota hai. 

let a = 10;
let b = 20;

console.log(a < b);
console.log(a > b);
console.log(a === 10);

Output:

true
false
true

Boolean() Function

JavaScript ka Boolean() function kisi value ko Boolean me convert karta hai. 

console.log(Boolean(10));

console.log(Boolean("Hello"));

console.log(Boolean(0));

console.log(Boolean(""));

Output:

true
true
false
false

Truthy Values

JavaScript me kuch values Boolean true ki tarah behave karti hain. Inhe Truthy Values kehte hain. 

Boolean(1);
Boolean(100);
Boolean(-10);
Boolean("Hello");
Boolean("false");
Boolean([]);
Boolean({});

Result:

All are true

Falsy Values

Kuch values Boolean false ki tarah behave karti hain. Inhe Falsy Values kehte hain.

Value Boolean Result
false false
0 false
-0 false
"" false
null false
undefined false
NaN false

Falsy Values Example 

console.log(Boolean(0));
console.log(Boolean(""));
console.log(Boolean(null));
console.log(Boolean(undefined));
console.log(Boolean(NaN));

Output:

false
false
false
false
false

Boolean With If Statement

Boolean variable ko directly if condition me use kar sakte hain. 

let isLoggedIn = true;

if (isLoggedIn) {
  console.log("Welcome User");
}

Output:

Welcome User

Boolean With If Else 

let hasPermission = false;

if (hasPermission) {
  console.log("Access Allowed");
} else {
  console.log("Access Denied");
}

Output:

Access Denied

Real Life Example

Maan lo student ke marks ke basis par pass status Boolean me store karna hai. 

let marks = 65;

let isPassed = marks >= 40;

console.log(isPassed);

Output:

true

Yahan marks >= 40 ka result directly Boolean value true me store ho raha hai.

Boolean Ko Reverse Karna

Logical NOT operator ! Boolean value ko reverse karta hai. 

let isOnline = true;

console.log(!isOnline);

Output:

false

Double NOT !!

Double NOT !! ka use bhi value ko Boolean me convert karne ke liye kiya ja sakta hai. 

console.log(!!"Hello");

console.log(!!0);

Output:

true
false

Important Points

1. Boolean me sirf true aur false values hoti hain.

2. Comparison operators Boolean result return karte hain.

3. Boolean() kisi value ko Boolean me convert karta hai.

4. 0, empty string, null, undefined aur NaN falsy values hain.

5. Non-empty strings, non-zero numbers, arrays aur objects truthy hote hain.

6. ! Boolean value ko reverse karta hai.
