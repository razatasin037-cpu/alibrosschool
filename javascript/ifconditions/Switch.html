Switch Statement Kya Hai?

JavaScript me switch statement ka use ek value ko multiple possible values ke saath compare karne ke liye hota hai.

Jab bahut saare else if conditions ho, tab kuch situations me switch code ko simple aur readable bana sakta hai.

Switch Statement Syntax 

switch (expression) {

  case value1:
    // code
    break;

  case value2:
    // code
    break;

  default:
    // default code
}

Switch Ke Important Parts

Keyword Use
switch Value ya expression ko check karta hai.
case Possible value define karta hai.
break Match hone ke baad switch ko stop karta hai.
default Koi case match na ho to default code chalata hai.

Basic Switch Example 

let number = 2;

switch (number) {

  case 1:
    console.log("One");
    break;

  case 2:
    console.log("Two");
    break;

  case 3:
    console.log("Three");
    break;

  default:
    console.log("Invalid Number");
}

Output:

Two

Switch Kaise Kaam Karta Hai?

1. switch(number) ke andar wali value li jati hai.

2. JavaScript har case ke saath value compare karta hai.

3. Match milne par us case ka code execute hota hai.

4. break switch statement ko wahi stop kar deta hai.

5. Agar koi bhi case match nahi karta to default execute hota hai.

Week Day Example 

let day = 3;

switch (day) {

  case 1:
    console.log("Monday");
    break;

  case 2:
    console.log("Tuesday");
    break;

  case 3:
    console.log("Wednesday");
    break;

  case 4:
    console.log("Thursday");
    break;

  case 5:
    console.log("Friday");
    break;

  case 6:
    console.log("Saturday");
    break;

  case 7:
    console.log("Sunday");
    break;

  default:
    console.log("Invalid Day");
}

Output:

Wednesday

String Value With Switch 

let role = "admin";

switch (role) {

  case "admin":
    console.log("Welcome Admin");
    break;

  case "user":
    console.log("Welcome User");
    break;

  case "manager":
    console.log("Welcome Manager");
    break;

  default:
    console.log("Unknown Role");
}

Output:

Welcome Admin

Default Case

Agar kisi bhi case ke saath value match nahi hoti to default block execute hota hai. 

let color = "black";

switch (color) {

  case "red":
    console.log("Red Color");
    break;

  case "blue":
    console.log("Blue Color");
    break;

  default:
    console.log("Color Not Found");
}

Output:

Color Not Found

Break Ka Kya Kaam Hai?

break matching case execute hone ke baad switch ko stop karta hai. 

let value = 1;

switch (value) {

  case 1:
    console.log("One");
    break;

  case 2:
    console.log("Two");
    break;
}

Output:

One

Break Na Lagaye To Kya Hoga?

Agar break nahi lagate, to matching case ke baad ke cases bhi execute ho sakte hain. Isse fall-through kehte hain. 

let number = 1;

switch (number) {

  case 1:
    console.log("One");

  case 2:
    console.log("Two");

  case 3:
    console.log("Three");
}

Output:

One
Two
Three

Multiple Cases Same Result

Multiple cases ko same code ke saath use kiya ja sakta hai. 

let day = 7;

switch (day) {

  case 1:
  case 2:
  case 3:
  case 4:
  case 5:
    console.log("Weekday");
    break;

  case 6:
  case 7:
    console.log("Weekend");
    break;

  default:
    console.log("Invalid Day");
}

Output:

Weekend

Grade Example

Switch exact values compare karta hai. Isliye range based marks ke liye pehle grade calculate karke switch use kar sakte hain. 

let grade = "B";

switch (grade) {

  case "A":
    console.log("Excellent");
    break;

  case "B":
    console.log("Very Good");
    break;

  case "C":
    console.log("Good");
    break;

  default:
    console.log("Invalid Grade");
}

Output:

Very Good

If Else vs Switch

If Else Switch
Complex conditions ke liye useful. Ek value ke multiple exact cases ke liye useful.
Range check easily kar sakta hai. Normally exact values match karta hai.
age >= 18 jaisi conditions ke liye better. role === "admin" jaisi multiple fixed values ke liye useful.

Important Points

1. switch ek expression ki value check karta hai.

2. case possible values define karta hai.

3. break matching case ke baad execution ko stop karta hai.

4. default tab chalta hai jab koi case match nahi karta.

5. Switch comparison strict comparison ke jaisa behave karta hai, isliye value aur type match honi chahiye.

6. Range based conditions ke liye generally if...else zyada simple hota hai.
