If Else Statement Kya Hai?

JavaScript me if...else statement ka use do possible situations ko handle karne ke liye hota hai.

Agar condition true hoti hai to if block execute hota hai, aur agar condition false hoti hai to else block execute hota hai.

If Else Syntax

Basic if...else syntax: 

if (condition) {
  // condition true hone par
} else {
  // condition false hone par
}

If Else Kaise Kaam Karta Hai?

1. Sabse pehle if ki condition check hoti hai.

2. Condition true hai to if block execute hota hai.

3. Condition false hai to else block execute hota hai.

4. Ek time par sirf ek block execute hota hai: if ya else.

Basic If Else Example 

let age = 20;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Output:

Adult

Else Block Example 

let age = 15;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Output:

Minor

Yahan 15 >= 18 false hai, isliye else block execute hoga.

Even or Odd Example

Number even hai ya odd check karne ke liye % modulus operator use kar sakte hain. 

let number = 7;

if (number % 2 === 0) {
  console.log("Even Number");
} else {
  console.log("Odd Number");
}

Output:

Odd Number

Student Pass or Fail 

let marks = 35;

if (marks >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

Output:

Fail

Positive or Negative Number 

let number = -10;

if (number >= 0) {
  console.log("Positive Number");
} else {
  console.log("Negative Number");
}

Output:

Negative Number

Find Greater Number 

let a = 50;
let b = 30;

if (a > b) {
  console.log("a is greater");
} else {
  console.log("b is greater");
}

Output:

a is greater

Password Check Example 

let password = "12345";

if (password === "12345") {
  console.log("Password Correct");
} else {
  console.log("Wrong Password");
}

Output:

Password Correct

If Else With Multiple Conditions

&& ka use karke multiple conditions ek saath check kar sakte hain. 

let age = 20;
let hasId = true;

if (age >= 18 && hasId === true) {
  console.log("Entry Allowed");
} else {
  console.log("Entry Not Allowed");
}

Output:

Entry Allowed

Important Points

1. if block tab chalta hai jab condition true ho.

2. else block tab chalta hai jab condition false ho.

3. else ke andar condition nahi likhte.

4. Ek if...else statement me ek time par sirf ek block execute hota hai.

5. Agar 2 se zyada conditions check karni ho to else if use karte hain.

If vs If Else

If If Else
Sirf true condition handle karta hai. True aur false dono conditions handle karta hai.
False hone par kuch execute nahi hota. False hone par else block execute hota hai.
if (condition) if (condition) ... else
