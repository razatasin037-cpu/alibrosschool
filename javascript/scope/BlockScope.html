Block Scope Kya Hai?

JavaScript me Block Scope ka matlab hai ki variable sirf curly braces { } ke andar accessible ho.

let aur const se declare kiye gaye variables block scoped hote hain.

Block Scope Syntax 

{
  let variable = "value";
}

Simple Block Scope Example 

{
  let name = "Ali";

  console.log(name);
}

Output:

Ali

Block Ke Bahar Access

Block ke andar let se bana variable block ke bahar access nahi hota. 

{
  let age = 20;
}

console.log(age);

Result:

ReferenceError

const Bhi Block Scoped Hai 

{
  const city = "Ranchi";

  console.log(city);
}

Output:

Ranchi

Block Scope With If 

if (true) {

  let message = "Hello";

  console.log(message);
}

Output:

Hello

Block Scope With For Loop 

for (let i = 1; i <= 3; i++) {
  console.log(i);
}

Output:

1
2
3

Loop ke bahar i access nahi hoga kyunki let i loop block me scoped hai.

var Block Scoped Nahi Hai

var block scope follow nahi karta. Agar var normal block ke andar declare ho aur koi function boundary na ho, to variable block ke bahar bhi accessible ho sakta hai. 

{
  var city = "Delhi";
}

console.log(city);

Output:

Delhi

let vs var in Block Scope

let / const var
Block scoped hote hain. Block scoped nahi hota.
{ let x = 10; } { var x = 10; }
Block ke bahar x available nahi. Same function/global scope me x accessible ho sakta hai.

Same Variable Name in Different Blocks

Different blocks me same let variable name use kiya ja sakta hai. 

{
  let name = "Ali";
  console.log(name);
}

{
  let name = "Rahul";
  console.log(name);
}

Output:

Ali
Rahul

Variable Shadowing

Inner block me same naam ka variable banaya jaye to inner variable outer variable ko temporarily shadow karta hai. 

let name = "Ali";

{
  let name = "Ahmed";

  console.log(name);
}

console.log(name);

Output:

Ahmed
Ali

Nested Block Scope

Inner block accessible outer block variables ko use kar sakta hai. 

{
  let country = "India";

  {
    let state = "Jharkhand";

    console.log(country);
    console.log(state);
  }
}

Output:

India
Jharkhand

Block Scope Quick Reference

Keyword Block Scoped?
let Yes
const Yes
var No

Important Points

1. Block { } ke andar ka code area hota hai.

2. let aur const block scoped hote hain.

3. var block scoped nahi hota.

4. Block scoped variable ko uske block ke bahar access nahi kar sakte.

5. Inner block outer accessible variables ko use kar sakta hai.

6. Different blocks me same variable name declare kiya ja sakta hai.
