Function Scope Kya Hai?

JavaScript me Function Scope ka matlab hai ki function ke andar declare kiya gaya variable us function ke andar hi accessible hota hai.

Function ke bahar us variable ko directly access nahi kiya ja sakta. var function scoped hota hai, jabki let aur const function ke andar hone ke saath-saath block scope rules bhi follow karte hain.

Function Scope Syntax 

function myFunction() {

  let variable = "value";

}

Simple Function Scope Example 

function showName() {

  let name = "Ali";

  console.log(name);
}

showName();

Output:

Ali

Function Ke Bahar Variable Access

Function ke andar declare variable ko function ke bahar access karne par error aa sakta hai. 

function showName() {

  let name = "Ali";

}

console.log(name);

Result:

ReferenceError

var Is Function Scoped

var function ke andar declare ho to poore function me accessible hota hai. 

function test() {

  if (true) {
    var city = "Ranchi";
  }

  console.log(city);
}

test();

Output:

Ranchi

let Inside Function 

function user() {

  let age = 20;

  console.log(age);
}

user();

Output:

20

Same Variable Name in Different Functions

Different functions apne alag scope rakhte hain. Isliye same variable name alag functions me use kiya ja sakta hai. 

function first() {

  let name = "Ali";

  console.log(name);
}

function second() {

  let name = "Rahul";

  console.log(name);
}

first();
second();

Output:

Ali
Rahul

Nested Function Scope

Inner function apne accessible outer function ke variables ko use kar sakta hai. 

function outer() {

  let name = "Ali";

  function inner() {
    console.log(name);
  }

  inner();
}

outer();

Output:

Ali

Outer Function Inner Variable Access Nahi Kar Sakta 

function outer() {

  function inner() {
    let age = 20;
  }

  inner();

  console.log(age);
}

outer();

Result:

ReferenceError

Parameters Bhi Function Scope Me Hote Hain 

function greet(name) {

  console.log(name);

}

greet("Ali");

Output:

Ali

name parameter function ke andar local variable ki tarah use hota hai.

Global And Function Scope Together 

let country = "India";

function student() {

  let city = "Ranchi";

  console.log(country);
  console.log(city);
}

student();

Output:

India
Ranchi

Function Scope vs Block Scope

Function Scope Block Scope
Function boundary tak limited hota hai. Curly braces block tak limited hota hai.
var function scoped hai. let aur const block scoped hain.
function test() { var x = 10; } { let x = 10; }

Important Points

1. Function ke andar declare variable function ke bahar directly accessible nahi hota.

2. var function scoped hota hai.

3. let aur const block scoped hote hain.

4. Different functions ke local variables alag scopes me hote hain.

5. Inner function accessible outer variables ko use kar sakta hai.

6. Outer function inner function ke local variable ko directly access nahi kar sakta.

7. Function parameters bhi function ke local scope ka part hote hain.
