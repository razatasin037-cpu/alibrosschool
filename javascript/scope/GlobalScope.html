Global Scope Kya Hai?

JavaScript me Global Scope ka matlab hai aisa variable jo kisi function ya block ke local scope ke bahar declare kiya gaya ho.

Global variable ko uske accessible nested functions aur blocks ke andar use kiya ja sakta hai.

Global Scope Syntax 

let variable = "value";

function myFunction() {
  console.log(variable);
}

Simple Global Scope Example 

let name = "Ali";

console.log(name);

Output:

Ali

Global Variable Inside Function

Function apne accessible outer/global scope ke variables ko use kar sakta hai. 

let country = "India";

function showCountry() {

  console.log(country);

}

showCountry();

Output:

India

Global Variable Inside Block 

let city = "Ranchi";

{
  console.log(city);
}

Output:

Ranchi

Global Variable in Multiple Functions

Ek global variable ko multiple functions access kar sakte hain. 

let language = "JavaScript";

function first() {
  console.log(language);
}

function second() {
  console.log(language);
}

first();
second();

Output:

JavaScript
JavaScript

Global Variable Ko Change Karna

Agar global variable let se declare hai, to accessible inner scope uski value change kar sakta hai. 

let count = 1;

function update() {
  count = 2;
}

update();

console.log(count);

Output:

2

Global const Variable 

const country = "India";

function show() {
  console.log(country);
}

show();

Output:

India

Global const ko nested scope se read kiya ja sakta hai, lekin variable ko direct reassignment nahi diya ja sakta.

Global Variable Shadowing

Function ke andar same naam ka local variable banane par local variable global variable ko us scope me shadow karta hai. 

let name = "Ali";

function show() {

  let name = "Rahul";

  console.log(name);
}

show();

console.log(name);

Output:

Rahul
Ali

Global Variable vs Local Variable

Global Variable Local Variable
Outer/global scope me declare hota hai. Function ya block ke andar declare hota hai.
Accessible nested scopes me use ho sakta hai. Apne scope aur accessible nested scopes tak limited hota hai.
let country = "India"; function test() { let city = "Ranchi"; }

Too Many Global Variables Kyu Avoid Kare?

Bahut zyada global variables rakhne se code ke different parts same data ko accidentally change kar sakte hain.

Isliye variables ko jitna possible ho utne limited scope me rakhna code ko easier to understand aur maintain banata hai.

Important Points

1. Global variable outer/global scope me declare hota hai.

2. Accessible nested functions global variable ko use kar sakte hain.

3. Accessible blocks bhi outer variables ko use kar sakte hain.

4. Same naam ka local variable outer/global variable ko shadow kar sakta hai.

5. Global mutable variables ko unnecessary use karna avoid karna better practice hai.

6. Local scope data ko limited area me rakhta hai, jisse code manage karna easy hota hai.
