Scope Kya Hai?

JavaScript me Scope decide karta hai ki koi variable code ke kis part me access kiya ja sakta hai.

Agar koi variable kisi specific block ya function ke andar bana hai, to ho sakta hai ki wo variable uske bahar access na ho sake. JavaScript me mainly Global Scope, Function Scope aur Block Scope important hote hain.

Types of Scope

Scope Meaning
Global Scope Variable code ke large/global area me accessible hota hai.
Function Scope Variable sirf function ke andar accessible hota hai.
Block Scope Variable sirf curly braces { } ke block ke andar accessible hota hai.

Global Scope

Function ya block ke bahar declare kiya gaya variable generally global scope me hota hai. 

let name = "Ali";

function showName() {
  console.log(name);
}

showName();

console.log(name);

Output:

Ali
Ali

Yahan name function ke bahar declare hua hai, isliye function ke andar bhi access ho raha hai.

Function Scope

Function ke andar declare variable normally function ke bahar access nahi hota. 

function student() {

  let name = "Ali";

  console.log(name);
}

student();

Output:

Ali

Agar function ke bahar console.log(name) karenge, to error milega kyunki name function ke andar scoped hai.

Block Scope

let aur const block scoped hote hain. Block ka matlab { } ke andar ka area hai. 

{
  let age = 20;

  console.log(age);
}

Output:

20

Block ke bahar age access nahi kiya ja sakta.

Block Scope With If 

if (true) {

  let message = "Hello";

  console.log(message);
}

Output:

Hello

var Aur Block Scope

var block scoped nahi hota. Ye function scoped hota hai. 

{
  var city = "Ranchi";
}

console.log(city);

Output:

Ranchi

var vs let vs const Scope

Keyword Scope Reassign
var Function scoped Yes
let Block scoped Yes
const Block scoped No direct reassignment

Same Variable Name in Different Scope 

let name = "Ali";

{
  let name = "Rahul";

  console.log(name);
}

console.log(name);

Output:

Rahul
Ali

Dono variables ka naam same hai, lekin dono different scope me hain.

Scope Chain

Agar variable current scope me nahi milta, JavaScript outer scope me us variable ko search karta hai. Is process ko Scope Chain samajh sakte hain. 

let country = "India";

function show() {

  let state = "Jharkhand";

  console.log(country);
  console.log(state);
}

show();

Output:

India
Jharkhand

Local Scope

Function ya block ke andar limited variable ko generally local variable kaha jata hai.

Local variables ka use code ko safer aur manageable banata hai, kyunki unnecessary global variables kam hote hain.

Scope Quick Reference

Variable Location Scope Accessible
Function ke bahar Global Relevant accessible scopes me
Function ke andar Function Function aur nested scopes me
{ } ke andar let/const Block Block aur uske nested scopes me

Important Points

1. Scope decide karta hai variable kaha accessible hoga.

2. Global variable outer/global scope me declare hota hai.

3. Function ke andar declare variable function scope me reh sakta hai.

4. let aur const block scoped hote hain.

5. var block scoped nahi, function scoped hota hai.

6. Inner scope apne accessible outer scope ke variables use kar sakta hai.

7. Unnecessary global variables avoid karna generally better practice hota hai.
