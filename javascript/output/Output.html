JavaScript Output Display Techniques

JavaScript me Data Display ya Output show karne ke mukhya tarike hote hain.

Aap web page elements, alert dialog box, browser console ya direct document output ka use karke result ko user tak pahuncha sakte hain.

innerHTML

HTML element ke andar dynamic text/content insert karne ke liye.

document.write()

Direct HTML output stream me data print karne ke liye.

window.alert()

Browser alert box show karke output pop-up dikhane ke liye.

console.log()

Debugging & testing ke liye browser console par write karne ke liye.

1. Using innerHTML

HTML element ka content badalane ke liye document.getElementById(id) ka upayog karke innerHTML property ko assign kiya jata hai. 

<!DOCTYPE html>
<html>
<body>

  <h2>My First Web Page</h2>
  <p id="demo"></p>

  <script>
    document.getElementById("demo").innerHTML = 5 + 6;
  </script>

</body>
</html>

2. Using document.write()

Testing purpose ke liye document.write() ka use hota hai. Note: HTML document load hone ke BAAD ise run karne se saara purana HTML overwrite/delete ho jata hai. 

<!DOCTYPE html>
<html>
<body>

  <h2>Document Write Example</h2>

  <script>
    document.write(5 + 6);
  </script>

</body>
</html>

3. Using window.alert()

Aap alert box ka use karke output popup show kar sakte hain: 

<!DOCTYPE html>
<html>
<body>

  <script>
    window.alert(5 + 6);
    // Aap sirf alert(5 + 6); bhi likh sakte hain
  </script>

</body>
</html>

4. Using console.log()

Debugging ke liye, aap browser me **F12** daba kar Console tab me values output dekhne ke liye console.log() method ka use kar sakte hain. 

<!DOCTYPE html>
<html>
<body>

  <script>
    console.log(5 + 6);
  </script>

</body>
</html>
