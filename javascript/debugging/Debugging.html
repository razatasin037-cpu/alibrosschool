Debugging Kya Hai?

Programming me code ke andar problem ya bug ko find karke fix karne ke process ko Debugging kehte hain.

JavaScript me debugging ke liye browser console, DevTools, breakpoints aur debugger statement ka use kiya jata hai.

Bug Kya Hota Hai?

Code ke andar aisi problem jiski wajah se program expected result nahi deta, us problem ko bug kehte hain.

Simple Bug Example 

const price =
  100;

const quantity =
  5;

const total =
  price + quantity;

console.log(total);

Wrong Output: 

105

Yahan code run ho raha hai, lekin calculation galat hai. Correct code: 

const total =
  price * quantity;

console.log()

console.log() debugging ka sabse basic aur commonly used method hai. 

const name =
  "Ali";

const age =
  20;

console.log(name);
console.log(age);
Ali
20

Variable ke saath label dene se debugging easy ho jati hai.

console.error()

Error message ko clearly show karne ke liye console.error() use hota hai.

    "User not found"

console.warn()

Warning message show karne ke liye console.warn() use hota hai.

);

Arrays aur objects ko table format me dekhne ke liye console.table() useful hota hai.

  {
    name:
      "Ali",

Useful Console Methods

Method Use
console.log() Normal value check karna
console.error() Error show karna
console.warn() Warning show karna
console.table() Array/Object ko table me show karna
console.clear() Console clean karna

debugger Keyword

JavaScript ka debugger keyword code execution ko temporarily pause karta hai jab browser DevTools open ho. 

const a =
  10;

const b =
  20;

debugger;

const total =
  a + b;

console.log(total);

Browser debugger line par code ko pause karega aur aap variables ki current value check kar sakte ho.

Browser DevTools Open Kaise Karein?

Chrome ya Edge me website open karo.

Keyboard se F12 press karo.

Ya Ctrl + Shift + I press karo.

Uske baad Console ya Sources tab open karo.

Sources Tab

Browser DevTools ka Sources tab JavaScript files ko inspect aur debug karne ke liye use hota hai. Yahin se breakpoints bhi add kiye ja sakte hain.

Breakpoint Kya Hai?

Breakpoint kisi specific line par program execution temporarily pause karta hai. 

const price =
  500;

const quantity =
  2;

const total =
  price * quantity;

console.log(total);

Agar const total wali line par breakpoint lagaya hai to execution wahan pause ho jayega.

Breakpoint Kaise Lagayein?

1. Browser DevTools open karo.

2. Sources tab open karo.

3. Apni JavaScript file select karo.

4. Jis line par code pause karna hai us line number par click karo.

5. Page ko reload ya function ko execute karo.

6. JavaScript us breakpoint par pause ho jayega.

Debugger Controls

Control Meaning
Resume Program ko continue karta hai.
Step Over Next line par jata hai.
Step Into Function ke andar jata hai.
Step Out Current function se bahar aata hai.

Step Over

Step Over current line execute karta hai aur next line par chala jata hai. Agar current line par function call hai to function ke andar enter nahi karta.

Step Into

Step Into function call ke andar jaakar us function ka code line-by-line debug karne deta hai.

Function Debugging Example 

function calculateTotal(
  price,
  quantity
) {

  debugger;

  const total =
    price * quantity;

  return total;

}

const result =
  calculateTotal(
    100,
    5
  );

console.log(result);
500

API Debugging

API response ko console me check karke problem easily find ki ja sakti hai. 

async function getUsers() {

  try {

    const response =
      await fetch(
        
          "https://example.com/users"
        
      );

    console.log(
      
        "Response:"
      ,
      response
    );

    const data =
      await response.json();

    console.log(
      
        "Data:"
      ,
      data
    );

  } catch (error) {

    console.error(
      
        "API Error:"
      ,
      error
    );

  }

}

getUsers();

Debugging Ka Simple Process

1. Error message ko dhyan se read karo.

2. Error kis file aur line par hai wo dekho.

3. Variable values ko console.log() se check karo.

4. Conditions ko individually check karo.

5. Breakpoint ya debugger use karo.

6. API issue ho to Network tab check karo.

7. Problem identify hone ke baad code fix karo.

8. Code ko dubara test karo.

Common Debugging Mistakes

1. Error message read kiye bina code change karna.

2. Har jagah random console.log() lagana.

3. Variable ki actual value check nahi karna.

4. API issue me Network tab check nahi karna.

5. Ek saath bahut sara code change kar dena.

6. Fix ke baad code ko dobara test nahi karna.

Important Points

1. Debugging ka matlab bugs ko find aur fix karna hai.

2. console.log() variable values check karne ke liye useful hai.

3. console.error() errors show karne ke liye useful hai.

4. console.warn() warnings ke liye use hota hai.

5. console.table() arrays aur objects inspect karne me helpful hai.

6. debugger code execution ko pause kar sakta hai.

7. Breakpoints se code line-by-line debug kiya ja sakta hai.

8. API debugging ke liye DevTools ka Network tab bahut important hai.

9. Error ki file, line number aur message ko sabse pehle check karna chahiye.

10. Debugging ek important programming skill hai jo practice se improve hoti hai.
