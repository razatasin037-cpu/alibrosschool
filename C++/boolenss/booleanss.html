C++ Booleans

Boolean Values Kya Hoti Hain?

C++ mein booleans ek aisi data type hai jisme sirf do values ho sakti hain: true (sahi) ya false (galat) .

Boolean variables ko declare karne ke liye bool keyword ka use kiya jata hai.

Boolean Values Declare Karna

Aap `bool` data type ka use karke `true` ya `false` values set kar sakte hain.

Jab aap boolean values ko print karte hain, to output mein true ki jagah 1 aur false ki jagah 0 print hota hai.

Boolean Values Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    bool isCodingFun = true;
    bool isFishTasty = false;

    cout << isCodingFun << endl; // Output: 1
    cout << isFishTasty << endl; // Output: 0

    return 0;
}

Boolean Expressions

Boolean expression ek aisa expression hota hai jo compare hone ke baad boolean value (1 ya 0) return karta hai.

Iske liye comparison operators jaise > (greater than), < (less than), aur == (equal to) ka use hota hai.

Boolean Expressions Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int x = 10;
    int y = 9;

    cout << (x > y) << endl;  // Output: 1 (True kyunki 10, 9 se bada hai)
    cout << (x == 10) << endl; // Output: 1 (True)
    cout << (10 == 15) << endl; // Output: 0 (False)

    return 0;
}

Real Life Example: Age Check

Real life programming mein hum Booleans ka use conditions check karne ke liye karte hain. Jaise ki check karna ki koi person voting ke liye eligible hai ya nahi:

Real Life Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int myAge = 25;
    int votingAge = 18;

    cout << (myAge >= votingAge); // Output: 1 (True, vote de sakta hai)

    return 0;
}

Important

  • Boolean type variable declare karne ke liye `bool` keyword ka use hota hai.
  • Boolean ki do values ho sakti hain: `true` (1) aur `false` (0).
  • C++ cout me `true` ko `1` aur `false` ko `0` ke roop me dikhata hai.
  • Booleans ka sabse bada use `if...else` logic aur conditional statements mein hota hai.
