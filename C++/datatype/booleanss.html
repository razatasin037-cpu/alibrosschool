C++ Booleans

C++ mein Boolean data type ka use sirf do values store karne ke liye hota hai: true ya false.

Boolean data type ko declare karne ke liye bool keyword ka use kiya jata hai.

Boolean Types

Boolean variable sirf do possible values rakh sakta hai: true ya false.

bool isCoding = true;
bool isFinished = false;

Boolean Types

C++ Example
bool isOnline = true;
bool isLoggedIn = false;
cout << isOnline;

Boolean ka Output

Jab hum C++ mein Boolean value ko print karte hain, to true ka output normally 1 aur false ka output 0 hota hai.

bool x = true;
bool y = false;

cout << x;
cout << y;

Is program ka output hoga:

1
0

Boolean ka Output

C++ Example
bool isReady = true;
cout << isReady;

Boolean Expressions

Boolean expressions ka result bhi true ya false hota hai. Example ke liye hum do numbers ko compare kar sakte hain.

int x = 10;
int y = 9;

cout << (x > y);

Yahan x > y check kiya ja raha hai. Kyunki 10, 9 se bada hai, expression ka result true (1) hoga.

1

Boolean Expressions

C++ Example
int age = 20;
bool adult = age >= 18;
cout << adult;

Boolean ke Saath Comparison

Boolean expressions mein comparison operators ka use bahut common hai.

Expression Result
10 > 5 true (1)
5 > 10 false (0)
10 == 10 true (1)
10 == 5 false (0)
10 != 5 true (1)

Boolean ke Saath Comparison

C++ Example
int x = 10;
int y = 20;
bool result = x < y;
cout << result;

Boolean ko if Statement mein use karna

Boolean values ka use if statement ke saath bhi kiya ja sakta hai.

bool isAdult = true;

if (isAdult) {
  cout << "You are an adult.";
}

Yahan isAdult ki value true hai, isliye if ke andar wala code execute hoga.

Short Summary

  • bool ek Boolean data type hai jo sirf true ya false value store karta hai.
  • C++ mein true ko normally 1 aur false ko 0 ke roop mein represent kiya jata hai.
  • Booleans ka sabse zyada use conditional statements (jaise if/else) mein hoga.

Boolean ko if Statement mein use karna

C++ Example
bool isStudent = true;

if (isStudent) {
    cout << "Student hai";
} else {
    cout << "Student nahi hai";
}
