C++ Real-Life Example

Practical Examples

Ab hum C++ ke variables aur data types ko use karke kuch practical real-life examples dekhenge.

In examples se aap samajh sakte hain ki real programs mein variables aur different data types ka use kaise hota hai.

Student Ki Information

Hum ek college student ki ID, age, fees aur grade ko different variables mein store kar sakte hain.

Student Ki Information

C++ Example
int studentID = 15;
int studentAge = 23;
float studentFee = 75.25;
char studentGrade = 'B';

cout << "Student ID: " << studentID << "\n";
cout << "Student Age: " << studentAge << "\n";
cout << "Student Fee: " << studentFee << "\n";
cout << "Student Grade: " << studentGrade;

Rectangle Ka Area

Rectangle ka area nikalne ke liye hum length aur width ko variables mein store kar sakte hain.

Rectangle Ka Area

C++ Example
int length = 4;
int width = 6;
int area = length * width;
cout << "Area: " << area;

Shopping Total Calculate Karna

Shopping system mein items ki quantity aur har item ki price ko store karke total cost calculate kar sakte hain.

Shopping Total Calculate Karna

C++ Example
int items = 50;
double costPerItem = 9.99;
double totalCost = items * costPerItem;
char currency = '$';

cout << "Total cost: " << totalCost << currency;

Welcome Message

String variables ka use karke user ke liye ek simple welcome message bana sakte hain.

Welcome Message

C++ Example
string message = "Good to see you, ";
string name = "Ali";
cout << message + name;

Voting Age Check

Age aur voting age ko compare karke hum check kar sakte hain ki person vote karne ke liye eligible hai ya nahi.

Voting Age Check

C++ Example
int myAge = 25;
int votingAge = 18;

if (myAge >= votingAge) {
    cout << "Old enough to vote!";
} else {
    cout << "Not old enough to vote.";
}

Even Ya Odd Number

Kisi number ko 2 se divide karke check kar sakte hain ki number even hai ya odd.

Even Ya Odd Number

C++ Example
int myNum = 5;

if (myNum % 2 == 0) {
    cout << myNum << " is even.";
} else {
    cout << myNum << " is odd.";
}

Temperature Check

Temperature ki value ko check karke hum bata sakte hain ki weather freezing, cool ya warm hai.

Temperature Check

C++ Example
int temperature = 30;

if (temperature < 0) {
    cout << "It's freezing!";
} else if (temperature < 20) {
    cout << "It's cool.";
} else {
    cout << "It's warm.";
}
