C++ Data Types

C++ mein jab hum koi variable banate hain, to uske data ka type batana zaroori hota hai.

Data type compiler ko batata hai ki variable mein kis type ka data store hoga.

Basic Data Types

C++ Example
int age = 20;
float price = 10.5;
double salary = 25000.75;
char grade = 'A';
bool passed = true;

Basic Data Types

C++ mein kuch commonly used basic data types hain, jaise int, float, double, char aur bool.

Data Type
Use
int
Whole numbers ke liye
float
Decimal numbers ke liye
double
Decimal numbers ke liye zyada precision ke saath
char
Ek single character ke liye
bool
true ya false ke liye

int Data Type

int ka use whole numbers store karne ke liye hota hai. Ismein decimal value nahi hoti.

int Data Type

C++ Example
int age = 20;
cout << age;

float Data Type

float ka use decimal ya fractional numbers store karne ke liye kiya jata hai.

float Data Type

C++ Example
float price = 10.5f;
cout << price;

double Data Type

double bhi decimal numbers store karta hai aur float ke comparison mein zyada precision provide karta hai.

double Data Type

C++ Example
double salary = 25000.75;
cout << salary;

char Data Type

char ka use ek single character store karne ke liye hota hai. Character ko single quotes ke andar likhte hain.

char Data Type

C++ Example
char grade = 'A';
cout << grade;

bool Data Type

bool data type sirf do values store karta hai: true ya false.

bool Data Type

C++ Example
bool isStudent = true;
cout << isStudent;

String Data Type

string ka use text store karne ke liye hota hai.

String Data Type

C++ Example
string name = "Ali";
cout << name;

Important

  • int whole numbers ke liye use hota hai.
  • float aur double decimal numbers ke liye use hote hain.
  • char single character ke liye use hota hai.
  • bool true ya false store karta hai.
  • string text store karne ke liye use hota hai.
