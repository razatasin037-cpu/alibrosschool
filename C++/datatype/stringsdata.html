C++ Strings

C++ mein string ka use text ya characters ka collection store karne ke liye kiya jata hai.

Jaise "Hello World" ek string hai. String ko double quotes " " ke andar likha jata hai.

C++ Strings

C++ Example
string greeting = "Hello";
cout << greeting;

String Variable Banana

String variable banane ke liye string keyword ka use karte hain.

String Variable Banana

C++ Example
string name = "Ali";
cout << name;

<string> Library

C++ mein standard string type use karne ke liye <string> library include karna hota hai.

<string> Library

C++ Example
#include <iostream>
#include <string>
using namespace std;

int main() {
    string greeting = "Hello";
    cout << greeting;
    return 0;
}

String Mein Multiple Words

String mein ek se zyada words, spaces aur punctuation bhi store kiye ja sakte hain.

String Mein Multiple Words

C++ Example
string greeting = "Hello and welcome!";
cout << greeting;

String Print Karna

String ko screen par dikhane ke liye cout ka use kar sakte hain.

String Print Karna

C++ Example
string message = "Welcome to Ali Learning";
cout << message;

String Ko Update Karna

Normal string variable ki value ko baad mein change bhi kiya ja sakta hai.

String Ko Update Karna

C++ Example
string message = "Hello";
cout << message << endl;
message = "Welcome";
cout << message;

Important

  • Text store karne ke liye string use hota hai.
  • String values double quotes ke andar likhi jati hain.
  • String mein multiple words aur spaces ho sakte hain.
  • Standard string use karne ke liye <string> library include karni hoti hai.
  • String ko cout ke through print kar sakte hain.
