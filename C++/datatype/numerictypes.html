C++ Numeric Data Types

Numeric Data Types

C++ mein numbers store karne ke liye mainly int, float aur double ka use kiya jata hai.

Agar number mein decimal nahi hai, to int useful hota hai. Decimal numbers ke liye float ya double use kar sakte hain.

Integer Number

C++ Example
int myNum = 1000;
cout << myNum;

int

int whole numbers store karta hai. Ismein decimal values nahi hoti hain.

int Example

C++ Example
int age = 25;
int score = 100;
cout << age << endl;
cout << score;

float

float decimal ya floating-point numbers store karne ke liye use hota hai.

float Example

C++ Example
float myNum = 5.75;
cout << myNum;

double

double bhi decimal numbers ke liye use hota hai aur float se zyada precision provide karta hai.

double Example

C++ Example
double myNum = 19.99;
cout << myNum;

float vs double

Floating-point number ki precision batati hai ki decimal point ke baad kitne digits accurately store kiye ja sakte hain.

Type
Precision
Use
float
6-7 digits
Decimal values
double
About 15 digits
More precise calculations

float and double

C++ Example
float f = 5.1234567;
double d = 5.123456789012345;
cout << f << endl;
cout << d;

Scientific Numbers

C++ mein floating-point number ko scientific notation mein bhi likh sakte hain.

Iske liye e ya E ka use kiya jata hai.

Scientific Numbers

C++ Example
float f1 = 35e3;
double d1 = 12E4;
cout << f1 << endl;
cout << d1;

Important

  • Whole numbers ke liye int use karein.
  • Decimal numbers ke liye float ya double use karein.
  • double generally float se zyada precision deta hai.
  • Scientific numbers mein e ya E use kar sakte hain.
