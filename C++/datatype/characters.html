C++ Characters

C++ Characters

C++ mein ek single character ko store karne ke liye char data type ka use kiya jata hai.

Character ko single quotes ' ' ke andar likha jata hai.

Basic char Example

C++ Example
char myGrade = 'A';
cout << myGrade;

char Variable Banana

Ek character variable banane ke liye char keyword use karte hain.

Creating a char Variable

C++ Example
char myLetter = 'B';
cout << myLetter;

Single Character

Ek char variable mein sirf ek character store kiya ja sakta hai.

Single Character

C++ Example
char firstLetter = 'A';
char lastLetter = 'Z';
cout << firstLetter << endl;
cout << lastLetter;

Character Output

Character ko screen par show karne ke liye cout ka use kar sakte hain.

Character Output

C++ Example
char letter = 'X';
cout << "Letter: " << letter;

ASCII Values

C++ mein characters ko internally numeric values ke through represent kiya jata hai. In values ko ASCII values kaha jata hai.

ASCII Value

C++ Example
char letter = 'A';
cout << letter << endl;
cout << int(letter);

Character ko Number mein Use Karna

Character ko int ke saath use karne par uski numeric value mil sakti hai.

Character as Number

C++ Example
char letter = 'A';
int number = letter;
cout << number;

Character Change Karna

Agar char variable const nahi hai, to uski value baad mein change ki ja sakti hai.

Changing a char Variable

C++ Example
char letter = 'A';
cout << letter << endl;
letter = 'B';
cout << letter;

Important

  • Single character ke liye char use hota hai.
  • Character ko single quotes ke andar likhte hain.
  • Ek char variable mein ek character store hota hai.
  • Characters ki numeric representation hoti hai.
  • Character ko cout se print kar sakte hain.
