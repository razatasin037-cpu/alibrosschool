C++ auto Keyword

The auto Keyword

C++ mein auto keyword compiler ko variable ka data type automatically detect karne deta hai.

Compiler us value ko dekhta hai jo variable ko assign ki gayi hai aur uske according variable ka type decide karta hai.

Isse code ko short, clean aur easy to read banaya ja sakta hai.

auto x = 5;

cout << x;

The auto Keyword

C++ Example 
auto age = 20;
cout << age;

Normal Type vs auto

Agar humein pata hai ki variable int hai, to normally hum int likhte hain.

Lekin auto use karne par compiler khud type identify kar leta hai.

int x = 5;
auto y = 5;

cout << x << endl;
cout << y;

Normal Type vs auto

C++ Example 
int age = 20;
auto score = 100;
cout << age << endl << score;

Different Data Types ke Saath auto

auto different values ke according different data types automatically select kar sakta hai.

auto myNum = 5;
auto myFloatNum = 5.99f;
auto myDoubleNum = 9.98;
auto myLetter = 'D';
auto myBoolean = true;

Different Data Types ke Saath auto

C++ Example 
auto number = 10;
auto price = 99.99;
auto grade = 'A';
cout << number << endl << price << endl << grade;

auto ko Value Dena Zaroori Hai

auto ko use karte waqt variable ko same time par value assign karni padti hai.

Sirf auto x; likhna valid nahi hai kyunki compiler ko type pata nahi chalega.

auto x = 5;

cout << x;

auto ko Value Dena Zaroori Hai

C++ Example 
auto age = 20;
// auto age;  // value ke bina auto use nahi kar sakte

auto Ka Type Baad Mein Change Nahi Hota

Ek baar auto ne variable ka type determine kar liya, to woh type same rehta hai.

auto x = 5;
x = 10;

cout << x;

auto Ka Type Baad Mein Change Nahi Hota

C++ Example 
auto number = 10;
// number = "Hello";  // type int hi rahega

auto ke Saath Different Values

auto myNum = 5;
auto myFloatNum = 5.99f;
auto myDoubleNum = 9.98;
auto myLetter = 'D';
auto myBoolean = true;

cout << myNum << endl;
cout << myFloatNum << endl;
cout << myDoubleNum << endl;
cout << myLetter << endl;
cout << myBoolean;

auto ke Saath Different Values

C++ Example 
auto age = 20;
auto name = "Ali";
auto price = 99.99;

auto Kab Use Karna Chahiye?

Simple aur easily understandable types ke liye int, double aur doosre basic types directly likhna zyada clear ho sakta hai.

Lekin complex types ke saath auto code ko kaafi clean aur readable bana sakta hai.

auto x = 5;
auto price = 99.99;
auto grade = 'A';

cout << x << endl;
cout << price << endl;
cout << grade;

Important

  • auto variable ka type automatically detect karta hai.
  • auto ke saath value assign karna zaroori hai.
  • Ek baar type decide hone ke baad woh change nahi hota.
  • auto C++11 se available hai.
  • Complex types ke saath auto code ko cleaner bana sakta hai.
