C++ Enums

Enums ka use related named constants ko ek custom type mein represent karne ke liye hota hai.

What is an Enum?

Enumeration (enum) ek special data type hai jisme named constant values ka group define kiya jata hai.

Enum ka use code ko readable banane ke liye kiya ja sakta hai.

Important

Default enum values normally 0 se start hoti hain aur har next item ka value increase hota hai.

Enum Declaration

C++ 
enum Level {
    LOW,
    MEDIUM,
    HIGH
};

Create an Enum Variable

Enum define karne ke baad us enum type ka variable bana sakte ho.

Example: Enum Variable

C++ 
enum Level {
    LOW,
    MEDIUM,
    HIGH
};

Level myLevel = MEDIUM;
cout << myLevel;

Output

1

Assign Custom Values

Enum members ko apni integer values bhi assign kar sakte ho.

Example: Custom Values

C++ 
enum Level {
    LOW = 25,
    MEDIUM = 50,
    HIGH = 75
};

Level myLevel = HIGH;
cout << myLevel;

Output

75

Enum with Switch

Enums switch statement ke saath readable condition handling ke liye useful hote hain.

Example: Enum + Switch

C++ 
enum Level { LOW, MEDIUM, HIGH };

Level level = HIGH;

switch (level) {
    case LOW:
        cout << "Low";
        break;
    case MEDIUM:
        cout << "Medium";
        break;
    case HIGH:
        cout << "High";
        break;
}

Output

High

Enum Names

Enum ke names descriptive rakhna better hota hai, taaki code dekhte hi value ka meaning samajh aaye.

Example: Days

C++ 
enum Day {
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY
};

Important Points

Enum named constants ka group hota hai.

Default values 0 se start ho sakti hain.

Custom integer values assign ki ja sakti hain.

Enums switch statements ke saath useful hote hain.

Important

Enum values ko meaningful names dene se program ki readability improve hoti hai.
