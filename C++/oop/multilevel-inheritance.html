Multilevel Inheritance

Multiple levels par inheritance ka flow aur practical example samjho.

What is Multilevel Inheritance?

Jab ek derived class kisi base class se inherit kare aur us derived class se koi aur class inherit kare, use multilevel inheritance kehte hain.

Example

C++ 
class Animal {
public:
    void eat() { cout << "Eating"; }
};
class Dog : public Animal {};
class Puppy : public Dog {};

int main() {
    Puppy p;
    p.eat();
}
