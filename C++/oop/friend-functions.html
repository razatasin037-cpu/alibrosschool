C++ Friend Functions

Friend functions ke through private aur protected data access karna samjho.

What is a Friend Function?

Friend function class ka member nahi hota, lekin friend keyword se permission milne par private aur protected members access kar sakta hai.

Example

C++ 
class Box {
private:
    int width = 10;
public:
    friend void show(Box b);
};

void show(Box b) { cout << b.width; }

int main() {
    Box b;
    show(b);
}

Declaring a Friend Function

Friend function ko class ke andar friend keyword ke saath declare kiya jata hai. Definition class ke bahar ho sakti hai.

Example

C++ 
class Box {
private:
    int width = 10;
public:
    friend void show(Box b);
};

void show(Box b) { cout << b.width; }

int main() {
    Box b;
    show(b);
}

Important Point

Friend function ko object ke member ki tarah nahi, normal function ki tarah call kiya jata hai.
