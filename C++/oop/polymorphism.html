C++ Polymorphism

Same interface ke different behaviors ko examples ke saath samjho.

What is Polymorphism?

Polymorphism ka meaning many forms hai. Same function ya interface different situations mein different behavior provide kar sakta hai.

Example

C++ 
class Animal {
public:
    virtual void sound() { cout << "Animal sound"; }
};
class Dog : public Animal {
public:
    void sound() override { cout << "Bark"; }
};

int main() {
    Dog d;
    d.sound();
}
