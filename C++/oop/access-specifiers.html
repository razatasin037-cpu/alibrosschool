C++ Access Specifiers

Public, private aur protected members ki accessibility clearly samjho.

What are Access Specifiers?

Access specifiers class ke members ki accessibility control karte hain. C++ mein public, private aur protected main access specifiers hain.

Example

C++ 
class Person {
private:
    int age = 18;
public:
    void show() { cout << age; }
};

int main() {
    Person p;
    p.show();
}

Public

Public members ko class ke bahar valid object ke through access kiya ja sakta hai.

Example

C++ 
class Person {
private:
    int age = 18;
public:
    void show() { cout << age; }
};

int main() {
    Person p;
    p.show();
}

Private

Private members ko class ke bahar directly access nahi kiya ja sakta. Ye data ko protect karne mein useful hain.

Example

C++ 
class Person {
private:
    int age = 18;
public:
    void show() { cout << age; }
};

int main() {
    Person p;
    p.show();
}

Protected

Protected members class ke andar aur derived classes mein accessible hote hain.

Example

C++ 
class Person {
private:
    int age = 18;
public:
    void show() { cout << age; }
};

int main() {
    Person p;
    p.show();
}
