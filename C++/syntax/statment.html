C++ Statements

C++ program mein statements woh instructions hoti hain jo computer ko batati hain ki kya kaam karna hai.

Ek simple C++ program mein multiple statements ho sakte hain, aur normally har statement ke end mein semicolon ; lagaya jata hai.

Statement ko Samjhein

Upar diye gaye program mein cout ek statement hai. Ye screen par Hello World! print karta hai.

Multiple Statements

Ek C++ program mein hum ek se zyada statements likh sakte hain.

Semicolon ;

C++ mein har statement ke end mein semicolon ; lagana important hota hai.

Agar aap semicolon nahi lagate hain, to compiler error de sakta hai.

Important

  • Har statement ko properly end karein.
  • Semicolon ; ko miss na karein.
  • Statements ko alag-alag lines mein likhne se code readable hota hai.
