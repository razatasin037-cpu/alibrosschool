C++ Syntax

C++ program ko samajhne ke liye humein uske basic syntax ko samajhna zaroori hai.

Chaliye neeche diye gaye program ko step-by-step samajhte hain.

C++ Example

Example

C++ 
#include <iostream>

using namespace std;

int main() {

    cout << "Hello World!";

    return 0;
}

Example Ko Samjhein

Line 1: #include <iostream>

Ye ek header file hai jo C++ mein input aur output ke liye zaroori functionality provide karti hai. Isi ki madad se hum cout jaise objects ka use kar sakte hain.

Line 2: using namespace std;

Iska matlab hai ki hum C++ standard library ke objects aur functions ko directly use kar sakte hain.

Line 3: int main()

Ye program ka main function hai. C++ program execution isi function se start hota hai. Jo code { } ke andar hota hai, woh execute hota hai.

Line 4: cout

cout ka use screen par text ya output print karne ke liye kiya jata hai.

Important Notes

  • C++ case-sensitive language hai.
  • Har C++ statement ke end mein ; lagaya jata hai.
  • Compiler spaces ko generally ignore karta hai, lekin spaces aur blank lines code ko readable banate hain.
  • return 0; main function ko successfully end karta hai.

Namespace ko Omit Karna

C++ mein using namespace std; likhna mandatory nahi hai.

Agar hum namespace ko directly use nahi karna chahte hain, to hum std:: ka use kar sakte hain.

Example

Example

C++ 
#include <iostream>

int main() {

    std::cout << "Hello World!";

    return 0;
}

Dono approaches valid hain. Learning ke time using namespace std; code ko short aur easy banata hai. Advanced projects mein std:: explicitly use karna bhi common hai.
