C++ ka Introduction

C++ kya hai?

C++ ek cross-platform language hai jo high-performance applications create karne ke liye use kiya ja sakta hai.

C++ ko Bjarne Stroustrup ne C language ka extension banakar develop kiya tha. Bjarne Stroustrup C++ ke creator hain.

C++ programmers ko system resources aur memory par high level ka control deti hai.

C++ language ko 5 baar major updates mile hain—2011, 2014, 2017, 2020 aur 2023 me. In updates ke baad iske versions ka naam C++11, C++14, C++17, C++20 aur C++23 rakha gaya.

C++ kyu use karein?

C++ duniya ki sabse popular programming languages me se ek hai.

Aaj ke samay me C++ ka use operating systems, Graphical User Interfaces (GUI), games, web browsers aur embedded systems me kiya jata hai.

C++ ek Object-Oriented Programming (OOP) language hai, jo programs ko ek clear structure deti hai aur code ko dobara use (code reuse) karne ki suvidha deti hai. Isse development ka time aur cost dono kam ho jate hain.

C++ ek portable language hai, jiska matlab hai ki isse aise applications develop kiye ja sakte hain jo multiple platforms par chal sakte hain.

C++ ek fast, powerful aur seekhne me aasan programming language hai.

C++ ka C, C#, aur Java se kaafi close relation hai, isliye programmers aasani se in languages ke beech switch kar sakte hain.

Difference between C and C++

C++ ko C language ke extension ke roop me develop kiya gaya tha, aur in dono languages ki syntax kaafi had tak same hai.

The main difference is that C++ supports classes and objects, while C does not.
