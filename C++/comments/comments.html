C++ Comments

Comments ka use C++ code ko explain karne ke liye kiya jata hai. Comments ko compiler ignore karta hai, isliye ye program ke output ko affect nahi karte.

Comments code ko samajhne aur future mein code ko easily maintain karne mein help karte hain.

Single-line Comments

C++ mein single-line comment banane ke liye // ka use kiya jata hai.

// ke baad likha hua poora text comment ban jata hai.

Code ke Upar Comment

Hum kisi code ke upar comment likh kar bata sakte hain ki neeche diya gaya code kya kaam kar raha hai.

Code ke Baad Comment

Comment ko code ke same line mein bhi likha ja sakta hai.

Multi-line Comments

Agar humein multiple lines ko comment karna ho, to /* se comment start aur */ se comment end karte hain.

Multi-line Comment Example

Ek multi-line comment mein hum ek se zyada lines ka explanation likh sakte hain.

Code ko Temporarily Disable Karna

Comments ka use kisi code ko temporarily disable karne ke liye bhi kiya ja sakta hai.

Important

  • Single-line comment ke liye // use hota hai.
  • Multi-line comment ke liye /* */ use hota hai.
  • Comments ko compiler ignore karta hai.
  • Comments code ko samajhne mein help karte hain.
  • Comments ka use code ko temporarily disable karne ke liye bhi kiya ja sakta hai.
