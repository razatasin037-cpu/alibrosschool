C++ Arrays

C++ mein array ka use ek hi variable ke andar multiple values store karne ke liye kiya jata hai.

Agar tumhare paas same type ki bahut saari values hain, to har value ke liye alag variable banane ke bajay array use karna easy hota hai.

Simple Meaning

Array ka matlab hai: "Ek variable mein same type ki multiple values store karna."

Declare an Array

Array declare karne ke liye pehle data type, phir array ka naam aur square brackets ke andar array ka size likha jata hai.

Array Declaration

Syntax 
string cars[4];

Is example mein cars naam ka array banaya gaya hai jo 4 string values store kar sakta hai.

Initialize an Array

Array declare karte waqt uske andar values bhi directly store kar sakte hain.

Array Initialization

C++ 
string cars[4] = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda"
};

Curly braces { } ke andar values comma se separate hoti hain.

Integer Array

Array ke andar numbers bhi store kiye ja sakte hain. Jaise:

Example: Integer Array

C++ 
int myNum[3] = {10, 20, 30};

Yahan myNum array mein 3 integer values store hain.

Access the Elements of an Array

Array ke kisi element ko access karne ke liye uska index number square brackets [ ] ke andar likhte hain.

Important

C++ arrays ka index 0 se start hota hai.

Isliye first element ka index 0, second ka 1, third ka 2 hota hai.

Example 1: Access Array Element

C++ 
string cars[4] = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda"
};

cout << cars[0];

Output

Volvo

Array Index

Neeche dekho ki array ke andar index kaise work karta hai:

Index Value Access
0 Volvo cars[0]
1 BMW cars[1]
2 Ford cars[2]
3 Mazda cars[3]

Change an Array Element

Array ke kisi element ki value ko change karne ke liye uska index use karke new value assign kar sakte hain.

Example 2: Change Array Element

C++ 
string cars[4] = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda"
};

cars[0] = "Opel";

cout << cars[0];

Output

Opel

Arrays and Loops

Array ke saare elements ko ek-ek karke print karne ke liye for loop ka use kar sakte hain.

Example 3: Loop Through an Array

C++ 
string cars[5] = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda",
    "Tesla"
};

for (int i = 0; i < 5; i++) {
    cout << cars[i] << "\n";
}

Output

Volvo
BMW
Ford
Mazda
Tesla

Print Index and Value

Loop ke andar tum index number aur uski value dono ko print kar sakte ho.

Example 4

C++ 
string cars[5] = {
    "Volvo",
    "BMW",
    "Ford",
    "Mazda",
    "Tesla"
};

for (int i = 0; i < 5; i++) {
    cout << i << " = " << cars[i] << "\n";
}

Loop Through Integer Array

Integer array ko bhi for loop ki help se easily traverse kar sakte hain.

Example 5

C++ 
int myNumbers[5] = {
    10,
    20,
    30,
    40,
    50
};

for (int i = 0; i < 5; i++) {
    cout << myNumbers[i] << "\n";
}

The foreach Loop

C++ mein version 11 se for-each loop available hai. Iska use array ke elements ko directly access karne ke liye kiya ja sakta hai.

Example 6: For-Each Loop

C++11 
int myNumbers[5] = {
    10,
    20,
    30,
    40,
    50
};

for (int num : myNumbers) {
    cout << num << "\n";
}

Isme index manually manage karne ki zarurat nahi hoti. Har iteration mein num ke andar next value aa jati hai.

Get the Size of an Array

Array ka total size bytes mein jaanne ke liye sizeof() operator use kiya ja sakta hai.

Example 7: sizeof()

C++ 
int myNumbers[5] = {
    10,
    20,
    30,
    40,
    50
};

cout << sizeof(myNumbers);

Important

sizeof() array ke bytes return karta hai, elements ki count nahi.

Get Array Length

Array mein kitne elements hain ye find karne ke liye array ke total size ko first element ke size se divide kar sakte hain.

Example 8

C++ 
int myNumbers[5] = {
    10,
    20,
    30,
    40,
    50
};

int length =
    sizeof(myNumbers) / sizeof(myNumbers[0]);

cout << length;

Loop Using Array Size

Array ki length ko calculate karke usse loop ki condition mein use karna hard-coded size se zyada useful ho sakta hai.

Example 9

C++ 
int myNumbers[5] = {
    10,
    20,
    30,
    40,
    50
};

int length =
    sizeof(myNumbers) / sizeof(myNumbers[0]);

for (int i = 0; i < length; i++) {
    cout << myNumbers[i] << "\n";
}

Important Points

  • Array ek variable mein multiple values store kar sakta hai.
  • Array ka index 0 se start hota hai.
  • Array elements ko array[index] se access kiya ja sakta hai.
  • Array ke elements ko change bhi kiya ja sakta hai.
  • Arrays ke saath for aur for-each loops commonly use hote hain.
  • sizeof() se array ka memory size aur elements ki count calculate ki ja sakti hai.

Summary

C++ arrays same type ki multiple values ko ek single variable mein store karne ka useful way hain. Array ko declare aur initialize karne ke baad uske elements ko index ke through access aur change kiya ja sakta hai. Loops ki help se array ke saare elements ko easily process kiya ja sakta hai.
