C++ Multidimensional Arrays

Multidimensional array ek array ke andar arrays ko represent karta hai, jaise rows aur columns wali table.

Multidimensional Arrays

2D array ko rows aur columns wali table ki tarah samjha ja sakta hai.

Har additional pair of square brackets ek additional dimension represent karta hai.

Example: 2D Array

C++ 
string letters[2][4] = {
    {"A", "B", "C", "D"},
    {"E", "F", "G", "H"}
};

Access Elements

2D array ke element ko access karne ke liye row aur column dono ke index dene padte hain.

Example: Access Element

C++ 
cout << letters[0][2];

Output

C

Change Elements

Row aur column indexes ke through kisi element ki value change kar sakte hain.

Example: Change Element

C++ 
letters[0][0] = "Z";
cout << letters[0][0];

Output

Z

Loop Through a Multidimensional Array

2D array ko traverse karne ke liye generally har dimension ke liye ek loop use hota hai.

Example: Nested Loops

C++ 
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 4; j++) {
        cout << letters[i][j] << "\n";
    }
}

Output

A
B
C
D
E
F
G
H

Three-Dimensional Array

C++ arrays 3 ya usse zyada dimensions bhi rakh sakte hain, lekin code aur indexing progressively complex ho jati hai.

Example: 3D Array

C++ 
string letters[2][2][2] = {
    {{"A", "B"}, {"C", "D"}},
    {{"E", "F"}, {"G", "H"}}
};
