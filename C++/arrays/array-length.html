C++ Array Length

sizeof() operator ki help se array ka size aur total elements ki count nikal sakte hain.

Get the Size of an Array

sizeof() array ke total size ko bytes mein return karta hai.

Agar int usually 4 bytes ka hai aur array mein 5 elements hain, to total size 20 bytes hoga.

Example: sizeof()

C++ 
int myNumbers[5] = {10, 20, 30, 40, 50};
cout << sizeof(myNumbers);

Output

20

Get Number of Elements

Elements ki count nikalne ke liye total array size ko first element ke size se divide karte hain.

Example: Array Length

C++ 
int myNumbers[5] = {10, 20, 30, 40, 50};
int length = sizeof(myNumbers) / sizeof(myNumbers[0]);
cout << length;

Output

5

Why Use This?

Is approach se loop mein fixed number likhne ke bajay actual array length use kar sakte ho.

Example: Use Length in Loop

C++ 
int length = sizeof(myNumbers) / sizeof(myNumbers[0]);
for (int i = 0; i < length; i++) {
    cout << myNumbers[i] << "\n";
}
