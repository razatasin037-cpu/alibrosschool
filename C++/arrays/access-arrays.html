C++ Access Arrays

Array ke elements ko index number ke through access kiya ja sakta hai.

Access Array Elements

Array ke kisi element ko access karne ke liye uska index square brackets ke andar likhte hain.

C++ arrays ka index 0 se start hota hai. Isliye first element [0] hota hai.

Example: Access First Element

C++ 
string cars[4] = {"Volvo", "BMW", "Ford", "Mazda"};
cout << cars[0];

Output

Volvo

Access Different Elements

Index badalkar array ke different elements ko access kar sakte ho.

Example: Other Elements

C++ 
cout << cars[1];
cout << cars[2];
cout << cars[3];

Output

BMW
Ford
Mazda

Index Table

Ek 4-element array ke indexes 0, 1, 2 aur 3 honge.

Indexes

C++ 
cars[0]  // First
cars[1]  // Second
cars[2]  // Third
cars[3]  // Fourth
