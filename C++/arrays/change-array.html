C++ Change Array Elements

Array ke kisi specific element ki value ko index ke through change kar sakte hain.

Change an Array Element

Kisi element ko change karne ke liye array ke index par new value assign karo.

Example: Change Element

C++ 
string cars[4] = {"Volvo", "BMW", "Ford", "Mazda"};
cars[0] = "Opel";
cout << cars[0];

Output

Opel

Change Multiple Elements

Ek se zyada elements ki values bhi alag-alag indexes par change ki ja sakti hain.

Example: Change Multiple Elements

C++ 
cars[1] = "Audi";
cars[2] = "Kia";
cars[3] = "Tesla";

Remember the Index

Index 0 first element ko represent karta hai. Galat index use karne se desired element change nahi hoga.

Example

C++ 
cars[0] = "Honda";
