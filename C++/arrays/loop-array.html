C++ Loop Through Array

for loop aur foreach loop ki help se array ke saare elements ko easily traverse kar sakte hain.

Loop Through an Array

for loop ka use karke array ke har element ko one by one print kar sakte hain.

Example 1: For Loop

C++ 
string cars[5] = {"Volvo", "BMW", "Ford", "Mazda", "Tesla"};

for (int i = 0; i < 5; i++) {
    cout << cars[i] << "\n";
}

Output

Volvo
BMW
Ford
Mazda
Tesla

Print Index and Value

Loop ke andar index aur value dono print kiye ja sakte hain.

Example 2: Index + Value

C++ 
for (int i = 0; i < 5; i++) {
    cout << i << " = " << cars[i] << "\n";
}

Output

0 = Volvo
1 = BMW
2 = Ford
3 = Mazda
4 = Tesla

The foreach Loop

C++11 se foreach style loop available hai. Ismein index manually manage karne ki zarurat nahi hoti.

Example 3: foreach Loop

C++ 
int myNumbers[5] = {10, 20, 30, 40, 50};

for (int num : myNumbers) {
    cout << num << "\n";
}

Output

10
20
30
40
50
