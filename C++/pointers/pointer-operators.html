C++ Pointer Operators

C++ pointers mein & aur * operators ka use kaise hota hai, examples ke saath samjho.

Pointer Operators

C++ pointers ke saath do important operators use hote hain: & address lene ke liye aur * pointer declare ya dereference karne ke liye.

Important

Yaad rakho: &variable address deta hai, jabki *ptr us address par stored value access karta hai.

The & Operator

& ko address-of operator kaha jata hai. Ye kisi variable ka memory address return karta hai.

Example

C++ 
int number = 50;

cout << &number;

The * Operator for Declaration

Pointer declaration mein * batata hai ki variable ek pointer hai.

Example

C++ 
int number = 50;
int* ptr = &number;

The * Operator for Dereferencing

Existing pointer ke saath * use karne par pointer jis address ko point karta hai, us address ki value milti hai.

Example

C++ 
int number = 50;
int* ptr = &number;

cout << *ptr;

Output

50

Read and Modify with *

Dereference operator se value ko read aur modify dono kar sakte ho.

Example

C++ 
int number = 50;
int* ptr = &number;

cout << *ptr << "\n";

*ptr = 75;

cout << number;

Output

50
75

Address vs Value

ptr pointer mein stored address deta hai, jabki *ptr us address par stored value deta hai.

Example

C++ 
int number = 25;
int* ptr = &number;

cout << ptr << "\n";
cout << *ptr;
