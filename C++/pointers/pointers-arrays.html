C++ Pointers and Arrays

Pointers ka use arrays ke elements ko access, loop aur modify karne ke liye kaise hota hai.

Pointers and Arrays

Pointers ka use arrays ke elements ko access karne ke liye bhi kiya ja sakta hai.

Important

Array name pointer expressions mein first element ke address ko represent kar sakta hai. Isliye pointer arithmetic ke through array elements access kiye ja sakte hain.

Get the Address of Array Elements

Array ke har element ka apna memory address hota hai.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};

cout << &numbers[0] << "\n";
cout << &numbers[1] << "\n";
cout << &numbers[2] << "\n";
cout << &numbers[3];

Array Name and First Element

numbers aur &numbers[0] array ke starting address ko represent kar sakte hain.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};

cout << numbers << "\n";
cout << &numbers[0];

Access the First Element

Array name ko dereference karke first element access kiya ja sakta hai.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};

cout << *numbers;

Output

25

Access Other Elements with Pointer Arithmetic

numbers + 1 next element aur numbers + 2 third element ko refer karta hai.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};

cout << *(numbers + 1) << "\n";
cout << *(numbers + 2);

Output

50
75

Loop Through an Array with a Pointer

Pointer ko array ke saath use karke loop mein elements access kiye ja sakte hain.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};
int* ptr = numbers;

for (int i = 0; i < 4; i++) {
    cout << *(ptr + i) << "\n";
}

Output

25
50
75
100

Change Array Values with Pointers

Pointer expressions ko dereference karke array elements ki values modify bhi ki ja sakti hain.

Example

C++ 
int numbers[4] = {25, 50, 75, 100};

*numbers = 13;
*(numbers + 1) = 17;

cout << *numbers << "\n";
cout << *(numbers + 1);

Output

13
17

Important Points

*numbers first element ko access karta hai.

*(numbers + 1) second element ko access karta hai.

Pointer arithmetic array ke elements ke saath carefully use karna chahiye.

Important

Array ki boundary ke bahar pointer se value access nahi karni chahiye. Pointers ko carefully handle karna zaroori hai.
