C++ Pointers

Pointers memory addresses ko store karte hain. Pointer banana, address lena aur value access karna seekho.

What is a Pointer?

Pointer ek variable hai jo kisi doosre variable ka memory address store karta hai.

C++ mein pointer ko * ke saath declare kiya jata hai aur variable ka address & operator se pointer mein store kiya ja sakta hai.

Example

C++ 
int number = 42;
int* ptr = &number;

cout << number << "\n";
cout << ptr;

Creating a Pointer

Pointer ka type us variable ke type se match hona chahiye jisko pointer point karta hai.

Example

C++ 
string food = "Pizza";
string* ptr = &food;

cout << food << "\n";
cout << &food << "\n";
cout << ptr;

Get the Value Using a Pointer

Pointer jis variable ko point karta hai uski value paane ke liye * dereference operator use hota hai.

Example

C++ 
int number = 42;
int* ptr = &number;

cout << *ptr;

Output

42

Modify a Value Through a Pointer

Dereference operator ke through pointer se original variable ki value change ki ja sakti hai.

Example

C++ 
int number = 42;
int* ptr = &number;

*ptr = 100;

cout << number;

Output

100

Three Ways to Declare a Pointer

Pointer declaration ke ye teen styles valid hain. Pehla style commonly preferred hai.

Example

C++ 
int* ptr1;
int *ptr2;
int * ptr3;

Important Points

Pointer memory address store karta hai.

& address-of operator hai aur * dereference operator hai.

Pointer ka type pointed variable ke type se compatible hona chahiye.

Important

Pointers ko carefully handle karo, kyunki invalid memory access program mein bugs ya crashes cause kar sakta hai.
