C++ Comparison Operators

Comparison Operators

C++ mein comparison operators ka use do values ko compare karne ke liye kiya jata hai.

Comparison ka result true ya false hota hai.

Operator
Name
Example
==
Equal to
5 == 5
!=
Not equal
5 != 3
>
Greater than
5 > 3
<
Less than
3 < 5
>=
Greater or equal
5 >= 5
<=
Less or equal
3 <= 5

Equal To (==)

== check karta hai ki dono values equal hain ya nahi.

Equal To (==)

C++ Example
int x = 10;
int y = 10;
cout << (x == y);

Not Equal (!=)

!= check karta hai ki dono values different hain ya nahi.

Not Equal (!=)

C++ Example
int x = 10;
int y = 5;
cout << (x != y);

Greater Than (>)

> check karta hai ki left value right value se badi hai ya nahi.

Greater Than (>)

C++ Example
int x = 10;
int y = 5;
cout << (x > y);

Less Than (<)

< check karta hai ki left value right value se chhoti hai ya nahi.

Less Than (<)

C++ Example
int x = 5;
int y = 10;
cout << (x < y);

Greater Than or Equal To (>=)

>= check karta hai ki value greater hai ya equal hai.

Greater Than or Equal To (>=)

C++ Example
int age = 18;
cout << (age >= 18);

Less Than or Equal To (<=)

<= check karta hai ki value smaller hai ya equal hai.

Less Than or Equal To (<=)

C++ Example
int age = 16;
cout << (age <= 18);

Comparison With Variables

Comparison operators ko variables ke saath bhi use kar sakte hain.

Comparison With Variables

C++ Example
int marks = 80;
int passMarks = 40;
cout << (marks >= passMarks);

Comparison in if Statement

Comparison operators ka use if statement mein conditions check karne ke liye bahut common hai.

Comparison in if Statement

C++ Example
int age = 20;
if (age >= 18) {
    cout << "Adult";
}

Important

  • == equal values check karta hai.
  • != different values check karta hai.
  • > greater than check karta hai.
  • < less than check karta hai.
  • >= greater ya equal check karta hai.
  • <= less ya equal check karta hai.
  • Comparison ka result true ya false hota hai.
