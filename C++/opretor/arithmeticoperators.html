C++ Arithmetic Operators

Arithmetic Operators

C++ mein arithmetic operators ka use mathematical calculations perform karne ke liye kiya jata hai.

Inki madad se hum addition, subtraction, multiplication, division aur remainder jaise calculations kar sakte hain.

Operator
Name
Example

Addition (+)

Plus + operator ka use do ya usse zyada values ko add karne ke liye hota hai.

Addition (+)

C++ Example
int x = 10;
int y = 5;
cout << x + y;

Subtraction (-)

Minus - operator ka use ek value mein se doosri value ko subtract karne ke liye hota hai.

Subtraction (-)

C++ Example
int x = 10;
int y = 5;
cout << x - y;

Multiplication (*)

Asterisk * operator multiplication ke liye use hota hai.

Multiplication (*)

C++ Example
int x = 10;
int y = 5;
cout << x * y;

Division (/)

Slash / operator division ke liye use hota hai.

Division (/)

C++ Example
int x = 10;
int y = 5;
cout << x / y;

Modulus (%)

Modulus % operator division ke baad remaining remainder deta hai.

Modulus (%)

C++ Example
int x = 10;
int y = 3;
cout << x % y;

Increment (++)

Increment ++ operator variable ki value ko 1 se increase karta hai.

Increment (++)

C++ Example
int x = 5;
x++;
cout << x;

Decreement (--)

Decrement -- operator variable ki value ko 1 se decrease karta hai.

Decrement (--)

C++ Example
int x = 5;
x--;
cout << x;

Arithmetic Operators ka Example

Ab ek example mein multiple arithmetic operators ko ek saath use karte hain.

Arithmetic Operators ka Example

C++ Example
int a = 10;
int b = 3;
cout << a + b << endl;
cout << a - b << endl;
cout << a * b << endl;
cout << a / b << endl;
cout << a % b;

Important

  • + addition ke liye use hota hai.
  • - subtraction ke liye use hota hai.
  • * multiplication ke liye use hota hai.
  • / division ke liye use hota hai.
  • % remainder nikalne ke liye use hota hai.
  • ++ value ko 1 se increase karta hai.
  • -- value ko 1 se decrease karta hai.
