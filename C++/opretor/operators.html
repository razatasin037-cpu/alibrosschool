C++ Operators

C++ mein operators ka use variables aur values ke saath different operations perform karne ke liye kiya jata hai.

Jaise addition, subtraction, comparison aur logical conditions ke liye different operators available hain.

C++ Operators

C++ Example
int x = 10;
int y = 5;
cout << x + y;

Arithmetic Operators

Arithmetic operators ka use mathematical calculations ke liye hota hai.

Arithmetic Operators

C++ Example
int x = 10;
int y = 5;
cout << x + y;

Assignment Operator

Assignment operator = ka use kisi variable ko value assign karne ke liye hota hai.

Assignment Operator

C++ Example
int x = 10;
x += 5;
cout << x;

Comparison Operators

Comparison operators do values ko compare karte hain aur result ke roop mein true ya false dete hain.

Comparison Operators

C++ Example
int x = 10;
int y = 5;
cout << (x > y);

Logical Operators

Logical operators ka use multiple conditions ko combine karne ke liye kiya jata hai.

Logical Operators

C++ Example
bool a = true;
bool b = false;
cout << (a && b);

Increment Operator

Increment operator ++ variable ki value ko 1 se increase karta hai.

Increment Operator

C++ Example
int x = 5;
x++;
cout << x;

Decrement Operator

Decrement operator -- variable ki value ko 1 se decrease karta hai.

Decrement Operator

C++ Example
int x = 5;
x--;
cout << x;

Important

  • Arithmetic operators calculations ke liye use hote hain.
  • Assignment operator value assign karta hai.
  • Comparison operators result mein true ya false dete hain.
  • Logical operators multiple conditions ko combine karte hain.
  • ++ value ko 1 se increase karta hai.
  • -- value ko 1 se decrease karta hai.
