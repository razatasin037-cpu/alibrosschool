C++ Assignment Operators

Assignment Operators

C++ mein assignment operators ka use kisi variable ko value assign karne ke liye kiya jata hai.

Sabse basic assignment operator = hai.

Assignment Operators

C++ Example
int x = 10;
cout << x;

Basic Assignment (=)

Equal = operator variable ke andar value store karta hai.

Basic Assignment (=)

C++ Example
int x = 10;
cout << x;

Add and Assign (+=)

+= operator variable mein value add karke result ko usi variable mein store karta hai.

Add and Assign (+=)

C++ Example
int x = 10;
x += 5;
cout << x;

Subtract and Assign (-=)

-= operator variable se value subtract karta hai aur result ko usi variable mein store karta hai.

Subtract and Assign (-=)

C++ Example
int x = 10;
x -= 3;
cout << x;

Multiply and Assign (*=)

*= operator variable ko kisi value se multiply karta hai.

Multiply and Assign (*=)

C++ Example
int x = 10;
x *= 2;
cout << x;

Divide and Assign (/=)

/= operator variable ko kisi value se divide karta hai.

Divide and Assign (/=)

C++ Example
int x = 10;
x /= 2;
cout << x;

Modulus and Assign (%=)

%= operator division ke baad bacha hua remainder variable mein store karta hai.

Modulus and Assign (%=)

C++ Example
int x = 10;
x %= 3;
cout << x;

Multiple Assignment Operators

Ek program mein hum different assignment operators ko ek saath bhi use kar sakte hain.

Multiple Assignment Operators

C++ Example
int x = 10;
x += 5;
x *= 2;
x -= 4;
cout << x;

Important

  • = value assign karta hai.
  • += value add karke assign karta hai.
  • -= value subtract karke assign karta hai.
  • *= value multiply karke assign karta hai.
  • /= value divide karke assign karta hai.
  • %= remainder calculate karke assign karta hai.
