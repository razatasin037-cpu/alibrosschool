C++ Logical Operators

Logical Operators

C++ mein logical operators ka use multiple conditions ko combine karne ke liye kiya jata hai.

Logical operators ka result true ya false hota hai.

Operator
Name
Meaning
&&
AND
Dono conditions true honi chahiye
||
OR
Kam se kam ek condition true honi chahiye
!
NOT
Result ko ulta kar deta hai

AND Operator (&&)

AND operator && tab true return karta hai jab dono conditions true hoti hain.

AND Operator (&&)

C++ Example
bool a = true;
bool b = true;
cout << (a && b);

AND Operator Example

Maan lo kisi person ki age 18 ya usse zyada honi chahiye aur uske paas ID bhi honi chahiye.

AND Operator Example

C++ Example
int age = 20;
bool hasID = true;
cout << (age >= 18 && hasID);

OR Operator (||)

OR operator || tab true return karta hai jab kam se kam ek condition true hoti hai.

OR Operator (||)

C++ Example
bool a = true;
bool b = false;
cout << (a || b);

OR Operator Example

Agar student ke marks 90 se zyada hain ya uska grade A hai, to hum usko special category mein rakh sakte hain.

OR Operator Example

C++ Example
int age = 16;
bool hasParent = true;
cout << (age >= 18 || hasParent);

NOT Operator (!)

NOT operator ! boolean result ko ulta kar deta hai.

NOT Operator (!)

C++ Example
bool isReady = true;
cout << !isReady;

NOT Operator Example

NOT Operator Example

C++ Example
bool isLoggedIn = false;
cout << !isLoggedIn;

Multiple Logical Operators

Ek hi condition mein multiple logical operators ko bhi combine kiya ja sakta hai.

Multiple Logical Operators

C++ Example
int age = 20;
bool hasID = true;
bool member = false;
cout << (age >= 18 && hasID || member);

Logical Operators with if

Logical operators ka sabse common use if statement ke saath hota hai.

Logical Operators with if

C++ Example
int age = 20;
bool hasID = true;

if (age >= 18 && hasID) {
    cout << "Allowed";
}

Important

  • && ka matlab AND hai.
  • || ka matlab OR hai.
  • ! ka matlab NOT hai.
  • AND mein dono conditions true honi chahiye.
  • OR mein kam se kam ek condition true honi chahiye.
  • NOT condition ke result ko reverse karta hai.
