C++ Structures

Structures ka use related variables ko ek single custom data type mein group karne ke liye hota hai.

What is a Structure?

C++ structure (struct) ek custom data type hai jo multiple related variables ko ek jagah group karta hai.

Array ke unlike, structure ke andar different data types jaise int, string aur bool ek saath rakhe ja sakte hain.

Important

Structure ke andar har variable ko member kaha jata hai.

Structure Declaration

C++ 
struct Student {
    string name;
    int age;
    char grade;
};

Create a Structure Variable

Structure define karne ke baad us structure ke type ka variable bana sakte ho.

Create Variable

C++ 
struct Student {
    string name;
    int age;
};

Student s1;

Access Structure Members

Structure ke members ko access karne ke liye dot (.) operator use hota hai.

Example: Access Members

C++ 
s1.name = "Ali";
s1.age = 20;

cout << s1.name << "\n";
cout << s1.age;

Output

Ali
20

Multiple Structure Variables

Ek hi structure type se multiple variables create kiye ja sakte hain.

Example: Multiple Variables

C++ 
Student s1;
Student s2;

s1.name = "Ali";
s2.name = "Rahul";

cout << s1.name << "\n";
cout << s2.name;

Output

Ali
Rahul

Initialize a Structure

Structure variable ko declaration ke time curly braces ke through initialize bhi kar sakte hain.

Example: Initialization

C++ 
Student s1 = {"Ali", 20, 'A'};

cout << s1.name << "\n";
cout << s1.age << "\n";
cout << s1.grade;

Output

Ali
20
A

Structure with Different Data Types

Structure ka main benefit ye hai ki related information ko different data types ke saath ek object mein rakh sakte ho.

Example: Car Structure

C++ 
struct Car {
    string brand;
    string model;
    int year;
    bool electric;
};

Car car1 = {"Tesla", "Model 3", 2025, true};

Structure Array

Structures ka array bhi bana sakte hain. Ye multiple records store karne ke liye useful hai.

Example: Array of Structures

C++ 
Student students[2] = {
    {"Ali", 20, 'A'},
    {"Sara", 19, 'B'}
};

cout << students[0].name << "\n";
cout << students[1].name;

Output

Ali
Sara

Important Points

Structure related data ko group karta hai.

Members ko dot operator se access kiya jata hai.

Ek named structure ko multiple variables ke liye reuse kar sakte ho.

Structures arrays ke andar bhi use kiye ja sakte hain.

Important

Structures tab useful hote hain jab ek entity ki multiple properties ko ek saath represent karna ho.
