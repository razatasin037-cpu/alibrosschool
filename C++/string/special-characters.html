C++ Special Characters

Special Characters kya hain?

C++ strings ke andar kuch characters ka special meaning hota hai.

Aise characters ko directly use karne ke liye hum escape sequences ka use kar sakte hain.

Escape sequence hamesha backslash (\) se start hota hai.

Double Quotes

Agar string ke andar double quotes " " print karne hain, to \" ka use karte hain.

Example: Double Quotes

Example

C++ 
string text = "He said \"Hello\"";

cout << text;

New Line

Text ko new line par le jane ke liye \n escape sequence ka use karte hain.

Isse cout ke output mein text next line se start hota hai.

Example: New Line

Example

C++ 
cout << "Hello\nWorld";

Tab Character

Text ke beech tab space dene ke liye \t ka use kiya jata hai.

Example: Tab

Example

C++ 
cout << "Hello\tWorld";

Backslash

Agar string ke andar actual backslash \ print karna ho, to \\ ka use karte hain.

Example: Backslash

Example

C++ 
cout << "C:\\Users\\Tasin";

Single Quote

Single quote ko string ke andar likhne ke liye normally directly use kiya ja sakta hai.

Lekin escape sequence \' ka use bhi kiya ja sakta hai.

Example: Single Quote

Example

C++ 
string text = "It's C++";

cout << text;

Common Escape Sequences

C++ mein kuch commonly used escape sequences neeche diye gaye hain.

Quick Reference

Example

C++ 
\n   New Line
\t   Tab
\"   Double Quote
\\   Backslash
\'   Single Quote

Complete Example

Ab ek complete example dekhte hain jisme multiple escape sequences ka use kiya gaya hai.

Main Program

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main()
{
    cout << "Hello\n";
    cout << "Welcome to C++\n";
    cout << "Name:\tTasin\n";
    cout << "Message: \"Hello World\"";

    return 0;
}

Important

  • Escape sequence backslash \ se start hota hai.
  • New line ke liye \n use hota hai.
  • Tab ke liye \t use hota hai.
  • Double quote ke liye \" use hota hai.
  • Backslash print karne ke liye \\ use hota hai.
