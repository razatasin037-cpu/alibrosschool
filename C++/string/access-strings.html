C++ Access Strings

String ke Characters ko Access Karna

C++ mein string ke andar maujood kisi particular character ko access kiya ja sakta hai.

Character ko access karne ke liye index number ka use kiya jata hai.

String ka first character hamesha index 0 par hota hai.

String Index

Maan lijiye string hai "Hello" .

Is string ke characters ki position 0 se start hogi.

Isliye H ka index 0, e ka index 1 aur l ka index 2 hoga.

String Index

Example

C++ 
string text = "Hello";

cout << text[0];
cout << text[1];
cout << text[2];

First Character Access Karna

First character ko access karne ke liye index 0 ka use karte hain.

Access First Character

Example

C++ 
string text = "Hello";

cout << text[0];

Kisi Bhi Character ko Access Karna

Aap kisi bhi character ko uske index number ka use karke access kar sakte hain.

Example mein index 1 par maujood character ko access kiya gaya hai.

Access a Character

Example

C++ 
string text = "Hello";

cout << text[1];

Character ko Change Karna

String ke kisi character ko uske index ke through change bhi kiya ja sakta hai.

Iske liye index ke saath = operator ka use karte hain.

Change a Character

Example

C++ 
string text = "Hello";

text[0] = 'J';

cout << text;

Last Character Access Karna

String ke last character ko access karne ke liye uske last index ka use kar sakte hain.

Last index nikalne ke liye string ki length se 1 minus karte hain.

Access Last Character

Example

C++ 
string text = "Hello";

cout << text[text.length() - 1];

String ke Characters ko Loop Karna

String ke har character ko ek-ek karke access karne ke liye loop ka use kiya ja sakta hai.

Isse poori string ke characters ko ek saath process ya print kar sakte hain.

Loop Through a String

Example

C++ 
string text = "Hello";

for (int i = 0; i < text.length(); i++)
{
    cout << text[i];
}

Complete Example

Neeche ek complete example hai jisme string ke characters ko access aur modify kiya gaya hai.

Complete Example

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main()
{
    string text = "Hello";

    cout << "First character: "
         << text[0] << endl;

    text[0] = 'J';

    cout << "New string: "
         << text;

    return 0;
}

Important

  • String ka first character index 0 par hota hai.
  • Characters ko index number ke through access kar sakte hain.
  • String ke characters ko change bhi kiya ja sakta hai.
  • Last character ka index string ki length se 1 kam hota hai.
  • Loop ka use karke string ke har character ko access kiya ja sakta hai.
