C++ C-Style Strings

C-Style Strings kya hain?

C++ mein C-style strings ko char type ke through create kiya jata hai.

Ismein characters ka ek array banaya jata hai aur usmein string store ki jati hai.

C-style string ka concept C language se aaya hai.

C-Style String Banana

#include <iostream>
using namespace std;

int main() {
    char name[] = "Ali";
    cout << name;
    return 0;
}

Char Array se String Banana

C-style string banane ke liye char array ka use kiya jata hai.

Array ke andar string ke characters store hote hain.

Char Array Example

char city[] = "Ranchi";
cout << city;

String aur C-Style String

C++ mein normal string type aur C-style string dono use kiye ja sakte hain.

Normal string ke liye string type use hota hai, jabki C-style string ke liye char array use hota hai.

Normal String vs C-Style String

#include <iostream>
#include <string>
using namespace std;

int main() {
    string normal = "Hello";
    char cstyle[] = "Hello";

    cout << normal << endl;
    cout << cstyle;

    return 0;
}

Character Array

C-style string actually characters ka ek array hota hai.

Isliye ise array ki tarah bhi access kiya ja sakta hai.

Character Array Example

char word[] = "Hello";

cout << word[0];
cout << word[1];

Characters ko Access Karna

C-style string ke individual characters ko index number ke through access kiya ja sakta hai.

First character ka index 0 hota hai.

Access Characters Example

char text[] = "Hello";

cout << text[0];
cout << text[4];

Character ko Change Karna

C-style string ke character ko index ke through change bhi kiya ja sakta hai.

Modify Character Example

char text[] = "Hello";

text[0] = 'Y';

cout << text;

C-Style String Functions

C-style strings ke saath C standard library ke kuch functions bhi use kiye ja sakte hain.

In functions ke liye <cstring> header file commonly use ki jati hai.

cstring Example

#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char text[] = "Hello";
    cout << strlen(text);
    return 0;
}

strlen() Function

C-style string ki length check karne ke liye strlen() function ka use kiya ja sakta hai.

strlen() Example

#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char name[] = "Ali";
    cout << "Length: " << strlen(name);
    return 0;
}

Complete Example

Neeche ek complete example hai jisme C-style string create karke usko print kiya gaya hai.

Complete C-Style String Example

#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char name[] = "Ali Learning";

    cout << "Name: " << name << endl;
    cout << "Length: " << strlen(name);

    return 0;
}

Important

  • C-style string ko char array se create kiya jata hai.
  • C-style string characters ka array hota hai.
  • Individual characters ko index ke through access kiya ja sakta hai.
  • C standard library ke string functions bhi use kiye ja sakte hain.
  • Normal string type generally use karna zyada convenient hota hai.
