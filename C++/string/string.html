C++ Strings

C++ Strings kya hain?

C++ mein Strings ka use text ya characters ko store karne ke liye kiya jata hai.

Example ke liye "Hello World" ek string hai.

String ke andar ek ya ek se zyada characters, words aur spaces store kiye ja sakte hain.

C++ mein string value ko double quotes ke andar likha jata hai.

Simple String

Ek simple string variable banane ke liye string keyword ka use kiya jata hai.

Example mein hum greeting naam ka variable banakar usme "Hello" store kar rahe hain.

String Variable Declaration

Example

C++ 
string greeting = "Hello";

String Library

C++ mein string ko properly use karne ke liye <string> header file include ki ja sakti hai.

Iske baad hum string data type ka use kar sakte hain.

Header File Inclusion

Example

C++ 
#include <string>

C++ String Example

Ab ek complete example dekhte hain jisme ek string variable banakar usko screen par print kiya gaya hai.

Complete String Program

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main() {
    string greeting = "Hello World";
    cout << greeting << endl;
    return 0;
}

String ko Print Karna

String ko output screen par dikhane ke liye cout ka use kiya ja sakta hai.

Printing a String

Example

C++ 
string myText = "Learning C++";
cout << myText;

Multiple Words

String ke andar multiple words bhi store kiye ja sakte hain.

Words ke beech spaces bhi rakhe ja sakte hain.

String mein punctuation marks jaise ! bhi use kiye ja sakte hain.

Storing Sentences

Example

C++ 
string sentence = "C++ is an awesome language!";

Spaces aur Punctuation

String mein words ke beech spaces aur punctuation dono store kiye ja sakte hain.

Punctuation & Spaces

Example

C++ 
string text = "Hello, World! How are you?";

Important

  • String ka use text store karne ke liye hota hai.
  • String value ko double quotes ke andar likha jata hai.
  • String ke andar multiple words store kiye ja sakte hain.
  • String mein spaces bhi store kiye ja sakte hain.
  • String mein punctuation marks bhi use kiye ja sakte hain.
  • String ko print karne ke liye cout ka use kar sakte hain.
