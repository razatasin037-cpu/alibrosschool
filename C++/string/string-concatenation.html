C++ String Concatenation

String Concatenation

C++ mein do ya usse zyada strings ko ek saath jodne ko String Concatenation kaha jata hai.

Strings ko join karne ke liye hum + operator ka use kar sakte hain.

Basic Concatenation

Example

C++ 
string firstName = "Ali";
string lastName = "Learning";

string fullName = firstName + lastName;

cout << fullName;

Do Strings ko Join Karna

Maan lo hamare paas first name aur last name alag-alag strings mein hain. Hum dono ko + operator se join kar sakte hain.

Joining Two Strings

Example

C++ 
string firstName = "Tasin";
string lastName = "Raza";

cout << firstName + lastName;

Strings ke Beech Space

Agar do strings ko join karte waqt unke beech space chahiye, to hum ek separate space string add kar sakte hain.

Concatenation with Space

Example

C++ 
string firstName = "Tasin";
string lastName = "Raza";

string fullName = firstName + " " + lastName;

cout << fullName;

Multiple Strings ko Join Karna

Hum ek se zyada strings ko bhi ek saath concatenate kar sakte hain.

Multiple Strings

Example

C++ 
string firstName = "Ali";
string lastName = "Learning";
string country = "India";

string result = firstName + " " + lastName + " " + country;

cout << result;

String Variable mein Result Store Karna

Concatenation ka result ek naye string variable mein bhi store kiya ja sakta hai.

Store the Result

Example

C++ 
string first = "Hello";
string second = "World";

string message = first + " " + second;

cout << message;

String ko += se Join Karna

Existing string mein doosri string add karne ke liye += operator ka use bhi kar sakte hain.

Using +=

Example

C++ 
string text = "Hello";

text += " World";

cout << text;

Complete Example

Neeche ek complete example hai jisme multiple strings ko combine kiya gaya hai.

Complete Example

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main() {
    string firstName = "Ali";
    string lastName = "Learning";

    string fullName = firstName + " " + lastName;

    cout << "Name: " << fullName;

    return 0;
}

Important

  • String concatenation ka matlab strings ko join karna hai.
  • Strings ko join karne ke liye + operator use kar sakte hain.
  • Multiple strings ko ek saath concatenate kiya ja sakta hai.
  • Space ke liye " " add karna hota hai.
  • += se existing string mein doosri string add kar sakte hain.
