C++ String Length

String Ki Length Kaise Nikalein?

C++ mein kisi string ki length (characters ki ginti) nikalne ke liye hum length() ya size() function ka use karte hain.

Dono functions bilkul ek hi tarah kaam karte hain aur aap apni pasand ke hisab se kisi ka bhi use kar sakte hain.

length() Function Example

Example

C++ 
string txt = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
cout << "Length: " << txt.length(); // Output: 26

length() vs size()

Aapko length() aur size() mein koi farq nahi milega. Dono function exact same result dete hain.

size() Function Example

Example

C++ 
string txt = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";
cout << "Length: " << txt.size(); // Output: 26

Spaces Aur Special Characters

Length count karte waqt C++ **spaces** aur **special characters** ko bhi count karta hai.

Spaces Count Example

Example

C++ 
string greeting = "Hello World!";
cout << greeting.length(); // Output: 12 (Space aur '!' bhi count hoga)

Example

Neeche poora program diya gaya hai jisme string length nikal kar print ki gayi hai.

Complete Program

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main() {
    string fullName = "Ali Learning";

    // length() ka use
    cout << "Length using length(): " << fullName.length() << endl;

    // size() ka use
    cout << "Length using size(): " << fullName.size() << endl;

    return 0;
}

Important Points

  • String ki length jaan-ne ke liye .length() ya .size() dono mein se kisi ka bhi use kar sakte hain.
  • Dono functions bilkul alias (same) hain, inke output mein koi differece nahi hota.
  • Spaces, numbers, aur special symbols (`!`, `@`, `#`) sabhi characters ke roop mein count hote hain.
