C++ Numbers and Strings

Numbers and Strings

C++ mein numbers aur strings alag-alag data types hote hain. Number ke saath hum mathematical calculations kar sakte hain, jabki string text ko store karti hai.

Agar number ko quotes ke andar likh diya jaye, to C++ usse number ki jagah ek string samajhta hai.

Numbers vs Strings

Example

C++ 
int x = 10;       // Number (Integer)
string y = "10";   // String (Text)

Number aur String mein Difference

Example ke liye 25 ek number hai, lekin "25" ek string hai.

Difference Example

Example

C++ 
int myNum = 25;       // Numeric operations possible
string myText = "25"; // String concatenation possible

Numbers ke Saath Calculation

Jab value integer ya kisi numeric type mein hoti hai, to hum uske saath mathematical operations perform kar sakte hain.

Numeric Calculation

Example

C++ 
int x = 10;
int y = 20;
int z = x + y;   // Output: 30

String ke Saath Calculation

String ke saath normal mathematical calculation nahi hoti. String ko + operator ke saath concatenate kiya ja sakta hai.

String Concatenation

Example

C++ 
string x = "10";
string y = "20";
string z = x + y; // Output: 1020

Number ko String ki Tarah Use Karna

Agar number ko double quotes ke andar likhte hain, to wo string ban jata hai.

Number in Quotes

Example

C++ 
string strNum = "100"; // Treat as string text

String ke Saath Number

Number ko string ke saath output mein combine karna bhi possible hai.

Output Combination

Example

C++ 
string text = "Result is: ";
int number = 50;

cout << text << number; // Output: Result is: 50

Example

Neeche number aur string ko ek program mein use kiya gaya hai.

Complete Program

Example

C++ 
#include <iostream>
#include <string>

using namespace std;

int main() {
    int num1 = 10;
    int num2 = 20;
    cout << "Sum of numbers: " << num1 + num2 << endl;

    string str1 = "10";
    string str2 = "20";
    cout << "Concatenation of strings: " << str1 + str2 << endl;

    return 0;
}

Important

  • 25 ek number hai.
  • "25" ek string hai.
  • Numbers ke saath mathematical operations kiye ja sakte hain.
  • Strings ko + operator se join kiya ja sakta hai.
  • Quotes ke andar likha hua number string ke roop mein treat hota hai.
