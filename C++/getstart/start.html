Get Started With C++

Ali Learning par aap bina kuch install kiye C++ ko try kar sakte hain.

Hamara Online C++ Editor seedha aapke browser mein chalta hai aur code ke saath-saath uska result bhi dikhata hai.

Install C++

Agar aap apne computer par C++ chalana chahte hain, to aapko do cheezon ki zarurat hogi:

  • Ek Text Editor , jaise Notepad, jisme aap C++ code likh sakte hain.
  • Ek Compiler , jaise GCC, jo C++ code ko computer ki samajh mein aane wali language mein convert karta hai.

Bahut saare Text Editors aur Compilers available hain. Agle steps mein hum aapko ek IDE use karna sikhayenge, jisme dono cheezein shamil hoti hain.

Chaliye apni pehli C++ file banate hain.

Sabse pehle Codeblocks open kijiye aur File > New > Empty File par jaiye.

Ab neeche diya gaya C++ code likhiye aur file ko myfirstprogram.cpp ke naam se save kijiye. (File > Save File As)

Codeblocks mein ye kuch is tarah dikhna chahiye:

Ab program ko run karne ke liye Build > Build and Run par click karein.

Program run hone ke baad result kuch is tarah dikhai dega: 

Hello World!
Process returned 0 (0x0) execution time : 0.011 s
Press any key to continue.

Congratulations! Aapne ab apna pehla C++ program successfully likh aur run kar liya hai.
