C++ User Input

Abhi tak humne cout ka use karke output screen par dikhaya hai.

Ab hum seekhenge ki user se keyboard ke through input kaise liya jata hai.

C++ mein user input lene ke liye cin ka use kiya jata hai.

C++ User Input

C++ Example 
#include <iostream>
using namespace std;

int age;
cout << "Enter your age: ";
cin >> age;
cout << "Your age is: " << age;

cin Kya Hai?

cin C++ ka predefined input object hai jo keyboard se user ka data read karta hai.

Input lene ke liye >> extraction operator ka use kiya jata hai.

cin Kya Hai?

C++ Example 
int age;
cin >> age;

Multiple Inputs Lena

Hum ek program mein user se ek se zyada values bhi input le sakte hain.

Multiple Inputs Lena

C++ Example 
string name;
int age;

cin >> name >> age;
cout << name << " " << age;

Simple Calculator Banana

Ab hum user se do numbers lenge aur unka sum calculate karenge.

Simple Calculator Banana

C++ Example 
int a, b;
cin >> a >> b;

int sum = a + b;
cout << "Sum: " << sum;

Program Kaise Kaam Karta Hai?

  • Pehle variable create kiya jata hai.
  • cin user se value leta hai.
  • >> operator input ko variable mein store karta hai.
  • Input values par calculation perform ki ja sakti hai.
  • Result ko cout se screen par show kar sakte hain.

<iostream> Library

cin aur cout dono <iostream> library ka part hain.

Isliye user input aur output ke liye program ke starting mein #include <iostream> likhna hota hai.

iostream Library

C++ Example 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello";
    return 0;
}

Important

  • User input lene ke liye cin use hota hai.
  • Input operator >> hota hai.
  • Output ke liye cout aur << use hota hai.
  • cin aur cout ke liye <iostream> library use hoti hai.
