C++ Real-Life Examples

Practical Examples

Ab tak humne C++ ke variables aur data types ke basic concepts samjhe hain.

Ab dekhte hain ki real-life programs mein in concepts ka use kaise kiya ja sakta hai.

Student Ki Information Store Karna

Hum ek student ki different information ko different variables mein store kar sakte hain.

Student Ki Information Store Karna

C++ Example 
string name = "Ali";
int age = 18;
char grade = 'A';

cout << "Name: " << name << endl;
cout << "Age: " << age << endl;
cout << "Grade: " << grade;

Rectangle Ka Area Calculate Karna

Real programs mein variables ka use calculation ke liye bhi kiya jata hai.

Jaise rectangle ka area nikalne ke liye length aur width ko variables mein store kar sakte hain.

Rectangle Ka Area Calculate Karna

C++ Example 
int length = 10;
int width = 5;
int area = length * width;

cout << "Area: " << area;

Shopping Bill Calculate Karna

Variables ka use shopping ya billing system mein items, price aur total amount store karne ke liye kiya ja sakta hai.

Shopping Bill Calculate Karna

C++ Example 
double price = 250.50;
int quantity = 3;
double total = price * quantity;

cout << "Total Bill: " << total;

Welcome Message Banana

String variables ka use user ka naam store karke ek simple welcome message banane ke liye kar sakte hain.

Welcome Message Banana

C++ Example 
string name = "Ali";

cout << "Welcome, " << name << "!";

Voting Age Check Karna

Boolean aur comparison operators ka use karke hum check kar sakte hain ki koi person vote karne ke liye eligible hai ya nahi.

Voting Age Check Karna

C++ Example 
int age = 20;
bool eligible = age >= 18;

cout << "Eligible to vote: " << eligible;

Isse Kya Seekha?

  • Variables real-world data ko store karne ke kaam aate hain.
  • Different data types ko ek hi program mein use kiya ja sakta hai.
  • Variables ki madad se calculations perform kar sakte hain.
  • Stored values ko cout se display kar sakte hain.
  • C++ ke basic concepts ko combine karke practical programs banaye ja sakte hain.
