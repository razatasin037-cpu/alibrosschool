C++ Multiple Variables

Multiple Variables

C++ mein hum ek hi program ke andar multiple variables bana sakte hain.

Har variable ka apna naam aur value ho sakti hai. Variables ko alag-alag lines mein declare karna sabse simple aur readable tarika hai.

Multiple Variables

C++ Example
int age = 20;
string name = "Ali";
double height = 5.8;

Same Type ke Multiple Variables

Agar multiple variables ka data type same hai, to unhe ek hi line mein bhi declare kiya ja sakta hai.

Same Type ke Multiple Variables

C++ Example
int x = 10, y = 20, z = 30;
cout << x << " " << y << " " << z;

Alag-Alag Values

Ek hi type ke variables ko different values di ja sakti hain.

Alag-Alag Values

C++ Example
int age = 20;
int marks = 85;
int score = 95;

Different Types ke Multiple Variables

Ek program mein hum different data types ke variables ko bhi ek saath use kar sakte hain.

Different Types ke Multiple Variables

C++ Example
int age = 20;
double price = 99.99;
char grade = 'A';
string name = "Ali";

Multiple Variables Ko Display Karna

Multiple variables ko cout ki madad se ek saath screen par display kar sakte hain.

Multiple Variables Ko Display Karna

C++ Example
int age = 20;
string name = "Ali";

cout << "Name: " << name << endl;
cout << "Age: " << age;

Multiple Variables Ko Add Karna

Numeric variables ko mathematical operators ki madad se calculate bhi kar sakte hain.

Multiple Variables Ko Add Karna

C++ Example
int first = 10;
int second = 20;
int total = first + second;

cout << total;

Important

  • Ek program mein multiple variables bana sakte hain.
  • Same data type ke variables ko ek line mein declare kiya ja sakta hai.
  • Har variable ki value alag ho sakti hai.
  • Different data types ke variables ko bhi ek hi program mein use kar sakte hain.
  • Multiple variables ko cout se display kar sakte hain.
