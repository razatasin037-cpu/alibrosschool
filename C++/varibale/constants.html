C++ Constants

Constants

Kabhi-kabhi humein kisi variable ki value ko change nahi hone dena hota hai. Aise case mein hum const keyword ka use karte hain. const variable ko read-only bana deta hai.

C++ Example 
const int minutesPerHour = 60;

Constants Ka Use Kyun Karein?

Agar koi value program ke andar change nahi honi chahiye, to us variable ko constant banana better hota hai. Isse accidentally value change hone ka risk kam hota hai.

C++ Example 
const int maxScore = 100;
cout << maxScore;

Constant Ki Value Change Nahi Kar Sakte

Agar aap constant variable ko baad mein koi nayi value dene ki koshish karenge, to compiler error dega.

C++ Example 
const int x = 10;
x = 20; // Error

Constant Ko Value Dena Zaroori Hai

Jab aap const variable declare karte hain, to usi time usko value assign karni hoti hai.

C++ Example 
const int number = 10;

Real-Life Constants

Kuch values generally change nahi hoti hain, jaise ek hour mein minutes ki fixed value.

C++ Example 
const int minutesPerHour = 60;
cout << minutesPerHour;

Important

  • Constant banane ke liye const keyword use hota hai.
  • Constant ki value change nahi ki ja sakti.
  • Constant declare karte waqt value assign karna zaroori hai.
  • Jo values normally change nahi hoti hain, unke liye constants useful hote hain.
