C++ Identifiers

C++ Identifiers

C++ mein har variable ka ek unique naam hota hai. In unique names ko identifiers kaha jata hai. Identifier short ya descriptive ho sakta hai.

C++ Example 
int x = 10;
int age = 20;
int totalVolume = 100;

Identifier Naming Rules

C++ mein variable ya identifier ka naam rakhte waqt kuch rules follow karne padte hain. Letters, numbers aur underscore use kar sakte hain, lekin naam number se start nahi ho sakta.

C++ Example 
int myName = 10;
int _score = 90;
int player2 = 5;

Valid Identifier Names

Neeche diye gaye variable names valid identifiers hain.

C++ Example 
int age = 20;
int totalMarks = 500;
int _value = 10;
int number2 = 2;

Invalid Identifier Names

Kuch names C++ ke rules ko follow nahi karte. Isliye unhe identifier ke roop mein use nahi kar sakte.

C++ Example 
int 2number = 10;   // Invalid
int my-name = 20;   // Invalid
int my name = 30;   // Invalid

Identifiers Case-Sensitive Hote Hain

C++ mein uppercase aur lowercase letters ko alag maana jata hai. Isliye myVar aur myvar do alag identifiers hain.

C++ Example 
int myVar = 10;
int myvar = 20;

cout << myVar;
cout << myvar;

Descriptive Names Use Karein

Variable ka naam aisa rakhna better hota hai jisse dekhte hi pata chale ki variable kis cheez ko store kar raha hai.

C++ Example 
int studentAge = 18;
double productPrice = 99.99;
string studentName = "Ali";

Important

  • Identifier unique hona chahiye.
  • Identifier number se start nahi ho sakta.
  • Spaces aur special characters allowed nahi hain.
  • C++ keywords ko identifier ke roop mein use nahi kar sakte.
  • Meaningful aur descriptive names use karna better hai.
