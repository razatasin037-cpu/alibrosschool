C++ Variables

Variables ko aap ek container ki tarah samajh sakte hain, jisme hum data ya values ko store karte hain. C++ mein alag-alag type ka data store karne ke liye alag-alag variable types ka use hota hai.

C++ Example 
int age = 20;

Common Variable Types

C++ mein requirement ke according different data types ke variables bana sakte hain.

C++ Example 
int myNum = 10;
double price = 19.99;
char grade = 'A';
string name = "Ali Learning";
bool isStudent = true;

Variable Declare Kaise Karein?

Variable banane ke liye pehle data type, phir variable ka naam aur uske baad value likhte hain.

C++ Example 
int myNum = 15;

Value Baad Mein Bhi De Sakte Hain

Variable create karte waqt value dena zaroori nahi hai. Aap pehle variable declare kar sakte hain aur baad mein usmein value assign kar sakte hain.

C++ Example 
int myNum;
myNum = 15;

Variable Ki Value Change Karna

Agar kisi existing variable ko nayi value assign karte hain, to purani value overwrite ho jaati hai.

C++ Example 
int myNum = 15;
myNum = 20;

Different Types Ke Variables

Ek program mein hum requirement ke according different data types ke variables bana sakte hain.

C++ Example 
int myNum = 5;
double myDecimal = 19.99;
char myLetter = 'A';
string myText = "Ali Learning";
bool myBool = true;

Variable Ko Display Karna

Variable ki value screen par dikhane ke liye cout aur << operator ka use karte hain.

C++ Example 
int myNum = 15;
cout << myNum;

Text Aur Variables Ko Saath Mein Display Karna

Hum text aur alag-alag variables ko ek hi cout statement mein combine kar sakte hain.

C++ Example 
int age = 20;
cout << "My age is " << age;

Variables Ko Add Karna

Do numeric variables ko add karne ke liye + operator ka use kar sakte hain.

C++ Example 
int x = 5;
int y = 10;
cout << x + y;

Important

  • Single-line comment ke liye // use hota hai.
  • Multi-line comment ke liye /* */ use hota hai.
  • Comments ko compiler ignore karta hai.
  • Comments code ko samajhne mein help karte hain.
  • Comments ka use code ko temporarily disable karne ke liye bhi kiya ja sakta hai.
