C++ While Loop

C++ Loops

Loops kisi block of code ko tab tak repeatedly execute kar sakte hain jab tak specified condition true hoti hai.

Loops useful hote hain kyunki ye time save karte hain, repeated code ko kam karte hain, errors ko reduce karte hain aur code ko zyada readable banate hain.

C++ While Loop

The while loop ek block of code ko baar-baar execute karta hai jab tak specified condition true hoti hai.

Syntax

While Loop Syntax

Syntax 
while (condition) {
    // code block to be executed
}

Example

Neeche example mein code loop ke andar baar-baar run hota hai, jab tak variable i ki value 5 se chhoti hai.

Print Numbers 0 to 4

Example 
#include <iostream>
using namespace std;

int main() {
    int i = 0;

    while (i < 5) {
        cout << i << "\n";
        i++;
    }

    return 0;
}

Important

Condition mein use hone wale variable ko update karna zaroori hai. Agar i++ nahi likhenge, to condition true hi reh sakti hai aur loop kabhi end nahi hoga.

Why Use i in a Loop?

Simple loops mein i ek common counter variable name hai. Ye short, traditional hai aur commonly index ya iterator ko represent karta hai.

Counter Variable

Example 
int i = 0;

while (i < 3) {
    cout << "Count: " << i << "\n";
    i++;
}

Countdown Example

While loop ka use countdown ke liye bhi kiya ja sakta hai. Yeh example 3 se 1 tak count karta hai aur uske baad Happy New Year!! display karta hai.

Countdown from 3 to 1

Example 
#include <iostream>
using namespace std;

int main() {
    int countdown = 3;

    while (countdown > 0) {
        cout << countdown << "\n";
        countdown--;
    }

    cout << "Happy New Year!!\n";

    return 0;
}

While Loop with a False Condition

Agar while loop ki condition starting mein hi false hai, to loop ke andar ka code ek baar bhi execute nahi hota.

Is example mein i ki starting value 10 hai aur condition i < 5 false hai, isliye loop ke andar ka message print nahi hoga.

False Condition Example

Example 
#include <iostream>
using namespace std;

int main() {
    int i = 10;

    while (i < 5) {
        cout << "This will never be printed\n";
        i++;
    }

    return 0;
}

Remember

Regular while loop condition ko pehle check karta hai. Agar condition beginning mein false ho, to code block skip ho jata hai.

Increasing the Counter

Counter ko increase karne ke liye i++ use kar sakte hain. Isse har iteration ke baad variable ki value 1 se increase hoti hai.

Increasing with i++

Example 
int i = 1;

while (i <= 5) {
    cout << i << "\n";
    i++;
}

Decreasing the Counter

Countdown ke liye counter ko decrease kiya ja sakta hai. i-- har iteration ke baad value ko 1 se decrease karta hai.

Decreasing with i--

Example 
int i = 5;

while (i > 0) {
    cout << i << "\n";
    i--;
}

While Loop with User Input

While loop ka use user se input lene ke liye bhi kiya ja sakta hai. Loop tab tak repeat ho sakta hai jab tak required condition satisfy nahi hoti.

User Input Example

Example 
#include <iostream>
using namespace std;

int main() {
    int number;

    cout << "Enter a positive number: ";
    cin >> number;

    while (number <= 0) {
        cout << "Try again: ";
        cin >> number;
    }

    cout << "Valid number entered.";

    return 0;
}

Infinite While Loop

Agar while loop ki condition kabhi false nahi hoti, to loop continuously run kar sakta hai. Isse infinite loop kehte hain.

Infinite Loop Example

Example 
while (true) {
    cout << "This loop keeps running.\n";
}

Warning

Infinite loops ka use sirf tab karein jab program ko intentionally continuously run karna ho. Normal counter loops mein condition ko eventually false banana important hai.

Example Explained

  • int i = 0; counter ki initial value set karta hai.
  • while (i < 5) check karta hai ki loop continue hona chahiye ya nahi.
  • cout current value ko display karta hai.
  • i++ counter ko increase karta hai.
  • Jab i < 5 false ho jata hai, loop stop ho jata hai.

Summary

  • while loop condition true hone tak code repeat karta hai.
  • Condition ko loop ke start mein check kiya jata hai.
  • Counter ko update karna zaroori hai, warna infinite loop ho sakta hai.
  • i++ counter ko increase karta hai.
  • i-- counter ko decrease karta hai.
  • Agar condition starting mein false hai, to while loop ek baar bhi execute nahi hota.
