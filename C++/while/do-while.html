C++ Do/While Loop

The Do/While Loop

do/while loop, while loop ka ek variant hai. Is loop mein code block condition check hone se pehle ek baar zaroor execute hota hai.

Uske baad condition check hoti hai. Agar condition true hai, to loop dobara execute hota hai.

Syntax

Do/While Loop Syntax

Syntax 
do {
    // code block to be executed
}
while (condition);

Important

while condition ke baad semicolon (;) lagana required hai.

Do/While Example

Is example mein loop 0 se start hota hai aur i < 5 tak repeat hota hai.

Basic Do/While Example

Example 
#include <iostream>
using namespace std;

int main() {
    int i = 0;

    do {
        cout << i << "\n";
        i++;
    }
    while (i < 5);

    return 0;
}

How It Works

Do/while loop mein pehle do block execute hota hai. Uske baad while condition check hoti hai.

  • Sabse pehle do ke andar ka code execute hota hai.
  • Uske baad condition check hoti hai.
  • Condition true hone par loop repeat hota hai.
  • Condition false hone par loop stop ho jata hai.

Do/While Flow

Example 
do {
    // Step 1: Execute code
}
while (condition);

// Step 2: Check condition
// true  → repeat
// false → stop

Condition is False from the Start

Regular while loop ke unlike, do/while loop condition false hone par bhi code ko kam se kam ek baar execute karta hai.

Is example mein i = 10 hai aur condition i < 5 false hai. Phir bhi code ek baar execute hoga.

False Condition Example

Example 
#include <iostream>
using namespace std;

int main() {
    int i = 10;

    do {
        cout << "i is " << i << "\n";
        i++;
    }
    while (i < 5);

    return 0;
}

While vs Do/While

Dono loops similar hain, lekin inmein ek important difference hai: while condition ko pehle check karta hai, jabki do/while pehle code execute karta hai.

While Loop

Comparison 
int i = 10;

while (i < 5) {
    cout << i;
    i++;
}

// Runs 0 times

Do/While Loop

Comparison 
int i = 10;

do {
    cout << i;
    i++;
}
while (i < 5);

// Runs 1 time

Do/While with User Input

Do/while loop user input ke liye useful hai kyunki user se input kam se kam ek baar lena guaranteed hota hai.

User Input Example

Practical Example 
#include <iostream>
using namespace std;

int main() {
    int number;

    do {
        cout << "Enter a number: ";
        cin >> number;
    }
    while (number != 0);

    cout << "You entered 0.";

    return 0;
}

Menu Example

Do/while ka practical use menu-based programs mein bhi hota hai, jahan user ko option choose karne ke liye kam se kam ek baar menu dikhana hota hai.

Simple Menu

Example 
#include <iostream>
using namespace std;

int main() {
    int choice;

    do {
        cout << "\n1. Start";
        cout << "\n2. Settings";
        cout << "\n0. Exit";
        cout << "\nEnter choice: ";
        cin >> choice;

        if (choice == 1) {
            cout << "Starting...\n";
        }
        else if (choice == 2) {
            cout << "Opening settings...\n";
        }
    }
    while (choice != 0);

    cout << "Program ended.";

    return 0;
}

Infinite Do/While Loop

Agar do/while ki condition hamesha true rahe, to infinite loop create ho sakta hai.

Infinite Loop Example

Example 
do {
    cout << "This keeps running.\n";
}
while (true);

Important

  • Do/while loop code ko kam se kam ek baar execute karta hai.
  • Condition code execute hone ke baad check hoti hai.
  • while ke baad semicolon ; lagana zaroori hai.
  • Counter ko update karna important hai.
  • Condition hamesha true hone par infinite loop ho sakta hai.
  • Do/while loops menus aur user-input based programs mein particularly useful hote hain.

Summary

  • do/while loop ek block ko repeatedly execute karta hai.
  • Code block condition check hone se pehle execute hota hai.
  • Isliye do/while loop minimum ek baar zaroor run hota hai.
  • Condition true hone par loop repeat hota hai.
  • Condition false hone par loop stop ho jata hai.
  • while condition ke baad semicolon required hai.
