C++ Function Real-Life Example

Functions ko real-life style programs mein kaise use karte hain, examples ke saath samjho.

Calculate Total Price

Function quantity aur price lekar total calculate kar sakta hai.

Example

C++ 
double totalPrice(int quantity, double price) {
    return quantity * price;
}

int main() {
    cout << "Total: " << totalPrice(3, 150.0);
    return 0;
}

Output

Total: 450

Calculate Discount

Function price aur discount percentage lekar final price return kar sakta hai.

Example

C++ 
double finalPrice(double price, double discount) {
    return price - (price * discount / 100);
}

int main() {
    cout << finalPrice(1000, 10);
    return 0;
}

Output

900

Check Age

Function condition check karke boolean result return kar sakta hai.

Example

C++ 
bool isAdult(int age) {
    return age >= 18;
}

int main() {
    if (isAdult(20))
        cout << "Adult";
    else
        cout << "Not Adult";

    return 0;
}

Output

Adult

Rectangle Area

Mathematical calculation ko reusable function mein rakh sakte hain.

Example

C++ 
int rectangleArea(int length, int width) {
    return length * width;
}

int main() {
    cout << "Area: " << rectangleArea(10, 5);
    return 0;
}

Output

Area: 50

Simple Calculator

Function operation ke according calculation kar sakta hai.

Example

C++ 
double calculate(double a, double b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;
    return 0;
}

int main() {
    cout << calculate(10, 5, '+');
    return 0;
}

Output

15
