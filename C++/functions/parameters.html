C++ Parameters/Arguments

Functions mein parameters aur arguments ke through information pass karna seekho.

Parameters and Arguments

Information ko function mein parameter ke through pass kiya ja sakta hai. Parameters function ke andar variables ki tarah behave karte hain.

Function definition mein variable parameter hota hai, aur function call mein actual value argument hoti hai.

Example

C++ 
void myFunction(string fname) {
    cout << fname << "\n";
}

int main() {
    myFunction("Liam");
    myFunction("Jenny");
    myFunction("Anja");
    return 0;
}

Output

Liam
Jenny
Anja

Parameter Syntax

Multiple parameters ko comma se separate kiya jata hai.

Example

C++ 
void functionName(parameter1, parameter2, parameter3) {
    // code
}

Parameter vs Argument

name parameter hai, jabki "Tasin" argument hai.

Example

C++ 
void greet(string name) {
    cout << name;
}

int main() {
    greet("Tasin");
    return 0;
}

Output

Tasin

Number of Arguments

Normally function call mein arguments ki quantity parameters ke according honi chahiye.

Example

C++ 
void add(int x, int y) {
    cout << x + y;
}

int main() {
    add(5, 3);
    return 0;
}

Output

8

Important Points

Parameters definition mein aur arguments function call mein hote hain.

Multiple parameters comma se separate hote hain.

Important

Arguments ko parameters ke same order mein pass karna chahiye.
