C++ Function Overloading

Same function name ko different parameter types ya number ke saath use karna seekho.

What is Function Overloading?

Function overloading mein multiple functions ka same name ho sakta hai, jab unke parameters type ya number mein different hon.

Example

C++ 
int plusFunc(int x, int y) {
    return x + y;
}

double plusFunc(double x, double y) {
    return x + y;
}

int main() {
    cout << plusFunc(8, 5) << "\n";
    cout << plusFunc(4.3, 6.2);
    return 0;
}

Output

13
10.5

Overloading by Number of Parameters

Different number of parameters ke saath same function name use kiya ja sakta hai.

Example

C++ 
int plusFunc(int x, int y) {
    return x + y;
}

int plusFunc(int x, int y, int z) {
    return x + y + z;
}

int main() {
    cout << plusFunc(3, 7) << "\n";
    cout << plusFunc(1, 2, 3);
    return 0;
}

Output

10
6

Overloading by Parameter Type

Same name ke functions different parameter types ke saath define kiye ja sakte hain.

Example

C++ 
int show(int x) {
    return x;
}

double show(double x) {
    return x;
}

int main() {
    cout << show(10) << "\n";
    cout << show(5.5);
    return 0;
}

Output

10
5.5

Why Use Function Overloading?

Similar tasks ke liye same function name use karna code ko readable aur convenient bana sakta hai.

Important

Sirf return type different hone se overloading possible nahi hoti. Parameters ka number ya type different hona chahiye.
