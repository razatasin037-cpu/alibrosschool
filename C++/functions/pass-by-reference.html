C++ Pass By Reference

Reference pass karke function se original variable ki value change karna seekho.

What is Pass By Reference?

Reference parameter function ko original variable ke saath kaam karne deta hai.

Example

C++ 
void changeValue(int &num) {
    num = 50;
}

int main() {
    int value = 10;
    changeValue(value);
    cout << value;
    return 0;
}

Output

50

Swap Two Values

Do variables ko reference ke through pass karke unki original values swap ki ja sakti hain.

Example

C++ 
void swapNums(int &x, int &y) {
    int z = x;
    x = y;
    y = z;
}

int main() {
    int firstNum = 10;
    int secondNum = 20;
    swapNums(firstNum, secondNum);
    cout << firstNum << " " << secondNum;
    return 0;
}

Output

20 10

Pass a String by Reference

String ko reference ke through modify kiya ja sakta hai.

Example

C++ 
void modifyStr(string &str) {
    str += " World!";
}

int main() {
    string greeting = "Hello";
    modifyStr(greeting);
    cout << greeting;
    return 0;
}

Output

Hello World!

Why Use Pass By Reference?

Jab function ko original data modify karna ho tab reference useful hota hai. Large objects ki unnecessary copy bhi avoid ho sakti hai.

Important

Reference parameter declare karte waqt type ke saath & lagaya jata hai.
