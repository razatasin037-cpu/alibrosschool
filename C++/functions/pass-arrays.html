C++ Pass Arrays

Arrays ko function parameters ke roop mein pass karke elements par kaam karna seekho.

Pass Arrays as Function Parameters

Array ko function ke parameter ke roop mein pass kiya ja sakta hai.

Example

C++ 
void myFunction(int myNumbers[5]) {
    for (int i = 0; i < 5; i++) {
        cout << myNumbers[i] << "\n";
    }
}

int main() {
    int myNumbers[5] = {10, 20, 30, 40, 50};
    myFunction(myNumbers);
    return 0;
}

Output

10
20
30
40
50

Pass the Array Name

Function call mein array pass karne ke liye array ka name use kiya jata hai.

Example

C++ 
void printArray(int numbers[4]) {
    for (int i = 0; i < 4; i++) {
        cout << numbers[i] << " ";
    }
}

int main() {
    int numbers[4] = {5, 10, 15, 20};
    printArray(numbers);
    return 0;
}

Output

5 10 15 20

Modify Array Elements

Function array elements ko modify bhi kar sakta hai.

Example

C++ 
void changeArray(int numbers[3]) {
    numbers[0] = 100;
    numbers[1] = 200;
}

int main() {
    int numbers[3] = {10, 20, 30};
    changeArray(numbers);
    cout << numbers[0] << " " << numbers[1];
    return 0;
}

Output

100 200

Loop Through a Passed Array

Array parameter ke saath for loop use karke har element process kiya ja sakta hai.

Example

C++ 
void printArray(int numbers[5]) {
    for (int i = 0; i < 5; i++) {
        cout << numbers[i] << "\n";
    }
}

Important Points

Function call mein array ka name pass hota hai. Function parameter mein array form specify kiya ja sakta hai.

Important

Array indexes aur loop limits ko carefully handle karo.
