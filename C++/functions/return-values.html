C++ Return Values

Function se value return karna aur returned result ko use karna seekho.

Return Values

Value return karne ke liye void ki jagah appropriate data type aur return keyword use hota hai.

Example

C++ 
int myFunction(int x) {
    return 5 + x;
}

int main() {
    cout << myFunction(3);
    return 0;
}

Output

8

Return the Sum

Function multiple parameters lekar result return kar sakta hai.

Example

C++ 
int add(int x, int y) {
    return x + y;
}

int main() {
    cout << add(5, 3);
    return 0;
}

Output

8

Store the Return Value

Returned result ko variable mein store karke baad mein use kar sakte ho.

Example

C++ 
int add(int x, int y) {
    return x + y;
}

int main() {
    int result = add(5, 3);
    cout << result;
    return 0;
}

Output

8

Return a String

Function string value bhi return kar sakta hai.

Example

C++ 
string getName() {
    return "Tasin";
}

int main() {
    cout << getName();
    return 0;
}

Output

Tasin

Void vs Return Value

void function value return nahi karta, jabki non-void function declared type ki value return karta hai.

Example

C++ 
int square(int x) {
    return x * x;
}

int main() {
    cout << square(5);
    return 0;
}

Output

25

Important Points

Return type function ke result ka type batata hai.

Important

Return value ka type function ke declared return type ke compatible hona chahiye.
