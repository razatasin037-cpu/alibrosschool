C++ Recursion

Function ka khud ko call karna, base case aur recursive examples samjho.

What is Recursion?

Recursion ek technique hai jisme function khud ko call karta hai. Isse complicated problem ko smaller problems mein break kiya ja sakta hai.

Example

C++ 
void countdown(int n) {
    if (n > 0) {
        cout << n << " ";
        countdown(n - 1);
    }
}

int main() {
    countdown(5);
    return 0;
}

Output

5 4 3 2 1

Recursive Sum

Recursion se 1 se kisi number tak ka sum calculate kiya ja sakta hai.

Example

C++ 
int sum(int k) {
    if (k > 0) {
        return k + sum(k - 1);
    } else {
        return 0;
    }
}

int main() {
    int result = sum(10);
    cout << result;
    return 0;
}

Output

55

How Recursion Works

sum(10) smaller values ke saath function ko call karta hai. Jab k zero hota hai, function further call nahi karta aur result return hona start hota hai.

Example

C++ 
sum(10)
10 + sum(9)
10 + 9 + sum(8)
...
10 + 9 + 8 + ... + 1 + sum(0)
10 + 9 + 8 + ... + 1 + 0

Factorial Using Recursion

Factorial ko recursive function se calculate kiya ja sakta hai.

Example

C++ 
int factorial(int n) {
    if (n > 1) {
        return n * factorial(n - 1);
    } else {
        return 1;
    }
}

int main() {
    cout << factorial(5);
    return 0;
}

Output

120

Base Case

Base case woh condition hai jahan recursive function further call nahi karta. Ye recursion ko stop karta hai.

Important

Base case ke bina recursion properly terminate nahi ho sakta aur excessive memory ya processor usage ho sakta hai.
