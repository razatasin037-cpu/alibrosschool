C++ Functions

Functions code ko reusable blocks mein organize karte hain. Function create, declare aur call karna seekho.

What is a Function?

Function C++ code ka ek block hota hai jo ek specific task perform karta hai. Function tab execute hota hai jab usse call kiya jata hai.

Functions ka main benefit code reuse hai.

Example

C++ 
void myFunction() {
    cout << "Hello World!";
}

int main() {
    myFunction();
    return 0;
}

Output

Hello World!

Create a Function

Function banane ke liye return type, function name aur parentheses () likhe jate hain. Function body curly braces ke andar hoti hai.

Example

C++ 
void myFunction() {
    cout << "I just got executed!";
}

Call a Function

Function ko run karne ke liye function name ke baad () ke saath call karna padta hai.

Example

C++ 
void myFunction() {
    cout << "Hello World!";
}

int main() {
    myFunction();
    return 0;
}

Output

Hello World!

Call a Function Multiple Times

Ek function ko multiple times call kiya ja sakta hai.

Example

C++ 
void myFunction() {
    cout << "Hello!\n";
}

int main() {
    myFunction();
    myFunction();
    myFunction();
    return 0;
}

Output

Hello!
Hello!
Hello!

Function Declaration and Definition

Agar function ko main() ke baad define karna ho, to pehle function declaration likh sakte ho.

Example

C++ 
void myFunction();

int main() {
    myFunction();
    return 0;
}

void myFunction() {
    cout << "Hello!";
}

Output

Hello!

Functions with Parameters

Parameters ke through function ko data pass kiya ja sakta hai.

Example

C++ 
void greet(string name) {
    cout << "Hello " << name;
}

int main() {
    greet("Tasin");
    return 0;
}

Output

Hello Tasin

Why Use Functions?

Functions repeated code ko avoid karte hain aur program ko small reusable blocks mein organize karte hain.

Important

Functions code ko read, test aur maintain karna easier bana sakte hain.
