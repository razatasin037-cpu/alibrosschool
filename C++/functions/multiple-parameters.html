C++ Multiple Parameters

Ek function mein multiple parameters kaise use karte hain, examples ke saath samjho.

Multiple Parameters

Function ke parentheses mein multiple parameters add kar sakte ho. Unhe comma se separate kiya jata hai.

Example

C++ 
void myFunction(string fname, int age) {
    cout << fname << " is " << age << " years old.\n";
}

int main() {
    myFunction("Liam", 3);
    myFunction("Jenny", 14);
    myFunction("Anja", 30);
    return 0;
}

Output

Liam is 3 years old.
Jenny is 14 years old.
Anja is 30 years old.

Different Data Types

Ek function mein parameters ke data types different ho sakte hain.

Example

C++ 
void showInfo(string name, int age, double height) {
    cout << name << "\n";
    cout << age << "\n";
    cout << height;
}

int main() {
    showInfo("Tasin", 20, 5.8);
    return 0;
}

Output

Tasin
20
5.8

Parameter Order

Arguments ko parameter ke same order mein pass karna chahiye.

Example

C++ 
void showInfo(string name, int age) {
    cout << name << " - " << age;
}

int main() {
    showInfo("Tasin", 20);
    return 0;
}

Output

Tasin - 20

Calculate a Sum

Multiple parameters ka use calculations ke liye commonly hota hai.

Example

C++ 
void calculateSum(int x, int y) {
    cout << "Sum: " << x + y;
}

int main() {
    calculateSum(5, 3);
    return 0;
}

Output

Sum: 8

Important Points

Function call mein normally arguments ki count parameters ke count ke according honi chahiye.

Important

Arguments ki quantity aur order parameters ke according rakho.
