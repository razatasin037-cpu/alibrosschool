C++ Pass Structures

Structure ko function mein pass karke grouped data ko process karna seekho.

Pass Structure to a Function

Structure ko function parameter ke roop mein pass kiya ja sakta hai.

Example

C++ 
struct Car {
    string brand;
    int year;
};

void myFunction(Car c) {
    cout << "Brand: " << c.brand
         << ", Year: " << c.year;
}

int main() {
    Car myCar = {"Toyota", 2020};
    myFunction(myCar);
    return 0;
}

Output

Brand: Toyota, Year: 2020

Access Structure Members

Function ke andar structure members ko dot operator se access kiya jata hai.

Example

C++ 
struct Student {
    string name;
    int age;
};

void showStudent(Student s) {
    cout << s.name << " " << s.age;
}

int main() {
    Student s = {"Tasin", 20};
    showStudent(s);
    return 0;
}

Output

Tasin 20

Pass Structure by Reference

Reference ke through function original structure ko modify kar sakta hai.

Example

C++ 
struct Car {
    string brand;
    int year;
};

void updateYear(Car &c) {
    c.year++;
}

int main() {
    Car myCar = {"Toyota", 2020};
    updateYear(myCar);
    cout << myCar.year;
    return 0;
}

Output

2021

Pass by Value vs Reference

Normal structure parameter mein function ko structure ki copy milti hai. Reference parameter original structure ke saath kaam karta hai.

Important

Original structure ko change karna ho to reference useful hai.
