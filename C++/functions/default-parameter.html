C++ Default Parameter

Default parameter value tab use hoti hai jab function call mein argument provide nahi kiya jata.

What is a Default Parameter?

Parameter ko default value di ja sakti hai. Agar call mein value nahi di gayi, default value use hoti hai.

Example

C++ 
void myFunction(string country = "India") {
    cout << country;
}

int main() {
    myFunction();
    return 0;
}

Output

India

Pass a Different Value

Default value ko function call mein apni value dekar replace kar sakte ho.

Example

C++ 
void myFunction(string country = "India") {
    cout << country;
}

int main() {
    myFunction("USA");
    return 0;
}

Output

USA

Default Number Parameter

Default parameters numbers ke saath bhi use kiye ja sakte hain.

Example

C++ 
void myFunction(int age = 18) {
    cout << age;
}

int main() {
    myFunction();
    return 0;
}

Output

18

Default Parameter with Multiple Parameters

Multiple parameters mein optional/default value di ja sakti hai.

Example

C++ 
void student(string name, int age = 18) {
    cout << name << " is " << age;
}

int main() {
    student("Tasin");
    return 0;
}

Output

Tasin is 18

Important Points

Default parameter function ko optional argument provide karne deta hai.

Important

Agar argument pass kiya gaya hai, passed value default value ki jagah use hoti hai.
