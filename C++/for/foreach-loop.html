C++ The foreach Loop

The foreach Loop

C++ mein for-each loop ko array ya kisi data set ke elements ko directly traverse karne ke liye use kiya ja sakta hai. Ye C++11 mein introduce hua tha.

For-Each Syntax

Syntax 
for (type variableName : arrayName) {
    // code to be executed
}

For-Each Array Example

Example 
int myNumbers[5] = {10, 20, 30, 40, 50};

for (int i : myNumbers) {
    cout << i << "\n";
}

Why Use foreach?

  • Array ke elements ko easily read kar sakte hain.
  • Index manually manage karne ki zarurat nahi hoti.
  • Code simple aur readable hota hai.

Names Array Example

Example 
string names[] = {"Ali", "Sara", "Rahul"};

for (string name : names) {
    cout << name << "\n";
}

Note

For-each loop tab particularly convenient hai jab humein array ke elements ko sequence mein access karna ho aur index ki zarurat na ho.
