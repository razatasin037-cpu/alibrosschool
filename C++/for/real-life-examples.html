C++ For Loop Real-Life Examples

Real Life Examples

For loop ka practical use counting, filtering values, repeated calculations aur multiplication tables jaise real programs mein hota hai.

Count by Tens

Is example mein 0 se 100 tak numbers 10 ke gap mein print kiye ja rahe hain.

Count by Tens

Example 
for (int i = 0; i <= 100; i += 10) {
    cout << i << "\n";
}

Even Numbers

Is example mein 0 se 10 ke beech sirf even values print hoti hain.

Even Numbers

Example 
for (int i = 0; i <= 10; i = i + 2) {
    cout << i << "\n";
}

Odd Numbers

Is example mein odd numbers print kiye ja rahe hain.

Odd Numbers

Example 
for (int i = 1; i <= 10; i = i + 2) {
    cout << i << "\n";
}

Powers of 2

Har iteration mein value double hoti hai, isliye 2 ki powers 512 tak print hoti hain.

Powers of 2

Example 
for (int i = 2; i <= 512; i *= 2) {
    cout << i << "\n";
}

Multiplication Table

Specified number 2 ka multiplication table 1 se 10 tak print hota hai.

Multiplication Table

Example 
int number = 2;

for (int i = 1; i <= 10; i++) {
    cout << number << " x " << i
         << " = " << number * i << "\n";
}

Summary

  • For loop known number of repetitions ke liye useful hai.
  • Nested loops loop ke andar loop allow karte hain.
  • Foreach loop arrays ke elements ko easily traverse karta hai.
  • Real-life programs mein for loops counting aur repeated calculations ke liye commonly use hote hain.
