C++ For Loop

Jab aapko exactly pata ho ki kisi block of code ko kitni baar repeat karna hai, tab for loop use karna useful hota hai.

Syntax

Syntax 
for (statement 1; statement 2; statement 3) {
    // code block to be executed
}

Statement 1 loop start hone se pehle ek baar execute hota hai. Statement 2 condition define karta hai. Statement 3 har iteration ke baad execute hota hai.

Print Numbers 0 to 4

Example 
for (int i = 0; i < 5; i++) {
    cout << i << "\n";
}

Example Explained

  • int i = 0 variable set karta hai.
  • i < 5 loop ki condition hai.
  • i++ har iteration ke baad value increase karta hai.
  • Condition false hone par loop end ho jata hai.

Print Even Numbers

Example 
for (int i = 0; i <= 10; i = i + 2) {
    cout << i << "\n";
}

Sum of Numbers

Example 
int sum = 0;

for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}

cout << "Sum is " << sum;

Countdown

Example 
for (int i = 5; i > 0; i--) {
    cout << i << "\n";
}
