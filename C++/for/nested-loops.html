C++ Nested Loops

Nested Loops

Ek loop ko doosre loop ke andar place karna nested loop kehlata hai. Inner loop, outer loop ki har iteration par execute hota hai.

Basic Nested Loop

Example 
for (int i = 1; i <= 2; ++i) {
    cout << "Outer: " << i << "\n";

    for (int j = 1; j <= 3; ++j) {
        cout << " Inner: " << j << "\n";
    }
}

Yahan outer loop 2 baar aur inner loop har outer iteration mein 3 baar execute hota hai, isliye inner statement total 2 × 3 = 6 baar execute hota hai.

Multiplication Table Example

Nested loops tables, matrices aur multi-dimensional data ke saath kaam karne mein useful hote hain.

Multiplication Table 1 to 3

Example 
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        cout << i * j << " ";
    }
    cout << "\n";
}

Output

1 2 3
2 4 6
3 6 9
