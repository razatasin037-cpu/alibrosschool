C++ Output

C++ mein screen par text ya koi value print karne ke liye hum cout ka use karte hain.

cout ke saath << operator use kiya jata hai. Text ko hamesha double quotes ke andar likha jata hai.

cout Ko Samjhein

cout ka use output ko screen par dikhane ke liye hota hai. Ye C++ ki standard output stream hai.

Double Quotes ka Use

Jab hum koi text print karna chahte hain, to us text ko double quotes " ke andar likhna hota hai.

Example: cout << "Hello World!";

Multiple cout Statements

Aap ek hi program mein jitne chahein cout statements use kar sakte hain.

Important

  • cout output print karne ke liye use hota hai.
  • Text ko double quotes ke andar likhein.
  • << operator ka use output ko cout mein bhejne ke liye hota hai.
  • Multiple cout statements use kiye ja sakte hain.

New Line

Dhyan rakhein ki cout apne aap output ke baad new line nahi lagata. Isliye agar aap next line mein output dikhana chahte hain, to uske liye alag method use karna padega.

Short Summary

C++ mein output print karne ke liye cout aur << operator ka use hota hai. Text ko double quotes ke andar likhna hota hai.
