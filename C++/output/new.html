C++ New Lines

C++ mein output ko next line par dikhane ke liye hum \n character ka use kar sakte hain.

Jab \n use hota hai, cursor output ki next line par chala jata hai.

Dusra Tarika

Hum << operator ka use karke bhi "\n" ko alag se likh sakte hain.

Blank Line

Agar aap do \n ek saath use karte hain, to output mein ek blank line create hoti hai.

endl ka Use

New line create karne ka ek aur tarika endl ka use karna hai.

Important

  • \n new line ke liye sabse commonly used method hai.
  • endl bhi output ko next line par le jata hai.
  • Do \n ek saath likhne se blank line create hoti hai.

Escape Sequences

\n ek escape sequence hai. Escape sequences special characters hote hain jo output mein special kaam karte hain.

Meaning
