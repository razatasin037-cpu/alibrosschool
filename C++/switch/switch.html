C++ Switch Statement

C++ mein switch statement ka use multiple choices mein se ek option select karne ke liye kiya jata hai.

Switch statement kisi expression ki value ko different case values ke saath compare karta hai.

Syntax

Switch Syntax

Syntax 
switch (expression) {
    case value1:
        // code
        break;

    case value2:
        // code
        break;

    default:
        // code
}

How It Works

Switch statement mein expression ki value ko cases ke saath compare kiya jata hai. Jo case match karta hai, uska code execute hota hai.

  • case ek possible value ko represent karta hai.
  • break switch ko stop karne ke liye use hota hai.
  • default tab execute hota hai jab koi case match nahi karta.

Example

Is example mein day ki value ke according day ka naam display kiya ja raha hai.

Day Name Example

Example 
#include <iostream>
using namespace std;

int main() {
    int day = 3;

    switch (day) {
        case 1:
            cout << "Monday";
            break;
        case 2:
            cout << "Tuesday";
            break;
        case 3:
            cout << "Wednesday";
            break;
        case 4:
            cout << "Thursday";
            break;
        case 5:
            cout << "Friday";
            break;
        case 6:
            cout << "Saturday";
            break;
        case 7:
            cout << "Sunday";
            break;
        default:
            cout << "Invalid day";
    }

    return 0;
}

The break Keyword

break keyword matching case execute hone ke baad switch statement se bahar nikalne ke liye use hota hai.

Using break

Example 
#include <iostream>
using namespace std;

int main() {
    int choice = 2;

    switch (choice) {
        case 1:
            cout << "Option One";
            break;
        case 2:
            cout << "Option Two";
            break;
        case 3:
            cout << "Option Three";
            break;
    }

    return 0;
}

The default Keyword

Agar kisi bhi case ki value expression se match nahi karti, to default block execute ho sakta hai.

Using default

Example 
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    switch (number) {
        case 1:
            cout << "One";
            break;
        case 2:
            cout << "Two";
            break;
        default:
            cout << "No matching case";
    }

    return 0;
}

Character Example

Switch ka use character values ke saath bhi kiya ja sakta hai.

Character Switch

Example 
#include <iostream>
using namespace std;

int main() {
    char grade = 'B';

    switch (grade) {
        case 'A':
            cout << "Excellent";
            break;
        case 'B':
            cout << "Very Good";
            break;
        case 'C':
            cout << "Good";
            break;
        default:
            cout << "Invalid grade";
    }

    return 0;
}

Multiple Cases

Ek switch statement mein jitne options ki zarurat ho, utne cases define kiye ja sakte hain.

Multiple Cases Example

Example

            break;

            break;
        case 4:

            break;

Complete Example

Yeh complete example user ke choice ke according ek simple menu option select karta hai.

Complete Switch Example

Example 
#include <iostream>
using namespace std;

int main() {
    int choice = 2;

    switch (choice) {
        case 1:
            cout << "You selected Home";
            break;
        case 2:
            cout << "You selected Profile";
            break;
        case 3:
            cout << "You selected Settings";
            break;
        default:
            cout << "Invalid choice";
    }

    return 0;
}

Important

  • Switch multiple choices handle karne ke liye useful hai.
  • Har option ko case kehte hain.
  • break statement switch ko stop karta hai.
  • default unmatched value ke liye use hota hai.
