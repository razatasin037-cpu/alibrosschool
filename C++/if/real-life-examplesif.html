C++ Real-Life Examples

Conditions in Real-Life Programs

Real programs mein conditions ka use decisions lene ke liye bahut commonly kiya jata hai.

User ki age check karna, number even ya odd check karna, password verify karna aur marks ke basis par result dena jaise kaamon mein conditions useful hoti hain.

Example 1: Check Age

Kisi person ki age check karke determine kiya ja sakta hai ki woh adult hai ya nahi.

C++ Age Check Example

Example 
#include <iostream>
using namespace std;

int main() {
    int age = 20;

    if (age >= 18) {
        cout << "You are an adult.";
    } else {
        cout << "You are not an adult.";
    }

    return 0;
}

Example 2: Even or Odd

Modulus operator % ke saath condition use karke check kar sakte hain ki number even hai ya odd.

C++ Even or Odd Example

Example 
#include <iostream>
using namespace std;

int main() {
    int number = 10;

    if (number % 2 == 0) {
        cout << "Even number";
    } else {
        cout << "Odd number";
    }

    return 0;
}

Example 3: Positive or Negative

Number ko zero se compare karke determine kar sakte hain ki number positive, negative ya zero hai.

C++ Positive or Negative Example

Example 
#include <iostream>
using namespace std;

int main() {
    int number = -5;

    if (number > 0) {
        cout << "Positive number";
    } else if (number < 0) {
        cout << "Negative number";
    } else {
        cout << "Zero";
    }

    return 0;
}

Example 4: Pass or Fail

Marks ke basis par student ka result check kiya ja sakta hai.

C++ Pass or Fail Example

Example 
#include <iostream>
using namespace std;

int main() {
    int marks = 75;

    if (marks >= 40) {
        cout << "Student Passed";
    } else {
        cout << "Student Failed";
    }

    return 0;
}

Example 5: Login Check

Conditions ka use login details ko verify karne jaise simple decision-making tasks mein bhi kiya ja sakta hai.

C++ Login Check Example

Example 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string username = "admin";
    string password = "1234";

    if (username == "admin" && password == "1234") {
        cout << "Login successful";
    } else {
        cout << "Invalid username or password";
    }

    return 0;
}

Example 6: Multiple Conditions

Logical operators ke saath multiple conditions ko combine karke more specific decisions liye ja sakte hain.

C++ Multiple Conditions Example

Example 
#include <iostream>
using namespace std;

int main() {
    int age = 25;
    bool hasID = true;

    if (age >= 18 && hasID) {
        cout << "Entry allowed";
    } else {
        cout << "Entry denied";
    }

    return 0;
}

Complete Real-Life Example

Neeche ek complete example hai jisme age aur marks ke basis par decision liya gaya hai.

Complete C++ Example

Example 
#include <iostream>
using namespace std;

int main() {
    int age = 20;
    int marks = 80;

    if (age >= 18 && marks >= 40) {
        cout << "Adult student and passed";
    } else if (age < 18 && marks >= 40) {
        cout << "Young student and passed";
    } else {
        cout << "Student failed";
    }

    return 0;
}

Summary

  • Conditions program ko decision lene mein help karti hain.
  • if, else aur else if common conditional statements hain.
  • Logical operators se multiple conditions combine ki ja sakti hain.
  • Real programs mein conditions ka use bahut common hai.
