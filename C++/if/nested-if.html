C++ Nested If

C++ mein ek if statement ke andar doosra if statement likha ja sakta hai.

Isse nested if kaha jata hai. Iska use tab hota hai jab ek condition ke true hone ke baad ek aur condition check karni ho.

Syntax

Nested If Syntax

if (condition1) {
    // Outer if code

    if (condition2) {
        // Inner if code
    }
}

Example

Neeche example mein pehle age check ki ja rahi hai. Agar age 18 ya usse zyada hai, tab doosri condition check hoti hai.

Nested If Example

int age = 20;
bool hasID = true;

if (age >= 18) {
    if (hasID) {
        cout << "You can enter.";
    }
}

Example Explained

Sabse pehle outer if condition check hoti hai.

Agar outer condition true hoti hai, tab uske andar wala if execute hokar doosri condition check karta hai.

  • Pehle outer condition check hoti hai.
  • Outer condition true hone par inner condition check hoti hai.
  • Inner condition true hone par inner block execute hota hai.

Multiple Nested if Statements

Zarurat ke according ek if ke andar multiple levels tak if statements likhe ja sakte hain.

Multiple Nested If Example

int age = 25;
bool hasID = true;
bool member = true;

if (age >= 18) {
    if (hasID) {
        if (member) {
            cout << "Access granted.";
        }
    }
}

Real-Life Example

Nested if ka use user ki age aur membership jaise multiple conditions ko check karne ke liye kiya ja sakta hai.

Real-Life Nested If Example

int age = 21;
bool member = true;

if (age >= 18) {
    if (member) {
        cout << "Welcome member!";
    }
    else {
        cout << "Please become a member.";
    }
}
else {
    cout << "You are under 18.";
}

Important

  • Nested if ka matlab hai ek if ke andar doosra if.
  • Inner condition tabhi check hoti hai jab outer condition true ho.
  • Nested conditions ko carefully use karna chahiye taaki code readable rahe.

Complete Nested If Example

#include <iostream>
using namespace std;

int main() {
    int age = 20;
    bool hasID = true;

    if (age >= 18) {
        if (hasID) {
            cout << "You are allowed to enter.";
        }
        else {
            cout << "ID is required.";
        }
    }
    else {
        cout << "You are under 18.";
    }

    return 0;
}
