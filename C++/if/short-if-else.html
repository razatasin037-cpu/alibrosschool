C++ Short Hand If...Else

Short Hand If...Else

C++ mein if...else ko short form mein likhne ke liye ternary operator ka use kiya ja sakta hai.

Ternary operator ka use mostly simple conditions ke liye kiya jata hai aur isse code ko ek line mein likha ja sakta hai.

The Ternary Operator

Ternary operator mein teen parts hote hain: condition, true result aur false result.

Syntax

Ternary Operator Syntax

condition ? expressionIfTrue : expressionIfFalse;

Normal if...else

Pehle same condition ko normal if...else ke through dekhte hain.

Normal if...else Example

int age = 20;

if (age >= 18) {
    cout << "Adult";
}
else {
    cout << "Not Adult";
}

Short Hand if...else

Isi logic ko ternary operator ke through ek line mein likh sakte hain.

Short Hand Example

int age = 20;

string result = (age >= 18) ? "Adult" : "Not Adult";

cout << result;

Example

Neeche example mein age check karke Adult ya Not Adult display kiya gaya hai.

Age Check Example

int age = 17;

cout << ((age >= 18) ? "Adult" : "Not Adult");

Storing the Result

Ternary operator ka result kisi variable mein bhi store kiya ja sakta hai.

Store Result Example

int number = 10;

string result = (number % 2 == 0) ? "Even" : "Odd";

cout << result;

When to Use Ternary Operator?

  • Simple conditions ke liye ternary operator useful hai.
  • Chhote if...else code ko short banaya ja sakta hai.
  • Complex conditions ke liye normal if...else zyada readable ho sakta hai.

Important

  • Ternary operator ko ?: symbols se represent kiya jata hai.
  • Ismein condition pehle likhi jati hai.
  • ? ke baad true result aur : ke baad false result hota hai.
  • Ye simple if...else ko short karne ke liye useful hai.

Complete Ternary Example

#include <iostream>
#include <string>
using namespace std;

int main() {
    int marks = 75;

    string result = (marks >= 40) ? "Pass" : "Fail";

    cout << result;

    return 0;
}
