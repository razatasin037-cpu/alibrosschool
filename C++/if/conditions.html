C++ Conditions (If...Else)

C++ Conditions aur If Statements

C++ mein jab hume koi decision (faisla) lena hota hai, tab hum Conditional Statements ka use karte hain.

C++ mein decision lene ke liye 4 main statements hote hain:

  • if: Agar condition true hai to code run hoga.
  • else: Agar wahi condition false hai to yeh code run hoga.
  • else if: Nayi condition check karne ke liye agar pehli condition false ho.
  • switch: Bahut saare alternative code blocks mein se ek chunne ke liye.

1. The if Statement

`if` statement ka use kisi code block ko tabhi execute karne ke liye kiya jata hai jab condition true ho.

if Statement Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int x = 20;
    int y = 18;

    if (x > y) {
        cout << "x, y se bada hai";
    }

    return 0;
}

2. The else Statement

Jab `if` ki condition false ho jati hai, to `else` ke andar ka code block execute hota hai.

else Statement Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int time = 20;

    if (time < 18) {
        cout << "Good day.";
    } else {
        cout << "Good evening."; // Yeh print hoga kyunki 20 < 18 false hai
    }

    return 0;
}

3. The else if Statement

Agar pehli condition false ho aur aap ek nayi condition check karna chahte hain, to `else if` ka use karte hain.

else if Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int time = 22;

    if (time < 10) {
        cout << "Good morning.";
    } else if (time < 20) {
        cout << "Good day.";
    } else {
        cout << "Good evening."; // Output: Good evening.
    }

    return 0;
}

Short Hand If...Else (Ternary Operator)

Agar aapka if-else simple hai, to aap use 1 line me likhne ke liye Ternary Operator (?) ka use kar sakte hain:

variable = (condition) ? expressionTrue : expressionFalse;

Ternary Operator Example

Example

C++ 
#include <iostream>
#include <string>
using namespace std;

int main() {
    int time = 20;
    string result = (time < 18) ? "Good day." : "Good evening.";
    
    cout << result; // Output: Good evening.
    return 0;
}

Important Points

  • `if` keywords ko hamesha lowercase (chote aksharo) mein likhein. `IF` ya `If` syntax error dega.
  • Condition ko hamesha parenthesis `()` ke andar likha jata hai.
  • Multiple lines code ko run karne ke liye curly braces `{}` lagana zaroori hai.
  • Ternary operator `? :` short single-line conditional check ke liye efficient hai.
