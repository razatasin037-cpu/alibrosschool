C++ Else If

The else if Statement

C++ mein else if ka use tab kiya jata hai jab humein ek se zyada conditions check karni hoti hain.

Agar pehli if condition false ho, to program next else if condition ko check karta hai.

Syntax

else if Syntax

if (condition1) {
    // code
}
else if (condition2) {
    // code
}
else {
    // code
}

Example

Neeche example mein time ke according different messages display kiye ja rahe hain.

Main Example

int time = 14;

if (time < 12) {
    cout << "Good morning.";
}
else if (time < 18) {
    cout << "Good afternoon.";
}
else {
    cout << "Good evening.";
}

How Does else if Work?

Program conditions ko upar se neeche ki taraf check karta hai. Jaise hi koi condition true hoti hai, us block ka code execute hota hai aur baaki conditions skip ho jati hain.

  • Sabse pehle if condition check hoti hai.
  • Agar false ho, to else if check hota hai.
  • Multiple else if conditions use ki ja sakti hain.
  • Agar koi condition true na ho, to optional else execute hota hai.

Condition Flow Example

int number = 10;

if (number > 10) {
    cout << "Greater than 10";
}
else if (number == 10) {
    cout << "Equal to 10";
}
else {
    cout << "Less than 10";
}

Grade Example

Marks ke basis par grade determine karne ke liye else if ka use kiya ja sakta hai.

Grade Example

int marks = 85;

if (marks >= 90) {
    cout << "Grade A+";
}
else if (marks >= 80) {
    cout << "Grade A";
}
else if (marks >= 70) {
    cout << "Grade B";
}
else if (marks >= 60) {
    cout << "Grade C";
}
else {
    cout << "Need improvement";
}

Multiple else if Statements

Aap ek hi program mein multiple else if statements use kar sakte hain.

Multiple else if Example

int age = 20;

if (age < 13) {
    cout << "Child";
}
else if (age < 18) {
    cout << "Teenager";
}
else if (age < 60) {
    cout << "Adult";
}
else {
    cout << "Senior citizen";
}

Important

  • else if multiple conditions check karne ke liye use hota hai.
  • Conditions order mein check hoti hain.
  • Pehli true condition ka block execute hota hai.
  • Zarurat ke according multiple else if use kar sakte hain.
