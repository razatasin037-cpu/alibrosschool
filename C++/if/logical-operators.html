C++ Logical Operators

C++ Logical Operators

Logical operators ka use do ya do se zyada conditions ko combine karne ke liye kiya jata hai.

C++ mein mainly teen logical operators hote hain: &&, || aur !.

Logical Operators

&&Logical AND

Dono conditions true honi chahiye.

||Logical OR

Kam se kam ek condition true honi chahiye.

!Logical NOT

Condition ke result ko reverse karta hai.

Logical Operators Overview

bool a = true;
bool b = false;

cout << (a && b) << endl;
cout << (a || b) << endl;
cout << (!a) << endl;

Logical AND (&&)

AND operator && tab true hota hai jab dono conditions true hoti hain.

AND Example

int age = 20;
bool hasID = true;

if (age >= 18 && hasID) {
    cout << "Access granted.";
}

Logical OR (||)

OR operator || tab true hota hai jab kam se kam ek condition true ho.

OR Example

bool isStudent = true;
bool hasCoupon = false;

if (isStudent || hasCoupon) {
    cout << "Discount available.";
}

Logical NOT (!)

NOT operator ! condition ke result ko opposite kar deta hai.

NOT Example

bool loggedIn = false;

if (!loggedIn) {
    cout << "Please log in.";
}

Combining Conditions

Multiple conditions ko combine karke complex decision bhi liya ja sakta hai.

Combining Conditions Example

int age = 22;
bool hasID = true;
bool member = false;

if ((age >= 18 && hasID) || member) {
    cout << "Access allowed.";
}

Real Example

Maan lijiye kisi user ko access tab milega jab uski age 18 ya usse zyada ho aur uske paas valid ID bhi ho.

Access Check Example

int age = 20;
bool validID = true;

if (age >= 18 && validID) {
    cout << "You can access this page.";
}
else {
    cout << "Access denied.";
}

Important

  • && mein dono conditions true honi chahiye.
  • || mein kam se kam ek condition true honi chahiye.
  • ! condition ko reverse karta hai.
  • Logical operators ko if statements ke saath commonly use kiya jata hai.

Complete Logical Operators Example 

#include <iostream>
using namespace std;

int main() {
    int age = 21;
    bool hasID = true;
    bool member = false;

    if (age >= 18 && hasID) {
        cout << "Age and ID are valid." << endl;
    }

    if (member || hasID) {
        cout << "At least one condition is true." << endl;
    }

    if (!member) {
        cout << "User is not a member.";
    }

    return 0;
}
