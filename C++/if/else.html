C++ Else

The else Statement

else statement ka use tab kiya jata hai jab aap chahte hain ki agar if condition false ho jaye, to ek alternate code block execute ho.

Syntax

Example

C++ 
if (condition) {
  // jab condition true hogi tab yeh block chalega
} else {
  // jab condition false hogi tab yeh block chalega
}

Else Statement Example

Is example mein `time` (20) variable `18` se bada hai, isliye `if` condition false ho jayegi aur `else` block chalega:

Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int time = 20;

    if (time < 18) {
        cout << "Good day.";
    } else {
        cout << "Good evening."; // Output: Good evening.
    }

    return 0;
}

Real-Life Example

Check karna ki koi user door open karne ke liye sahi door code enter kar raha hai ya nahi:

Door Code Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    int doorCode = 1337;

    if (doorCode == 2024) {
        cout << "Correct code. The door is open.";
    } else {
        cout << "Wrong code. The door remains locked.";
    }

    return 0;
}

Important Rules

  • `else` ke aage kabhi koi condition `()` mein nahi likhi jaati.
  • `else` statement hamesha ek `if` statement ke turant baad hi aayega.
  • `else` block ke andar ka code tabhi execute hoga jab `if` ki condition `false` return karegi.
