C++ Math Functions

C++ mein mathematical operations perform karne ke liye built-in functions aur <cmath> library ka use kiya jata hai.

Max aur Min Functions

Do numbers me se maximum (sabse bada) value nikalne ke liye max(x, y) aur minimum (sabse chota) value nikalne ke liye min(x, y) function ka use hota hai.

Max and Min Example

Example

C++ 
#include <iostream>
using namespace std;

int main() {
    cout << max(5, 10); // Output: 10
    cout << min(5, 10); // Output: 5
    return 0;
}

C++ <cmath> Header File

Advance mathematical calculations jaise ki square root, power, logarithm, aur round off ke liye hume #include <cmath> header file add karni hoti hai.

cmath Functions Example

Example

C++ 
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << sqrt(64) << endl; // Output: 8 (Square Root)
    cout << round(2.6) << endl; // Output: 3 (Round off)
    cout << log(2) << endl; // Output: 0.693147 (Logarithm)
    cout << pow(2, 3) << endl; // Output: 8 (2 raised to power 3)
    return 0;
}

Anya Math Functions List

Neeche diye gaye table mein kuch popular <cmath> functions listed hain:

Function Description
abs(x) Absolute value (positive value) deta hai
ceil(x) Number ko nearest highest integer par round karta hai
floor(x) Number ko nearest lowest integer par round karta hai
pow(x, y) x ka power y (xy) calculate karta hai

Important

  • `max()` aur `min()` bina extra header file ke bhi standard library me mil jate hain.
  • `sqrt()`, `pow()`, aur `round()` ke liye `` include karna zaroori hai.
  • Trigonometric functions jaise `sin()`, `cos()`, `tan()` bhi `` me hote hain.
