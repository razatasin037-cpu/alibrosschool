C++ Break and Continue

Loops ko control karne ke liye break aur continue statements ka use karte hain.

C++ Break

C++ mein break statement ka use loop ko turant stop karne ke liye hota hai.

Jab program ko koi particular condition milti hai, tab break loop se bahar nikal jata hai. Matlab loop ki remaining iterations execute nahi hoti.

Simple Meaning

break ka matlab hai: "Loop ko abhi ke abhi stop karo."

Break Syntax

Syntax 
break;

Break Example

Neeche loop numbers print karta hai, lekin jab i == 4 hota hai, break loop ko stop kar deta hai.

Example 1: Break in For Loop

C++ 
for (int i = 0; i < 10; i++) {
    if (i == 4) {
        break;
    }

    cout << i << "\n";
}

Output

0
1
2
3

C++ Continue

C++ mein continue statement current iteration ko skip karta hai aur loop ki next iteration par chala jata hai.

Iska matlab loop completely stop nahi hota. Sirf current iteration ka remaining code skip hota hai.

Simple Meaning

continue ka matlab hai: "Is iteration ko skip karo aur next iteration par jao."

Continue Syntax

Syntax 
continue;

Continue Example

Is example mein jab i == 4 hota hai, value 4 print nahi hoti. Loop next iteration par chala jata hai.

Example 2: Continue in For Loop

C++ 
for (int i = 0; i < 10; i++) {
    if (i == 4) {
        continue;
    }

    cout << i << "\n";
}

Output

0
1
2
3
5
6
7
8
9

Break and Continue in While Loop

break aur continue ko while loop ke saath bhi use kar sakte hain.

Break Example

While Loop 
int i = 0;

while (i < 10) {
    cout << i << "\n";

    i++;

    if (i == 4) {
        break;
    }
}

Continue Example

While Loop 
int i = 0;

while (i < 10) {
    if (i == 4) {
        i++;
        continue;
    }

    cout << i << "\n";

    i++;
}

Break vs Continue

Break Continue
Loop ko completely stop karta hai. Sirf current iteration ko skip karta hai.
Loop ke bahar control chala jata hai. Control next iteration par chala jata hai.
break; continue;

Important Points

  • break loop ko completely stop karta hai.
  • continue current iteration ko skip karta hai.
  • Dono statements ko for aur while loops mein use kar sakte hain.
  • break ke baad loop ki remaining iterations execute nahi hoti.
  • continue ke baad loop next iteration se continue hota hai.

Summary

C++ mein break aur continue loop ko control karne ke important statements hain. break loop ko completely stop karta hai, jabki continue current iteration ko skip karke next iteration par chala jata hai.
