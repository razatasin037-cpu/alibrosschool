SQL Aliases

Alias column ya table ko temporary readable name deta hai. Complex queries ko samajhna easy ho jata hai.

SQL Aliases Kya Hai?

Alias column ya table ko temporary readable name deta hai. Complex queries ko samajhna easy ho jata hai. Is concept ko samajhne ke liye pehle syntax dekho, phir example ko sample data par run karke output observe karo.

Basic Example 

SELECT name AS student_name,
       city AS student_city
FROM students;

Step-by-Step Samjho

Column Select Karo

Sabse pehle jis column ko result mein dikhana hai, usko SELECT ke andar likhte hain.

AS Keyword

AS keyword ke through original column ko ek temporary readable naam diya ja sakta hai.

Alias Name

Alias name result mein original column name ki jagah display hota hai.

Result

Query execute karne ke baad output mein alias diya hua readable naam दिखाई deta hai.

Another Example

Ab isi concept ko ek aur example se practice karo. Values change karke result mein difference dekho.

Practice Query 

SELECT s.name
FROM students AS s;

Practical Use

Real projects mein ye concept students, users, products, orders aur reports jaise data ke saath use ho sakta hai. Pehle small sample table par practice karo aur phir apne project mein apply karo.

Important Points

  • Alias temporary naam hota hai.
  • Alias original table ya column ka naam permanently change nahi karta.
  • AS keyword alias define karne ke liye commonly use hota hai.
  • Table aliases JOIN queries mein especially useful hote hain.
  • Query ko sample data par run karke output verify karo.

Best Practices

  • Readable SQL ke liye proper indentation rakho.
  • Alias ke liye short aur meaningful names use karo.
  • JOIN queries mein table aliases consistently use karo.
  • Complex queries mein readable naming convention maintain karo.

Summary

SQL Aliases ka main concept samajhne ke baad aap SQL queries ko better tarike se read aur write kar sakte ho. Syntax ke saath practical examples aur repeated practice se concept strong hota hai.
