HTML Element Kya Hota Hai?

An HTML Element Start Tag se lekar End Tag tak ka sab kuch hota hai. Isme content tag ke andar likha jata hai.

Syntax Format: <tagname> Content yahan likhein... </tagname>

HTML Elements Table Examples

Kuch popular HTML elements aur unke components:

Start Tag Element Content End Tag
<h1> Mera Pehla Heading </h1>
<p> Mera pehla paragraph. </p>
<button> Click Me </button>
<br> None (Empty Element) None

Nested HTML Elements

HTML elements ko ek doosre ke andar dala ja sakta hai. Is process ko Nesting kehte hain. Webpage ka pura structure nesting par hi chalta hai. 

<!DOCTYPE html>
<html>
  <body>

    <h1>Heading <span>Text</span></h1>
    <p>Ye ek <b>bold paragraph</b> hai.</p>

  </body>
</html>

Empty HTML Elements (Self-closing)

Jin HTML elements me koi text/content nahi hota aur unka koi closing tag nahi hota, unhein Empty Elements kehte hain.

  • <br> - Line break dene ke liye use hota hai.
  • <hr> - Horizontal rule (line) draw karne ke liye.
  • <img> - Image attach karne ke liye tag.
  • <input> - Form input fields ke liye.
