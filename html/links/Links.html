HTML Links (Hyperlinks) Complete Guide

HTML me links ko Hyperlinks kaha jata hai. Unka upayog external web pages, internal sections, files, image click redirect, phone numbers aur email setup ke liye kiya jata hai.

Link banane ke liye HTML me <a> (Anchor Tag) ka upayog hota hai aur destination path href attribute ke andar define kiya jata hai.

1. Basic Text Link

Ye sabse simple hyperlink style hai jisme default browser window me URL open hota hai. 

<a href="https://www.google.com">
  Visit Google
</a>
Visit Google

2. Open Link in New Tab

target="_blank" ka use page ko naye tab me open karne ke liye hota hai. 

<a href="https://www.wikipedia.org" target="_blank">
  Open Wikipedia in New Tab
</a>
Open Wikipedia in New Tab

3. Absolute vs Relative Path Links

Full web address (Absolute) vs Local project file address (Relative). 

<!-- Absolute Link -->
<a href="https://www.google.com">Google</a>

<!-- Relative Link -->
<a href="./HTML_CSS.html">CSS Tutorial</a>
Absolute: Google Website Relative: HTML CSS Page

4. Image Link

Image ke andar <a> tag wrapper lagakar image ko clickable banaya ja sakta hai. 

<a href="https://www.google.com" target="_blank">
  <img src="logo.png" alt="Google Logo" />
</a>

5. Section Bookmark Link (#)

Same page ke kisi specific element tak direct scroll karne ke liye href="#id_name" ka use hota hai. 

<!-- Target Link -->
<a href="#table-section">Go to Reference Table</a>

<!-- Target Element -->
<div id="table-section">Table Content...</div>
Jump to Table Below ↓

6. Button Link

JS onclick ya custom CSS button layout ka use karke link create karna. 

<button onclick="location.href='https://google.com'">
  Click Me
</button>

7. Mail, Call & Download Links

Directly email client open karna, call start karna ya file download initiation trigger karna. 

<!-- Email Link -->
<a href="mailto:test@example.com">Send Mail</a>

<!-- Phone Call -->
<a href="tel:+1234567890">Call Us</a>

<!-- Download Link -->
<a href="file.pdf" download>Download PDF</a>
Mail Call Download

All Target Attribute Values Reference

Target Attribute Behavior / Description
_self Document ko same window/tab me open karta hai (Default).
_blank Document ko ek new window ya tab me open karta hai.
_parent Document ko parent frame me open karta hai.
_top Document ko full body window me open karta hai.
