HTML Favicon Guide

Favicon ek chhota sa icon (image) hota hai jo browser tab me aapke web page ke title ke paas dikhai deta hai.

Ye website ki branding aur user identification ke liye bohot zaroori hota hai taaki users multiple open tabs me se aapki site ko aasani se pehchan sakein.

1. Favicon Kaise Add Karein?

Favicon ko add karne ke liye HTML ke <head> section ke andar <link> tag ka use kiya jata hai. 

<!DOCTYPE html>
<html>
<head>
  <title>My Awesome Website</title>
  
  <!-- Favicon Link Tag -->
  <link 
    rel="icon" 
    type="image/x-icon" 
    href="favicon.ico">
</head>
<body>
  <h1>Welcome to my site</h1>
</body>
</html>
My Awesome Website

💡 Browser tab me title ke bagal me dikhne wala icon hi Favicon hota hai.

2. Supported Favicon Formats

Favicon ke liye aap alag-alag image formats ka use kar sakte hain:

Standard

.ICO File

Traditional browser format. Saare old & modern browsers supports karte hain.

type="image/x-icon"
Modern

.PNG File

High quality transparent logos ke liye sabse zyada use hone wala format.

type="image/png"
Scalable

.SVG File

Vector format jo kisi bhi screen size par crisp aur clear dikhta hai.

type="image/svg+xml"

3. Attributes Reference

Attribute Value Description
rel "icon" / "shortcut icon" HTML document aur linked file ke beech relationship batata hai.
href URL path Favicon image ka path (file location) specify karta hai.
type MIME Type Image file ka exact format batata hai (e.g. image/x-icon, image/png).
sizes "16x16" / "32x32" Optional attribute jo icon ke dimensions specify karne me help karta hai.

4. Practical Favicon Examples

Alag-alag devices (Mobile, Desktop, Apple iOS) aur requirement ke hisab se favicon implementation ke standard examples:

Recommended Best Practice Multiple Sizes

High-DPI / Multi-Device Support

Normal desktop aur Retina displays ke liye alag-alag sizes provide karna: 

<!-- 16x16 for small tabs -->
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">

<!-- 32x32 for standard displays -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
iOS / Safari Mobile Bookmark

Apple Touch Icon

Jab user aapki website ko iPhone/iPad ke Home Screen par add karta hai: 

<!-- Apple Home Screen Bookmark -->
<link 
  rel="apple-touch-icon" 
  sizes="180x180" 
  href="/apple-touch-icon.png">
Dark/Light Mode Ready Vector SVG

Dynamic SVG Favicon

SVG favicon pixelated nahi hota aur CSS theme queries ko support karta hai: 

<link 
  rel="icon" 
  type="image/svg+xml" 
  href="/icon.svg">
Animated GIF Format

Animated Favicon

Tab me animated icon dikhane ke liye GIF image ka use kiya jata hai: 

<link 
  rel="icon" 
  type="image/gif" 
  href="/animated-favicon.gif">
