HTML Form Basics

HTML Form ka use user input collect karne ke liye kiya jata hai. Yeh user input aamtaur par processing ke liye server par bheja jata hai.

1. The <form> Element

HTML <form> element ka use user input ke liye HTML form create karne mein hota hai: 

<form>
form elements
</form>

<form> element alag-alag tarah ke input elements ke liye ek container hota hai, jaise: text fields, checkboxes, radio buttons, submit buttons, aadi.

2. The <input> Element

HTML <input> element sabse zyada istemaal hone wala form element hai. Ek <input> element ko type attribute ke aadhar par kai tarikon se display kiya ja sakta hai.

Type Description
<input type="text"> Ek single-line text input field display karta hai
<input type="radio"> Ek radio button display karta hai (kai choices mein se ek select karne ke liye)
<input type="checkbox"> Ek checkbox display karta hai (kai choices mein se zero ya zyada select karne ke liye)
<input type="submit"> Ek submit button display karta hai (form submit karne ke liye)
<input type="button"> Ek clickable button display karta hai

3. Text Fields & The <label> Element

<input type="text"> text input ke liye ek single-line input field define karta hai. Note karein ki form khud visible nahi hota. Saath hi dhyan dein ki ek input field ki default width 20 characters hoti hai.

<label> tag kai form elements ke liye ek label define karta hai. Yeh screen-reader users ke liye useful hai, aur un users ki bhi madad karta hai jinhe bahut chote regions par click karne mein dikkat hoti hai. <label> tag ka for attribute aur <input> element ka id attribute barabar hona chahiye taaki unhe ek saath bind kiya ja sake. 

<form>
  <label for="fname">First name:</label><br>
  <input type="text" id="fname" name="fname"><br>
  <label for="lname">Last name:</label><br>
  <input type="text" id="lname" name="lname">
</form>

4. Radio Buttons

<input type="radio"> ek radio button define karta hai. Radio buttons user ko limited choices mein se sirf EK select karne dete hain. 

<p>Choose your favorite Web language:</p>

<form>
  <input type="radio" id="html" name="fav_language" value="HTML">
  <label for="html">HTML</label><br>
  <input type="radio" id="css" name="fav_language" value="CSS">
  <label for="css">CSS</label><br>
  <input type="radio" id="javascript" name="fav_language" value="JavaScript">
  <label for="javascript">JavaScript</label>
</form>

5. Checkboxes

<input type="checkbox"> ek checkbox define karta hai. Checkboxes user ko limited choices mein se ZERO ya MORE (zyada) options select karne dete hain. 

<form>
  <input type="checkbox" id="vehicle1" name="vehicle1" value="Bike">
  <label for="vehicle1"> I have a bike</label><br>
  <input type="checkbox" id="vehicle2" name="vehicle2" value="Car">
  <label for="vehicle2"> I have a car</label><br>
  <input type="checkbox" id="vehicle3" name="vehicle3" value="Boat">
  <label for="vehicle3"> I have a boat</label>
</form>

6. The Submit Button

<input type="submit"> form data ko form-handler par submit karne ke liye ek button define karta hai. Form-handler aamtaur par server par ek file hoti hai jisme input data ko process karne ke liye ek script hoti hai. Form-handler form ke action attribute mein specify kiya jata hai. 

<form action="/action_page.php">
  <label for="fname">First name:</label><br>
  <input type="text" id="fname" name="fname" value="John"><br>
  <label for="lname">Last name:</label><br>
  <input type="text" id="lname" name="lname" value="Doe"><br><br>
  <input type="submit" value="Submit">
</form>
