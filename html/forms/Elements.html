Form Elements Basics

HTML forms ke andar alag-alag tarah ke interactive controls hote hain jaise input fields, drop-down lists, textareas, aur buttons. Inhe Form Elements kaha jata hai.

1. The <input> Element

Yeh sabse zyada use hone wala form element hai. type attribute ke basis par iska behavior change hota hai (e.g., text, password, checkbox, radio). 

<label for="username">Username:</label>
<input type="text" id="username" name="username">

2. The <label> Element

<label> element form controls ko text caption deta hai. Isse screen readers aur mobile accessibility improve hoti hai. 

<label for="email">Email Address:</label>
<input type="email" id="email" name="email">

3. The <select> and <option> Elements

<select> element ek drop-down list banata hai, aur <option> tags list ke items define karte hain. 

<label for="cars">Choose a car:</label>
<select id="cars" name="cars">
  <option value="volvo">Volvo</option>
  <option value="bmw">BMW</option>
  <option value="audi">Audi</option>
</select>

4. The <textarea> Element

Multi-line text input (jaise feedback, address ya message) lene ke liye <textarea> use kiya jata hai. 

<label for="message">Message:</label>
<textarea id="message" name="message" rows="4" cols="50">
Type your message here...
</textarea>

5. The <button> Element

<button> element clickable button define karta hai. Isme aap text, images ya icons add kar sakte hain. 

<button type="button" onclick="alert('Hello World!')">
  Click Me!
</button>

6. The <fieldset> and <legend> Elements

<fieldset> related elements ko ek group me box kar deta hai, aur <legend> us box ka title/caption define karta hai. 

<fieldset>
  <legend>Personal Info:</legend>

  <label for="fname">First name:</label>
  <input type="text" id="fname" name="fname">
</fieldset>
