Form Attributes Basics

HTML <form> element ke attributes yeh decide karte hain ki form ka data server par kahan aur kaise bheja jayega.

1. The Action Attribute

action attribute specify karta hai ki form submit hone ke baad form ka data kis URL ya file par bheja jayega. 

<form action="/action_page.php">

  <label for="fname">First name:</label>
  <br>

  <input
    type="text"
    id="fname"
    name="fname"
    value="John"
  >

  <br>

  <input type="submit" value="Submit">

</form>

2. The Target Attribute

target attribute batata hai ki form submit hone ke baad response kahan open hoga.

Value Description
_blank Response naye tab ya window me open hota hai.
_self Response current tab me open hota hai. Ye default hai. 
<form
  action="/action_page.php"
  target="_blank"
>

  ...

</form>

3. The Method Attribute (GET vs POST)

method attribute HTTP method specify karta hai jiske through form data server par submit hota hai.

GET Method

GET method me form ka data URL ke query parameters ke through send hota hai.

example.com?name=John

Search aur filter jaise non-sensitive data ke liye GET commonly use hota hai.

POST Method

POST method me form data HTTP request body ke through server par send hota hai.

Login, registration, database insert aur file upload jaise operations me POST commonly use hota hai. 

<form
  action="/action_page.php"
  method="POST"
>

  ...

</form>

4. The Autocomplete Attribute

autocomplete attribute browser ko batata hai ki pehle enter ki gayi information automatically suggest/fill karni hai ya nahi.

Value Meaning
on Browser autocomplete use kar sakta hai.
off Browser ko autocomplete na karne ka hint milta hai. 
<form
  action="/action_page.php"
  autocomplete="on"
>

  <input
    type="text"
    name="name"
  >

</form>

5. The Novalidate Attribute

novalidate attribute form submit karte waqt browser ki built-in HTML validation ko disable karta hai. 

<form
  action="/action_page.php"
  method="POST"
  novalidate
>

  <label for="email">
    Email:
  </label>

  <input
    type="email"
    id="email"
    name="email"
    required
  >

  <input
    type="submit"
    value="Submit"
  >

</form>

Note: Agar novalidate laga hua hai, to browser form submit karte waqt built-in HTML validation ko run nahi karega.
