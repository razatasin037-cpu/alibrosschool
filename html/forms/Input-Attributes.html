Input Attributes Overview

Input Attributes ka use HTML <input> elements ka behavior, restriction, default values aur validation rules decide karne ke liye kiya jata hai.

Important Input Attributes

Attribute Description
value Input field ke liye initial (default) value set karta hai.
readonly Input field ko read-only banata hai (modify nahi ho sakta, par submit hota hai).
disabled Input field ko disable kar deta hai (modify aur submit dono nahi hota).
placeholder Input field ke andar temporary hint text dikhata hai.
required Form submit karne se pehle field ko fill karna mandatory banata hai.
maxlength / minlength Maximum aur Minimum characters count limit set karta hai.
min / max Numeric inputs ke liye minimum aur maximum limits define karta hai.
autofocus Page load hote hi input field par automatic cursor focus kar deta hai.

1. Value, Readonly and Disabled

Ye attributes field ki state aur default values ko control karte hain: 

<!-- Default Value -->
<input type="text" value="John Doe">

<!-- Read-only Field -->
<input type="text" value="ID: 1001" readonly>

<!-- Disabled Field -->
<input type="text" value="Not Applicable" disabled>

2. Placeholder and Required

User guidance aur client-side validation ke liye standard attributes: 

<label for="email">Email:</label>
<input type="email" id="email" placeholder="name@example.com" required>

3. Character and Numeric Limits

Numeric values aur text character length par restrictions lagane ke liye: 

<!-- Character length limit -->
<input type="text" placeholder="Max 10 chars" maxlength="10">

<!-- Numeric range limit -->
<input type="number" min="1" max="100" value="18">
