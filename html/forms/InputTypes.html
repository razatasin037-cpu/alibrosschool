Input Types Overview

HTML <input> element me type attribute define karta hai ki user se kis tarah ka data collect kiya jayega, jaise text, password, email, numbers ya files.

Commonly Used Input Types

Input Type Description
text Single-line text field banata hai (default value).
password Characters mask ho jate hain (dots ya asterisks me).
email Email format check karta hai aur automatic validation deta hai.
number Sirf numeric values allow karta hai.
checkbox Multiple options select karne ke liye checkbox deta hai.
radio Group me se sirf ek option choose karne ke liye use hota hai.
file User ko file upload karne ka option deta hai.
submit Form data submit karne ke liye button banata hai.

1. Text and Password Inputs

Username aur passwords collect karne ke liye use hone wale basic input types: 

<label for="user">Username:</label>
<input type="text" id="user" name="user">

<label for="pass">Password:</label>
<input type="password" id="pass" name="pass">

2. Radio Buttons and Checkboxes

Radio buttons single selection ke liye aur checkboxes multi-selection ke liye hote hain: 

<!-- Radio Buttons -->
<input type="radio" id="male" name="gender" value="male">
<label for="male">Male</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">Female</label>

<!-- Checkbox -->
<input type="checkbox" id="subscribe" name="subscribe" value="yes">
<label for="subscribe">Subscribe to newsletter</label>

3. Date and Time Picker Inputs

Browsers me inbuilt date/time selectors enable karne ke liye in types ka use hota hai: 

<label for="birthday">Birthday:</label>
<input type="date" id="birthday" name="birthday">

<label for="appt">Select Time:</label>
<input type="time" id="appt" name="appt">

4. Color, Range and File Inputs

HTML5 ke specialized inputs color picker, slider control aur file uploader enable karte hain: 

<label for="favcolor">Select Color:</label>
<input type="color" id="favcolor" name="favcolor">

<label for="volume">Volume:</label>
<input type="range" id="volume" name="volume" min="0" max="100">

<label for="myfile">Select File:</label>
<input type="file" id="myfile" name="myfile">
