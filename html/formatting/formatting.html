HTML Text Formatting Kya Hoti Hai?

HTML me text ko special visual look (Bold, Italic, Highlighted, Subscript, etc.) dene ya special meaning show karne ke liye Formatting Elements ka use hota hai.

Ye elements text ka visual presence change karne ke sath screen readers aur Search Engines ko bhi batate hain ki kaunsa text important hai.

Practical Code Example

Basic formatting tags ka code aur unka real-time output dekhein:

index.html HTML 
<p>Ye <b>Bold Text</b> hai.</p>
<p>Ye <strong>Important Text</strong> hai.</p>
<p>Ye <i>Italic Text</i> hai.</p>
<p>Ye <em>Emphasized Text</em> hai.</p>
<p>Ye <mark>Marked Text</mark> hai.</p>
<p>H<sub>2</sub>O (Subscript) aur X<sup>2</sup> (Superscript)</p>

Formatting Tags Reference

Tag Description Browser Output Style
<b> Bold text (Bina kisi extra importance ke). Bold Text
<strong> Important text (Strong importance show karta hai). Important Text
<i> Italic text (Technical term, foreign words, etc.). Italic Text
<em> Emphasized text (Stress dene ke liye). Emphasized Text
<mark> Highlighted/Marked text. Marked Text
<small> Smaller text (Copyright info/Fine print ke liye). Small Text
<del> Deleted text (Line-through strike effect). Deleted Text
<ins> Inserted text (Underline effect). Inserted Text
<sub> Subscript text (Chemical formulas ke liye). H2O
<sup> Superscript text (Math powers/Dates ke liye). X2, 1st

Best Practices (<b> vs <strong>)

  • Semantic Meaning: Structural importance aur SEO ke liye <strong> aur <em> ka use karein. Only visual look ke liye <b> aur <i> use karein.
  • Screen Readers: Screen readers <strong> aur <em> tags ko bolte waqt alag emphasis/tone ke sath read karte hain, jo Accessibility (a11y) ke liye accha hai.
