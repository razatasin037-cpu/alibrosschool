HTML Class Attribute Kya Hai?

HTML me class attribute ka upyog ek ya multiple HTML elements ko identify karne ke liye kiya jata hai. CSS me class name ke aage dot (.) lagakar style apply kiya jata hai.

Class Attribute Ki Khasiyat

Reusable

Ek hi class name ko aap page ke multiple HTML elements par apply kar sakte hain.

Multiple Classes

Ek single element me space dekar multiple class names (jaise class="card dark-mode") diye ja sakte hain.

Case Sensitive

Class names case-sensitive hote hain. .btn aur .BTN dono alag consider honge.

CSS <style> Tag Example

CSS Styling

Dekhein kaise <style> tag ke andar dot (.) lagakar classes define ki jati hain aur HTML elements me use hoti hain: 

<style>
  /* Class Selector dot (.) se start hota hai */
  .card-box {
    background-color: #0f172a;
    border: 2px solid #3158ff;
    border-radius: 16px;
    padding: 24px;
  }

  .btn-custom {
    background-color: #3158ff;
    color: #ffffff;
    padding: 10px 20px;
    border-radius: 10px;
  }

  .text-highlight {
    color: #facc15;
  }
</style>

HTML Code Example

Code Block

Niche dekhein kaise hum alag-alag elements par same class aur multiple classes use kar sakte hain: 

<!-- Single Class Reusability -->
<h2 class="heading">Pahli Heading</h2>
<h2 class="heading">Dusri Heading</h2>

<!-- Multiple Classes on One Element -->
<div class="card active">
  <p class="text-highlight">Class attribute multiple elements ko styling dene ke kaam aata hai.</p>
</div>

When to use Classes?

  • ✓ Jab multiple elements ko same CSS styles dene hon (jaise sabhi buttons ya cards ko ek jaisa look dena).
  • ✓ JavaScript me getElementsByClassName() ya querySelectorAll() se group of elements select karne ke liye.
  • ✕ Khas Baat: Class names kabhi number se start na karein (e.g., class="1box" galat hai, class="box1" sahi hai).
