HTML Layout Kya Hai?

Webpages me alag-alag sections (Header, Navigation Bar, Main Content, Sidebar, aur Footer) ko organize aur structure karne ke liye HTML5 Semantic Layout Elements ka upyog kiya jata hai. Isse website accessibility aur SEO me behter banti hai.

Standard HTML5 Layout Structure

Visual Wireframe
<header> (Website Logo & Navigation Title)
<nav> (Navigation Links)
<main> <section> aur <article> content yahan aata hai
<aside> (Sidebar Links / Ads)
<footer> (Copyright, Links & Info)

HTML Layout Elements Table

Quick Reference
Tag Name Kaam / Purpose Kahan Use Hota Hai?
<header> Page ya section ke shuruaati content/logo ke liye. Top Banner / Navigation Header
<nav> Navigation links ka container hota hai. Menu Links, Navbar
<main> Page ka mukhya/primary unique content. Primary Article / Tutorial Section
<section> Document me topic wise alag-alag group/parts ke liye. Features, Services, About Section
<article> Independent, self-contained content ke liye. Blog Posts, News Cards, User Comments
<aside> Main content se related secondary/side details. Sidebar Menu, Related Links, Ads
<footer> Page ka bottom part jisme details rehti hain. Copyright, Social Links, Terms

HTML Layout Example

Code Block

HTML5 layout structure likhne ka clean example code: 

<!-- Website Header -->
<header>
  <h1>My Official Website</h1>
  <nav>
    <a href="#home">Home</a> | 
    <a href="#about">About</a>
  </nav>
</header>

<!-- Main Content Area -->
<main>
  <section>
    <h2>Welcome Section</h2>
    <p>Yeh website ka primary content hai.</p>
  </section>

  <aside>
    <h3>Sidebar Links</h3>
    <p>Related posts yahan dikhenge.</p>
  </aside>
</main>

<!-- Website Footer -->
<footer>
  <p>&copy; 2026 All Rights Reserved.</p>
</footer>

Layout Best Practices

  • ✓ Use Semantic Tags: Layout banane ke liye purane <div class="header"> ki jagah hamesha native HTML5 tags (<header>, <main>, etc.) ka upyog karein.
  • ✓ Single <main> Tag: Har web page me poore main content ke liye sirf ek hi <main> element ka use karein.
  • ✕ Avoid Div Overuse (Divitis): Bina kisi wajah ke har element ko <div> me wrap karne se bachein.
