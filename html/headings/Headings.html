HTML Headings Kya Hoti Hain?

HTML Headings titles ya subtitles hote hain jinhein aap apne webpage par show karna chahte hain.

HTML me <h1> se <h6> tak kul 6 types ki headings hoti hain. <h1> sabse badi aur main heading hoti hai, jabki <h6> sabse chhoti heading hoti hai.

Practical Code Example

Niche diye gaye HTML code ko dekhein aur uska browser preview bagal me samjhein:

index.html HTML 
<!DOCTYPE html>
<html>
<body>

  <h1>This is Heading 1</h1>
  <h2>This is Heading 2</h2>
  <h3>This is Heading 3</h3>
  <h4>This is Heading 4</h4>
  <h5>This is Heading 5</h5>
  <h6>This is Heading 6</h6>

</body>
</html>

Heading Tags & Unka Default Usage

<h1> Tag:

Heading 1 (Main Webpage Title)

<h2> Tag:

Heading 2 (Main Sub-section)

<h3> Tag:

Heading 3 (Sub-topic Header)

<h4> Tag:

Heading 4 (Minor Sub-topic)

<h5> Tag:
Heading 5 (Detail Header)
<h6> Tag:
Heading 6 (Smallest Header)

Headings Kyun Zaroori Hain? (SEO & Structure)

  • 1. Search Engine Optimization (SEO): Search engines (jaise Google) headings ka use karke aapke webpage ka structure aur main content samajhte hain.
  • 2. Better User Experience: Users poora page padhne ke bajaye headings ko dekh kar samajh jaate hain ki page par kya information hai.
  • 3. Only One <h1> Rule: Hamesha ek page par sirf ek hi <h1> main heading honi chahiye. Baaki sub-topics ke liye <h2> se <h6> ka use karein.
