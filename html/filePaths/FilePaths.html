HTML File Path Kya Hai?

HTML me File Path kisi external file (jaise Images, CSS, JavaScript, ya doosre HTML pages) ka address batata hai. Yeh browser ko batata hai ki file folder structure me kahan par hai.

Types of File Paths

Absolute File Path

Yeh internet par file ka pura Web URL address (https://...) hota hai.

https://www.example.com/images/logo.png

Relative File Path

Yeh current working file/folder ke hisab se relative address hota hai.

../images/logo.png

Relative Path Symbols & Rules

Cheat Sheet
Path Syntax Kya Matlab Hai? Example Use
picture.jpg File usi same folder me hai jahan HTML file hai. <img src="picture.jpg">
images/picture.jpg Same folder ke andar images naam ke sub-folder me. <img src="images/picture.jpg">
/images/picture.jpg Root directory (main domain folder) ke andar. <img src="/images/picture.jpg">
../picture.jpg Current folder se 1 folder piche (parent directory) me. <img src="../picture.jpg">
../../js/app.js 2 level piche jakar js folder ke andar file. <script src="../../js/app.js">

HTML Code Example

Code Block

Real projects me file paths embed karne ke alag-alag tarike: 

<!-- Absolute Path (External Web URL) -->
<img src="https://cdn.tailwindcss.com" alt="External File">

<!-- Relative Path: File in Subfolder -->
<img src="assets/images/logo.png" alt="Logo">

<!-- Relative Path: Going 1 Step Backwards (Parent Folder) -->
<a href="../index.html" class="text-blue-400">Back to Home</a>

<!-- Relative Path: Going 2 Folders Backwards -->
<script src="../../js/sidebar.js"></script>

File Path Best Practices

  • ✓ Use Relative Paths for Local Files: Website deployment easy rakhne ke liye hamesha local files ke liye relative paths hi use karein.
  • ✓ Case-Sensitivity: File names aur extensions me capital/small letters dhyan se likhein (jaise Image.PNG aur image.png Linux servers par alag hote hain).
  • ✕ Avoid Hardcoded Local Disk Paths: HTML me C:\Users\Name\Desktop\image.png jaisa path mat use karein, yeh dusre kisi browser ya server par nahi chalega.
