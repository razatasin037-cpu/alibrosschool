HTML Attributes Kya Hote Hain?

HTML Attributes HTML elements ko extra information ya properties dene ke liye use kiye jaate hain.

Ye hamesha Start Tag me likhe jaate hain aur inka format name="value" pair me hota hai.

Most Common HTML Attributes

href Attribute

Ye <a> tag ke sath link ka URL specify karta hai.

<a href="https://example.com">Visit Site</a>

src Attribute

Ye <img> tag me image ka file path define karta hai.

<img src="img_girl.jpg">

alt Attribute

Agar image load na ho sake toh ye alternate text show karta hai.

<img src="logo.png" alt="Company Logo">

style Attribute

Ye element par inline CSS styling (color, size) add karta hai.

<p style="color:red;">Red Text</p>

Attribute Quick Reference Table

Attribute Kiske Sath Use Hota Hai Description
href <a> Link URL specify karta hai
src <img>, <script> Media ya file ka source path deta hai
width & height <img>, <video> Elements ke dimensions (pixels) set karta hai
title Any HTML Element Hover karne par tooltip text dikhata hai
lang <html> Document ki language specify karta hai
