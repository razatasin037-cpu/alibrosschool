HTML <head> Element Kya Hai?

HTML me <head> element document ka container hota hai jisme Metadata (webpage ke bare me data) rakha jata hai. Iske andar ka content browser screen par visible nahi hota, balki browser aur search engines (SEO) ke liye use hota hai.

<head> Tag Ke andar Aane Wale Important Elements

<title>

Browser tab me dikhne wala document ka title define karta hai aur SEO ke liye sabse important hai.

<meta>

Character set, page description, keywords aur viewport (responsive zoom) jaise settings define karta hai.

<link>

External stylesheet (CSS), favicon icons, aur fonts ko document se connect karne ke liye use hota hai.

Head Child Tags Overview

Quick Reference
Tag Name Kaam / Description Example Use
<title> Browser tab par page ka naam dikhata hai. <title>My Website</title>
<meta> SEO aur responsiveness information set karta hai. <meta name="viewport" ...>
<link> External CSS file ya Favicon icon add karta hai. <link rel="stylesheet" href="style.css">
<style> Internal CSS styling likhne ke liye. <style> body { color: red; } </style>
<script> JavaScript file/code load karne ke liye. <script src="app.js"></script>

Complete <head> Structure Example

Code Block

Ek modern web application ke `` tag ka standard format: 

<head>
  <!-- UTF-8 Character Encoding -->
  <meta charset="UTF-8">

  <!-- Mobile Responsive Viewport Settings -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Webpage Title -->
  <title>My Awesome Website</title>

  <!-- SEO Meta Tags -->
  <meta name="description" content="Learn HTML from scratch with tutorials">
  <meta name="keywords" content="HTML, CSS, JavaScript, Web Development">

  <!-- External Stylesheet -->
  <link rel="stylesheet" href="style.css">

  <!-- Favicon Icon -->
  <link rel="icon" type="image/x-icon" href="favicon.ico">
</head>

Head Element Best Practices

  • ✓ Always Include Viewport Meta: Mobile responsiveness ke liye <meta name="viewport" content="width=device-width, initial-scale=1"> add karna mandatory hai.
  • ✓ Unique Titles for Pages: Har page ke liye unique aur descriptive <title> tag ka upyog karein.
  • ✕ Don't Put Visible Elements: <head> ke andar <p>, <h1>, ya <div> jaise visible tags mat likhein.
