Introduction to HTML Lists

HTML Lists ka use web pages par related items ko structured aur organized tarike se group karne ke liye kiya jata hai.

Types of HTML Lists

HTML me mukhya roop se 3 tarah ki lists hoti hain:

<ul>

Unordered List

Bullet points ke roop me items dikhane ke liye.

 <ol>

Ordered List

Numbers ya Letters ke sequence me items dikhane ke liye.

 <dl>

Description List

Terms aur unki definitions ko align karne ke liye.

Lists Visual Example

Basic List Structure Example

Har list item ko <li> (List Item) tag ke andar rakha jata hai: 

<!-- List Items Example -->
<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>
