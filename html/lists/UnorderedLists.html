Unordered HTML List Kya Hai?

Ek unordered list <ul> tag se shuru hoti hai. Iske items me koi particular order ya numbering nahi hoti, balki yeh bullet points ke roop me dikhayi dete hain.

Basic Example

Unordered list banane ke liye har item ko <li> tag ke andar rakha jata hai: 

<ul>
  <li>Coffee</li>
  <li>Tea</li>
  <li>Milk</li>
</ul>
Output Preview:
  • Coffee
  • Tea
  • Milk

Unordered List Item Markers (CSS Styles)

CSS property list-style-type ka use karke aap bullet markers ki shape badal sakte hain:

list-style-type: disc;

Default shape (Filled black circle)

  • HTML5
  • CSS3
list-style-type: circle;

Hollow circle bullet marker

  • HTML5
  • CSS3
list-style-type: square;

Solid square bullet marker

  • HTML5
  • CSS3
list-style-type: none;

Bina kisi bullet marker ke (Navigation menus ke liye best)

  • HTML5
  • CSS3

Nested Unordered Lists

Aap ek list ke andar doosri list bhi daal sakte hain (jise Nested List kaha jata hai): 

<ul>
  <li>Coffee</li>
  <li>Tea
    <ul>
      <li>Black tea</li>
      <li>Green tea</li>
    </ul>
  </li>
  <li>Milk</li>
</ul>
Output Preview:
  • Coffee
  • Tea
    • Black tea
    • Green tea
  • Milk
