Ordered HTML List Kya Hai?

Ordered list <ol> tag se shuru hoti hai. Isme sabhi items ek specific order, number, ya alphabetical sequence me display hote hain.

1. Basic Ordered List

By default, HTML ordered list numeric numbers (1, 2, 3...) ka use karti hai: 

<ol>
  <li>First item</li>
  <li>Second item</li>
  <li>Third item</li>
</ol>
Output Preview:
  1. First item
  2. Second item
  3. Third item

2. The `type` Attribute

type attribute ka use karke aap numbering ka style badal sakte hain:

<ol type="A">

Uppercase Letters

  1. Apple
  2. Banana
<ol type="a">

Lowercase Letters

  1. Apple
  2. Banana
<ol type="I">

Uppercase Roman

  1. Chapter One
  2. Chapter Two

3. Control Counting (`start` & `reversed`)

Custom Start Index

List ko kisi specific number se start karne ke liye start="10" use karein:

  1. Item 10
  2. Item 11
  3. Item 12

Reverse Counting

Numbers ko उल्टे क्रम (Descending order) me dikhane ke liye reversed use karein:

  1. 3rd Item
  2. 2nd Item
  3. 1st Item
