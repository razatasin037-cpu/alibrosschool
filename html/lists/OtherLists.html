Description List Kya Hai?

HTML Description List (<dl>) ka use terms aur unki definitions/descriptions ko group karne ke liye kiya jata hai (jaise Glossary ya Metadata display).

Key Tags Used

<dl>

Description List

Puri list ka main wrapper element.

<dt>

Definition Term

Jis term ya word ko define karna hai.

<dd>

Definition Description

Term ke baare me detail / description.

Example Structure

Description list ka basic syntax aur uska output rendering: 

<dl>
  <dt>Coffee</dt>
  <dd>- Black hot drink</dd>
  <dt>Milk</dt>
  <dd>- White cold drink</dd>
</dl>
Output Preview:
Coffee
Black hot drink
Milk
White cold drink
