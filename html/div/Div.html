<div> Element Kya Hai?

HTML me <div> (Division) ek generic container element hai. Yeh ek Block-level element hai jiska upyog dusre HTML elements ko group karne aur layout structure banane ke liye kiya jata hai.

<div> Element Ki Khasiyat

Non-Semantic Container

Iska apna koi khas matlab ya semantic sense nahi hota. Yeh sirf CSS styling aur layout structuring ke kaam aata hai.

Block Display

Yeh hamesha new line se start hota hai aur available screen width ka 100% space occupancy leta hai.

CSS & JS Friendly

Classes, IDs, flexbox aur grid attributes apply karke poore section ko ek saath control kiya ja sakta hai.

HTML Code Example

Code Block

Kaise <div> ke andar alag-alag elements ko group karke card container banaya jata hai: 

<!-- Main Wrapper Div -->
<div class="card">
  <h3 class="card-title">HTML Tutorial Card</h3>
  <p class="card-desc">Yeh content ek div container ke andar wrapped hai.</p>
  <button class="btn">Explore More</button>
</div>

When to use <div>?

  • Jab kisi content block par specific CSS layout (flexbox, grid, background, padding) dena ho.
  • Jab multiple related elements (jaise Heading + Paragraph + Button) ko ek Card ya Box me group karna ho.
  • Div-itis Se Bachen: Jahan semantic tags available hon (jaise <header>, <footer>, <section>, <article>), wahan bina waja <div> ka use na karein.
