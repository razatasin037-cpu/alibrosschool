HTML me CSS Kya Hoti Hai?

CSS (Cascading Style Sheets) ka upayog HTML elements ke layout, colors, fonts, aur overall visual look ko design karne ke liye kiya jata hai.

HTML me CSS ko add karne ke 3 alag tareeqe hote hain:

  • Inline CSS: HTML element ke andar style attribute ka use karke.
  • Internal CSS: HTML page ke <head> section me <style> tag ka use karke.
  • External CSS: External .css file ko <link> tag se connect karke.

1. Inline CSS

Inline CSS me single HTML element par unique style apply karne ke liye style attribute use karte hain.

inline-example.html HTML 
<h1 style="color: #3158ff; text-align: center;">
  Inline CSS Heading
</h1>
<p style="color: #22c55e; font-size: 18px;">
  Ye text green color me render hoga.
</p>
Browser Output

Inline CSS Heading

Ye text green color me render hoga.

2. Internal CSS

Jab ek poore single page ko alag design dena ho tab <head> ke andar <style> tag me CSS likhi jati hai.

internal-example.html HTML 
<head>
  <style>
    .my-box {
      background-color: #1e1b4b;
      color: #a7f3d0;
      padding: 15px;
      border-radius: 8px;
    }
  </style>
</head>
<body>
  <div class="my-box">Internal CSS Box</div>
</body>
Browser Output
Internal CSS Box

3. External CSS

Multiple web pages ko ek sath style karne ke liye external style.css file banakar <link> tag se link karte hain.

index.html & style.css HTML/CSS 
<!-- HTML File -->
<head>
  <link rel="stylesheet" href="style.css">
</head>

/* style.css File */
button {
  background-color: #3158ff;
  color: white;
  padding: 10px 20px;
  border-radius: 6px;
}
Browser Output

CSS Methods Quick Comparison

Method Syntax Location Best Use Case
Inline CSS style="..." attribute inside HTML element Quick testing ya single element styling ke liye.
Internal CSS <style> tag inside <head> Single page custom layout ke liye.
External CSS <link rel="stylesheet" href="style.css"> Large websites aur full multi-page styling ke liye (Best Practice).
