Styling Entire Columns with ``

HTML me <colgroup> aur <col> tags ka use karke aap poori columns ko ek saath styling (jaise background color ya width) de sakte hain, bina har cell (``/``) me CSS repeat kiye.

1. Basic Column Styling

<colgroup> ko hamesha <table> ke andar aur sabhi rows ya headers se pehle rakha jata hai: 

<table>
  <colgroup>
    <col style="background-color: #1e293b">
    <col style="background-color: #334155">
  </colgroup>
  <tr>
    <th>ID</th>
    <th>Name</th>
  </tr>
  <tr>
    <td>01</td>
    <td>Aman</td>
  </tr>
</table>

Visual Result

ID Name
01 Aman
02 Rohan

2. Multiple Columns Styling (`span`)

Ek se zyaada columns ko ek saath style karne ke liye span attribute ka use hota hai: 

<colgroup>
  <!-- 1st column -->
  <col style="background-color: #1e293b"> 
  <!-- Next 2 columns together -->
  <col span="2" style="background-color: #3158ff"> 
</colgroup>

Visual Result (Span = 2)

Item Qty Price
Laptop 1 ₹50,000
Mouse 2 ₹1,000
