Merging Table Cells

HTML me do ya usse zyada cells ko combine (merge) karne ke liye colspan (horizontal merging) aur rowspan (vertical merging) attributes ka use kiya jata hai.

1. Combining Columns (`colspan`)

Ek cell ko multiple columns tak stretch karne ke liye colspan attribute ka use karein: 

<table>
  <tr>
    <th>Name</th>
    <th colspan="2">Phone</th>
  </tr>
  <tr>
    <td>Rahul</td>
    <td>9876543210</td>
    <td>9123456789</td>
  </tr>
</table>

Visual Result (Colspan = 2)

Name Phone
Rahul 9876543210 9123456789

2. Combining Rows (`rowspan`)

Ek cell ko multiple rows tak vertically span karne ke liye rowspan attribute ka use hota hai: 

<table>
  <tr>
    <th>Name</th>
    <td>Priya</td>
  </tr>
  <tr>
    <th rowspan="2">Phone</th>
    <td>9876543210</td>
  </tr>
  <tr>
    <td>9123456789</td>
  </tr>
</table>

Visual Result (Rowspan = 2)

Name Priya
Phone 9876543210
9123456789
