Table Borders

By default, HTML tables me koi borders nahi hote. CSS ki <border> property ka use karke aap table cells, headers, aur outer boundary par custom borders apply kar sakte hain.

1. Basic CSS Border Syntax

Table, <th>, aur <td> teeno par border lagane ke liye CSS selector ka use karein: 

table, th, td {
  border: 2px solid #38bdf8;
}

2. Collapsing Table Borders

By default, har cell ka border alag dikhta hai (double borders). Single neat border banane ke liye border-collapse: collapse; property ka use kiya jata hai. 

table {
  border-collapse: collapse;
  width: 100%;
}
th, td {
  border: 1px solid #64748b;
}

3. CSS Border Styles Reference

Style Value CSS Example Description
solid border: 2px solid white; Continuous single line border.
dotted border: 2px dotted #38bdf8; Dots wali border line banata hai.
dashed border: 2px dashed #a855f7; Dashes (tukde-tukde) wali border line.
double border: 4px double #22c55e; Parallel double line border banata hai.

4. Advanced Border Tricks

Horizontal Borders Only

Bottom Border Style

Sirf rows ke niche line dene ke liye (no vertical lines):

th, td {
  border-bottom: 1px solid #334155;
}
Rounded Corners

Border Radius

Table ke corners round karne ke liye (border-collapse: separate required):

table {
  border-radius: 12px;
  overflow: hidden;
}
