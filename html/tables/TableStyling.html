Styling HTML Tables with CSS

HTML tables ko visually attractive aur readable banane ke liye CSS properties jaise Zebra Striping, Hover Effects, aur Padding ka use kiya jata hai.

1. Zebra Striped Tables (`nth-child`)

Alternate rows ko alag background color dene ke liye CSS :nth-child(even) ya :nth-child(odd) selector ka use hota hai: 

tr:nth-child(even) {
  background-color: #1e293b;
}
tr:nth-child(odd) {
  background-color: #0f172a;
}

2. Hoverable Rows

Jab user kisi row ke upar mouse le jaye to use highlight karne ke liye tr:hover pseudo-class ka use karein: 

tr:hover {
  background-color: #334155;
  transition: 0.3s;
}
