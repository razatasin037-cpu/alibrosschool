Controlling Table & Column Sizes

HTML tables me overall width, individual column widths, aur row heights ko control karne ke liye CSS width aur height properties ka use kiya jata hai.

1. Setting Table Width

By default table sirf content ke according space leta hai. Pure screen/container me phailane ke liye width: 100%; set karein: 

table {
  width: 100%;
  border-collapse: collapse;
}
th, td {
  border: 1px solid #334155;
}

2. Specific Column Width & Row Height

Aap kisi particular column ki width (<th> ya <td>) aur row ki height (<tr>) define kar sakte hain:

Column Sizing

Custom Column Width

Percentage ya pixels me width set karein:

th.col-small {
  width: 20%;
}
th.col-large {
  width: 80%;
}
Row Sizing

Custom Row Height

Row ka vertical space badhane ke liye:

tr {
  height: 60px;
}
