What are Table Headers (<th>)?

HTML table me header information dene ke liye <th> element ka use kiya jata hai. By default, browser <th> elements ke text ko bold aur center-aligned dikhata hai.

1. Table Header Placement

Headers ko aap table ke top (columns ke liye) ya row ke starting me (vertical header ke liye) place kar sakte hain. 

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Aman</td>
    <td>24</td>
  </tr>
</table>

Visual Output

Name Age
Aman 24

2. Important Header Attributes

Accessibility

`scope` Attribute

Screen readers ko batane ke liye ki header row ke liye hai ya column ke liye:

<th scope="col"> ya <th scope="row">
Styling

Text Alignment

CSS text-align: left; use karke default center alignment ko change kar sakte hain:

th { text-align: left; }
