HTML Tables

HTML Tables (<table> tag) ka use web page par data ko rows aur columns ke format me organize aur display karne ke liye kiya jata hai.

Ye structured data jaise marksheet, pricing plans, schedule, aur comparison charts dikhane ke liye sabse best element hai.

1. Basic Table Structure

Table banane ke liye main tags: <table> (main wrapper), <tr> (table row), <th> (heading cell), aur <td> (data cell). 

<table border="1">
  <tr>
    <th>Name</th>
    <th>Role</th>
  </tr>
  <tr>
    <td>Rahul</td>
    <td>Developer</td>
  </tr>
</table>

Visual Output Preview

Name Role
Rahul Developer

2. Important Table Tags Reference

Tag Name Full Form Description
<table> Table Wrapper Aapke saare table content ka container element hota hai.
<tr> Table Row Table me ek horizontal line/row create karta hai.
<th> Table Header Header cell create karta hai (Text by default bold aur centered hota hai).
<td> Table Data Normal data cell create karta hai jisme actual content rehta hai.
<thead>, <tbody>, <tfoot> Semantic Structure Table ko Header, Body aur Footer sections me divide karne ke liye.

3. Colspan aur Rowspan (Cell Merging)

Multiple columns ya rows ko merge karne ke liye colspan aur rowspan attributes ka use kiya jata hai.

Colspan (Column Merge)

Horizontal Merge

Ek cell ko 2 ya zyada columns me phelane ke liye:

<td colspan="2">Merged Header</td>
Rowspan (Row Merge)

Vertical Merge

Ek cell ko 2 ya zyada rows me extend karne ke liye:

<td rowspan="2">Merged Row Cell</td>

5. Responsive Table & Styling Rules

📱 Mobile Responsive Kaise Banayein?

Small screens par table outer screen se bahar na nikle, iske liye hamesha table ko <div class="overflow-x-auto"> ke andar wrap karein. Isse mobile browsers par smooth horizontal scrolling enabled ho jati hai.

🎨 Zebra Striping & Hover Effects

Table ki readability badhane ke liye alternate rows par background color change karein (nth-child(even)) aur cursor move hone par hover:bg-slate-900 transition apply karein.
