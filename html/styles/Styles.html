HTML Style Attribute Kya Hota Hai?

HTML elements ka look (Color, Size, Font, Alignment) change karne ke liye style attribute ka use kiya jata hai.

Isse hum Inline CSS kehte hain. Iska basic syntax hota hai: <tagname style="property: value;">

Style Attribute Syntax Breakdown

Property (Gundharm)

Ye CSS ki specific property hoti hai jise aap change karna chahte hain, jaise color, font-size, ya background-color.

Value (Maan)

Ye us property ki value hoti hai jo aap apply karte hain, jaise red, 20px, ya center.

Practical Style Examples

Niche alag-alag CSS properties ke saath HTML style attribute ka use dekhein:

index.html HTML 
<!-- Text Color -->
<p style="color: red;">Lal text</p>

<!-- Background Color -->
<p style="background-color: yellow;">Background Yellow</p>

<!-- Font Size -->
<p style="font-size: 25px;">Bada Text</p>

<!-- Text Align -->
<p style="text-align: center;">Center Text</p>

Common Style Properties Reference

Property Description Example Value
color Text ka color set karne ke liye. red, #ff0000, rgb(255,0,0)
background-color Element ka background color set karta hai. blue, #0000ff
font-family Text ka font style (font face) badalne ke liye. Arial, Verdana, sans-serif
font-size Text ki sizing control karta hai. 16px, 120%, 1.5rem
text-align Text ki horizontal positioning align karta hai. left, center, right, justify

Best Practices (Dhyan Rakhne Yagya Baatein)

  • Quick testing ke liye inline styles best hain: Chote testing ya single element ke liye style="" attribute upyogi hai.
  • Large projects ke liye CSS file use karein: Badi websites me hamesha External CSS (style.css) ka use karein taaki code clean aur maintainable rahe.
  • Multiple styles ko semicolon se alag karein: Hamesha har CSS property ke baad ; zaroor lagayein (Jaise: style="color: red; font-size: 20px;").
