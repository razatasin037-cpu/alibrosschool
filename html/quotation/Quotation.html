HTML Quotation Elements Kya Hain?

HTML me kisi external source, quote, address, abbreviation, ya book/work reference ko display karne ke liye Quotation & Citation Tags ka use kiya jata hai.

Ye elements search engines aur browsers ko batate hain ki text ek quotation hai aur iska origin source kya hai.

Practical Code Example

Basic quotation aur citation tags ka example aur live rendering dekhein:

index.html HTML 
<p>APJ Abdul Kalam ne kaha tha: <q>Dream is not that which you see while sleeping...</q></p>

<blockquote cite="https://example.com">
  Failures are the stepping stones to success.
</blockquote>

<p><abbr title="HyperText Markup Language">HTML</abbr> web dev ke liye zaroori hai.</p>
<p><cite>Mona Lisa</cite> was painted by Leonardo da Vinci.</p>

Quotation Tags Quick Reference

Tag Description Default Behavior
<blockquote> Long quotation from another source. Indented (Margin Left & Right) block
<q> Short inline quotation. Automatic quotation marks (" ")
<abbr> Abbreviation ya Acronym. Hover par full form show karta hai. Dotted underline & hover tooltip (using title attribute)
<address> Author/Owner ki contact information. Italic text with line break
<cite> Creative work ka title (Book, Song, Painting, Movie, etc.). Italic text
<bdo> Bi-Directional Override (Text Direction reverse karta hai). Changes text flow (e.g. dir="rtl")

Best Practices (Dhyan Rakhne Yagya Baatein)

  • Use cite attribute in <blockquote>: Search engines ko source URL batane ke liye cite="URL" attribute ka use zaroor karein.
  • Always use title in <abbr>: Abbreviation ki full form dene ke liye title attribute compulsary hai.
