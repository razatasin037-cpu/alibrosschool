HTML Inline Frame (Iframe) Kya Hai?

HTML me <iframe> (Inline Frame) ka use ek HTML page ke andar dusre Web Page, YouTube Videos, Google Maps, ya PDFs ko embed (display) karne ke liye hota hai.

Iframe Attributes Ki Khasiyat

src Attribute

src me us webpage, video ya document ka URL diya jata hai jise aap apne page par load karna chahte hain.

Width & Height

Iframe ka size tay karne ke liye width aur height attributes ya Tailwind responsive classes ka use hota hai.

title Attribute

Accessibility ke liye title attribute dena zaroori hai, taaki screen readers samajh sakein ki frame me kya content hai.

HTML Code Example

Code Block

Iframe include karne ke alag-alag HTML syntax: 

<!-- Basic Webpage Embed -->
<iframe src="https://example.com" width="600" height="400" title="Example Page"></iframe>

<!-- Tailwind Responsive Aspect Ratio Video Embed -->
<div class="aspect-video w-full">
  <iframe 
    class="w-full h-full rounded-xl"
    src="https://www.youtube.com/embed/VIDEO_ID" 
    title="YouTube Video" 
    allowfullscreen>
  </iframe>
</div>

<!-- Borderless Clean Map Embed -->
<iframe 
  src="https://maps.google.com/..." 
  class="w-full h-64 border-0 rounded-2xl" 
  title="Map Location">
</iframe>

Iframe Best Practices & Security Rules

  • ✓ Always Add Title: Accessibility standards ke liye har iframe me meaningful title attribute likhein.
  • ✓ Use Sandbox for Security: Kisi unverified external site ko embed karte waqt sandbox attribute use karein taaki malicious scripts run na ho sakein.
  • ✕ X-Frame-Options Error: Kuch websites (jaise Google, Facebook) security reason se apney aap ko iframe me load karne ki anumati nahi deti hain.
