Background Images Guide

HTML elements (jaise <div> ya <body>) ke background me image set karne ke liye CSS background-image property ka use kiya jata hai.

Is guide me hum background images ko repeat na hone dena, screen par fit karna aur parallax effect lagana sikhenge.

1. Basic Background Image Syntax

CSS me background-image: url('image_name.jpg'); attribute ka use karke background image apply ki jati hai. 

<!-- Inline CSS Example -->
<div style="background-image: url('bg.jpg');">
  <h2>Hello World</h2>
</div>

<!-- Internal CSS Example -->
<style>
  body {
    background-image: url('bg.jpg');
  }
</style>

2. Background Repeat & Size Control

By default, background image repeat hoti hai. Usse control karne ke liye ye CSS properties use hoti hain:

background-repeat

no-repeat

Image ko multiple times tile/repeat hone se rokta hai.

background-repeat: no-repeat;
background-size

cover

Image ko poore container me stretch karke fit kar deta hai.

background-size: cover;
background-size

contain

Image ka full view bina crop kiye fit karta hai.

background-size: contain;

3. Background Image CSS Properties Table

Property Common Values Description
background-image url('path/image.jpg') Element par background image set karta hai.
background-repeat repeat | no-repeat | repeat-x | repeat-y Define karta hai ki image repeat hogi ya nahi.
background-size auto | cover | contain | 100% 100% Image ke display size ko control karta hai.
background-position center | top right | 50% 50% Image ki starting alignment set karta hai.
background-attachment scroll | fixed Fixed value se image scroll karne par bhi ek jagah lock rehti hai (Parallax Effect).
