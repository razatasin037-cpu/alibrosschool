HTML Images Complete Guide

HTML me images insert karne ke liye <img> tag ka upayog kiya jata hai. Ye ek self-closing tag hota hai jisme closing tag nahi hota.

Image display karne ke liye sabse zaroori attributes src (Source path) aur alt (Alternate text) hain.

1. Basic Image Tag Syntax

Basic image tag me src attribute image ka path define karta hai. 

<img src="nature.jpg" alt="Nature View" />

2. Alt Attribute (Fallback Text)

Agar image load nahi hoti (slow network ya wrong path), to alt text screen par show hota hai. Ye SEO aur Accessibility ke liye mandatory hai. 

<!-- Broken Image Path Example -->
<img src="wrong_path.jpg" alt="Sample Profile Picture" />

3. Image Width & Height Attributes

Image ke size ko control karne ke liye width aur height attributes ka use kiya jata hai. 

<img 
  src="laptop.jpg" 
  alt="Laptop" 
  width="150" 
  height="100" 
/>

4. Image as a Clickable Link

Image ko clickable banane ke liye use <a> tag ke andar wrap karein. 

<a href="https://wikimedia.org" target="_blank">
  <img src="logo.png" alt="Wikimedia Logo" />
</a>

5. Responsive Image (CSS Styling)

max-width: 100% aur height: auto ka use karke image ko sabhi screen sizes par responsive banaya jata hai. 

<img 
  src="city.jpg" 
  alt="City Skyline" 
  style="max-width:100%; height:auto;" 
/>

6. Figure & Figcaption Tag

Image ke sath caption (description) dikhane ke liye Semantic HTML <figure> aur <figcaption> tags ka upayog hota hai. 

<figure>
  <img src="mountains.jpg" alt="Mountains" />
  <figcaption>Fig.1 - Beautiful Mountain View.</figcaption>
</figure>

7. Common HTML Image Formats

Format Extension Best Use Case
JPEG / JPG .jpg / .jpeg High-quality photographs and complex scenes.
PNG .png Images with transparent background and sharp edges.
SVG .svg Vector graphics, icons, and scalable logos.
WebP .webp Modern web format with high compression and fast load speed.
GIF .gif Simple animated graphics.
