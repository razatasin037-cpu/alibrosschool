HTML Picture Element Guide

HTML <picture> element ka use alag-alag screen sizes (Mobile, Tablet, Desktop) ya device types ke liye alag-alag images show karne ke liye kiya jata hai.

Ise Responsive Images aur Modern Image Formats (jaise AVIF/WebP) serve karne ke liye sabse best tarika mana jata hai.

1. Basic <picture> Syntax & Media Query

Browser upar se niche tak <source> tags ko check karta hai. Pehla matching condition waala image load hota hai, otherwise fallback <img> tag render hota hai. 

<picture>
  <!-- Large Screens (Min 768px) -->
  <source 
    media="(min-width: 768px)" 
    srcset="desktop.jpg" />

  <!-- Small Screens (Min 480px) -->
  <source 
    media="(min-width: 480px)" 
    srcset="tablet.jpg" />

  <!-- Fallback Default Image -->
  <img 
    src="mobile.jpg" alt="Responsive View" />
</picture>

💡 Screen ko resize karke dekhein: Desktop par Laptop aur Mobile par Phone image swapp hogi.

2. Main Use Cases of <picture> Tag

Developer do sabse bade kaaranon se <picture> tag ka use karte hain:

Art Direction

Screen Size Adaptability

Desktop ke liye wide landscape image aur Mobile ke liye cropped vertical image dikhana.

media="(min-width: 650px)"
Format Selection

Modern Format Support

Browser ke according lightweight modern formats (AVIF/WebP) load karna, purane browser ke liye JPG/PNG fallback dena.

type="image/webp"

3. Tags & Attributes Reference

Tag / Attribute Value / Type Description
<picture> Wrapper Tag Multiple <source> tags aur ek fallback <img> tag ka main container.
<source> Child Tag Specific condition waale image files define karta hai.
srcset URL path <source> tag ke andar image ka source file URL batata hai.
media Media Query (e.g. min-width) Screen size condition define karta hai jispar image trigger hoti hai.
type MIME Type (e.g. image/webp) Image format define karta hai taaki browser support ke hisab se pick kare.
<img> Required Tag Last fallback tag - iske bina <picture> screen par render nahi hota.
