HTML Image Maps Guide

HTML Image Map ka use karke aap ek hi image ke alag-alag hisson (clickable areas) par alag-alag links set kar sakte hain.

Iske liye <map> aur <area> tags ko usemap attribute ke sath upayog kiya jata hai.

1. Image Map Basic Syntax

Image ke usemap attribute ka value <map> ke name attribute se start hona chahiye (# symbol ke sath). 

<!-- Image Link to Map -->
<img src="workplace.jpg" usemap="#workmap" alt="Workplace" />

<!-- Map Definition -->
<map name="workmap">
  <area shape="rect" coords="34,44,270,350" href="computer.html" alt="Computer" />
  <area shape="circle" coords="337,300,44" href="coffee.html" alt="Coffee" />
</map>

💡 Image ke alag-alag parts par click karke dekhein (Laptop / Background).

2. Types of Shapes in <area>

shape attribute me hum 4 alag-alag options specify kar sakte hain:

shape="rect"

Rectangle (Aayatakar)

Top-Left corner aur Bottom-Right corner ke coordinates diye jate hain.

coords="x1, y1, x2, y2"
shape="circle"

Circle (Vrittakar)

Center point (x, y) aur Circle ka radius (r) specify kiya jata hai.

coords="x, y, radius"
shape="poly"

Polygon (Bahubhuj)

Kisi bhi irregular shape ke sabhi corner points ke coordinates diye jate hain.

coords="x1,y1,x2,y2,..."

3. <area> Tag Attributes Reference

Attribute Value Description
shape rect | circle | poly | default Clickable region ka shape define karta hai.
coords numbers (e.g. 10,20,50,60) Pixel position values jo clickable area ko locate karti hain.
href URL Target link destination jahan pe click karne par navigate hoga.
alt text Area ka alternate descriptive text (SEO/Accessibility ke liye).
target _blank | _self Define karta hai ki link same tab me khulega ya naye tab me.
