HTML Colors Kya Hote Hain?

HTML me web elements ko visually attractive banane ke liye colors ka use hota hai. Aap text, background, borders, aur buttons me alag-alag color formats ka upayog kar sakte hain.

HTML me colors ko specify karne ke liye Color Names, HEX Values, RGB/RGBA Values, aur HSL/HSLA Values ka upayog kiya jata hai.

1. Color Names Example

HTML me 140+ standard predefined color names hote hain jinhe aap direct style property me likh sakte hain.

color-names.html HTML 
<h1 style="background-color: Tomato; color: white;">Tomato</h1>
<h1 style="background-color: DodgerBlue; color: white;">DodgerBlue</h1>
<h1 style="background-color: MediumSeaGreen; color: white;">MediumSeaGreen</h1>
<h1 style="background-color: SlateBlue; color: white;">SlateBlue</h1>
Browser Output
Tomato
DodgerBlue
MediumSeaGreen
SlateBlue

Color Formats Quick Summary

Format Syntax Example Best Used For
Color Name red, blue, tomato Quick testing and basic styling.
HEX Code #FF0000, #3158FF Standard web production and branding colors.
RGB / RGBA rgb(255, 0, 0), rgba(0,0,0,0.5) Transparency aur background opacity control ke liye.
HSL / HSLA hsl(0, 100%, 50%), hsla(...) Dynamic color themes aur shades create karne ke liye.
