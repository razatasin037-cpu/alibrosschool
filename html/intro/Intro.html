HTML Kya Hai?

HTML ka full form HyperText Markup Language hai. Ye Web Pages ka basic structure (dhancha) banane ke liye use hone wali standard language hai.

HTML browser ko batata hai ki content ko page par kaise display karna hai. Isme alag-alag Tags hote hain (jaise headings, paragraphs, links, images, tables).

HTML Tags

HTML tags elements ko wrap karte hain, jaise <h1> Heading ke liye aur <p> Paragraph ke liye.

Web Browsers

Chrome, Firefox, Edge jaise browsers HTML code ko read karke use visual web page me convert karte hain.

1. Simple HTML Document Code

Har HTML page ka basic structure kuch is tarah ka dikhta hai: 

<!DOCTYPE html>
<html>
  <head>
    <title>Page Ka Title</title>
  </head>
  <body>

    <h1>Mera Pehla Heading</h1>
    <p>Mera pehla paragraph text.</p>

  </body>
</html>

2. Code Ka MATLAB (Step-by-Step)

  • <!DOCTYPE html> - Ye browser ko batata hai ki ye HTML5 document hai.
  • <html> - Ye HTML document ka root element hai.
  • <head> - Isme page ki metadata aur title rakha jata hai (jo page par directly nahi dikhta).
  • <title> - Ye browser tab me dikhne wala title set karta hai.
  • <body> - Website ka main visible area! Saara dikhne wala content iske andar hi aata hai.
  • <h1> - Badi Heading ke liye use hota hai.
  • <p> - Paragraph likhne ke liye use hota hai.

3. HTML Elements Structure

An HTML Element Start Tag se shuru hokar End Tag par khatam hota hai. Kuch elements me koi content ya closing tag nahi hota, inhein Empty Elements kehte hain.

Start Tag Element Content End Tag
<h1> My First Heading </h1>
<p> My first paragraph. </p>
<br> None (Line break) None
<img src="..."> None (Self-closing) None
<a href="..."> Click Here Link </a>

Nested HTML Elements

HTML elements ek doosre ke andar rakhe ja sakte hain (Nesting). Jaise <body> ke andar <h1> aur <p> tags hain.

HTML Attributes

Attributes elements ko extra information dete hain. Ye hamesha start tag me likhe jate hain (jaise href="" link ke liye ya src="" image ke liye).
