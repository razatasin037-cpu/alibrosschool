HTML Button Element Kya Hai?

HTML me <button> element ka upyog clickable buttons banane ke liye kiya jata hai. Yeh user interaction (jaise form submit karna, click event trigger karna) ke liye zaroori hai.

Button Attributes Ki Khasiyat

type Attribute

Button ke kaam ko define karta hai: type="button" (normal click), submit (form data bhejne ke liye), ya reset.

disabled State

disabled attribute lagane se button unclickable ho jata hai aur user us par click nahi kar sakta.

JS Click Events

JavaScript me onclick attribute ya event listener ke zariye click hone par functions execute kiye jate hain.

HTML Code Example

Code Block

Niche HTML me buttons declare karne ka standard tareeka aur unke alag-alag types diye gaye hain: 

<!-- Basic Clickable Button with Tailwind Styling -->
<button type="button" class="bg-blue-600 text-white px-5 py-2.5 rounded-xl font-bold">
  Click Me
</button>

<!-- Submit Button inside a Form -->
<button type="submit" class="bg-emerald-600 text-white px-5 py-2.5 rounded-xl font-bold">
  Submit Form
</button>

<!-- Button with JS Onclick Event -->
<button type="button" onclick="alert('Hello World!')" class="bg-purple-600 text-white px-5 py-2.5 rounded-xl font-bold">
  Trigger Alert
</button>

<!-- Disabled Button State -->
<button type="button" disabled class="bg-gray-600 text-gray-300 px-5 py-2.5 rounded-xl font-bold cursor-not-allowed">
  Cannot Click
</button>

Button Best Practices

  • ✓ Always Specify Type: Hamesha type="button" ya type="submit" explicit roop se likhein taaki forms me unwanted page reload na ho.
  • ✓ Hover & Active States: Tailwind me hover: aur active click effects dekar user experience (UX) ko behter banayein.
  • ✕ Don't use Div for Buttons: Clickable element ke liye <div> ke bajaye hamesha native <button> tag ka upyog karein taaki accessibility (screen readers) sahi rahe.
