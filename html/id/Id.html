HTML ID Attribute Kya Hai?

HTML me id attribute ka use kisi specific element ko Uniquely Identify (eklauta pehchan) karne ke liye hota hai. Ek HTML page me ek id name sirf ek hi element ko diya ja sakta hai.

ID Attribute Ki Khasiyat

Unique Identifier

Poore HTML document me ek ID ka naam sirf ek baar use hona chahiye.

CSS Hash (#) Selector

CSS me ID wale element ko style karne ke liye hash Symbol (#header) ka use kiya jata hai.

JS & Page Anchors

JavaScript getElementById() aur bookmark links (href="#section1") ke liye ID zaroori hoti hai.

CSS <style> Tag Example (#ID)

CSS ID Selector

Dekhein kaise <style> tag me hash (#) symbol se specific element ko targeted styling di jati hai: 

<style>
  /* ID Selector hash (#) se start hota hai */
  #main-header {
    background-color: #0f172a;
    border: 2px solid #3158ff;
    padding: 24px;
  }

  #unique-title {
    color: #60a5fa;
  }

  #special-card {
    border: 2px dashed #10b981;
  }

  #action-btn {
    background-color: #10b981;
    color: #ffffff;
  }
</style>

CSS #ID Selectors Applied Output:

Unique Header Section (#unique-title)

Yeh block #main-header ID ke through styled hai.

Yeh card #special-card ID dwara green dashed border me styled hai.

Custom ID Button (#action-btn)

HTML Code Example

Code Block

Kaise kisi specific element ko Unique ID di jati hai aur CSS / Links me connect kiya jata hai: 

<!-- Unique Header with ID -->
<h1 id="main-heading">Welcome to My Website</h1>

<!-- Bookmark Link targeting ID -->
<a href="#about-section">Go to About Section</a>

<!-- Target Section with ID -->
<div id="about-section" class="card">
  <p>Yeh ek specific section hai jiska ID unique hai.</p>
</div>

Class vs ID Quick Rules

  • ✓ ID Unique Hoti Hai: Ek page me ek ID naam sirf EK element ko mil sakta hai (e.g., id="header").
  • ✓ Class Multiple Hoti Hai: Ek class naam MULTIPLE elements ko diya ja sakta hai (e.g., class="btn").
  • ✕ Niyam: Ek element me multiple IDs (jaise id="box1 box2") nahi de sakte. Yeh invalid HTML hai.
