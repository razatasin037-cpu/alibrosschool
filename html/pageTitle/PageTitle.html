HTML Page Title Guide

HTML Page Title (ya <title> tag) browser ki tab bar me web page ka naam dikhane ke liye use hota hai.

Ye Search Engine Optimization (SEO), browser bookmarks, aur user experience (UX) ke liye web page ka sabse important element hota hai.

1. Page Title Kaise Add Karein?

Page Title ko add karne ke liye HTML ke <head> section ke andar <title> tag ka use kiya jata hai. 

<!DOCTYPE html>
    <html>
    <head>
    <!-- Page Title Tag -->
    <title>My Official Website - Home Page</title>
    </head>
    <body>
    <h1>Welcome to my website!</h1>
    </body>
    </html>
My Official Website - Home Page

💡 Browser tab me jo text sabse upar dikhta hai, wahi <title> tag hota hai.

2. Page Title Kyu Zaroori Hai?

Aapki website par accha Title tag hone ke mukhya fayde:

SEO Value

Google Ranking

Search engines (Google, Bing) aapke page ke title se hi topic ko samajhte hain aur results me dikhate hain.

UX / Usability

Tab Navigation

Multiple open tabs me se user bina page khole samajh sakta hai ki tab kis baare me hai.

Bookmarks

Easy Bookmarking

Jab user page ko bookmark karta hai, toh yahi title default bookmark name ban jata hai.

3. Title Best Practices Reference

Rule Parameter Recommended Value Description
Title Length 50 - 60 Characters Google search result me text cut hone se bachata hai.
Keyword Placement Primary Keyword First Main target word ko title ke shuruat me rakhein.
Brand Name At the End (| Brand) Title ke end me pipe (|) ya dash (-) laga kar brand name likhein.
Uniqueness 1 Unique Title Per Page Website ke har page ka title alag aur specific hona chahiye.

4. Real-World Title Tag Examples

Alag-alag type ke web pages ke liye title likhne ke SEO-friendly aur standard examples:

E-Commerce Title Product Page

Product Specific Title

Product page me product ka naam, key specs aur brand name shamil karein: 

<title>Buy Wireless Headphones Noise Cancelling | TechStore</title>
Blog / Article Title Content Page

Informational Blog Post Title

Blog post ka title lagatar clickable aur catchy hona chahiye: 

<title>10 Easy Ways to Learn HTML Fast - Beginner Guide</title>
Homepage Title Main Portal

Main Brand Homepage

Home page title me Brand Name aur Primary Business Domain hona zaroori hai: 

<title>CodeLearn - Online Coding Tutorials & Free Courses</title>
Utility Page Contact & Support

Contact & Support Page Title

Simple aur direct title user ko sahi page tak turant pahunchane me help karta hai: 

<title>Contact Us - Customer Support & Help Center</title>
