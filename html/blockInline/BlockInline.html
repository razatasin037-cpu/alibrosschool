Block vs Inline Elements Kya Hain?

HTML me har element ka ek default display value hota hai. Mukhya roop se do display values hoti hain: Block-level aur Inline.

Main Difference

display: block;

Block-level Elements

  • ✓ Hamesha nayi line (new line) se shuru hote hain.
  • ✓ Available width ki puri 100% space cover karte hain.
  • ✓ Top aur bottom margin/padding apply ki ja sakti hai.
display: inline;

Inline Elements

  • ✓ Nayi line se shuru nahi hote, baaki content ke saath inline rehte hain.
  • ✓ Sirf jitni zaroorat (content size) hoti hai, utni hi width lete hain.
  • ✓ Top aur bottom margin/height fix nahi ki ja sakti.

Visual Demonstration

Dono ka visual behavior layout me kaisa dikhta hai:
