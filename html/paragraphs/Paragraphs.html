HTML Paragraph Kya Hota Hai?

HTML me text content likhne ke liye <p> tag ka use hota hai.

Browser automatic har <p> element ke pehle aur baad me thoda extra margin (space) add kar deta hai.

Paragraphs Code Example

Niche diye gaye code aur browser preview me dekhein ki paragraphs kaise render hote hain:

index.html HTML 
<!DOCTYPE html>
<html>
<body>

  <p>Ye pehla paragraph hai.</p>
  <p>Ye doosra paragraph hai.</p>

</body>
</html>
Browser Result Preview

Ye pehla paragraph hai.

Ye doosra paragraph hai.

💡 Notice karein ki do paragraphs ke beech automatic spacing bani hui hai.

Important Paragraph Helper Tags

<br> Tag (Line Break)

Naya paragraph shuru kiye bina line break dene ke liye use hota hai. Ye ek single/empty tag hai.

<p>Pehli line.<br>Doosri line.</p>

<hr> Tag (Horizontal Rule)

Content ke beech me horizontal line (line divide) draw karne ke liye use hota hai.

<h1>Topic</h1>
<hr>
<p>Description...</p>

<pre> Tag (Preformatted Text)

Normal <p> tag extra spaces aur line breaks ko ignore kar deta hai. Agar aapko exact spaces aur poetry/poem format preserve rakhna hai, toh <pre> tag ka use karein. 

<pre>
   Twinkle, twinkle, little star,
   How I wonder what you are!
</pre>

Paragraph Tags Quick Reference

Tag Type Description Example
<p> Block Element Paragraph create karta hai auto margin ke sath. <p>Text</p>
<br> Empty/Void Single line break add karta hai. Line 1<br>Line 2
<hr> Empty/Void Horizontal line break / divider insert karta hai. <hr>
<pre> Block Element Preformatted text - Spaces aur enters ko preserve rakhta hai. <pre>Space Text</pre>

Best Practices (Dhyan Rakhne Yagya Baatein)

  • Closing tag zaroor lagayein: Always </p> closing tag use karein clean HTML structure ke liye.
  • Spacing ke liye <br> overuse na karein: Do paragraphs ke beech space dene ke liye multiple <br> use karne ke bajaye CSS Margin/Padding use karein.
  • Block elements avoid karein inside <p>: Paragraph ke andar headings (<h1>) ya <div> tags ko nest na karein.
