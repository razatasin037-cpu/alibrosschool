HTML Me JavaScript Kya Hai?

JavaScript Web Pages ko dynamic aur interactive banane ke liye use hoti hai. HTML me JavaScript add karne ke liye <script> tag ka upyog kiya jata hai, jisse aap DOM elements ko modify, hide/show, ya update kar sakte hain.

JS Connect Karne Ke 3 Tarike

Internal JS

HTML file ke andar <script> tag me seedhe JavaScript code likha jata hai.

External JS

Alag .js file banakar <script src="script.js"></script> se include karte hain.

Inline Event

Direct HTML tag me onclick="..." jaise attributes se JS triggers diye jate hain.

HTML & JS Code Example

Code Block

Is feature ko implement karne ka complete HTML aur JavaScript code structure: 

<!-- HTML Elements with Unique ID -->
<h4 id="demo-text" class="text-2xl font-bold">Hello World!</h4>

<!-- Button triggering JS Function -->
<button onclick="changeContent()" class="bg-blue-600 text-white px-5 py-2.5 rounded-xl">
  Change Text
</button>

<!-- JavaScript Code inside Script Tag -->
<script>
  function changeContent() {
    // Target element by ID and update text
    document.getElementById("demo-text").innerText = "JavaScript dwara Text Change Ho Gaya!";
  }
</script>

JavaScript Integration Rules

  • ✓ Place Script at Bottom: Page loading speed aur DOM load hone ke liye <script> tag ko hamesha </body> tag se thik pehle rakhein.
  • ✓ Use defer or async: Head tag me external script lagate waqt defer attribute ka use karein taaki HTML parsing na ruke.
  • ✕ Avoid Heavy Inline Scripts: Direct HTML tags me bada JS code likhne se bachein; hamesha separate functions ya external files ka use karein.
