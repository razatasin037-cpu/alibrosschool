CSS Multiple Columns

CSS Multiple Columns ka use text ko ek se zyada columns mein divide karne ke liye hota hai. Ye newspaper aur article layouts ke liye kaafi useful hai.

CSS Multiple Columns Kya Hai?

Multiple Columns CSS feature text ko automatically multiple vertical columns mein arrange karta hai. Isse long text ko read karna easy ho jata hai.

CSS web pages ko attractive aur readable banane ke liye bahut useful hai. Multiple columns ki help se long paragraphs ko newspaper-style layout mein display kiya ja sakta hai. Browser available space ke according content ko columns mein divide karta hai.

Is technique ka use blogs, news websites, articles aur documentation pages mein kiya ja sakta hai. Column count aur gap ko easily control kiya ja sakta hai.

Responsive design ke saath multiple columns ko use karna bhi possible hai. Small screen par columns ki count kam ki ja sakti hai.

column-count

column-count property batati hai ki content ko kitne columns mein divide karna hai.

Ye first column ka content hai. Browser text ko automatically next column mein continue karta hai.

Ye second column mein content continue hota hai aur available height ke according text distribute hota hai.

Third column mein remaining content automatically place ho jata hai.

Example 

.article {
  column-count: 3;
}

column-width

column-width se har column ki preferred width set kar sakte hain.

Column width browser ko batati hai ki ek column approximately kitna wide hona chahiye. Available space ke according browser columns ki number adjust kar sakta hai.

Fixed column width responsive layouts mein useful hoti hai, especially jab readability ko priority deni ho.

Width ko px, em ya rem jaise units mein specify kiya ja sakta hai.

Example 

.article {
  column-width: 180px;
}

column-gap

column-gap columns ke beech ka space control karta hai.

Small Gap

CSS columns content ko separate sections mein divide karta hai. Gap columns ke beech distance control karta hai.

Large Gap

CSS columns content ko separate sections mein divide karta hai. Gap columns ke beech distance control karta hai.

Code 

.article {
  column-count: 3;
  column-gap: 35px;
}

column-rule

column-rule columns ke beech ek line create karta hai.

Column rule ek visual separator ki tarah kaam karta hai. Isse multiple columns ke beech clear separation milti hai.

Rule ki width, style aur color ko CSS ke through customize kiya ja sakta hai.

Newspaper-style designs mein column rule kaafi useful ho sakta hai.

Example 

.article {
  column-count: 3;
  column-gap: 35px;
  column-rule: 2px solid #475569;
}

column-rule Styles

Column rule ko solid, dashed ya dotted style mein set kar sakte hain.

Dashed Rule

Dashed column rule columns ko separate karne ke liye dotted ya dashed visual effect provide karta hai.

Ye modern layouts mein subtle separator ke liye use kiya ja sakta hai.

Rule style ko design ke according change kiya ja sakta hai.

Dotted Rule

Dotted rule ek lightweight separator create karta hai jo content ko visually divide karta hai.

Iska use minimal designs mein kiya ja sakta hai.

Width aur color ko bhi customize kar sakte hain.

column-span

column-span: all kisi heading ya element ko sabhi columns ke across spread karta hai.

Article Heading

Ye paragraph multiple columns mein display hoga. Heading sabhi columns ke upar full width mein show ho rahi hai.

column-span ka use article headings ya important section headings ke liye useful hota hai.

Is property se heading ko ek particular column ke andar limit karne ke bajay complete column layout ke across display kiya ja sakta hai.

Code 

h2 {
  column-span: all;
}

column Shorthand

columns shorthand se column-width aur column-count ko ek saath set kiya ja sakta hai.

Example 

.article {
  columns: 180px 3;
}

break-inside

break-inside se kisi element ko columns ke beech unnecessarily split hone se prevent kiya ja sakta hai.

Card 1: Is content ko break-inside avoid ki wajah se possible hone par ek hi column mein rakha jata hai.

Card 2: Multiple columns mein cards ya small sections ko split hone se bachana useful hota hai.

Card 3: Long content ke layouts mein ye property better readability provide kar sakti hai.

Code 

.card {
  break-inside: avoid;
}

Practical Newspaper Layout

Multiple Columns ka ek common practical use newspaper ya article-style layout banana hai.

Web development mein content ko readable format mein present karna important hota hai. Multiple columns long articles ko compact aur organized appearance de sakte hain.

Newspaper websites aur online magazines mein columns ka use commonly dekha ja sakta hai. CSS ke through columns ko responsive bhi banaya ja sakta hai.

Desktop par three columns aur mobile par one column ka layout create karna simple CSS properties ke through possible hai.

Proper column gap aur readable font size use karne se content ko scan aur read karna easier hota hai.

Isliye Multiple Columns ek useful CSS layout technique hai jab page par large amount of text present ho.

Responsive Multiple Columns

Desktop par multiple columns useful hain, lekin mobile par columns ki number reduce karna better readability provide karta hai.

Responsive Code 

.article {
  column-count: 3;
}

@media (max-width: 768px) {
  .article {
    column-count: 2;
  }
}

@media (max-width: 640px) {
  .article {
    column-count: 1;
  }
}

Important Points

  • column-count columns ki number set karta hai.
  • column-width preferred column width set karta hai.
  • column-gap columns ke beech spacing control karta hai.
  • column-rule columns ke beech separator line create karta hai.
  • column-span element ko all columns ke across spread kar sakta hai.
  • Responsive design ke liye media queries ka use karein.

Common Mistakes

  • Mobile screen par bahut zyada columns use karna.
  • Columns ke beech proper gap na dena.
  • Long elements ko unnecessarily columns ke beech split hone dena.
  • Column width ko readability ke bina choose karna.
  • Responsive layout ko ignore karna.

Best Practices

  • Long text ke liye readable column width rakhein.
  • Columns ke beech sufficient gap rakhein.
  • Mobile par columns ki count reduce karein.
  • Important cards ya sections ke liye break-inside use karein.
  • Column rules ko simple aur subtle rakhein.

Summary

CSS Multiple Columns ka use content ko multiple vertical columns mein divide karne ke liye hota hai. Important properties hain column-count, column-width, column-gap, column-rule aur column-span. Responsive design ke liye columns ki count screen size ke according adjust karni chahiye.
