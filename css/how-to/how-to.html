CSS How To

CSS How To Kya Hai?

CSS ko HTML page ke saath connect karne ke liye hum alag-alag methods use kar sakte hain.

CSS ko external file mein, HTML ke andar, ya directly kisi HTML element ke andar likha ja sakta hai.

CSS Add Karne Ke 3 Ways

External CSS

CSS ko ek separate .css file mein likha jata hai.

Internal CSS

CSS ko HTML ke <style> tag ke andar likha jata hai.

Inline CSS

CSS ko directly HTML element ke style attribute mein likha jata hai.

1. External CSS

External CSS mein styling ko ek separate CSS file mein rakha jata hai. Is method mein same CSS file ko multiple HTML pages ke saath use kiya ja sakta hai.

HTML File 

<!DOCTYPE html>

<html>

<head>

  <link
  rel="stylesheet"
  href="style.css"
  >

</head>

<body>

  <h1>
    Hello CSS
  </h1>

</body>

</html>

style.css 

h1 {
  color: blue;
  font-size: 40px;
}

<link> Tag Ka Kaam

External CSS ko HTML page se connect karne ke liye <link> tag ka use hota hai. 

<link
  rel="stylesheet"
  href="style.css"
>

rel="stylesheet" browser ko batata hai ki linked file stylesheet hai.

href="style.css" CSS file ka path ya location batata hai.

2. Internal CSS

Internal CSS mein CSS rules ko HTML document ke <head> ke andar <style> tag mein likha jata hai.

Example 

<html>

<head>

  <style>

    h1 {
      color: green;
      text-align: center;
    }

  </style>

</head>

<body>

  <h1>
    Hello World
  </h1>

</body>

</html>

3. Inline CSS

Inline CSS mein styling directly HTML element ke style attribute ke andar likhi jati hai.

Example 

<h1
  style="color: blue;"
>

  Hello World

</h1>

Multiple CSS Properties

Ek hi HTML element ke andar multiple CSS properties bhi add ki ja sakti hain. 

<p
  style="
    color: red;
    font-size: 20px;
    text-align: center;
  "
>

  CSS Example

</p>

Multiple Style Sheets

Ek HTML page mein ek se zyada external CSS files bhi connect ki ja sakti hain. 

<head>

  <link
  rel="stylesheet"
  href="style.css"
  >

  <link
  rel="stylesheet"
  href="layout.css"
  >

</head>

CSS Methods Comparison

Method Location Best Use
External CSS Separate .css file Multiple pages
Internal CSS <style> tag Single page
Inline CSS style attribute Specific element

Real-Life Example

Maan lo tum ek website bana rahe ho jisme bahut saare HTML pages hain aur sabhi pages ka design same hai.

Ek common style.css file banayi ja sakti hai.

Har HTML page mein CSS file ko <link> tag se connect kiya ja sakta hai.

CSS file mein changes karne par connected pages ki styling update ho sakti hai.

Important Points

  • External CSS ke liye <link> tag use hota hai.
  • Internal CSS <style> tag ke andar likha jata hai.
  • Inline CSS style attribute ke andar likha jata hai.
  • Multiple external CSS files ko ek page mein connect kiya ja sakta hai.
  • Large websites ke liye External CSS useful hota hai.

CSS How To Quick Summary

CSS ko HTML mein 3 main ways se add kiya ja sakta hai.

External CSS separate CSS file mein hota hai.

Internal CSS <style> tag ke andar hota hai.

Inline CSS style attribute ke andar hota hai.

Ek page mein multiple CSS files bhi connect ki ja sakti hain.
