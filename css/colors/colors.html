CSS Colors

CSS Colors Kya Hai?

CSS ka use karke hum HTML elements ke text, background, border aur doosre parts ke colors change kar sakte hain.

CSS mein colors ko alag-alag formats mein define kiya ja sakta hai, jaise color name, HEX, RGB, RGBA, HSL aur HSLA.

CSS Color Property

Text ka color change karne ke liye CSS mein color property ka use kiya jata hai. 

p {
  color: blue;
}

CSS Color Names

CSS mein predefined color names ka directly use kiya ja sakta hai.

Example 

h1 {
  color: red;
}

p {
  color: blue;
}

div {
  color: green;
}

CSS Background Color

Kisi element ka background color change karne ke liye background-color property ka use hota hai. 

body {
  background-color: lightblue;
}

Text Color

Text ka color set karne ke liye color property use hoti hai. 

h1 {
  color: tomato;
}

p {
  color: dodgerblue;
}

Border Color

Border ka color change karne ke liye border-color property ka use hota hai. 

p {
  border: 2px solid;
  border-color: red;
}

HEX Colors

HEX color hexadecimal value ka use karta hai. Ye normally # se start hota hai. 

h1 {
  color: #ff0000;
}

p {
  color: #0000ff;
}

RGB Colors

RGB ka matlab hai Red, Green, Blue. RGB mein teen values hoti hain. 

p {
  color: rgb(255, 0, 0);
}

RGBA Colors

RGBA, RGB ka extended version hai. Ismein fourth value alpha hoti hai jo transparency ko control karti hai. 

div {
  background-color:
    rgba(255, 0, 0, 0.5);
}

HSL Colors

HSL ka matlab hai Hue, Saturation, Lightness. 

p {
  color: hsl(0, 100%, 50%);
}

HSLA Colors

HSLA mein HSL ke saath alpha value bhi hoti hai. 

p {
  color:
    hsla(0, 100%, 50%, 0.5);
}

Important Points

  • Text ka color set karne ke liye color property use hoti hai.
  • Background ka color set karne ke liye background-color use hota hai.
  • CSS mein predefined color names use kiye ja sakte hain.
  • HEX colors # symbol se start hote hain.
  • RGB mein Red, Green aur Blue values hoti hain.
  • RGBA mein alpha value transparency control karti hai.
  • HSL mein Hue, Saturation aur Lightness use hote hain.

CSS Colors Quick Summary

CSS colors website ke elements ko attractive banate hain.

Color names simple aur easy method hain.

HEX colors web development mein bahut commonly use hote hain.

RGB aur RGBA se colors ko numerical values ke through define kiya ja sakta hai.

HSL aur HSLA colors ko Hue, Saturation aur Lightness ke basis par define karte hain.
