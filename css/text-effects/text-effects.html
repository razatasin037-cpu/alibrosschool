CSS Text Effects

CSS Text Effects ka use text ko control aur stylish banane ke liye kiya jata hai. Isme text wrapping, overflow aur spacing jaise effects handle kiye ja sakte hain.

CSS Text Effects Kya Hai?

CSS text effects ki help se long text ko properly handle aur display kiya ja sakta hai. Ye especially cards, headings aur responsive layouts mein useful hain.

text-overflow

text-overflow tab useful hota hai jab text container se bahar ja raha ho. Iske saath commonly overflow aur white-space use kiye jate hain.

Example 

.text {
  width: 200px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Word Wrapping

Long words kabhi-kabhi container se bahar nikal sakte hain. overflow-wrap aise words ko break karne mein help karta hai.

Example 

.content {
  width: 250px;
  overflow-wrap: break-word;
}

word-break

word-break property decide karti hai ki words ko line ke andar kis tarah break kiya ja sakta hai.

Example 

.text {
  word-break: break-all;
}

writing-mode

writing-mode text ki writing direction ko control karta hai. Iska use vertical text layouts mein kiya ja sakta hai.

Example 

.vertical {
  writing-mode: vertical-rl;
}

Text Spacing Effects

Text ko stylish banane ke liye letter aur word spacing ko bhi control kiya ja sakta hai.

Example 

h1 {
  letter-spacing: 3px;
  word-spacing: 8px;
}

Practical Example

Responsive card mein long title ko handle karne ke liye text effects ka use kiya ja sakta hai.

Complete Example 

.card-title {
  max-width: 250px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  letter-spacing: 1px;
}

Important Points

  • text-overflow overflowing text ko handle karta hai.
  • overflow-wrap long words ko break kar sakta hai.
  • word-break word breaking behavior control karta hai.
  • writing-mode text ki direction change kar sakta hai.
  • Text spacing ke liye letter-spacing aur word-spacing use kar sakte hain.

Summary

CSS Text Effects ki help se text ko properly fit, wrap aur style kiya ja sakta hai. Important properties mein text-overflow, overflow-wrap, word-break aur writing-mode shamil hain.
