CSS Object Position

The CSS object-position property controls which part of an image or video is visible inside its container.

CSS Object Position Kya Hai?

object-position batata hai ki container ke andar image ka kaunsa part dikhaya jayega. Ye property normally object-fit: cover ke saath bahut useful hoti hai.

Object Position Syntax

Basic Syntax

img {
  width: 300px;
  height: 200px;
  object-fit: cover;
  object-position: center;
}

1. object-position: center

center image ke center portion ko container ke center mein rakhta hai. 

img {
  object-fit: cover;
  object-position: center;
}

2. object-position: top

top image ke upper part ko visible rakhta hai. 

img {
  object-fit: cover;
  object-position: top;
}

3. object-position: bottom

bottom image ke lower part ko visible rakhta hai. 

img {
  object-fit: cover;
  object-position: bottom;
}

4. object-position: left

left image ke left side ko visible rakhta hai. 

img {
  object-fit: cover;
  object-position: left;
}

5. object-position: right

right image ke right side ko visible rakhta hai. 

img {
  object-fit: cover;
  object-position: right;
}

Custom Position with Percentage

Percentage values se image ki exact position ko control kiya ja sakta hai. 

img {
  object-fit: cover;
  object-position: 70% 30%;
}

Horizontal and Vertical Position

Do values use karne par pehli value horizontal position aur doosri value vertical position control karti hai. 

img {
  object-fit: cover;
  object-position: 70% 30%;
}

Important Points

  • object-position controls the position of an image inside its container.
  • It is especially useful with object-fit: cover.
  • Common values include center, top, bottom, left and right.
  • Percentage values can be used for custom positioning.
  • Two values can control horizontal and vertical positioning.

Common Mistakes

  • Using object-position without understanding the effect of object-fit.
  • Expecting object-position to resize the image.
  • Using incorrect percentage values for the desired position.

Best Practices

  • Use object-fit: cover when cropping is acceptable.
  • Use object-position to keep the important part of an image visible.
  • Use percentages when a predefined position is not enough.

Summary

CSS object-position controls which part of an image or video is visible inside its container. You can use values such as center, top, bottom, left, right and custom percentage values.
