CSS Gradients

CSS Gradients ki help se do ya usse zyada colors ke beech smooth transition create kiya ja sakta hai. Iska use backgrounds aur modern designs mein hota hai.

CSS Gradients Kya Hai?

Gradient ek color se doosre color mein smooth transition hota hai. CSS mein gradients ko background ke roop mein use kiya jata hai.

Linear Gradient

Linear gradient colors ko ek direction mein change karta hai, jaise left se right ya top se bottom.

Example 

.box {
  height: 200px;
  background:
    linear-gradient(to right, blue, purple);
}

Gradient Direction

Linear gradient mein direction bhi set kar sakte hain. Common directions left, right, top aur bottom hain.

Example 

.box {
  background:
    linear-gradient(to bottom, red, yellow);
}

Multiple Colors

Ek gradient mein do se zyada colors bhi use kiye ja sakte hain. Har color ko comma se separate kiya jata hai.

Example 

.box {
  background:
    linear-gradient(to right, red, yellow, green);
}

Radial Gradient

Radial gradient center point se bahar ki taraf colors ka smooth transition create karta hai.

Example 

.box {
  height: 200px;
  background:
    radial-gradient(circle, yellow, red);
}

Conic Gradient

Conic gradient center point ke around colors ko rotate karta hai. Iska use circular aur decorative designs mein kiya ja sakta hai.

Example 

.circle {
  width: 200px;
  height: 200px;
  border-radius: 50%;

  background:
    conic-gradient(red, yellow, blue, red);
}

Gradient with Angle

Linear gradient mein angle use karke exact direction control kar sakte hain.

Example 

.box {
  background:
    linear-gradient(45deg, blue, purple);
}

Practical Example

Gradient ka use website ke hero section ya card ko attractive banane ke liye kiya ja sakta hai.

Complete Example 

.hero {
  padding: 80px;
  text-align: center;

  background:
    linear-gradient(135deg, #2563eb, #7c3aed);

  color: white;
}

Important Points

  • Linear gradient ek direction mein colors change karta hai.
  • Radial gradient center se bahar ki taraf change hota hai.
  • Conic gradient center ke around rotate hota hai.
  • Ek gradient mein multiple colors use kar sakte hain.
  • Gradient ko background property ke saath commonly use kiya jata hai.

Summary

CSS Gradients se colors ke beech smooth transition create kiya jata hai. Main types linear-gradient(), radial-gradient() aur conic-gradient() hain.
