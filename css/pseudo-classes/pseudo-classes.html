CSS Pseudo-Classes

CSS Pseudo-Classes ka use HTML elements ki different states aur special conditions ko select aur style karne ke liye kiya jata hai. Jaise jab user kisi button par mouse lekar jata hai, input mein click karta hai, link visit kar chuka hota hai, ya list ka first item select karna hota hai.

CSS Pseudo-Classes Kya Hai?

Pseudo-Class ek special keyword hota hai jo selector ke saath use kiya jata hai. Iski madad se hum kisi HTML element ki particular state ko target kar sakte hain.

Normal selector jaise button ya .box kisi element ko directly select karta hai. Lekin pseudo-class us element ki condition ke according styling apply karta hai.

Example ke liye agar hum chahte hain ki mouse button ke upar jaane par button ka background change ho jaye, to hum :hover pseudo-class use kar sakte hain.

Pseudo-Class Syntax

Pseudo-class ko selector ke baad colon (:) ke saath likha jata hai. Colon ke baad pseudo-class ka naam diya jata hai.

Basic Syntax 

selector:pseudo-class {
  property: value;
}

Yahan selector HTML element ko represent karta hai aur pseudo-class us element ki specific state ya condition ko represent karta hai.

1. :hover Pseudo-Class

:hover sabse commonly used pseudo-class mein se ek hai. Iska use tab hota hai jab user apne mouse pointer ko kisi element ke upar lekar jata hai.

Buttons, links, cards aur navigation menus mein hover effect bahut common hota hai. Isse user ko visual feedback milta hai ki jis element par cursor hai wo interactive hai.

Hover Example

button:hover {
  background-color: blue;
  color: white;
}

Is code mein jab user button ke upar mouse lekar jayega, tab button ka background blue aur text white ho jayega.

2. :focus Pseudo-Class

:focus pseudo-class ka use us element ko style karne ke liye hota hai jo currently focus mein hai.

Input fields mein iska use bahut important hai. Jab user kisi input field par click karta hai ya keyboard se us input ko focus karta hai, tab hum border, outline ya background change karke user ko clearly bata sakte hain ki abhi kaunsa field active hai.

Focus Example

input:focus {
  border: 2px solid blue;
  outline: none;
}

3. :active Pseudo-Class

:active pseudo-class us waqt apply hota hai jab user kisi interactive element ko actively press kar raha hota hai.

Buttons par click karte waqt ek chhota visual effect dene ke liye :active ka use kiya ja sakta hai. Isse interface zyada responsive aur interactive feel hota hai.

Active Example

button:active {
  transform: scale(0.95);
}

4. :visited Pseudo-Class

:visited pseudo-class ka use un links ko style karne ke liye kiya jata hai jinko user pehle visit kar chuka hai.

Iska use documentation websites, navigation systems aur long article pages mein useful ho sakta hai, jahan user ko pata chal sake ki kaunsa link already visit kiya ja chuka hai.

Visited Example

a:visited {
  color: purple;
}

5. :first-child

:first-child pseudo-class parent ke andar maujood first child element ko select karta hai.

Ye list, menus aur repeated content blocks mein useful hota hai. Isse first item ko alag margin, color, border ya kisi bhi other style ke saath design kiya ja sakta hai.

First Child Example

li:first-child {
  font-weight: bold;
  color: blue;
}

6. :last-child

:last-child parent ke andar jo element last mein hota hai usko select karta hai.

Iska use specially list aur cards ke layout mein useful hota hai. Example ke liye last item ka bottom border remove karna ho to :last-child ka use kiya ja sakta hai.

Last Child Example

li:last-child {
  border-bottom: none;
}

7. :nth-child()

:nth-child() pseudo-class ka use child elements ke specific position ko select karne ke liye hota hai.

Iska sabse common use tables, lists, cards aur grid layouts mein hota hai. Hum specific item jaise second, third ya even/odd items ko target kar sakte hain.

Nth Child Example

li:nth-child(2) {
  color: red;
}

Is example mein list ka second item red ho jayega. Isi tarah :nth-child(3) third item ko select karega.

8. Even aur Odd Items

:nth-child() ki help se hum even aur odd items ko bhi easily select kar sakte hain. Tables aur lists ko readable banane ke liye alternating styles dena ek common practical use hai.

Even and Odd Example

tr:nth-child(even) {
  background-color: #1e293b;
}

tr:nth-child(odd) {
  background-color: #0f172a;
}

Practical Form Example

Real website mein pseudo-classes ka use form inputs, buttons aur links ko interactive banane ke liye bahut kiya jata hai. Neeche ek simple form ka example hai jahan focus hone par input ka border change hota hai aur button hover hone par uska background change hota hai.

Complete Example

<input
  type="text"
  placeholder="Enter your name"
/>

<button>
  Submit
</button>

input:focus {
  border: 2px solid #4d6fff;
  outline: none;
}

button:hover {
  background-color: #254ccb;
  color: white;
}

Pseudo-Classes Kahan Use Hote Hain?

  • Buttons ke hover aur active effects ke liye.
  • Input fields ko focus state mein highlight karne ke liye.
  • Visited links ko alag style dene ke liye.
  • Lists ke first aur last items ko target karne ke liye.
  • Tables mein even aur odd rows ko style karne ke liye.
  • Navigation menus ko interactive banane ke liye.
  • Cards aur repeated components mein specific items ko select karne ke liye.

Important Points

  • Pseudo-classes ko colon : ke saath likha jata hai.
  • :hover mouse pointer element ke upar hone par apply hota hai.
  • :focus focused element ko target karta hai.
  • :active element ko press karte waqt apply hota hai.
  • :visited visited links ko target karta hai.
  • :first-child first child ko select karta hai.
  • :last-child last child ko select karta hai.
  • :nth-child() specific child position ko target karta hai.
  • Pseudo-classes interactive aur dynamic webpages banane mein bahut useful hain.

Summary

CSS Pseudo-Classes ka use HTML elements ki different states aur conditions ko target karne ke liye hota hai. Inki help se hum buttons, links, forms, lists, tables aur other interactive elements ko easily style kar sakte hain.

Sabse commonly used pseudo-classes mein :hover, :focus, :active, :visited, :first-child, :last-child aur :nth-child() aate hain. Inka proper use website ko zyada interactive, clean aur user-friendly banata hai.
