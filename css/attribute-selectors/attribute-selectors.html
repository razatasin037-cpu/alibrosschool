CSS Attribute Selectors

CSS Attribute Selectors ki help se hum HTML elements ko unke attributes ke basis par select aur style kar sakte hain. Normal selectors mein hum element, class ya ID ko target karte hain, lekin attribute selectors mein hum check kar sakte hain ki kisi element ke paas particular attribute hai, attribute ki exact value kya hai, value kisi text se start hoti hai, end hoti hai ya uske andar koi particular word present hai.

CSS Attribute Selectors Kya Hai?

HTML elements ke andar attributes information provide karte hain. Jaise href, target, type, title, disabled aur class. CSS attribute selector square brackets [] ka use karke in attributes ko directly target karta hai.

Basic Syntax

Attribute selector ka basic syntax is tarah hota hai: 

[attribute] {
  property: value;
}

Square brackets ke andar attribute ka naam diya jata hai. CSS phir un sabhi elements ko select karta hai jinke paas woh attribute present hota hai.

1. Attribute Present Hai Ya Nahi

Sabse simple attribute selector sirf attribute ke existence ko check karta hai. Agar element ke paas given attribute hai, to CSS us element par apply ho jayega. Ismein attribute ki value check nahi ki jati.

[attribute] Example 

input[type] {
  border: 2px solid blue;
}

a[target] {
  background-color: lightblue;
}

Yahan input[type] un input elements ko select karega jinke paas type attribute hai. Isi tarah a[target] un links ko select karega jinke paas target attribute present hai.

2. Exact Attribute Value Select Karna

Kabhi-kabhi hume sirf attribute ka hona enough nahi hota. Hume particular value wale elements ko select karna hota hai. Iske liye [attribute="value"] syntax use hota hai.

Exact Value Example 

input[type="text"] {
  background-color: #f1f5f9;
  border: 2px solid blue;
}

input[type="email"] {
  border: 2px solid green;
}

Pehla selector sirf type="text" wale inputs ko target karega, jabki second selector sirf type="email" wale inputs par apply hoga.

3. Multiple Attribute Conditions

Ek hi element ke liye multiple attribute conditions bhi combine ki ja sakti hain. Isse selection aur specific ho jata hai. Multiple conditions ko same selector mein likhne par element ko sabhi conditions satisfy karni hoti hain.

Multiple Conditions Example 

input[type="text"][required] {
  border: 2px solid red;
  background-color: #fff7ed;
}

Is example mein input ke paas type="text" bhi hona chahiye aur required attribute bhi. Dono conditions match hone par hi style apply hoga.

4. Attribute Value Kisi Text Se Start Ho

^= operator ka use tab hota hai jab hume check karna ho ki attribute ki value kisi particular text se start hoti hai. Ye especially links ko unke URL pattern ke according style karne mein useful hai.

Starts With Example 

a[href^="https"] {
  color: green;
}

a[href^="http"] {
  font-weight: bold;
}

a[href^="https"] un links ko select karega jinki href value https se start hoti hai.

5. Attribute Value Kisi Text Par End Ho

$= operator ka use attribute value ke ending part ko check karne ke liye hota hai. For example, hum particular file type ke links ko identify kar sakte hain.

Ends With Example 

a[href$=".pdf"] {
  color: red;
  font-weight: bold;
}

a[href$=".zip"] {
  color: purple;
}

Ismein .pdf par end hone wale links ko ek style milega aur .zip par end hone wale links ko doosra style milega.

6. Attribute Value Mein Word Present Ho

~= operator attribute value ke andar ek specific word ko search karta hai. Ye class-like space-separated values ke saath useful hota hai.

Contains Word Example 

[title~="important"] {
  background-color: yellow;
  font-weight: bold;
}

Agar kisi element ka title attribute "important notice" hai, to [title~="important"] us element ko match karega, kyunki important ek separate word ke roop mein present hai.

7. Attribute Value Mein Text Kahin Bhi Ho

*= operator attribute ki complete value ke andar given text ko kahin bhi search karta hai. Text beginning, middle ya end kahin bhi ho sakta hai.

Contains Text Example 

a[href*="google"] {
  color: orange;
}

img[src*="logo"] {
  border: 2px solid blue;
}

a[href*="google"] un links ko match karega jinki href value ke andar kahin bhi google text present hai.

8. Attribute Value Patterns Ke Saath Links Style Karna

Attribute selectors ka practical use navigation aur external links mein bahut common hai. Hum internal links, external links aur different file types ko alag-alag style de sakte hain bina extra classes add kiye.

Link Styling Example 

a[href^="https"] {
  color: green;
}

a[href$=".pdf"] {
  color: red;
}

a[href*="example"] {
  text-decoration: underline;
}

9. Form Controls Ko Select Karna

Forms mein different types ke inputs hote hain, jaise text, email, password, number, checkbox aur submit. Attribute selectors ki help se har type ke input ko individually target kiya ja sakta hai.

Form Attribute Example 

input[type="text"] {
  padding: 10px;
}

input[type="email"] {
  padding: 10px;
}

input[type="submit"] {
  background: blue;
  color: white;
}

10. disabled aur required Attributes

Boolean attributes jaise disabled aur required ko bhi attribute selectors se target kiya ja sakta hai. Ye forms ko visually communicate karne mein useful hai.

State Styling Example 

input[required] {
  border-left: 4px solid orange;
}

input[disabled] {
  opacity: 0.5;
  cursor: not-allowed;
}

Complete Attribute Selector Example

Neeche HTML aur CSS ka ek complete example hai jisme different attribute selectors ko ek saath use kiya gaya hai. Is example ko browser mein run karke aap selectors ka actual behavior easily samajh sakte hain.

HTML + CSS

<input type="email">

<a href="https://example.com">

</a>

Attribute Selector Cheat Sheet

Selector Meaning
[attr] Attribute present hai
[attr="value"] Exact value match
[attr~="value"] Value mein complete word present hai
[attr^="value"] Value given text se start hoti hai
[attr$="value"] Value given text par end hoti hai
[attr*="value"] Value ke andar text kahin bhi present hai
[attr|="value"] Value exact hai ya given text se hyphen ke saath start hoti hai

Common Mistakes

1. Attribute Name Galat Likhna

Selector mein HTML attribute ka exact naam use karna chahiye. Agar attribute ka naam wrong hai, selector expected elements ko match nahi karega.

2. Exact Value Aur Contains Selector Ko Confuse Karna

[attr="value"] exact match karta hai, jabki [attr*="value"] value ke andar text ko kahin bhi search karta hai. Dono ka behavior same nahi hai.

3. ~= Ka Wrong Use

~= complete space-separated word ko match karta hai. Ye arbitrary substring search ke liye nahi hai. Substring ke liye *= use karein.

4. Unnecessary Selectors Use Karna

Agar simple class selector se kaam easily ho raha hai, to har situation mein complex attribute selector use karna zaroori nahi hai. Selector ko project ki actual requirement ke according choose karein.

Practical Uses

External Links

External URLs ko href^ selector se identify karke different styling di ja sakti hai.

File Links

PDF, ZIP ya other file extensions ko $= selector ke through identify kiya ja sakta hai.

Form Fields

Different input types aur required/disabled controls ko easily style kiya ja sakta hai.

Images

Specific image source patterns ko target karke special styling apply ki ja sakti hai.

Important Points

  • Attribute selectors square brackets [] ka use karte hain.
  • [attribute] attribute ki presence ko check karta hai.
  • [attribute="value"] exact attribute value ko match karta hai.
  • ^= beginning, $= ending aur *= value ke andar text ko target karne ke liye use hota hai.
  • ~= space-separated complete word ko match karta hai.
  • Multiple attribute conditions ko ek selector mein combine kiya ja sakta hai.
  • Forms aur links mein attribute selectors ka practical use bahut common hai.

Summary

CSS Attribute Selectors ki help se HTML elements ko unke attributes aur attribute values ke basis par select kiya ja sakta hai. Basic [attribute] selector attribute ki presence check karta hai, jabki [attribute="value"] exact value match karta hai. ^=, $=, ~= aur *= jaise operators different value patterns ko target karne mein help karte hain. Ye selectors especially forms, links, file types aur pattern-based UI styling mein useful hain.
