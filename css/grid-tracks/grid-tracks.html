CSS Grid Tracks

CSS Grid mein rows aur columns ko Grid Tracks kaha jata hai. Is page par hum track sizes, fr, repeat(), auto aur minmax() ko examples ke saath samjhenge.

Grid Tracks Kya Hai?

Grid ke andar har row aur column ek track hota hai. Columns ko grid-template-columns aur rows ko grid-template-rows se define kiya jata hai.

Basic Example 

.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

fr Unit in Tracks

fr available space ka fractional part represent karta hai. Jaise 1fr 2fr mein second track ko first ke comparison mein double share milta hai.

Example

grid-template-columns: 1fr 2fr 1fr;

Multiple Track Sizes

Ek hi Grid mein different track sizes combine kiye ja sakte hain. Isse complex layouts easily create hote hain.

Example

.container {
  display: grid;
  grid-template-columns: 200px 1fr 2fr;
  grid-template-rows: 80px 1fr auto;
}

Important Grid Track Properties

Property / Function Use
grid-template-columns Column tracks define karta hai
grid-template-rows Row tracks define karta hai
fr Available space ka fractional part
repeat() Repeated tracks create karta hai
minmax() Minimum aur maximum track size define karta hai
auto Available space/content ke according size adjust karta hai

Important Points

  • Grid ki har row aur column ko Grid Track kaha jata hai.
  • grid-template-columns column tracks ko control karta hai.
  • grid-template-rows row tracks ko control karta hai.
  • fr flexible available space ko divide karta hai.
  • repeat() repeated track patterns ke liye useful hai.
  • minmax() responsive track sizing ke liye useful hai.

Common Mistakes

  • Rows aur columns ko confuse karna.
  • Har track ke liye unnecessary fixed pixel values use karna.
  • fr units ka proportion samjhe bina use karna.
  • Responsive layouts mein minmax() aur flexible units ko ignore karna.

Best Practices

  • Flexible layouts ke liye fr ka use karein.
  • Repeated columns ke liye repeat() use karein.
  • Responsive sizing ke liye minmax() useful hai.
  • Different screen sizes par Grid tracks ko test karein.

Summary

CSS Grid Tracks rows aur columns ke individual tracks hote hain. grid-template-columns aur grid-template-rows se inka size define kiya jata hai. fr, repeat(), auto aur minmax() ki help se flexible aur responsive Grid layouts banaye ja sakte hain.
