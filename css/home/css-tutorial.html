CSS Introduction

CSS Kya Hai?

CSS ka full form Cascading Style Sheets hai. Simple words mein, CSS ka use HTML webpage ko design aur style karne ke liye kiya jata hai.

HTML webpage ka structure banata hai, jabki CSS decide karta hai ki wo webpage dikhega kaisa . CSS ki madad se hum colors, fonts, spacing, borders, backgrounds, layouts, buttons, cards, animations aur responsive design bana sakte hain.

Easy Example

Agar HTML ek ghar ka structure hai, to CSS us ghar ka paint, decoration, furniture aur design hai.

CSS Ka Use Kyon Karte Hain?

Agar hum sirf HTML ka use karein, to webpage basic aur simple dikhega. CSS ka use karke hum us webpage ko attractive, professional aur user-friendly bana sakte hain.

CSS Se Hum Kya-Kya Kar Sakte Hain?

  • Text ka color change kar sakte hain.
  • Background color aur background image laga sakte hain.
  • Font ka size aur style change kar sakte hain.
  • Buttons ko attractive bana sakte hain.
  • Cards aur boxes create kar sakte hain.
  • Website ka complete layout design kar sakte hain.
  • Mobile responsive website bana sakte hain.
  • Animation aur transition add kar sakte hain.

Pehla CSS Example

Chalo ek simple example se samajhte hain. Neeche hum h1 heading ka color blue aur text ko center kar rahe hain. 

h1 {
  color: blue;
  text-align: center;
}

Output

Heading blue color mein hogi aur page ke center mein dikhayi degi.

CSS Syntax Samjho

CSS mein ek rule ke andar generally selector , property aur value hoti hai. 

selector {
  property: value;
}

Selector

Selector batata hai ki CSS kis HTML element par apply hogi.

Property

Property batati hai ki element mein kya change karna hai.

Value

Value batati hai ki property ki actual setting kya hogi.

HTML + CSS Ka Example

Ab ek complete example dekhte hain. Ismein hum HTML ke andar heading aur paragraph banayenge aur CSS ke through unko style karenge. 

<!DOCTYPE html>
<html>

<head>

<style>

body {
  background-color: #020617;
  color: white;
  font-family: Arial, sans-serif;
}

h1 {
  color: #4d6fff;
  text-align: center;
}

p {
  color: #cbd5e1;
  font-size: 20px;
  line-height: 1.7;
}

</style>

</head>

<body>

<h1>
  My CSS Website
</h1>

<p>
  Main CSS seekh raha hoon.
</p>

</body>

</html>

Output

Page ka background dark hoga.
Heading blue aur center mein hogi.
Paragraph light gray color mein readable spacing ke saath dikhega.

Real-Life CSS Example

Real website mein CSS ka use sirf text ka color change karne tak limited nahi hai. Hum CSS se complete UI components bana sakte hain. Jaise ek course card: 

<div class="course-card">

  <h2>
    CSS Course
  </h2>

  <p>
    CSS ko basic se advanced level tak seekho.
  </p>

  <button>
    Start Learning
  </button>

</div>


<style>

.course-card {
  width: 350px;
  padding: 30px;
  background: #111827;
  color: white;
  border: 1px solid #334155;
  border-radius: 24px;
  box-shadow: 0 15px 35px rgba(0,0,0,.3);
}

.course-card h2 {
  color: #4d6fff;
  margin-bottom: 12px;
}

.course-card p {
  color: #cbd5e1;
  line-height: 1.7;
}

.course-card button {
  margin-top: 15px;
  padding: 13px 22px;
  border: none;
  border-radius: 10px;
  background: #3158ff;
  color: white;
  cursor: pointer;
}

.course-card button:hover {
  background: #1d4ed8;
}

</style>

Output

Ek dark course card banega.
Card ke corners rounded honge.
Heading blue hogi.
Description light gray hogi.
Neeche blue "Start Learning" button hoga.
Button par mouse le jaane par uska color change hoga.
