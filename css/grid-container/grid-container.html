CSS Grid Container

CSS Grid Container wo parent element hota hai jisme Grid layout enable kiya jata hai. Is page par hum Grid Container ki important properties jaise display, columns, rows, gaps aur alignment ko samjhenge.

Grid Container Kya Hai?

Jis parent element par display: grid lagaya jata hai, use Grid Container kaha jata hai. Uske direct children automatically Grid Items ban jate hain.

Basic Example 

.container {
  display: grid;
}

Grid Columns

grid-template-columns se Grid Container ki columns define hoti hain.

Example

.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

Grid Rows

grid-template-rows se rows ki height define ki ja sakti hai.

Example

.container {
  display: grid;
  grid-template-rows: 100px 150px auto;
}

Column Gap

column-gap columns ke beech horizontal space set karta hai.

Example

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  column-gap: 30px;
}

Row Gap

row-gap rows ke beech vertical space set karta hai.

Example

.container {
  display: grid;
  row-gap: 20px;
}

Grid Container Alignment

Grid Container ke andar poore grid ko align karne ke liye justify-content aur align-content use kiye ja sakte hain.

Example

.container {
  display: grid;
  justify-content: center;
  align-content: center;
}

gap Rows aur columns ke beech spacing
row-gap Rows ke beech spacing
column-gap Columns ke beech spacing
justify-content Grid ko horizontal direction mein align karta hai
align-content Grid ko vertical direction mein align karta hai

Important Points

  • Parent element par display: grid lagane se wo Grid Container ban jata hai.
  • Container ke direct children Grid Items hote hain.
  • grid-template-columns aur grid-template-rows layout ka structure define karte hain.
  • gap, row-gap aur column-gap spacing ke liye use hote hain.
  • fr available space ko flexible proportion mein divide karta hai.

Common Mistakes

  • Grid Container ke bajay individual item par display: grid lagana jab parent layout banana ho.
  • Rows aur columns ke beech spacing ke liye unnecessarily margins ka use karna.
  • Bahut zyada fixed column widths rakhna jisse mobile layout break ho sakta hai.
  • Grid Container aur Grid Item properties ko confuse karna.

Best Practices

  • Main layout ke liye Grid Container ko clearly define karein.
  • Flexible layouts ke liye fr, repeat() aur minmax() ka use karein.
  • Spacing ke liye gap ko prefer karein.
  • Mobile aur desktop dono screen sizes par layout test karein.

Summary

CSS Grid Container wo parent element hai jisme Grid layout enable hota hai. display: grid se container create hota hai, jabki grid-template-columns, grid-template-rows, gap, row-gap aur column-gap layout ko control karte hain. In properties ko samajhkar hum flexible aur responsive layouts easily bana sakte hain.
