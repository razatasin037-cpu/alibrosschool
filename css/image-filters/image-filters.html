CSS Image Filters

CSS filter property is used to add visual effects to images such as blur, grayscale, brightness, contrast and more.

What is CSS Image Filter?

The filter property changes the visual appearance of an element. It is commonly used for image galleries, hover effects and modern website designs.

CSS Filter Syntax

Basic Syntax

img {
  filter: blur(5px);
}

1. blur()

The blur() function makes an image blurry.

Example

img {
  filter: blur(5px);
}

2. brightness()

The brightness() function controls the brightness of an image. 

img {
  filter: brightness(1.6);
}

3. contrast()

The contrast() function controls the difference between light and dark areas. 

img {
  filter: contrast(1.8);
}

4. grayscale()

The grayscale() function removes colors from an image. 

img {
  filter: grayscale(100%);
}

5. hue-rotate()

The hue-rotate() function changes the colors of an image. 

img {
  filter: hue-rotate(120deg);
}

6. invert()

The invert() function reverses the colors of an image. 

img {
  filter: invert(100%);
}

7. opacity()

The opacity() function controls image transparency. 

img {
  filter: opacity(45%);
}

8. saturate()

The saturate() function increases or decreases color intensity. 

img {
  filter: saturate(220%);
}

9. sepia()

The sepia() function gives an image a warm, old-photo appearance. 

img {
  filter: sepia(100%);
}

10. drop-shadow()

The drop-shadow() function adds a shadow around the visible shape of an element. 

img {
  filter: drop-shadow(10px 10px 8px #000);
}

Multiple Filters

You can combine multiple filter functions in a single filter property. 

img {
  filter:
    brightness(1.2) contrast(1.3) saturate(1.5);
}

Filter on Hover

Filters can be combined with :hover to create interactive image effects. 

img {
  filter: grayscale(100%);
  transition: 0.5s;
}

img:hover {
  filter: grayscale(0%);
}

Filter with Transition

Use transition to make filter changes smooth. 

img {
  filter: grayscale(100%);
  transition: filter 0.4s ease;
}

img:hover {
  filter: grayscale(0%);
}

Important Points

  • The filter property creates visual effects.
  • Multiple filter functions can be combined.
  • Different filter functions use different values and units.
  • Filters work well with :hover and transition.
  • drop-shadow() can follow the visible shape of an image.

Common Mistakes

  • Using an incorrect filter function.
  • Forgetting units such as px or deg.
  • Using too many strong filters.
  • Forgetting transition for smooth hover effects.

Best Practices

  • Use moderate filter values.
  • Combine filters carefully.
  • Use transitions for interactive effects.
  • Make sure filtered images remain visible and understandable.

Summary

CSS Image Filters allow you to change the appearance of images using functions such as blur(), brightness(), contrast(), grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia() and drop-shadow().
