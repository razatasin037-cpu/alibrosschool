CSS Inline-Block

CSS inline-block ek important display value hai jo inline aur block elements ke features ko combine karta hai. Iska use elements ko ek hi line mein rakhne ke saath unki width aur height set karne ke liye kiya ja sakta hai.

CSS Inline-Block Kya Hai?

Normally ek block element apni poori available width le sakta hai aur new line se start hota hai. Inline element generally same line mein doosre elements ke saath aa sakta hai, lekin uski width aur height ko control karna limited hota hai.

display: inline-block; dono behaviors ko combine karta hai. Element same line mein reh sakta hai aur saath hi hum uski width, height, padding aur margin ko bhi properly control kar sakte hain.

display: inline-block

Inline-block use karne ke liye element ke CSS mein display property ko inline-block set karna hota hai.

Basic Example 

.box {
  display: inline-block;
  width: 200px;
  height: 100px;
}

Inline, Block aur Inline-Block mein Difference

Inline-block ko achhe se samajhne ke liye inline aur block display ke behavior ko compare karna useful hai.

Display New Line Width / Height Same Line
block Usually yes Yes No
inline No Limited Yes
inline-block No Yes Yes

Multiple Boxes ko Same Line mein Rakhna

Inline-block ka common use multiple boxes ko ek hi line mein rakhna hai. Agar boxes ki total width available space se kam hai, to boxes ek doosre ke side mein appear kar sakte hain.

Example 

.box {
  display: inline-block;
  width: 30%;
  height: 150px;
  margin: 1%;
}

Inline-Block mein Width Set Karna

Inline-block elements ki width ko pixels, percentage, rem ya kisi other supported CSS unit mein set kiya ja sakta hai. Is wajah se inline-block buttons, cards aur menu items ke liye useful hota hai. 

.item {
  display: inline-block;
  width: 200px;
}

Inline-Block mein Height Set Karna

Inline-block element ki height bhi easily set ki ja sakti hai. Ye feature inline-block ko normal inline elements se different banata hai. 

.card {
  display: inline-block;
  width: 250px;
  height: 180px;
}

Padding aur Margin

Inline-block elements ke saath padding aur margin ka use bhi kiya ja sakta hai. Isse elements ke andar aur bahar spacing control karna easy ho jata hai. 

.button {
  display: inline-block;
  padding: 12px 24px;
  margin: 10px;
}

Navigation Menu mein Inline-Block

Inline-block ka use navigation menu ke items ko ek hi horizontal line mein dikhane ke liye bhi kiya ja sakta hai. Har list item ko inline-block dene se menu items side-by-side aa sakte hain.

Example 

li {
  display: inline-block;
  margin-right: 20px;
}

a {
  padding: 10px 15px;
}

Buttons ke Liye Inline-Block

Buttons aur custom links ko style karte waqt inline-block kaafi useful ho sakta hai. Isse element ko same line mein rakhte hue padding, width aur height control ki ja sakti hai. 

.btn {
  display: inline-block;
  padding: 12px 25px;
  width: 150px;
  text-align: center;
}

Inline-Block ke Beech Space

HTML mein inline-block elements ke beech agar whitespace ya newline hoti hai, to browser usse ek chhote gap ke roop mein render kar sakta hai. Isliye inline-block layouts banate waqt unwanted spacing ka dhyan rakhna important hai. 

.box {
  display: inline-block;
  vertical-align: top;
}

vertical-align ke Saath Inline-Block

Inline-block elements ke vertical alignment ko control karne ke liye vertical-align property useful hai. Isse elements ko top, middle ya bottom ke according align kiya ja sakta hai. 

.box {
  display: inline-block;
  vertical-align: middle;
}

Practical Card Layout

Inline-block ka use simple card layout banane mein bhi kiya ja sakta hai. Har card ko fixed ya percentage width dekar ek row mein place kiya ja sakta hai.

Card Example 

.card {
  display: inline-block;
  width: 30%;
  padding: 20px;
  margin: 1%;
  vertical-align: top;
}

Inline-Block aur Responsive Design

Responsive website banate waqt inline-block elements ki width ka dhyan rakhna zaroori hai. Desktop par jo 3 cards ek line mein aa rahe hain, wo mobile screen par fit na ho sakte hain. Media queries ke through width change ki ja sakti hai. 

.card {
  display: inline-block;
  width: 31%;
}

@media (max-width: 600px) {
  .card {
    width: 100%;
  }
}

Inline-Block vs Float

Feature Inline-Block Float
Same line Yes Yes
Width / Height Easy to control Supported
Text wrapping Normal inline flow Text can flow around floated element

Important Points

  • display: inline-block; inline aur block dono ka behavior combine karta hai.
  • Inline-block elements same line mein aa sakte hain.
  • Inline-block elements ki width aur height set ki ja sakti hai.
  • Padding aur margin ko easily control kiya ja sakta hai.
  • Navigation menus aur buttons mein inline-block useful ho sakta hai.
  • Inline-block elements ke beech unwanted whitespace aa sakta hai.
  • Responsive design mein width ko screen size ke according adjust karna chahiye.

Summary

CSS inline-block ka use elements ko same line mein rakhne ke saath unki width aur height ko control karne ke liye kiya jata hai. Ye inline aur block display ke features ko combine karta hai.

Inline-block ka use cards, buttons, navigation menus aur simple horizontal layouts mein kiya ja sakta hai. Responsive website banate waqt element ki width aur available screen space ka dhyan rakhna important hai.
