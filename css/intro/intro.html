CSS Introduction

What is CSS?

CSS ka full form Cascading Style Sheets hai.

CSS ek styling language hai jiska use HTML webpage ko design aur style karne ke liye hota hai.

HTML se hum webpage ka structure banate hain, lekin CSS ki madad se hum decide karte hain ki wo webpage screen par kaisa dikhega .

CSS ke Important Points

  • CSS ka full form Cascading Style Sheets hai.
  • CSS HTML elements ko style karne ke liye use hoti hai.
  • CSS webpage ka layout aur appearance control kar sakti hai.
  • Ek CSS file se multiple HTML pages ko style kiya ja sakta hai.
  • CSS desktop, tablet aur mobile jaise different screen sizes ke liye responsive design banane mein help karti hai.

Simple Words Mein CSS

Agar HTML ko hum website ka skeleton samjhein, to CSS us skeleton ka design hai.

HTML

Website ka structure banata hai.

CSS

Website ko style aur design karta hai.

JavaScript

Website mein interaction aur functionality add karta hai.

CSS Demo

Ek hi HTML page ko alag-alag CSS styles ke saath completely different look diya ja sakta hai.

Example ke liye ek simple heading aur paragraph ko hum CSS se color, alignment, font aur spacing de sakte hain. 

<h1>
  Welcome to My Website
</h1>

<p>
  This is my first CSS page.
</p>

<style>

h1 {
  color: #4d6fff;
  text-align: center;
}

p {
  color: #cbd5e1;
  font-size: 20px;
}

</style>

Is Example Mein Kya Hoga?

Heading blue color mein hogi aur center mein appear hogi.
Paragraph ka color light gray hoga.
Paragraph ka font size 20px hoga.

Why Use CSS?

CSS ka use webpage ke design, layout aur appearance ko control karne ke liye kiya jata hai.

CSS Se Hum Kya Kar Sakte Hain?

Colors

Text aur background ke colors change kar sakte hain.

Fonts

Font family, size, weight aur style change kar sakte hain.

Layout

Website ke elements ko different positions aur layouts mein arrange kar sakte hain.

Responsive Design

Website ko mobile, tablet aur desktop ke liye responsive bana sakte hain.

CSS Example

Ab ek complete CSS example dekhte hain jisme body ka background, heading ka color aur paragraph ka font style change kiya gaya hai. 

body {
  background-color: lightblue;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: Verdana;
  font-size: 20px;
}

Code Ko Samjho

  • body poore webpage ko target karta hai.
  • background-color page ka background color change karta hai.
  • color text ka color set karta hai.
  • text-align text ko left, center ya right align kar sakta hai.
  • font-family text ke font ko define karta hai.
  • font-size text ka size set karta hai.

CSS Saves a Lot of Work!

CSS ka ek bahut bada advantage ye hai ki hum styling ko ek separate .css file mein rakh sakte hain.

Agar website mein 10, 20 ya 100 HTML pages hain, to har page par same CSS baar-baar likhne ki zarurat nahi hoti.

External CSS Example

Maan lo humare paas style.css naam ki file hai. 

body {
  background-color: #020617;
  color: white;
}

h1 {
  color: #4d6fff;
}

Ab HTML file mein hum is CSS file ko link kar sakte hain: 

<!DOCTYPE html>

<html>

<head>

  <link
    rel="stylesheet"
    href="style.css"
  />

</head>

<body>

  <h1>
    My Website
  </h1>

</body>

</html>

Iska Fayda Kya Hai?

  • Ek CSS file ko multiple HTML pages use kar sakte hain.
  • Design change karna bahut easy ho jata hai.
  • Same styling ko baar-baar likhne ki zarurat nahi hoti.
  • Website ka code cleaner aur manageable rehta hai.
  • Puri website ka design ek hi CSS file se update kiya ja sakta hai.

Real-Life Example

Maan lo tumne ek website banayi hai jisme Home, About, Contact aur Courses ke 4 pages hain.

Agar sabhi pages mein same header, buttons, fonts aur colors chahiye, to ek external CSS file bana kar sab pages mein use kar sakte ho.

Without CSS File

Har page mein same styling dobara likhni padegi. Isse code bada aur difficult ho sakta hai.

With External CSS

Ek CSS file sabhi pages ko style kar sakti hai. Design maintain karna easy ho jata hai.
