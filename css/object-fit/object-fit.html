CSS Object Fit

The CSS object-fit property controls how an image or video fits inside its container.

What is Object Fit?

When an image has a fixed width and height, its original aspect ratio may not match the container. The object-fit property decides how the image should be resized inside that space.

Object Fit Syntax

Basic Syntax

img {
  width: 300px;
  height: 200px;
  object-fit: cover;
}

1. object-fit: fill

fill stretches the image to completely fill the container. The original aspect ratio may be changed. 

img {
  object-fit: fill;
}

2. object-fit: contain

contain keeps the complete image visible while maintaining its aspect ratio. Empty space may appear inside the container. 

img {
  object-fit: contain;
}

3. object-fit: cover

cover fills the entire container while maintaining the image's aspect ratio. Some parts of the image may be cropped. 

img {
  object-fit: cover;
}

4. object-fit: none

none keeps the original image size instead of scaling it to fit the container. 

img {
  object-fit: none;
}

5. object-fit: scale-down

scale-down chooses the smaller result between none and contain. 

img {
  object-fit: scale-down;
}

Object Fit Comparison

fill

Stretches to fill the container.

contain

Shows the complete image.

cover

Fills the container and may crop the image.

Object Fit with Hover

You can combine object-fit with hover effects to change how an image is displayed. 

img {
  object-fit: cover;
  transition: 0.4s;
}

img:hover {
  object-fit: contain;
}

Important Points

  • object-fit controls how images and videos fit inside a container.
  • cover fills the container while maintaining the aspect ratio.
  • contain keeps the complete image visible.
  • fill can distort the image.
  • The property works best when the element has a defined width and height.

Common Mistakes

  • Using object-fit without giving the image a useful container size.
  • Using fill when maintaining the image ratio is important.
  • Expecting contain to fill every pixel of the container.

Best Practices

  • Use cover for cards, thumbnails and galleries.
  • Use contain when the complete image must remain visible.
  • Avoid fill when image distortion is undesirable.

Summary

CSS object-fit controls how an image or video fits inside its container. The main values are fill, contain, cover, none and scale-down.
