CSS Animations

CSS Animations ka use elements ko automatically animate karne ke liye kiya jata hai. Animation mein multiple stages define kiye ja sakte hain aur element move, rotate, resize, fade ya color change kar sakta hai.

CSS Animation Kya Hai?

CSS Animation ek element ki CSS properties ko different stages mein change kar sakta hai. Animation ko @keyframes ke through define kiya jata hai aur animation properties se control kiya jata hai.

Basic Animation 

@keyframes moveBox {
  from {
    transform: translateX(0);
  }

  to {
    transform: translateX(200px);
  }
}

.box {
  animation: moveBox 2s ease-in-out infinite alternate;
}

1. @keyframes

@keyframes animation ke different stages define karta hai. Ismein from aur to ya percentage values use ki ja sakti hain.

Keyframes Syntax 

@keyframes example {
  0% {
    transform: scale(1);
  }

  50% {
    transform: scale(1.2);
  }

  100% {
    transform: scale(1);
  }
}

2. animation-name

animation-name batata hai ki element par kaunsa @keyframes animation apply hoga.

Example 

.box {
  animation-name: moveBox;
}

3. animation-duration

animation-duration batata hai ki animation ka ek complete cycle kitne time mein chalega.

Duration 

.box {
  animation-duration: 2s;
}

4. animation-timing-function

Ye animation ki speed ka behavior control karta hai. Common values ease, linear, ease-in, ease-out aur ease-in-out hain.

Timing Function 

.box {
  animation-timing-function: ease-in-out;
}

5. animation-delay

animation-delay animation start hone se pehle waiting time set karta hai.

Delay Example 

.box {
  animation-delay: 1s;
}

6. animation-iteration-count

Ye batata hai ki animation kitni baar repeat hoga. Ismein number ya infinite use kiya ja sakta hai.

Repeat Animation 

.box {
  animation-iteration-count: infinite;
}

7. animation-direction

animation-direction decide karta hai ki animation normal direction mein chalega ya reverse direction mein.

Direction Example 

.box {
  animation-direction: alternate;
}

8. animation-fill-mode

animation-fill-mode define karta hai ki animation ke before ya after element par kaunsi styles apply rahengi.

Fill Mode 

.box {
  animation-fill-mode: forwards;
}

9. animation-play-state

animation-play-state se running animation ko pause ya resume kiya ja sakta hai.

Play State 

.box:hover {
  animation-play-state: paused;
}

16. animation Shorthand

Animation ki multiple properties ko shorthand animation property mein likha ja sakta hai.

Shorthand Syntax 

.box {
  animation:
    moveBox 2s ease-in-out 1s infinite alternate;
}

17. Practical Example

Animation ka use loading indicators, cards, notifications, buttons aur other interactive UI elements mein kiya ja sakta hai.

Animated Card 

@keyframes cardMove {
  50% {
    transform: translateY(-10px);
  }
}

.card {
  animation: cardMove 2s ease-in-out infinite;

Important Points

  • CSS animations ko @keyframes se define kiya jata hai.
  • animation-name keyframes ka naam select karta hai.
  • animation-duration animation ka time set karta hai.
  • animation-delay start hone se pehle wait karta hai.
  • animation-iteration-count repeat count control karta hai.
  • animation-direction animation ki direction control karta hai.
  • animation-play-state se animation pause ya resume kiya ja sakta hai.
  • Multiple animation properties ko shorthand mein likh sakte hain.

Common Mistakes

  • @keyframes ka naam aur animation-name mismatch karna.
  • Animation duration bahut zyada rakhna.
  • Har element par unnecessary infinite animation lagana.
  • Excessive motion se user experience kharab karna.

Best Practices

  • Animations ko simple aur meaningful rakhein.
  • Appropriate duration aur timing function choose karein.
  • Performance ke liye transform aur opacity jaise properties prefer karein.
  • Accessibility ke liye excessive motion avoid karein.

Summary

CSS Animations elements ko automatically animate karne ka powerful way hain. @keyframes se animation ke stages define hote hain, jabki animation properties duration, timing, delay, repeat aur direction ko control karti hain.
