CSS Lists

CSS Lists Kya Hai?

CSS ka use HTML lists ko style karne ke liye kiya jata hai. Aap list ke marker, position, color aur appearance ko easily change kar sakte hain.

HTML mein mainly do types ki lists hoti hain: unordered list aur ordered list.

1. Unordered List

Unordered list mein items ke saamne normally bullets dikhte hain. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

2. List Style Type

list-style-type property list ke marker ka type change karti hai. 

ul {
  list-style-type: square;
}

3. Ordered List

Ordered list mein items numbers ya letters ke sequence mein show hote hain. 

ol {
  list-style-type: upper-roman;
}

4. List Style Image

list-style-image property se bullet ki jagah image use ki ja sakti hai. 

ul {
  list-style-image:
    url("star.png");
}

5. List Style Position

list-style-position property marker ki position ko control karti hai. 

ul {
  list-style-position: inside;
}

6. List Style Shorthand

list-style shorthand se multiple list properties ko ek hi line mein set kar sakte hain. 

ul {
  list-style: square inside;
}

7. Remove List Markers

List ke bullets ya numbers remove karne ke liye list-style-type: none use kiya ja sakta hai. 

ul {
  list-style-type: none;
  padding: 0;
}

8. Horizontal List

List items ko horizontal navigation menu ke liye bhi use kiya ja sakta hai. 

li {
  display: inline;
  margin-right: 20px;
}

Practical Example 

ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}

li {
  display: inline-block;
  padding: 12px 20px;
  background-color: #254ccb;
  margin-right: 8px;
}

Important Points

  • CSS list ke markers ko customize kar sakta hai.
  • list-style-type marker ka type change karta hai.
  • list-style-image se custom image marker use kar sakte hain.
  • list-style-position marker ki position control karta hai.
  • list-style shorthand property hai.
  • Lists ko navigation menus ke liye bhi use kiya ja sakta hai.

CSS Lists Quick Summary

CSS se HTML lists ko easily style kar sakte hain.

Bullets aur numbers ke different styles available hain.

List markers ko remove ya custom image se replace kar sakte hain.

Lists ko horizontal navigation ke liye bhi use kiya ja sakta hai.
