CSS Z-Index

CSS ka z-index property elements ke overlap hone par unki stacking order ko control karta hai.

Z-Index Kya Hai?

Jab webpage par do ya usse zyada elements ek doosre ke upar overlap karte hain, tab z-index decide karta hai ki kaunsa element upar dikhai dega.

Jis element ka z-index value zyada hota hai, wo generally doosre overlapping element ke upar dikhai deta hai.

Z-Index Syntax

Z-index ko CSS mein is tarah use kiya jata hai:

Example 
.box {
  position: relative;
  z-index: 5;
}

Higher Z-Index

Agar overlapping elements mein kisi element ka z-index zyada hai, to wo element upar dikhai dega.

Example 
.box1 {
  position: relative;
  z-index: 1;
}

.box2 {
  position: relative;
  z-index: 2;
}

Yahan box2 ka z-index zyada hai, isliye overlapping hone par box2 upar dikhai dega.

Negative Z-Index

Z-index mein negative values bhi use ki ja sakti hain. Negative z-index wala element doosre elements ke peeche ja sakta hai.

Example 
.box {
  position: relative;
  z-index: -1;
}

Z-Index aur Position

Z-index ka use commonly positioned elements ke saath kiya jata hai, jaise relative, absolute, fixed aur sticky.

Example 
.header {
  position: fixed;
  top: 0;
  z-index: 100;
}

Practical Example

Maan lo do boxes ek doosre ke upar overlap kar rahe hain. Hum z-index ki help se decide kar sakte hain ki kaunsa box sabse upar rahega.

Example 
.box1 {
  position: absolute;
  z-index: 1;
}

.box2 {
  position: absolute;
  z-index: 10;
}

Is example mein box2 upar dikhai dega kyunki uska z-index 10 hai, jabki box1 ka z-index 1 hai.

Important Points

  • Z-index overlapping elements ki stacking order control karta hai.
  • Higher z-index wala element generally upar dikhai deta hai.
  • Z-index mein positive aur negative dono values use kar sakte hain.
  • Z-index ka use positioned elements ke saath commonly hota hai.
  • Z-index ka default value auto hota hai.

CSS Z-Index Summary

CSS ka z-index property overlapping elements ki layering ko control karta hai. Jis element ka z-index value higher hota hai, wo generally doosre overlapping elements ke upar dikhai deta hai.
