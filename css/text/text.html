CSS Text

CSS Text Kya Hai?

CSS mein text properties ka use text ka color, alignment, decoration, spacing aur appearance control karne ke liye kiya jata hai.

CSS text properties ki help se website ke text ko attractive aur readable banaya ja sakta hai.

1. Text Color

color property text ka color change karti hai. 

p {
  color: blue;
}

2. Text Alignment

text-align property text ko left, right, center ya justify karne ke liye use hoti hai. 

h1 {
  text-align: center;
}

Left

Text left side align hota hai.

Center

Text center mein align hota hai.

Right

Text right side align hota hai.

3. Text Decoration

text-decoration property text ke upar, neeche ya through line lagane ke liye use hoti hai. 

p {
  text-decoration: underline;
}

4. Text Transform

text-transform text ko uppercase, lowercase ya capitalize karne ke liye use hoti hai. 

p {
  text-transform: uppercase;
}

5. Text Indent

text-indent paragraph ki first line ko indent karne ke liye use hoti hai. 

p {
  text-indent: 40px;
}

6. Letter Spacing

letter-spacing letters ke beech ka horizontal space control karti hai. 

h1 {
  letter-spacing: 3px;
}

7. Word Spacing

word-spacing words ke beech ka space control karti hai. 

p {
  word-spacing: 10px;
}

8. Line Height

line-height text ki lines ke beech vertical spacing control karti hai. 

p {
  line-height: 1.8;
}

9. Text Shadow

text-shadow text ke peeche shadow effect create karti hai. 

h1 {
  text-shadow: 2px 2px 5px gray;
}

10. Text Direction

direction property text ki writing direction set karne ke liye use hoti hai. 

p {
  direction: rtl;
}

11. White Space

white-space property decide karti hai ki spaces aur line breaks ko browser kaise handle karega. 

p {
  white-space: nowrap;
}

12. Text Overflow

text-overflow ka use overflowing text ko indicate karne ke liye kiya ja sakta hai. 

.text {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Practical Example 

h1 {
  color: #ffffff;
  text-align: center;
  text-transform: uppercase;
  letter-spacing: 2px;
  text-shadow: 2px 2px 5px gray;
}

Important Points

  • color text ka color change karta hai.
  • text-align text ki alignment control karta hai.
  • text-decoration underline aur doosri decorations ke liye use hota hai.
  • text-transform uppercase, lowercase aur capitalize ke liye use hota hai.
  • letter-spacing letters ke beech distance control karta hai.
  • word-spacing words ke beech distance control karta hai.
  • line-height lines ke beech vertical space control karta hai.
  • text-shadow text ko shadow effect deta hai.

CSS Text Quick Summary

CSS text properties text ki appearance ko control karti hain.

Alignment, decoration aur transformation easily change ki ja sakti hai.

Letter, word aur line spacing ko control kiya ja sakta hai.

Text shadow se attractive text effects banaye ja sakte hain.
