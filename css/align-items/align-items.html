CSS Align Items

CSS align-items Flex Container ke cross axis par Flex Items ki alignment control karta hai. Ye especially vertical alignment ke liye useful hai jab direction row ho.

Align Items Kya Hai?

Jab parent element par display: flex hota hai, tab align-items uske direct children ko cross axis par align karta hai.

Basic Syntax 

.container {
  display: flex;
  align-items: center;
}

Column Direction Mein align-items

Agar flex-direction: column use kiya hai, to cross axis horizontal ho jata hai. Isliye align-items horizontal alignment control karega.

Example

  flex-direction: column;

Align Items Values

Value Kaam
stretch Items ko cross axis par stretch karta hai.
flex-start Items ko starting point par rakhta hai.
flex-end Items ko ending point par rakhta hai.
center Items ko center mein rakhta hai.
baseline Items ke text baselines ko align karta hai.

Important Points

  • align-items cross axis par alignment control karta hai.
  • Row direction mein cross axis vertical hota hai.
  • Column direction mein cross axis horizontal hota hai.
  • center vertical ya horizontal centering ke liye commonly use hota hai.
  • baseline text-based alignment ke liye useful hai.

Common Mistakes

  • align-items aur justify-content ko same samajhna.
  • flex-direction change hone par cross axis bhi change hoti hai.
  • stretch ka expected result na milne par child ki fixed cross-axis size check na karna.
  • Parent par display: flex lagana bhool jana.

Best Practices

  • Alignment se pehle main axis aur cross axis identify karein.
  • Simple centering ke liye align-items: center useful hai.
  • Text elements ke different sizes mein baseline try karein.
  • Responsive layouts mein Flexbox alignment properties ko fixed positioning se prefer karein.

Summary

CSS align-items Flex Container ke cross axis par items ki alignment control karta hai. Iski important values stretch, flex-start, flex-end, center aur baseline hain. Flex direction ke according cross axis change ho sakti hai.
