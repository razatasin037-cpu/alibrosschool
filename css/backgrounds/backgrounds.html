CSS Backgrounds

CSS Backgrounds Kya Hai?

CSS ka use karke hum kisi HTML element ke background ko color, image ya different settings ke saath style kar sakte hain.

Background ko control karne ke liye CSS mein kai background properties available hain.

Main Background Properties

background-color

Element ka background color set karta hai.

background-image

Background mein image add karta hai.

background-size

Background image ka size control karta hai.

background-position

Background image ki position set karta hai.

background-repeat

Image repeat hogi ya nahi, ye control karta hai.

background-attachment

Background image scroll ke saath kaise behave karegi, ye define karta hai.

1. Background Color

background-color property se kisi element ka background color set kiya jata hai.

Example 

body {
  background-color: lightblue;
}

h1 {
  background-color: yellow;
}

Background Color Example

Is box ka background blue hai.

2. Background Image

background-image property ka use background mein image lagane ke liye kiya jata hai. 

body {
  background-image:
    url("background.jpg");
}

3. Background Repeat

By default background image repeat ho sakti hai. background-repeat property se is behavior ko control kiya ja sakta hai. 

body {
  background-image:
    url("image.jpg");

  background-repeat: no-repeat;
}

repeat

Image repeat hoti hai.

no-repeat

Image repeat nahi hoti.

repeat-x

Horizontal direction mein repeat.

repeat-y

Vertical direction mein repeat.

4. Background Position

background-position property background image ki position set karti hai. 

body {
  background-image:
    url("image.jpg");

  background-repeat: no-repeat;

  background-position: center;
}

5. Background Size

background-size property background image ka size control karti hai. 

body {
  background-image:
    url("image.jpg");

  background-size: cover;
}

cover

Image element ke complete area ko cover karne ki koshish karti hai.

contain

Image ko element ke andar fit karne ki koshish karti hai.

6. Background Attachment

background-attachment property background image ko scrolling ke saath kaise behave karna hai, ye define karti hai. 

body {
  background-image:
    url("image.jpg");

  background-attachment: fixed;
}

7. Background Shorthand

Multiple background properties ko ek hi background property mein combine kiya ja sakta hai. 

body {
  background:
    #020617 url("image.jpg") no-repeat center;
}

8. Multiple Background Images

CSS mein ek element ke liye multiple background images bhi define ki ja sakti hain. 

div {
  background-image:
    url("image1.png"),
    url("image2.png");
}

Practical Example

Neeche ek simple card ka example hai jisme background color aur background image dono use kiye gaye hain. 

.card {
  background-color: #111827;

  background-image:
    url("image.jpg");

  background-repeat: no-repeat;

  background-position: center;

  background-size: cover;
}

Important Points

  • background-color background ka color set karta hai.
  • background-image se background mein image add hoti hai.
  • background-repeat image repetition ko control karta hai.
  • background-position image ki position set karta hai.
  • background-size image ka size control karta hai.
  • background-attachment scrolling behavior control karta hai.
  • Multiple background images ko comma se separate kiya ja sakta hai.

CSS Backgrounds Quick Summary

CSS background ko color ya image ke saath style kiya ja sakta hai.

Background image ko repeat, position aur size control kiya ja sakta hai.

cover aur contain background image sizing ke useful values hain.

Background shorthand se multiple properties ko short form mein likh sakte hain.
