CSS Syntax

CSS Syntax Kya Hai?

CSS syntax ka matlab hai CSS rule ko likhne ka proper structure .

Ek normal CSS rule mein mainly selector aur declaration block hota hai. 

selector {
  property: value;
}

CSS Syntax Ke Parts

Is basic syntax ko samajhne ke liye humein uske different parts ko samajhna hoga.

1. Selector

Selector batata hai ki CSS kis HTML element par apply karni hai. 

p {
  ...
}

Yahan p paragraph element ko select kar raha hai.

2. Declaration Block

Curly braces { } ke andar jo CSS declarations hoti hain, unko declaration block kaha jata hai. 

p {
  color: red;
}

3. Property

Property batati hai ki selected HTML element mein kya change karna hai. 

color: red;

Yahan color property hai.

4. Value

Value batati hai ki property ko kaunsi setting deni hai. 

color:
red;

Yahan red property ki value hai.

Colon ( : ) Ka Use

CSS mein property aur value ko separate karne ke liye colon (:) ka use hota hai. 

color: blue;

Is example mein color property hai aur blue uski value hai.

Dono ke beech colon : lagaya gaya hai.

Semicolon ( ; ) Ka Use

CSS mein ek declaration ke end mein semicolon (;) lagaya jata hai. 

color: red;
font-size: 20px;
text-align: center;

Yahan teen alag declarations hain aur har declaration ke end mein semicolon use hua hai.

Curly Braces { } Ka Use

CSS declaration block ko curly braces { } ke andar likha jata hai. 

h1 {
  color: blue;
  font-size: 36px;
}

Complete CSS Syntax Example

Ab selector, property, value, colon, semicolon aur curly braces ko ek hi example mein dekhte hain. 

p {
  color: red;
  text-align: center;
  font-size: 20px;
}

Is Code Ko Step-by-Step Samjho

Step 1 — Selector

p selector hai. Iska matlab hai ki ye CSS paragraph elements par apply hogi.

Step 2 — Opening Curly Brace

{ declaration block ko start karta hai.

Step 3 — Property

color, text-align aur font-size properties hain.

Step 4 — Value

red, center aur 20px properties ki values hain.

Step 5 — Semicolon

Har declaration ke end mein ; lagaya gaya hai.

Step 6 — Closing Curly Brace

} declaration block ko close karta hai.

Multiple CSS Declarations

Ek CSS selector ke andar hum ek se zyada declarations likh sakte hain. 

h1 {
  color: #4d6fff;
  font-size: 40px;
  text-align: center;
  margin-bottom: 20px;
}

Is example mein ek hi h1 selector ke andar chaar different properties use ki gayi hain.

Practical Example

Maan lo tumhare webpage par ek paragraph hai aur tum uska color blue, text center aur font size 18px karna chahte ho. 

p {
  color: blue;
  text-align: center;
  font-size: 18px;
}

Result

  • Paragraph ka color blue hoga.
  • Paragraph center mein align hoga.
  • Paragraph ka font size 18px hoga.

CSS Syntax Mein Common Mistakes

❌ Property aur value ke beech colon bhoolna 

color red;

Sahi syntax:

color: red;

❌ Property ke end mein semicolon na lagana 

color: red
font-size: 20px;

Better practice hai ki har declaration ke baad semicolon lagao.

❌ Curly braces bhool jana 

p
  color: red;

CSS declaration ko selector ke curly braces ke andar likhna chahiye.

CSS Syntax Quick Summary

  • Selector batata hai ki kis HTML element ko style karna hai.
  • Declaration block curly braces { } ke andar hota hai.
  • Property batati hai ki kya change karna hai.
  • Value property ki setting batati hai.
  • Property aur value ke beech colon : hota hai.
  • Declarations ko normally semicolon ; se separate kiya jata hai.
