CSS Grid

CSS Grid ek powerful CSS layout system hai jisse hum rows aur columns mein elements ko easily arrange kar sakte hain. Iska use cards, galleries, dashboards aur complete website layouts banane ke liye hota hai.

CSS Grid Kya Hai?

CSS Grid ek two-dimensional layout system hai. Isme hum ek saath rows aur columns ko control kar sakte hain.

Simple Idea

Grid ko ek table jaisa samajh sakte ho jisme rows aur columns hoti hain. Lekin CSS Grid table se kaafi flexible aur powerful hai.

display: grid

Grid start karne ke liye parent element par display: grid lagaya jata hai.

Example 

.container {
  display: grid;
}

Grid Columns

grid-template-columns se hum columns ki width aur number define kar sakte hain.

Example

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
}

Grid Rows

grid-template-rows se rows ki height define ki ja sakti hai.

Example

.container {
  display: grid;
  grid-template-rows: 100px 150px;
}

Gap

gap grid items ke beech ka space set karta hai.

Example

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

repeat()

Agar same size ke multiple columns chahiye, to repeat() function useful hota hai.

Example

grid-template-columns: repeat(3, 1fr);

fr Unit

fr ka matlab fractional unit hai. Ye available space ko proportion ke according divide karta hai.

Example

grid-template-columns: 1fr 2fr;

Grid Items

Grid container ke andar ke direct children ko grid items kaha jata hai. Inki position ko grid-column aur grid-row se control kar sakte hain.

Example

.item1 {
  grid-column: 1 / 3;
}

.item2 {
  grid-row: 2 / 4;
}

Responsive Grid

Grid ko responsive banane ke liye auto-fit aur minmax() ka combination bahut useful hai.

Code

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(160px, 1fr));
  gap: 20px;
}

Important Grid Properties

Property Use
display Grid container banata hai
grid-template-columns Columns define karta hai
grid-template-rows Rows define karta hai
gap Rows aur columns ke beech spacing
grid-column Item ki column position/size
grid-row Item ki row position/size

Important Points

  • Grid container banane ke liye display: grid use hota hai.
  • grid-template-columns columns ko control karta hai.
  • grid-template-rows rows ko control karta hai.
  • gap grid items ke beech spacing deta hai.
  • fr available space ko proportion mein divide karta hai.
  • Responsive layouts ke liye auto-fit aur minmax() useful hain.

Common Mistakes

  • Grid container par display: grid lagana bhool jana.
  • Columns aur rows ke size ko incorrectly define karna.
  • Fixed widths use karke responsive layout ko break kar dena.
  • Grid aur Flexbox ko bina reason ke unnecessarily mix karna.

Best Practices

  • Layout ke liye Grid aur component ke andar alignment ke liye Flexbox use kar sakte hain.
  • Responsive cards ke liye minmax() aur auto-fit try karein.
  • Unnecessary fixed widths se bachein.
  • Different screen sizes par Grid layout ko test karein.

Summary

CSS Grid ek two-dimensional layout system hai jo rows aur columns ke through elements ko arrange karta hai. display: grid, grid-template-columns, grid-template-rows, gap, grid-column aur grid-row iske important properties hain. Responsive layouts ke liye repeat(), auto-fit aur minmax() bahut useful hain.
