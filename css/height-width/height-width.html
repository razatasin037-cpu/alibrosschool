CSS Height and Width

CSS Height and Width Kya Hai?

CSS mein height aur width properties ka use HTML element ki height aur width set karne ke liye kiya jata hai.

In properties ki help se hum element ka size control kar sakte hain.

Simple Example 

div {
  width: 300px;
  height: 200px;
}

CSS Width

width property element ki horizontal size set karti hai. 

div {
  width: 400px;
}

CSS Height

height property element ki vertical size set karti hai. 

div {
  height: 200px;
}

Width and Height in Pixels

Pixels ek fixed unit hai. Iska use karke exact size set kiya ja sakta hai. 

.box {
  width: 500px;
  height: 250px;
}

Percentage Width

Percentage value parent element ke size ke according element ki size determine kar sakti hai. 

.box {
  width: 50%;
}

Width Auto

auto browser ko available space ke according width calculate karne deta hai. 

.box {
  width: auto;
}

max-width

max-width element ki maximum width set karta hai. 

.box {
  max-width: 600px;
}

min-width

min-width element ki minimum width set karta hai. 

.box {
  min-width: 200px;
}

max-height

max-height element ki maximum height set karta hai. 

.box {
  max-height: 300px;
}

min-height

min-height element ki minimum height set karta hai. 

.box {
  min-height: 150px;
}

Height Auto

Height ke liye auto browser ko content aur available layout ke according height determine karne deta hai. 

.box {
  height: auto;
}

Viewport Units

Responsive layouts mein vw aur vh ka use kiya ja sakta hai. 

.box {
  width: 50vw;
  height: 50vh;
}

Practical Example 

.card {
  width: 100%;
  max-width: 500px;
  min-height: 200px;
  margin: 20px auto;
}

Important Points

  • width element ki horizontal size set karta hai.
  • height element ki vertical size set karta hai.
  • min-width minimum width set karta hai.
  • max-width maximum width set karta hai.
  • min-height minimum height set karta hai.
  • max-height maximum height set karta hai.
  • Percentage values responsive layouts mein useful hoti hain.
  • vw viewport width aur vh viewport height ke according size set karte hain.

CSS Height and Width Quick Summary

width horizontal size control karta hai.

height vertical size control karta hai.

min aur max properties size ki limits set karti hain.

Responsive design mein percentage, vw aur vh useful hain.
