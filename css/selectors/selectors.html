CSS Selectors

CSS Selectors Kya Hai?

CSS selector ka use HTML page ke un elements ko select karne ke liye hota hai jinhe hum style karna chahte hain.

Simple words mein, selector CSS ko batata hai ki kis HTML element par styling apply karni hai .

CSS Selectors Ki Main Categories

Simple Selectors

Element name, ID aur class ke basis par elements select karte hain.

Combinator Selectors

HTML elements ke relationship ke basis par elements select karte hain.

Pseudo-class Selectors

Kisi element ki specific state ko target karte hain, jaise hover.

Pseudo-elements

Element ke kisi specific part ko style karne ke liye use hote hain.

Attribute Selectors

HTML attributes ya unki values ke basis par elements select karte hain.

CSS Element Selector

Element selector HTML element ke tag name ke basis par usko select karta hai.

Jaise agar hum p selector use karte hain, to page ke sabhi paragraph elements target ho jayenge. 

p {
  text-align: center;
  color: red;
}

HTML Example 

<p>
  First paragraph
</p>

<p>
  Second paragraph
</p>

CSS ID Selector

ID selector ka use kisi specific unique element ko select karne ke liye kiya jata hai.

ID selector likhne ke liye ID ke naam se pehle # symbol lagaya jata hai. 

#title {
  color: blue;
  text-align: center;
}

HTML Mein ID 

<h1
  id="title"
>
  My Website
</h1>

Yahan title ID hai aur CSS mein usko #title se target kiya gaya hai.

Important

Ek page par ID ko normally unique rakhna chahiye. Ek hi ID ko multiple unrelated elements par use karna avoid karo.

CSS Class Selector

Class selector ka use un HTML elements ko select karne ke liye hota hai jinke paas same class hoti hai.

Class selector ke liye class name se pehle . dot lagaya jata hai. 

.center {
  text-align: center;
  color: red;
}

HTML Example 

<h1
  class="center"
>
  Welcome
</h1>

<p
  class="center"
>
  This is a paragraph.
</p>

Dono elements ki class center hai, isliye dono par .center selector ki styling apply ho sakti hai.

Element ke Saath Class Selector

Kabhi-kabhi humein kisi class ko use karne wale sirf specific HTML element ko target karna hota hai. 

p.center {
  text-align: center;
  color: red;
}

Iska Matlab

p.center ka matlab hai: sirf un <p> elements ko select karo jinki class center hai.

Multiple Classes

Ek HTML element ke andar ek se zyada classes bhi di ja sakti hain. 

<p
  class="center large"
>
  This paragraph has two classes.
</p>
.center {
  text-align: center;
}

.large {
  font-size: 24px;
}

Real-Life Example

Maan lo tum ek shopping website bana rahe ho. Tumhare paas bahut saare product cards hain aur sabhi cards ka same design hona chahiye. 

.product {
  padding: 20px;
  border-radius: 16px;
  background: #0f172a;
  color: white;
}

.product h2 {
  color: #4d6fff;
}

.product button {
  background: #3158ff;
  color: white;
}

Product 1

Same class se same styling.

Product 2

Same class se same styling.

Product 3

Same class se same styling.

ID vs Class

Feature ID Class
Symbol # .
Main Use Specific element Reusable styling
Reuse Normally unique Multiple elements

Important Points

  • Selector decide karta hai ki CSS kis element par apply hogi.
  • Element selector tag name ke basis par elements select karta hai.
  • ID selector ke liye # use hota hai.
  • Class selector ke liye . use hota hai.
  • Ek element mein multiple classes ho sakti hain.
  • Same class ko multiple elements par reuse kiya ja sakta hai.

CSS Selectors Quick Summary

p → sabhi paragraph elements select karega.

#title → specific ID wale element ko select karega.

.center → center class wale elements select karega.

p.center → sirf center class wale paragraphs select karega.
