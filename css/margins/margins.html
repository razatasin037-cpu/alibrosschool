CSS Margin

CSS Margin Kya Hai?

CSS mein margin ka use kisi HTML element ke bahar space create karne ke liye kiya jata hai.

Margin ek element ko doosre elements se distance dene mein help karta hai.

Simple Example 

p {
  margin: 20px;
}

Is example mein paragraph ke bahar 20px margin diya gaya hai.

Margin Ke 4 Sides

Margin ko chaar alag sides ke liye separately set kiya ja sakta hai.

margin-top

Element ke upar space.

margin-right

Element ke right side space.

margin-bottom

Element ke neeche space.

margin-left

Element ke left side space.

1. Margin Top

margin-top element ke upar space create karta hai. 

div {
  margin-top: 30px;
}

2. Margin Right

margin-right element ke right side mein space create karta hai. 

div {
  margin-right: 30px;
}

3. Margin Bottom

margin-bottom element ke neeche space create karta hai. 

div {
  margin-bottom: 30px;
}

4. Margin Left

margin-left element ke left side mein space create karta hai. 

div {
  margin-left: 30px;
}

Margin Shorthand

Chaaron sides ko ek hi margin property se set kiya ja sakta hai. 

div {
  margin: 10px 20px 30px 40px;
}

Values Ka Order

1st

Top

2nd

Right

3rd

Bottom

4th

Left

Two Values 

div {
  margin: 20px 40px;
}

Yahan pehla value top aur bottom ke liye, aur doosra value left aur right ke liye apply hota hai.

Three Values 

div {
  margin: 10px 20px 30px;
}

Teen values mein order hota hai: top, left-right, bottom.

Margin Auto

margin: auto ka use fixed width wale block element ko horizontally center karne ke liye kiya ja sakta hai. 

div {
  width: 300px;
  margin: auto;
}

Centered Element

Negative Margin

CSS mein negative margin bhi use kiya ja sakta hai. Isse element doosre elements ki direction mein move kar sakta hai. 

div {
  margin-top: -20px;
}

Margin Collapse

Kuch block elements ke vertical margins ek doosre ke saath collapse ho sakte hain. Is behavior ko margin collapse kaha jata hai. 

h1 {
  margin-bottom: 30px;
}

p {
  margin-top: 20px;
}

Practical Example

Cards ya sections ke beech distance create karne ke liye margin ka use commonly kiya jata hai. 

.card {
  width: 300px;
  margin: 20px auto;
  padding: 20px;
  border: 2px solid blue;
}

Important Points

  • Margin element ke bahar space create karta hai.
  • Margin ke liye top, right, bottom aur left properties available hain.
  • margin shorthand se multiple sides ek saath set kiye ja sakte hain.
  • margin: auto fixed-width block ko horizontally center karne mein useful hai.
  • Negative margin bhi use kiya ja sakta hai.
  • Vertical margins kuch situations mein collapse ho sakte hain.

CSS Margin Quick Summary

Margin elements ke beech external space create karta hai.

Four sides ko separately control kiya ja sakta hai.

Shorthand mein 1, 2, 3 ya 4 values use ki ja sakti hain.

auto value elements ko center karne mein useful hai.
