CSS Display

CSS Display Kya Hai?

CSS ki display property decide karti hai ki HTML element webpage par kis tarah behave aur appear karega.

Is property ki help se elements ko block, inline, flex, grid, none aur doosre display modes mein set kiya ja sakta hai.

1. display: block

block element normally poori available width leta hai aur new line se start hota hai. 

span {
  display: block;
}

2. display: inline

inline element new line se start nahi hota aur sirf required width leta hai. 

div {
  display: inline;
}

3. display: inline-block

inline-block inline ki tarah same line mein rehta hai, lekin uspar width aur height set ki ja sakti hai. 

span {
  display: inline-block;
  width: 150px;
  height: 50px;
}

4. display: none

display: none element ko page se hide kar deta hai aur uske liye layout mein space bhi nahi rehta. 

.box {
  display: none;
}

5. display: flex

display: flex element ke children ko flexible layout mein arrange karne ke liye use hota hai. 

.container {
  display: flex;
}

6. display: grid

display: grid elements ko rows aur columns wale grid layout mein arrange karne ke liye use hota hai. 

.container {
  display: grid;
  grid-template-columns:
    repeat(3, 1fr);
}

7. display: inline-flex

inline-flex flex container ko inline element ki tarah behave karne deta hai. 

.box {
  display: inline-flex;
}

8. display: inline-grid

inline-grid grid container ko inline element ki tarah display karta hai. 

.box {
  display: inline-grid;
}

9. display: none vs visibility: hidden

display: none element ko hide karke layout se remove kar deta hai, jabki visibility: hidden element ko hide karta hai lekin uski space retain rehti hai. 

.box1 {
  display: none;
}

.box2 {
  visibility: hidden;
}

Practical Example 

.container {
  display: flex;
  gap: 20px;
}

.card {
  display: block;
  padding: 20px;
}

.hidden {
  display: none;
}

Important Points

  • display: block element ko block-level element banata hai.
  • display: inline element ko inline-level element banata hai.
  • display: inline-block inline behavior ke saath width aur height allow karta hai.
  • display: none element ko layout se remove kar deta hai.
  • display: flex flexible layouts ke liye useful hai.
  • display: grid rows aur columns ke layout ke liye useful hai.

CSS Display Quick Summary

Display property element ke layout behavior ko control karti hai.

Block, inline aur inline-block basic display values hain.

Flex aur Grid modern layouts ke liye commonly use hote hain.

display: none element ko completely hide karta hai.
