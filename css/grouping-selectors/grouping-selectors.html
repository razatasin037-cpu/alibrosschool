CSS Grouping Selectors

Grouping Selectors Kya Hai?

CSS mein kabhi-kabhi humein ek hi styling ko multiple HTML elements par apply karna hota hai.

Agar hum har element ke liye alag-alag CSS rule likhen, to code unnecessarily bada ho sakta hai. Is problem ko solve karne ke liye hum grouping selectors ka use karte hain.

Simple Idea

Agar h1, h2 aur p tino ka color same rakhna hai, to tino selectors ko comma , se separate karke ek hi rule mein likh sakte hain.

Grouping Ke Bina CSS

Pehle dekhte hain ki agar grouping na karein to code kaisa dikhega. 

h1 {
  color: blue;
}

h2 {
  color: blue;
}

p {
  color: blue;
}

Problem

Yahan same color property aur same blue value teen baar likhni pad rahi hai.

Grouping Ke Saath CSS

Ab hum tino selectors ko comma se separate karke ek hi CSS rule mein likhenge. 

h1, h2, p {
  color: blue;
}

Ab Kya Hua?

Ab h1, h2 aur p tino par ek hi CSS rule apply hoga.

Isse code chhota, clean aur maintain karna easy ho jata hai.

Comma ( , ) Ka Use

Grouping selectors mein comma , sabse important part hai.

Comma CSS ko batata hai ki hum multiple independent selectors ko ek hi rule ke andar style karna chahte hain. 

h1,
h2,
h3 {
  font-family: Arial;
  color: white;
}

Grouping Mein Multiple Properties

Grouping selector ke andar hum sirf ek property nahi, balki multiple properties bhi add kar sakte hain. 

h1, h2, p {
  color: #4d6fff;
  font-family: Arial;
  text-align: center;
}

Class Selectors Ko Group Karna

Sirf HTML elements hi nahi, hum multiple class selectors ko bhi group kar sakte hain. 

.title, .heading, .description {
  color: white;
}

Different Selectors Ko Group Karna

Grouping ka use karte waqt different types ke selectors ko bhi ek saath use kar sakte hain. 

h1, #main-title, .special {
  color: #4d6fff;
  font-weight: bold;
}

Element

h1

ID

#main-title

Class

.special

Real-Life Example

Maan lo tum ek website bana rahe ho jisme heading, sub-heading aur paragraph ka text center mein hona chahiye. 

h1, h2, p {
  text-align: center;
}

h1, h2 {
  color: #4d6fff;
}

p {
  color: #cbd5e1;
}

Grouping Selectors Ke Fayde

Code Chhota

Same CSS rules ko baar-baar likhne ki zarurat nahi padti.

Clean Code

CSS zyada clean aur readable rehti hai.

Easy Changes

Ek jagah change karke multiple selectors ki styling update ki ja sakti hai.

Less Repetition

Repeated CSS declarations kam ho jati hain.

Important Points

  • Multiple selectors ko comma , se separate kar sakte hain.
  • Grouped selectors ek hi CSS declaration block share karte hain.
  • Element, class aur ID selectors ko bhi group kiya ja sakta hai.
  • Grouping se CSS code short aur maintainable hota hai.
  • Same styling wale elements ke liye grouping useful hai.

Quick Summary

h1, h2, p → tino selectors ko ek saath style karega.

Comma , grouping ke liye use hota hai.

Grouping repeated CSS ko reduce karta hai.

Isse code clean aur easy to maintain hota hai.
