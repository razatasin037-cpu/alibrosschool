CSS Grid Item Alignment

CSS Grid Item Alignment se hum individual Grid Item ko uske grid area ke andar horizontally aur vertically position kar sakte hain.

Grid Item Alignment Kya Hai?

Grid container ko align karne ke alawa hum kisi ek Grid Item ko bhi independently align kar sakte hain. Iske liye mainly justify-self, align-self aur place-self use hote hain.

Main Properties

  • justify-self — item ko horizontal direction mein align karta hai.
  • align-self — item ko vertical direction mein align karta hai.
  • place-self — justify-self aur align-self ko ek saath set karta hai.

1. justify-self

justify-self Grid Item ko uske cell ke andar horizontal direction mein position karta hai.

Start
Center
End

Example 

.box1 {
  justify-self: start;
}

.box2 {
  justify-self: center;
}

.box3 {
  justify-self: end;
}

2. justify-self Values

Value Meaning
start Item ko cell ke start par rakhta hai.
center Item ko horizontal center mein rakhta hai.
end Item ko cell ke end par rakhta hai.
stretch Item ko available horizontal space mein stretch karta hai.

3. align-self

align-self ek individual Grid Item ko vertical direction mein align karta hai.

Start
Center
End

Example 

.box1 {
  align-self: start;
}

.box2 {
  align-self: center;
}

.box3 {
  align-self: end;
}

4. align-self Values

Value Meaning
start Item ko grid area ke top/start par rakhta hai.
center Item ko vertical center mein rakhta hai.
end Item ko bottom/end par rakhta hai.
stretch Item ko available vertical space mein stretch karta hai.

5. place-self

place-self ek shorthand property hai jo align-self aur justify-self dono ko ek saath set karti hai.

Centered Item

Example 

.box {
  place-self: center;
}

6. Different Horizontal and Vertical Alignment

Agar horizontal aur vertical alignment alag rakhna ho to place-self mein do values de sakte hain. Pehli value vertical aur doosri horizontal alignment ke liye hoti hai.

Example 

.box {
  place-self: center end;
}

Important Points

  • justify-self horizontal alignment control karta hai.
  • align-self vertical alignment control karta hai.
  • place-self dono properties ko combine karta hai.
  • Alignment individual Grid Item par apply ki ja sakti hai.
  • Grid Item ke paas available space hona alignment ko visible banata hai.

Common Mistakes

  • justify-content ko justify-self samajhna.
  • align-items aur align-self ko confuse karna.
  • Grid Item ke available space ko ignore karna.
  • Unnecessary alignment properties ko har item par apply karna.

Best Practices

  • Simple alignment ke liye start, center aur end use karein.
  • Ek item ko alag position karna ho to justify-self ya align-self use karein.
  • Dono directions ko ek saath control karna ho to place-self use karein.
  • Responsive layouts mein unnecessary fixed sizes avoid karein.

Summary

CSS Grid Item Alignment mein individual Grid Items ko unke grid area ke andar control kiya jata hai. justify-self horizontal alignment, align-self vertical alignment aur place-self dono directions ko control karta hai.
