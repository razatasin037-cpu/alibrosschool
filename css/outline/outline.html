CSS Outline

CSS Outline Kya Hai?

CSS mein outline ka use kisi HTML element ke border ke bahar ek line draw karne ke liye kiya jata hai.

Outline border se alag hota hai aur element ki layout size ko normally affect nahi karta.

Border vs Outline

Border

Border element ke box ka part hota hai aur box model ko affect kar sakta hai.

Outline

Outline border ke bahar draw hota hai aur normally layout size ko affect nahi karta.

Simple Example

Neeche element ke around ek solid outline lagayi gayi hai. 

div {
  outline: 2px solid blue;
}

Outline Style

outline-style se outline ka style set kiya jata hai.

solid

Solid Outline

dashed

Dashed Outline

dotted

Dotted Outline 
div {
  outline-style: solid;
}

Outline Width

outline-width se outline ki thickness set ki jati hai. 

div {
  outline-width: 4px;
  outline-style: solid;
}

Outline Color

outline-color se outline ka color set kiya jata hai. 

div {
  outline-style: solid;
  outline-width: 3px;
  outline-color: blue;
}

Outline Offset

outline-offset outline aur element ke border ke beech distance create karta hai. 

div {
  outline: 3px solid blue;
  outline-offset: 5px;
}

Outline Shorthand

outline shorthand se width, style aur color ko ek hi line mein set kiya ja sakta hai. 

div {
  outline: 3px solid blue;
}

3D ridged appearance.

Practical Example

Outline ka common use input fields ko focus state mein highlight karna hai. 

input:focus {
  outline: 3px solid blue;
  outline-offset: 2px;
}

outline: none

outline: none outline ko remove kar deta hai. 

input {
  outline: none;
}

Accessibility Tip

Keyboard users ke liye focus indicator important hota hai. Isliye outline: none use karte waqt ek alternative visible focus style dena chahiye.

Important Points

  • Outline border ke bahar draw hota hai.
  • Outline normally element ki layout size ko affect nahi karta.
  • outline-style se style set hota hai.
  • outline-width se thickness set hoti hai.
  • outline-color se color set hota hai.
  • outline-offset outline aur border ke beech distance deta hai.
  • outline shorthand se multiple values ek saath set ki ja sakti hain.
  • Focus states mein outline accessibility ke liye useful hota hai.

CSS Outline Quick Summary

Outline element ke border ke bahar draw hota hai.

Outline mein width, style aur color set kiya ja sakta hai.

outline-offset outline ki position ko control karta hai.

Focus indicators ke liye outline bahut useful hai.
