CSS Grid Gaps

CSS Grid mein gap properties ka use rows aur columns ke beech spacing dene ke liye hota hai. Is page par hum gap, row-gap aur column-gap ko examples ke saath samjhenge.

CSS Grid Gaps Kya Hai?

Grid items ke beech jo empty space hota hai, use gap kaha jata hai. Gap ko set karne se items ke beech clean aur consistent spacing milti hai.

Basic Syntax 

.container {
  display: grid;
  gap: 20px;
}

gap Property

gap ek shorthand property hai jo rows aur columns dono ke beech spacing set kar sakti hai.

Property Use

Important Grid Gap Properties

Property Description
gap Rows aur columns dono ke beech space
row-gap Rows ke beech vertical space
column-gap Columns ke beech horizontal space

Important Points

  • gap rows aur columns dono ke beech spacing set karta hai.
  • row-gap sirf rows ke beech spacing ke liye hai.
  • column-gap sirf columns ke beech spacing ke liye hai.
  • gap: 30px 15px mein 30px row gap aur 15px column gap hota hai.
  • Gap margins ki tarah items ke outer edges par space add nahi karta.

Common Mistakes

  • row-gap aur column-gap ko ulta samajhna.
  • Gap ki jagah unnecessary margins use karna.
  • Bahut large gap rakhna jisse layout mein unnecessary empty space aa jaye.
  • Mobile screens par gap ko test na karna.

Best Practices

  • Consistent spacing ke liye gap ka use karein.
  • Rows aur columns ki different spacing chahiye to row-gap aur column-gap use karein.
  • Responsive layouts mein gap ko reasonable value par rakhein.
  • Unnecessary margins ke bajay Grid gap ko prefer karein.

Summary

CSS Grid mein gaps ka use Grid items ke beech spacing ke liye hota hai. gap rows aur columns dono ki spacing control karta hai, jabki row-gap sirf rows aur column-gap sirf columns ko control karta hai. Different row aur column spacing ke liye gap mein do values bhi di ja sakti hain.
