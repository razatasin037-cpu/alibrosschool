CSS Grid Item Alignment

CSS Grid Item Alignment se hum kisi individual Grid Item ko uske grid area ke andar horizontally aur vertically position kar sakte hain.

CSS Grid Item Alignment Kya Hai?

Grid container ke andar har item ek grid area mein hota hai. CSS ki item alignment properties se hum ek particular item ki position control kar sakte hain.

Main Properties

  • justify-self — item ko horizontal direction mein align karta hai.
  • align-self — item ko vertical direction mein align karta hai.
  • place-self — horizontal aur vertical alignment ko ek saath set karta hai.

1. justify-self

justify-self individual Grid Item ko uske grid cell ke andar horizontal direction mein align karta hai.

Start
Center
End

justify-self Example 

.box1 {
  justify-self: start;
}

.box2 {
  justify-self: center;
}

.box3 {
  justify-self: end;
}

2. justify-self Values

Value Meaning
start Item ko cell ke starting side par rakhta hai.
center Item ko horizontal center mein rakhta hai.
end Item ko cell ke ending side par rakhta hai.
stretch Item ko available horizontal space mein stretch karta hai.

3. align-self

align-self individual Grid Item ko uske grid cell ke andar vertical direction mein align karta hai.

Start
Center
End

align-self Example 

.box1 {
  align-self: start;
}

.box2 {
  align-self: center;
}

.box3 {
  align-self: end;
}

4. align-self Values

Value Meaning
start Item ko grid area ke start par rakhta hai.
center Item ko vertical center mein rakhta hai.
end Item ko grid area ke end par rakhta hai.
stretch Item ko available vertical space mein stretch karta hai.

5. place-self

place-self ek shorthand property hai jo align-self aur justify-self dono ko ek saath control karti hai.

Centered
End

place-self Example 

.box {
  place-self: center;
}

6. Different Horizontal and Vertical Alignment

place-self mein do values dene par vertical aur horizontal alignment ko alag control kar sakte hain.

Two Value Example 

.box {
  place-self: center end;
}

8. Grid Item Alignment vs Container Alignment

Property Controls
justify-items Container ke saare Grid Items ki horizontal alignment.
align-items Container ke saare Grid Items ki vertical alignment.
justify-self Ek individual Grid Item ki horizontal alignment.
align-self Ek individual Grid Item ki vertical alignment.
place-self Ek individual item ki horizontal + vertical alignment.

Important Points

  • justify-self individual item ki horizontal alignment control karta hai.
  • align-self individual item ki vertical alignment control karta hai.
  • place-self dono directions ko ek saath control karta hai.
  • Common values start, center, end aur stretch hain.
  • Item alignment tab clearly visible hoti hai jab grid cell mein extra space available ho.

Common Mistakes

  • justify-items aur justify-self ko confuse karna.
  • align-items aur align-self ko confuse karna.
  • Grid Item ke cell mein extra space na hone par alignment ka visible effect expect karna.
  • Har item par unnecessarily alag alignment properties lagana.

Best Practices

  • Ek individual item ko control karna ho to justify-self ya align-self use karein.
  • Dono directions ko ek saath set karne ke liye place-self use karein.
  • Container ke sabhi items ko same tarah align karna ho to justify-items aur align-items better choice hain.
  • Responsive layouts mein fixed positioning ke bajay Grid alignment properties ka use karein.

Summary

CSS Grid Item Alignment se individual Grid Items ko unke grid area ke andar align kiya jata hai. justify-self horizontal alignment, align-self vertical alignment aur place-self dono directions ko control karta hai.
