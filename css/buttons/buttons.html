CSS Buttons

CSS se buttons ko color, size, border, shape, shadow, hover effect aur different styles ke saath design kiya ja sakta hai.

CSS Buttons Kya Hai?

Button ek interactive element hota hai jise user click karke koi action perform karta hai. CSS ka use karke button ka appearance aur interaction improve kiya ja sakta hai.

Basic Button

Sabse simple button banane ke liye background, color, padding aur border-radius use kar sakte hain. 

button {
  background: #254ccb;
  color: white;
  padding: 12px 24px;
  border-radius: 10px;
}

Button Colors

Different background colors use karke different types ke buttons create kiye ja sakte hain. 

.success {
  background-color: green;
}

.danger {
  background-color: red;
}

Rounded Buttons

border-radius ka use karke buttons ko rounded ya pill shape diya ja sakta hai. 

button {
  border-radius: 999px;
}

Outline Buttons

Transparent background aur border ke saath outline button banaya ja sakta hai. 

button {
  background: transparent;
  border: 2px solid #3b82f6;
  color: #3b82f6;
}

Button Sizes

Padding aur font-size change karke buttons ke different sizes banaye ja sakte hain. 

.small {
  padding: 8px 12px;
}

.large {
  padding: 16px 28px;
}

Button Shadow

box-shadow button ko depth aur modern appearance deta hai. 

button {
  box-shadow:
    0 8px 20px rgba(0,0,0,0.35);
}

Gradient Button

Gradient background se attractive modern buttons banaye ja sakte hain. 

button {
  background:
    linear-gradient(135deg, #2563eb, #7c3aed);
}

Button Hover Effect

:hover pseudo-class se mouse button par aane par style change kar sakte hain. 

button {
  background: #254ccb;
  transition: 0.3s;
}

button:hover {
  background: #304cd6;
}

Buttons with Icons

Font Awesome icons ko buttons ke andar use karke UI ko aur clear banaya ja sakta hai. 

<button>

  <i class="fa-solid fa-download"></i>

  Download

</button>

Disabled Button

disabled attribute se button ko inactive kiya ja sakta hai. 

<button disabled>
  Disabled
</button>

Active Button

:active pseudo-class button press karte waqt temporary effect create karti hai. 

button:active {
  transform: translateY(3px);
}

Button Group

Multiple buttons ko ek group mein rakhkar toolbar ya action controls banaye ja sakte hain. 

<div class="button-group">

  <button>Save</button>

  <button>Submit</button>

  <button>Delete</button>

</div>

Important Points

  • Buttons ko style karne ke liye background, color, padding aur border useful properties hain.
  • border-radius se rounded buttons banaye ja sakte hain.
  • :hover se interactive hover effects create kiye ja sakte hain.
  • :active button press hone par effect deta hai.
  • Disabled buttons ke liye disabled attribute use karein.

Common Mistakes

  • Button ka text aur background color readable na hona.
  • Hover state ko completely ignore karna.
  • Bahut chhota clickable area banana.
  • Disabled aur active states ko properly define na karna.

Best Practices

  • Buttons ka text clear aur readable rakhein.
  • Hover aur active states provide karein.
  • Buttons ko touch devices ke liye sufficiently large rakhein.
  • Similar actions ke liye consistent button styling use karein.

Summary

CSS Buttons ko background, color, padding, border, border-radius, box-shadow aur pseudo-classes jaise :hover aur :active ke saath attractive aur interactive banaya ja sakta hai.
