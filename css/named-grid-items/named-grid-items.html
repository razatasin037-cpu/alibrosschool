CSS Named Grid Items

CSS Named Grid Items se hum grid ke different areas ko naam dekar layout ko easily organize kar sakte hain.

Named Grid Items Kya Hai?

CSS Grid mein grid-template-areas ka use karke hum grid ke areas ko custom names de sakte hain. Phir grid-area property se kisi item ko us named area mein place kar sakte hain.

Main Properties

  • grid-template-areas — grid areas ke names define karta hai.
  • grid-area — item ko named area assign karta hai.
  • Named areas layout ko readable aur easy-to-maintain banate hain.

1. grid-template-areas

Sabse pehle grid container mein areas ke names define karte hain. Har string ek row ko represent karti hai.

Example 

.container {
  display: grid;

  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

2. grid-area

Ab individual Grid Items ko unke named areas assign karte hain.

Example 

.header {
  grid-area: header;
}

.sidebar {
  grid-area: sidebar;
}

.main {
  grid-area: main;
}

.footer {
  grid-area: footer;
}

3. Complete Named Grid Layout

Neeche ek complete layout hai jisme header, sidebar, main content aur footer ko names diye gaye hain.

Header
Sidebar
Main Content
Footer

Complete Code 

.layout {
  display: grid;

  grid-template-areas:
    "header header header"
    "sidebar main main"
    "footer footer footer";

  grid-template-columns:
    180px 1fr 1fr;

  grid-template-rows:
    80px 180px 70px;

  gap: 12px;
}

.header {
  grid-area: header;
}

.sidebar {
  grid-area: sidebar;
}

.main {
  grid-area: main;
}

.footer {
  grid-area: footer;
}

4. Same Area Multiple Times

Ek named area ko multiple cells mein repeat karke kisi item ko bada area diya ja sakta hai.

Example 

.layout {
  display: grid;

  grid-template-areas:
    "header header header"
    "sidebar content content"
    "sidebar content content"
    "footer footer footer";
}

.sidebar {
  grid-area: sidebar;
}

.content {
  grid-area: content;
}

5. Empty Grid Cells

Named grid areas mein dot . ka use empty cell ke liye kiya ja sakta hai.

Example 

.layout {
  display: grid;

  grid-template-areas:
    "header header"
    "sidebar ."
    "footer footer";
}

6. Responsive Named Grid

Media Query ke andar grid-template-areas ko change karke mobile layout easily banaya ja sakta hai.

Responsive Example 

.layout {
  display: grid;

  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

@media (max-width: 700px) {
  .layout {
    grid-template-areas:
      "header"
      "sidebar"
      "main"
      "footer";
  }
}

7. Named Grid Areas vs Line Numbers

Method Use
grid-area Named areas se layout readable hota hai.
grid-column / grid-row Grid lines ke through exact placement ke liye useful hai.
grid-template-areas Overall layout structure visually define karta hai.

Important Points

  • grid-template-areas named layout areas define karta hai.
  • grid-area item ko named area mein place karta hai.
  • Same name ko multiple cells mein repeat karke area ko span kar sakte hain.
  • Dot . empty grid cell ko represent karta hai.
  • Responsive design mein named areas ko media queries ke saath change kiya ja sakta hai.

Common Mistakes

  • Different rows mein named area ka invalid shape banana.
  • grid-area ka naam grid-template-areas se match na karna.
  • Empty cells ke liye dot . ka use bhoolna.
  • Mobile layout mein areas ko update na karna.

Best Practices

  • Area names ko meaningful rakhein, jaise header, sidebar aur footer.
  • Complex layouts ke liye named areas code ko readable banate hain.
  • Responsive layouts mein media queries ka use karein.
  • Ek area ko unnecessarily bahut complex na banayein.

Summary

CSS Named Grid Items mein grid-template-areas se named areas define kiye jaate hain aur grid-area se items ko un areas mein place kiya jata hai. Isse complex aur responsive layouts ko simple aur readable way mein create karna easy ho jata hai.
