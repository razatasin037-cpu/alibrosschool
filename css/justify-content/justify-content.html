CSS Justify Content

CSS justify-content Flex Container ke main axis par Flex Items ki position aur unke beech ki spacing control karta hai.

Justify Content Kya Hai?

Jab parent element par display: flex hota hai, tab justify-content items ko main axis par arrange karta hai. Default value flex-start hoti hai.

Basic Syntax 

.container {
  display: flex;
  justify-content: center;
}

Justify Content Values

Value Kaam
flex-start Items start mein
flex-end Items end mein
center Items center mein
space-between Items ke beech equal space
space-around Items ke around space
space-evenly Sabhi spaces equal

Important Points

  • justify-content main axis par alignment control karta hai.
  • flex-direction: row mein main axis horizontal hota hai.
  • flex-direction: column mein main axis vertical hota hai.
  • space-between, space-around aur space-evenly available space distribute karte hain.
  • Alignment samajhne ke liye main axis aur cross axis ko identify karna important hai.

Common Mistakes

  • justify-content ko cross axis alignment ke liye use karna.
  • display: flex ke bina property use karna aur expected result na milna.
  • flex-direction: column ke baad bhi justify-content ko horizontal samajhna.
  • Space distribution values ko bina difference samjhe use karna.

Best Practices

  • Sabse pehle main axis identify karein.
  • Navigation layouts ke liye space-between useful hai.
  • Equal spacing ke liye space-evenly useful ho sakta hai.
  • Responsive layouts mein unnecessary fixed margins ki jagah Flexbox alignment use karein.

Summary

CSS justify-content Flex Container ke main axis par items ki alignment aur spacing control karta hai. Iske important values flex-start, flex-end, center, space-between, space-around aur space-evenly hain.
