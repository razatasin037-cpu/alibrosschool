CSS 2D Transforms

CSS 2D Transforms ka use kisi element ko move, rotate, scale ya skew karne ke liye kiya jata hai. Iske liye mainly transform property aur uske functions use hote hain.

CSS 2D Transform Kya Hai?

2D transform kisi element ko horizontal ya vertical direction mein move kar sakta hai, rotate kar sakta hai, size change kar sakta hai ya tilt kar sakta hai.

Basic Transform 

.box {
  transform: translateX(50px);
}

1. translate()

translate() element ko uski original position se move karta hai. Isme X aur Y direction dono control ki ja sakti hain.

Translate Example 

.box {
  transform: translate(50px, 30px);
}

translateX() element ko sirf horizontal direction mein move karta hai.

3. translateY()

translateY() element ko vertical direction mein move karta hai.

translateY() 

.box {
  transform: translateY(-30px);
}

4. rotate()

rotate() element ko clockwise ya anticlockwise rotate karta hai. Angle ko degree mein define kiya jata hai.

Rotate Example 

.box {
  transform: rotate(45deg);
}

5. 360 Degree Rotation

Kisi element ko complete circle rotate karne ke liye rotate(360deg) use kar sakte hain.

360 Degree 

.box:hover {
  transform: rotate(360deg);
}

6. scale()

scale() element ka size increase ya decrease karta hai. scale(1) normal size hota hai.

Scale Example 

.box {
  transform: scale(1.3);
}

7. scaleX() aur scaleY()

scaleX() width direction mein aur scaleY() height direction mein scaling karta hai.

Scale X and Y 

.box {
  transform: scaleX(1.5);
}

.box2 {
  transform: scaleY(1.5);
}

8. skew()

skew() element ko horizontally aur vertically tilt karta hai.

Skew Example 

.box {
  transform: skew(20deg, 10deg);
}

9. skewX() aur skewY()

skewX() horizontal axis par tilt karta hai aur skewY() vertical axis par tilt karta hai.

skewX() and skewY() 

.box {
  transform: skewX(20deg);
}

.box2 {
  transform: skewY(20deg);
}

10. Multiple Transforms

Ek hi element par multiple transform functions ko ek saath use kiya ja sakta hai.

Multiple Transforms

  transform:
    translateX(30px) rotate(20deg) scale(1.1);
}

11. Rotate + Scale

Transform functions ko combine karke attractive hover effects create kiye ja sakte hain.

Rotate + Scale Example 

.card:hover {
  transform:
    rotate(5deg) scale(1.05);
}

12. Translate + Rotate

Element ko move karte hue rotate bhi kiya ja sakta hai.

Translate + Rotate 

.box:hover {
  transform:
    translateY(-10px) rotate(3deg);
}

14. transform-origin

transform-origin define karta hai ki transform kis point ke around perform hoga. Default origin generally center hota hai.

Transform Origin 

.box {
  transform-origin: top left;
  transform: rotate(20deg);
}

15. matrix()

matrix() ek advanced transform function hai jo multiple 2D transform operations ko ek mathematical matrix ke through represent karta hai.

Matrix Example 

.box {
  transform: matrix(1, 0, 0, 1, 50, 30);
}

16. Practical Example

Ab ek practical card example dekhte hain jisme translate, scale aur rotate ko combine kiya gaya hai.

Complete Transform Example 

.card {
  transition: transform 0.4s ease;
}

.card:hover {
  transform:
    translateY(-10px) rotate(2deg) scale(1.05);
}

Important Points

  • translate() element ko move karta hai.
  • rotate() element ko rotate karta hai.
  • scale() element ka size change karta hai.
  • skew() element ko tilt karta hai.
  • Multiple transform functions ek saath use kiye ja sakte hain.
  • transform-origin transformation ka starting point control karta hai.
  • Hover effects ke liye transforms kaafi useful hain.

Best Practices

  • Smooth effects ke liye transition use karein.
  • Bahut zyada rotation ya scaling avoid karein.
  • Transform effects ko user experience improve karne ke liye use karein.
  • Complex transforms ko readable rakhein.

Summary

CSS 2D Transforms ke through elements ko move, rotate, scale aur skew kiya ja sakta hai. translate(), rotate(), scale(), skew() aur matrix() important transform functions hain. Inhe combine karke attractive hover effects aur interactive UI designs create kiye ja sakte hain.
