CSS Borders

CSS Borders Kya Hai?

CSS border ka use kisi HTML element ke around line ya boundary create karne ke liye kiya jata hai.

Border ka style, width, color aur corners ko CSS properties ki help se customize kiya ja sakta hai.

Main Border Properties

border-style

Border ka design ya style set karta hai.

border-width

Border ki thickness set karta hai.

border-color

Border ka color set karta hai.

border-radius

Border ke corners ko rounded banata hai.

border

Multiple border properties ko short form mein likhta hai.

Individual Borders

Top, right, bottom aur left border ko separately style kar sakte hain.

1. Border Style

border-style property border ka type define karti hai. 

p {
  border-style: solid;
}

2. Border Width

border-width property border ki thickness set karti hai. 

p {
  border-style: solid;
  border-width: 5px;
}

3. Border Color

border-color property border ka color set karti hai. 

p {
  border-style: solid;
  border-width: 3px;
  border-color: red;
}

4. Border Radius

border-radius property border ke corners ko rounded banane ke liye use hoti hai. 

div {
  border: 3px solid blue;
  border-radius: 15px;
}

Rounded Border

Border radius se corners smooth aur rounded ho jate hain.

5. Individual Borders

Top, right, bottom aur left borders ko separately define kiya ja sakta hai. 

div {
  border-top: 3px solid red;
  border-right: 3px solid blue;
  border-bottom: 3px solid green;
  border-left: 3px solid orange;
}

6. Border Shorthand

border shorthand se width, style aur color ko ek hi line mein define kiya ja sakta hai. 

div {
  border: 5px solid blue;
}

7. Different Border Styles

solid — simple continuous line

dashed — broken line

dotted — dots wali line

double — double line

Important Points

  • border-style border ka design set karta hai.
  • border-width border ki thickness set karta hai.
  • border-color border ka color set karta hai.
  • border-radius corners ko rounded banata hai.
  • Top, right, bottom aur left borders ko separately style kar sakte hain.
  • border shorthand se width, style aur color ek line mein likh sakte hain.
