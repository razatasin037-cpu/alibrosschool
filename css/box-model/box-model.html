CSS Box Model

CSS Box Model Kya Hai?

CSS ka Box Model har HTML element ko ek box ke form mein treat karta hai.

Har element ke andar aur bahar alag-alag layers hoti hain: Content, Padding, Border aur Margin.

Content

Element ka actual text ya content.

Padding

Content ke around andar ka space.

Border

Padding aur margin ke beech ki boundary.

Margin

Element ke bahar ka space.

Box Model Structure

Content

Padding

Border

1. Content

Content element ka main part hota hai. Ismein text, image ya koi doosra HTML content ho sakta hai. 

div {
  width: 300px;
  height: 150px;
}

2. Padding

Padding content aur border ke beech ka internal space hota hai. 

div {
  padding: 20px;
}

3. Border

Border padding ko surround karta hai aur element ki boundary create karta hai. 

div {
  border: 2px solid blue;
}

4. Margin

Margin element ke bahar space create karta hai aur doosre elements se distance maintain karta hai. 

div {
  margin: 20px;
}

Complete Box Model Example 

.box {
  width: 300px;
  height: 150px;
  padding: 20px;
  border: 5px solid blue;
  margin: 30px;
}

box-sizing Property

box-sizing property decide karti hai ki element ki width aur height kaise calculate hogi. 

* {
  box-sizing: border-box;
}

content-box

content-box default value hai. Ismein width aur height sirf content area ke liye hoti hai. 

div {
  box-sizing: content-box;
}

border-box

border-box mein specified width aur height ke andar padding aur border include hote hain. 

div {
  box-sizing: border-box;
}

Practical Example 

.card {
  width: 300px;
  padding: 20px;
  border: 2px solid #3158ff;
  margin: 20px auto;
  box-sizing: border-box;
}

Important Points

  • CSS Box Model ke four main parts hain: Content, Padding, Border aur Margin.
  • Padding content ke andar hota hai.
  • Border element ki boundary create karta hai.
  • Margin element ke bahar space create karta hai.
  • box-sizing: border-box layouts ko manage karna easier bana sakta hai.
  • Width aur height calculate karte waqt box model ko samajhna important hai.

CSS Box Model Quick Summary

Content element ka actual content hota hai.

Padding content ke around internal space hota hai.

Border element ki boundary hoti hai.

Margin element ke bahar ka space hota hai.
