CSS Float

CSS Float property ka use kisi element ko left ya right side par place karne ke liye kiya jata hai. Float ka use especially images ke around text ko flow karne, layouts banane aur old CSS layouts mein columns create karne ke liye kiya jata tha.

CSS Float Kya Hai?

CSS mein float property ka use element ko normal document flow se ek side move karne ke liye kiya jata hai. Element ko left ya right float kiya ja sakta hai.

Jab kisi element par float apply hota hai, to uske baad aane wala content us floated element ke around flow kar sakta hai. Ye behavior images aur text ke layouts mein bahut useful hota hai.

CSS Float Syntax

Basic Syntax 

selector {
  float: value;
}

Float Property ke Values

Float property ke kuch important values hote hain. In values ko use karke hum decide karte hain ki element kis direction mein float karega.

Value Meaning
left Element ko left side float karta hai.
right Element ko right side float karta hai.
none Element float nahi karega. Ye default value hai.
inherit Parent element ki float value inherit karega.

float: left

float: left; ka use element ko left side move karne ke liye kiya jata hai. Element ke baad ka text ya inline content uske right side flow kar sakta hai.

Example 

img {
  float: left;
  margin-right: 20px;
}

float: right

float: right; element ko container ke right side par move karta hai. Iska use bhi images aur layout elements ke saath kiya ja sakta hai.

Example 

img {
  float: right;
  margin-left: 20px;
}

float: none

float: none; ka matlab hai ki element float nahi karega. Ye float property ki default value hoti hai. Agar kisi element par pehle se float apply hai aur aap usse normal position mein lana chahte hain, to none use kiya ja sakta hai.

Image ke Saath Float

Float ka sabse common example image aur paragraph ke saath dekhne ko milta hai. Agar image ko left float kiya jaye, to paragraph ka text image ke right side se flow kar sakta hai.

HTML + CSS Example 

<img
  src="image.jpg"
  class="photo"
/>

<p>
  Ye text floated image ke around flow karega.
</p>

.photo {
  float: left;
  margin-right: 20px;
}

Float ke Saath Margin

Float karne ke baad margin ka use karna useful hota hai. Isse floated element aur surrounding content ke beech proper space create hota hai. 

.image {
  float: left;
  margin-right: 25px;
  margin-bottom: 15px;
}

Multiple Elements ko Float Karna

Ek se zyada elements ko float kiya ja sakta hai. Agar multiple boxes ko float: left; diya gaya hai, to wo available horizontal space ke according ek doosre ke side mein aa sakte hain.

Example 

.box {
  float: left;
  width: 30%;
  margin: 1%;
}

CSS clear Property

Float ke saath clear property ko samajhna bhi important hai. Clear property ka use ye control karne ke liye hota hai ki koi element floated elements ke side mein aa sakta hai ya nahi. 

.next-section {
  clear: both;
}

clear ke Important Values

Value Use
left Left floated elements ko clear karta hai.
right Right floated elements ko clear karta hai.
both Left aur right dono floats ko clear karta hai.
none Clear apply nahi karta.

Float se Layout Banana

Purane CSS layouts mein float ka use columns create karne ke liye bahut common tha. Ek container ke andar multiple boxes ko left float karke columns ka layout banaya jata tha. 

.column {
  float: left;
  width: 33.33%;
  padding: 20px;
}

Float aur Modern Layout

Aaj ke modern web development mein complete page layout banane ke liye Flexbox aur CSS Grid zyada convenient hote hain. Lekin iska matlab ye nahi hai ki Float useless ho gaya. Text ke around images flow karane jaise situations mein Float abhi bhi useful hai.

Method Best Use
Float Image ke around text aur simple floating elements.
Flexbox One-dimensional row ya column layouts.
Grid Complex rows aur columns wala layout.

Important Points

  • Float property element ko left ya right side move kar sakti hai.
  • float: left; element ko left side float karta hai.
  • float: right; element ko right side float karta hai.
  • float: none; default floating behavior ko remove karta hai.
  • Float ke saath clear property ko samajhna important hai.
  • Images ke around text flow karane ke liye Float useful hai.
  • Modern page layouts ke liye Flexbox aur Grid generally easier options hain.

Summary

CSS Float ka use elements ko left ya right side float karne ke liye kiya jata hai. float: left element ko left side aur float: right element ko right side place karta hai. Float ke saath text surrounding area mein flow kar sakta hai.

Float ko properly use karne ke liye clear property ko bhi samajhna zaroori hai. Modern layouts mein Flexbox aur Grid ka use zyada common hai, lekin images ke around text arrange karne ke liye Float abhi bhi useful CSS property hai.
