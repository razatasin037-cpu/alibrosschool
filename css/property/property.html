CSS @property

CSS @property se hum custom CSS properties ko register karke unka data type, inheritance aur default value control kar sakte hain. Iska sabse useful feature custom properties ko smoothly animate karna hai.

CSS @property Kya Hai?

@property ek CSS at-rule hai jo custom property ko register karta hai. Is registration se browser ko pata chalta hai ki custom property kis type ki value accept karegi, kya woh inherit karegi aur uski initial value kya hogi.

Simple Idea

Normal custom property sirf value store karti hai. Lekin @property browser ko us value ka type bhi batata hai. Is wajah se browser us property ko transition aur animation mein smoothly handle kar sakta hai.

Basic Syntax

@property ke andar mainly teen important descriptors hote hain: syntax, inherits aur initial-value.

Example 

@property --progress {
  syntax: "<number>";
  inherits: false;
  initial-value: 0;
}

syntax

syntax batata hai ki custom property kis type ki value accept karegi.

Number 

@property --size {
  syntax: "<number>";
  inherits: false;
  initial-value: 1;
}

Color 

@property --main-color {
  syntax: "<color>";
  inherits: false;
  initial-value: blue;
}

Common Syntax Types

Syntax Use
<number> Number values
<length> px, rem, %, etc.
<color> Color values
<angle> deg, rad, turn
<percentage> Percentage values

inherits

inherits decide karta hai ki custom property parent element se child element mein inherit hogi ya nahi.

inherits: true 

@property --theme-color {
  syntax: "<color>";
  inherits: true;
  initial-value: blue;
}

Child elements parent ki value inherit kar sakte hain.

inherits: false 

@property --theme-color {
  syntax: "<color>";
  inherits: false;
  initial-value: blue;
}

Child automatically parent ki value inherit nahi karega.

initial-value

initial-value custom property ki default value define karta hai. Agar property ko koi value nahi di gayi, to registered initial value use hoti hai.

Example 

@property --box-size {
  syntax: "<length>";
  inherits: false;
  initial-value: 100px;
}

.box {
  width: var(--box-size);
  height: var(--box-size);
}

@property --progress {

.progress-box {

    conic-gradient(

}

@property Kyun Use Karein?

Smooth Animation

Typed custom properties ko browser interpolate kar sakta hai.

Type Control

Browser ko property ka expected data type pata hota hai.

Inheritance Control

inherits se inheritance behavior control kar sakte hain.

Default Value

initial-value se default value define hoti hai.

Important Points

  • @property ek CSS at-rule hai jo custom property ko register karta hai.
  • Custom property ka naam normally -- se start hota hai.
  • syntax property ka data type define karta hai.
  • inherits decide karta hai ki value children mein inherit hogi ya nahi.
  • initial-value default value define karta hai.
  • Typed custom properties smooth transitions aur animations ke liye useful hain.
  • @property ko use karte waqt syntax aur initial-value compatible hone chahiye.

Common Mistakes

Wrong Syntax 

@property --size {
  syntax: number;
}

Syntax descriptor mein type ko string format mein likhna chahiye.

Correct Syntax 

@property --size {
  syntax: "<number>";
  inherits: false;
  initial-value: 1;
}

Best Practices

  • Custom properties ke naam meaningful rakhein.
  • Correct syntax select karein.
  • inherits ko requirement ke according set karein.
  • Valid aur sensible initial-value use karein.
  • @property ka use especially typed custom properties aur animations mein karein.
  • Production project mein browser support ko bhi check karein.

Summary

CSS @property custom CSS properties ko register karne ka powerful way hai. Isme syntax value ka type, inherits inheritance aur initial-value default value define karta hai. Typed custom properties ki help se smooth transitions aur animations create karna easier ho jata hai.
