CSS Position

CSS ka position property kisi element ko webpage par kis jagah aur kis tarah position karna hai, ye control karta hai.

CSS Position Property

CSS mein position property ka use kisi HTML element ki positioning ko control karne ke liye kiya jata hai.

Is property ki help se hum decide kar sakte hain ki element normal document flow mein rahega ya kisi specific position par place hoga.

CSS Position ki Values

CSS mein position property ki mainly ye values hoti hain:

  • static – default position
  • relative – apni normal position ke according move karna
  • absolute – positioned parent ke according position karna
  • fixed – screen ke according fixed rehna
  • sticky – scroll karne par ek position par stick rehna

position: static

static CSS position ki default value hoti hai. Agar hum kisi element ki position define nahi karte hain, to normally element static position mein hota hai.

Example 
.box {
  position: static;
}

position: relative

relative position ka use karke hum element ko uski normal position ke comparison mein move kar sakte hain.

Iske saath hum top, right, bottom aur left properties ka use kar sakte hain.

Example 
.box {
  position: relative;
  left: 30px;
  top: 20px;
}

position: absolute

absolute position wala element normal document flow se remove ho jata hai.

Ye element apne nearest positioned parent ke according position hota hai.

Example 
.box {
  position: absolute;
  top: 20px;
  right: 20px;
}

position: fixed

fixed position wala element browser window ke according fixed position par rehta hai.

Page ko scroll karne ke baad bhi element apni position par bana rehta hai.

Example 
.box {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

position: sticky

sticky position initially normal position ki tarah behave karta hai.

Lekin jab page scroll hota hai aur element specified position tak pahunchta hai, to wo wahan stick ho jata hai.

Example 
.box {
  position: sticky;
  top: 0;
}

Top, Right, Bottom aur Left

Positioned elements ko move karne ke liye hum top, right, bottom aur left properties ka use kar sakte hain.

Example 
.box {
  position: relative;
  top: 20px;
  left: 30px;
}

Important Points

  • static position default hoti hai.
  • relative element ko uski normal position se move karta hai.
  • absolute element normal document flow se bahar ho jata hai.
  • fixed element viewport ke according fixed rehta hai.
  • sticky scrolling ke time specified position par stick hota hai.

CSS Position Summary

CSS ka position property elements ki positioning ko control karne ke liye use hota hai. Iski important values static, relative, absolute, fixed aur sticky hain.
