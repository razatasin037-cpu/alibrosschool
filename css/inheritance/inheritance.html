CSS Inheritance

CSS Inheritance ek important concept hai jisme ek HTML element ki kuch CSS properties uske child elements tak automatically pahunch jaati hain. Is concept ki wajah se hume har child element ke liye same CSS property baar-baar likhne ki zarurat nahi padti. Inheritance ko samajhna clean, reusable aur maintainable CSS likhne ke liye bahut important hai.

CSS Inheritance Kya Hai?

Inheritance ka simple meaning hai parent element ki CSS property ka child element tak inherit hona. HTML mein elements ek parent-child relationship mein ho sakte hain. Agar parent element par koi inheritable CSS property apply ki gayi hai, to browser us property ko child elements par bhi apply kar sakta hai.

Example ke liye agar ek div ke andar multiple paragraphs hain aur hum div ka text color set kar dete hain, to paragraphs generally wahi color inherit kar sakte hain. Isse CSS code chhota aur easy to manage ho jata hai.

Basic Inheritance Example 

body {
  color: white;
}

p {
  font-size: 18px;
}

Yahan body ka color child elements ko inherit ho sakta hai. Lekin har CSS property inherit nahi hoti. Ye baat CSS Inheritance mein sabse important concepts mein se ek hai.

Parent aur Child Elements

Inheritance ko samajhne ke liye parent aur child relationship samajhna zaroori hai. Agar ek element ke andar doosra element hai, to outer element parent aur inner element child ho sakta hai.

HTML Structure 

<div>
  <h2>Heading</h2>
  <p>Paragraph</p>
</div>

Is example mein div parent hai aur h2 aur p uske children hain. Agar div par koi inheritable property set ki jaati hai, to uska effect child elements par aa sakta hai.

1. Color Inheritance

color ek common inheritable property hai. Agar parent element ka text color define kiya gaya hai, to child elements normally us color ko inherit kar sakte hain jab tak child par alag color explicitly define na kiya gaya ho.

Color Inheritance Example 

.container {
  color: #60a5fa;
}

.container p {
  font-size: 18px;
}

Agar paragraph ke liye alag color define nahi kiya gaya, to paragraph parent container ka color use kar sakta hai.

2. Font Properties ki Inheritance

Font se related kai properties inherit hoti hain. Jaise font-family, font-size, font-style aur font-weight context ke according child elements ko inherited value de sakti hain.

Font Inheritance Example 

.article {
  font-family: Arial, sans-serif;
  font-size: 18px;
}

.article p {
  line-height: 1.7;
}

3. inherit Keyword

CSS ka inherit keyword explicitly browser ko batata hai ki property ki value parent element se inherit ki jaye. Ye tab useful hota hai jab hum kisi property ko child element par specifically inherited rakhna chahte hain.

inherit Example 

.parent {
  color: #38bdf8;
}

.child {
  color: inherit;
}

4. initial Keyword

initial keyword kisi CSS property ko uski initial value par reset karne ke liye use hota hai. Ye inheritance ko continue karne ke bajay property ko CSS specification ki initial value par le ja sakta hai.

initial Example 

.box {
  color: red;
}

.child {
  color: initial;
}

5. unset Keyword

unset ek special CSS value hai jo property ke inheritance behavior ke according decide karta hai ki property ko inherit karna hai ya initial value par reset karna hai. Agar property naturally inherit hoti hai, to unset inheritance behave karta hai. Agar property inherit nahi hoti, to initial behavior use hota hai.

unset Example 

.parent {
  color: blue;
}

.child {
  color: unset;
}

6. revert Keyword

revert keyword CSS cascade mein applied author styling ko previous origin ke behavior ki taraf revert kar sakta hai. Ye advanced CSS situations mein useful hota hai, especially jab browser ya user-agent styles ko restore karna ho.

revert Example 

button {
  all: revert;
}

7. Har CSS Property Inherit Nahi Hoti

Ye inheritance ka sabse important rule hai. CSS ki har property automatically inherit nahi hoti. Kuch properties naturally inherit hoti hain aur kuch properties nahi hoti. Isliye agar parent par margin ya padding set kiya gaya hai, to automatically ye assume nahi karna chahiye ki child ko same margin ya padding mil jayega.

Common Inherited

  • color
  • font-family
  • font-size
  • font-style
  • font-weight
  • line-height
  • text-align

Commonly Not Inherited

  • margin
  • padding
  • border
  • width
  • height
  • background
  • display

8. Child Inherited Value ko Override Karna

Agar child element par same property ki value explicitly define kar di jaye, to child ki own declaration inherited value ko override kar sakti hai. Isse hum parent ke common styling ko maintain karte hue specific child ko different bana sakte hain.

Override Example 

.parent {
  color: white;
}

.parent p {
  color: #60a5fa;
}

9. Multiple Levels of Inheritance

Inheritance ek hi level tak limited nahi hoti. Agar parent se child ko koi value inherit hoti hai aur child ke andar bhi grandchild element hai, to inherited value further descend bhi kar sakti hai, jab tak beech mein kisi element par alag value define na ho.

Inheritance Chain 

body {
  font-family: Arial, sans-serif;
  color: #e2e8f0;
}

main {
  line-height: 1.7;
}

article {
  max-width: 70ch;
}

10. all Property aur Inheritance

CSS ka all shorthand property ek element ki almost sabhi CSS properties ko ek saath control karne ke liye use kiya ja sakta hai. Iske saath inherit, initial, unset aur revert jaise global values use ki ja sakti hain.

all: inherit Example 

.child {
  all: inherit;
}

11. Practical Inheritance Example

Real website mein inheritance ka use common typography aur text styling ko parent container par define karne ke liye kiya ja sakta hai. Isse har heading aur paragraph ke liye same font-family ya text color baar-baar likhne ki need kam ho jaati hai.

Complete Example 

.website {
  font-family: Arial, sans-serif;
  color: #e2e8f0;
  line-height: 1.6;
}

.website h1 {
  font-size: 40px;
}

.website p {
  font-size: 18px;
}

.website a {
  color: #38bdf8;
}

CSS Inheritance ka Practical Use

Typography

Parent container par font-family aur text color define karke child text elements ko consistent styling di ja sakti hai.

Theme Styling

Common text color aur font properties ko parent level par maintain karna easy hota hai.

Less CSS

Repeated declarations ko reduce karke CSS ko cleaner aur maintainable banaya ja sakta hai.

Consistent Design

Related content ke andar common styling automatically maintain karne mein inheritance helpful hoti hai.

Common Mistakes

  • Ye assume karna ki har CSS property automatically inherit hoti hai.
  • margin aur padding jaise properties ko inheritance samajhna.
  • inherit aur initial keywords ka purpose confuse karna.
  • Child element par explicitly defined value ko ignore karna.
  • Deeply nested elements mein inherited styles ka source check na karna.

Best Practices

  • Common typography properties ko parent containers par define karein.
  • Har property ko inherit hone wali property samajhne se pehle check karein.
  • Specific child styling ke liye explicit CSS declaration use karein.
  • inherit, initial, unset aur revert ka purpose clearly samjhein.
  • Browser DevTools se inherited styles inspect karna practice karein.

Important Points

  • CSS inheritance parent element se child element tak values pass karne ka concept hai.
  • Har CSS property inherit nahi hoti.
  • color aur kai font-related properties commonly inherit hoti hain.
  • margin, padding aur border jaise properties normally inherit nahi hoti.
  • inherit keyword explicitly parent value use karne ke liye helpful hai.
  • initial property ko uski initial value par reset karta hai.
  • unset property ke inheritance behavior ke according kaam karta hai.
  • Child element ki explicit declaration inherited value ko override kar sakti hai.
  • Inheritance CSS repetition ko reduce karke code ko cleaner bana sakti hai.

Summary

CSS Inheritance ka matlab hai ki parent element ki kuch CSS properties child elements tak automatically pass ho sakti hain. Is concept ki wajah se same styling ko multiple elements par baar-baar likhne ki zarurat kam ho jaati hai.

Inheritance mein sabse important baat ye hai ki har CSS property inherit nahi hoti. color, font-related properties aur kuch text properties commonly inherit hoti hain, jabki margin, padding aur border jaise properties normally inherit nahi hoti. inherit, initial, unset aur revert jaise keywords inheritance ko control karne mein useful hain.
