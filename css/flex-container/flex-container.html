CSS Flex Container

CSS Flex Container ek parent element hota hai jiske andar ke child elements ko Flexbox ke through arrange kiya jata hai. Is page par hum Flex Container ki important properties ko examples ke saath samjhenge.

Flex Container Kya Hai?

Jab kisi element par display: flex; lagate hain, to woh Flex Container ban jata hai. Uske direct children Flex Items ban jaate hain.

Important Points

  • display: flex parent element ko Flex Container banata hai.
  • flex-direction items ki direction control karta hai.
  • flex-wrap items ko next line mein jaane ki permission deta hai.
  • justify-content main axis par alignment control karta hai.
  • align-items cross axis par items ko align karta hai.
  • align-content multiple flex lines ko align karta hai.
  • gap items ke beech spacing set karta hai.

Common Mistakes

  • display: flex parent par na lagana.
  • align-items aur align-content ko same samajhna.
  • Small screens par flex-wrap ko ignore karna.
  • Spacing ke liye unnecessary margins use karna jab gap enough ho.

Best Practices

  • Layout ke according flex-direction choose karein.
  • Responsive layouts mein flex-wrap ka use karein.
  • Consistent spacing ke liye gap use karein.
  • Main aur cross axis ko samajhkar alignment properties use karein.

Summary

CSS Flex Container Flexbox layout ka parent element hota hai. display: flex se container create hota hai aur flex-direction, flex-wrap, justify-content, align-items, align-content aur gap jaise properties se uske items ko control kiya jata hai.
