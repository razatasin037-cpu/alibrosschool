CSS Masking

CSS Masking ka use element ke kuch parts ko hide ya visible karne ke liye kiya jata hai. Isse images aur other elements ko creative shapes aur fade effects diye ja sakte hain.

CSS Masking Kya Hai?

CSS Masking ek technique hai jisme mask decide karta hai ki element ka kaunsa part visible rahega aur kaunsa part hide hoga. Masking ka use mostly images, backgrounds aur decorative designs mein hota hai.

mask-image Property

mask-image kisi image, gradient ya other mask source ko use karke element ki visibility control karta hai.

Basic Syntax

.image {
  mask-image:
    linear-gradient(to right, transparent, black);
}

1. Circular Mask

Radial gradient ka use karke image ko circular shape mein mask kiya ja sakta hai. 

.circle {
  mask-image:
    radial-gradient(circle, black 60%, transparent 61%);
}

2. Gradient Mask

Linear gradient se image ke edges ko smoothly fade kiya ja sakta hai. 

.fade {
  mask-image:
    linear-gradient(
      to right,
      transparent,
      black 25%,
      black 75%,
      transparent
    );
}

3. Vertical Mask

Mask ko vertical direction mein bhi apply kiya ja sakta hai. 

.vertical {
  mask-image:
    linear-gradient(
      to bottom,
      transparent,
      black 25%,
      black 75%,
      transparent
    );
}

4. Ellipse Mask

Radial gradient ka ellipse shape use karke image ko oval appearance diya ja sakta hai. 

.ellipse {
  mask-image:
    radial-gradient(
      ellipse,
      black 55%,
      transparent 56%
    );
}

5. Diagonal Mask

Linear gradient ke angle ko change karke diagonal masking effect create kar sakte hain. 

.diagonal {
  mask-image:
    linear-gradient(
      135deg,
      black 50%,
      transparent 51%
    );
}

mask-position

mask-position mask ki position control karta hai. 

.image {
  mask-position: center;
}

mask-size

mask-size mask ke size ko control karta hai. 

.image {
  mask-size: cover;
}

mask-repeat

mask-repeat decide karta hai ki mask repeat hoga ya nahi. 

.image {
  mask-repeat: no-repeat;
}

Mask Shorthand

Mask properties ko shorthand mein bhi combine kiya ja sakta hai. 

.image {
  mask:
    linear-gradient(to right, transparent, black);
}

Important Points

  • CSS masking element ke visible aur hidden areas ko control karta hai.
  • mask-image masking ke liye sabse important property hai.
  • Gradients se creative masking effects banaye ja sakte hain.
  • mask-position, mask-size aur mask-repeat additional control dete hain.
  • Browser compatibility ke liye -webkit-mask-* bhi useful ho sakta hai.

Common Mistakes

  • Mask ke liye incorrect gradient ya image source use karna.
  • black aur transparent areas ka effect na samajhna.
  • Browser compatibility ke liye -webkit- prefix ko ignore karna jab required ho.

Best Practices

  • Simple masks se start karein.
  • Images ke important content ko accidentally hide na karein.
  • Gradients ko carefully adjust karke smooth edges banayein.
  • Different browsers mein masking effects test karein.

Summary

CSS Masking ka use elements ke visible area ko control karne ke liye hota hai. mask-image ke saath gradients aur images use karke circular, diagonal, faded aur other creative effects create kiye ja sakte hain. mask-position, mask-size aur mask-repeat se mask ko aur control kiya ja sakta hai.
