CSS Pseudo-Elements

CSS Pseudo-Elements ka use kisi HTML element ke specific part ko style karne ke liye kiya jata hai. Iski madad se hum element ke first letter, first line, before content, after content aur selection jaise parts ko directly style kar sakte hain.

CSS Pseudo-Elements Kya Hai?

Pseudo-Element CSS ka ek special feature hai jiske through hum kisi HTML element ke complete element ko style karne ke bajay uske kisi particular part ko style kar sakte hain.

For example, agar ek paragraph ke sirf first letter ko bada aur different color ka banana hai, to hum ::first-letter pseudo-element ka use kar sakte hain. Isi tarah paragraph ki sirf first line ko style karne ke liye ::first-line use hota hai.

Pseudo-elements ka use decorative content add karne ke liye bhi kiya jata hai. Iske liye ::before aur ::after sabse useful pseudo-elements hain. Inki help se hum HTML mein extra element add kiye bina visual content create kar sakte hain.

Pseudo-Element Syntax

Modern CSS mein pseudo-elements ko generally double colon :: ke saath likha jata hai. Double colon browser ko batata hai ki hum element ke kisi special part ko target kar rahe hain.

Basic Syntax 

selector::pseudo-element {
  property: value;
}

1. ::first-letter

::first-letter pseudo-element ka use kisi text ke sirf first letter ko style karne ke liye hota hai.

Iska use normally articles, blogs, magazines aur newspaper-style designs mein kiya jata hai. Aap first letter ko bada, bold ya different color ka bana sakte ho. Isse paragraph ka starting part visually attractive lagta hai.

First Letter Example

p::first-letter {
  font-size: 40px;
  font-weight: bold;
  color: #4d6fff;
}

2. ::first-line

::first-line pseudo-element ka use paragraph ya kisi text element ki visible first line ko style karne ke liye hota hai.

Important baat ye hai ki first line screen size ke according change ho sakti hai. Desktop par first line mein zyada words aa sakte hain, jabki mobile screen par wahi line chhoti ho jayegi. Isliye responsive design mein iska behavior automatically adjust hota hai.

First Line Example

p::first-line {
  color: #4d6fff;
  font-weight: bold;
}

3. ::before

::before pseudo-element ka use kisi element ke content se pehle generated content add karne ke liye hota hai.

Ye decorative icons, quotation marks, bullets, labels aur different visual effects banane mein useful hai. Iska sabse important part content property hai. Agar generated text ya character add karna hai to normally content property specify karni padti hai.

Before Example

h2::before {
  content: "★ ";
  color: gold;
}

Is example mein heading ke text se pehle star symbol automatically add ho jayega.

4. ::after

::after pseudo-element ::before ke opposite kaam karta hai. Ye kisi element ke content ke baad generated content add karta hai.

::after ka use decorative lines, icons, badges, quotation marks aur hover effects mein bahut hota hai. Web design mein kai baar ek extra HTML element banane ki zarurat nahi padti kyunki ::after se hi visual element create kiya ja sakta hai.

After Example

h2::after {
  content: " ✓";
  color: #4ade80;
}

5. ::selection

::selection pseudo-element ka use tab hota hai jab user webpage ke text ko mouse se select karta hai.

Default browser selection color ko customize karne ke liye iska use kiya ja sakta hai. Aap selected text ka background aur text color change kar sakte ho.

Selection Example

::selection {
  background-color: #254ccb;
  color: white;
}

6. ::marker

::marker pseudo-element ka use list items ke marker ko style karne ke liye kiya jata hai.

Normal unordered list mein bullet aur ordered list mein number marker hota hai. ::marker ki help se hum marker ka color aur kuch supported text properties change kar sakte hain.

Marker Example

li::marker {
  color: #4d6fff;
  font-size: 24px;
}

Practical Before & After Example

Ab ek practical example dekhte hain jahan ::before aur ::after dono ka use kiya gaya hai. Ye type ka design headings, cards aur section titles mein commonly use kiya ja sakta hai.

Complete Example

<h2>Learn CSS</h2>

h2::before {
  content: "★ ";
  color: gold;
}

h2::after {
  content: " →";
  color: #4d6fff;
}

Pseudo-Class vs Pseudo-Element

Pseudo-class aur pseudo-element naam mein similar lagte hain, lekin dono ka kaam different hai. Pseudo-class generally element ki state ya condition ko target karta hai, jabki pseudo-element element ke kisi specific part ko target karta hai.

Feature Pseudo-Class Pseudo-Element
Purpose State ya condition Element ka specific part
Example :hover ::before
Syntax Single colon Double colon

Pseudo-Elements Kahan Use Hote Hain?

  • Paragraph ke first letter ko stylish banane ke liye.
  • Paragraph ki first line ko highlight karne ke liye.
  • Heading ke before ya after decorative content add karne ke liye.
  • Buttons aur links mein icons ya visual effects add karne ke liye.
  • Lists ke bullets ya numbers ko customize karne ke liye.
  • Selected text ka appearance customize karne ke liye.
  • Extra HTML elements create kiye bina decorative design banane ke liye.

Common Mistakes

  • ::before aur ::after mein content property ko bhool jana.
  • Pseudo-class aur pseudo-element ko same samajhna.
  • ::first-letter ko poore paragraph par apply hone wala selector samajhna.
  • Decorative content ke liye unnecessary extra HTML elements banana.
  • ::before aur ::after ko use karte waqt positioning aur layout ko properly manage na karna.

Important Points

  • Pseudo-elements ko modern CSS mein generally double colon :: ke saath likha jata hai.
  • ::first-letter sirf first letter ko target karta hai.
  • ::first-line text ki first line ko target karta hai.
  • ::before element ke content se pehle generated content add karta hai.
  • ::after element ke content ke baad generated content add karta hai.
  • ::selection selected text ko style karne ke liye use hota hai.
  • ::marker list markers ko style karne ke liye useful hai.
  • ::before aur ::after ke saath generated content ke liye content property important hoti hai.
  • Pseudo-elements website ke visual design ko improve karne ke liye bahut useful hain.

Summary

CSS Pseudo-Elements ka use HTML elements ke specific parts ko style karne aur decorative content create karne ke liye hota hai. Ye webpage ke design ko bina unnecessary HTML elements add kiye improve karne mein help karte hain.

Sabse important pseudo-elements mein ::first-letter, ::first-line, ::before, ::after, ::selection aur ::marker aate hain. In concepts ko properly samajhne ke baad aap headings, paragraphs, lists, buttons aur cards ko aur zyada professional tarike se design kar sakte ho.
