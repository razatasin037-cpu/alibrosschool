CSS Shadows

CSS Shadows ka use elements aur text ke around shadow effect dene ke liye kiya jata hai. Isse design ko depth aur attractive look milta hai.

CSS Shadow Kya Hai?

CSS shadow kisi element ke peeche ek dark ya colored effect create karta hai. Box ke liye box-shadow aur text ke liye text-shadow use hota hai.

box-shadow

box-shadow ka use kisi box, card, button ya container ke around shadow lagane ke liye kiya jata hai.

Example 

.card {
  box-shadow: 5px 5px 10px gray;
}

Horizontal aur Vertical Offset

Shadow mein pehli value horizontal position aur doosri value vertical position ko control karti hai. Positive aur negative values direction change kar sakti hain.

Example 

.box {
  box-shadow: 10px 8px 12px gray;
}

Blur Effect

Third value blur radius hoti hai. Blur value badhne par shadow zyada soft aur spread hua dikhai deta hai.

Example 

.card {
  box-shadow: 0 8px 20px gray;
}

Spread Radius

Spread radius shadow ko expand ya shrink karta hai. Ye blur value ke baad likha jata hai.

Example 

.box {
  box-shadow: 0 0 15px 5px gray;
}

Shadow Color

Shadow ka color bhi set kar sakte hain. RGBA ka use karke shadow ko transparent bhi banaya ja sakta hai.

Example 

.card {
  box-shadow:
    0 5px 20px rgba(0, 0, 0, 0.4);
}

Multiple Shadows

Ek element par multiple shadows bhi laga sakte hain. Har shadow ko comma se separate kiya jata hai.

Example 

.box {
  box-shadow:
    0 5px 10px gray,
    0 10px 25px rgba(0,0,0,.3);
}

text-shadow

text-shadow ka use text ke peeche shadow effect lagane ke liye hota hai. Ye headings aur special text designs mein useful hai.

Example 

h1 {
  text-shadow: 2px 2px 5px gray;
}

Practical Example

Cards mein subtle shadow use karke clean aur modern design banaya ja sakta hai.

Complete Example 

.card {
  padding: 30px;
  border-radius: 15px;
  background: white;

  box-shadow:
    0 8px 25px rgba(0, 0, 0, 0.25);
}

Important Points

  • box-shadow elements ke around shadow lagata hai.
  • text-shadow text ke around shadow lagata hai.
  • Blur radius shadow ko soft banata hai.
  • Spread radius shadow ka size control karta hai.
  • Multiple shadows ko comma se separate kiya ja sakta hai.

Summary

CSS Shadows se elements aur text ko depth effect diya ja sakta hai. Elements ke liye box-shadow aur text ke liye text-shadow property use hoti hai.
