CSS Flex Items

CSS Flex Items woh direct child elements hote hain jo Flex Container ke andar hote hain. In items ko flex-grow, flex-shrink, flex-basis, flex, order aur align-self se control kiya ja sakta hai.

Flex Items Kya Hai?

Jab kisi parent element par display: flex lagate hain, uske direct children Flex Items ban jaate hain. Flex Item ki properties parent ke andar uski size aur position ko control karti hain.

Basic Example 

.container {
  display: flex;
}

.item {
  flex-grow: 1;
}

Important Flex Item Properties

Property Kaam
flex-grow Extra space mein item ka growth control karta hai.
flex-shrink Space kam hone par item ka shrink control karta hai.
flex-basis Item ka initial main size set karta hai.
flex Grow, shrink aur basis ka shorthand hai.
order Items ka visual order change karta hai.
align-self Individual item ki cross-axis alignment control karta hai.

Important Points

  • Flex Items Flex Container ke direct children hote hain.
  • flex-grow extra space mein item ka size increase karta hai.
  • flex-shrink available space kam hone par shrinking control karta hai.
  • flex-basis initial main size set karta hai.
  • flex grow, shrink aur basis ka shorthand hai.
  • order visual order change karta hai.
  • align-self individual item ki alignment change karta hai.

Common Mistakes

  • Flex Item properties ko parent par apply kar dena.
  • flex-grow aur flex-shrink ke purpose ko confuse karna.
  • order change karne se HTML ka actual order change samajhna.
  • flex-basis ko fixed width ke exactly same samajhna.

Best Practices

  • Responsive cards ke liye flex shorthand useful hai.
  • Items ko equal growth dene ke liye flex: 1 simple option hai.
  • Visual ordering ke liye order carefully use karein.
  • Individual alignment ke liye align-self use karein.

Summary

CSS Flex Items, Flex Container ke direct children hote hain. flex-grow, flex-shrink, flex-basis, flex, order aur align-self se individual items ki size, order aur alignment ko control kiya ja sakta hai.
