CSS 3D Transforms

CSS 3D Transforms ka use elements ko three-dimensional space mein move, rotate aur scale karne ke liye kiya jata hai. Isme X, Y aur Z axes ka use hota hai. perspective, rotateX(), rotateY(), translate3d() aur scale3d() important functions hain.

CSS 3D Transform Kya Hai?

2D transforms mein X aur Y axes hoti hain, jabki 3D transforms mein Z-axis bhi add ho jati hai. Isse element ko depth ke saath screen ke andar ya bahar move kiya ja sakta hai.

Basic 3D Transform 

.box {
  transform: rotateY(45deg);
}

1. perspective()

perspective() 3D element ki depth ko visible banata hai. Perspective value jitni chhoti hogi, 3D effect utna strong dikhega.

Perspective Example 

.box {
  transform:
    perspective(600px) rotateY(45deg);
}

7. transform-style

transform-style batata hai ki child elements 3D space mein preserve honge ya flat ho jayenge. preserve-3d commonly use kiya jata hai.

preserve-3d 

.container {
  transform-style:
    preserve-3d;
}

8. backface-visibility

backface-visibility control karta hai ki element rotate hone ke baad uska back side visible rahega ya hidden hoga.

Backface Example 

.card {
  backface-visibility:
    hidden;
}

11. transform-origin

transform-origin transformation ka pivot point define karta hai. Isse rotation ka starting point control kiya ja sakta hai.

Is practical example mein perspective, rotateX, rotateY, translateZ aur scale ko ek saath use kiya gaya hai.

Important Points

  • 3D transforms mein X, Y aur Z axes hoti hain.
  • rotateX() X-axis ke around rotate karta hai.
  • rotateY() Y-axis ke around rotate karta hai.
  • rotateZ() Z-axis ke around rotate karta hai.
  • translate3d() X, Y aur Z direction mein movement deta hai.
  • perspective 3D depth ko visible banata hai.
  • transform-style: preserve-3d nested 3D elements ke liye useful hai.
  • backface-visibility back side ko control karta hai.

Best Practices

  • 3D effects ko simple aur purposeful rakhein.
  • Smooth effects ke liye transition use karein.
  • Perspective ko carefully choose karein.
  • Excessive 3D effects se readability affect ho sakti hai.

Summary

CSS 3D Transforms elements ko three-dimensional space mein manipulate karne ke liye use hote hain. Isme rotateX(), rotateY(), rotateZ(), translate3d(), scale3d() aur perspective() important hain. Inka use karke interactive cards, hover effects aur depth-based UI create ki ja sakti hai.
