CSS Tables

CSS Tables Kya Hai?

CSS ka use HTML tables ko attractive aur readable banane ke liye kiya jata hai.

CSS se table ke borders, padding, alignment, colors, spacing aur hover effects ko control kar sakte hain.

1. Basic Table

HTML mein table banane ke liye <table>, <tr>, <th> aur <td> elements use hote hain. 

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>

  <tr>
    <td>Ali</td>
    <td>20</td>
  </tr>
</table>

2. Table Border

Table aur cells ke around border add karne ke liye border property use hoti hai. 

table, th, td {
  border: 1px solid white;
}

3. Border Collapse

border-collapse property se adjacent borders ko ek single border mein combine kiya ja sakta hai. 

table {
  border-collapse: collapse;
}

4. Table Width

width property se table ki width set ki ja sakti hai. 

table {
  width: 100%;
}

5. Table Height

height property se table rows ya cells ki height control ki ja sakti hai. 

td {
  height: 50px;
}

6. Table Text Alignment

text-align property se table ke text ko left, center ya right align kiya ja sakta hai. 

td {
  text-align: center;
}

7. Vertical Alignment

vertical-align property cell ke content ko vertically align karti hai. 

td {
  vertical-align: middle;
}

8. Table Padding

Cells ke andar spacing dene ke liye padding use hoti hai. 

th, td {
  padding: 15px;
}

9. Table Colors

background-color aur color properties se table ka background aur text color change kar sakte hain. 

th {
  background-color: #254ccb;
  color: white;
}

10. Table Hover Effect

:hover pseudo-class se mouse ko table row ke upar le jaane par background change kar sakte hain. 

tr:hover {
  background-color: #1e293b;
}

11. Zebra Striped Table

:nth-child(even) ka use alternate rows ko different background dene ke liye kiya ja sakta hai. 

tr:nth-child(even) {
  background-color: #1e293b;
}

12. Responsive Table

Large tables ko small screens par responsive banane ke liye table ko ek scrollable container ke andar rakha ja sakta hai. 

.table-container {
  overflow-x: auto;
}

table {
  width: 100%;
}

Practical Example 

table {
  width: 100%;
  border-collapse: collapse;
}

th, td {
  border: 1px solid #64748b;
  padding: 12px;
  text-align: left;
}

th {
  background-color: #254ccb;
  color: white;
}

tr:hover {
  background-color: #1e293b;
}

Important Points

  • border table aur cells ke around border create karta hai.
  • border-collapse borders ko combine karta hai.
  • padding cells ke andar spacing ke liye use hoti hai.
  • text-align table content ki horizontal alignment set karta hai.
  • vertical-align vertical alignment control karta hai.
  • :hover se table rows mein hover effect add kar sakte hain.
  • :nth-child(even) se zebra-striped tables banayi ja sakti hain.

CSS Tables Quick Summary

CSS se HTML tables ko attractive aur readable bana sakte hain.

Borders, padding aur alignment ko customize kiya ja sakta hai.

Hover effects aur zebra stripes tables ko better UI dete hain.

Responsive tables small screens par bhi usable reh sakti hain.
