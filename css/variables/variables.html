CSS Variables

CSS Variables reusable values ko store karne ke liye use hote hain. Isse colors, spacing, sizes aur themes ko easily manage aur update kar sakte hain.

CSS Variables Kya Hai?

CSS Variables ko custom properties bhi kaha jata hai. Variable ka naam usually -- se start hota hai aur uski value ko var() se use kiya jata hai.

Ye card CSS Variables ka use kar raha hai.

Basic Syntax

Variable define karne ke liye property name ko -- se start karte hain.

Example 

:root {
  --main-color: #2563eb;
  --text-color: white;
}

.box {
  color: var(--text-color);
  background: var(--main-color);
}

:root Variables

:root mein define ki gayi variables generally poori document mein available hoti hain. Global colors aur common spacing ke liye ye bahut useful hain.

Global Primary Color

Code 

:root {
  --primary-color: #2563eb;
}

.box {
  background: var(--primary-color);
}

var() Function

Variable ki stored value ko use karne ke liye var() function ka use hota hai.

Example 

:root {
  --primary-color: #2563eb;
}

button {
  background: var(--primary-color);
}

Local Variables

Variable kisi specific selector ke andar bhi define ki ja sakti hai. Aisi variable ka scope us element aur uske descendants tak hota hai.

Ye local variable se green color le raha hai.

Example 

.box {
  --local-color: green;
  color: var(--local-color);
}

Fallback Value

Agar variable available nahi hai to var() ke andar fallback value provide kar sakte hain.

Fallback color apply hua hai.

Example 

.box {
  color: var(--unknown-color, blue);
}

Variables with calc()

CSS Variables ko calc() ke saath combine karke dynamic values create kar sakte hain.

Variable + calc() Example

Code 

:root {
  --base-size: 20px;
}

.text {
  font-size: calc(var(--base-size) + 4px);
}

Important Points

  • CSS Variables ko custom properties bhi kaha jata hai.
  • Variable names normally -- se start hote hain.
  • Stored value ko use karne ke liye var() use hota hai.
  • :root global variables define karne ke liye useful hai.
  • Variables ko colors, spacing, sizes aur themes ke liye reuse kar sakte hain.
  • Fallback value var(--name, fallback) format mein di ja sakti hai.
  • Variables ko calc() ke saath bhi use kar sakte hain.

Common Mistakes

  • Variable name ke beginning mein -- na lagana.
  • Variable define karke var() use na karna.
  • Local variable ko galat scope mein use karna.
  • Undefined variable ke liye fallback na dena jab fallback required ho.
  • Variable names ko unclear ya inconsistent rakhna.

Best Practices

  • Common colors aur spacing ko variables mein store karein.
  • Global variables ke liye :root ka use karein.
  • Variable names meaningful rakhein.
  • Themes ke liye variables ka use karein.
  • Reusable values ko baar-baar hard-code karne se avoid karein.

Summary

CSS Variables reusable CSS values ko store karne ka powerful way hain. Variable ko --name se define aur var(--name) se use kiya jata hai. :root global variables ke liye, fallback values missing variables ke liye aur calc() dynamic calculations ke liye useful hai. Variables ka use code ko clean, consistent aur easy to maintain banata hai.
