CSS Links

CSS Links Kya Hai?

CSS ka use HTML links ko attractive banane aur unke color, decoration, background aur hover effect ko control karne ke liye kiya jata hai.

Links ko normally <a> element ke through create kiya jata hai.

1. Basic Link

HTML mein basic link banane ke liye <a> tag use hota hai. 

<a
  href="https://example.com"
>
  Visit Website
</a>

2. Link Color

color property se link ka color change kiya ja sakta hai. 

a {
  color: #4d6fff;
}

3. Remove Underline

Default underline ko remove karne ke liye text-decoration: none use kar sakte hain. 

a {
  text-decoration: none;
}

4. Link Hover

:hover pseudo-class ka use mouse link ke upar le jaane par style change karne ke liye hota hai. 

a:hover {
  color: red;
}

5. Link States

CSS mein links ke different states ko pseudo-classes ke through style kiya ja sakta hai.

a:link

Normal, unvisited link.

a:visited

User ke visited link ko style karta hai.

a:hover

Mouse link ke upar hone par apply hota hai.

a:active

Link click karte waqt apply hota hai.

6. Link Background

Link ke background ko background-color property se change kiya ja sakta hai. 

a {
  background-color: #254ccb;
  color: white;
}

7. Link as a Button

CSS ki help se normal link ko button jaisa design bhi diya ja sakta hai. 

a {
  background-color: #254ccb;
  color: white;
  padding: 12px 20px;
  text-decoration: none;
  border-radius: 8px;
}

8. Link with Border 

a {
  border: 2px solid #4d6fff;
  padding: 10px 18px;
  border-radius: 10px;
}

Practical Example 

a {
  color: white;
  background-color: #254ccb;
  padding: 12px 20px;
  border-radius: 10px;
  text-decoration: none;
}

a:hover {
  background-color: #304cd6;
}

Important Points

  • Links HTML mein <a> tag se create hote hain.
  • color se link ka color change kar sakte hain.
  • text-decoration: none se underline remove kar sakte hain.
  • :hover se mouse hover effect create kar sakte hain.
  • Links ko CSS se button jaisa design diya ja sakta hai.

CSS Links Quick Summary

CSS links ki appearance ko control karta hai.

Links ke color, background aur decoration ko change kar sakte hain.

Hover effect ke liye :hover use hota hai.

CSS se links ko buttons ki tarah bhi style kar sakte hain.
