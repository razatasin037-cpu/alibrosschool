CSS Image Styling

CSS ka use karke images ko stylish aur responsive banaya ja sakta hai. Hum images par border, radius, shadow, opacity, hover effects aur captions jaise effects apply kar sakte hain.

Basic Image Styling

Image ko style karne ke liye normal CSS properties jaise width, height, border aur border-radius use ki ja sakti hain.

Basic Example 

img {
  width: 300px;
  height: 200px;
  border-radius: 20px;
}

1. Rounded Images

border-radius se image ke corners ko rounded banaya ja sakta hai.

2. Circular Image

Image ko completely circular banane ke liye border-radius: 50% use kiya ja sakta hai.

Circular Image Code 

img {
  border-radius: 50%;
}

3. Image Border

Image ke around border add karne ke liye border property use hoti hai.

4. Image Shadow

box-shadow image ko depth aur elevation effect deta hai.

5. Image Opacity

opacity se image ko partially transparent banaya ja sakta hai.

Hover the Image

Opacity Code

}

img:hover {
  opacity: 1;

12. Practical Example

Complete Image Style 

.image {
  width: 100%;
  max-width: 500px;
  height: 300px;
  object-fit: cover;
  border-radius: 20px;
  box-shadow:
    0 20px 40px rgba(0,0,0,0.3);
  transition:
    transform 0.5s ease;
}

.image:hover {
  transform: scale(1.05);
}

Important Points

  • border-radius se rounded aur circular images ban sakti hain.
  • border se image ke around border add hota hai.
  • box-shadow image ko depth deta hai.
  • opacity se transparency control hoti hai.
  • object-fit fixed-size containers mein image ko properly fit karta hai.
  • transition aur transform se smooth hover effects banaye ja sakte hain.
  • Responsive images ke liye max-width: 100% useful hai.

Common Mistakes

  • Image ka fixed width rakhkar responsive behavior ignore karna.
  • object-fit ke bina fixed dimensions use karna.
  • Bahut zyada shadows aur hover effects use karna.
  • Images mein meaningful alt text na dena.

Best Practices

  • Images ko responsive rakhein.
  • Correct aspect ratio maintain karne ke liye object-fit use karein.
  • Meaningful images ke liye proper alt text likhein.
  • Hover effects ko subtle aur smooth rakhein.

Summary

CSS Image Styling se images ko rounded, circular, bordered, shadowed aur responsive banaya ja sakta hai. Opacity, transform, transition aur object-fit jaise properties ke saath attractive aur professional image designs create kiye ja sakte hain.
