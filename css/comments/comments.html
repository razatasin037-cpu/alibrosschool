CSS Comments

CSS Comments Kya Hote Hain?

CSS comments ka use code ke andar notes ya explanations likhne ke liye kiya jata hai. Browser comments ko ignore karta hai, isliye comments webpage par display nahi hote.

Comments developer ko code ko samajhne, organize karne aur future mein code ko easily maintain karne mein help karte hain.

CSS Comment Syntax

CSS mein comment /* se start aur */ se end kiya jata hai. 

/*
  This is a CSS comment
*/

Simple CSS Comment

Aap kisi CSS rule ke upar comment likhkar bata sakte hain ki us rule ka kaam kya hai. 

/* Main heading ka color */

h1 {
  color: blue;
}

Rule Ke Upar Comment

Usually comments ko us CSS rule ke upar likhna useful hota hai jiske baare mein comment information de raha hai. 

/* Website ka main background */

body {
  background-color: lightgray;
}

/* Main heading */

h1 {
  color: darkblue;
}

CSS Rule Ke Andar Comment

Comment ko CSS declaration block ke andar bhi likha ja sakta hai. 

h1 {

  color: blue;

  /* Heading ko center mein rakhen */

  text-align: center;

}

Multi-Line Comment

Agar comment lamba ho to usse multiple lines mein bhi likh sakte hain. Bas comment /* se start aur */ se end hona chahiye. 

/*
  Ye website ke main heading ka style hai.
  Is heading ko center mein rakha gaya hai.
  Color blue rakha gaya hai.
*/

h1 {
  color: blue;
  text-align: center;
}

CSS Code Ko Temporarily Disable Karna

Comments ka ek useful use kisi CSS rule ko temporarily disable karna bhi hai. Isse rule code mein rahta hai, lekin browser usse apply nahi karta. 

h1 {
  color: blue;
}

/*
p {
  color: red;
}
*/

Comments Ka Use Kahan Kare?

Explanation

Complex CSS ko samjhane ke liye notes add kar sakte hain.

Debugging

Kisi CSS rule ko temporarily disable karke problem find kar sakte hain.

Team Work

Team members ke liye important information comments mein likhi ja sakti hai.

Code Organization

Large CSS files mein different sections ko identify karna easy ho jata hai.

Real-Life Example

Ek large website mein CSS file bahut badi ho sakti hai. Comments ki help se developer easily identify kar sakta hai ki kaunsa section kis purpose ke liye hai. 

/* Header Section */

header {
  height: 80px;
}

/* Navigation Section */

nav {
  display: flex;
}

/* Footer Section */

footer {
  padding: 20px;
}

Important Points

  • CSS comments /* */ ke andar likhe jate hain.
  • Browser comments ko ignore karta hai.
  • Comments webpage par normally display nahi hote.
  • Comments single-line ya multi-line ho sakte hain.
  • Comments ka use CSS code ko explain aur organize karne ke liye kiya ja sakta hai.
  • CSS rules ko temporarily disable karne ke liye bhi comments useful hain.

CSS Comments Quick Summary

CSS comments /* */ ke andar likhe jate hain.

Browser CSS comments ko ignore karta hai.

Comments code ko explain aur organize karne mein help karte hain.

Comments ke through CSS rules ko temporarily disable kiya ja sakta hai.
