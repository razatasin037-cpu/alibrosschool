CSS Custom Fonts

CSS Custom Fonts ki help se website mein apni font files use kar sakte hain. Isse website ka text design aur appearance better hota hai.

Custom Font Kya Hai?

Custom font ka matlab hai ki hum browser ki default fonts ke alawa kisi external font file ko website mein load karke use karte hain.

@font-face

@font-face rule ka use custom font ko CSS mein define karne ke liye kiya jata hai.

Example 

@font-face {
  font-family: "MyFont";
  src: url("myfont.woff2");
}

body {
  font-family: "MyFont";
}

Font File Formats

Common web font formats mein WOFF, WOFF2, TTF aur OTF shamil hain. Web projects mein WOFF2 commonly preferred hota hai.

Example 

@font-face {
  font-family: "CustomFont";
  src:
    url("font.woff2") format("woff2");
}

Custom Font Weight

Agar font ka specific weight available ho, to font-weight ke through us weight ko define kiya ja sakta hai.

Example 

@font-face {
  font-family: "MyFont";
  src: url("bold-font.woff2");
  font-weight: 700;
}

Font Style

Custom font ke saath normal ya italic style bhi define kiya ja sakta hai.

Example 

@font-face {
  font-family: "MyFont";
  src: url("italic-font.woff2");
  font-style: italic;
}

External Fonts

Google Fonts jaise external font services se bhi fonts load kiye ja sakte hain. Iske liye HTML mein font stylesheet include ki jati hai.

Example 

<link
  href="https://fonts.googleapis.com/css2?family=Poppins"
  rel="stylesheet"
>

body {
  font-family: "Poppins", sans-serif;
}

Practical Example

Ek custom font ko define karke heading aur paragraph dono mein use kar sakte hain.

Complete Example 

@font-face {
  font-family: "WebsiteFont";
  src: url("website.woff2") format("woff2");
}

body {
  font-family: "WebsiteFont", sans-serif;
}

h1 {
  font-weight: 700;
}

Important Points

  • Custom fonts define karne ke liye @font-face use hota hai.
  • Font file ka correct path dena zaroori hai.
  • WOFF2 web fonts ke liye commonly useful format hai.
  • Font weight aur style ko bhi define kiya ja sakta hai.
  • External font services se bhi fonts load kiye ja sakte hain.

Summary

CSS Custom Fonts ki help se website mein external ya custom font files use ki ja sakti hain. @font-face rule custom fonts define karne ka main method hai.
