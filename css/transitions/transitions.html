CSS Transitions

CSS Transitions ka use kisi element ke property change ko smoothly animate karne ke liye kiya jata hai. Isse sudden change ke bajay gradual effect milta hai. Transitions ko mostly :hover, :focus aur interactive UI elements ke saath use kiya jata hai.

CSS Transition Kya Hai?

Transition kisi CSS property ke old value se new value tak hone wale change ko specified duration mein smoothly perform karta hai. Example ke liye button ka background color hover par gradually change kiya ja sakta hai.

Basic Transition 

.button {
  background: #254ccb;
  transition: background 0.5s ease;
}

.button:hover {
  background: #22c55e;
}

Important Points

  • Transition CSS property changes ko smooth banata hai.
  • transition-property property select karta hai.
  • transition-duration animation ka time set karta hai.
  • transition-timing-function speed behavior control karta hai.
  • transition-delay start hone se pehle wait time set karta hai.
  • Transition ko shorthand mein bhi likh sakte hain.
  • Transform, opacity, color, shadow aur dimensions ke saath transitions useful hain.

Common Mistakes

  • Duration define na karna.
  • Transition ko wrong element par apply karna.
  • Bahut long duration use karna.
  • Har property ko unnecessarily animate karna.
  • User experience ko ignore karke excessive effects use karna.

Best Practices

  • Generally short aur smooth duration use karein.
  • Interactive elements par meaningful transitions use karein.
  • Transform aur opacity jaise properties smooth UI effects ke liye useful hain.
  • Accessibility ke liye motion ko excessive na banayein.

Summary

CSS Transitions elements ke CSS property changes ko smoothly animate karne ke liye use hote hain. Iske important parts transition-property, transition-duration, transition-timing-function aur transition-delay hain. Inhe shorthand transition property ke through bhi likha ja sakta hai.
