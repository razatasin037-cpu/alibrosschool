CSS Tooltips

CSS Tooltip ek small information box hota hai jo user ko kisi element ke baare mein extra information dikhata hai. Ye commonly hover karne par show hota hai.

Tooltip Kya Hai?

Tooltip ek hidden element hota hai jo kisi button, link, icon ya other element par hover karne ke baad visible ho jata hai.

Basic Tooltip 

.tooltip {
  position: relative;
}

.tooltip-text {
  visibility: hidden;
  opacity: 0;
  position: absolute;
}

.tooltip:hover .tooltip-text {
  visibility: visible;
  opacity: 1;
}

Tooltip Arrow

Tooltip ke saath ::after pseudo-element use karke small arrow create kiya ja sakta hai.

Arrow Example 

.tooltip-text::after {
  content: "";
  position: absolute;
  top: 100%;
  border-width: 7px;
  border-style: solid;
  border-color:
    #1e293b transparent transparent transparent;
}

Practical Example

Complete Tooltip 

.tooltip {
  position: relative;
}

.tooltip-text {
  visibility: hidden;
  opacity: 0;
  position: absolute;
  bottom: 135%;
  left: 50%;
  transform: translateX(-50%);
  transition: opacity 0.3s ease;
}

.tooltip:hover .tooltip-text {
  visibility: visible;
  opacity: 1;
}

Important Points

  • Tooltip usually hover par show hota hai.
  • Parent element ko generally position: relative diya jata hai.
  • Tooltip ko position: absolute se place kiya ja sakta hai.
  • visibility aur opacity se tooltip ko hide/show kiya ja sakta hai.
  • Tooltip ko top, bottom, left aur right position kiya ja sakta hai.
  • ::after se tooltip arrow create kiya ja sakta hai.
  • Transition se tooltip ko smooth appearance diya ja sakta hai.

Common Mistakes

  • Tooltip ko proper position na dena.
  • Z-index ki wajah se tooltip ka doosre elements ke peeche chale jana.
  • Tooltip text ko bahut long rakhna.
  • Important information ko sirf tooltip ke andar hide karna.

Best Practices

  • Tooltip ko short aur useful rakhein.
  • Tooltip ko viewport ke bahar overflow hone se bachayein.
  • Important information ke liye tooltip par completely depend na karein.
  • Smooth transition use karke better user experience dein.

Summary

CSS Tooltips small information boxes hain jo user interaction par extra information show karte hain. Inhe position, visibility, opacity, transform aur transition jaise CSS properties ke saath easily create kiya ja sakta hai.
