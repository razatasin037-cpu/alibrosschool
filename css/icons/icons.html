CSS Icons

CSS Icons Kya Hai?

Icons website ke different parts ko visually represent karne ke liye use kiye jaate hain.

CSS ke saath icon libraries jaise Font Awesome, Bootstrap Icons aur Google Material Icons ko easily use kiya ja sakta hai.

1. Font Awesome Icons

Font Awesome ek popular icon library hai jisme bahut saare ready-made icons available hain. 

<i
  class="fa-solid fa-house"
></i>

House Icon

2. Add Icon Library

Icon library use karne ke liye uski CSS file ko HTML ke <head> section mein add karna hota hai. 

<link
  rel="stylesheet"
  href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css"
/>

3. Change Icon Size

Icons ka size CSS ke font-size property se change kiya ja sakta hai. 

.icon {
  font-size: 50px;
}

4. Change Icon Color

Icons ka color normal CSS color property se change kiya ja sakta hai. 

.icon {
  color: blue;
}

6. Icon With Button

Icons ko buttons ke andar bhi use kiya ja sakta hai. 

<button>
  <i
    class="fa-solid fa-download"
  ></i>
  Download
</button>

7. Icon Spacing

Icon aur text ke beech spacing dene ke liye margin ya gap use kar sakte hain. 

.icon {
  margin-right: 10px;
}

Practical Example 

.my-icon {
  font-size: 40px;
  color: #4d6fff;
  margin-right: 10px;
}

Important Points

  • Icons website ko visually attractive banate hain.
  • Font Awesome ek popular icon library hai.
  • Icons ko CSS se size aur color diya ja sakta hai.
  • Icons ko buttons, links aur navigation mein use kiya ja sakta hai.
  • Icon library ko HTML ke <head> mein include karna hota hai.

CSS Icons Quick Summary

CSS ke saath icon libraries easily use ki ja sakti hain.

Font Awesome mein bahut saare ready-made icons available hain.

Icons ka size aur color CSS se change kiya ja sakta hai.

Icons buttons aur navigation ko easy to understand banate hain.
