CSS Fonts

CSS Fonts Kya Hai?

CSS font properties ka use webpage ke text ka font, size, style, weight aur appearance change karne ke liye kiya jata hai.

Fonts website ko readable aur attractive banane mein important role play karte hain.

1. Font Family

font-family property decide karti hai ki text ka font kaunsa hoga. 

p {
  font-family: Arial;
}

2. Font Size

font-size property text ka size change karti hai. 

p {
  font-size: 20px;
}

3. Font Weight

font-weight property text ko normal, bold ya kisi specific thickness mein show karti hai. 

h1 {
  font-weight: bold;
}

4. Font Style

font-style property text ko normal, italic ya oblique style mein display karti hai. 

p {
  font-style: italic;
}

5. Font Variant

font-variant property text ko small-caps jaise format mein display kar sakti hai. 

p {
  font-variant: small-caps;
}

6. Font Stretch

font-stretch available font variations ke according text ko condensed ya expanded karne ke liye use hoti hai. 

p {
  font-stretch: condensed;
}

7. Google Fonts

Website mein external fonts bhi use kiye ja sakte hain. Google Fonts ek popular source hai. 

@import url('https://fonts.googleapis.com/css2?family=Poppins');

body {
  font-family: Poppins;
}

8. Font Shorthand

font shorthand property se multiple font properties ko ek hi line mein likha ja sakta hai. 

p {
  font: italic bold 20px Arial;
}

9. Generic Font Families

Serif

Letters ke edges par small strokes hote hain.

Sans-serif

Simple fonts jinke edges par strokes nahi hote.

Monospace

Har character same width ka hota hai.

Cursive

Handwriting style jaisa appearance.

Fantasy

Decorative aur stylish fonts.

System-ui

User ke operating system ka default UI font.

Practical Example 

h1 {
  font-family: Arial, sans-serif;
  font-size: 40px;
  font-weight: bold;
  font-style: italic;
}

Important Points

  • font-family font ka type select karta hai.
  • font-size text ka size set karta hai.
  • font-weight text ki thickness control karta hai.
  • font-style italic ya normal style ke liye use hota hai.
  • font-variant small-caps jaise formats ke liye use hota hai.
  • Multiple font properties ko font shorthand se likh sakte hain.

CSS Fonts Quick Summary

CSS Fonts text ke appearance ko control karte hain.

Font family aur font size sabse commonly used properties hain.

Font weight se text ko bold ya light banaya ja sakta hai.

Google Fonts jaise external fonts bhi use kiye ja sakte hain.
