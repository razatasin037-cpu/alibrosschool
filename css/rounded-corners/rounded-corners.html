CSS Rounded Corners

CSS Rounded Corners ka use HTML elements ke sharp corners ko smooth aur rounded banane ke liye kiya jata hai. Iske liye CSS mein sabse important property border-radius hai. Cards, buttons, images, input fields, containers aur modern UI components mein rounded corners bahut commonly use hote hain. Is chapter mein hum border-radius ko basic se advanced level tak examples ke saath samjhenge.

CSS Rounded Corners Kya Hai?

Normally HTML elements jaise div, button ya input box ke corners square hote hain. CSS ki border-radius property in corners ko round kar deti hai. Radius jitna increase karenge, corners utne hi zyada curved dikhai denge.

Rounded corners website ko modern aur visually clean appearance de sakte hain. Lekin har element par same radius use karna zaroori nahi hai. Buttons ke liye small radius, cards ke liye medium radius aur pill-shaped elements ke liye bahut large radius use kiya ja sakta hai.

border-radius Syntax

Rounded corners banane ke liye basic syntax bahut simple hai. Selector ke andar border-radius property likhkar uski value set karni hoti hai. Value pixels, percentage ya other supported length units mein di ja sakti hai.

Basic Example 

.box {
  border-radius: 15px;
}

Is example mein box ke chaaron corners ka radius 15px hai. Matlab top-left, top-right, bottom-right aur bottom-left sabhi corners same amount se round honge.

Different Border Radius Values

Aap ek hi value dene ke alawa multiple values bhi de sakte hain. Values ki position ke according different corners control hote hain. Isse har corner ko individually ya group mein customize kiya ja sakta hai.

Four Values Example 

.box {
  border-radius: 10px 20px 30px 40px;
}

Jab chaar values di jaati hain, to order hota hai: top-left, top-right, bottom-right aur bottom-left. Is order ko yaad rakhna important hai, especially jab custom shapes design kar rahe hon.

Two Values Ka Use

Agar sirf do values di jaati hain, to pehli value top-left aur bottom-right corners par apply hoti hai, aur doosri value top-right aur bottom-left corners par apply hoti hai. Ye symmetrical designs banane ke liye useful hai.

Two Values Example 

.box {
  border-radius: 20px 40px;
}

Ismein top-left aur bottom-right ka radius 20px hoga, jabki top-right aur bottom-left ka radius 40px hoga. Is technique se simple box ko interesting shape diya ja sakta hai.

Three Values Ka Use

Teen values ke case mein pehli value top-left, doosri top-right aur bottom-left, aur teesri bottom-right corner par apply hoti hai. Is shorthand behavior ko samajhna useful hai kyunki CSS shorthand properties mein values repeat ki ja sakti hain.

Three Values Example 

.box {
  border-radius: 10px 20px 30px;
}

Individual Corners Ko Control Karna

Kabhi-kabhi hume chaaron corners par same radius nahi chahiye hota. CSS mein har corner ke liye separate properties available hain. In properties ki help se aap ek specific corner ko independently round kar sakte hain.

Individual Corner Example 

.box {
  border-top-left-radius: 30px;
  border-top-right-radius: 10px;
  border-bottom-right-radius: 30px;
  border-bottom-left-radius: 10px;
}

Individual corner properties tab useful hoti hain jab design mein asymmetric shape chahiye. Example ke liye ek card ka sirf top-left aur bottom-right corner zyada rounded rakha ja sakta hai.

Percentage Ke Saath Rounded Corners

border-radius mein percentage values bhi use ki ja sakti hain. Percentage responsive designs mein useful ho sakta hai kyunki radius element ke dimensions ke relative calculate hota hai.

Percentage Example 

.box {
  width: 300px;
  height: 200px;
  border-radius: 20%;
}

Percentage radius especially flexible shapes ke liye useful ho sakta hai. Lekin percentage ka behavior element ke dimensions par depend karta hai, isliye complex designs mein output browser mein check karna achha practice hai.

Circle Banana

Agar element ki width aur height equal ho aur border-radius: 50% use kiya jaye, to square element circle ki shape le sakta hai. Ye profile pictures, icons, status indicators aur avatar designs mein commonly use hota hai.

Circle Example 

.circle {
  width: 150px;
  height: 150px;
  border-radius: 50%;
}

Width aur height equal hone ki wajah se 50% radius element ko circular shape deta hai. Agar width aur height equal na hon, to result circle ki jagah ellipse jaisa dikh sakta hai.

Pill Shape Banana

Buttons, badges aur tags ke liye pill-shaped design bahut popular hai. Ismein element ki height comparatively chhoti hoti hai aur border radius ko kaafi large value diya jata hai. Isse left aur right side completely rounded appearance deti hain.

Pill Button Example 

.pill {
  padding: 10px 25px;
  border-radius: 999px;
}

Large radius value ka purpose element ko pill-like shape dena hai. Ye approach modern UI mein buttons, categories, filters aur status badges ke liye frequently use hoti hai.

Cards Mein Rounded Corners

Cards modern websites ka common component hain. Product cards, blog cards, profile cards aur dashboard panels mein rounded corners design ko softer appearance dete hain. Card ke andar content ko proper padding dena bhi important hai.

Card Example 

.card {
  width: 320px;
  padding: 25px;
  border: 1px solid #334155;
  border-radius: 20px;
}

Card mein radius ke saath padding aur border ka combination use kiya gaya hai. Isse card ka outer shape rounded hota hai aur content ke around comfortable spacing maintain hoti hai.

Images Ko Rounded Karna

Rounded corners sirf containers ke liye nahi hain. Images par bhi border-radius apply kiya ja sakta hai. Isse normal rectangular image ko rounded image ya circular avatar mein convert kiya ja sakta hai.

Rounded Image Example 

img {
  width: 250px;
  border-radius: 20px;
}

.avatar {
  width: 120px;
  height: 120px;
  border-radius: 50%;
}

Buttons Ko Rounded Karna

Buttons par rounded corners use karna modern interface design mein common hai. Small radius se subtle rounded button milta hai, jabki large radius se pill-style button create hota hai.

Rounded Button Example 

button {
  padding: 12px 24px;
  border: none;
  border-radius: 12px;
  cursor: pointer;
}

border-radius Aur overflow

Kabhi-kabhi parent container ko rounded corners dene ke baad uske andar ka image ya background rounded shape ke bahar visible ho sakta hai. Aise situation mein overflow: hidden useful hota hai.

Overflow Example 

.card {
  border-radius: 20px;
  overflow: hidden;
}

overflow: hidden child content ko parent ke rounded boundary ke andar clip karta hai. Ye especially image cards mein useful hai jahan image card ke top corners ke saath perfectly match karni hoti hai.

Complete Practical Example

Ab ek practical card design dekhte hain jisme rounded container, rounded image, button aur pill badge ko ek saath use kiya gaya hai. Real websites mein isi tarah multiple rounded components combine kiye ja sakte hain.

Complete Example 

.product-card {
  width: 320px;
  padding: 20px;
  border: 1px solid #334155;
  border-radius: 20px;
  overflow: hidden;
}

.product-card img {
  width: 100%;
  border-radius: 15px;
}

.tag {
  display: inline-block;
  padding: 6px 14px;
  border-radius: 999px;
}

button {
  padding: 12px 22px;
  border: none;
  border-radius: 10px;
}

Common Mistakes

Beginners aksar border-radius ko sirf visual decoration samajhte hain, lekin layout ke context ko bhi consider karna important hai. Bahut bada radius small element par unexpected shape create kar sakta hai.

Ek common mistake hai circle banane ke liye unequal width aur height ke saath 50% use karna. Agar proper circle chahiye, to generally width aur height equal rakhna easier hota hai.

Dusri mistake rounded parent ke andar overflowing child content ko ignore karna hai. Image ya background agar parent ke rounded corners se bahar aa raha ho, to overflow: hidden ko consider kiya ja sakta hai.

Best Practices

  • UI ke different components ke liye consistent border-radius values maintain karein.
  • Buttons aur badges ke liye unnecessarily extreme radius use na karein jab tak pill shape required na ho.
  • Circle banate waqt equal width aur height ka use karna simple approach hai.
  • Rounded cards ke andar overflowing images ke liye overflow behavior check karein.
  • Shorthand aur individual corner properties ko situation ke according use karein.
  • Different screen sizes par rounded components ka appearance test karein.

Important Points

  • CSS mein rounded corners ke liye mainly border-radius property use hoti hai.
  • Ek value dene par chaaron corners same radius lete hain.
  • Multiple values se different corners ko customize kiya ja sakta hai.
  • Individual corners ke liye border-top-left-radius jaise properties available hain.
  • Equal width aur height ke element par border-radius: 50% se circle banaya ja sakta hai.
  • Large radius values pill-shaped buttons aur badges ke liye useful hoti hain.
  • Images, cards, buttons aur input elements par rounded corners apply kiye ja sakte hain.
  • Rounded parent ke andar overflowing content ke liye overflow: hidden useful ho sakta hai.

Summary

CSS Rounded Corners ke liye border-radius property ka use kiya jata hai. Is property se normal square corners ko smooth aur rounded appearance diya ja sakta hai. Aap ek, do, teen ya chaar values ke through different corner combinations create kar sakte hain. Individual corner properties se aur bhi precise control milta hai. Equal dimensions aur 50% radius se circle banaya ja sakta hai, jabki large radius se pill-shaped buttons aur badges create kiye ja sakte hain. Modern website design mein cards, images, buttons, forms aur other UI components ko visually improve karne ke liye rounded corners kaafi useful hain.
