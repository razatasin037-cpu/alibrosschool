CSS Background Size

CSS background-size property ka use background image ka size control karne ke liye kiya jata hai.

Background Size Kya Hai?

background-size se hum decide karte hain ki background image element ke andar kitni badi ya chhoti dikhni chahiye.

Basic Example 

.box {
  background-image: url("image.jpg");
  background-size: cover;
}

background-size: cover

cover image ko poore element ko cover karne ke liye resize karta hai. Zarurat padne par image ka kuch part crop ho sakta hai.

Example 

.hero {
  height: 300px;
  background-image: url("hero.jpg");
  background-size: cover;
  background-position: center;
}

background-size: contain

contain image ko poora visible rakhta hai. Image crop nahi hoti, lekin element ke andar empty space aa sakta hai.

Example 

.product {
  width: 400px;
  height: 250px;
  background-image: url("product.png");
  background-size: contain;
  background-repeat: no-repeat;
}

Custom Background Size

Hum background image ka custom width aur height bhi set kar sakte hain.

Example 

.box {
  background-image: url("pattern.png");
  background-size: 200px 100px;
}

Percentage Size

Percentage ka use karke background image ka size element ke according set kiya ja sakta hai.

Example 

.banner {
  background-image: url("banner.jpg");
  background-size: 100% 100%;
}

Multiple Background Images

Multiple background images ke saath har image ka size alag se define kiya ja sakta hai.

Example 

.box {
  background-image:
    url("logo.png"),
    url("background.jpg");

  background-size:
    80px, cover;
}

Important Points

  • cover element ko poora cover karta hai.
  • contain poori image ko visible rakhta hai.
  • Custom width aur height bhi set kar sakte hain.
  • Percentage values responsive layouts mein useful hain.
  • Multiple backgrounds ke liye multiple sizes comma se likhe ja sakte hain.

Summary

CSS background-size property background image ka size control karti hai. Isme cover, contain, pixels aur percentages jaise values ka use kiya ja sakta hai.
