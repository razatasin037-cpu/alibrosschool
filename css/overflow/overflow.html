CSS Overflow

CSS ka overflow property tab useful hota hai jab kisi element ke andar ka content uske available area se bada ho jata hai. Is property ki help se hum decide kar sakte hain ki extra content ko kaise handle karna hai.

CSS Overflow Kya Hai?

Jab kisi HTML element ki width ya height fixed hoti hai aur uske andar ka content us available space se bahar nikalne lagta hai, to is situation ko overflow kaha jata hai.

CSS ka overflow property hume control deta hai ki ye extra content visible rahe, hide ho, scroll ho ya automatically handle ho.

Overflow ka use specially fixed-height boxes, cards, menus, tables, images aur responsive layouts mein bahut useful hota hai.

CSS Overflow Syntax

Overflow property ko CSS mein simple tarike se is tarah likha jata hai:

Example 

.box {
  width: 200px;
  height: 100px;
  overflow: hidden;
}

CSS Overflow ki Values

CSS overflow property ki kuch important values hoti hain:

  • visible – extra content normally visible rahega.
  • hidden – extra content hide ho jayega.
  • scroll – scrollbars available ho jayenge.
  • auto – browser zarurat ke according scrolling provide karega.

overflow: visible

visible overflow ki default value hoti hai. Isme agar content element ke box se bahar nikalta hai, to wo content visible rehta hai.

Example

.box {
  width: 200px;
  height: 100px;
  overflow: visible;
}

Is case mein extra content ko browser hide nahi karega. Content box ke bahar bhi dikh sakta hai.

overflow: hidden

hidden value extra content ko element ke box ke bahar display nahi hone deti.

Jo content defined width ya height se bahar chala jata hai, wo visible nahi hota.

Example

.box {
  width: 200px;
  height: 100px;
  overflow: hidden;
}

overflow: scroll

scroll value use karne par element ke andar scrolling ki facility available ho jati hai.

Content kam ho tab bhi browser scrollbar show kar sakta hai.

Example

.box {
  width: 200px;
  height: 100px;
  overflow: scroll;
}

overflow: auto

auto value browser ko allow karti hai ki jab content overflow kare, tab zarurat ke according scrollbar provide kare.

Isliye responsive layouts mein overflow: auto kaafi useful hota hai.

Example

.box {
  width: 300px;
  height: 150px;
  overflow: auto;
}

overflow-x

overflow-x horizontal direction mein hone wale overflow ko control karta hai.

Agar content left aur right side se bahar nikal raha hai, to overflow-x ka use kiya ja sakta hai.

Example

.box {
  width: 300px;
  overflow-x: auto;
}

overflow-y

overflow-y vertical direction mein hone wale overflow ko control karta hai.

Agar content upar ya neeche ki taraf available height se bahar ja raha hai, to overflow-y useful hota hai.

Example

.box {
  height: 200px;
  overflow-y: auto;
}

overflow-x aur overflow-y Together

Hum horizontal aur vertical overflow ko separately bhi control kar sakte hain.

Example

.box {
  width: 300px;
  height: 150px;

  overflow-x: auto;
  overflow-y: hidden;
}

Real World Example

Overflow ka practical use tables mein bahut common hai. Mobile screen par agar table bahut wide ho, to hum horizontal scrolling allow kar sakte hain.

Responsive Table Example

.table-container {
  overflow-x: auto;
}

table {
  min-width: 700px;
}

Isse chhoti screen par table page ko break nahi karega. User horizontal scroll karke table ko dekh sakta hai.

Overflow Values mein Difference

Value Kya Karta Hai?
visible Extra content visible rehta hai.
hidden Extra content hide ho jata hai.
scroll Scrolling available hoti hai.
auto Zarurat padne par scrollbar aata hai.

Important Points

  • visible overflow ki default value hai.
  • hidden extra content ko hide karta hai.
  • scroll scrolling provide karta hai.
  • auto zarurat ke according scrolling provide karta hai.
  • overflow-x horizontal overflow control karta hai.
  • overflow-y vertical overflow control karta hai.
  • Responsive tables aur containers mein overflow bahut useful hai.

CSS Overflow Summary

CSS ka overflow property tab use hota hai jab element ke andar ka content uski available width ya height se bahar nikal jata hai.

visible, hidden, scroll aur auto iski important values hain. Horizontal aur vertical overflow ko separately control karne ke liye overflow-x aur overflow-y use kiye ja sakte hain.
