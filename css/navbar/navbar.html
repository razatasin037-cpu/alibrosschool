CSS Navigation Bar

CSS Navigation Bar website ka ek important part hota hai. Navigation bar ki help se users website ke different pages ya sections par easily ja sakte hain. CSS ka use karke hum navigation links ko horizontal, vertical, responsive aur attractive bana sakte hain.

CSS Navigation Bar Kya Hai?

Navigation Bar ek aisa section hota hai jisme website ke important links diye jate hain. Jaise Home, About, Services, Contact, Login aur Products. User in links par click karke website ke different pages par navigate kar sakta hai.

HTML navigation bar ka basic structure provide karta hai, jabki CSS us structure ko design karta hai. CSS ki help se hum links ko ek line mein arrange kar sakte hain, background color de sakte hain, padding aur spacing add kar sakte hain aur hover effects create kar sakte hain.

Modern websites mein navigation bar usually website ke top par hota hai. Lekin requirement ke according ise sidebar, vertical menu ya responsive mobile menu ke form mein bhi design kiya ja sakta hai.

Basic Navigation Bar Structure

Navigation bar banane ke liye hum generally ek nav element ke andar unordered list aur list items ka use kar sakte hain. Har list item ke andar ek anchor link hota hai.

Example 

<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
</nav>

Yahan nav navigation area ko represent karta hai. ul links ki list banata hai aur a element actual clickable navigation link provide karta hai.

List Styling Remove Karna

By default unordered list mein bullets appear hote hain. Navigation bar mein normally bullets ki zarurat nahi hoti, isliye hum list-style-type: none ka use karke bullets remove kar sakte hain.

Example 

ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}

Is CSS ke baad list ke default bullets remove ho jayenge aur navigation bar clean appearance ke saath start hoga.

Horizontal Navigation Bar

Most websites mein navigation links horizontal form mein dikhte hain. Iska matlab Home, About, Services aur Contact jaise links ek hi line mein side-by-side appear karte hain.

Iske liye hum list items ko display: inline ya display: inline-block de sakte hain.

Example 

li {
  display: inline-block;
}

li a {
  padding: 15px 20px;
  text-decoration: none;
}

Navigation Bar Ka Background

Navigation bar ko visually separate dikhane ke liye hum background color ka use kar sakte hain. Dark, light ya brand-specific color navigation ko website ke overall design ke saath match kar sakta hai.

Example 

ul {
  background-color: #1e293b;
}

a {
  color: white;
}

Navigation Links Ko Style Karna

Navigation bar ka main purpose clickable links provide karna hai. Isliye anchor element ko proper padding, color aur text-decoration dena important hota hai.

Default anchor links generally underline ke saath appear hote hain. Navigation bar mein hum text-decoration: none use karke underline remove kar sakte hain.

Example 

a {
  color: white;
  text-decoration: none;
  padding: 15px 20px;
}

Navigation Bar Mein Hover Effect

Navigation bar ko interactive banane ke liye hover effect bahut useful hota hai. Jab user kisi link par mouse le jata hai, tab background color ya text color change kiya ja sakta hai.

Example 

a {
  color: white;
  padding: 15px 20px;
  text-decoration: none;
}

a:hover {
  background-color: #334155;
}

Ab jab user link ke upar mouse move karega, us link ka background change ho jayega. Isse user ko clear visual feedback milta hai.

Active Navigation Link

Navigation bar mein user ko ye pata chalna chahiye ki wo currently website ke kis page par hai. Iske liye active link ko different background ya text color diya ja sakta hai.

Example 

.active {
  background-color: #2563eb;
  color: white;
}

Jis link par active class lagi hogi, wo baaki navigation links se visually different dikhega.

Vertical Navigation Bar

Har navigation bar horizontal hona zaroori nahi hai. Sidebar ya dashboard jaisi websites mein links vertical direction mein arrange kiye ja sakte hain.

Vertical navigation ke liye list items ko block-level layout mein rakha ja sakta hai. Har link alag line mein appear karega.

Example 

ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
  width: 200px;
}

li a {
  display: block;
  padding: 15px;
}

Complete CSS Navigation Bar Example

Ab ek complete navigation bar banate hain jisme HTML structure, background color, horizontal links, padding aur hover effect sab ek saath use kiya gaya hai.

Complete Example 

<nav>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><a href="#">Contact</a></li>
  </ul>
</nav>

ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
  background-color: #1e293b;
}

li {
  display: inline-block;
}

li a {
  display: block;
  color: white;
  padding: 16px 20px;
  text-decoration: none;
}

li a:hover {
  background-color: #334155;
}

Responsive Navigation Bar

Modern websites ko desktop ke saath mobile devices par bhi properly work karna chahiye. Agar navigation mein bahut saare links hain, to mobile screen par sabhi links ek hi line mein fit nahi honge.

CSS media queries ki help se hum screen size ke according navigation ka layout change kar sakte hain. Desktop par links horizontal aur smaller screen par vertical ho sakte hain.

Responsive Example 

li {
  display: inline-block;
}

@media (max-width: 600px) {

  li {
    display: block;
  }

  li a {
    width: 100%;
  }

}

Important Points

  • Navigation bar website ke different pages aur sections ke links provide karta hai.
  • HTML navigation ka structure banata hai aur CSS usko style karta hai.
  • list-style-type: none se default list bullets remove kiye ja sakte hain.
  • display: inline-block se navigation links ko horizontal arrange kiya ja sakta hai.
  • text-decoration: none se links ki default underline remove ki ja sakti hai.
  • :hover pseudo-class se navigation links par hover effects create kiye ja sakte hain.
  • Active page ko different styling dekar user ko current location batayi ja sakti hai.
  • Responsive navigation ke liye media queries ka use kiya ja sakta hai.

Summary

CSS Navigation Bar website ke navigation links ko organized aur attractive way mein display karne ke liye use hota hai.

Navigation bar mein hum list styling remove karke links ko horizontal ya vertical layout mein arrange kar sakte hain. Background color, padding, text color aur hover effects navigation ko better appearance dete hain.

Real-world websites mein responsive navigation bahut important hai, kyunki navigation desktop, tablet aur mobile sabhi screen sizes par properly usable hona chahiye.
