CSS Multiple Backgrounds

CSS Multiple Backgrounds ki help se hum ek hi element par ek se zyada background images ya colors use kar sakte hain. Isse websites mein decorative aur attractive designs banana easy ho jata hai.

CSS Multiple Backgrounds Kya Hai?

Normally hum kisi element par ek background image lagate hain. Lekin CSS mein hum multiple background images ko comma se separate karke ek hi element par use kar sakte hain.

Har background ke liye alag position, size aur repeat value bhi set ki ja sakti hai. Iska use banners, cards, decorative sections aur modern website designs mein hota hai.

Basic Syntax

Multiple backgrounds ke liye background-image property mein images ko comma se separate kiya jata hai.

Example 

.box {
  background-image:
    url("image1.png"),
    url("image2.png");
}

Background Layers

Multiple background images layers ki tarah kaam karti hain. CSS mein jo background pehle likha hota hai, woh upar hota hai, aur baad wala background uske neeche hota hai.

Example 

.hero {
  background-image:
    url("flower.png"),
    url("background.jpg");

  background-position:
    right bottom, left top;

  background-repeat:
    no-repeat, no-repeat;
}

Multiple Backgrounds with Gradient

Multiple backgrounds mein image ke saath gradient bhi use kiya ja sakta hai. Gradient ko image ke upar rakhkar overlay effect banaya ja sakta hai.

Example 

.banner {
  background-image:
    linear-gradient(rgba(0,0,0,.5), rgba(0,0,0,.5)),
    url("banner.jpg");

  background-size:
    cover;

  background-position:
    center;
}

Background Position

Har background image ki position separately set ki ja sakti hai. Values ko comma se separate karke first image aur second image ki position define kar sakte hain.

Example 

.card {
  background-image:
    url("logo.png"),
    url("bg.jpg");

  background-position:
    top right, center;

  background-repeat:
    no-repeat;
}

Background Size

Multiple backgrounds ke saath background-size bhi use kar sakte hain. Isse har background image ka size control kiya ja sakta hai.

Example 

.section {
  background-image:
    url("icon.png"),
    url("background.jpg");

  background-size:
    80px, cover;

  background-repeat:
    no-repeat;
}

Practical Example

Real website mein multiple backgrounds ka use hero section ko attractive banane ke liye kiya ja sakta hai.

Complete Example 

.hero {
  width: 100%;
  height: 350px;

  background-image:
    linear-gradient(rgba(0,0,0,.4), rgba(0,0,0,.4)),
    url("mountain.jpg");

  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

Important Points

  • Multiple backgrounds ko comma se separate kiya jata hai.
  • Pehla background layer sabse upar hota hai.
  • Har background ke liye position aur size set kiya ja sakta hai.
  • Gradient aur image ko ek saath use kiya ja sakta hai.
  • Multiple backgrounds design ko attractive banane mein useful hain.

Summary

CSS Multiple Backgrounds se ek element par multiple background images aur gradients use kiye ja sakte hain. Images ko comma se separate karke unki position, size aur repeat values control ki ja sakti hain.
