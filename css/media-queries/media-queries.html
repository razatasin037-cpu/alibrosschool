CSS Media Queries

CSS Media Queries ka use website ko different screen sizes aur devices ke according responsive banane ke liye kiya jata hai. Isse mobile, tablet, laptop aur desktop ke liye alag CSS rules apply kar sakte hain.

Media Queries Kya Hai?

Media Query ek CSS condition hai. Jab condition true hoti hai, browser uske andar likhe CSS rules apply karta hai. Ye responsive web design ka important part hai.

Simple Example

Agar screen 768px ya usse chhoti ho, to hum kisi element ka color, size, layout ya spacing change kar sakte hain.

Basic Syntax

Example 

@media (max-width: 768px) {
  .box {
    background: blue;
  }
}

max-width

max-width ka use tab hota hai jab screen ki width given value se kam ya equal ho.

Code 

@media (max-width: 768px) {
  .box {
    background: purple;
  }
}

@media (max-width: 480px) {
  .box {
    background: pink;
  }
}

Live Example

Browser window ko resize karke dekho. Width ke according box ka background aur padding change hoga.

Resize The Browser

Screen width ke according color change hoga.

min-width

min-width tab apply hota hai jab screen ki width given value se greater ya equal ho.

Code 

@media (min-width: 768px) {
  .box {
    background: green;
  }
}

min-width Example

768px ya usse badi screen par color change hoga.

Common Breakpoints

Responsive design mein common screen ranges ke liye breakpoints use kiye jate hain. Ye fixed rule nahi hain; project ke design ke according breakpoints choose kiye ja sakte hain.

Breakpoint Typical Use
480px Small mobile
640px Large mobile / small tablet
768px Tablet
1024px Laptop / desktop
1280px Large desktop

Responsive Grid

Media Queries ki help se grid columns ko screen size ke according change kar sakte hain.

Code 

.grid {
  display: grid;
  grid-template-columns: 1fr;
}

@media (min-width: 640px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Responsive Text

Ye text browser resize karne par change hoga.

Orientation

orientation media feature se portrait aur landscape orientation ke liye different styles apply kar sakte hain.

Orientation Example

Device ko rotate karke border change dekhein.

Code 

@media (orientation: landscape) {
  .box {
    border: 3px solid blue;
  }
}

@media (orientation: portrait) {
  .box {
    border: 3px solid purple;
  }
}

Dark Mode

prefers-color-scheme se user ke operating system ya browser ki preferred color scheme ke according styling kar sakte hain.

Color Scheme Example

System ki color preference ke according style change ho sakti hai.

Code 

@media (prefers-color-scheme: dark) {
  body {
    background: #020617;
    color: white;
  }
}

Print Media Query

print media type ka use page ko print karte waqt different styling dene ke liye kiya ja sakta hai.

Print Example

Print preview mein is box ka background aur text color change hoga.

Code 

@media print {
  .box {
    background: white;
    color: black;
  }
}

Multiple Media Queries

Ek page mein multiple media queries use kar sakte hain. Har query apni condition ke according CSS rules apply karegi.

Example 

@media (max-width: 480px) {
  .box {
    font-size: 14px;
  }
}

@media (min-width: 481px) {
  .box {
    font-size: 18px;
  }
}

@media (min-width: 1024px) {
  .box {
    font-size: 22px;
  }
}

Important Points

  • Media Queries responsive web design ke liye important hain.
  • max-width smaller screens ke liye commonly use hota hai.
  • min-width larger screens ke liye commonly use hota hai.
  • Multiple media queries ek hi page par use ki ja sakti hain.
  • Media Queries se layout, font, spacing aur colors change kar sakte hain.
  • orientation, print aur prefers-color-scheme bhi useful media features hain.
  • Breakpoints ko project ke actual design aur content ke according choose karein.

Common Mistakes

Too Many Breakpoints

Har small screen size ke liye alag breakpoint banana unnecessary complexity create kar sakta hai.

Fixed Device Assumption

Sirf popular device widths ko target karne ke bajay content ke according responsive breakpoints choose karein.

Viewport Meta Tag Missing

Mobile responsive pages mein viewport meta tag properly include karein.

Only Testing Desktop

Responsive CSS ko different screen sizes par test karna important hai.

Best Practices

  • Mobile aur desktop dono layouts ko properly test karein.
  • Breakpoints content ke according choose karein, sirf devices ke naam par nahi.
  • Media Queries ko readable aur organized rakhein.
  • Responsive layouts mein flexible units jaise %, rem aur fr ka use karein.
  • Browser resize karke intermediate widths bhi test karein.

Summary

CSS Media Queries responsive websites banane ke liye use hoti hain. max-width aur min-width se different screen sizes ke liye CSS rules apply kar sakte hain. Iske alawa orientation, print aur prefers-color-scheme jaise features bhi useful hain. Media Queries ke saath flexible layouts use karke website ko mobile se desktop tak responsive banaya ja sakta hai.
