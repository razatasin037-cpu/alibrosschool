CSS Box Sizing

CSS box-sizing property decide karti hai ki element ki total width aur height ko browser kaise calculate karega. Isme sabse important values content-box aur border-box hain.

CSS Box Sizing Kya Hai?

CSS mein har element ek box ki tarah behave karta hai. box-sizing property decide karti hai ki width aur height ke andar content, padding aur border ko kaise include kiya jayega.

Simple Idea

box-sizing ye control karti hai ki CSS width aur height sirf content ke liye hogi ya content ke saath padding aur border ko bhi include karegi.

CSS Box Model

CSS Box Model mein content, padding, border aur margin hote hain. box-sizing width aur height ki calculation ko control karti hai.

Content

Element ke andar ka actual content.

Padding

Content aur border ke beech ki space.

Border

Element ke around boundary.

Margin

Element ke bahar ki space.

Syntax

Basic Syntax 

selector {
  box-sizing: border-box;
}

content-box

content-box default value hai. Isme specified width sirf content ki width hoti hai. Padding aur border width ke bahar add hote hain.

Example 

.box {
  box-sizing: content-box;
  width: 220px;
  padding: 25px;
  border: 8px solid blue;
}

Total Width

220px content + 50px padding + 16px border = 286px total width.

Live Example: content-box

Is box ki width 220px hai, lekin padding aur border add hone ke baad iska total size 286px ho jata hai.

content-box

Total Width: 286px

border-box

border-box mein specified width ke andar content, padding aur border sab include hote hain. Isliye total width predictable rehti hai.

Example 

.box {
  box-sizing: border-box;
  width: 220px;
  padding: 25px;
  border: 8px solid blue;
}

Total Width

Specified width 220px hai, isliye padding aur border ke saath bhi total width 220px hi rahegi.

Live Example: border-box

Is box mein padding aur border already 220px ki total width ke andar included hain.

border-box

Total Width: 220px

All Elements Ko border-box Dena

Responsive layouts mein commonly sabhi elements ko border-box diya jata hai. Isse padding aur border ki wajah se unexpected width problems kam hoti hain.

Common CSS 

*, *::before, *::after {
  box-sizing: border-box;
}

100% Width Ka Problem

width: 100% ke saath agar padding aur border add kiya jaye, to content-box element parent se bahar ja sakta hai. border-box is problem ko avoid karne mein helpful hai.

Important Points

  • box-sizing width aur height ki calculation ko control karti hai.
  • content-box default value hoti hai.
  • content-box mein padding aur border specified width ke bahar add hote hain.
  • border-box mein padding aur border specified width ke andar included hote hain.
  • Responsive layouts mein border-box kaafi useful hota hai.
  • Universal selector ke through sabhi elements par border-box apply kiya ja sakta hai.

Common Mistakes

Unexpected Width

content-box ke saath padding aur border add karne par element expected width se bada ho sakta hai.

100% Width Overflow

100% width ke saath padding aur border use karte waqt content-box unwanted overflow create kar sakta hai.

Best Practices

  • Responsive layouts mein border-box consider karein.
  • Padding aur border ke saath width calculation ko dhyan mein rakhein.
  • Global box-sizing rule ko project ke start mein define kar sakte hain.
  • Different box-sizing values ko mix karte waqt layout carefully test karein.

Summary

CSS box-sizing property decide karti hai ki element ki width aur height ka calculation kaise hoga. content-box mein width content ke liye hoti hai, jabki border-box mein content, padding aur border sab specified width ke andar include hote hain. Responsive aur predictable layouts ke liye border-box bahut useful hai.
