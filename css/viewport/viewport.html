CSS Viewport

Viewport browser window ka visible area hota hai jahan webpage दिखाई deta hai. Responsive website banane ke liye viewport ko samajhna bahut important hai, especially mobile devices par.

Viewport Kya Hai?

Viewport browser ka woh visible area hai jisme webpage user ko दिखाई deta hai. Desktop par viewport usually bada hota hai, jabki mobile par viewport chhota hota hai.

Desktop Viewport

Screen generally wide hoti hai, isliye multiple columns aur larger layouts easily fit ho sakte hain.

Mobile Viewport

Screen width chhoti hoti hai, isliye layout ko responsive banana zaroori hota hai.

Viewport Meta Tag

Mobile browsers mein responsive layout ke liye HTML ke <head> section mein viewport meta tag use kiya jata hai.

Basic Viewport Tag 

<meta
  name="viewport"
  content="width=device-width, initial-scale=1"
/>

width=device-width

width=device-width browser ko batata hai ki webpage ki viewport width device ki actual screen width ke according honi chahiye.

Example 

<meta
  name="viewport"
  content="width=device-width"
/>

initial-scale=1

initial-scale=1 page ko initial load par normal 100% zoom level par display karta hai.

Common Viewport Settings

Setting Meaning
width=device-width Viewport width ko device width ke equal karta hai.
initial-scale=1 Initial zoom level ko normal rakhta hai.

Responsive Design Mein Viewport

Viewport meta tag responsive CSS ke saath milkar kaam karta hai. Media queries, flexible widths aur responsive images ko properly work karne ke liye mobile viewport setting important hai.

Responsive Viewport

Browser width change karke responsive behavior observe karein.

Complete HTML Example

Ek simple responsive page mein viewport meta tag aur responsive CSS ko is tarah use kar sakte hain.

HTML + CSS 

<!DOCTYPE html>
<html lang="en">
<head>

  <meta
    name="viewport"
    content="width=device-width, initial-scale=1"
  />

  <style>
    .container {
      width: 90%;
      max-width: 900px;
      margin: auto;
    }

    @media (max-width: 600px) {
      .container {
        width: 95%;
      }
    }
  </style>

</head>
<body>

  <div class="container">
    Responsive Content
  </div>

</body>
</html>

Important Points

  • Viewport browser ka visible area hota hai.
  • Mobile responsive pages mein viewport meta tag important hai.
  • width=device-width device ki screen width ko use karta hai.
  • initial-scale=1 initial zoom ko normal rakhta hai.
  • Viewport settings ko responsive CSS ke saath use karna best practice hai.

Common Mistakes

  • Viewport meta tag ko completely remove kar dena.
  • Mobile layout ke liye fixed width ka excessive use karna.
  • Sirf viewport par depend karna aur responsive CSS na likhna.

Best Practices

  • Standard viewport meta tag use karein.
  • Flexible widths aur responsive units use karein.
  • Media queries ke through different screen sizes handle karein.
  • Real mobile devices par bhi page test karein.

Summary

CSS Viewport browser ke visible area ko represent karta hai. Responsive websites ke liye width=device-width aur initial-scale=1 wala viewport meta tag commonly use kiya jata hai. Viewport ko responsive CSS ke saath use karne se webpage different screen sizes par better behave karta hai.
