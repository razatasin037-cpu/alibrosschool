CSS Padding

CSS Padding Kya Hai?

CSS mein padding ka use element ke content aur uske border ke beech space create karne ke liye kiya jata hai.

Simple words mein, padding element ke andar ka space hota hai.

Padding vs Margin

Margin

Element ke bahar space create karta hai.

Padding

Element ke andar content ke around space create karta hai.

Simple Example

Neeche paragraph ke andar 20px padding di gayi hai. 

p {
  padding: 20px;
}

Padding Ke 4 Sides

Padding ko chaar alag sides ke liye separately set kiya ja sakta hai.

padding-top

Content ke upar andar space.

padding-right

Content ke right andar space.

padding-bottom

Content ke neeche andar space.

padding-left

Content ke left andar space.

1. Padding Top

padding-top content ke upar andar space create karta hai. 

div {
  padding-top: 30px;
}

2. Padding Right

padding-right content ke right side mein andar space create karta hai. 

div {
  padding-right: 30px;
}

3. Padding Bottom

padding-bottom content ke neeche andar space create karta hai. 

div {
  padding-bottom: 30px;
}

4. Padding Left

padding-left content ke left side mein andar space create karta hai. 

div {
  padding-left: 30px;
}

Padding Shorthand

Chaaron sides ko ek hi padding property se set kiya ja sakta hai. 

div {
  padding: 10px 20px 30px 40px;
}

Values Ka Order

1st

Top

2nd

Right

3rd

Bottom

4th

Left

Two Values 

div {
  padding: 20px 40px;
}

Pehla value top aur bottom ke liye, aur doosra value left aur right ke liye apply hota hai.

Three Values 

div {
  padding: 10px 20px 30px;
}

Teen values mein order hota hai: top, left-right, bottom.

Padding With Border

Padding aur border ko ek saath use karke content ko border se distance diya ja sakta hai. 

div {
  padding: 20px;
  border: 2px solid blue;
}

Practical Example

Buttons, cards aur boxes mein content ko comfortable space dene ke liye padding ka bahut use hota hai. 

.card {
  padding: 25px;
  border: 2px solid #3158ff;
  border-radius: 15px;
}

Padding Aur Box Size

Normal box model mein padding element ki total size ko affect kar sakta hai. 

div {
  width: 300px;
  padding: 20px;
}

box-sizing: border-box

box-sizing: border-box use karne par padding aur border specified width ke andar include hote hain. 

div {
  box-sizing: border-box;
  width: 300px;
  padding: 20px;
}

Important Points

  • Padding element ke andar space create karta hai.
  • Padding content aur border ke beech hota hai.
  • padding-top, padding-right, padding-bottom aur padding-left separately use kiye ja sakte hain.
  • padding shorthand se multiple sides ek saath set kiye ja sakte hain.
  • Padding mein negative values use nahi ki ja sakti.
  • Padding background ke area ka part hota hai.
  • Padding element ki size ko affect kar sakta hai.

CSS Padding Quick Summary

Padding content aur border ke beech ka space hai.

Padding ki four individual side properties hoti hain.

Shorthand mein 1, 2, 3 ya 4 values use ki ja sakti hain.

Padding ka use cards, buttons aur layouts mein bahut common hai.
