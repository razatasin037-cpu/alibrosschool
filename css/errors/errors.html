CSS Errors

CSS Errors Kya Hai?

CSS code likhte waqt agar syntax, property, value ya selector mein mistake ho jaye to CSS expected tarike se work nahi karti.

CSS errors ko identify karke correct karna debugging ka important part hai.

Common CSS Errors

Syntax Error

CSS rule ka syntax galat hone par browser us rule ko properly read nahi kar pata.

Wrong Property

Agar property ka naam galat likha gaya ho to browser us property ko apply nahi karega.

Wrong Value

Property ke saath invalid value dene par styling expected tarike se work nahi karegi.

CSS File Not Linked

External CSS file HTML se properly connected na ho to CSS load nahi hogi.

1. Syntax Error

CSS syntax mein brackets, colon ya semicolon galat hone par problem aa sakti hai.

Wrong Example 

h1 {
  color: blue
  font-size: 30px;
}

Correct Example 

h1 {
  color: blue;
  font-size: 30px;
}

2. Wrong Property Name

CSS property ka exact naam use karna zaroori hai.

Wrong 

p {
  text-colour: red;
}

Correct 

p {
  color: red;
}

3. Wrong Value

Har CSS property ke liye valid values ka use karna chahiye.

Wrong 

p {
  font-size: big;
}

Correct 

p {
  font-size: 30px;
}

4. Missing Semicolon

CSS declarations ko normally semicolon ; se end kiya jata hai. 

h1 {
  color: blue;
  margin: 20px;
  padding: 10px;
}

5. Missing Curly Bracket

CSS rule ko close karne ke liye closing curly bracket } zaroori hota hai. 

h1 {
  color: blue;
  font-size: 30px;
}

CSS Work Nahi Kar Rahi Ho To?

  • Check karo CSS file HTML se properly linked hai ya nahi.
  • Selector ka naam check karo.
  • Property ka spelling check karo.
  • Property ki value valid hai ya nahi check karo.
  • Curly brackets { } properly close hain ya nahi check karo.
  • Semicolon ; missing to nahi hai check karo.
  • Browser Developer Tools ke Console aur Styles panel ko check karo.

Browser Developer Tools

Browser ke Developer Tools se hum check kar sakte hain ki CSS kis element par apply ho rahi hai aur kis rule ko browser ignore kar raha hai.

Element par right-click karke Inspect select kar sakte ho.

Styles panel mein applied CSS rules dekhi ja sakti hain.

Galat ya overridden CSS rule ko identify kiya ja sakta hai.

Important Points

  • CSS mein spelling mistakes check karo.
  • Property aur value ko carefully check karo.
  • Curly brackets properly close karo.
  • CSS declarations ke end mein semicolon use karo.
  • External CSS file ka path check karo.
  • Developer Tools debugging mein bahut useful hain.

CSS Errors Quick Summary

CSS error ka main reason syntax ya incorrect CSS rule ho sakta hai.

Property aur value ko carefully check karna chahiye.

Brackets aur semicolons ka correct use important hai.

External CSS use kar rahe ho to file path aur link check karo.

Developer Tools se CSS problems ko easily debug kiya ja sakta hai.
