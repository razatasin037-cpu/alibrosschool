CSS Pagination

CSS Pagination ka use jab content multiple pages mein divide hota hai tab users ko pages ke beech navigate karne ke liye kiya jata hai.

CSS Pagination Kya Hai?

Pagination ka matlab hai large content ko chhote-chhote pages mein divide karna. CSS se hum pagination links ko attractive, responsive aur easy to use bana sakte hain.

Basic Pagination

Sabse simple pagination mein page numbers ko links ke form mein show kiya jata hai.

Example 

.pagination {
  display: flex;
  gap: 8px;
}

.pagination a {
  padding: 10px 16px;
  background: #1e293b;
  color: white;
  text-decoration: none;
}

Responsive Pagination

Mobile screens par pagination links wrap ho sakte hain. Isliye flex-wrap: wrap useful hota hai.

Code 

.pagination {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

Important Points

  • Pagination large content ko multiple pages mein divide karta hai.
  • display: flex se links ko easily arrange kar sakte hain.
  • Active page ko different background se highlight karein.
  • Previous aur Next buttons navigation ko easy banate hain.
  • Mobile ke liye flex-wrap ka use karna useful hai.
  • Pagination links ko readable aur clickable size ka rakhein.

Common Mistakes

  • Active page ko highlight na karna.
  • Mobile screen par pagination overflow hone dena.
  • Bahut chhote clickable links banana.
  • Previous/Next button ko confusing banana.
  • Current page ka clear indication na dena.

Best Practices

  • Active page ko clearly highlight karein.
  • Pagination ko responsive rakhein.
  • Previous aur Next navigation provide karein.
  • Links ke beech proper spacing rakhein.
  • User ko clearly batayein ki kaunsa page currently active hai.

Summary

CSS Pagination ka use large content ko multiple pages mein divide karne ke liye hota hai. display: flex, gap, border-radius, background aur justify-content jaise CSS properties se attractive pagination design ki ja sakti hai. Active, disabled, Previous aur Next states ko properly style karna important hai.
