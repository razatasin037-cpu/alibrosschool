CSS Flexbox

CSS Flexbox ek powerful layout system hai jiska use elements ko row ya column mein arrange karne, align karne aur responsive layout banane ke liye kiya jata hai.

Flexbox Kya Hai?

Flexbox ka full form Flexible Box Layout hai. Iska main purpose container ke andar child elements ko efficiently arrange karna hai. Flexbox se alignment aur spacing manage karna kaafi easy ho jata hai.

Simple Idea

Flexbox mein ek parent element ko flex container banate hain aur uske direct children flex items ban jate hain.

Basic Syntax

Example 

.container {
  display: flex;
}

.item {
  padding: 20px;
}

Sirf display: flex; lagane se parent flex container ban jata hai aur uske direct child elements flex items ban jate hain.

Main Axis Aur Cross Axis

Flexbox mein do important axes hote hain: Main Axis aur Cross Axis. Default direction mein main axis horizontal hoti hai aur cross axis vertical hoti hai.

Main Axis

Default row direction mein items left se right main axis par move karte hain.

Cross Axis

Main axis ke perpendicular direction ko cross axis kehte hain.

justify-content Aur align-items

Flexbox mein justify-content main axis par alignment control karta hai, jabki align-items cross axis par alignment control karta hai.

Centered Item

Center Example 

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

Responsive Flexbox

Important Flexbox Properties

Property Use
display Flex container create karta hai.
flex-direction Items ki direction set karta hai.
flex-wrap Items ko next line mein wrap karta hai.
justify-content Main axis alignment.
align-items Cross axis alignment.
align-content Multiple flex lines ki alignment.
gap Items ke beech spacing.

Common Mistakes

Wrong Parent

Flex properties jaise justify-content aur align-items ko generally flex container par apply karna chahiye.

Axis Confusion

flex-direction change hone par main axis bhi change ho sakti hai.

No Wrap

Bahut saare items hone par required layout ke liye flex-wrap consider karein.

Fixed Width

Responsive layout mein unnecessary fixed widths overflow create kar sakti hain.

Important Points

  • display: flex parent ko flex container banata hai.
  • Flex container ke direct children flex items hote hain.
  • Default flex-direction row hoti hai.
  • justify-content main axis par alignment control karta hai.
  • align-items cross axis par alignment control karta hai.
  • flex-wrap items ko multiple lines mein arrange kar sakta hai.
  • gap flex items ke beech spacing dene ka simple way hai.

Best Practices

  • Layout ke according flex-direction carefully choose karein.
  • Spacing ke liye unnecessary margins ke bajay gap consider karein.
  • Responsive layouts mein Flexbox ko Media Queries ke saath use karein.
  • Main axis aur cross axis ka concept clear rakhein.
  • Different screen sizes par layout test karein.

Summary

CSS Flexbox ek flexible layout system hai jo elements ko row ya column mein arrange aur align karne ke liye use hota hai. display: flex se flex container create hota hai. flex-direction, flex-wrap, justify-content, align-items aur gap Flexbox ke important properties hain. Responsive layouts banane ke liye Flexbox ko Media Queries ke saath easily combine kiya ja sakta hai.
