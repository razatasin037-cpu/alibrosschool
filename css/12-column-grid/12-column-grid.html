CSS 12-Column Grid

CSS 12-Column Grid ek popular layout system hai jisme page ko 12 equal columns mein divide karke flexible aur responsive layouts banaye jaate hain.

12-Column Grid Kya Hai?

12-column grid mein container ko 12 equal columns mein divide kiya jata hai. Phir different elements ko 1, 2, 3, 4 ya multiple columns ka width diya ja sakta hai.

Basic Structure

  • Grid ko 12 equal columns mein divide kiya jata hai.
  • grid-template-columns se columns create kiye jaate hain.
  • grid-column se item ko specific columns mein place kar sakte hain.
  • 12-column system responsive layouts ke liye bahut useful hai.

1. Creating 12 Columns

Sabse pehle repeat(12, 1fr) ka use karke 12 equal columns create karte hain.

12 Columns

Example 

.container {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 10px;
}

2. grid-column

grid-column property se decide hota hai ki item kaunse column se start aur kaunse column par end hoga.

3. Four Column Layout

12 columns ko 3 equal sections mein divide karke har section ko 4 columns diye ja sakte hain.

Code 

.left {
  grid-column: 1 / 5;
}

.middle {
  grid-column: 5 / 9;
}

.right {
  grid-column: 9 / 13;
}

4. Full Width Item

Agar kisi element ko complete 12 columns ki width deni ho to grid-column: 1 / 13 use kar sakte hain.

Full Width — 12 Columns

Example 

.header {
  grid-column: 1 / 13;
}

5. Main Content + Sidebar

6. Span Keyword

span keyword se directly bataya ja sakta hai ki item kitne columns occupy karega.

Example 

.box {
  grid-column: span 4;
}

8. Responsive 12-Column Grid

Desktop par 12 columns useful hote hain, lekin mobile par simple single-column layout better ho sakta hai. Media Query se columns ko change kiya ja sakta hai.

Responsive Example 

.grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
}

@media (max-width: 700px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Important Points

  • 12-column grid mein container ko 12 equal columns mein divide kiya jata hai.
  • repeat(12, 1fr) 12 equal flexible columns create karta hai.
  • grid-column se item ki column position control hoti hai.
  • span se item ke occupied columns ki number specify kar sakte hain.
  • 12-column system complex layouts ko flexible banata hai.

Common Mistakes

  • Column numbers ko galat calculate karna.
  • grid-column mein start aur end line ko confuse karna.
  • Mobile screens par 12 columns ko bina responsive adjustment ke use karna.
  • Grid items ke beech gap ko ignore karna.

Best Practices

  • Desktop layouts ke liye 12-column structure ka use karein.
  • fr unit se flexible columns create karein.
  • Responsive layouts ke liye media queries ka use karein.
  • Layout ko unnecessarily bahut complex na banayein.

Summary

CSS 12-Column Grid mein page ko 12 flexible columns mein divide karke different layouts create kiye jaate hain. grid-template-columns, grid-column aur span ka use karke items ki width aur placement control ki ja sakti hai. Ye technique responsive websites ke layouts ke liye bahut useful hai.
