CSS Grid Item Order

CSS Grid Item Order se hum Grid Items ka visual order change kar sakte hain bina HTML ka order change kiye.

CSS Grid Item Order Kya Hai?

Grid mein items normally HTML mein jis order mein likhe hote hain, usi order mein place hote hain. order property se hum unka visual placement order change kar sakte hain.

order Property

order ek Grid Item ko ek numeric value deta hai. Items normally increasing order ke according arrange hote hain.

1. Basic order Example

Neeche HTML order 1, 2, 3 hai, lekin CSS mein order values change karne se visual order change ho gaya hai.

Example 

.item1 {
  order: 3;
}

.item2 {
  order: 1;
}

.item3 {
  order: 2;
}

2. Default Order

Agar kisi Grid Item par order property nahi lagayi gayi hai, to uska default order 0 hota hai.

Default Example 

.box {
  order: 0;
}

3. Positive Order Values

Positive values jaise 1, 2 aur 3 use karke items ka order control kiya ja sakta hai. Smaller order value pehle aati hai.

Example 

.first {
  order: 1;
}

.second {
  order: 2;
}

.third {
  order: 3;
}

4. Negative Order Values

Negative values bhi use ki ja sakti hain. Negative order values normal 0 order items se pehle place hoti hain.

6. Same Order Value

Agar multiple items ki order value same ho, to unka relative order source order ke according maintain hota hai.

Example

8. order vs HTML Order

Concept Meaning
HTML Order Source code mein elements ka actual order.
order: 0 Default visual order.
order: -1 Item ko default order se pehle la sakta hai.
order: 1, 2, 3... Items ko increasing order mein arrange karta hai.

Important Points

  • order Grid Items ka visual order change karta hai.
  • Default order value 0 hoti hai.
  • Smaller order values pehle place hoti hain.
  • Negative values items ko default order se pehle la sakti hain.
  • Same order value hone par source order maintain hota hai.

Common Mistakes

  • order property ko Grid Container par apply karna.
  • Visual order change hone ko HTML/source order change hona samajhna.
  • Bahut random order numbers use karke layout ko difficult banana.
  • Accessibility ke liye source order ko completely ignore karna.

Best Practices

  • Order values ko simple aur meaningful rakhein.
  • Important content ka logical HTML source order maintain karein.
  • Responsive layouts mein order ka carefully use karein.
  • Keyboard navigation aur accessibility ko dhyan mein rakhein.

Summary

CSS Grid Item Order mein order property ka use karke Grid Items ka visual placement change kiya jata hai. Default value 0 hoti hai, smaller values pehle aur larger values baad mein place hoti hain.
