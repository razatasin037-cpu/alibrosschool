CSS Grid Align

CSS Grid mein alignment properties ki help se Grid items aur poore Grid ko horizontal aur vertical direction mein align kiya ja sakta hai.

Grid Align Kya Hai?

Grid alignment ka use items ko unke Grid area ke andar ya poore Grid ko container ke andar position karne ke liye hota hai. Iske liye mainly justify-*, align-* aur place-* properties use hoti hain.

Basic Example 

.container {
  display: grid;
  align-items: center;
  justify-items: center;
}

Grid Alignment Values

Property Use
justify-items Items ko horizontal direction mein align karta hai
align-items Items ko vertical direction mein align karta hai
place-items justify-items + align-items
justify-content Poore Grid ko horizontal direction mein align karta hai
align-content Poore Grid ko vertical direction mein align karta hai
place-content justify-content + align-content

Important Points

  • justify-items Grid items ko horizontal direction mein align karta hai.
  • align-items Grid items ko vertical direction mein align karta hai.
  • place-items dono properties ka shorthand hai.
  • justify-content aur align-content poore Grid ko position karte hain.
  • place-content content alignment ki shorthand property hai.

Common Mistakes

  • align-items aur align-content ko same samajhna.
  • Items ko align karne ke liye justify-content use karna.
  • Container ki extra space na hone par justify-content ya align-content ka effect expect karna.
  • Grid item aur complete Grid ki alignment ko confuse karna.

Best Practices

  • Items ki alignment ke liye justify-items aur align-items use karein.
  • Poore Grid ko position karne ke liye justify-content aur align-content use karein.
  • Dono directions mein same alignment chahiye to place-items ya place-content use kar sakte hain.
  • Different screen sizes par alignment ko test karein.

Summary

CSS Grid alignment ke liye justify-items, align-items, place-items, justify-content, align-content aur place-content important properties hain. Items ko align karne aur poore Grid ko position karne ke liye alag properties use hoti hain.
